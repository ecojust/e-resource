# 五原路251号花园住宅山墙拱框百叶窗

2013年与2023年照片中右山墙的浅色拱框、后退的横百叶与紧贴窗边的红砖。

正面可数出半圆拱口里平行的深色百叶，白色衬面从叶间透出。斜向可辨百叶退在浅色拱框后，转折窗台与红砖侧缘有厚度。远档保持同样的通透节奏，外拱圆弧分段略粗。
