# 柳亚子旧居（思南书局）主楼与东侧砖券入口

上海市黄浦区复兴中路517号。此制作快照提供三档模型、作者源码及原创模型图。可编辑 Blender 原件与全城实机验收仍在进行。

模型表现修缮后花园住宅的东侧红砖券门与转折台阶、南侧两层玻璃花廊、露台、山墙、交叉坡屋顶和烟囱。建筑外形据平面、剖面与照片配准，砖缝、五金、材色和绿化细部含估计。室内、相邻住宅及外围庭院未纳入本次范围。
