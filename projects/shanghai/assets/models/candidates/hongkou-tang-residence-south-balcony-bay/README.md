# 原汤公馆南门廊中跨弧形阳台与双柱

四川北路2023弄35号南门廊的两根中央通高石柱、科林斯式柱头、弧形阳台石边及铁花栏杆，并表现其后可见的红褐色木窗。

近远正面均可分辨光面石柱、层层柱脚、卷叶柱头及栏杆。斜视可见栏杆沿阳台外弧绕回，前缘石线分出四层，后方两组木窗之间留有墙垛。修订后底层门下段有实木板；远档叶饰比近档简洁。
