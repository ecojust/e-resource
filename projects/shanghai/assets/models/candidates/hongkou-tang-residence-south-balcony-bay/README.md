# 原汤公馆南门廊中跨弧形阳台与双柱

四川北路2023弄35号南门廊的两根中央通高石柱、科林斯式柱头、弧形阳台石边及铁花栏杆，并表现其后可见的红褐色木窗。 尺寸按斜向外观照片的比例估算。两层通高、四柱与阳台形式可由区级档案和第二张照片交叉确认。
