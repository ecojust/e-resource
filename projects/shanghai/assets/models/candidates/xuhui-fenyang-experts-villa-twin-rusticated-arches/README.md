# 上海音乐学院专家楼底层双券与毛石拱饰

花园侧底层廊角连续两券和共墩，包括凿面灰石端块、三块冠石、起拱层与顶部水平檐线。 每券净跨取约2.32米为比例尺。原照无尺寸标记，厚度与墙脚标高为制作估计。
