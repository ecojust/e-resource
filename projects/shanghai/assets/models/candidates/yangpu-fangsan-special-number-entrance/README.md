# 纺三小区特号住宅门廊与石阶

许昌路227弄特号面向圆形绿地的入口，含七级石阶、两道斜杆、方柱、平挑雨篷、绿底特号牌及门上楼梯窗。 门高和踏步高度取常用范围作相片尺度估算。雨篷进深、遮挡后的柱身、门扇、墙厚及栏杆直径按照片约束。
