# 皋兰路12弄街面住宅双层圆窗与弧形带窗

市表第五批第15行写皋兰路12号；照片中的市级铭牌实写皋兰路12弄1–4号，皋兰路10号、14号。建模取铭牌后方的两层街面弧窗、同层圆窗和夹在窗带之间的水刷石带。

正面观察，两层圆窗外圈均在红砖墙前方。上层深色钢框分出多道横格，下层浅色窗框分出短亮窗。斜看时，两层弧窗都比左侧圆窗墙突出，中间的水刷石腰带沿圆角转折。近远景的窗框和窗后玻璃可分别命中。
