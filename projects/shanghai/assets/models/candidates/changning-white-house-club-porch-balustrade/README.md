# 白宫俱乐部廊顶瓶栏与浮雕柱头

1390号小白楼正面门廊的两根圆柱、浮雕柱头、齿形檐带和三面瓶栏，连同廊后的半圆券。

正面近档的十二支瓶栏之间有透空，左右圆柱上的柱头可见方形浮雕与两侧卷叶。转到斜面可看见廊后券比柱身更深，两侧栏杆回转。券下扇窗与下层菱格玻璃分别可辨，远档保留扇骨和格条。
