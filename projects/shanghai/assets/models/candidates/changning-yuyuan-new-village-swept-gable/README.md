# 愚园新村外展弧山墙

规资局原图靠近镜头的灰砖端山墙。模型取屋檐折线、两层窄窗、红砖水平带与一段退后的坡瓦面。 两道砖带与屋脊高度按原照相对量测。取端墙净宽6.40米作展示比例，屋前草地及室内没有实测定尺。
