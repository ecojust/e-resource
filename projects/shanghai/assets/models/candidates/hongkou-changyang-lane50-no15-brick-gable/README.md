# 长阳路50弄15号圆饰山墙与双层砖券门面

按2015年2月3日实照复原弄内15号门牌所在的一开间，包含花形砖圆饰、逐级叠出的山墙檐、二层弧顶窗、一层砖券、绿色号牌及三阶石级。

近、远两档正面均能辨认砖圆饰、两层浅砖券、右侧绿色15号牌和三阶石级。由左斜看，可见右窗扇向院内一侧的室外开启，石阶立面与踏面分开，敞开的下层门券可见两侧砖回转和后退的内门。
