# 公和洋行大楼切角圆章与卷草檐带

取2015年具名照片中切角正面并列的两方圆章、相邻街面可见的四方卷草板，以及下方带横线的浅色墙身、左邻窗上段和右侧阴影中的托檐。

正面两方圆章之间有竖缝，左边四方随外墙折去。转到斜面能看到卷草绕着平滑圆心，檐底和红色木窗之间留出阴影，近远两档都可辨认纹饰的排列。
