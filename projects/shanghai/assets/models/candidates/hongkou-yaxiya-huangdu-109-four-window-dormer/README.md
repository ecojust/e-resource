# 亚细亚里黄渡路109号四窗老虎窗与瓦坡

取黄渡路109号2014年街照中并列四窗的横向老虎窗，含前脸、挑檐、浅坡红瓦与左侧相接的陡瓦面。

正视和斜视都能数清四个窗洞。左两窗为浅色双扇；右两窗有深色横档和上亮。修订后的斜视能看清陡坡与窗顶浅坡之间闭合的深色侧壁，两坡瓦垄在远景仍可辨认。
