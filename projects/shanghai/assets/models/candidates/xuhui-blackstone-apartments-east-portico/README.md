# 黑石公寓复兴中路弧形柱廊东段

复兴中路1331号朝街的一层开放柱廊，仅含东端一对柱、首组前柱、这两对柱间的弯檐及其上方十格交叉石栏。 两组同期街景解得端柱对至首组前柱中心距5.75米、5.68米。剩余各层、遮挡的柱脚细部与室内不在重建范围内。
