# 中实大楼屋顶方亭双柱与弧饰额枋

以中实大楼圆转角上方的最顶层方亭为范围，展示两根圆柱、两端方墩、柱间后退暗面、五组弧形额饰及出挑檐板。

正视可逐一识别两圆柱、两方墩、五组弧形浅浮雕及柱后退进。斜视能看见柱径、外挑檐和屋顶栏杆的两个圆角。远档保留这组结构并减少圆柱与弧饰的曲面分段。
