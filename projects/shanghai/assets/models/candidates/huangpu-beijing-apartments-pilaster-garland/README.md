# 北京公寓街面椭圆花饰壁柱与双层窗楣

取北京东路163号红砖立面上一跨较高窗列和相邻通高壁柱，包含上层的浅砖券、白色券心、铁栏，下层的三角窗楣、长梯形垂石，以及壁柱上的椭圆花环。

上窗的砖券在长石形券心两侧展开，下窗三角檐的横线被垂石盖住。黑色铁栏在玻璃前方，椭圆花环和下垂串饰浮在浅色壁柱表面，两档的实射均可区分铁花前缘和后方直杆。
