# 角田公寓转角两组双联拱窗

原五层沿街转角相邻两个折面上的四扇圆头窗，含弧顶气窗、双扇竖框、转角凸带、石窗台及2024年可辨的分片窗罩。 窗净宽及窗台深度为建模估值；角度由西楼OSM连续边回算，不是对窗下街墙的测绘。
