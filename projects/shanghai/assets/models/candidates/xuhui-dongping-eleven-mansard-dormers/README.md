# 东平路11号宋氏住宅南坡三扇老虎窗

东平路11号花园主宅南坡三扇带山花的老虎窗，含两扇式木窗、叠层窗套、侧壁及相连的红瓦屋面。 三条窗轴线取自园内主屋航片，间距约3.8米；窗宽和叠线高度按修缮后正面原照片比例还原，南阳台遮住的一小段下槛经过估计。
