# 上海十六区 · 真实建筑轮廓街区模型

每个 GLB 是该区漫游起点周围约 **1 km²** 的本地建筑样本，用于下载、编辑和离线查看；在线页面通过 Overture / OpenStreetMap 数据覆盖全市。这些文件不冒充整区的完整离线模型。

所有模型均以真实公开建筑轮廓建成，保留凹形轮廓及内部空洞。未编造街道网格；河流、道路与地形由在线地图显示。

共 **8,294** 个建筑/建筑分部，总文件体积 **8.43 MB**，最大单文件 **0.966 MB**。

## 高度说明

- 91 个要素使用来源高度。
- 271 个使用来源楼层数 × 3.2 米估算。
- 7932 个没有高度或楼层标签，统一按 **12 米示意**；这不是实测高度。

## 坐标

GLB 为本地米制坐标，X 向东、Y 向上、Z 向南。每个文件的 WGS84 经纬度原点、地理范围、要素数量与高度来源见 `metadata.json`，同样写入 GLB 节点 extras。
