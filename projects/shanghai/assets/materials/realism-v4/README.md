# Bund surface maps, v4

Nine local 1K texture maps provide restrained pale-stone, granite and asphalt
grain in the Shanghai viewer. Total image download size: 4,898,227 bytes.
`src/architectural-material.js` loads these files automatically; no texture CDN
or API is needed when using the local launcher.

All maps are CC0-1.0 assets from Poly Haven. See `SOURCES.md` for authors,
original asset URLs, physical scales and the limitations of these generic
surface references. `LICENSE-CC0.txt` is the unmodified license text downloaded
from https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt .

`manifest.json` contains exact download URLs, original MD5 checksums, SHA-256
checksums, file sizes and dimensions. Stone sampling excludes the source grout;
window openings and facade stone joints remain the model's actual geometry.
