# 上海全域建筑模型

覆盖全部16区的公开源建筑体块，共 **1,708 个 GLB / 1,796,435 个建筑及部件**，总模型体积 **285.7 MB**，最大 GLB **940,388 字节**。每块都小于100,000,000字节；无需Git LFS。

这里是当前HTML加载的完整模型集合。每栋建筑按唯一归属格保存，跨格建筑不人为切开。跨区格可同时出现在多个区的下载清单中；请按格ID去重下载。每个GLB都以自己的WGS84锚点为原点，坐标 **X东 / Y上 / Z南，单位米**，不要直接把所有文件叠在世界原点。

`manifest.json` 包含坐标、实际边界、字节数、SHA-256、三角面和高度来源；`records/`保留每块完成记录；`ids/`用于与在线远景精确去重。五个精细地标单独加载，模型已去除其被核验的通用体块。

**模型完整**表示已处理展示范围内此次公开源提供的全部建筑，不代表每栋现实建筑都被地图采集，也不代表高度和立面经过实测。城市体块为LoD1；通用窗格仅用于视觉辨识。详见项目README和data/audit、data/heights。

浏览器使用Meshopt压缩；不支持此扩展的编辑器可以用项目`tools/unpack_model.py`转换，或按源码以`--no-compress`重新生成。GLB地理坐标保存在manifest/record中，编辑器不会自动进行地理定位。
