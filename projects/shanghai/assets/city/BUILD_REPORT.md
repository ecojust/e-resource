# 上海 16 区建筑模型构建报告（外滩细化 V3）

已完成 1,708 个通用 GLB，共 1,796,419 个建筑或建筑部件，27,008,894 个三角形。GLB 总大小 285,702,324 字节；最大单文件 940,388 字节，全部低于 100,000,000 字节。

范围是记录的上海16区显示边界内全部可取得的Overture源足迹，并非每栋实体建筑都已被来源测绘的保证。通用几何为真实地图轮廓的LoD1挤出；14个精细地标单独加载，其中10栋为本轮外滩历史建筑。精细模型的屋顶、檐口、柱廊和窗洞另行建模；未有实测依据的尺寸仍注明估计。

计数对账：1,796,116 个源可渲染要素 + 401 个父楼残差 − 98 个精细模型替代要素 = 1,796,419 个通用模型要素。原始地上源共 1,796,667 个UUID；原始被部件替代的父楼 551 个保留在源档案中。另有 11 个地下要素独立归档，不抬升为地上楼。

高度优先级为源 height、楼层×3.2m、严格轮廓匹配的 CMAB 预测、CNBH2020 10m 足迹像元估计、GHSL2018 约80×93m区域均值、12m缺省。除源高度外均明确属于估计；源标签本身也不等于独立测量证明。残差裙房不继承父楼总高或楼层数，独立按残差轮廓估计高度。

当前 401 个通用残差父体保留约953,540m²面积。V2 基线为402个；本轮中国银行主楼残差已由其完整精细模型替代。原始残差处理剔除42个总残差≤1m²的父体残差，合计22.635866m²。V2网格审计中1mm点距/0.01m²退化环阈值另略去94个极小polygon片，共0.104702m²，未丢弃任何一个恢复父体；该数值是原始基线的几何机制审计，非本轮新测量。原始残差GeoJSON仍保留全部组件。

完整审计通过：所有GLB与IDs文件SHA256、GLB2完整二进制长度、三角形数、1,796,667个源UUID的sidecar成员关系、每条输出记录唯一归属以及16区计数。孔洞/法线/闭合性抽样通过；压缩保留所有已成模三角形。局部float32误差约0.061mm；已检压缩格最大单轴舍入约1.7cm。

坐标：WGS84经纬度origin + 局部米制，X东/Y上/Z南。完整建筑按源owner格唯一分配，不在格边界切断；geographic_bbox为owner格，geometry_bbox为真实几何延伸范围。

每块GLB使用EXT_meshopt_compression与KHR_mesh_quantization。网页需MeshoptDecoder；不支持的建模软件可用提供的源码及 --no-compress 重建普通GLB。
