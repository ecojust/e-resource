# 刘氏花园住宅庭院山墙核查

市房管局名录4B020列长乐路786号、784号，市级铭牌记为1930年代建。2015年的庭院近照及2018年的独立总照均可辨右侧露木山墙、四扇二层白框窗、底层折面凸窗。近照还可读出凸窗中央的双语牌。建模范围止于该段浅屋面和窗旁墙面，左面素山墙、连续拱窗、两处街门及屋后仍由原城表现。[来源与年代](../../../source/precise/jingan-liu-residence-changle-courtyard-gable/reference-review.json) · [独立模型页](../../../liu-residence-changle-courtyard-gable.html)
