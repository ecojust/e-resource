# 黄浦路106号联合国大厦灰楼北立面

市级名录2F001同时登记黄浦路106号的红楼和灰楼。2014年1月27日街面原片、虹口区政府另一处机位和方志所引1945、1947及1973年远景共同定位了朝向黄浦路的灰色石质正面。原片可辨六根凹槽壁柱、五个柱间、三座中央门洞和顶层七组成对窗。1948年1月，多家联合国机构使用的灰楼定名为“联合国大厦”。1911年滨江红楼保留原有城市轮廓。[照片署名、分别建造的两栋楼及年代差异](../../../source/precise/hongkou-unrra-gray-building-north-front/README.md)

三个GLB逐档实测六根壁柱各六道真凹槽、门叶后退、中央横带与壁柱相接的节点、两翼竖窗、阁楼石饰和檐口，每档115条射线。近景与原生均为28,664个三角面，远景为5,676个三角面。桌面和390像素触屏各自实际打开正视、斜视和远景，四个下载均由浏览器保存并逐字节核对。小屏远景能分清三道门和六根柱，石缝、柱槽深浅及小浮雕纹样难以辨读。[几何检查](surface-checks.json) · [独立页实测](viewer.json) · [两版比照与目检](visual-review.json)
