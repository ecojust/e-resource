# 上海京剧传习馆1号楼鹅卵石墙与门楣双圆饰

徐汇文旅2021年3月的《1号楼抢先看》照片中，“1号楼”标字就在鹅卵石墙面上。其左侧门套有两枚扁圆饰，往上接门柱的折线柱头和向外逐级挑出的收边。本作截取门楣右部与旁边一小段干粘石外墙。
