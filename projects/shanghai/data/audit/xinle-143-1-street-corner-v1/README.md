# 新乐坊143-1号临街前楼
     
按2018年原照、2015至2021年的街景和2019、2025年的航片制作临街前楼及弄内7.1米窗墙。近景673个闭合构件、21,850个三角形，远景661个闭合构件、18,358个三角形。弄口绿色门牌与店门黑色143-1牌分别位于两处墙面。临街钢窗分格、两个穿墙金属件、灰门框与玻璃、灯箱与布蓬招牌、入口黄柱和压槽均按原片复核。

每档门面51处、七樘钢窗51处均直接命中预期材质。单独复核首层东段橱窗、绿门和表箱的7处观察均命中。弄内34处有27处直接命中，33处在对应1050像素图幅的3像素范围内命中。屋檐40处有20处直接命中，38处在画宽0.6%的范围内命中。斜向冬季站仍保留两处偏差，分别位于细管和远端檐槽。街侧和弄内可核部位分别建模，后排房屋及弄口对面的地物仍维持原样。[测量与模型源码](../../../source/precise/xuhui-xinle-143-1-street-corner/README.md) · [双站模型对照](registration/street-stations-model.jpg)


八项下载已生成，包含可重建的源码包、网页与原始GLB、远景模型、可编辑Blender、FBX、OBJ/MTL和STL。源码包经独立重建，所得三份发布GLB和四张纹理完全相同。Blender保留276个分组、九台相机和两处原照视角，全部机位均实渲检查。OBJ包保留材料发光参数及适用于Blender的读取脚本，STL为米制三角网。[模型页与下载](../../../xinle-143-1-street-corner.html)
