# 公园坊24号弧形砖凸窗

二层三扇窗随弧形墙面转向。中窗下扇向外打开，能看到棕色扇背和浅色自由边。它遮住右窗横档和左边框的一小段。一层三扇有宽白横档，上亮的下半部装有带卷花的细铁条。三扇各自以一段白色下横框收在连续的石窗台上。

2019年9月16日，上海学习平台刊出虹口区《上海市优秀历史建筑——公园坊》。第6张图片的图注和绿色门牌都指向24号。窗体量测使用这张640×853像素的照片，窗框边沿读数约有1.5至3.5个像素误差。外开角约95°，由单张照片的自由边估计。专题图用两档模型重现原来的观察角度。[图文出处](https://www.xuexi.cn/lgpage/detail/index.html?id=16613037030431701524)

六个孔的两侧边点与二层窗台、两排窗头和中横档定义在同一相机中。逐窗文件保存了像点、预期材料、网格实际首先相交的三角面和三维坐标。针对被外开扇遮挡的两个检查点，文件还保存了后方固定框的材料及首先相交的扇体深度。

2022年3月5日，“文化虹口”在澎湃号刊出的《纪念“左联”成立92周年｜美联：战斗的画作》将另一幅照片题作“野风画会旧址”。绿色24号、弧形砖窗和三扇窗所在的石窗台都在同一画面；文章将画会当时的使用面积记为37平方米。照片未标拍摄日期。两照的同名点、窗脚估高和斜视时的像素偏差见测量文档。专题另记六处直接观察到的玻璃、十五处底框的实际首交结果。[图文出处](https://www.thepaper.cn/newsDetail_forward_16981350)

用2022年的斜视照片观察最右窗，原先较深的玻璃被模型木框挡住。缩小玻璃与木框正面的距离以后，可以看见照片中的玻璃。测量记录保留了35、5和4毫米三种模型设置的首交结果；斜视角度与像素读数都会影响推定值。
