# 公园坊24号拱下灰墙、木框与红色壁箱

2022年3月刊发的《野风画会旧址》照片中，可辨门内灰粉墙、深红木框和外伸的红色壁箱。模型依据可见轮廓绘制。壁箱的用途和铭文缺少可辨的影像证据。[照片出处](https://www.thepaper.cn/newsDetail_forward_16981350)

按原图538 × 802像素复核，原始网、近景解码网、远景解码网分别命中19处可辨表面。另以暗部木梃的判读点（103，250）检查边界。三档在此点均先碰到券内暗砖，向左移2像素至（101，250）即碰到深红木梃。这处边界单独记录。
