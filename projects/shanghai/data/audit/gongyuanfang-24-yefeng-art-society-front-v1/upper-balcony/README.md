# 公园坊24号三层弧形露台

2019年刊登的正面照片题作「公园坊24号现状」。露台正面的铁栏和水泥边缘沿弧线弯出，浅色两道唇口之间有一道暗槽。上方檐梁走直线。右端有宽卵石饰面墙墩，左端有一截浅色实心矮墙。[虹口区《上海市优秀历史建筑——公园坊》，图4、图6](https://www.xuexi.cn/lgpage/detail/index.html?id=16613037030431701524)

同篇图4从斜侧面只拍到露台左端。两图共有的卵石纹理可用来对齐这片灰山墙。用图4天际线另核图6的三个檐缘点，纵向差依次为−0.54、−0.76、+0.11像素。右端铁栏受枝叶遮挡，模型沿用左段可读的间距。后部深阴影按可见横梁收口；投影板中最深的暗面是模型剖切面。
