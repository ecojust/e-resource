# 皋兰路17号花园住宅临街灰卵石山墙与折窗

灰色卵石墙中嵌红棕百叶和木格，底层折窗有三面玻璃，瓦罩上方另有浅砖券。 [历史照片与出处](references.md)

近景模型有60,545个三角面，远景模型有6,521个。两份下载均为内嵌全部资源的 GLB，可直接在支持 glTF 的查看器中打开。[近景 GLB](gaolan-gable-near.glb) · [远景 GLB](gaolan-gable-far.glb)
