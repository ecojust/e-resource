# 凤阳路450号小楼半圆山花与绶带花环

取凤阳路450号小楼正面左侧凸部阳台上方的半圆山花、双涡卷及绶带浮饰。2017年5月21日，Fayhoo从院门方向拍到两座同类侧部与较低的中央屋檐。
