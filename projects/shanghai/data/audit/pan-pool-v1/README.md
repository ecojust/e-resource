# 泮池与登云桥候选构件验证

本记录只覆盖独立模型与查看页，不是城市接入或测绘复原验收。

- geometry.json：完整模型35,024面，远景7,632面；实际 Meshopt 解码后三角形顶点与原始文件一致，坐标有限、三角面无退化、无重复索引面。LOD仅减少曲线采样与雕刻近似，台阶数量和拱洞保持。
- structure-full.json、structure-lod.json：实际导出网格各106条水平射线验证拱洞贯通；逐级检查两端共24个水平踏面，以及两处池面高度。它不是行走碰撞或现场尺寸校验。
- native.json：Blender导入数量与源GLB相等，保存后重新打开的建筑网格哈希一致。native-geometry.json进一步比较已保存原生文件与源GLB的实际三角顶点，排除展示地面等舞台对象。
- browser.json：真实Chromium验证完整/远景加载、手动切换、损坏文件拒绝并保留原模型、重试、距离自动切换与回返、移动端无横向溢出；检查无页面异常。qa-browser.cjs可以配合本地HTTP服务复跑。
- 两种原始GLB从源码重新生成后逐字节一致；所有模型和解码文件均小于100,000,000字节。通用 model-resources.test.mjs 通过。

初次导出出现22个共用栏杆支撑块重复，导致原始GLB比Blender多264面；现已在源组件层去重，并增加导入面数与重复面检查。最终资源、清单及验证均以去重后的版本为准。

原生正面、斜面和后侧渲染，以及网页桌面和移动端截图保存于此目录。主体比例、台阶与栏杆开口参照公开照片；石狮只保留简化体态，雕刻、桥拱题字及历史风化未完成。预览剖露池壁和桥台基础，展示地面低于池底，不能据此判断实地高程。没有经过照片摄影测量、精确地理配准、完整自交检测或现场通行验证。
