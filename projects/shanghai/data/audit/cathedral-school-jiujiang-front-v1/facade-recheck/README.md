# 九江路219号沿街五个开间

2013年12月19日的街照和后来的修缮报道均能辨认双山墙、沿街窗带和中央尖券门。修缮报道的近照还显示斩假石窗套、钢窗和门两侧的铜色竖牌。模型以这一面五个开间为范围。牌上文字和盾形装饰的细部在照片中辨认不足。此次查验了12张来源图的原始字节、摘要与像素尺寸。[原图与出处](source-photographs.json)

原始、近景、远景三份GLB经过独立解码。检查从街面和上方向门、窗、装饰、山墙及其顶面发射射线，记录最先命中的表面和距离。原始和近景网格各有34,428个三角面，分别检查224条射线。远景网格有10,392个三角面，检查170条射线。三档618条结果与先前留存的检查逐项一致。[实测结果](delivered-rays.json) · [复测程序](check-delivered-facade.py)
