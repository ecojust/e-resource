# 武夷路154号住宅山墙八角砖窗与横档

在2018年冬季的武夷路154号街照中，后排红砖墙有一个平顶、平底的八角形开口，八边沿口均有朝洞口排列的红砖。深色洞面中央留有一根横档，上方檐下是竖砖带。
