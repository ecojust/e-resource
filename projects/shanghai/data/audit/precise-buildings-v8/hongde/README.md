# 鸿德堂网页接入核对

本版新增虹口多伦路59号鸿德堂，应用精选导航24项、街区精细建筑5栋、普通建筑目录3个宏块。这里只核对本栋及其同近景块的10个邻楼，不代表上海16区已经逐栋按照片完成。

静态场景的7张实际截图已逐张查看：正面、斜向屋檐和窗洞、远景模型、返回完整模型、离开释放、再次返回、城市清单重置。在5个近景、返回及重置取景前后，实际核对备用地图中的目标旧壳已隐藏、残余几何不含本栋；原有10个邻楼保留。实际full/LOD资源及解码几何检查通过。远景受到前景建筑遮挡，仅用于切换和资源检查，不作为立面细节照片证据。

目录三阶段及5张实际截图均通过：复用已加载的静态模型；仅由目录加载后卸载并释放25个几何对象、返回创建新对象；故意损坏索引后拒绝精细模型，保留完整11个原建筑要素（含目标与10邻楼），没有请求被拒绝的精细模型。武康和青浦既有目录及原23条导航数据保留。
