# 原亚洲文会博物院虎丘路立面

虎丘路20号位于上海市房管局第三批名录3A009。现存大楼由George L. Wilson设计，馆方将其竣工年份记为1932年。2007年开始规划改造，2010年上海外滩美术馆成立。模型复原虎丘路历史西门街面，今天参观美术馆从东侧博物院广场入内。[建筑、来源和不同年代的入口](../../../source/precise/huangpu-royal-asiatic-society-huqiu-front/README.md)

馆方2010年街照与2007、2011、2013及2015年照片用于交叉核对。街面共有三道石券、成对的八卦窗、石栏阳台与高出两翼的中央竖窗。顶部的R.A.S.字母、侧翼卷草石板和阳台弯托按照片中可辨的轮廓塑形。窗花的深度、阳台退距、门廊侧面和雕刻凹凸均为估计值。其余三面、室内与现代展览装置留待另行考证。[照片及许可](../../../source/precise/huangpu-royal-asiatic-society-huqiu-front/reference-review.json) · [实景与原生渲染](visual-review.json) · [原生渲染图](huangpu-royal-asiatic-society-huqiu-front-preview.png)

在Blender 4.3.2中重开工程，共62个网格、12种材质、18,932个三角面。网页近景和远景实解后分别有18,932面和12,160面。对三档模型各发出66条射线，核对券顶、门内阴影、八卦窗刻线、竖窗和屋顶饰件。各材质三角面的排序和方向以解码结果交叉核对。[工程与三档校验](geometry-native.json) · [实际命中记录](surface-probes.json) · [四文件下载](../../../royal-asiatic-society.html)

历史街面宽约12.28米，局部模型从沿街面往内约2.34米。冻结底图2274与具名OpenStreetMap环的交并比为93.91%。近景和远景分别保留原屋的92.46%和92.63%平面投影。一条切面封住剖口，另有17个街道、门内与相邻建筑样点。原屋以外最近的非目标三角面距裁片约3.79米，安培洋行等四周邻房各有独立核查。桌面与手机默认取景分别检验十个表面位置。[裁片与邻楼](placement-geometry.json) · [地面样点](ground-witnesses.json) · [默认取景](overview-sightlines.json)

## 桌面与手机的独立模型页

虎丘路正面两档均显出三道深色石券门。门侧的两枚八角窗、竖向分带、中央通高券顶窗和高出两端的石檐在桌面及手机图中可分别辨出。 桌面右栏与手机下栏均显示切换后的模型三角数。手机上门基至最高石檐完整，左右两窗未被说明栏遮住。 原照的匾饰微纹和铭文字母在默认手机缩放下很小。本次比较限于可辨的构件和分布。

## 正式城市地图复核

虎丘路的原街景保留了博物院与两侧邻楼的关系。中央窗带和阶梯形女儿墙高于两翼。街面的资料卡和前景立柱遮住部分入口，转到近距离斜角后，同一机位的地图画布可逐一辨认三道石券、三扇竖栅和三处踏步。八角窗的斜边和格条清晰，横向铭牌受遮挡，只露出部分字形。

前后两期名录从281处增至282处。桌面鼠标和手机触屏均点中本栋，街面复核的21个地面与相邻位置均与记录一致。河岸远景实际载入12,160个三角面。桌面与手机独立页均切换了近远档，并对可编辑原件、原始网格、近档及远档四种文件进行了真实另存和指纹复核。
