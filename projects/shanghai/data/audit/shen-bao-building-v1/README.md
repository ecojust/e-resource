# 申报馆东北转角外观

上海市第二批优秀历史建筑2A034，汉口路309号。东北角斜门及两街各13.6米的建筑外观取形于2015年和2016年的独立摄影。厅内、印刷厂范围、屋顶附属及两翼远段待查。建筑高度和石栏、壁柱剖面均为照片比例估计。[两年照片和来源](photo-credits.md) · [建筑位置与依据](../../../source/precise/huangpu-shen-bao-building/README.md) · [单体与四件下载](../../../shen-bao-building.html)

「申報館」三字按2015年金字门额核字，字形为可重建的三维轮廓。两侧二楼在角头收住石栏，上面两层的竖槽壁柱有卷饰及叶形柱头，窗间留菱形纹，深檐下方可见两级托齿。[门额](entrance-name-2015.jpg) · [阳台](street-balconies-2015.jpg) · [柱头和大檐](pilasters-and-cornice-2015.jpg) · [汉口路路牌和转角](hankou-road-sign-2016.jpg)

原始与网页近档各41,640三角面，远档36,680。Blender重开77个可编辑网格，逐材质比较有向三角面与原始GLB吻合。每份实际GLB分别通过121个格窗、三字门额、竖槽与菱纹、洞口、石栏、屋面和空街探针。[原生及压缩核验](geometry-native.json) · [三档实体构件核验](surface-probes.json)
