# 武夷路234号住宅竖梳粉墙与阶梯砖窗套

2018年2月13日的临街照片中，一扇狭长单窗位于前后两层红瓦坡檐之间。浅色框外两列深红横砖分段向浅色墙面伸出，形成阶梯形窗套。
