# 高桥蔡宅阶梯封火山墙的两级瓦头与三角灰饰

Fayhoo于2015年5月9日拍到高桥蔡宅封火山墙。端头随墙身分级增高，白色窄端层层叠出，三角形小面内有浅浮弧纹；上方的深色瓦盖和脊尖向上翘起。
