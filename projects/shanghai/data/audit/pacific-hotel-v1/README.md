## 来源和可见形态

[文献复核](documentary-review.json)实际读取官方介绍与志书等7份资料。38.16米为本件选用的总高解释；36.16米另有记载；2026年招标镜像南楼40.1米和北楼24米是未与历史尺寸绑定的项目量。9米塔高的计量端点未核实，模型中央屋顶29.16米到塔顶38.16米的关系只是设计解释。8／9／10层及改建叙述未完全统一，两翼9层、中央8层为造型分层。官方1926年竣工与名录1933年差异保留。

[地图范围审查](footprint-review.json)读取已有冻结要素，确认其为无分栋的粗四边形；不将它直接挤出，也不以经营地址108号拆出另一历史身份。主体42×36米、前退4米与后退6米均为估计；加上檐口、阳台等突出部分，实际模型外包约43.64×38.19×38.16米。

[照片复核](photo-review.json)与[原生图复核](visual-review.json)实际查看Livelikerw的2013-12-05正面照片及最终三张渲染，绑定图片、模型和建模源码SHA256。可识别双翼、中央退进、长窗带、石栏阳台和两层圆顶钟塔，但**照片中钟塔下的抬高窗亭、拱形中龛、两侧列柱及小尖饰被简化为平直窗带／屋顶**；中央顶部小窗层、复合重檐与钟塔下部曲面浮雕也有简化。侧背规则窗格、完整工字形屋面及被树遮挡的低层构造是估计性补全，不能由正面照片验收。钟面10:10为示意，表面颜色与柱式简化。本件未达到完整照片复原或测绘精度。
