# 金陵东路174号麦兰捕房旧址登记

上海市房屋管理局第五批优秀历史建筑表将5A077列于金陵东路174号。原名栏并列“上海法租界麦兰捕房/上海市警察局黄浦分局（1943）”，公布时名称栏为“上海市公安局黄浦分局”。[市房管局第五批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [登记原行](municipal-source.json)

《上海租界志》记载，老北门捕房于1932年3月改称麦兰捕房，1939年的机构名单仍分别列中央捕房和麦兰捕房。《黄浦区志》记载，1943年改组后的麦兰区分局于11月1日并入黄浦分局。市表括注的年份在区志中有机构事件对应。地方志网页保留了一条题为“法租界麦兰捕房”的插图说明，现有证据可核地址和名称沿革，历史建筑各面尺寸仍待有年代的原照复核。[《上海租界志》警务机构章](https://web.archive.org/web/20160427154732/http://www.shtong.gov.cn/Newsite/node2/node2245/node63852/node63858/node63882/node64474/userobject1ai57982.html) · [《黄浦区志》公安机构章](https://web.archive.org/web/20160326114413/http://www.shtong.gov.cn/Newsite/node2/node4/node2249/huangpu/node35610/node35612/node62460/userobject1ai20580.html) · [原文交叉核录](gazetteer-crosscheck.json)
