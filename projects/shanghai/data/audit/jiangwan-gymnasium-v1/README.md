# 江湾体育馆历史主楼接入主地图

[全局主图直达](../../../index.html#landmark=yangpu-jiangwan-gymnasium&mode=overview) · [来源与重建](../../../source/precise/yangpu-jiangwan-gymnasium/README.md) · [四资产清单](../../../assets/models/candidates/yangpu-jiangwan-gymnasium/manifest.json)

本件为江湾体育中心内独立封闭体育馆，西端朝向室外主场。交付弧形屋面、纵向天窗、砖长墙、高侧窗、两端外观及西侧浅石三拱入口；室内球场、观众席、屋架与场馆外道路不作为本栋建筑网格。已建室外看台环、独立游泳馆和其他邻楼分别保留，本轮不关闭整条名录b1-021。

## 来源与边界

两张KIC原运营站照片经实际归档HTML链接确认属于“综合体育馆”，可见三拱、三高竖窗、带圆孔挑台和浅色端立面；2011是网页归档时间，不作已知摄影日期。2013高位泳馆照片中背景体育馆显示灰金属弧顶、纵向天窗与砖长墙；前景低浅屋盖属于游泳馆，不能混入本栋。2024两张航空总图用于核对位置与大轮廓，馆内照片仅辅助识别天窗及高侧窗，不据此交付室内模型。

1934原设计透视、平面、正侧背立面分别查看，背面与正面不同，没有把三拱正门镜像到背端。原文“八角小窗各十六孔”是窗形八角、每侧16孔；初读误把八角作数量的记录已纠正，历史数量不冒称当前逐窗测量。所有参考原图、整篇网页及PDF仅私下研究，不嵌入模型或随库分发。

地图冻结足迹约72.878×44.847米、面积3078.759平方米，与1934整体约82×46米设计存在差异；采用冻结地图轮廓配准，保留异文，未为凑82米在西门外道路上增加长台阶。设计屋顶20米、侧墙12米、钢桁架支点42.7米与百科46米跨度口径分开；具体模型米高、窗数分配、隐藏背面、构件及装饰尺度均为作者估计，非现状测绘或1934原状完整复原。

## 资产与实际几何验证

四件资产共11,110,949字节：原始GLB 5,727,660字节、网页GLB 1,881,528字节、远景GLB 562,704字节、Blender源2,939,057字节。原始与网页档110,972三角，远景29,512三角；含外挑外包约74.111×45.647×20.170米，所有高程与构件尺寸为作者估计。

三档各149项作者实际射线通过，完整网页档逐材质有方向FLOAT32三角等于原始档；远景另与未经压缩LOD核对。Blender实际保存重开保持几何一致，便携源码异目录重建原始档与未压缩LOD逐字节相同。作者与主审分别实际查看最终七张原生图，门洞横带、短返墙和屋面明暗异常已修正。天窗约33.47米、约占主屋面55%，为受照片约束的估计，不冒称测绘比例。

## 地图替换与通行

本栋绑定宏块14-13722-6690中的独立源1558：`building / adde8d71-bc6d-497a-a682-3bb158c1f160`，原记录名称“江湾体育中心综合体育馆”。原near楼组有12个owner，只替换1558，其他11个真实邻体保留；原始地图与城市GLB不修改。

显示掩膜沿原12顶点凹轮廓外扩0.12米，覆盖旧粗略外檐，共10个三角。原有192行裁剪数据12288字节保持不变，新增后202行；生产代码仅将GPU容量从192扩为224，纹理增加2048字节，owner和碰撞算法不放宽。真实WebGL编译与旧源可见状态由浏览器另验，纯Node shader构造不冒称GPU运行。

地面碰撞依据实际三档z=0–2米三角投影，并仅在原源范围内保守填补未开放的主厅／前厅闭合室内孔；这是导航阻挡，不是已建室内实体。西门前凹及高挑台下按真实低位构件处理，不把弧顶压成地面封堵。门道几何检查不表示室内或登楼漫游已开放。

## 目录与后续

按区目录汇总79处、16区，其中杨浦4处、黄浦28处。40处原有入口保留既有漫游，39件候选提供近似定位俯瞰；README所有模型查看链接都进入index主地图，灯牌从同一登记生成。现有20×18紧凑编号格可容纳79处，文字保持12像素，本轮不增加灯牌样式。

33项已交付制作任务和46项库存退出重复制作；10条已完成主楼不重复列项，活动历史名录／构件仍1048条。体育馆源不在原1036条具名快照中，关联仍19条、待查1017条。b1-021中体育馆任务移入完成范围，保留游泳馆和已列主场局部边界／门台细部调查，其他旧名录任务不变。

下一项是江湾游泳馆（历史池馆与现状屋盖）：1934原设计为露天池，2013照片已存在现代大屋盖，后续按实际图像与独立源核对，不将原方案直接冒充现存形态。

## 集成检查

独立几何审查对三档各295项自选射线通过，另实际只读重开Blender，验证完整档顶点、法线、材质归属与原始档一致。低位投影234.387平方米，保守室内导航填充2887.264平方米，最终碰撞1环109点；66个正负探针、9个开放范围及道路肩带通过，邻源保留。

最终79目录的7组增量集成检查、35项灯牌／镜头检查和12项导航／目录测试通过。累计资产登记41份清单、164件、681,033,977字节，本轮实际仅增量验证新4件；未重复运行历史全资产矩阵。9组主审目录与范围检查通过，旧38条候选登记和其他名录任务保持原值。

默认主地图晨光下西入口背光较深；缩小视角的密集屋面立缝及石缝有像素取样纹，不能把它当作原墙斑驳贴图或测绘细节。实际门前近景可辨三拱、真孔格门与挑台，近景与源身份检查共同排除旧粗模贴面。网页验收保留被邻楼遮挡的首次入口机位作为不充分过程帧，使用门前调整机位作入口证据，未隐藏邻楼。
