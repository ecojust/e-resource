# 愚园路1294号花园住宅18号楼

正文按区规资局的18号楼单栋记录、2018年江苏路街道带18号圆牌的庭院照片及题名保护牌配对。最初生成两档南面券廊和东山墙，再补可独立编辑的木窗、三道券框和红砖烟囱。十个实际Blender视角与区图复核后，终版增补阁楼山墙下的短瓦檐，左侧瓦口伸到紧邻的廊间，东边取树遮处可见范围。

近远档487、391个闭体，13,580和8,612面，独立解码的两份GLB各自检查40个原照片像点；短瓦檐在两档的左中右三处均首先命中红瓦。两组原照片视角是独立透视求解，特别是外阶的全宅位置仍有误差。来源、两期正射、源网与七项模型、十个原生镜位和独立重建结果在相应目录。原生编辑件、FBX、OBJ和STL均独立复开。

在普通城图块14-13717-6695中，按168号户南边和18号山墙向东试放，传统远网分别与新近、远档产生1,374和752处三角形相交，普通近网产生3,142和2,885处相交。门廊展示以独立页面提供，城内保全168号整宅和所有邻屋。
