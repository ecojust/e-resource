# 虹口中国银行大楼西南弧角

市优秀历史建筑名录将四川北路894号列为2F009。《虹口区志》记原中国银行职员宿舍坐东朝西，七层，门牌为四川北路912—922号。2012年4月29日的照片显示，下部石面横窗由两条红砖带绕过弧角，上面四层的砖壁柱从同一条横带升到檐口。窗下有方饰，沿四川北路的部分开间可见酒红色篷。对街虹口大旅社、末端屋顶竖向标识、后院和长西墙北段均未纳入。[2012年弧角与遮篷照片](photo-credits.md) · [来源与地址](../../../source/precise/hongkou-bank-of-china-hongkew/README.md) · [单体与四件下载](../../../bank-of-china-hongkew.html)

2015、2022两个航片版本、另一组现状航片及固定的两条道路共同用于辨认转角。在匿名粗面2427内量取16.92米的街面，包含三处平直西墙开间及四处弧角开间。原始、近档各24,988面，远档21,208面，Blender重新打开105个分类网格并独立比较；三份实际GLB各通过116个物理取点与材质检查。[原件及压缩件](geometry-native.json) · [弧面、七层窗、遮篷及方饰](surface-probes.json)
