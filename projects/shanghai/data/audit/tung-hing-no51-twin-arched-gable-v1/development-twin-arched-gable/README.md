# 同兴纱厂51号住宅折坡山墙与双拱窗

上海市第四批优秀历史建筑名录4G003列平凉路1777弄51号及相邻成组工房。高参88的原照中，两扇小拱窗各有突出的窗台。顺着它们下方略上拱的深檐，可以看见三面向外折出的木窗。展品保留每扇拱窗的两根细竖梃、窗框内凹和下部窗扇的横档。房屋尺寸按照片估计。[查看原照](https://blog.sina.com.cn/s/blog_5d1bdf480102w2yn.html)

正面可看双窗与檐底的关系，斜面可看三面窗的折角。每个细节层都从导出的实际三角面交点复核了119处窗格、窗框、墙体、瓦边和轮廓。第一轮预览发现局部砂浆纹理被拉成长条，第二轮在导出的模型中改正了纹理坐标。
