# 襄阳南路351至355号街面窗框花饰与垂叶

2018年8月2日Antigng拍摄的《襄阳南路351–355号住宅》中，红砖立面一层可见灰绿色窗框。窗楣有一行六朵小花，两朵花之间伸出带卷尖的对称垂叶。作品取原照里清楚的一段窗头和窗间饰带。
