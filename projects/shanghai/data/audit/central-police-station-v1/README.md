# 福州路历史街面核验

房管局第二批优秀历史建筑2A030的登记地址为福州路185号。1930年代的 Yo-s23 正面档案照与2013年斜向街照能对上中央六列、两翼各四列、两条高竖带和三种高度的屋缘。模型采用可见的历史正面，地面层是一道封闭浅浮雕。照片中格构天线和现代附属物未纳入模型。[建筑身份与照片](../../../source/precise/huangpu-central-police-station/README.md) · [逐源证据](../../../source/precise/huangpu-central-police-station/reference-review.json)

原始GLB和网页近景均有39,072个三角面，网页远景17,396面。Blender重开工程后可见55个独立可编辑对象，按材质分组的面方向、位置与原始GLB相符。两档压缩模型均实际解码。每份GLB另做68个实体采样，覆盖窗组、双竖带半圆饰及三段屋缘，三份共204次。整面渲染直接来自重开的原生工程。[四份成品](../../../assets/models/candidates/huangpu-central-police-station/manifest.json) · [独立页](../../../central-police-station.html) · [原生工程核验](geometry-native.json) · [实体采样](surface-checks.json) · [档案照与成像对照](visual-review.json) · [原生工程渲染](huangpu-central-police-station-preview.png)

模型占用临福州路的一段窄带。实测原城市体块在近景保留95.59%，远景保留95.72%。同一地图分组内的美国总会及其他既有楼体继续保留，单独检查的相邻近景组78,680个面与截取区无面积重叠。截面沿原通用楼体的屋顶高度闭合。碰撞以历史展件本身的实体为准，福州路街面保持通行。[街面测量与原始地块](../../../source/precise/huangpu-central-police-station/footprint-review.json) · [实际近远景及重叠检查](placement-geometry.json) · [登记合同](final-placement-contract.json)
