# 中垦大楼北京东路239号东北转角门楼

北京东路239号大门斜向江西中路口。1933年10月6日的落成合影记录了中国垦业银行新屋，上海市保护铭牌记1932年建。市表4A008同时列出的255号有独立入口，位于北京东路一翼。本次取2020年调查照所见的东北门楼，建模范围包括黑铁双扇、上亮、石框、九排三联窗与阶梯塔冠。石楣六处旧字的底板依原照保留。隐蔽内厅和两侧长楼翼仍待查证。[来源、年代和两处门牌](../../../source/precise/huangpu-zhongken-bank-239-corner/README.md) · [独立页及四款下载](../../../zhongken-bank-239-corner.html)

五个摄影点测得入口宽约4.23米，门轴离原城1970斜面约4.70米。模型接在原有7.10米斜面。原城网格高32米，远街照对转角塔冠的估计在44至47米之间，本次取44.7米。近模保留原有投影面积的97.58%，远模保留97.62%。原楼的其余屋面接缝由3段收住。[实地摄影方位与像素](../../../source/precise/huangpu-zhongken-bank-239-corner/street-photometry.json) · [近远模型、原楼和邻屋](placement-geometry.json)

七栋共用的旧近景网格有75,970面。将三角面中心与官方底图多边形、带建筑编号的远景投影分别比对，再按三个顶点的平均距离复算，三次均将同一组26,496面归入1970。入口外的台阶可从人行道接近，两扇关闭的铁门构成通行边界。地面共测32点，另查18栋邻楼。矢量底图156761670原有17个部件，239号所在一片减少17.66平方米，其余16片与另五个建筑集合均保留。[原城与地面验算](placement-geometry.json) · [矢量底图复算](initial-vector-comparison.json)
