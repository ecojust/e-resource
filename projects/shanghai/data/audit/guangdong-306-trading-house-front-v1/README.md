# 广东路306号洋行旧址南立面

原始及近景版本各17,536个三角面，远景13,816个三角面。重新解码三个GLB后，逐档核对161处材质、进深和栏杆空隙。红色贴面的程序纹理逐顶点比对UV，二层以上的窗洞、四道通长金属栏杆、四个端部小阳台、折线与菱纹均有实际厚度。[三档实体射线](preflight/three-exported-surfaces.json) · [内嵌纹理与UV](preflight/embedded-texture.json) · [模型正面与斜面](preflight/authored-facade.jpg)

广东路南侧视角可同时看到端部阳台、两组红色腰饰、中央长栏杆和底层菱纹。桌面和390像素设备各检验12个外部视线，实际远近网格分别从两个相机回测。最初切口碰到西邻2413的九个三角面，最终西界收进至本楼。近景1,498个相交三角面及远景6个三角面全属原楼2074，保留整栋投影96.85%及97.00%。另检查33个沿街地面点及十三个邻体。[默认取景](preflight/overview-sightlines.json) · [远近实物视线](preflight/exported-mesh-sightlines.json) · [切面与地面](preflight/source-cut-and-walk.json) · [修订记录](preflight/construction-review.json)
