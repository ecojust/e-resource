# 浙江兴业银行北京东路窗跨复核

市房管局第四批名录的 4A007 行登记浙江兴业银行，北京东路230号。Fayhoo 的街角照片在夹角处同时收入两面街墙，2015年1月19日是上传日期。言衣草的三张街照可对照回纹板、三扇并窗与红色竖墩。上海市银行博物馆文章的五张图提供现状、旧照、草案和建成图纸。复读的名录与九张图均与原记录逐字相符，作者、出处、尺寸和逐件摘要列在[来源表](external-references.json)。

模型取北京东路西端一跨，宽约6.15米，自原地面上方3.04米起。原楼2404与同组五栋均保留。原始、网页近景和远景各复算98处表面。近远两档各用桌面、手机的十条视线检查宽窗、回纹、钢窗和压檐，另核15个原房地面点。表面、两份视线、落位及其合同共五份计算结果逐字复现。[三档与落位](repeated-measurements.json)

第268期正式目录与作者初算的目录摘要不同。用本期原目录和同一张171,484字节的向量瓦片重算，203条既有裁切规则仍适用，27个邻近矢量分片的几何和裁切结果与初算一致。[前期目录复算](preceding-city-clip-comparison.json)
