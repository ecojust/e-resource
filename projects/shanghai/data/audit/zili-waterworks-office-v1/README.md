# 自力大楼江西中路464号券门及上层窗墙

市房管局登记4A003的原用名为英商自来水公司办公楼，地址为江西中路464–466号。Fayhoo上传的照片拍到门券内的“464”和相邻巷牌“460弄”。本件采用街面的三处红砖券、上方八扇窗和三层挑檐。另编4A002的484号北楼与本楼足印相距26.57米。[来源、年代和照片](../../../source/precise/huangpu-zili-waterworks-office-front/reference-review.json)

近、远原城分别保留1588号原房5,437和12个三角面，原屋顶最高处分别为19.2和16米。照片实证的三层街墙高约11.25米，背缘衔入原墙。两栋楼在矢量底图中共用116293700号对象，各为独立分片。27个地面点核对街面和合拢门扇；模型没有原房裁切。桌面与390像素手机的默认位置均验过门牌、门洞、窗扇等12处，另以两个原近景组及其远档验证对面街坊遮挡。原先正对街面58°俯角的镜位会受664号建筑遮挡，已改为36°。[局部配准](preflight/source-registration.json) · [普通目录镜位](preflight/ordinary-camera.json) · [建筑近远实网格视线](preflight/retained-source-camera.json)

网页及原始预制几何各6,192面，远档4,896面。每档110条射线区分了开券、填砖券、折栅门、门牌、砖挑齿与嵌窗。此处记录编辑工程打包前的专项结果。[三档表面](preflight/three-surfaces.json) · [几何与材质](preflight/summary.json)

接缝地面复验覆盖原地块、门前街地与同组15座邻屋。南端与163号原屋共有约29毫米宽的墙接头，原底图已有其中约0.0059平方米的阻挡；新碰撞轮廓绕过这段共有墙。

原始网格、网页近景和远景的灰砖纹理都使用重复采样。对三份实际 GLB 的 UV 与纹素重采样见 [纹理实测](preflight/texture-mapping.json)，首次试制与修正件的几何二进制完全一致，差异见 [采样修正](preflight/sampler-repair.json)。

## 正式城市地图复核

江西中路464–466号自力大楼的街墙已加入城市目录。本期前后两份目录分别有299和300处地标。手机和桌面分别从484号自来大楼的城市视图点击本栋标记，均抵达464号券门。实测保留了15座相邻原建筑，本栋及周边共57个地面测点的碰撞结果与预期吻合。

十个城市场景分别留存窗口画面、同机位的WebGL画布和X11显示屏。桌面目录图可辨深色砖墙、两层窗和浅色窗台。屋顶斜看可辨红色檐线及相邻建筑的体量。门洞近景里城市名签遮住中央券顶的小门牌，侧看可见侧面的窄券和盲券。远景保留街廓、河道及成组标记。

独立页面的四幅正面图分别在桌面和手机看过。桌面近景能直接读出中央红砖券上的绿色「464」门牌，上方两层窗列、中央交叉铁门、左侧窄券和右侧盲券均可辨。手机正面完整显示街墙及两条层间线，门牌字在该比例下不宜判读。原始GLB、网页近档、远档和Blender编辑工程已分别用页面下载链接保存并核对字节。
