# 祥德路25弄住宅临院双扇格窗与竖砖窗台

Fayhoo的2015年4月12日原照摄于祥德路25弄1号、2号住宅。临院红砖墙的两扇红框格窗在树冠下露出，窗内呈蓝绿色，窗下有一整排向墙外突出的竖砖。取下半部可见的框扇、窗台及墙边。
