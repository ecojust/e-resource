# 延安西路238号市文联老楼南园面

第二批优秀历史建筑名录2B009在238号登记“意大利总会、市文联”。房产证据上海文联记载为1925年。西侧花园住宅在1950年成为市文联用房。修缮团队依据历史行号图、航拍和1995年照片，将东面1941年建成的商务总会大礼堂定位于另一地块。其外观已登记为单独的历史复原待办。[建筑来源与定位](../../../source/precise/jingan-wenlian-old-house/README.md)

模型表现花园面两端的切角凸窗和小阳台、中央两层敞廊、第三层六轴窗及山花。几何包含成对的石柱与涡卷柱头、栏杆、退入的木门及曲梃、三盏廊灯，构件截面和色彩据1995年及修缮后照片估计。原始和网页近档各有65,010个三角面，远档有33,342个。原生Blender重开后有118个可编辑网格，10种材质的有向三角面逐一匹配原始GLB。三个交付网格均通过76项独立射线检查，覆盖窗、涡卷、门板、可见空隙和屋面。[独立模型页](../../../wenlian-old-house.html) · [四个下载](../../../assets/models/candidates/jingan-wenlian-old-house/manifest.json) · [原生复核](geometry-native.json) · [三档构件实测](surface-checks.json)

238号对应宏块14-13718-6695中的1559号建筑。南园面在模型中长约30.7米，山花顶高约17.5米。原城景中后部及附房结为一幢，近、远网格分别保留其投影面积的68.77%和68.81%。九座相邻建筑以及花园外侧均沿用原地图。檐口与后部之间的切面沿原楼估计高度封闭。十八个地面样点覆盖可通行的廊内地面、构成障碍的柱脚和两翼，以及两个保留原楼占地的后侧位置。两个视口的八个取景点均另按原楼与邻楼体积检查。[落位](final-placement-contract.json) · [原建筑投影与碰撞](placement-geometry.json) · [两端视线](overview-sightlines.json) · [原始城景切片](../../../source/precise/jingan-wenlian-old-house/footprint-review.json)

在正式31236的桌面和390像素手机上，分别通过页面控件查看近档正面、近档斜面和远档俯视。正面可以分辨中央双层敞廊与两端山花；斜面可以看见凸窗斜返、前排柱身、石栏及退在柱后的门窗。俯视给出近街这段屋瓦的形状。两套设备各取得三幅截图，四个下载与模型清单的字节数和SHA-256逐项相符。独立页面验收和运行时地面测量已完成，全城普通地图的桌面与触屏现场仍按发布次序进行。[近档桌面斜视](viewer-desktop-full-oblique.png) · [手机正面](viewer-mobile-full-front.png) · [远档俯视](viewer-desktop-lod-above.png) · [六幅及四个下载](viewer.json) · [27处运行时地面检查](runtime-placement.json)
