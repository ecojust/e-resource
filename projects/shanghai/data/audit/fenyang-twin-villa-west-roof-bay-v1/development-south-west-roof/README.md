# 汾阳路152–154号并立花园住宅西端折坡瓦檐与阁窗

2020年2月2日的照片将两栋并立花园住宅收入同一画面。南栋的西端有折坡瓦檐，横向阁窗嵌在红瓦上坡与短披檐之间。下层的成对开窗上方，可见伸出檐口的木托。本研究取南栋152–154号的这一开间。[Legolas1024 摄，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:%E5%B9%B6%E7%AB%8B%E8%8A%B1%E5%9B%AD%E4%BD%8F%E5%AE%85%C2%B7%E4%B8%8A%E6%B5%B7.jpg)

近景含22,012个三角面，远景含14,306个。修订后，三档网格的五段斜脊均检查了实际接合位置，每档另用31条射线核对瓦面、窗、披檐与挑托。[近景 GLB](fenyang-west-roof-near.glb) · [远景 GLB](fenyang-west-roof-far.glb) · [实物对照与测量](model-and-photo-comparison.json)
