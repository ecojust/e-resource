# 枫泾生产街70号入巷门洞与嵌砖墙脚

Fayhoo于2015年9月20日拍摄枫泾生产街70号住宅。门洞左侧绿底牌面可读“70 生产街”，与市级名录中的生产街70号相合。取凹入墙面的矩形入巷口、折入过道的砖脚和剥落抹灰，以及上方门牌。
