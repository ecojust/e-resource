# 两种尺寸的六个建筑视角与八款下载

桌面视口为1024×690，手机为390×760。独立的Chromium会话从普通建筑页实际加载两种GLB，核对渲染相机的位置、观察方向、视场角。两端各完成六个原视角，以及八次有实体文件的下载。桌面第一段已取得六镜、手动近远和自动缩远及返近，随后近档、原网、远档和 Blender 的下载完成事件均已记录。第五项 FBX 已保存完整的 710,672 字节，与发布件 SHA-256 相同；浏览器收到 SIGKILL（退出码 −9），报告未写入该项的完成事件。另一独立桌面会话从同一页面完整保存八项，退出码0。手机的六镜、三种模式和八项保存在同一会话内完成，退出码0。逐张照片和两端的下载校验见[浏览器记录](browser-checks.json)。

花园总览可同时辨认木格山墙、廊窗、高烟囱和后退的小屋。廊窗近景中黑色横木与白色填面交错，两只老虎窗分别朝向不同的瓦坡，东侧烟囱从屋面向上穿出。退后小山墙的视角重点呈现两墙相交与两扇窗的位置，屋尖和近侧檐端局部在画缘。俯视镜中可以分出三条屋脊及高低关系。三组历史相机采用另行标注的原图坐标，参见[留检误差](../control/three-photographic-stations.json)。
