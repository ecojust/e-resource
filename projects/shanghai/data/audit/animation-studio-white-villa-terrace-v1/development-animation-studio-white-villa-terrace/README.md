# 上美影小白楼庭院弧形露台与四根圆柱

万航渡路618号原上海美术电影制片厂本部“小白楼”面向庭院处有弧形露台。模型取上观新闻2026年所刊照片中的外挑台板、四根细圆柱和台上向中间收拢的几何铁栏。
