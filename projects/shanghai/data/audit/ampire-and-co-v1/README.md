# 安培洋行大楼圆明园路主立面

市房管局第二批名录2A023登记圆明园路97号。2014年正面照片和2020年发布的街面斜照共同确定了中央砖拱门、三层圆挑窗、二层两扇带弧形窗冠的窗、四层双山花以及两端各层三窗的半圆凸翼。佳士得在其迁址公告中记始建于1907年，OSM属性记1911年。楼层记法和尺寸差异见来源说明。[来源与建模范围](../../../source/precise/huangpu-ampire-and-co-building/README.md) · [建筑细部目视对照](visual-review.json)

Blender 4.3.2重新打开工程得到55个网格、10种材质与39,204个三角面。原始GLB和近景GLB均为39,204面，远景为20,144面。两档压缩后均实际解码并逐材质对比三角形。对原始、近景和远景模型各发出99条射线，核对入口、侧翼窗和砖石表面。原生渲染的砖色与窗楣较现场均匀，高度、弧度和窗棂分格由照片估计。[单体浏览与下载](../../../ampire-and-co.html) · [工程复验](geometry-native.json) · [射线结果](surface-probes.json) · [渲染图](huangpu-ampire-and-co-building-preview.png)

仅替换街面约3.8米深的部分。城市底图对象1125与具名OSM地块重叠98.60%，地图近、远两档分别保留原体投影的82.15%和82.35%。南北邻楼保持完整。两处相接边依照原体封口，地面采用街道、门槛、墙及后部原屋等十个点校核。在900像素宽桌面和390像素宽手机的投影中，十个建筑细部均在可见地图内。[近远景与邻房实测](placement-geometry.json) · [地面样点](ground-witnesses.json) · [取景投影](overview-sightlines.json)

独立页在第271处登记的冻结站实测。桌面与390像素触屏均完成近景和远景切换，近景39,204面、远景20,144面。原始GLB、两个网页档与Blender工程均通过实际下载和摘要核对。[四幅截图与下载收据](viewer.json) · [冻结站核验](release-verification.json)
