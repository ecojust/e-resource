2014年6月图录的保护牌标有1936年；区政府的住宅说明写作1925年。12月独立拍摄的原片可直接读到入口旁的17号牌。西门和车库的两种砖券与保护牌记载相符，区政府配图给出南侧券廊、露台及方形阁楼。[建筑身份与照片](../../../source/precise/changning-xinhua-lane-329-no17/reference-review.json)

按相片重做西门的单坡筒瓦雨篷与内收托座，细化砖砌深门洞、门扇铁花、17号牌和三层阁楼的三组方窗。[首稿](draft-review/west-and-garden-first.jpg) · [修订](draft-review/west-and-garden-revised.jpg) · [修订说明](draft-review/final-comparison.json) · [角部叠面修订前](draft-review/west-and-garden-before-wall-joints.jpg) · [墙体接缝记录](draft-review/wall-joint-comparison.json)

原始和网页近景各26,018个三角面，远景13,274面。Blender原生重开后105个可编辑网格与原始版逐面比对一致。三种交付网格各检查66条射线，涵盖四扇车库门、砖券与灰缝、花铁、号牌笔画、园廊和瓦面。[构件检查](surface-checks.json) · [原生工程复核](geometry-native.json)

模型取代原图1248这栋19.8米的简化楼体。两套独立归属判断覆盖近景组的551,984个顶点及重心位置；其中5,592个三角面属于本栋。远景12个三角面有独立来源标识。两档原址和新模型至最近原生邻楼净距分别为3.15米及3.22米。西门的外部台阶与南廊保持可走，闭合门扇位于廊后。六座邻楼分别核对。[放置与通行](placement-geometry.json) · [桌面和手机的取景](../../../source/precise/changning-xinhua-lane-329-no17/camera-preflight.json)

222处与223处的预览站点实取目录逐行核对。17号住宅替换原楼1248时保留315号住宅对4029的裁切，同组裁切从6片增至8片。两套矢量源共核14项，地面、门洞、花园券廊和相邻建筑共核24处。[前后目录与裁切](renderer-parent-controls.json) · [运行结果](renderer-runtime-placement.json)
