# 山阴路209弄3号底层券廊

2015年4月12日，Fayhoo从花园一侧拍下左券前放射铁罩、罩后的窗、中右两道敞券和灰砖窄墩。绿底3号牌位于这一单元前。对应上图和下图的左列均为同一张原片的裁切，右列由各自的成品网格按同一摄影机生成。[同机位对照](ground-arcade.jpg) · [Fayhoo原照](https://commons.wikimedia.org/wiki/File:Shanyinlu_209_Long_Zhuzhai.JPG) · [整版许可 CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

老房子爱好者在2022年2月发布的图文中，将一张独立的侧仰照片题为“山阴路209弄3-4号”。在该图640×432原像素中，两柱头与两券顶的留出点误差为1.48–2.59像素，左端放射铁罩的轮廓也清楚可辨。两张照片的拍摄时间间隔未知。该图仅用作几何复核。模型尺寸以券跨约2.38米为尺度假设，铁罩外挑估计约0.30米。[独立照片出处](https://www.toutiao.com/article/6984724111138243084/)

三个整栋文件各用256条不筛材质的原照视线检查实物，包括中、右券在可观察的近段通透，以及左侧铁条之间可见后窗。首轮的八处偏差集中在最右墩，原照的衣杆、红衣、天线和枝叶遮住这些像点；再验选取同墩裸露砖带。首撞、原观测和修订点均在制作源码的测量记录中。[原网](whole-raw.json) · [解码近网](whole-full.json) · [解码远网](whole-lod.json) · [首轮遮挡记录](../../../../source/precise/hongkou-shanyin-209-brick-arched-front/measurements/ground-arcade-first-whole-occlusions.json)
