# 花园正面的两个机位

左图为 Fayhoo 于 2015 年拍摄的 209 弄住宅原照的裁切。中图用同一组相机参数绘制解码后的近景 GLB。右图采用另一张发表时标有“山阴路209弄3-4号”的照片机位，展示从院内仰望时屋窗与檐口的遮挡关系。图上包含的照片及改绘遵循 CC BY-SA 3.0。[照片作品页](https://commons.wikimedia.org/wiki/File:Shanyinlu_209_Long_Zhuzhai.JPG) · [第二张照片所在文章](https://www.toutiao.com/article/6984724111138243084/) · [许可](https://creativecommons.org/licenses/by-sa/3.0/)
