# 二层三道砖券与扇形上亮

2015年4月12日，Fayhoo 摄下山阴路209弄这组三窗。中央券遮挡最少，可以辨出四道红砖砌带、券脚逐级出挑的红色构件、白色横框，以及从小弧伸向外弧的三根窗条。横框下的四块玻璃宽窄略有不同。左、右窗部分被树枝和临时物品遮住，其窗宽、券顶和窗台分别按仍可见的边缘取样。[原始照片](https://commons.wikimedia.org/wiki/File:Shanyinlu_209_Long_Zhuzhai.JPG)

另一张标明“山阴路209弄3–4号”的照片从斜方向显示这三扇窗。以左右窗八个角配准，留出中央窗四角和券顶，五点在原尺寸640×432图像上的均方根偏差为2.04像素。中央下窗的竖料位置在两图间有变化，模型取2015年能直接读到的四光分格。[第二张照片的发表出处](https://www.toutiao.com/article/6984724111138243084/)

[原照和模型对照板](three-upper-arches.jpg)使用相同画幅、相同比例，将照片裁片与正式原网的透视投影上下排列。摄影署名 Fayhoo。原照和本对照板均依知识共享署名—相同方式共享3.0许可。原照的变动仅为裁切和等比缩放。模型对照部分由本项目制作。[许可全文](https://creativecommons.org/licenses/by-sa/3.0/)

[可编辑构件检查](editable-arch-solids.json)逐件核了砖块、木框、压条、窗条和玻璃的闭合与有向体积。近档含102组、614个独立闭体，远档含57组、176个独立闭体。[三档射线结果](three-upper-arches-checks.json)从正面分别命中每道砖带、三条环形灰缝、两侧承托、窗框、四个下窗格和各块扇形上亮，逐束记录材质和墙面进深。砖缝厚度、木材表面和玻璃色调按历史照片估计，窗框进深采用模型展示尺寸。
