# 练塘陆家米行旧址沿河院墙与石框门洞

陈永年在《春节走进陈云故里练塘古镇》中点出前进街77号陆家米行的高围墙和石库门。紧随题注的沿河照片可读出白灰墙、偏右的矩形大门、门边较矮的横孔和左端较高的方孔。青浦区发改委2026年6月的修缮批复写明同一门牌，并列出各立面、院落格局、木质结构、门窗及走廊栏杆等修缮项目。本件仅取照片中白墙中段。
