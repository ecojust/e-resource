# 福州路沿街三开间的复核

房屋管理局第四批优秀历史建筑登记表的4A021列福州路17、19号。2015年2月6日的照片可辨北立面三个底层圆券门洞、上层三个尖券框、挑檐托块、东侧铁栏楼梯和中部门前平台。2021年街景里的绿色17号牌在西边的浅色加建上。模型表现三开间石墙，范围止于两端。底图1140号足印和OSM 380340030的交并比为98.86%，东边临江的轮船招商局另有1580号足印。

三档资产各通过184次射线检查。原始网与编辑工程对照19,988个三角形，重新打开的Blender工程含94个可编辑网格组。石材材质使用768×1024的原PNG，逐一检查11,472个UV角。地面遮挡使台阶高度和局部进深只能估算，中央白门平台到檐顶的照片量测范围约9.2至10.2米。
