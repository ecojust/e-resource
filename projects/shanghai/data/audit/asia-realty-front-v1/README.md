## 正式城市地图复核

四川中路普益大楼是第277个城市模型。前版目录有276项，旧城对照图选中的是卜内门大楼。新版手机和桌面目录都打开了“普益大楼四川中路街面”资料卡；从邻楼切回本栋时，触屏点在（168.5，426.5），鼠标点在（343.5，261），两次都落到本栋图钉。桌面斜景中，一侧较高的邻楼掩住部分侧墙，正面的连续窗列仍可辨。

街面近照能分清凹入的底层入口、列柱和高窗上的横梃。屋顶俯视图里，滴水线沿长立面转到侧翼，檐下的小窗逐间排列。南端近照可辨双扇门、门头窗和左侧的圈饰窗格，附近建筑的图钉遮住了窗面中段。上层开间的正视图可见成组的方窗、竖向窗间墙和檐下齿饰。远景保留了城市街口、江岸和一列密集的图钉；资料卡仍选中本栋，实际载入27,572面的远档。近档为48,868面。街面地面和邻楼共26处逐点核过。

独立页的六张图分别来自桌面与手机。两张正面图能从上层窗组看到底层门洞，斜视图里能看出退进的柱廊与两端较高的檐口，远档俯视保留了屋顶长度和两端台阶。手机竖屏将资料和按钮排在模型下方。页面实际保存了原始网格、近档、远档和可编辑原生文件，四件均与清单中的字节数及SHA-256一致。
