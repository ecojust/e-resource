# 华邨五原路76弄起伏铁门与弄牌

2017年8月19日Antigng拍摄的五原路76弄住宅入口，门柱绿牌写有“76弄1–16号 五原路”。内侧铁门的两道曲线顶栏间有环与菱芯，门右侧窄条用连续卷铁装饰。
