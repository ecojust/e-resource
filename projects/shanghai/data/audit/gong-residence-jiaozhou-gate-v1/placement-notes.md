# 胶州路522号拱门的定位与通行

市房管局第四批名录4B017登记龚氏花园住宅。522号街门与院内住宅分属两个位置。院屋是原城宏块14-13718-6694的1778号，底图房形与OSM建筑490282703的重合率为98.45%。510号属于第四批名录4B016，原城建筑3183在门心东南约27米。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

## 门心与照片尺度

2015年1月28日和2020年2月23日的四个街景站分别交会。两期各自解得的门心相距约1.5米。登记采用两次门心的中点，东经121.43699422度、北纬31.23432555度。局部X沿街朝东南158度，Y向东北进院。门心距1778原城房形最近约5.69米。绝对位置估计有0.8至2米误差。

两期街景独立解得门洞宽3.09米和3.62米。模型采用2020年的3.62米。以此标尺及2015年1月22日正面原片EXIF等效33毫米焦距，用同一正立面四点求单应矩阵，测得起拱高3.86米、内拱顶5.70米、外压顶6.47米。四点均取门墩外侧立面，内退铁扇不参与标定。原片保留透视、电线与砖石压顶的分界。竖向误差区间另见测量文件，其试算采用3.45至3.80米的宽度范围。2015年1月28日街景估得的较小洞宽是另一项尺度偏差，应与条件区间一并阅读。[Livelikerw于2015年1月22日拍摄的522号原片](https://commons.wikimedia.org/wiki/File:522_Jiaozhou_Rd._Shanghai.JPG)

2015年原片和2024年实照可辨左扇向院内开启。2020年街景可辨两片铁扇在中间接合。模型把左扇设为82度、右扇设为7度，均按展示状态估计。房屋名录对住宅的登记不提供街门建造年份。[陈洁的2024年门口照片](https://www.thepaper.cn/newsDetail_forward_27269259)

## 原城与实体复核

街屋2100的北端在门心向内0.44米处开始遮住右半幅门洞。原网该屋的23.806米高度来自100米分辨率的栅格估算。局部截取后，近档保留原投影43.22平方米，约74.43%。远档保留41.47平方米，约74.67%。唯一新增的房端截面依原城实际屋高补齐。院内1778、510号的3183及周围房屋均完整保留。实际回退瓦片的1,335个房面与新切区无面积相交。

实际原始、近档、远档各用三道水平截面核底。53个采样覆盖砖墩、两片门扇、街面和原有屋身。街边至门后留有贯通的1.25米宽、7.05米长连续带。默认机位的方位角为48度、俯仰为57度，镜头从胶州路偏南一侧看入左墩内侧。桌面和手机均能看到圆形慢牌黄底和独立黑色字面、半圆扇花、两块印有机构及门牌的铜牌、保护牌和右扇中缝立梃。右侧铰链被本门砖墩遮住约0.66米，右扇的卷花和中缝仍可辨。字样的细笔画以独立实物页近景核验。

三档实网对14处构件共作84条材质首射。两屏三档另有6条射线穿过打开的门洞。将这些视线在旧街屋与院宅所在的两个原城分组各跑近远档，共360条。42处原交点落在2100的切除范围内，登记后没有保留建筑挡住目标点。
