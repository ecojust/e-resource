# 戈登路巡捕房南院面中央山墙与柱廊

江宁路511号历史主楼的南院面保留砖砌山墙、三层窗和两侧柱廊。布里斯托大学所藏早期照片与建筑师发布的修缮完成正照能对应山墙下的放射券砖、浅色石门套及上层柱头。2017年的公开照片从北侧摄入，用于核对体量和屋瓦。模型覆盖南院面中央约14.5米，两翼、北面与后续室内改造留待调查。[作者来源与年代](../../../source/precise/jingan-gordon-road-station-south-front/README.md)

近景22,516个三角面，远景9,876个，50组可编辑构件。原始、网页近景和远景各125条射线实查门套左右的收分与凹进、中央窗券与辐射砖、廊柱的柱身和柱头、栏杆及屋檐。进深和檐口高度依据照片估算。[实体逐项检验](preflight-surface-checks.json)

底图的主楼为1295号原体，街院南侧另有2862号原体。在已有31271站上，两套平面来源均只切本楼南侧约52.56平方米，分别保留约777.75平方米，其余1,812个聚合分量保留。另以真实近远网格与46处地面点检查院前、后退门扇与保留楼体，地图专项还检查一处保留面及17栋邻房。[原城网格、碰撞与地面](placement-geometry.json) · [预检站的矢量复核](preflight-vector-31271.json)

原正面角度下，南侧保留建筑挡住全部11个外观标志。现选14°方位与54°俯角，沿院斜看，两种屏宽上均可见券窗、廊柱和石门套。两档模型和周边原城三角分别接受44次实际射线复核；山墙中央、石门楣和中层玻璃的取样落在实体表面。原图纸未标实高，结论限于模型与公开照片可辨的构件。[两种屏宽的视线](camera-sightlines.json) · [保留建筑的实际三角](actual-camera-city-triangles.json) · [两档模型首交](both-lod-self-visibility.json) · [原机位压缩记录与校验](author-scene-review.json)
