# 黄渡路17弄3号住宅临街双层砖券门

Fayhoo于2015年4月12日拍到黄渡路17弄3号临街小门及院门。模型取灰褐色外墙中的拱门，门右有绿色3号牌；可见两道前后错开的红砖券、淡色砖门脚和深色双扇铁门。
