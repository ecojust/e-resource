# 陕西南路195号住宅临街二层窗

上海市第五批优秀历史建筑名录5A052登记陕西南路191—197号。WQL于2018年6月10日拍摄并以《陕西南路195号》为题公开全幅街照。本次测绘范围为195号主屋临街二层的北、南两组窗。两组窗各有两道粗中梃，三个宽格中央各有一道细竖梃。每格的横梃将玻璃分为四行。中央横梃在树叶和电线遮挡处使用其两端及相邻净距复原。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [WQL原照与许可](https://commons.wikimedia.org/wiki/File:%E9%99%95%E8%A5%BF%E5%8D%97%E8%B7%AF195%E5%8F%B7.jpg)

以两窗轴线中点为X0，南为正。2018年4160×3120像素原片和2013、2015、2017、2021年的五个沿街观测共同估计两窗轴距约4.21米。2018年各自边缘反算净框宽约1.52米与1.51米，窗顶约6.71米、窗台约5.45米。逐次剔除一处街景观测所得共同宽度在1.44—1.59米之间。街景投影的竖向差异及树木遮挡使绝对高度有约三十厘米量级的不确定性。窗框相对灰墙的0.10米凹进与窗台0.125米的挑出为模型估计。门牌范围中其它住宅与底图各户的对应留待独立实证。

近、远两档各有48块玻璃、12列和两根带斜面的灰色窗台。每档实网格上的130条街向探线检查左右框、粗梃、细梃、玻璃与窗台。两个JSON文件列出各探点的第一命中材质及深度。对照板使用2018年WQL原照裁切和近档实网格的同机位投影，采用CC BY-SA 4.0。街景图像仅用于摄影测量，公开资料附各原始相片和投影参数的出处。[许可](https://creativecommons.org/licenses/by-sa/4.0/)
