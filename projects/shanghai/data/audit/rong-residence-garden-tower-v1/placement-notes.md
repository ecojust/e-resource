# 荣氏花园住宅角塔与柱廊的地图定位

原城房屋749与陕西北路186号的OSM足印相交面积占并集97.90%。谷歌斜俯航照中，取花园中央折面两端的三道水平线，用2015年与修缮后立面照片估出的标高把像点外推至地面。ESRI影像独立显示，角塔位于花园面西南端，向东北接双层柱廊。塔前中央估计在东经121.451242°、北纬31.228541°。航照楼体有倾斜，不同影像的位置误差约4米。陕西北路外六个街景站多有树冠和园墙遮挡。[航照取点](../../../source/precise/jingan-rong-residence-garden-tower/measurements/garden-site-registration.json)

原城把整座主屋画作26.1米高的房体，旧房角伸到照片中的塔基前方。切去749西南端及首间敞廊，近网保留原屋投影656.91平方米，远网保留648.79平方米，各为原来的84.70%。两条切面收住剩余原城屋身。另查过12栋邻屋及53个地面点，其中包括两根实体柱、可走的柱间石板以及敞廊后墙。[实物网格及地面点](preflight/garden-city-meshes.json) · [裁切合同](preflight/garden-placement-contract.json)

底图将这块区域的建筑并为含1813个部件的面。原城第269期作为作者阶段对照时，只有荣宅对应部件减少约117.17平方米，其他1812个部件保持原有形状。正式前态应从第302期物理清单重新绑定。[矢量面积核验](preflight/garden-vector.json)

普通目录从花园看向住宅，方位角−42°、俯仰56°。900×650桌面与390×844手机分别测试了12个构件，包括两侧折窗、两根柱、铜顶和后退门。用同一眼位在近、远模型各实测全部12条单面可见射线。仅核对城内遮挡时，早期候选−31°/37°也能看见外轮廓，但模型自身遮住东折窗和廊后门，因此改用现有视角。这里记录的是从真实网格和地图相机算出的视线。[城市遮挡](preflight/garden-overview-camera.json) · [逐材质首个交点](preflight/garden-model-camera.json)
