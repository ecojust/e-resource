# 长乐坊337号退进侧翼、落水斗与西端窗

两处近街冬季机位相距2.30米。引入约16.34米外的2015年东斜站，百叶罩前面四角的三站交会进深为2.81至2.87米，各射线到交点的最大距离约11厘米。第三版依据该读数定位散热罩、米色退翼和黑色雨水斗。西端红木小窗与前墙之间有短折面，西站与近站推算的折进深度尚有差异。2017年夏照对画面最右部分的横向投影仍有系统偏差，右部单独测得的位置偏移与误差见量测表。

中央两座瓦檐调整了分皮瓦色、封檐板与斜脊帽鼻。两版对照留下初模型23个能穿出天空的像点，新墙顶按实际板底接合。西端小窗保留暗玻璃、红色木框和下部斜撑。原图上的散热罩读数逐站复核，实际首击和穿过横片看到后墙两类分别记录。后墙与深处房间仍待实测。
