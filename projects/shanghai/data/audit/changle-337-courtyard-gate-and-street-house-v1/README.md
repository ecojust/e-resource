# 长乐坊337号院门与相邻临街窗墙

绿底337号牌在院门左柱上。从这里向东经过低围墙、退进的百叶罩和黑色落水斗，再到面向长乐路的双窗。两片低瓦顶向后抬起，高层设一对白色滑窗和一樘向外开启的绿窗。院内深处和同组另一端335号门牌另待核实。[互动模型及下载](../../../changle-337-courtyard-gate-and-street-house.html) · [七个街面机位](registration/registered-street-models.jpg)

| 部位 | 实测 |
| --- | --- |
| 绿窗与门牌 | 原近远网和各自独立解码网每档30个窗内点均首中框或玻璃。两站原图中的门牌中心均打在实物牌面，中心差分别3.64和3.54像素。 |
| 檐墙接合 | 初次组合的23条视线可穿出天空。按屋面板底的实际三角面封接墙顶后，四档同位置全部首中实体。 |
| 低屋顶与后起高层 | 四档低屋面31点各有28点在原像素命中目标材质，3处保留边界差异。高窗和上檐16个清晰位置全部通过，另一原像点被树干遮挡。 |
| 退进院翼 | 两个2015年冬季机位相距16.34米，百叶外框三站实测退进约2.84米。60个采样中51个直接碰到罩或其内机，6个穿过格条看见后墙，东斜视角另3个先遇2017年照片所见的街角绿管。 |
| 两档及编辑工程 | 近景2,003个闭体、104,144面，远景543个闭体、24,956面。Blender重开得到235个编辑网格与九相机，三台实照相机各检九个原分辨率点。源码包106项，可重建八张程序材质、两原网及三份发行GLB。 |
| 页面 | 桌面与触屏各实选九个机位、下载五项文件并放大三幅自渲图。 |
