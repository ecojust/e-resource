# 长乐坊337号屋面、退进窗墙与院门第二版

加入中央深色瓦坡、退进侧翼瓦坡与后起高层。高层有并排白框滑窗、外开的绿扇和屋内阴影面。灰砂浆以上的屋墙顶边依据每块瓦坡板底的实际三角面收口，中央前墙上的两对绿窗和院门的四周均保留可编辑实体。根据2017年照片构造百叶的十道横片、弯曲的一片、两侧返片和可见的内层散热片。退进深度和不同年份影像上的横向偏差保留在测读表。

九个观察机位包含三个实照相机。院门左柱的牌心采用两处冬季相机的交会，单件近远两档分别重射两处照片的门牌中心，均命中真实的绿色牌面。首次组合曾在右瓦檐下漏出天空；这次保留贴合板底的承墙。两档源网包含1,971和522件闭合构件，分别102,400和24,456个三角形。瓦色、檐下暗部及完成版渲染继续在后续迭代校准。
