# 武康路129号街门与阳台复核

按Antigng（2017）及Windmemories（2026）的原机位重新渲染，重新放置号牌，对照斜槽、漆木和固定上亮，并按2026年状态制作两扇外开阳台门。门牌的位置采用两个年代的共同测量值，白色数字依2017年照片轮廓做成立体描边。完整表面之外，三个数字的笔画与9字中孔均可独立核查。

修订版近景215,684面，远景121,626面，每档4,215件。原始网格及两档网页网格已实际解码核对。每档20个门牌与拱边预留点有19处直接命中，2017年左肩的另1处相差1个原像素。旧铁栏保留原有曲线，具体弯曲形状仍待进一步测绘。[同机位修订前后对照](../registration/registered-openings.jpg)
