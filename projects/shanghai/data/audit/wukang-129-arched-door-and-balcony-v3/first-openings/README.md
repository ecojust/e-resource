# 武康路129号双拱首轮修订

首轮复用了城市地块3733、原山墙、后退墙面、瓦面和弧形围栏，着手修正入口的斜纹拱套和圆端阳台的双扇。2026年按原拍摄站核对后，发现绿底129号牌的上部被新的内拱边遮挡，灰色斜槽也需微调。此处保存的是当时实际导出的两档闭体及发现偏差的图，不代表门牌的完成状态。

原图来自Antigng（2017）与Windmemories（2026），均为CC BY-SA 4.0；原照片链接和许可见本模型的SOURCES-LICENSE.md。这里的图像由模型渲染。原始公开模型为2026年10月26日提交的 xuhui-wukang-129，原网15,002,212字节，重新构建得到相同签名。当前近景214,028面、远景120,126面。
