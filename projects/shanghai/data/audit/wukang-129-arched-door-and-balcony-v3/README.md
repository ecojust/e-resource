# 武康路129号德利那齐宅

模型沿用原有建筑轮廓和局部坐标，重做临街拱套、红色木门和“129”号牌，以及右侧弧形阳台的双扇与固定上亮。2017参考照由Antigng拍摄，2026参考照由Windmemories拍摄。本页所示图像全部由模型重新渲染。[修订前后同机位对照](registration/registered-openings.jpg)

| 部位 | 核验结果 |
| --- | --- |
| 门口灰拱 | 近远景中，左右拱脚各有两条实拍剖面可辨斜槽。近景的起伏在7.8至11.8毫米之间，沿两腿测得的灰槽横向差最大约3.4厘米。 |
| 门牌与漆木 | 每档20个预留的两期实拍点有19处直接命中，2017年左拱肩的另一点相差1个原图像素。2017年三个数字的六个笔画点、9字内孔和牌外木面共8点全部命中。 |
| 弧阳台 | 双扇按2026年状态朝街面打开，固定上亮保留。两年22个独立位置中18处直接命中，其余在标读容差内。旧栏因沿用原件，8个实拍栏线及缝隙测试只直接符合1处，后续仍需重测。 |
| 整栋保留 | 近景4,174个原有构件按逐三角位置、法线、材质和顺序复核，188,546个面一致。远景的4,042件盖瓦和底瓦保留原布局。 |
| 交付 | 近景215,684面、远景121,626面，各4,215个闭合构件。Blender 4.3.2新进程重新打开，140组、16种材质、9个机位通过核验。源码包重建8张纹理和3份交付GLB，全部逐字节一致。 |
| 网页 | 桌面与手机各操作9个机位、各实存5项下载。两期实拍对照图可放大查看。 |
