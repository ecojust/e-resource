# 电力大楼东北转角塔楼

[独立模型](../../../electric-company-corner-tower.html) · [地图位置](../../../index.html#landmark=huangpu-electric-company-corner-tower&mode=overview) · [街照、作者与日期](../../../source/precise/huangpu-electric-company-corner-tower/reference-review.json)

南京东路181号登记为3A008。1929至1931年建成的六层大楼，在转角底层主门上方排有五层窗。主门前的三道石阶、红棕门框、双扇门的镂空栅与浮雕、两盏竖灯及181号牌取自正面街照。两扇门独立建模，左扇有执锤人形和闪电，右扇有伸手人形和日光。两条街上的窗带、铸铁层间饰板、砖柱及石质塔冠取自斜视照片。尺寸与装饰进深含估计，其余两条长街翼和完整屋顶仍待补证。

近景有23,752个三角面，远景有8,732个。原始GLB、近景、远景各检验126处表面射线，包含高低浮雕、镂空、材料和窗洞。1024像素的原创顺砖纹理分别嵌入三个GLB和可编辑Blender文件。[表面检验](surface-checks.json) · [可编辑文件](geometry-native.json) · [材质与纹理](packed-masonry.json)
