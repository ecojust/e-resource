原始／网页近景216,912面，远景96,128面。原始GLB 11,736,148字节，网页GLB 3,647,560字节，远景GLB 1,759,244字节，Blender 6,302,484字节。本件包含先施历史主楼的街面骑楼、两种削角、柱列与山花、阳台、东南摩星塔，以及浙江路北段降低的翼部。时装商店与东亚饭店是同楼不同用途；相邻老／新永安、新新、大新和另一处东亚大楼不在范围内。未原址配准或替换城市对象。

## 资料与尺度边界

[文献复核](documentary-review.json)实际读取两份官方志书等来源。南京路约66米、浙江路约61米是沿街长度，不能与7000余平方米占地直接拼成完整矩形；官方记主楼共7层、高“30余米”，未给准确塔顶高度。[地图审查](footprint-review.json)读取已冻结的先施单要素及邻楼，约106.04×74.99米的粗外包无分栋、天井或高度证据。

模型主体100×68米、主檐30.6米、东北低翼21.8米、摩星塔帽顶47.3米和杆顶51.3米均为作者设计估计。主楼7个／低翼5个造型层、退台与削角边界、两方亭一圆亭的段高均未测绘标定。装饰突出后实际模型外包102.10×70.05×51.30米；这不是已核实的实楼长宽高。不能用“30余米”加自拟塔高作为尺寸证据。

[三图照片复核](photo-review.json)实际查看Pyzhou的2010年长街面（GFDL1.2或以后版本）、Livelikerw的2013年摩星塔近照（CC BY-SA3.0）、Chainwit.的2024年街角夜照（CC BY4.0）。多期参照不等于1917原貌或2026实测现状。照片仅供观察，不取样、不嵌入、不随包分发；原创建模代码与几何采用MIT。

[最终四图复核](visual-review.json)绑定最终模型、建模源码、原生文件和四张渲染SHA256。东南大山花背板、主檐／柱列层级、两级方亭与圆亭、东北降层均可辨认。长街窗网仍较规则，精确开间、柱式、雕饰和栏杆没有完整复原；广告遮挡位置采用简化封闭过渡，不能认为这是已知原墙。深部平面、后立面和屋面为估计补全，封闭屋面不证明实楼不存在内院。钟面10:10为示意，尺寸与色彩未经现场校准。

## 实际检查

- [作者及原始几何](geometry.json)：近景4,448个、远景2,889个作者构件分别闭合、正体积，绕序和法线一致；导出坐标有限、无退化面。每版70条实际网格射线验证骑楼玻璃约3.52／3.51米后退、南侧70米和东侧45米的廊内通道、方亭拱洞与圆亭透空，以及东北21.8米屋面和上空无飞出竖墩。所有射线数值只描述模型，不是实楼测量。
- [立面净距](facade-clearance.json)：作者专项检查显示加强后的分组壁柱横缝与窗洞最小净距约0.03976米；东北墩／缝顶不高于21.55米。这项检查绑定最终源码及原始导出，检验建模构造而非历史精度。
- [四资产与压缩解码](packaged.json)：实际解码网页近远景，逐材质FLOAT32有向三角面集合与未压缩导出精确一致，保留重复次数、禁止面反向。三个GLB均通过70条射线、包络、面数、绕序和法线检查，无材质批次拓扑告警。四件文件的字节数和SHA256与manifest吻合，单件小于100,000,000字节。原生文件只读检查无图像数据块或图像纹理节点。
- [Blender保存重开](native.json)：Blender4.3.2重新打开后建筑1个网格、216,912面，来源raw SHA、几何哈希和候选范围元数据一致。摄影棚地面、灯光与相机不计入建筑。
- [桌面与手机网页](browser.json)：近远景切换和四件下载摘要通过。桌面／390×844手机均核验投影外包完整可见，无横向溢出；初始角色位于外包外6米。W键前进0.10米，松键后连续8帧不再前进，Escape返回；手机触屏前进0.20米后清空按键。60米模型范围、80米场地边界生效，能越过旧46米边界，在约79.95米停止，无页面、控制台或HTTP错误。[实际截图复核](browser-visual-review.json)

作者构件未作全楼布尔并集，不宣称整楼是单一流形。原生文件为一个可编辑建筑网格，参数化源码另行提供。
