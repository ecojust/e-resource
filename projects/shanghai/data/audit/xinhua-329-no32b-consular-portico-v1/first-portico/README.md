# 新华路329弄32号乙双柱门廊首稿

正面近照能读出左柱脚的32乙字样，较远的庭院照片显示同一门廊、东侧凸出的楼梯间和坡屋顶。首稿包括两根平滑石柱和柱础、叠涩檐枋、八个瓶式栏杆、半圆券门、铁花亮子和向庭院展开的台阶。绝对尺度暂以门扇净高2.10米归一。两张原照共同估计柱列至门面的距离约1.31米，庭院远景的九个门墙标志重投影均方根误差2.76像素。古典石饰与墙身交接、砖拱、柱上门号以及楼梯间外墙继续细化。[近景网格](full-source.glb) · [远景网格](lod-source.glb) · [正面机位](registration/portrait-model.jpg) · [庭院机位](registration/wide-model.jpg) · [闭合检查](solid-review.json)
