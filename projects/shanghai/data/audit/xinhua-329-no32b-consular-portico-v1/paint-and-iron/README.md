# 新华路329弄32号乙的手绘门牌与门上铁花

原照片左圆柱下部的蓝色“32乙”有清楚的三个手写轮廓。每个笔画沿相机射线分割、贴合到圆柱实际可见的表面。门上方的八段弧形铁花、折回处和扇形下边的可见短条分别建模。中央菱形红纸及其浅色边缘记录近照拍摄时的装饰，纸面纹样另核。庭院远照挂有灯笼，两张照片的节庆装饰分期处理。门扇净高暂按2.10米归一，绝对尺度尚待现场测量。研究原照未嵌入模型。[近照与庭院照片来源](https://www.sohu.com/a/145677223_391447)

近档99个闭合构件、13,560个三角面；远档92个闭合构件、6,668个三角面。两档从原照片两机位分别投射33个像点，首击预期材质的结果为近档31/33、远档31/33。逐点记录保留未命中项。院面墙板、券砖及屋面仍在细化。[近景 GLB](full-source.glb) · [远景 GLB](lod-source.glb) · [手绘字](registration/near/pier-number-model.jpg) · [拱门铁花](registration/near/iron-fanlight-model.jpg) · [庭院机位](registration/near/wide-model.jpg) · [逐点复核](registration/two-photo-rays.json) · [闭合检查](solid-review.json)
