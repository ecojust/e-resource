# 新华路329弄32号乙的屋顶与楼梯间

施工时的庭院照片记录了屋顶双扇老虎窗、背后陡山墙和门廊东侧多边形楼梯间。近照里只能看到其中一面。将规划图册第10页施工照与2017年庭院远照的17组可辨部位配对，屋面读点的均方根误差分别为2.66和1.75像素。绝对尺度沿用门扇净高2.10米的假定。瓦面有实际洞口，两扇玻璃分别退进，塔身两层正窗和斜面错层窗均单独开洞。屋面不可见的一侧取对称坡，陡山墙回折暂取3.20米。西侧底层边界、背面和平面布局尚缺测绘依据。[规划图册，第10页](http://www.dayuehs.com/pdf/xmyh02.pdf) · [2017年庭院及入口照片](https://www.sohu.com/a/145677223_391447)

近网220个闭合构件、20,312个三角面，远网213个闭合构件、12,732个三角面。两档各从原网绘出八张对位图。门廊近照、庭院远照和施工照共63处材质读点，两档各有60处首击相符。三处差异分别为庭院西窗的窗框、老虎窗中部邻近的浅色框，以及塔身斜面错层窗在施工照中约9至12像素的竖向偏差。[原始近网](full-source.glb) · [原始远网](lod-source.glb) · [施工照机位](registration/near/scaffold-station-model.jpg) · [双扇老虎窗](registration/near/dormer-model.jpg) · [门户铁花](registration/near/iron-fanlight-model.jpg) · [逐点实射](registration/three-photo-rays.json) · [网格闭合核查](solid-review.json)
