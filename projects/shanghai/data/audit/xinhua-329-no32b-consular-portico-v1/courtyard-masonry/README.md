# 新华路329弄32号乙庭院砖券和两侧窗墙

庭院远照可见西侧一扇分格窗、东侧两扇窄窗。三处开洞都有进深、窗框和窗台。正面近照还能辨认圆拱上的中间顶心、放射状砖块、左墙铭牌的中英文标题和门上节庆贴纸的淡色笔画。券砖的27道暗缝可从照片亮度变化直接辨认，两侧暗处按相邻砖宽补齐。铭牌上能辨认的两行用字库重新排印，小字留白。墙体进深采用暂定值，屋顶和侧后翼仍在核对。[照片出处](https://www.sohu.com/a/145677223_391447) · [规划图册第4、10页](http://www.dayuehs.com/pdf/xmyh02.pdf)

砖墙、柱石、柱础和门扇各使用一组原创颜色与法线贴图。色调据照片中各三处区域的中值，贴图按米制重复。第三方照片未打包。[照片颜色统计](../../../../source/precise/changning-xinhua-329-no32b-consular-portico/measurements/surface-colours.json)
