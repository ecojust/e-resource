# 同孚大楼 · 中国银行西区分行旧址

南京西路801号的中国银行旧分行和803号公寓入口共用一座弧形建筑。市房管局名录2B003、现场标牌和两个地点记录可相互对应。标牌记陆谦受、吴景奇设计，大昌建筑公司承建，1936年竣工。区志和街志各有1934年与1935年的记载。模型以区志34.45米作为楼梯塔顶控制值。街区专著记露台立柱两排、每排八根，吴江路端保留早期供暖设施。临街弧线、各窗宽度和背面服务廊仍有估计误差。[来源](../../../source/precise/jingan-yates-apartments/README.md) · [原表、照片和区志](../../../source/precise/jingan-yates-apartments/reference-review.json)
