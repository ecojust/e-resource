# 圣玛利亚女中礼堂山墙圆窗与拱饰

浅色圆框内退入一道深色窗槽。外围灰黄色玻璃分成狭长扇面，青绿色内圈围绕中央小圆片排成花瓣。两坡檐下的小拱逐级上升，凹部可以看到后方灰泥墙面。绝对尺度、玻璃色值和铅条细部依照片估算。
