# 朱家角天主堂钟楼中段双菱形砖花与叠层盲拱

朱家角天主堂位于漕河街317弄27号。Fayhoo于2016年2月7日从正面记录钟楼。中层两侧红灰相间，中轴两旁排列成对浅凹盲拱，下部各有一道阶梯形菱花，中央另有一枚短横砖。它们与上一层真正敞开的百叶窗分处两段。
