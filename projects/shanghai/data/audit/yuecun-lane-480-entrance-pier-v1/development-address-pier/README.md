# 月村门柱与2018年的两块号牌

[正面](test-front.jpg) · [斜侧面](test-oblique.jpg) · [68号铜色铭牌](test-number-68.jpg) · [66号蓝牌](test-number-66.jpg) · [远档](test-far.jpg)

上部铭牌两边的固定件与黑色数字直接建入网格，数字6和8内部能透出铜色底板。下部蓝牌单独固定在石面上。斜视可见柱帽从四边微微起坡，伸出的腰线在蓝牌上方投下阴影。

[近档网格](yuecun-pier-near.glb)有4,804个三角面。[远档网格](yuecun-pier-far.glb)有3,140个。两档各以80条射线核对柱脚、横缝、两枚固定件、数字笔画和字孔。[几何与图像记录](models-and-views.json)
