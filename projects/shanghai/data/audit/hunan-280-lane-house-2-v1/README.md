# 湖南路280弄2号五层住宅

三面窗墙与四层弧窗、两扇房门依据两份入弄实照及六个街景机位建立。近档727个闭合构件、30,560个三角形，远档680个闭合构件、20,104个三角形。院内门左的绿色2号小牌在两个实际拍摄机位均可见。两档各19处门扇、门框和门牌照片点均首先命中相应部件。直窗与固定设备在三处原机位另有50个独立复核点，逐点保留实际命中及偏差。主街东端的顶层窗与外墙止线正在根据另外两站的侧照复核。[照片、门号及制作范围](../../../source/precise/xuhui-hunan-280-lane-house-2/README.md) · [直窗与设备](working-geometry/full-wall.json) · [门洞及绿牌](working-geometry/full-entrance.json) · [三处摄影站的模型图](registration/three-stations-model.jpg)
