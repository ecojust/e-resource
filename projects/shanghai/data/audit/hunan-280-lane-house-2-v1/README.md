# 湖南路280弄2号临街窗墙与弧窗

2016年入弄照片记录了楼门旁的2号绿牌。湖南路与弄内共八处机位确定了五层窗墙、底层双扇门、弧窗的三个玻璃折面和三层向外开启的窗扇。街东另两处冬季机位可见东端转折和三扇窄窗。上部临街东窗列转折约16.3°，四站交会的圆角实墙檐口约18.20米。远侧屋檐、院墙遮挡的低层及同组其他门号继续留待核实。[资料与范围](../../../source/precise/xuhui-hunan-280-lane-house-2/README.md) · [四站檐口测量及各站残差](../../../source/precise/xuhui-hunan-280-lane-house-2/measurements/eastern-roof-four-stations.json)

近景777个闭合构件、33,004个三角形，远景728个闭合构件、21,552个三角形。两档在临街东端的26个窗墙点全部正中。东侧面另27处独立读点中24处正中，2020年枝后中窗在上方8像素处命中，两处天际线位置与模型有偏差。三站直窗与固定设备的50个检查点中43处正中、49处在4像素内，弄内一处落水管仍有偏差。射线记录保留原照片坐标和实际首次命中的材质。[原始近景网格](working-geometry/full-source.glb) · [远景网格](working-geometry/lod-source.glb) · [东端26点](working-geometry/full-oblique-26.json) · [侧墙与天际线27点](working-geometry/full-east-side.json) · [窗墙和设备50点](working-geometry/full-main-wall.json)
