# 保定路410至448号住宅成对老虎窗与瓦顶斜脊

Fayhoo于2017年1月28日从高处拍摄保定路410至448号双号联排住宅。大坡屋面分作多段，取紧邻左侧大山墙右边的两扇老虎窗，各有向前收尖的小坡、两侧瓦面及短脊。
