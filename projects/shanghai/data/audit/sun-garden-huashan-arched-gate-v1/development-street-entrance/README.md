# 华山路831号孙氏花园住宅筒瓦拱门

[正面](test-front.jpg) · [斜看券腹](test-vault.jpg) · [831号牌与六边形铁花窗](test-light.jpg) · [远档](test-far.jpg)

模型呈现华山路临街院门。门洞两侧各有六边形小窗，两根铁条在窗内相交。正面能读出绿色831号牌，上方筒瓦随两级山肩起落。斜面可见券腹深度。墙上的竹叶纹及灰色牌板按照片中的外观绘制。[出处与门洞量测](../../../../source/precise/xuhui-sun-garden-huashan-arched-gate/README.md)

[近档网格](huashan-gate-near.glb)含20,532个三角面，[远档](huashan-gate-far.glb)含12,468个。实物各有296组装配部件。[本轮几何和图像校验](source-test.json)
