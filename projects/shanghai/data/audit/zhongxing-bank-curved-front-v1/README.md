# 中兴银行前楼东北圆弧窗墙

福州路89号申达大楼为市房管局第四批4A022。2011年修缮实践记述了六层L形前楼、五层后楼和连接体。2015年的路口原照提供了圆弧三轴从基座、上层双窗到顶层女儿墙的连续外观。2022年刊载的89号直翼门牌近照补充了矩形窗和窗下浅凹板的材料关系。[日期与原图](../../../source/precise/huangpu-zhongxing-bank-curved-front/README.md) · [原照和两角度模型](preflight/street-and-authored-corner.jpg)

三个导出件分别为20,556、20,556、12,600个三角面。每件实测159条射线，覆盖三组底层窗和格栅、四排成对长窗及其进深、浅陷窗裙、十二根檐托和弧形屋檐。图面明暗与纹理来自自制材质。[三档实测](preflight/three-exported-surfaces.json) · [实际导出模型的视线](preflight/exported-mesh-sightlines.json)

原城2362与福州路89号具名轮廓相符。13.05米街面圆弧以五个点拟合；局部切口25.11平方米，在近、远两档分别保留98.97%及99.03%的原投影。十四段截面位于圆弧及其两端的交界处。20处地面样点及10栋原邻楼均按实际网格核查。[原址及邻体](preflight/identity-and-neighbors.json) · [裁口与步行点](preflight/source-cut-and-walk.json)

正式工程重开后逐网格核对外墙纹理及UV，原始、近景与远景三个GLB共作477次材质和进深核验。二十处地面点、十四段裁口均已复测。[交付三档](surface-checks.json) · [工程纹理](native-uv.json) · [最终配准](placement-geometry.json) · [独立预览](../../../zhongxing-bank-curved-front.html)

## 城市主图复核

福州路89号中兴银行前楼已接入黄浦区目录，用于现场影像复核的城市目录收录319处建筑。两张街面照片可辨福州路直立面、四川中路转角的连续弧窗及其窗梃。三档模型保留这段圆弧。1948年航片用于核对街角的方向，现有街景资料用于核对窗轴。
