# 宛平路42号九个模型机位

总览从街面斜看四组折面凸窗，正看一镜可数清四组。其余近景分别放大卷叶栏板、黄砖与红砖交界、入口门楣、楼梯间的双列花板、顶层斜格和白色挑椽。最后一镜转到南侧，可见沿街端竖排的三樘窗、后侧的两个小窗和灰色屋面。

每款实体均有31处相机投影和首击检测。照片专题另从2019年原摄影站查45处真实三角面，覆盖玻璃、交叉格条、弧肩与椽头。2019年最远的椽头被原片边缘裁掉一部分；2020年从相反方向取景的街面照片可复核其位置。两端的遮挡和原单站对椽深的约束见源目录测量表。二、三维转写按平面与立向各自的尺度校正。

九幅图用可交互页面的实数相机渲染。源码复用[华山路登记相机渲染器](../../../../source/precise/xuhui-huashan-823-827-stair-loggia/measurements/render_public_cameras.py)，以本栋 `source/cameras.json` 作为 `--cameras` 输入。
