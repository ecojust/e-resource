# 北京东路街面实看

城市镜位的建筑标牌和下方资料卡遮住了入口柱脚。桌面和手机分别从同一栋楼的普通独立页点击“北京东路正面”和“斜看石柱门廊”，保存整页和画布。正面可见首层中央双柱、门扇及分为三组的上层窗。斜看可分辨门廊的凹进和东侧墙。两端画面都保留原五层檐口与上方加建两层。此尺度下匾上文字无法逐字辨认。
