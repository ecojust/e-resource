# 中一信托大楼北京东路正面与大厅彩绘天棚

独立页可从北京东路看三开间正面、两根槽柱和东侧门。点“仰看彩绘天棚”可进入大厅，从下方看彩绘玻璃与铅条，再点“从天井俯看”观察上层起脊的透明护盖。修缮前后照片确定了两种玻璃的上下关系，1924年二层平面与现状地块给出约17.94米长、5.69米宽的天窗。底高10.55米为估计值。[独立模型](../../../central-trust-beijing-front.html) · [制作说明及原始图据](../../../source/precise/huangpu-central-trust-beijing-front/README.md) · [厅内模型画面](preflight/painted-glass-from-below.jpg) · [天井模型画面](preflight/courtyard-from-above.jpg)

交付前检验逐档读取了62,138、62,138及41,146个三角面，每档以111处表面射线核对窗、门廊与天棚。在桌面和手机计算的默认街景中，各有12处外墙目标可见。场址采用宏块14-13720-6693内的原楼1082，另行核对西邻280号盐业银行的原楼718。97个地面位置和逐态144处高度检查区分了街面开口、天井上方与大厅下方保留部分。[已签预检](preflight/model-review.json) · [各档表面射线](preflight/facade-and-skylight-rays.json) · [临街相机](preflight/ordinary-map-views.json) · [原楼与盐业银行](preflight/signed-city-runtime-31256.json)

## 城市地图与营业大厅

本期在街区原有的305处地点上加入中一信托大楼。桌面鼠标和手机触摸均可从建筑标牌打开本栋。97个地面点逐一复测，远景在距模型约810米处显示简化档。两张城市近照中的建筑标牌和资料卡遮住了部分门廊，用独立页的正面、斜看按钮可看清中央双柱、三开间窗列和挑出的五层檐口。[城市十八幅逐图观察](city-31271/visual-review.json) · [北京东路正面与门廊](city-31271/exterior-views/README.md)
