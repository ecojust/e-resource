# 中一信托大楼成品网格复核

原始模型和从网页近景、远景文件重新解码的模型分别通过111处表面检查。三份结果的材质、第一交点及三角面数与首次交付的记录相同。桌面和手机的仰视、俯视各取49个屏幕位置，两种模型一共复查392束。仰视中心命中象牙色彩玻，俯视中心命中锌条。

在本目录运行 `python recheck.py 输出目录` 可得到两份逐点记录和解码网格。项目自己的 Node 模型读取器在 CPU 上处理两种相机窗口。[输入与结果摘要](independent-result.json) · [原始表面记录](../delivered-surface-checks.json) · [原始取景记录](../delivered-hall-sightlines.json)
