# 合肥路 592 弄弄口与东侧山墙

两张图版均使用已交付 GLB 的几何、材质和测量相机绘制。可从沿街远景、门扇挑头、弄牌、百叶和街面判断两种细节等级的差异。出处、机位和像素测量记录见模型源。图版没有使用街景原图像素。[近景图版](hefei-592-entrance.jpg) · [轻量图版](hefei-592-entrance-lod.jpg)

两门柱正面砖棱间距约 3.07 米。2015 年的东西向影像均可见开启的两扇铁门，二者宽度有别，东扇上格挑出。绿牌主字可读作“592弄”，小字未能逐字确认。弄内 19、22 号分别有地图门号证据，街道相机不能辨认这两户的立面。
