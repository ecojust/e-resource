# 西园大厦

西园大厦（West Park Mansions，名录现名西园公寓）位于愚园路1396号。市房管局第二批列为2M004。长宁区规划资源局将建造年代记为1928年，建筑史研究给出1927至1928年。二手名录所写1912年及另一个旧照说明所写1926年保留在取证记录中。[市名录、各期原片和逐项来源](../../../source/precise/changning-west-park-mansions/reference-review.json) · [独立照片核对](independent-source-review.json) · [查看单体](../../../west-park-mansions.html)

2014年南侧庭院实照所示的三组宽浅拱之上有六个较小窗位，顶层为平头窗，两侧端间分别高出一架透空花架。早期照片中部分敞开的阳台已有住户装窗。2021年从长宁路摄得的两个视点可见北面中央窄窗及两侧凹入的窗井。模型止于本栋，花园、沿街后建住宅与独立门牌1382号保留；私宅内部、井深及2022年修缮后的个别窗式仍待实测。[三期楼顶航片](../../../source/precise/changning-west-park-mansions/aerial-editions.json) · [具名原底图与两条实路](../../../source/precise/changning-west-park-mansions/footprint-review.json)
