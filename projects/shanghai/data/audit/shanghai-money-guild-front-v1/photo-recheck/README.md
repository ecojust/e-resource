# 宁波路三开间立面

2015 年 2 月的宁波路照片和 2022 年 3 月刊出的街景照片都能辨出三组长窗、三座出挑阳台、中央券门和上部装饰带。2015 年照片右下部受车辆与招牌遮挡，2022 年照片能从另一侧看见门前自行车和底层大窗。题名和门牌以市级名录第 4A015 项及建筑铭牌为据。建筑史料记载过修缮和加层，本次模型取宁波路可比对的正面。栏杆截面、窗深和牛腿深度属于模型估算。

按三个模型文件实际导出的三角面重新计算，三开间轴线在模型局部坐标的 −4.88、0、4.88 米处。每座阳台分四点测前缘、四点测扶手、四点穿栏杆孔校到玻璃、三点测托座。射线从街面侧向墙内发射，距离以正面墙线为零；表中正数为向街面挑出，负数为向室内退进。三档均测得阳台板挑出约 1.11 米、铁栏扶手约 1.08 米，穿过铁栏间隙后在墙线后约 0.34 米处遇到玻璃。每档还检验门柱、券顶、花饰和窗框，以及模型外沿留空的部位。照片没有用于推算这些米制尺寸。
