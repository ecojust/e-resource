# 八仙桥青年会 · 西藏南路临街翼

## 模型范围

此次建成西藏南路123号沿街的西翼，包含红砖窗墙、底层入口、两层蓝瓦挑檐和两端墙面。主管部门资料记载历史建筑围合成凹字院落，北部另有较高体量。冻结地图的临街翼原始西边长约37米，进深约11米。模型高33.71米；檐口、斗拱、窗格和被遮挡的后墙按照片比例估计。东侧其他建筑和庭院未计入本模型。[参考资料](../../../source/precise/huangpu-baxianqiao-ymca/reference-review.json) · [位置与相邻后楼](../../../source/precise/huangpu-baxianqiao-ymca/footprint-review.json)

原始及网页模型各有151,200个三角面，远景模型60,876个。重新打开 Blender 工程后，88组可编辑网格的有向表面与原始模型相符。三档 GLB 分别通过51处表面探测，合计153处。入口、分层檐口另有从最终工程取出的近图。[工程核验](geometry-native.json) · [表面检查](surface-checks.json) · [最终外观](huangpu-baxianqiao-ymca-preview.png) · [入口](entrance.png) · [檐口](eaves.png)

## 城市配准与行走区域

宏块14-13720-6694中的2224号原建筑与1408号后楼在北后角相接。两片原始矢量轮廓相交面积为零，其近景窗台向外延伸，两栋近景在水平面上的投影重叠约0.88平方米。矢量替换使用2224号精确原环。近远城市网格另按该楼的源编号施加0.25米向外余量，可去除旧窗台，并保留另一近景包和远景中属于1408号的所有三角面。新模型距后楼的实际近景屋面/外墙投影最近0.21米。[实解码位置与间隔](placement-geometry.json) · [定位、源边界与显示裁剪](final-placement-contract.json)

三份成品的两米以下外墙、门扇和柱脚投影约31.85平方米，模型采用空心外墙。地面碰撞沿实际封闭墙体扩展至楼内，由三档模型中一致的四边形顶板确定内外边界，入口保留直到退进门扇的开口。最终阻挡区域约400.92平方米。独立页在桌面和390像素窄屏实看近远两档，四件下载逐项比对文件字节。[独立预览](../../../baxianqiao-ymca.html) · [校验与四件下载](viewer.json) · [手机近景](viewer-mobile-full.png)

## 主图实看

在冻结的92处地图中，从390×844手机目录打开了西藏南路入口；其后以870×660桌面打开同一地点，分别查看临街窗墙、双层挑檐和后楼。街面及屋顶摄影均等到原城市近景启用，源2224的分组只对本楼应用4个三角面，邻组中的后楼1408继续显示。楼内、退进门厅、人行道、中院及三处邻楼的7个实地点均与预期一致。近景为151,200个三角面，600×460城市远景实际载入60,876个。浏览器还逐项回读四份交付物和两份原城市网格，文件字节与SHA-256均一致。[主图实测及文件回读](main-browser.json) · [正式92处的14项逐文件核对](primary-map-inputs.json) · [运行与源碰撞](runtime-placement.json) · [五图目视记录](map-visual-review.json)
