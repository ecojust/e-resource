# 延庆路121号住宅的可编辑工程

Blender 工程包含152组可单独编辑的建筑部件、22,412个三角面及7个摄像机。灰色丁顺砖、红砖横带和人字砌窗芯分别使用一张内嵌的自绘贴图。每张图按原作的砖缝间距重复铺贴。

第二次 Blender 进程从磁盘重新打开工程，与原始 GLB 逐材质比较有向三角面、贴图内容与每个三角面的三个 UV 坐标。近、远两档网页模型也分别解码并核对了 54,828 和 2,268 个贴图角点。
