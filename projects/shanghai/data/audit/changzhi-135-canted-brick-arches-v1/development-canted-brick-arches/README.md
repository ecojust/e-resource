# 长治路135号公寓转角砖券窗与楔形券心石

Fayhoo在2016年拍下长治路135号街角的红砖公寓。顶层转折的两面墙各开一扇半圆头窄窗，外圈砖券在顶部托住一块上宽下窄的竖向券心石，两面墙的腰线与顶檐在折角处相连。
