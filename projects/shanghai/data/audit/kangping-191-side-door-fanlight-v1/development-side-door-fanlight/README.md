# 康平路191号边门的双道弧梃与五辐扇窗

高参88在康平路187、189、191号的逐幢图录中，把一张拱形深褐木门的照片题作“康平路191号边门”。其扇窗有五根放射梃和两道同心弧梃，门框上缘在中央轻微隆起。
