# 东湖路17号门牌墙段的三档模型

原始网格和近景各有5,601个三角面，远景有2,827个。三份GLB均已重新解码，门牌数字、东湖路三个字、分缝红面和转折石带各有射线在实际表面命中，共计78次。正面、斜视及三个局部图来自这轮几何检查。

绿色牌上的数字和街名取自钱泽民于2026年10月刊出的街面照片。绿牌宽0.32米、高0.22米是正面比例换算的依据，现场绝对尺寸与门后两处建筑的历史用途仍待测。右侧折墙和上方叠石带以独立展品呈现。[实拍第37幅](https://www.meipian.cn/5q6lq3ec)

可编辑建模程序、实拍出处和字形许可收在本项目的 [制作源](../../../../source/precise/xuhui-donghu-road-17-numbered-wall)。中文街名字形采用取得SIL开放字体许可的Noto子集，其余几何与预览图由项目制作。
