# 枕流公寓南花园面

市房管局第二批名录2B020记载枕流公寓在华山路731号。《上海名建筑志》另记699号，列出哈沙德洋行设计、馥记营造厂施工，地上七层和地下室一层。2023年修缮报道记建于1930年，二手名录列1931年。公寓主入口朝北，南侧另有通向花园的门厅和台阶。[市名录、地方志、历史年份与各期照片](../../../source/precise/jingan-brookside-apartments/reference-review.json) · [查看单体](../../../brookside-apartments.html)

2019年12月8日的无人机照片记录了长翼、中央直段和东侧短翼。2023年花园地面照则能看到中央高山花下的透空券列、两侧凸窗、入口门阶，以及与主体分开的两座低门架。华山路一侧另有2020至2021年的三个街面视点。低层侧跨有树冠遮挡，部分窗洞和屋顶设备按比例估计，公寓内部、花园和两座低门架另计。[独立读图记录](independent-source-review.json) · [可编辑几何](../../../source/precise/jingan-brookside-apartments/source/brookside_geometry.py)

项目城市底图中的2669号原楼与三段屋面的折点对应。由原片光心、焦距、航向、云台俯角和四处建筑角部估得纯屋面约747平方米，现状底图投影约765平方米。扣除整体偏移后，转角残差最大约3.6米，摄影机定位与树后底层拐点均有误差。史志所载979平方米为历史用地数据。2018、2021和2024年版航片均保持同一建筑与庭院关系。[近远源建筑与照片配准](../../../source/precise/jingan-brookside-apartments/footprint-review.json) · [各期航片](../../../source/precise/jingan-brookside-apartments/aerial-editions.json)

近景有84,852个三角面，简化远景有34,172个。Blender重新打开70个可编辑网格。原始、网页、简化三档共141条射线检查顶券是否透空，以及券间立柱、山花、门窗、凸窗、台阶和屋面的位置。[原生预览](jingan-brookside-apartments-preview.png) · [三个文件的实际测点](surface-probes.json) · [原生与导出网格](geometry-native.json)

原生组含七栋楼，近景和远景分别替换约777.77和765.07平方米。最近保留网格距裁剪面10.11米。备用矢量图中的2426个合并部件只裁去主屋一件，约765.08平方米。南庭院、道路与其余邻楼保留。[实地模型落位](placement-geometry.json) · [发布合同](final-placement-contract.json)

2023年花园正照所见的连续窗台较浅。首版共用构件另外留下了外挑石台；修订后只保留少数真正的阳台，并按原片补足中央菱形透孔及山花纹饰。窗台最外缘距外墙约8.5厘米。[近照和原生模型的修正对照](garden-detail-revision.json)

单体页已分别在桌面和手机切换近远模型，四个公开下载与清单逐件核实。[浏览器实际操作记录](viewer.json)

## 正式城市地图复核

从239处的旧地图进入华山路原美国学校办公楼地点卡，再移到南花园一侧的同一机位，可见原住宅的平墙与重复方窗。旧图下方仍显示刚才点选的学校。新增后，240处目录中的“枕流公寓”在390像素触屏与740像素桌面均可打开。两端还分别以手指和鼠标从邻楼点击画布上的枕流公寓灯牌，地点卡均显示本楼。楼前定位光点与折转的长西翼、中央直段、东侧短翼可在这四张默认画面上核对。桌面右侧两张邻楼标签相距较近。

南花园专项近景显示两侧外凸的窗跨及中段窗列。屋顶俯视与上层券廊近景可分辨中央高券口、侧面连续透空券列及后方的屋面体块。转到长翼一侧，窗排沿折角收向中央壁面。画面下部被地点卡覆盖，门槛和台阶在这些地图截图中难以逐级辨认；单体原图和三档模型的门阶测点见上文。

在实际城市地面分别检查了5处墙身或门厅、5处庭院或道路空地，以及同组6栋相邻建筑的内部。16个位置的碰撞结果逐一符合预期。城市网页端读取了近景84,852面模型；独立页桌面和手机的近远四图、四种下载与这期签出的网页、脚本、清单及资产逐件同签。前三次街墙取图发生内存不足，原进程退出记录与成功重拍记录一并保存在本次审计中。

旧窄幅远档把建筑截在左边。补拍的620像素方形全图在街区中央可见院面长、短两翼和门前光点，本栋灯牌遮住了中央屋顶的一部分。两张远景都从实际场景读取到34,172面的远档，四件下载的字节数及SHA-256均与发布清单相符。
