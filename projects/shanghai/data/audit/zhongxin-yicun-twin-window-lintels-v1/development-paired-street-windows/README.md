# 中信一村沿街双窗的连檐、曲肩与双层窗台

Antigng于2018年2月7日摄下中信一村红砖街墙。两樘并排的深色双扇窗共用一条浅色水平檐线。每个窗头的两端弯收至细边框，窗底则各自伸出一块浅色阶形窗台。
