# 狄思威公寓四川北路砖砌女儿墙冠与窗檐

五条砖脊在屋顶收成五个小峰。正面可辨相邻脊头的四个低谷，斜面能看出砖层在外缘折回。日间街照和十年后的夜景还保留相同的浅色女儿墙带，下方两扇窗各有一片薄挑檐。[2014年日景](https://commons.wikimedia.org/wiki/File:Liyang_Apartments_Shanghai.JPG) · [2024年夜景](https://commons.wikimedia.org/wiki/File:20240107_Liyang_Building,_North_Sichuan_Road.jpg) · [官方名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

近景模型1,956个三角面，远景模型1,108个。三个交付网格各检验81个砖脊、窗檐、钢窗及留空位置。片段尺寸、挑檐进深及窗框厚度据照片比例估算。[近景GLB](dixwell-parapet-near.glb) · [远景GLB](dixwell-parapet-far.glb)
