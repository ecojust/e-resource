# 姜氏双子别墅东馆花园面西端柱廊

南花园的两张独立照片和两处屋顶轮廓将东馆、西馆及其间的连廊定位到同一宗地。本件取东馆靠中央过道的第一柱跨。方墩、圆柱、瓶式栏杆、后墙窗及上檐按照片制作。原始及近档有23,384个三角面，远档有13,068个。各档使用102条射线核对可见材质与开口。[近景正视](preflight/model-front.jpg) · [近景斜视](preflight/model-oblique.jpg) · [逐条射线](preflight/rays.json)

原城编号52同时包住两栋住宅。原楼近、远网格各自实测后只在东馆这一跨裁去覆盖面，西馆、东馆余下部分、连接廊和北侧2685保持完整。柱间留作通行，石栏、方墩、圆柱与后墙按实际网格截出碰撞面。52个地面点、14个邻体及两套城市轮廓分别对照，双屏相机核对各档真实射线。[两套原网与地面](placement-geometry.json) · [普通相机与邻体](original-city-sightlines.json) · [实站加载与恢复](public-31281-map-runtime.json)
