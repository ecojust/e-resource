# 张小乙宅临街浅凸窗的八扇红框四格窗

2015年1月10日的署名正照显示，新场大街283号张小乙宅门廊上方设浅凸窗。临街一面有四组双扇红框窗，每一扇由三道细横梃分为四格；窗下竖木板表面露出深浅不一的旧红色。
