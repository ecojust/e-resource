# 储康里红砖墙三角窗楣与双菱铁栏

2017年8月19日Antigng拍摄的储康里弄内原照，左侧红砖墙近处的一扇窗有三角形石面窗楣，窗前灰色铁栏的两条横带之间排列同心圆和一对交叠菱形。本作截取窗头、格窗和这一段铁栏。
