# 陈氏花园住宅阶梯三拱窗与绞绳柱

窗台沿粗面墙向右逐级抬高，三道弧券从同一方向重复这一节奏。每扇窄窗上面设扇光，下面由一道中梃和三道横档分出两列玻璃。相邻两窗之间的短柱由方座、双股螺旋柱身和外张柱头组成。侧光下能看到绞绳柱的凹槽和窗框退入墙面的深度。
