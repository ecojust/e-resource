# 襄阳南路313号修缮后两处院面

施工单位两张580×380照片分别校核南、北院的开孔窗墙。南院七处退进开口、四扇二十格凸窗、钢阳台及五台外机按实照落位。北院三扇上窗含青色雨篷，二层有向外开启的窗扇和铸管。两面按3304原户平面和街景层距放入同一坐标系。近景433个闭合构件、16,740个三角形，远景412个闭合构件、11,648个三角形。9处清晰粉刷面影像采样约束原创程序纹理与法线。

从两个原拍摄机位逐点追踪实际导出的两档网格。每档南凸窗25个原像点全部直接命中对照材质，包含首次版本偏离的下层门篷。钢阳台20/21个直接命中，余点先遇棚下钢檩。退进南窗21/24点在对应材质，另三点位于栏槽、窗台和门梃边缘。北面30/31个直接命中，另一点与中梃相距半像素。真实街侧折窗与楼顶仍在单独建模，本阶段保留两院面的独立结果。
