# 襄阳南路313号修缮后住宅

建筑位于313号院内，原城市地物编号3304。现按两处院面和临街折墙的实照制作外观，结合街景高度及航片恢复混凝土平屋顶。近景645个闭合构件、23,156个三角形，远景570个闭合构件、15,636个三角形。
