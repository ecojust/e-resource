# 瑞瑢船厂旧址转角双层绿铁栏外廊

杨树浦路640号临街建筑的圆转角上，两层外廊各有连续绿铁栏。取圆角上的数扇窄窗、上下阳台板、交叠菱格和下垂弧杆。
