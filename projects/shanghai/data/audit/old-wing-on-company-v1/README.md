## 资料与尺度

[文献核验](documentary-review.json)实际读取上海名建筑志、市国资委、上海规划资源转刊及复旦／市委党史资料等。主楼6层、局部7层，屋顶塔2层；占地5681.5平方米、建筑面积30992.3平方米，均未给出准确长宽或老楼总高。志书塔名“倚云阁”与现代来源“绮云阁”异文保留，不认定正式改名；新楼的627／727号、1932／1933年差异另行待核，不转用于老楼。

[冻结地图审查](footprint-review.json)分别核对老永安、新永安和先施，老／新两栋最近间距约10.03米，无重叠。老楼粗外包约66.67×94.64米、没有高度、楼层、内院或分段部件证据；与另一官方转刊“略呈正方形”的描述尚未统一。地图外框不当作实测历史墙线。

作者选择66×94米主体、12.4米东北弧角半径、30米主屋面、34.4米东南局部第七层屋面，以及北侧偏西的塔基和两层开放亭。塔帽45.8米、现代照片参照细杆顶54米。上述尺度、楼层标高、塔位坐标和局部第七层边界均为估计；不把天线认作原始历史构件或已核实的建筑总高。

[照片复核](photo-review.json)实际查看8图，其中6张用于核心建模：Legolas1024的2011年塔部近照（CC BY-SA4.0）、Livelikerw的2013年全景（CC BY-SA3.0）、Suicasmo的2025年白天街角（CC0），以及Supanut Arunoprayote的3张2025年夜间街面（CC BY4.0）。当前页和固定版本页分别实取、各记字节与SHA256；不把上传日混作拍摄日。照片不取样、不嵌入、不随包分发，原创建模代码与几何采用MIT。

## 实际检查

最终检查数据与图像见下列报告，验证只针对本件模型及其独立查看页：

- [作者及原始几何](geometry.json)：近景296,412面／6,945个作者构件，远景103,692面／3,529个构件，分别闭合、正体积、坐标有限且无退化面。每版91条实际网格射线通过，覆盖后退橱窗、圆气窗、东北弧角玻璃与墙墩、阳台板、两层塔亭穿孔与柱、主屋面及局部第七层四侧边界。玻璃后退0.32／0.31米；屋面内侧板顶29.985米、局部第七层顶34.4米，均只描述模型。
- [四件资产、压缩解码及原生文件](packaged.json)：实际解码网页近远景，与原始导出逐材质FLOAT32有向三角面多重集精确一致，保留重复次数并禁止面反向。三个GLB每版91条射线、外包、面数、绕序与法线检查通过，无材质批次拓扑例外；东北额外弧角墙从30.65米衔接低女儿墙，消除了原先重叠的共面墙片。四件文件字节及SHA与manifest一致，单件严格小于100,000,000字节；原生只读复查无图像数据块／图像纹理节点。
- [立面净距](facade-clearance.json)：作者检查近景1,010件／远景215件壁柱与山花对490个主楼洞口无正面积投影交叠。普通山花底距窗洞顶0.09米，距上层洞底至少0.15米；主壁柱到洞口最小净距约0.1043米，扣除窗框外沿后约0.0243米。每版480个窗台、无重复，圆气窗不加矩形窗台；不把这项作者检查称作独立历史尺寸核验。
- [Blender保存重开与四图摘要](native.json)：Blender4.3.2重新打开后，1个建筑网格、296,412面、来源raw SHA和候选元数据一致，保存前后几何哈希相同。记录实际相机、四PNG字节／SHA及建筑世界包络8角和杆顶的相机投影，四图上下至少留3%余量；北侧近景允许裁切长侧的水平范围。
- [四图与参考照片比较](visual-review.json)：独立审阅者实际查看最终四张渲染，绑定最终源码、raw、Blender及四PNG摘要。东北低弧冠与偏西塔分开，亭顶弧山花经修正后更清楚；没有发现阻断本候选主要识别的形态错置，但不构成照片精确复原验收。
- [桌面／手机网页操作](browser.json)：近远景切换和四件下载的字节／SHA匹配，桌面及390×844手机的实际投影完整、无横向溢出。南侧起点距整栋外包6米，W键走0.10米、触屏走0.40米，松键后8帧不再移动；返回查看、60米模型范围及80米外围边界通过，无页面、控制台或HTTP错误。[六张实际截图复核](browser-visual-review.json)
