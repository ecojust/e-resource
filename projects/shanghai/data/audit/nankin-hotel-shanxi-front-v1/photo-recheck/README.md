# 南京饭店西墙入口、雨篷与钝角阳台

2015 年的山西南路街景可沿透视方向数出连续开间和上部阳台。当时店招覆盖了部分地面层。2018 年的近照可辨入口上方独立伸出的雨篷、两侧的深色门框和南侧的铜色饭店牌。现状模型的门篷分段参考了较晚的照片。[2015 年街景原图（Livelikerw，CC BY-SA 4.0）](https://commons.wikimedia.org/wiki/File:Nankin_Hotel_Shanghai.JPG) · [2018 年近照](http://5b0988e595225.cdn.sohucs.com/images/20180115/c34b47350bd14e57ba37efcff0edbc90.jpeg) · [照片大小、原始字节及署名](source-photos.json)

2019 年 5 月 17 日的两个街景机位距西墙约 5.94 米和 5.51 米。用同一张全景内墙面和前缘的像素差复算，阳台尖端相对墙面的投影中位数为 0.815 米，北肩为 0.612 米，南肩为 0.601 米。街景的尺度估计约有 0.12 米的不确定度。[测量机位与原始读数](../../../../source/precise/huangpu-nankin-hotel-shanxi-front/source/balcony-depths.json)

三档模型均实际重读了 142 条射线。其中 36 条检查十二座阳台各自的前缘和两肩，原始与近景模型各有 37,872 个三角面，远景有 17,448 个。每个开间在四楼、五楼各有一座折角阳台，远景仍保留折角和肩部。[三档结果与十二座阳台的逐座测量](balcony-projections.json) · [复算程序](check-balconies.py)
