# 乌鲁木齐南路180号住宅山墙烟囱与阁楼双窗

市表并列180、182号。2018年署名180号住宅的原照片显示，临街红砖山墙中央有一宽矩形烟囱高出两条深色斜封檐；两边的窄白框阁窗与烟囱位于同一端面。
