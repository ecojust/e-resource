# 华山路823、825、827号院临街住宅可编辑工程

本工程以米为单位，含 182 组可分别编辑的部件、38,708 个三角面和 9 台透视相机。工程使用 17 种建筑材质，其中 1 种使用内嵌的原创程序纹理。

Blender 保存工程并退出后，另一进程重新打开文件，与本次原始 GLB 核对各材质的有向三角面、线性颜色、金属度、粗糙度、贴图文件和逐角 UV。近景模型与远景模型分别重新解码，核对了 10,248 和 9,336 个贴图角点。原始网格、网页近景、网页远景及可编辑工程的 SHA-256 见 [four-role-manifest.json](four-role-manifest.json)。
