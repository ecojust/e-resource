# 华山路三山墙住宅的九个观察机位

总览覆盖两侧山墙与向前突出的中央明梯。近看楼梯时可以分辨平台、踏面与细钢扶手；从较低位置看大券，能看到后壁钢窗及门洞。左右扇窗各有独立机位，中央山尖的三处菱花孔与屋檐也可近看。最后一镜转到南侧，在同一画面内观察低凸窗、上层窗、红瓦坡和带三个菱孔的烟囱。

原网格与网页近景、远景的独立解码网格均接受相同的28处检查。每束从对应的登记相机出发，逐三角面记录首个交点、材质和画幅内位置；三档各有28处符合预期。南面第一个斜视角能见到烟囱，但视线被孔侧壁挡住。沿南墙外侧调整视线后，三束均先碰到烟囱菱孔内的深色凹面。模型渲染图和网页实测图分别保留。

2018年照片中被栏板遮住的踏面数量按两端高差推估。观察机位用于阅读模型，不代表历史摄影者站位。
