# 四川北路2305号住宅弧券门头与双曲托

四川北路2305号署名街照中，半圆门券的两侧各有一枚收脚的曲线托座，上部托起平出门檐，檐底有一排小齿饰。模型取门券起拱线以上及两侧托座。
