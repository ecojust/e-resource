# 新华路211弄16号花园住宅老虎窗与相邻山墙

沿侧屋面看过去，一道窄老虎窗穿出红瓦坡；相邻的大山墙向前突出，数扇窄窗收进深色罩板的阴影。米黄色墙面由红色饰带分隔，大窗窗槛下仍露出一排短竖带。两座山尖的檐板、雨罩和玻璃都使用不同的进深。
