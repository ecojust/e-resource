# 贝当公寓临街窗下圆珠与弧带浮饰（2013年外观）

2013年的临街照片中，端部一跨浅色窗扇下方嵌着白色浮饰。比对平窗两端和上下窗台，将窗裙校正到正视平面后，模型沿两侧各三节弧带绘出轮廓，按大小和位置搭出中央26块圆片。[Livelikerw 原照与许可](https://commons.wikimedia.org/wiki/File:Petain_Apartments.JPG)

两档网格各含93个命名构件。近景有12,906个三角面，远景有4,526个。弧带的浅凸面及边缘斜面随视角改变明暗，绿色粗糙墙面与浅色浮饰在同一张自绘纹理中分别取样。[近景 GLB](petain-spandrel-near.glb) · [远景 GLB](petain-spandrel-far.glb)
