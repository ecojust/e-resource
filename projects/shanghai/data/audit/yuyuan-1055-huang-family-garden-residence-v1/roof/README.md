# 愚园路1055号住宅屋顶

庭院一侧的两座老虎窗各有两扇窄窗、独立的小瓦顶和檐沟。旁侧另有一块紧贴坡面的长方形玻璃。屋面在阳光室南侧退开，露出穿花栏围成的平台。

跟Tom看老洋房的转刊照片可以辨认两座凸窗和贴坡玻璃。2016年6月11日由另一位置拍摄的高参第05张中，左侧老虎窗双扇外开。模型采用转刊照片所见的闭窗状态。同期第08张从花格露台方向可以辨认斜向瓦边、远处侧窗与水平栏顶。树木遮挡了屋后多处瓦面，后段的四坡与交沟依据地籍转折作近似复原。[转刊照片](https://m.thepaper.cn/baijiahao_16580844)

原网和独立解码的近、远档各追踪23束，其中十束取自照片、八束从两机位检查四块窗玻璃、五束从上方检查露台。七个点用于配准2016年第05张，原图宽4912像素，重投偏差15.8至65.4像素。留出的贴坡窗上缘为10.3像素。各束首个相交面及材质见 [roof-three-roles.json](roof-three-roles.json)。[05原照](https://s2.sinaimg.cn/orignal/001HIrzOzy849cWTH0D7b) [08原照](https://s2.sinaimg.cn/orignal/001HIrzOzy849cYMYTd4f)

近档439件、远档207件屋面构件分别通过闭合和正体积测试。两档砖瓦纹理是程序生成的周期图，4552和1768个瓦面三角形均有非零UV面积。[逐档核验](roof-editable-solids.json)
