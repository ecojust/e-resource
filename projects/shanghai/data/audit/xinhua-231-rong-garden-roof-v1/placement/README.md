# 新华路231号屋顶与原城市模型的建筑轮廓

上海市优秀历史建筑名录以 **3M012** 登记新华路231号住宅。对照市图块 `14-13718-6695` 的4,157个建筑要素，两期航片上的住宅主屋顶均与编号 **564** 的原城市轮廓相交。该轮廓面积约292.05平方米，质心位于东经121.42308980°、北纬31.20433868°。

| 航片日期 | 屋顶长 × 宽 | 长轴方位角（自真北顺时针） | 与564相交面积 | 占所测屋顶 |
| --- | --- | --- | --- | --- |
| 2019-02-24 | 20.20 × 10.46 米 | 108.35° | 188.73 平方米 | 89.3% |
| 2025-04-07 | 19.48 × 10.77 米 | 106.69° | 120.67 平方米 | 57.5% |

每期各量长、横两轴。以长轴两端作垂线，以横轴两端作长轴的平行线，四条线围出测量矩形。瓦檐、山墙突出部分与墙脚轮廓的差异会影响重叠面积。影像来源给出的绝对误差为8.47米。在该范围内抽取的293个平移位置中，2019年均与564相交，2025年有15个落在建筑轮廓之间的空地。周围其它原户在该半径内均与测量矩形有间距。

`roof-owner-comparison.json` 给出两期原始端点转换后的米制范围、候选原户、面积和误差检验。将其中 `source_url` 所列固定城市建筑表保存为 `feature-table.json.gz` 后，可在含 Shapely 的 Python 环境复算，程序和控制点均在本栋 `measurements` 目录。

```sh
python compare_roof_owners.py feature-table.json.gz roof-control.json roof-owner-comparison.json
```
