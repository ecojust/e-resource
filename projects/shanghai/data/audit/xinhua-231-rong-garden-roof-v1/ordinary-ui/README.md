# 新华路231号住宅的桌面和手机实测

两次独立的 Chromium 会话分别采用 1024 × 690 和 390 × 760 的 CSS 视口，绘图像素比均为 0.5。两个会话分别通过鼠标或触摸选用花园、山墙、老虎窗、屋顶四台摄影机。每次都从正在渲染的透视相机复核了位置、观察方向和视场角。完整近景与简化远景均从普通页面加载。桌面的一次滚轮缩远触发了远景，重新选中相机后恢复近景。

花园总览能同时分辨突出木格山墙和伸出瓦坡的老虎窗。山墙近景可见竖向木格、上下两道横木与灰白填面。老虎窗近景主要显示有三格玻璃的长窗，屋顶俯视可读出两处横向脊线和前后坡面的衔接。手机的初次截图保留了点按按钮后的滚动位置，木格山尖上方局部被截去。建筑的背面和树冠下的首层部分以简化面收合。

桌面、手机各自通过普通下载链接取得八个文件，包括原始、网页近景和网页远景 GLB、Blender 工程、FBX、含 MTL 和瓦纹的 OBJ 压缩包、STL 与离线重建源码。两次共十六份实际保存均在 Chromium 发出下载完成事件后重新逐字节校验。两浏览器均正常退出。逐图签名、实际相机参数、WebGL 渲染器、模型响应及各文件字节数见[浏览器实测记录](browser-checks.json)。

四张以 `centered-phone-` 开头的手机实图来自同尺寸补拍。点按原按钮后将画布滚回可视区，山墙山尖和交叉坡顶上缘均可见。该补拍会话完成四镜后，在下一个切档步骤收到 SIGKILL。上述完整双端验收与十六份实存均来自各自退出码为零的会话。

Linux 系统安装 Python 3.11 或更新版本与 Chromium 后，可用 `python check-ordinary.py desktop all --site /path/to/projects/shanghai --output ./captures` 从包含模型、独页、源码和网页依赖的发布目录复验。把 `desktop` 改成 `phone` 即可重做触屏端。
