# 真光大楼圆明园路东立面

修缮设计方公布的整街立面图和落成照片显示了七组双列窗、两类凸砖壁柱、中央四个独立小尖券和北端局部高起的女儿墙。2010年黄浦区档案中的近照还能辨认中央石门头的「真光大樓」。模型的两侧店窗按修缮后街景制作，字形、砖缝和折面石柱头以照片比例近似。[建筑身份与修缮年份](../../../source/precise/huangpu-china-baptist-publication-building/README.md) · [档案和设计方原始资料](../../../source/precise/huangpu-china-baptist-publication-building/reference-review.json) · [逐图核对](visual-review.json)

原始和网页近景均有57,036个三角面，远景有27,132个。重开Blender工程后，29个可编辑网格全部重新导出，与原始GLB逐材质核对。网页两档经过实际解码。对三份GLB分别投射97条检测射线，核对了六层以内的代表窗格、尖券玻璃与砖眉、两类凸砖截面、柱头石环、门牌四字及三个屋缘标高，合计291次通过。[四件成品](../../../assets/models/candidates/huangpu-china-baptist-publication-building/manifest.json) · [独立页](../../../china-baptist-publication.html) · [原生工程核验](geometry-native.json) · [真实成像](huangpu-china-baptist-publication-building-preview.png) · [实体检测](surface-checks.json)

设计图按25米图例量取的街墙宽约22.8—23.5米，现行地块的圆明园路边线宽23.32米。原城市体块2954北端少了约5.4米。模型补齐了街墙实长，并保留原体块投影的88.68%（近景）及88.99%（远景）。虎丘路广学大楼3051位于相反方向，同组裁切边距其冻结地块17.87米。其余相邻组亦做独立面片核验。[街边和两个来源](../../../source/precise/huangpu-china-baptist-publication-building/footprint-review.json) · [实际几何检查](placement-geometry.json) · [放置合同](final-placement-contract.json)
