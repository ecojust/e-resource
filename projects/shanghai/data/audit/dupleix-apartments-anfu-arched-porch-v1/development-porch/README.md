# 安福路233号临街石券门廊

前柱中心距约3.01米，柱饰到旧砖墙弧窗前缘在水平方向约1.17米。正面能辨中央石墩两侧各七个瓶栏、拱心石上起伏的纵槽、放射扇窗与两道槽柱。四幅检查图显示近景18,508个三角面和远景10,420个三角面的模型。石材自绘颗粒和金属玻璃的反射由查看器光照决定；窗扇分格及侧面栏杆遮挡处采用外观近似。
