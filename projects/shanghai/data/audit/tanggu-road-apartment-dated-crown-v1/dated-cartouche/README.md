# 塘沽路公寓楼冠纪年匾

浅色长匾写有 **1912—1936**。上下各一条长直边，四角收成短弧折肩，深色周界随浅底折转。数字1有向左的起笔与双向平足，两枚9和末位6各留一个内孔。公开照片仅能支持字迹接近石面，模型把字迹处理为贴面的薄层。两组年份的含义仍待史料说明。

人民网2015年10月29日的报道附有一张雨天正面照。其图像原件为800×533，匾宽约63个原像素。沂蒙生活于2017年7月26日发表的组图中，第六幅从另一个位置拍到近景，640×530画幅中的匾宽约129个像素。同组较广的照片带有2016年5月30日的日期戳。两张独立照片可区分边框的长直边、中央横线及各个数字。凤凰网的2015年转载沿用人民网的曝光。[人民网原图](https://sh.people.com.cn/NMediaFile/2015/1029/LOCAL201510291737000146830179068.JPG) · [2015年报道转载](https://sdqy.dzwww.com/jdtp/201510/t20151030_13263603.htm) · [2017年近照组图](https://kknews.cc/zh-sg/history/6pzgb9q.html)

从近照提取的九组笔画在2015年影像的对应位置均比邻近底色更暗，亮度中位数相差36–61级（8位灰度）。最左侧数字1中段在两张照片里都较淡，模型保留这处收细。匾宽约定为4个展示单位，按影像比例取高0.724。绝对尺寸和背部厚度未经现场测量。专题板使用建筑模型的原创渲染。

whole-raw.json、whole-full.json 和 whole-lod.json 分别记录原始几何、解压近景和解压远景中93处的第一交点，覆盖笔画、数字内孔、周界和浅底。dated-cartouche.jpg 展示整匾与两个局部。运行项目 measurements/finish_dated_cartouche.py，传入发布模型目录与本审计目录即可重做检查和专题板。两个摄影平面及其量测均在项目 measurements/dated-cartouche-tracings.json 中。
