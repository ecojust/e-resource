# 纪年匾下的四窗与浅凹砖板

[查看四窗构造图](crown-window-details.jpg)

2015年的历史建筑报道可辨出左边两只独立的深色曲篷。另一组建筑史配图可见曲篷的端布、浅色波边，以及右边两窗各四列六行的格子。右二窗由上数第二道横梃较粗。每窗上方各有一块窄边浅凹砖板。[人民网原图](https://sh.people.com.cn/NMediaFile/2015/1029/LOCAL201510291737000146830179068.JPG) · [建筑史配图](https://kknews.cc/zh-sg/history/6pzgb9q.html)

图板以纪年匾宽为一个比例单位。左二窗被篷布遮住的框头依据露出的窗边和相邻窗头补齐。窗框入墙深度、篷布出挑、砖板凹深都是展示估计。

近档中，四窗及凹板共32个可编辑部件，内含86个闭合实体。远档保留全部格条，以整片玻璃承接每扇窗。检查程序逐一读取32个部件的三角面边和有向体积，再在导出模型上抽查164处框、横梃、玻璃、篷沿和砖板。图板由项目模型投影生成。
