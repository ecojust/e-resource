# 兰心大楼圆明园路入口塔楼与东立面

上海市历史建筑第三批3A014，门牌圆明园路185号。2014年现场照把塔下的中文匾、两侧LYCEUM、185门号和塔身拍在同一幅内。修缮单位的整街东立面图和修后街照补足北翼的四组三联窗、上部退台、塔楼浅色圆券及侧返。塔顶坡面、塔内楼梯、后部各期仍待档案核实。[来源和使用范围](../../../source/precise/huangpu-rockbund-lyceum-building/README.md) · [外观独立核对](independent-source-review.json)

原始GLB和网页近景有17,592个三角面，远景有11,024个。三档实际解码后各用115条射线检查双语门额各字、近景185号、上亮与门洞深度、砖翼六层窗梃、石窗楣、双托与塔楼北侧券窗。四件均嵌入同一原创米制砖纹。近景保留细于远景的铁栅和门号。[原生工程重开](geometry-native.json) · [345条实际网格射线](surface-checks.json) · [三档与Blender纹理核验](packed-masonry.json)

以原生轮廓2358的东墙定位。局部裁切区约145.05平方米，近景保留原楼西部约296.10平方米，远景保留291.97平方米。同一源的保留部分与正面以3段截面衔接。28处地面探针分别检验临街通行区、模型实体和后部原楼。南邻882、北侧真光大楼2954及同组其他实体均保留。OpenMapTiles将28个部分共用一个ID，只在对应本址的第15片（从0计数）裁去约106.85平方米。[原生近远归属](source-cut.json) · [地面、接墙与邻房](placement-geometry.json) · [两种矢量来源](vectors/initial-correspondence.json)

正常桌面与手机预设使用方位−100°、俯角44°。从两种屏幕视点发出的11条射线，均能到达门号、上下券窗、屋檐、北翼街窗、三联窗或退台。[视线计算](camera-sightlines.json)
