# 淮海中路1800号花岗石门柱与三角压顶

Antigng于2017年8月19日实拍的淮海中路1800号住宅入口，金褐色凹角牌写有1800和淮海中路，系在灰色毛面石柱前。石封顶呈小三角，两坡之下可见一块前突的多边石与后退的暗面。
