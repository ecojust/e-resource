# 庭院转角的七个观察机位

总览包含两面相交的外墙、斜顶、玻璃山墙和三管烟囱。庭院正视可辨低处券门、门顶徽饰、两侧斜墙与上部窗组。临街正视可见玻璃山墙下的近角窗与更长的窗墙。

对原始网格和分别独立解码的近、远网格，各从七台登记相机向18个目标发射视线。每档18处目标都在画框内且首先击中预期材质。其中三处落在檐下两扇绿色窗和一扇浅色窗的玻璃上。首轮试镜有一束先碰到绿色钢框，沿窗墙移动该相机后可分辨三扇窗面。七幅示意图使用完整交付网格，网页实机画面另见普通界面记录。

采样的原始坐标与相机均按三组窗轴复核所得的1.184倍定标。每个结果保存相机和模型的SHA-256、画框中的相对位置、首个相交的面和材质。独立视角属于模型观察位置。
