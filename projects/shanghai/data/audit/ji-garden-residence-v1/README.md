# 纪氏花园住宅临街窗塔

北京西路1510号的南侧窗塔有三个临街折面。模型保留上部拱窗、挑出的檐口、山花下的浮雕圆环和四坡瓦盖。几何依据现场照片比例和城市原地块配准。叶片数、檐口出挑和瓦盖背面为估量。登记资料及摄影者、原始链接和使用条件见 [reference-review.json](../../../source/precise/jingan-ji-garden-residence-south-bay/reference-review.json)。

桌面和手机实拍都可看到正面、斜视和轻量档的屋顶。六张图片、四种下载的实存校验值和浏览器退出记录在 [独立页复核](standalone-31308/physical-review.json)。Blender 4.3.2 重开得到91个网格、8种材质和11,586个三角面。原始、网页近景与轻量网各检查了99条表面射线。[可编辑验证](geometry-native.json)
