# 卫乐园街门的默认取景

从28164正式站实取目录、相机模块及55米以内五组近景和同范围远景。对源模型与卫乐园街门的实际三角面做深度比较。870×660、390×844、1280×800三个视口的近远双档中，八栋邻房均未挡住安全框内的街门像素。两侧墙尽端超出部分视口，街门中央券面、葡萄饰件、门柱与120号牌均在框内。[逐视口结果](summary.json) [每处坐标及角度](164-pixels.json)

程序所用安全框来自目录、地点卡和工具栏的边距估计。灯牌占用的位置与真实点击结果以浏览器报告为准。图中灰色为保留的邻楼，米色为建筑模型，黑框圈出扣除界面的范围。[桌面](164-default-desktop.png) [手机](164-default-phone.png) [实取原生文件的SHA-256](164-decode.json)
