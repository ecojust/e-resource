# 朱学仁住宅南园栏杆

2013年9月26日高参88从南廊、东侧与端头拍摄的照片，分别记录了七个正面栏段、地层两道栏段和两道东回栏。二层从西至东为7＋7、3＋8＋3、7＋7，共42根。地层西段11根、东段10根。东端两层各4根。东端近照可见双道鼓圈、收细颈部，以及各自独立的方脚与方领。图板使用解码后的模型绘制。

三份网格的307条垂直于构件的首交射线均命中预期的石瓶、方柱、扶手、底座或孔隙。三张原照另留63个固定像点，原网、高清解码各45个首中石瓶，简化解码44个。东内七瓶另由两张照片独立读出的横坐标复核，其中图13的第七根受到墩柱遮挡。13项横向读数全部在对应高度首中实瓶。全部材料与遮挡均可在报告逐点核对。

项目源 measurements/check_balustrades.py 接收模型与输出报告两个路径。measurements/balustrade_board.py 接收模型与输出图像两个路径。
