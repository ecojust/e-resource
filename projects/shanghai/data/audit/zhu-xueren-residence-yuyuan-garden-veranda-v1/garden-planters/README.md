# 朱学仁住宅南园花池矮墙

2013年9月26日的庭园照片05从西面拍入，照片08在弧阶前方拍摄。西花池沿长边、直边与回角可辨8、3、1块灰色嵌板。东花池的内侧回角1块，斜向长边7块，末块的外边缘受车遮挡。截角灰板、浅色压顶与下部滴水线均由可编辑网格形成。墙后仅表现照片紧接压顶可辨的窄土带。

照片08的四处墙脚与弧阶共用庭前地坪。按对应上下边反算，压顶高约0.40至0.45米，建模取0.43米。两处最接近台阶的收口分别在模型位置（7.285，−2.045）和（11.402，−1.976）米。源测量记录外推段的坐标转换、相机差异及估计厚度。

三个最终网格各65条射线核对了嵌板、缝、压顶、滴水与土面。照片08的8个固定灰板像点有6个首中嵌板，2个落在浅色边。直接使用针对楼身拟合的05相机时，20个固定像点有1个首中。以两图同名的四个花池脚点单独登记庭前平面后，同一批05像点有19个首中。两种读法和原始射线均列入各档报告。

项目源 measurements/check_garden_planters.py 接收模型与输出报告两个路径。measurements/planter_board.py 可从解码网格生成专题板。
