# 朱学仁住宅的屋脊与老虎窗

从南侧花园望去，两扇棚式老虎窗都有浅色窗颊和前伸的红瓦帽。高参88于2013年9月26日拍摄的图05显示，中央一跨的深色檐口向花园突出，方形檐托沿三个开间连续排列。两扇窗以西还能辨出一条更短的瓦沿，外檐和树木遮住其下部。模型将这段做成可单独选取的瓦口与短坡。[南面原照](https://album.sina.com.cn/pic/001HIrzOgy6IyKBpFaA7c)

同日下午的东面图10显示，入口上方另一扇小窗有一道中竖框和一道横档，分出四片玻璃。浅色颊板、红瓦帽和窗下深灰檐口属于东门上方相邻的局部屋面。东窗前后深度取自单张可读特写，估计误差约为0.7米。[东面原照](https://album.sina.com.cn/pic/001HIrzOgy6IyKHGiF95f)

四期高位影像中，逐次量得的主脊长度为12.99至13.62米，南檐长度约18.3至19.1米。三维模型分别表达西侧斜脊、东侧低坡交线及南、北坡。东部浅色附顶与树下北翼的连接位置仍有遮挡。瓦皮纹理由作者程序生成，每0.96米横排四块，每0.84米叠三行。[四期屋面原像坐标](../../../../source/precise/changning-zhu-xueren-residence-yuyuan-garden-veranda/measurements/four-edition-original-roof-traces.json)

相机检查沿已公布照片的原像点向整栋模型发射光线，记录最先碰到的材质。定向检查另行核对每扇窗的玻璃、框、檐帽和窗颊，并检验八条屋脊及檐托。航片检查以每一期南檐为基准，在各自原图的五条线段上取样。檐边采样沿屋内方向移入1.1米，主脊和东侧坡折采样使用原线位置。[实测像点与来源](../../../../source/precise/changning-zhu-xueren-residence-yuyuan-garden-veranda/measurements/roof-photographic-observations.json)

最终原网、解码近模和解码远模的144束构造光线、120束航片取样均逐一复核。三档的三组原照首击结果相同。南面主视43个像点中41个落到对应构件，树枝遮挡较多的南面斜视16个中9个相符，东面34个全部相符。南面差异集中在退入的窗框、窗颊和薄檐边。[整屋投影图](zhu-red-roofs-and-dormers.jpg) · [原网](roof-raw.json) · [解码近模](roof-decoded-full.json) · [解码远模](roof-decoded-lod.json)
