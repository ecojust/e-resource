# 朱学仁住宅园廊与东入口的图像及范围复核

底图原屋编号 1389 覆盖一片约 25.5 × 12.4 米的范围。四期航片中，南侧直檐可辨约 19.1 ± 1.3 米，主屋瓦顶进深约 10.5 ± 1.2 米。东侧转折处可辨的瓦面最远约 21.8 ± 1.5 米。另见东侧浅顶和北侧较远的红瓦，两者的年代、遮挡关系及与住宅的连接仍有疑问。独立解算和影像取样依据列在模型源的 measurements 目录。

三份网格沿十条平面截线取瓦面真实三角形。在 X 为 1.25 至 15.5 米的五处主屋截面，瓦面的南北跨度为 10.22 至 10.53 米。东端回转处的独立后部瓦面至 Y 约 12.17 米。沿花园和周边取十二个平面点向下投射，三档均为空。测试覆盖这些位置，整座院落的历史边界仍待考。

把三张照片的实测像点按各自投影矩阵回投，原始、解码近档及解码远档均有 36 条射线击中模型，39 条射线的第一交点与材质按照片逐行保存。两张图上的 a0 轮廓点及东侧近端雨篷左沿各有一条射线落空。边缘误差和西北侧资料不足均保留在记录中。首交可用来检查遮挡和外轮廓，影像的绝对比例受原图定标及正射误差制约。

在项目根目录运行以下命令，输入为原网或从发布件解码得到的近、远网，输出为相同格式的逐点量测。

```sh
OPENBLAS_NUM_THREADS=1 python data/audit/zhu-xueren-residence-yuyuan-garden-veranda-v1/GIS-review/check-image-rays.py INPUT.glb OUTPUT.json .
```
