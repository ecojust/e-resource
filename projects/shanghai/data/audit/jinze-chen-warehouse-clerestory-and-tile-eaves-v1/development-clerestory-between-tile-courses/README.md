# 金泽陈家仓库层檐之间的窄窗带与小青瓦

金泽镇下塘街16号为陈家仓库。Fayhoo署名街照显示，长白墙上有连续的暗色瓦头，靠后较高的瓦檐下露出狭长的分格窗带。取照片中墙顶和后方屋檐同时清楚的一段，建两道青灰瓦檐、两者之间的暗色竖框及下部抹灰线。
