# 益民食品一厂复建小楼屋面

区级展馆资料、游客斜照和市文旅宣传图均能看到高低不同的两面山墙。中央券廊上方有三扇双光老虎窗，左翼朝院的一扇从游客斜照可辨。2020 年两张街侧视图另见左翼外坡两扇双光窗。两端凸窗各有一道三面折瓦小盖，檐口的深浅两条斜带分别建成独立部件。瓦面纹理由程序绘制。

成品三档逐一复核 71 个原照像点。2018 年区级正面照片 27 点中有 25 点首先击中所判材质，2023 年宣传照片 19 点全部相符，游客斜照 25 点中有 19 点相符。其余 8 点逐项列出实际材料，包含侧板和瓦坡、金属鼻和窗扇之间的投影差异。四幅展示图均使用封包模型渲染。

航片六处屋檐转折给出的后缘进深约为 8.5 米，估计误差约 1.3 米。三张院内照片上的正面屋脊轮廓可以配准；航片所见的里面色带没有独立点可证与这道高脊重合。1937 年始建的原楼于 1985 年拆除，本件的比例依据后来易地缩建的小楼，以正面中券净宽 1.75 米作为展示尺度。
