# 上海中学历史大礼堂外观复核

本页记录上中路400号大礼堂的独立外观模型。南入口采用2020年10月17日的照片，东窗墙采用1934年可辨细节，纵向红屋面及北部浅色条带参考四期航片。远近网格分别有527和627个闭合构件。原始网格有13,580个三角面，远景有11,652个。Blender工程保留279个可编辑构件组和九个相机。

| 实测项目 | 检验方法和结果 |
| --- | --- |
| 正立面与东侧轮廓 | 每档由两处原摄影站投射29个可归属样点，27点直接命中，另2点在4个工作像素内命中。1934年照片右后方另有三点投向未确定归属的高体量，单独列在日志中。 |
| 六扇木门、上亮和八级台阶 | 每档检查37束原图射线，35束在原像素命中，另两束在4个原始像素内命中。 |
| 东墙两层窗、墙垛和窗间墙 | 每档45束实射均在玻璃、墙垛或墙板的预期表面首击。 |
| 屋面与后退顶饰支承 | 每档143条垂直射线检查坡面、侧屋面、后屋面与条带；另有5条水平射线穿过瓦面上方，均命中顶饰下方的承托。修订前的同一位置曾有空缝。 |
| 纹理 | 薄灰墙面、浅黄粉刷、石阶和红色屋面各有独立颜色及法线图。脚本在原始及两个解码网格的每条纹理三角边上复测每米重复比例。 |
