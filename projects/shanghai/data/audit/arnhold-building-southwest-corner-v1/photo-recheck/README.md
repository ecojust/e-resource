# 安利大楼的檐高、门窗和砖纹

四川中路 320 号灰石入口有“安利大楼”四个金字，九江路 80 号另有石券门，两者分处西南转角的两面街墙。2023 年 9 月影像中，角部的现状标志为蓝色弧带。[影像来源及不同年份的对照](../../../../source/precise/huangpu-arnhold-building-southwest-corner/README.md)

把四个街景机位的相机倾角、相机到实墙的距离和窗线原图行号代入全景投影，实墙顶部四次测量约为 25.69 至 27.44 米，中位数为 26.59 米，栏顶中位数为 27.30 米。每个机位均保留墙身各层的窗台和窗楣高程，方便检查角度与遮挡造成的差异。[四机位复算](streetscape-heights.json) · [复算脚本](check-heights.py) · [原街景读数](../preflight/vertical-survey.json)

原始、近景和远景三份 GLB 都按交付清单校验，压缩档解码后分别重跑 227 条射线，检查门券、四个金字、玻璃和砖面等构件。三个文件的射线和砖纹 UV 结果均与首次的逐项记录一致。[三档几何与纹理复算](surface-replay.json)

重读市文旅局的导览文章和三张原照片后，按原文图序核实了街角两栋楼的门牌。九江路 80 号的照片能看见红砖墙、白色水平腰线和绕角的深檐。随后的两张灰石转角照片属于九江路 89 号江川大楼。[三张原图、门牌及校验记录](photographs.json) · [市文旅局导览](https://www.thepaper.cn/newsDetail_forward_22086178)
