# 武进路225弄住宅山墙上的卷草砖雕

这块红色浮雕位于两扇上层窗之间。它在素砖屏下方，上下各有一道凸出的砖檐。对照图能逐一辨认四个上卷、四个下卷和中央的扇叶。现有照片以9、11号合题，未分别注明这面山墙所属的门牌。

左图采用 Fayhoo 于2016年2月9日拍摄的原照。原片2144×1424，按墙面横向砖缝和竖向边缘校正透视，再按雕板矩形裁切。右图从模型三角面直接正投影。原摄者按 CC BY-SA 3.0 发布；本裁切、校正及并排对照沿用该许可。[Wikimedia Commons 原照](https://commons.wikimedia.org/wiki/File:Wujinlu_225_Long_9,_11_Hao_Zhuzhai.jpg) · [许可全文](https://creativecommons.org/licenses/by-sa/3.0/)

高参88于2015年7月发表的图05从另一侧拍到下部完整的四卷。从两幅原图可取得13对相互匹配的叶脊纹理点，覆盖原比例图的下部。图06给出同式砖雕较清楚的截面，但右下卷涡的损伤与Fayhoo原照有别。本网依Fayhoo原照刻画完整卷头。资料采用几何描读；随本页刊发的照片出自上列Commons原件。[高参88原文及组图](https://blog.sina.com.cn/s/blog_5d1bdf480102vysd.html)

模型依据青砖皮数估得板宽约1.82米。浮雕出墙深度是根据卷涡斜缘和投影作的估计。48个检验点分布在八处卷心、八处回卷、扇叶及露出的红色承面；每点均在实际成品上取第一个相交的三角面，并读取其材质与凸出深度。
