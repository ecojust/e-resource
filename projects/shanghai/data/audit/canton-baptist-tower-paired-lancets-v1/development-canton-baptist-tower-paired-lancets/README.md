# 广东浸信会堂旧址塔楼双联尖券长窗

Fayhoo于2015年拍摄的广东浸信会堂旧址，临院塔楼正面有一对狭长尖券窗。蓝色中梃将上下两排窗格及米黄色下栏板分开，外侧一圈蓝色大尖券围合两孔。
