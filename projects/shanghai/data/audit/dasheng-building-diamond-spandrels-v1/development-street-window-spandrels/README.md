# 大生公司大楼菱纹窗间墙与成列木窗

市房管局登记九江路230号为大生公司大楼。依Livelikerw于2019年7月11日拍摄的同址街景，制作街面相邻两开间的菱纹窗间墙、深色窗框和檐下曲托。
