# 太原路50弄并立式住宅的两道檐线与双窗罩

修订后的模型在折起的窗罩前缘补入薄侧板、竖接缝与斜撑，将瓦面颜色调为灰棕色。斜视可看清低檐在高檐北侧终止，落水管分别沿两层屋面下落。近景有6,894个三角面，远景有3,378个。四幅检查图来自重新导出的实际GLB。窗罩、管道两侧的细接缝按可见轮廓处理，部分节点在实照中被线缆遮住。本轮保存上层街面构件，绝对标高由原城估算。
