# 太原路50弄临街二层第一版近景研究

[打开近景模型](taiyuan-lane-50.glb) · [正面](test-front.jpg) · [斜看](test-oblique.jpg)

从太原路看50弄1–2号并立住宅，南侧瓦檐较高，北侧两扇窗上的瓦檐较低。两张模型图上都能看清两道檐口在转折处的高度差。较长的落水管从高檐落在大窗与窄窗之间，较短的一根从低檐落在两扇方窗之间。模型只取临街二层这段可见外壁。2015年12月两个拍摄站位给出的低檐两窗中心距约2.56米。今1号与2号各自使用哪扇窗仍待门牌资料。

首轮检查修正了立面剖切后侧面的法线朝向。此版有6,654个三角面，两幅图直接从同一份GLB生成。2015年街照里两扇方窗的窗罩比此版更突出，斜看能区分薄面板与前沿折边。照片中的瓦面以灰褐色为主，此版的红褐色较深，交错瓦色在正斜两图里均偏重。下一版将校订窗罩折边、明暗与瓦色。
