# 塔冠与圆眼山花

从长治路望向南浔路，屋顶有一座浅色折角小塔。朝街的三面中，中间一面为素壁，两侧各有一个窄窗。南浔路侧的小窗可辨出中央竖梃和两道横梃。长治路上的三角山花有两道折坡石边，圆眼嵌在墙面之后，顶部压有一块短石饰。

三期卫星影像给出了塔冠背向街道的四个折角。2019年11月9日、2021年11月25日和2025年4月18日的单点最大差为0.18至0.43米。背街墙面的窗饰缺少可辨认的照片，模型保留其体量和折边。

两个视角共七个圆眼采样均先击中凹入的圆窗。七个影像分歧里，三个斜檐边点在模型投影中落在天空，两个点跨过石边与灰墙分界，另两个点在2021年刊图中位于数像素宽的塔窗旁。三份逐束结果保留了每个像点及其实际首交材质。
