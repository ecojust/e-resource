# 同仁医院旧址沿街的上层窗

长治路直墙有24个可见开口，南浔路直墙18个，三个折面依次有3、2、3个。转角中央中层为实墙。第五批市表此处原名同仁医院，地址为长治路155–159号单号及南浔路193号。另列的长治路119–135号为相邻的万岁馆。

[窗扇与封板专题图](registered-window-study.jpg)取自三维网格。左上采用2023年区刊街角照片的相机。其余四幅分别展示南浔路六轴、长治路的圆券上亮与成对窗扇，以及街道远端金属框内的封板。各开口可在编辑源中逐面、逐轴调整。

## 拍摄年代与可见范围

2016年2月6日Fayhoo拍摄长治路墙面。2021年1月6日的三个街站分别拍摄长治路和南浔路。另有2021年《长治路上的优秀历史保护建筑》图66及2023年8月7日虹口区刊的街角照。区刊画面涵盖南浔路靠转角两轴与第三轴的局部。远端的窗以图66和南浔路两台相距8.740米的街景摄影点复核。摄影点下方看见的是突出的腰檐，它遮住上排窗的下半部。两台的180个像点有20个留出，首轮自由姿态解的留出点中位偏差4.13像素。采用不同站位先验时，最上排可见下缘估在14.40–15.00米，具名远照则可看到约13米处的窗台。

2021年的南浔路照片可辨金属框、浅色覆盖面及褐红色背衬。远端三组按该年的可见状态制作。窗框相对墙面的进深为照片估值。区刊原照显示长治路顶层窗退进较浅，中间一列的长窗洞膛较深。详见本栋measurements下的upper-window-setback-pixels.json、nanxun-named-and-two-street-marks.json及two-station-nanxun-window-bundle.json。

## 验证与复算

[原网](whole-raw.json.gz)、[近档解码](whole-full.json.gz)和[远档解码](whole-lod.json.gz)各保存359条构件法向首交，以及131条摄影射线。前者检查洞膛、固定框、对开扇交缝、水平窗梃、玻璃、石窗台及金属框内衬。后者保留实际首中材质、三角形编号、摄影像点和空间坐标。区刊长治路部分窄窗的取样位置就落在灰色洞膛上。还有若干处被枝叶或街灯遮住，两张南浔路大仰角照片里的上排开口则受腰檐遮挡。较远两轴的配准误差亦保留在记录中。[历次摄影检查](observation-limits.json)

在本栋源码measurements目录运行以下命令。每个GLB分别生成一份首交报告，专题图采用近、远两档网格。

```bash
python check_window_mesh.py model.glb whole-raw.json.gz
python render_upper_windows.py decoded-full.glb decoded-lod.glb registered-window-study.jpg
```
