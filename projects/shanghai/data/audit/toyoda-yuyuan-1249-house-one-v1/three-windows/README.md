# 1号住宅侧墙三扇小券窗

高参88于2013年6月17日拍摄的侧面全景，将三扇窄窗、砖带及挑出门廊一并收入画面。Antigng于2018年2月10日拍摄并具名为1号住宅的原照，可分辨每扇红砖环、半圆上亮、横梃和不同的砖楔接缝。两张实照上没有能独立读清的1号数字门牌。高参同文第二组照片中的绿牌为2号。[高参88原文](https://blog.sina.com.cn/s/blog_5d1bdf480101iozf.html) · [Antigng原图及CC BY-SA 4.0授权](https://commons.wikimedia.org/wiki/File:%E6%84%9A%E5%9B%AD%E8%B7%AF1249%E5%BC%841%E5%8F%B7%E4%BD%8F%E5%AE%85.jpg)

每档组件有153个可分别编辑的闭合实体。独立复核将两个拍摄日期的36个像点分别投向原始组件，检查曲面砖、内框、上下玻璃、半圆上亮和窗台。完整楼体与单项组件分别核验。该组尺寸以砖皮比例为依据。
