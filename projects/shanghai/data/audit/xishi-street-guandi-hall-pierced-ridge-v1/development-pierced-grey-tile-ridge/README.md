# 西市街关帝庙正厅的镂空菱格正脊与卷端

Fayhoo于2015年5月9日从庭院正面对着西市街54号关帝庙正厅拍摄。正脊中央两侧各嵌一段菱格，两头还有较短的透空纹饰，翘起的卷端连接正面坡顶的灰瓦垂脊。
