# 外滩14号塔顶旗杆

市房管局第三批登记3A002对应中山东一路14号上海市总工会大楼。原建筑已有临江立面、西伸后翼及中央石脊。此次结合2012、2014年的两个斜角和2025年的正面照片，在同一地图建筑上补入旗杆、杆头与垂旗。[制作说明与来源](../../../source/precise/bund14/revisions/roof-mast/README.md)

对三份交付模型逐件解码，原三角网、材质顺序、UV，以及近景中嵌入的完整2025年照片均保留。逐个记录了原48个窗洞，28个窗组中的137片照片采样仍用原图。原生工程重开后核对了原模型的顶点、面索引、材质、UV、变换及打包图片。[三档实际解码](decoded-geometry.json) · [窗洞与分格](geometry-comparison.json) · [Blender重开记录](native-reopen.json)

同一造型在三档各做8条射线，覆盖杆身、圆头、窄幅下垂布面及周围空处。各档射线均符合预期。最高石砌处约33.4米，新增杆头约35.68米。模型采用1.75米的估计退距，隐蔽的杆座与绳具仍待考。[实际表面与投影](roof-probes.json)

同一份重新打开的Blender工程以相同镜位分别渲染原有塔冠及补作后的旗杆。斜视能分清旗杆与塔冠前端的两枚弧形饰件，临江正面只见部分红色旗幅。[原塔冠](roof-prior.png) · [修订后](roof-revised.png) · [临江正面](river-view.png)

市区入口、地块和水平四界沿用旧登记。五份登记表已用实物连续更新两次，第二次的字节与第一次相同。登记最高点取杆头，旧石材塔冠和地面的位置可分别核对。[五表核验](five-records.json) · [高度变更与负例](height-validation.json)

在前后两份276处目录中逐项核对，仅本栋的资产、面数和制作说明有变。其他275处的登记，以及本栋的地图位置、可步行入口、地块编号和边界均一致。外滩总表与两份单栋元数据同步指向新文件。[五份登记文件的具体字段](in-place-catalog-comparison.json)
