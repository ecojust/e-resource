# 江湾体育场历史主场接入主地图

[全局主图直达](../../../index.html#landmark=yangpu-jiangwan-stadium&mode=overview) · [来源与重建](../../../source/precise/yangpu-jiangwan-stadium/README.md) · [四资产清单](../../../assets/models/candidates/yangpu-jiangwan-stadium/manifest.json)

本件交付国和路346号历史室外主场的两半阶梯看台、砖外墙、西侧三拱入口及场内特别台、局部棚、东侧平台和两个不同的短端通道。内场保持开放，建筑资产没有草场、跑道或场地底板。独立体育馆、游泳馆、场内独立建筑、高杆照明、临时活动设施和室内不并入，名录b1-021仍保留未完成范围。

## 来源与估计

[文字审查](documentary-review.json)实际阅读三份资料，[图像审查](photo-review.json)实际查看六张现代照片及四张主场设计图。[独立来源复核](independent-reference-review.json)复核同一范围。1934设计第21页的“西门立面图”明确区分外侧三大拱与内侧特别台，现代照片互证；没有把长边西门放到短端，也没有将其镜像到东侧。第三方照片、整篇网页和扫描PDF只作私人研究，不随库分发。

设计周长760米、看台宽17米、20排座位不当作现状高度。近景28级／远景20级、普通座台顶11.15米、外圈压顶12.01米、西门墙16.4米及双鼎最高约18.63356米均为作者估计。西侧棚顶约14.075米、前檐14.225米。百科20米司令台说法没有套用于整圈。门牌、1935年8月竣工与10月投入使用、1934启用表格异文分别保留。

## 模型与修订

普通砖拱和西门拱口有凹入、后部铁门或上升阶梯；它们不被描述为全部直通内场。南端中央矩形通口7.2×6.2米，北端7×5.7米，均为模型估计尺寸且真实贯通。西台三小拱、红座与局部平棚分开建模。牌匾留空，雕饰采用原创简化几何。

最终对照发现西台场内墙与核心之间缺少前沿平台，已补入高4.35–4.50米的平台及两中柱后高13.40–13.75米的连接梁。新增三个组件共36三角，三档原有三角及重复次数全部保留；z=0–2米实际三角严格不变。隐藏梁形是作者估计，不能当作测绘。修复覆盖约63.106平方米原差值；西源仍有约49.906平方米粗源边界／未核细部差异，其中北翼约28.273平方米，不为追求100%投影覆盖而机械填墙。

## 原源替换与地面通行

[定位合同](footprint-review.json)绑定宏块14-13722-6690中的西半源1646／b773143c-051f-411b-86bf-281e395a0576和东半源1816／c8ecf662-6618-4e44-881a-91f99f08907b。西半作为主替换，东半使用独立site替换和自身owner。两块C形显示掩膜分别25与20个三角；原147行裁剪纹理字节不变，本次达到192／192，生产GPU上限未改。

显示替换掩膜覆盖旧粗略外檐，不能当作真实模型足迹或地面碰撞。原主场两源及其实际far／near残留为零；其他2322个原源及东侧共享near组的三个邻体没有误裁。独立体育馆、游泳馆和场内建筑继续保留。

地面碰撞依据真实低位三角，不把高位看台通廊、棚或连接梁压成地面障碍；保留内场与两个短端通道。CPU碰撞格式扩为最多32片、每片32环、单环256点、总4096点，以保存本场11片、956点的真实孔洞；显示替换仍用原65点／8环限制。新增测试约束这两个用途，旧77项合并结果保持一致。

## 实际网页验收

[浏览器记录](browser.json)、[QA逐图审查](qa-visual-review.json)和[根代理十图实看](browser-visual-review.json)绑定同一组最终截图。辅助页桌面全量／远景和手机全量正常；主图默认桌面与手机完整显示大环，默认采用实际远景档，内场、西门和南端三张专门近景视图使用完整网页档。内场地面保持开放，但原有独立附属粗源仍保留，没有把整个场地误说为空无建筑。

西门近照清楚显示三大拱凹进和后部铁门，南端近照显示中央真实通口与连续地面；两者语义不同。东西两组实际near HTTP字节与冻结源一致，25／20裁剪行分别绑定正确owner，三个共享邻体保留。64个实际scene.collisionAt探针（8实体／56开放）通过，远近模型实际切换成功，GPU错误为零且上下文未丢失。

320×568全城图显示78个独立22×18编号牌；320×548最坏标题净区使用20×18，文字仍为12像素，全部78个逐一命中、无重叠或溢出。最坏净区由全部标题实际测量推导，截图真实选中卡仍是绿瓦大楼。原生CDP触屏随后从绿瓦大楼跳到江湾体育场，地址片段、标题、中心与已加载目标资产一并变化。

每张主图都等待真实数据队列及feature-state待写归零，并比较三帧稳定结果；近场图的“建筑模型加载中”是既有全目录累计提示，不能用来替代目标已加载状态。浏览器零页面错误、零警告、零HTTP失败。[宿主收尾](qa-host-completion.json)确认唯一Chrome、Node和私服务器退出，三个控制记录归档，活控制移除；本轮没有重开第二个浏览器宿主。
