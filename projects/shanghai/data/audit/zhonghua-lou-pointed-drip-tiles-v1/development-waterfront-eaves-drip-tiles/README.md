# 新场中华楼临水檐口的弧形筒瓦与尖头滴水

Fayhoo在2015年4月18日摄下新场中华楼邻桥的长立面。临水一侧的檐口交替露出拱形筒瓦端与向下收尖的滴水，下面可见连续深色横木和间隔排列的小木端。
