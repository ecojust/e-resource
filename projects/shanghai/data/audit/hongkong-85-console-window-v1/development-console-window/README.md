# 香港路85号卷首石托窗楣与外开钢窗

香港路85号红砖平立面下排三处相似高窗中，取中间一窗。Antigng在2017年8月31日拍下了左右两个卷头石托、上方出挑的线脚，以及下格向外打开的深色钢窗。
