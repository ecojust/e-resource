# 巨鹿路735号住宅（5B037）

上海市第五批优秀历史建筑名录在5B037项登记「住宅」，地址为巨鹿路735号。1939年《上海市行号路图录》的街号数据分别列出733与735 Route Ratard。两条门号各自独立，1932年住址名录中的733号住户和1942年741号公寓的业主各有其明载地址。[上海市房管局第五批名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [历史街号数据与底本](https://www.virtualshanghai.net/Data/Tables?ID=200)

**研究待补。** 高参88于2022年发表的同街图文中，第一图的后加标示遮住立面，另一幅题注作「巨鹿路735弄」。现收材料尚不能核定735号花园住宅的第一业主或可据以测绘的历史立面。逐项来源、原版名录及图注在[历史来源记录](historical-sources.json)。[原图文](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102zdym.html)
