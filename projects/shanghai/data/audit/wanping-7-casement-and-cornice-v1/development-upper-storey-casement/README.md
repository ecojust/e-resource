# 宛平路7号上层三联格窗与齿饰檐口

Livelikerw于2019年2月23日拍摄的宛平路7号街面，最上层赭色墙面开深色格窗，细浅边框和外挑窗台围住三个并排窗扇。檐下的一列浅色方齿以阴影相隔。
