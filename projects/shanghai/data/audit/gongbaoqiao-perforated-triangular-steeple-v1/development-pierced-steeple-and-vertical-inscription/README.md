# 嘉定耶稣圣心堂尖塔透空三角与天主堂竖题

市第五批名录将耶稣圣心堂、宫保桥天主堂列于嘉定镇中下塘街99号。Fayhoo的2016年1月24日现场照片题为“圣心堂 嘉定中下塘街小囡桥西南堍”，从水岸正对教堂。只取其尖塔上部：浅色三角外轮廓、透光的下三角洞口、上方竖列“天主堂”及顶部细十字架。
