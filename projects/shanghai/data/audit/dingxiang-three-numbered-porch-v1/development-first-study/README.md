# 丁香花园三号楼门廊初稿

华山路849号丁香花园三号楼，原为1918年建造的藏书楼。门廊左柱上挂着数字3。入口两旁的铁栏由圆环和绞杆组成，扶手随五级弧形石阶向庭院展开。模型以2015年入口照片及2024年发表的院内照片为依据，尺寸由砖缝周期估算。[摄影记录](reference-review.json) · [尺寸换算](measurements/porch-and-steps.json)
