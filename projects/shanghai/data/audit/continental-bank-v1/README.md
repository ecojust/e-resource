# 大陆银行九江路北立面

上海市第二批优秀历史建筑2A041，九江路111号。两翼各四列窗、中间凹入七列窗，银行营业厅和底层石门洞跨过整个临街面。2013至2015年的修缮恢复了外部砖面。本模型以修缮后的可见外观为依据，门额包含「上投大厦」「SITICO」和两处「111」。未取得的后部办公楼和楼顶加建细部另待资料。[来源与分期](../../../source/precise/huangpu-continental-bank/README.md) · [单体与四种下载](../../../continental-bank.html)
