# 良友公寓多边形楼梯井与折角木扶手

市表永福路68号、复兴西路91及93号良友公寓。上海房管的俯照、扶手侧照和台阶特写显示不规则折边的楼梯井、赭红木扶手、黑色细栏杆和马赛克踏面。据此截取一层连续的梯段与转折平台。
