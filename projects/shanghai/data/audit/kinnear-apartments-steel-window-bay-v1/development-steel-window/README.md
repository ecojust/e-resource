# 开纳公寓钢窗与砖垛

武定西路1375号原称开纳公寓，市第四批优秀历史建筑名录4M003登记现名武定公寓。Antigng在2014年4月12日从街面斜拍整栋楼，最右侧一段上层窗的细部清晰。厚钢梃把下部窗扇分为四组，每组三列，上亮横贯窗宽。红砖垛贴着左窗边，窗台和窗楣各有数道出挑的水平线。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Antigng署名原照](https://commons.wikimedia.org/wiki/File:开纳公寓1.jpg)

近景有2,392个三角面，远景有1,796个。两份网格分别实测127处窗玻璃、钢梃、砖面、灰缝和收边。首次审图的红砖偏平，修订时加入独立砖面纹理并加深了灰缝与红砖的区别。绝对宽高和各层出挑深度按照片估计。
