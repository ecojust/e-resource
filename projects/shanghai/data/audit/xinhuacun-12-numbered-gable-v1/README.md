# 新华村12号的题号山墙和三跨院廊

愚园路1320号的市级保护名录将新华村12号列作3M003。此版保留中央浅色12号、三樘绿色格窗、交牙砖边、下有烟道的侧屋面，及花园侧两层三跨敞廊和平台下的三道砖券。两期院内实照与旧照共同核对烟囱、远端红瓦坡与门牌位置。城市粗模1888内有具名12号的独立地图点，未见的背面与整栋深度在范围记录中保留。[摄影、保护编号和尺度](../../../source/precise/changning-xinhuacun-12-numbered-gable/README.md) · [三张原机位的模型图](final/registration/registered-views.jpg)

近档489个闭合构件及25,676面，远档351个及9,032面。粗砂露石、红砖、水泥及屋瓦各有独立的程序颜色和法线纹理。三份分发模型对同一组61个原照像点核对首个可见面，50点直接命中，58点在4像素内命中。远端红瓦偏约7像素，两幅较早照片中的左侧烟囱中心均已命中。[三档原照检验](final/registration/independent-three-levels.json) · [闭合构件](final/whole/solid-review.json) · [四组原作饰面](final/mesh/decoded-house-12-finishes.json)
