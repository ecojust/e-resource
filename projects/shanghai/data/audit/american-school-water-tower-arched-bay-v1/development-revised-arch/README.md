# 美童公学水塔顶层砖券窗与挑檐

刊载照片里，券洞上部嵌灰色百叶，下部是一扇蓝绿框窗。修订版将窗洞的清晰边缘与外侧灰色窗套分别量读，净窗宽约占顶层墙宽的16%，窗台到券顶约占49%。檐口两端微微抬起，浅色低屋坡在砖檐后露出。[水塔原照](https://imagepphcloud.thepaper.cn/pph/image/242/310/170.jpg) · [上海市美国问题研究所图文](https://m.thepaper.cn/newsDetail_forward_22259828)
