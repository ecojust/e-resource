# 美童公学水塔顶层砖券窗与挑檐

衡山路10号美童公学旧址的水塔顶层有一扇细长券窗。照片能辨出上部灰色百叶、下部蓝绿框扇和两侧浅壁柱。首版模型保留檐口几道砖挑与檐后可见的低坡屋面。可核资料未给出这段立面的实物尺寸、朝向或其余三面的细部。[上海市美国问题研究所，2023年3月13日](https://m.thepaper.cn/newsDetail_forward_22259828)

近景模型有1,768个三角面，远景有1,420个，两档各含59组几何。四张检查图分别呈现正面、券窗、檐口和远景斜视。GLB内嵌项目自绘的错缝砖纹。与原照对读，这版窗洞显得偏高、偏宽，原照中砖檐两端也有轻微上翘。[制作资料与史料](../../../../source/precise/xuhui-shanghai-american-school-water-tower-arched-bay/README.md)
