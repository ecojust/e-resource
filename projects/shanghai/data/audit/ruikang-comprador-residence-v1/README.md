# 瑞康洋行买办住宅的历史庭院立面

市房屋管理局第三批名录3A020*登记黄陂南路25号乙，附注原建筑约于2000年灭失。1999年入册、2000年现场采访和2019年旧照再刊分别记录了这栋住宅的不同阶段。瞿凯拍摄时的具体年份仍待底片或旧版刊物佐证。[市级名录、当时报刊和照片出处](../../../source/precise/huangpu-ruikang-comprador-residence/README.md) · [历史展件](../../../ruikang-comprador-residence-history.html)

两端的凸墙夹住双券翼廊，中央山花下上下叠置两层三券，深色廊道前有浅石柱与透空栏。独立侧照补出短折墙和底层三券。初稿的端窗偏浅、山花下大窗券头过平，已据照片改为较深的侧壁与半圆石罩。窗口尺度按照片估算。本模型近景及原始档各59,600面，远景35,996面。每档206条射线检查真实窗扇、砖券、柱廊开口和栏杆之间的空隙。[旧照与修订记录](independent-architecture-review.json) · [三档618条射线](surface-checks.json) · [Blender重开](geometry-native.json)
