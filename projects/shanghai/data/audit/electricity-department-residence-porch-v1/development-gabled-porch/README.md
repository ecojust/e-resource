# 胶州路561号电力部住宅门廊与砖山墙

木门廊山尖与带窄阁孔的砖山墙并列。斜侧木饰、上下层白窗和门前台阶各自有立体轮廓。 [历史照片与出处](references.md)

近景模型有26,544个三角面，远景模型有8,756个。两份下载均为内嵌全部资源的 GLB，可直接在支持 glTF 的查看器中打开。[近景 GLB](jiaozhou-porch-near.glb) · [远景 GLB](jiaozhou-porch-far.glb)
