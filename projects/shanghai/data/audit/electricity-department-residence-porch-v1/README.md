# 胶州路561号电力部住宅门廊与砖山墙

第四批优秀历史建筑名录以4B018登记这座住宅。2015年冬街照与2024年10月24日发表的署址照片共同支持小木门廊、两根木柱、檐边挂落以及花栏后的砖山墙。右山墙的窄阁孔与相邻较高山墙的方阁窗可以区分。照片没有提供精确进深，双坡木檐和窗栏的尺寸按画面比例估计。[市房管局保护表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [微不足道署名街照](https://www.meipian.cn/57uah7e2)

近档26,544个三角面，远档8,756个三角面。三份模型共75次材质与深度检测。门棚与山墙位于原房2157的一侧，原建筑约117.12平方米继续显示。近景受裁的760个面和远景受裁的10个面均属该房。城市试验取21栋邻房与22处地面样点，范围包含已另行登记的510号、522号。原街景正视角在两种显示宽度均被旁边保留房屋遮住；调整后的普通概览在桌面与手机上各读到九处实物构件。该项通过运行时相机与实三角面计算，后续实屏另行记录。
