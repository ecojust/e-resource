# 愚园路1112弄20号北栋巷面与室内石阶

2015年11月16日踏访所拍的20号门牌、巷面、室内楼梯和区政府保护铭牌分别提供地址、立面、室内装修和名录依据。巷面照片与楼梯照片各用一台相机。两张照片缺少共同测量点，两组构件的相对位置仍待实测。

近景193件、3,820个三角面，远景150件、3,232个三角面。两张照片中取27个点，原网及两个网页解码网各有25点直接命中，另两点在6个原始像素内命中。四种自绘材料各有一张色纹与一张法线图。编号门牌另附局部模型。

八种下载含可编辑的Blender工程和可独立重建的源码。源码复建两原网、三份发行网格及八张PNG逐字一致。制作工程时，第一轮在预览前退出，第二轮已写完工程后在预览时退出。独立重开此工程，逐件复核拓扑、纹理、UV、材质、九个相机。FBX、OBJ/MTL及STL逐个重新导入，STL首次重开中断及随后成功的两份进程记录均在交换目录。九个原生视图各由一个Blender新进程渲染，包含两张照片校准视图。
