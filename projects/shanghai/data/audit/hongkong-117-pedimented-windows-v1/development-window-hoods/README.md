# 香港路117号键石窗楣与三角窗山花

市表5A043登记香港路117号为SHELL汽车公司、美灵登有限公司、永实业有限公司旧址，现名凯恩宾馆。模型取Antigng在2015年7月20日拍到的两种并列窗楣及上部窗间墙。
