# 福州路 390 号街景与模型

两张对照图分别使用交付的近景和远景 GLB，同一侧的两个小图保留了街景与模型相同的取景范围。左图由 Fayhoo 于 2015 年 4 月 4 日拍摄，原图为 2144 × 1424 像素。模型按现场照片、独立登记照片和沿街的原建筑轮廓重建。各年的树木、展品、车流和店内陈列不在这座建筑模型的范围内。
