# 世界书局上层临街窗扇

福州路390号的五排办公窗共有90个砖砌窗洞。沿街从西向东，每排依次开4、3、5、3、3孔。窄孔的横梃下是一扇玻璃，宽孔横梃下是两扇，各孔横梃上方均为整幅上亮子。两档模型都保存了150片下扇的独立框、玻璃与五片外开扇的空间位置。

照片与几何对照图左侧是2015年4月4日的街面，右侧在同一相机中绘制近景资产的实际三角面。下方放大图使用2016年3月17日两张近照的相机参数，展示实物模型中外推的叶框。摄影者为Fayhoo，本页照片裁切及对照图按CC BY-SA 3.0共享。[Wikimedia Commons原照片](https://commons.wikimedia.org/wiki/File:Waiwen_Shudian.JPG) · [许可](https://creativecommons.org/licenses/by-sa/3.0/)

测量依据包括主照片、两幅方向相反的建档街景以及三幅2016年详照。西端四孔按近照折回街面基准后的净宽约为0.89、0.92、0.92、0.92米。五个局部窗框后退估计分布在0.18至0.34米之间。移除缝隙假设、改在0至40毫米之间取值时，各次反算结果亦有变化。相机配准在最低一排东西两端的高程有约0.26米系统差，本模型分跨取孔缘局部中位值。该差异的测量精度不足以推定楼板坡度。

2016年特写中五扇开叶的铰侧及自由端都可辨，角度估值约为50至63度。头部横亮的实际开启机构和深色涂层下的材料仍待考证。详照使用的是摄影登记的焦距与传感器尺寸，本页只公开照片目次、原件摘要、像素测点、相机与几何数据。[2016年立面建档资料](https://web.archive.org/web/20210423181912/http://www.heritage-architectures.com/index.php/archives/architectures/hp-j-048-v)

近景和远景每份有575条街面首交记录。每个实体窗洞都检查左右叶的玻璃与竖框、通长中横梃、上部整幅玻璃和固定窗框；另在五片实际开启的叶缘检查透过的空隙。核验源码及重投影程序在本栋的source/precise目录中。
