# 会乐精舍（卫乐公寓）

市房管局在第二批名录2D043将复兴西路34号记为会乐精舍、会乐公寓。徐汇区房管局根据1935年的照片和工程册，将这座花园公寓记为Willow Court、卫乐公寓，记载建筑设计为义品放款银行营造部，结构设计为康益洋行，施工为王兰记。现存主楼南向花园，同院后配楼和车库另有轮廓。[制作说明与原始来源](../../../source/precise/xuhui-willow-court/README.md) · [单体模型](../../../willow-court.html)

按历史总平面和区级档案照片制作抬高的南侧入口、七级半圆台阶、八字形凸窗、十一层弧形阳台及十层内阳台。东端车道保持前后贯通，西南内凹处保留后墙。主楼占地在区档案中约380平方米，模型落位采用约352平方米的4000号底图外框。楼高约40米，侧背窗序、屋顶设备和局部尺寸按照片估计。[总平面、楼层及照片依据](../../../source/precise/xuhui-willow-court/author-controls.json) · [原底图和街线](../../../source/precise/xuhui-willow-court/footprint-review.json)

原始模型有54,520个三角面，远景有26,776个。Blender重新打开55个可编辑网格。三档各以101条射线记录栏板和玻璃门之间的进深、两端上下层开口、车道上方的楼板、七级阶面和门前平台。[南花园原生图](xuhui-willow-court-preview.png) · [实际面探针](surface-probes.json) · [重新打开源文件](geometry-native.json)

原近景组有17栋楼。近景和远景原主楼分别约357.71和352.13平方米，最近另栋近景网格距裁剪边约6.21米。备用矢量图的2426个合并部件里仅替换本楼的352.13平方米。地面碰撞分别验证东车道前中后、西端凹口后墙、南花园与真实门阶。[裁剪和碰撞](placement-geometry.json) · [落位合同](final-placement-contract.json)

按正式桌面和手机相机分别检查从画面到入口、凸窗、屋冠和车道的八条视线。[相机和周围原楼高度](candidate-camera-sightlines.json)

已在前一场景的真实矢量模块中验算保留全部其他成分及原属性。[矢量备用层对照](vector-source-checks.json)

对照现状入口近照，补入窗下的成对矮窗、红门罩和浅色弧底。首版屋顶、过道与地面接缝出现黑线；三档模型各查十三处，转角与板边都只保留一个可见表面。[首版与终版的面和实图核对](entrance-and-wall-revision.json)

## 正式城市地图复核

从旧城普通目录进入时，复兴西路34号尚无本栋地点卡，同一朝向显示原建筑。新城目录从245处增加到246处。390像素触屏与桌面鼠标分别实点地图灯牌，均落到会乐精舍（卫乐公寓）。两种初始画面都能看到南立面中央连续的红褐色半圆阳台，街道远景则用于辨认它在周边街块中的位置。

宽屏俯看可见中央高屋面的浅色边缘、小型屋面出入口及两侧较低的平台。南侧入口的宽屏近景可辨底层两座多面凸窗、抬高的门与七级扇形踏步。较窄画面的下部被地点卡遮挡，已与宽屏补拍一并保存。东侧车道在近景形成楼下通口。28处地面实测中，车道南口、中央和北口均可通行；西侧凹处内可走，到后墙即遇实体。16幢邻屋的原地阻挡均保留。

地图近、远两档分别实载54,520面和26,776面。独立单体页的1250像素桌面、390像素触屏各两幅实图显示相同的阳台轴线、翼部及顶部退台。已将这些原图、当时保存的四件下载与正式站的页面、浏览脚本、模型清单和实取文件逐项核对。
