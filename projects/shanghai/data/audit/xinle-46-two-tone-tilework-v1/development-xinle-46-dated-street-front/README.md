# 慎成里新乐路46号双色陶面砖与竖砖过梁

新乐路44弄入口旁46号铺面上半部。深红和浅米色的面砖交替错缝，洞口上方改用竖砖，浅色抹面包住上沿和两侧。成排的面砖从街面转入弄口，较暗的砖带与橙色线脚收住墙头。
