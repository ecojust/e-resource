# 胶州路510号山墙三联窗

上海市第四批名录将4B016记为「司米托莫银行」。陈洁2024年从胶州路拍到510号黑色院门后方赭红色山墙、阁窗和连续三扇深色窗。2020年2月23日的两处街景可交会窗肩、竖梃、山墙尖和浅色檐板的位置。522号龚氏花园住宅的足印另在北侧。[两栋足印和年代](../../../source/precise/jingan-sumitomo-staff-house-gable/footprint-review.json) · [照片、拍摄者与逐项判读](../../../source/precise/jingan-sumitomo-staff-house-gable/reference-review.json)

近档和远档各保留两侧拱肩、中间直顶窗、分立的阁楼小窗、凸出深浅相间的檐板和瓦缘。近档增加窗格与细瓦构造。原城保留其余屋面、首层、院墙和通行；本次局部显示裁切只影响原户3183山墙上部。三份文件分别实测91处材料、退深与开口。[表面验收](preflight/pilot-surface-checks.json) · [近景正视](preflight/full-straight.png) · [远景檐口](preflight/lod-verge.png)

两处街景交会估得主窗台离地约5.1米，窗顶约7.3米，山墙尖约11.7米。树冠与围墙遮住首层，模型范围从4.70米高开始。窗线平面误差约0.3米，尖顶约0.55米。[街面实测点](preflight/stereo-identified-points.json) · [正式摆放](final-placement-contract.json)
