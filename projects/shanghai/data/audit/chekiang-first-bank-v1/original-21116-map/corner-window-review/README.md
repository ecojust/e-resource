# 浙江第一商业银行折角窗

以模型作者文件中的折角立面为基准，取六层各两扇退入窗玻璃的四角。原站桌面和手机相机来自此前正常目录点击记录。用网站同版 MapLibre 投影，在两张原始画面中以细绿线标注窗的位置。输入图像、留白和相机名单在上一级目录。

用相同的界面条件重放原有灯牌和台湾银行标签修正后的位置。390像素下12扇窗投影为1010.38平方像素，旧版灯牌覆盖809.73平方像素，修订后为零。870像素、展开目录时，12扇窗投影为1631平方像素，两版灯牌与该窗组均无重叠。复原定位与重放结果见 [逐窗口面积](overlap.json)、[桌面定位](map-desktop-window-outlines.jpg) 和 [手机定位](map-mobile-window-outlines.jpg)。
