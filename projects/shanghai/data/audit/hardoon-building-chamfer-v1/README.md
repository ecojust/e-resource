# 哈同大楼东南转角核对

保护名录第三批3A017同时列出哈同大楼、慈安里大楼和南京东路98–114号。2014年路口原照中可读南京东路、四川中路两块街牌；2020年上海规划资源供图将同一跨标为东南角。另一幅图题为西南角，报道还记述114号边门的纪念地点。模型表现的是两条道路交口的东南斜面。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [2014年原照](https://commons.wikimedia.org/wiki/File:Fu-Li_Building.JPG) · [2020年建筑导读及配图](https://www.thepaper.cn/newsDetail_forward_8982975)

原楼714号在近景和远景中分别有8,664面和24面。两个原始网格的檐顶都在12.80米。斜面宽5.02米，25个墙面交点显示近景灰墙向内最多约0.21米。新增立面从约3.25米高的店面檐线上方开始，带弧形栏板的阳台向街口突出，曲线老虎窗高于原檐。模型接到原有切角，两条人行道和底商保留。近景组另含738、1562和2945号原房，其中1562号是另案制作的美伦西楼。[位置与资料](../../../source/precise/huangpu-hardoon-building-chamfer/footprint-review.json) · [核验程序](verify-placement.py)

三份GLB各核验63处，包括斜面两肩的接缝、券窗、弧形重栏台、铁栏和老虎窗。近景30,280面，远景8,242面。四份成品下载和桌面、手机共六张单体图均已核过。[各档射线](surface-checks.json) · [六图与四件下载](viewer.json) · [实图观察](visual-review.json)

原楼714的近景8,664面和远景24面、既有屋面12.80米均保留。店铺上方3.25米起建，两面原模型各测25个原墙交点，地面15处核在原有实体内部。两种屏幕各对10处构件发出视线，在近、远两版中共读到40次实际交点。[原楼与人行道](placement-geometry.json) · [正式镜位](overview-sightlines.json) · [四组实际视线](model-sightlines.json)

第254期冻结的289处目录中，原楼714号东南切角没有在先模型占用。美伦西楼占用邻房1562，哈同大楼保留原城两向长翼与店面。两版实际向量底图逐一核过23个部件，包含2927187770号要素第52号子部件。[原房与库存](final-prior-coverage.json) · [原始向量部件](vector-on-predecessor.json)
