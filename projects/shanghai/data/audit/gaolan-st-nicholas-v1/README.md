# 皋兰路圣尼古拉斯堂主堂

上海市房管局第二批名录以「东正教堂」和皋兰路16号登记此处。地方志记载1932年奠基、1934年祝圣，历史上曾有九顶。1942年前照片中的侧顶、1995年灰绿色的主顶和2021年金色的主顶分别留档。本次取思南书局诗歌店改造后的外观，按2020年设计方平剖面和实景恢复主堂、街侧门楼、两翼与东侧圆端。两颗在西侧照片中能独立辨清的小顶纳入模型，其余历史小顶及北侧后勤空间有待测绘。各时期材料、尺寸估算与位置分别见原始来源。[地方志、官方名录与设计图纸](../../../source/precise/huangpu-gaolan-st-nicholas-church/README.md) · [历史照片](before-1942.jpg) · [1995年西侧](west-1995.jpg) · [2017年门楼](gate-2017.jpg) · [2021年金顶](roof-2021.jpg) · [摄影署名](photo-credits.md)
