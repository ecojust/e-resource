# 西南转角的表面与视线

模型取四川中路、汉口路转角的八角塔，铜穹高度和顶杆依据 2017 年修缮后的街照。2013 年的照片可见灰色外墙，2017 年的照片已能辨认红砖、浅色窗框、绿铜穹面和顶杆。西南角和汉口路正门的屋顶各自有不同的轮廓。[两期街照](../preflight/2013-and-2017-west-corner.jpg)

本次从原始、网页近景、网页远景三件 GLB 重新读取几何和嵌入纹理。三档分别有 23,336、23,336 和 12,816 个三角面。每档的 89 条测试射线核对石框、玻璃、砖墙、铜皮等表面的第一处交点及其进深。[三档实测](delivered-rays.json) · [复测程序](check-delivered-rays.py)

砖面沿塔身各折面的长度重复铺设。三档分别复核 1,636、1,630、1,294 个纹理坐标，最大绝对误差为 0.00000177。两种默认取景还在近、远网格各复测 12 处构件，共 48 条视线。[纹理坐标](effective-uv.json) · [相机与构件视线](two-view-sightlines.json)

首次检查转角拱窗视线时，现场读到 1024 像素的阴影图、13 个参与投影的模型和可用的摄影反射。设备绘图比例为 0.5。浏览器报告中的阴影配置字段记录脚本请求值，实际照明以本次读取的场景状态为准。[实测照明与绘图设备](portal-render-state.json)
