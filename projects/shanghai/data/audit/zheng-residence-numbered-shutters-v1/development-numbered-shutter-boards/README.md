# 郑生官宅190号沿街木排门的八块编号板与圆边横档

Fayhoo上传的新场大街街照显示，190号绿牌装在门扇上，其右一间有八块连续的竖向活动排板。板面从左到右可读浅色数字1至8；下端齐落在横档后，横档两头留有凸起的挡块。
