# 长乐路327至329号住宅双窗上方的斜脊瓦顶

Antigng在2017年8月19日拍摄的长乐路327至329号住宅照片中，沿街浅色墙上的两扇钢窗共用一片灰褐色瓦顶。两道浅褐斜脊从顶端向深色檐口张开，檐下露出一排短椽头。
