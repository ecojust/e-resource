# v5候选生成器几何核验

这两份报告针对冻结候选freeze-v6，保留原始JSON字节和源码SHA；报告中的工作目录路径是当时的审计环境记录。

- [结构墙边界](cdt-structural-boundaries.json)：10个覆盖五建筑族、轴向/旋转和中庭的合成案例，墙/洞边界与侧壁顶点严格配对，零T接点。
- [126处来源屋顶](all-126-source-roofs-cdt.json)：直接调用候选生成器核对全部126处已核验屋顶的来源字段、屋面及上坡墙float32三角。该测试为隔离屋顶采用house族，实际类型选择另行核验。

两者均已通过，但未包含全量模型导出、压缩、16区产物对账或浏览器画面验收，不能作为全城已经完成的依据。全量最终状态见[本轮说明](../../../bund/REALISM_V5.md)。源码见[普通建筑生成器](../../../../source/city/detail/README.md)。
