# 大桥公寓门厅方形几何拼花地面

2013年门厅原照记录了赭红方心、四向黑色折带和四角的三条黑线。模型依原照四边校正透视，将各色带与铺面填料建成相邻的实体。所用纹理为程序生成的细颗粒。[Legolas1024门厅照片](https://commons.wikimedia.org/wiki/File:%E5%A4%A7%E6%A1%A5%E5%A4%A7%E6%A5%BC%E9%97%A8%E5%8E%85%E5%9C%B0%E7%A0%96.jpg) · [四川北路85号正立面](https://commons.wikimedia.org/wiki/File:%E5%A4%A7%E6%A1%A5%E5%A4%A7%E6%A5%BC.jpg) · [官方名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

近景4,648面，远景2,760面，各用51条垂直射线核验彩色区域和黑线间隙。模型采用1.80米的展示边长，现场实尺未见于照片。[近景GLB](bridge-lobby-floor-near.glb) · [远景GLB](bridge-lobby-floor-far.glb) · [模型与原照的对照记录](model-and-photo-comparison.json)
