# 安和新村瑞金二路198弄铁门核验

2021年实照中两扇门闭合，南扇有小门，南墩可见绿底白字和白底蓝字两种门牌。近档27,556面，远档12,080面。每档及原始网格各核98条材质与空隙射线。[正面](preflight/model-front.jpg) · [斜面](preflight/model-oblique.jpg) · [逐条实测](preflight/surface-rays.json)

71处地面样点取自模型实面切片。两根门墩、两片门的底横杆构成各自的碰撞范围，沿街和院内两块近门人行区域维持畅通。两组原近档及原远档、12个邻体和两个地面数据来源实核，原建筑3023保留完整。街区矢量底图中最近的面距门约71米，门区没有匹配原多边形；本件独立登记碰撞。[近远档实拍和运行进程](preflight/220-cpu-closed.json) · [原城三角形及地面](placement-geometry.json) · [普通目录机位](overview-sightlines.json) · [载入与卸载六态](public-31279-map-runtime.json)
