# 4号南凸翼、两片红瓦屋面和院门

2015年11月16日的4号近照可读出绿底的“4”和“愚园路一一一二弄”；同日稍远的斜照显示门牌左侧是有盖公告箱，右侧为绿色铁门。三处摄影机位和七个建筑细节机位均已记录。近档587个闭合构件、13500面，远档301件、8448面。五种原创程序纹理分别表现灰泥、带状灰基、灰石线脚、红瓦和瓷漆。北端隐藏的屋面范围、院内地坪高度仍按已有影像估计。[近景](full-source.glb) · [远景](lod-source.glb) · [闭合及体积检查](solid-review.json) · [对应实地摄影](https://4travel.jp/travelogue/11082493)
