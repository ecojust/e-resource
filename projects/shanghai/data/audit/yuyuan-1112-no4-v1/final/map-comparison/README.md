# 4号屋顶与城市原建筑轮廓

按六站量得的南翼方向和腰线西端，将原始GLB中红色瓦面的三角形投影到当地水平面，再与原城市轮廓求交。模型的瓦面投影约261.98平方米，与南栋841原轮廓相交167.94平方米。南栋原轮廓约284.57平方米，其中116.63平方米在精细模型屋顶之外。模型投影与两栋之间的小体量1083相交约1.57平方米，距北栋800约9.78米。四号门牌与南栋实景位置已核对，屋檐和城市底图足迹采用的边线口径仍有差异。

城市地图保留南栋、北栋和两栋间的独立体量。后续可依据院内实测或带尺度的总平面校正后部瓦顶、附房及院落关系。[各区相交面积](measured-roof-overlap.json) · [瓦面及原轮廓](roof-and-three-owners.geojson) · [复算程序](compare_roof.py)
