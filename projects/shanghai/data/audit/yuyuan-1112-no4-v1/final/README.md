# 愚园路1112弄4号实景对照模型

[打开可旋转模型](../../../../yuyuan-1112-no4.html)可查看三处实景机位与七处建筑细节，手动或随距离切换近景和远景。南翼三联窗、弄内两片弧形墙头、4号绿牌、公告箱、铁门及两片瓦屋顶均可分别查看。源包冷重建所得10幅程序图、近远原网及三个GLB下载与网页版本逐字相同。[三机位模型视图](registration/registered-views.jpg)

[四站檐口复测](../../../../source/precise/changning-yuyuan-1112-no4/measurements/front-cornice-four-stations.json)记录了四处街景、十列像素的瓦口和出挑线脚。原取点重测，三套网格在26处均直接命中。修正后的檐口底唇距街面约11.83米。首轮仍能在[旧结果](../../../../source/precise/changning-yuyuan-1112-no4/measurements/independent-surface-check-first.json)中查看。[修改前后模型对照](cornice/two-cornice-models.jpg)
