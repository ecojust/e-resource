# 愚园路1112弄4号实景对照模型

[打开可旋转模型](../../../../yuyuan-1112-no4.html)可查看三处实景机位与七处建筑细节，手动或随距离切换近景和远景。南翼三联窗、弄内两片弧形墙头、4号绿牌、公告箱、铁门及两片瓦屋顶均可分别查看。源包冷重建所得10幅程序图、近远原网及三个GLB下载与网页版本逐字相同。[三机位模型视图](registration/registered-views.jpg)

[独立取点检查](../../../../source/precise/changning-yuyuan-1112-no4/measurements/independent-surface-check.json)覆盖26个图像位置，包括绿牌、公告箱、门扇和红瓦。三个网格各有25处原像素直接命中预期材质。2020年街面图的一处檐唇像素和周围六像素范围仍只命中灰泥。院内外地面高差和后端屋面尺寸仍待实测。
