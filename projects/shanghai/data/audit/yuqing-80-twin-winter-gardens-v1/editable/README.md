# 余庆路80号双圆冬园可编辑工程

Blender 工程含 251 个独立网格、26,220 个三角面、16 种材质与九台相机。两台相机保留花园双向照片的视场、原始光轴及横滚。另一 Blender 进程重新打开工程，核对原网有向三角面、材料和相机。

两个冬园均保留钢窗和反光面，西南近照清楚辨认一扇向外开启的玻璃扇。近景与远景分别实解码，重新打开的原生场景也逐材质核对 Principled Alpha。颜色与法线贴图按作者源文件、采样坐标和逐角 UV 核验。
