# 余庆路80号双圆阳光房两站核对

两幅花园模型图对应同一栋住宅两端的观察位置。东北视图采用2013年9月14日15时35分54秒的实拍相机记录，太阳真方位约254.50°、高度约30.29°。西南视图的实拍缺少可核时刻，只使用天空漫射光。天空光采用18个方向，按楼体自身的遮挡计算廊内、挑檐底和窗边的明暗。两图均由发布的近景几何渲染，未使用原照片作纹理。

完整网格有26,220个三角面、524个闭合构件，远景有12,216个三角面、407个闭合构件。九个观看机位包含上述两台实拍相机。各相机保存光轴和横滚角，便于在网页和Blender工程中复看同一处。

可从两图核对不同的下层构造。西南端的侧券实际穿通，可以在2013年的照片位置隔券望见一扇木门。东北端有五道分扇钢窗和前庭栏杆。两侧阳光房的窗角和开启扇在三档网格各35束测线均直接命中；西南敞廊各17束中的15束直接命中，余下2束在4个工作像素以内。东北窗墙与前庭栏杆各31束中的27束直接命中，其余4束在4个工作像素以内。窗梃或栏杆边上的像素可能先接触相邻材质，具体偏移见逐点报告。

2021和2025年两期屋缘量测采用两端弧顶之间的距离，得到16.53米和15.93米。建筑单户门牌的点位落在院内树冠处。现场同址有多栋，当前交付范围为可从花园看到的双圆主楼立面。照片没有提供足够信息分清门牌所涵盖的二、三号楼。摄影、铭牌、分期影像出处可在模型源码目录中的资料说明核对。

两张照片共同可见的上层栏板西角，三角交会落在局部X约0.12米、Y约−1.18米。最初版本的上层挑廊向西超出近五米，会从东北机位遮住落水管。现已缩短上层挑廊并保留西侧回墙。两张图的中部柱心轴线也把圆柱从临栏位置校回X约0.11米、Y约−0.63米，弯托向花园侧伸出。两站15个独立部位在近景原网、网页近景和网页远景中均直接命中。西南板背面的四个检查位置原先透空，补齐的连接板使其落在照片可见的实底上。
