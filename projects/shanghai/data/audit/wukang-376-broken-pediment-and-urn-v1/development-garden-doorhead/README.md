# 武康路376号住宅断弧门楣与石瓶

市表5D018涵盖武康路374、376号。Antigng的署名照片明确标为376号住宅，院内侧翼门口两段石弧的中央留出缺口，一只瓶形饰件立于平檐正中。这里制作门楣、石瓶、左右托座与上亮窗。
