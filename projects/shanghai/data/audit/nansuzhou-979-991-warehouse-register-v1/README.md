# 南苏州路979号仓库

市房管局在第五批优秀历史建筑名单的5A049条目中，把建筑名称写作“南苏州路979号仓库”，地址栏写作“南苏州路991号”。同一行列有章华毛绒纺织公司上海货栈、中国垦业银行仓库两个历史名称。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

上海市住房和城乡建设管理委员会2020年刊文介绍了衍庆里沿河仓库。2018年的改造重新打开中庭，作为两栋连体建筑的主要出入口。文中将有“1929”题字的入口明确标在南苏州路955号。现有照片可核对这处入口和沿河外立面，5A049在其中的独立边界仍需有门牌的历史照片或界址图校定。[2020年图文原载](https://m.thepaper.cn/newsDetail_forward_7767914)
