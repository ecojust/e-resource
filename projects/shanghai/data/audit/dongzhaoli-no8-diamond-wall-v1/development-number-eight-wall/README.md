# 东照里八号门柱与菱形院墙

山阴路133弄的弄内照片中，右侧门柱留有绿色8号牌。柱顶由数层收放不同的石料叠成，院墙浅浮雕菱形的下端在深色墙脚上方。原作取出这一格院墙，并逐处检查数字的两个孔、柱缝、菱形斜边和墙上方的净空。[Fayhoo摄于2015年4月12日](https://commons.wikimedia.org/wiki/File:Rizhaoli.JPG) · [市名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

近档1,410个三角面，远档794个，各有80处射线检查。墙体和门柱的可见比例取自原照，绝对尺寸与背面进深为展示估尺。[近景GLB](dongzhaoli-wall-near.glb) · [远景GLB](dongzhaoli-wall-far.glb)
