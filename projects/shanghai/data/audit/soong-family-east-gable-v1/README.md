# 宋氏花园住宅东山墙与南园折角窗

东山墙下的敞廊、双柱、正面百叶窗和南侧折角窗属于陕西北路369号院内南宅。两张2016年从街外与园内拍摄的照片，以及2024年、2026年两期航片，共同确定了主楼的位置。原城557与南宅足迹相合；北宅1770的红色直屋脊以及375号怀恩堂留在原位。[历史与实际照片](../../../source/precise/jingan-soong-family-residence-east-gable/reference-review.json) · [航片及落位](../../../source/precise/jingan-soong-family-residence-east-gable/frontage-location.json)

原始与网页网格各20,952个三角面，远景4,744个。三档分别通过155条表面射线。两个原城网格分组共测16座独立邻体，裁片与这些邻体均无相交。主宅原体保留面积在近景为76.32%，远景为76.14%。另测了20个地面点，覆盖柱脚、两柱之间、百叶窗前、园内小路和原宅后部。[实际网格与地面证据](preflight/placement-geometry.json) · [三档表面](preflight/visible-surfaces.json)

普通地图从东面取景。桌面和手机计算视线各可见十项标志中的八项；南园一面应结合独立页的南园机位查看。平面与进深约有1至2米估算误差，窗檐和屋脊等高度约有1米误差。五张预检图使用制作网格和原创粗抹灰纹理，记录东山墙、园窗、敞廊、南园折角与相交屋脊。[机位测算](preflight/camera-sightlines.json) · [原生及网页预检](preflight/model-review.json)
