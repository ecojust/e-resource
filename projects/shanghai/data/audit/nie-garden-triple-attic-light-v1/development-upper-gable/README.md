# 聂家花园高山墙三联窗与拱顶楔石

辽阳路51弄的2014年现场照片里，较高的红砖山墙顶端开三扇共用平窗台的阁窗。中窗以半圆收顶，两侧较矮的窄窗为平头，上方两道坡檐收在同一脊点。
