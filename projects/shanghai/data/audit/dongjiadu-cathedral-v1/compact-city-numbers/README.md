# 320 像素宽手机的全市编号

在全市视图打开长建筑名卡片时，编号还要避开顶部工具栏和底部卡片。原版在108处入口的实际手机页面出现6对编号重叠。每个编号取9个位置，972次中有27次命中另一个地标。实际触摸外滩9号的号码，界面打开了金山卫瓮城。调整后的108处页面按同样方法逐个命中，点击尚贤坊的号码进入门楼。[原版与修订版截图、触摸和采样](../../shangxianfang-gate-v1/compact-capacity/comparison.json)

新的排布按每行实际能容纳的两位、三位编号分配位置，保留12像素字号。在125处的真实页面，125个编号均有可见笔画，1,125次点击位置采样全部匹配，触摸最后一项打开了中山医院历史主楼。另对截图中的26个三位数逐一量取笔画范围。[全屏截图](map-125-markers.png) · [实际触摸记录](capacity-browser.json) · [数字局部](numbers-closeup.png) · [像素检查](painted-text.json)

125处预演使用与本次发布相同的编号模块。手机实拍在建筑目录升级前后分别保留，对应的两个目录都记在原始报告中。[浏览器检查脚本](check-125.cjs) · [数字笔画测量](check-painted-text.py)
