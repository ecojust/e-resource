# 汉口路花园住宅错层楼梯窗

2020年2月19日西南侧的街照能辨认楼梯间上下两排窗。每排四窗，窗头由西往东逐级降低。五个街景机位的16块原图及2014年全楼斜照已按原文件摘要重新核验。[现场照片与署名](source-photographs.json) · [照片和模型对照图](../photo-model-comparison.jpg)

按实照配准，西侧上排窗头高约9.08米，东侧约8.17米。下排分别约5.61米和4.79米。高度估计误差约0.40米，树冠和杆件遮挡处的细格参照同排可见窗。[测量记录](../../../../source/precise/huangpu-bund-garden-residence-stair-bay/dimensions.json)

近、远两档的桌面与手机相机各检查10个构件，包括玻璃凹面、红砖肩部、石带及压顶。40束视线均先碰到预期材质，交点距设计位置均在7.5厘米之内。三种交付网格还分别检查了169束穿过各档窗框、窗洞及装饰边界的视线。近档11,192面，远档2,716面。[相机与实网交点](delivered-sightlines.json) · [三档网格复核](delivered-surface-rays.json)
