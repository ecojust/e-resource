# 汉口路花园住宅临街错层楼梯窗

市房管局第四批名单列4A020、花园住宅、上海外滩花园酒店、汉口路200号。具名OSM与2013年逐址街访写作汉口路210号。原城1555与具名足印交并比98.14%，旧英童学校、三一堂及钟楼另占独立地块。[市房管局第四批名单](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [逐址街访](https://www.oldkids.cn/blog/view.php?bid=492032) · [2014年Legolas1024原图](https://commons.wikimedia.org/wiki/File:Residence,_Hankow_Road,_Shanghai.jpg)

上、下两列错层窗各四扇，西高东低。两档都保留玻璃凹面、贯通的钢框和窄格、浅色窗带及交替嵌入红砖的石块。近景额外保留砖缝与钢框压条。清楚的2020年2月19日西南视图与2015年两处侧站共同限定范围，树下和电杆后的格条按相邻窗估配。原花园围墙、底层门、屋面和其他立面沿用原城。[实照与模型](photo-model-comparison.jpg)

两版原城均保留住宅近档4,008面、远档12面，以及原组其余四栋。十处构件在桌面、手机计算的实际相机和两种几何细度均是首个实材质交点。原城两档网格的二十条对应视线均通，十四个矢量分片逐个比对。地面核33点，其中9处是开放地面。[原墙](placement-geometry.json) · [模型交点](model-sightlines.json) · [原城遮挡](actual-camera-city-triangles.json) · [地面点](map-case.json)
