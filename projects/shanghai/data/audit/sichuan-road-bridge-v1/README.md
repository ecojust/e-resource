# 四川路桥三孔桥身与两侧人行道

市政志给出四川路桥长70.97米，三跨17.14、36.58、17.14米，车行道12.8米，步道各2.7米。2010年2月17日的高位照片拍到了四座灯柱和两侧步道，2014年1月27日的下游照片清楚显示三孔梁腹和北岸的邮政总局。梁腹起拱、栏墙分缝及塔灯分节依据两期照片估计。[照片和年代记录](../../../source/precise/huangpu-sichuan-road-bridge/README.md) · [来源指纹](../../../source/precise/huangpu-sichuan-road-bridge/reference-review.json)
