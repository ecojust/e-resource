# 集贤村金坛路35弄南弄口验收

市房管局4A037列“集贤村”，整组门牌为金坛路35弄1至30号、32至44号。模型表现南弄口在2021年照片里的敞开状态。两块竖匾的底色、细框和固定点可见，小字未逐字复原。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海黄浦的街面照片](https://m.thepaper.cn/baijiahao_15894173) · [街景摄影点与资料](../../../source/precise/huangpu-jixian-terrace-jintan-gate/reference-review.json)

底模核查取自14-13721-6695。近景9.41万面原组中，距门楼最近的网格为1.36米；远景宏块中为1.43米。两侧住宅、内弄及地图三组共775个建筑轮廓保留。两扇铁门分别按实物方向设置碰撞，东半幅仍可通行。53个街面与邻屋位置均有独立核验。三档网格各做138条射线检查，两种屏幕的普通目录相机分别验证12处可辨构件。[地面与原网格](preflight/city-meshes.json) · [矢量底图前后对照](preflight/vector-preflight.json) · [远近档射线](preflight/surface-rays.json) · [桌面与手机视线](preflight/ordinary-sightlines.json)

近景37,452面、远景9,376面。门冠和楣板指向薄拱，东扇向弄内折起；从东侧斜位观看时，近侧的石柱会遮住折入的门扇。冠高约5.57米、净宽约3.20米，均为摄影配准估计。[正面几何](preflight/gate-front.jpg) · [东侧斜位](preflight/gate-oblique.jpg) · [范围与尺寸依据](../../../source/precise/huangpu-jixian-terrace-jintan-gate/street-registration.json)
