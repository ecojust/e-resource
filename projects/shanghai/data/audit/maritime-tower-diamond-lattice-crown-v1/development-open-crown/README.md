# 徐汇滨江海事瞭望塔塔冠的交叉菱格外网

龙华港汇入黄浦江处的海事瞭望塔在Fayhoo于2015年3月29日拍摄的照片中，塔冠腰部外鼓，顶部收窄。两组浅银色斜杆沿曲面反向盘升，围出能透见后面暗色横带的菱格。
