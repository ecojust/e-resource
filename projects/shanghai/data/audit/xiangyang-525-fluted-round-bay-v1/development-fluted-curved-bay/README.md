# 襄阳南路525号住宅弧形窗廊与椭圆饰墩

2018年署名实照中的住宅上层弧形窗廊，三根浅色嵌柱间并排两扇分格钢窗。各柱脚下有红色椭圆饰面，窗顶外伸檐口可见浅黄托块。
