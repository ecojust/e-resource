# 中央储备银行常熟路旧址正门的地图复核

第321期保留356栋城市模型。第322期把花园侧正门和三跨石阳台加入原建筑3343，城市模型数升至357。两次复核使用相应服务的完整目录、发布签名和渲染模块。第321期在内存中加入拟议入口，第322期读取正式目录中的入口。可核查地面位置、邻楼、裁剪前后可见几何以及原矢量瓦片的保留部分。

在本目录执行下列命令。需要 Python 3 与 Node.js。程序按期号使用本地31321、31322端口，可用 `--origin` 选择其他承载同一版本的站点。

```sh
python replay-map.py 321 --output replay-321.json
python replay-map.py 322 --output replay-322.json
```

原始瓦片含2426个矢量建筑构件。第2277个构件有约80.22平方米的正门裁切，检查记录列有其余2425个构件的最大面积变化。完整明细见同目录 verified-321-vector.json。地图原楼、网页模型及射线检查分别保留独立的摘要。
