# 中央储备银行常熟路旧址正门与三跨石阳台

原始和网页近景各有25,652个三角面，远景有16,376个。分别实解网页模型、远景模型，逐面比较三角位置、朝向和材质。三份几何各取207条射线，其中穿过石栏孔、门洞和压顶周围的射线单独记录。五个窗内采样共覆140个三角面。两档模型各有九个实画视角与逐幅观察。[几何射线](preflight/geometry-rays.json) · [独立解码](preflight/surfaces.json) · [窗内采样](preflight/window-samples.json) · [目视记录](preflight/visual-review.json)

在现有城市楼号3343上裁入面向花园的正门凸部。近、远原体分别保留93.00%与93.10%。默认俯视保持原有后楼高度，能在新压顶后看见后楼屋面；从门前花园视高1.65米、距正门11米或14米观察，精模遮住后楼顶线。已有父场景覆盖67个地面和邻房用例，实测保留体量与两种屏宽的射线另有明细。[配准与保留量](placement-checklist.json) · [实测后楼遮挡](retained-roof.json) · [已完成的父场景复核](preflight/early-placement.json)
