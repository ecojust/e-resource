# 延庆路42号住宅扇窗与转角灰饰腰线

Antigng于2018年2月7日拍摄的延庆路42号住宅照片中，街面浅绿拱口内有米色辐形扇窗。灰蓝饰带从扇窗上方延伸至外墙转角；两面的短横纹列在同一高度。
