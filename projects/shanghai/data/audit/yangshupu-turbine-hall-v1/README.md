# 杨树浦电厂汽机房及4号锅炉房的历史立面

上海市第二批优秀历史建筑名录2G001列有“杨树浦路2800号（铁皮车间）”。杨浦区文物资料称汽机房俗称铁皮车间，并将水滤房、开关车间和两处循泵房分别列出。1926年老照片的图题明确记载汽机房与4号锅炉房同框。1935年3月6日从北、东侧拍摄的厂房照片提供了第二个比较角度。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [杨浦区文物资料](https://www.shyp.gov.cn/shypq/shxd-gyyj/20231128/442695.html) · [1926年合影和原图题](https://www.thepaper.cn/newsDetail_forward_17429374) · [1935年档案影像](https://www.virtualshanghai.net/Photos/Images?ID=34894)
