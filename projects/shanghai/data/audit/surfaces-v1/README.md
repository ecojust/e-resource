# 地面与水系第一批验收

本批提供16区独立平面模型；不新增或提升任何建筑的逐栋照片复原状态，也没有替换现有建筑漫游地面与碰撞。

- 16件GLB合计9,900,684字节、410,447个三角面；最大2,303,996字节。
- 16件Blender合计12,192,339字节；最大2,746,828字节。每件保存后实际重新打开，顶点和面索引哈希一致，见 [native.json](native.json)。
- [geometry.json](geometry.json) 检查全部16件真实GLB的有限坐标、零高程、朝向、退化面、三角形并集、源分区差异、水陆重叠；不是仅检查生成器中间数据。
- 数值误差按周长关联的面积预算及半径4厘米侵蚀残差检查，不表示所有边界点位移小于4厘米；全批极窄水陆重叠合计约4.55平方米，最大单区约4.14平方米。源GIS分区与网格合计对称差面积约123,206平方米（主要为长岸线的窄条状坐标归并差异；不是漏建同等面积的一块地）。全部差异在该侵蚀检查下没有显著残留。此模型不能据此声称厘米级现场精度或严格无缝。
- [rebuild.json](rebuild.json) 从冻结water protobuf ZIP重新生成32件GLB/GIS文件，全部与交付文件字节一致。Blender不作确定性字节重建声明。
- `python tests/surface-mesh.test.py` 的5项拓扑回归通过：水中岛、离散水体与窄渠、瓦片接缝、水陆补集、空几何。
- [browser.json](browser.json) 记录9组实际Chromium检查：所有16区真实模型与面数、下载、图层开关、切区释放、迟到请求、全区组合、损坏文件回退与重试、片段重载、手机布局。没有页面异常或HTTP错误。
- [visual-review.json](visual-review.json) 记录主代理实际查看的5张最终网页截图及对应SHA256。

网页运行时新增独立查看器及OrbitControls，主漫游HTML增加入口链接；既有漫游JavaScript保持不变。未重新执行全部既有建筑验收，也未声明新地面已接入第三人称行走。

高程、河床、潮汐、堤岸、铺装、未收录水道和逐栋建筑仍待后续来源补充与建模。来源、许可与重建方法见 [建模说明](../../../source/surfaces/README.md)。
