# 虹桥路2374号花园住宅菱孔山墙与筒瓦

低屋的向阳坡铺凸盖瓦和槽瓦，整列瓦口露在侧檐上。菱形小孔从白色山墙穿入暗处，下方的钢窗向外打开。前后两档均保留透空部位、独立钢横梃和沿坡的瓦脊接缝。
