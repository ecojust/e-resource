# 大成殿外观候选：技术校验

[独立网页](../../../dacheng-hall.html) · [来源与未复原部分](../../../source/precise/chongming-dacheng-hall/README.md) · [交付资产哈希](../../../assets/models/candidates/chongming-dacheng-hall/manifest.json)

此记录核验候选资产的几何一致性和独立网页，不代表通过逐栋照片复原验收。没有地理配准、城市源对象替换或第三人称漫游。

- `rebuild.json`：近景411,500面、远景58,252面的独立源码重建字节一致；构建时检查404个相邻屋面边界样本。
- `geometry.json`：实际Meshopt解码后全部三角坐标与原始模型一致；有限坐标、无退化三角形、无重复索引面，原始和解码文件均小于100,000,000字节。
- `structure-full.json` / `structure-lod.json`：每扇门窗抽查一个格孔，共20个；实际射线穿过格栅间隙后击中内退暗面，另核查7级台阶踏面，以及背面层间饰面3个点各只有一种材质占据表面，避免白墙与木饰面重叠闪烁。不是全部格孔或碰撞系统验证。
- `native.json` / `native-geometry.json`：Blender 4.3.2导入面数未变化、保存重开几何哈希一致；保存文件中的模型三角坐标与原始GLB精确一致，预览舞台排除。
- `browser.json` / `qa-browser.cjs`：实际Chromium检查完整与远景版本、损坏响应时保留旧模型、重试、自动距离切换、三个视向与390×844手机布局；五项模型资源测试另通过。
- `visual-review.json`：实际查看的原生和网页截图、对应SHA256及限制。
- `source-files.json`：冻结来源、构建与验证入口的字节及SHA256。照片登记另记录作者、许可和原始文件。

尺寸来自博物馆文献；墙线、屋面曲线、侧后墙、月台台阶与栏杆含估计。雕像、匾额文字、精确雕刻、室内、相邻建筑和院落地形尚未复原。照片只有正面，不能据此认可隐藏面。现有38处漫游目录及全市建筑完成数量没有因此增加。
