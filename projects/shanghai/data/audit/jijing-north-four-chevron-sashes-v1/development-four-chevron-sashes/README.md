# 高桥季景北路608至612号街屋的四联折线格窗

Fayhoo于2016年2月13日摄下季景北路608至612号街屋。临街赭色立面有几组楼上窗，610号绿牌在左侧方格窗下方；本件选择它右边的四联窗，窗内的斜格成对交替向中间收拢。
