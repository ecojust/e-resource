# 四行储蓄会大楼（联合大楼）

四川中路261号的四行储蓄会大楼是市房管局第二批保护建筑2A049。现存银行楼地块在四川中路、汉口路交叉口西北角。2014年刊出的街角、塔冠与入口细节照片同2019年航拍互相印证。模型有约50米高，保留白石柱座、独立金属格栅、扇形气窗、四层棕砖窗墙、屋顶退台和带四瓣花孔的八角塔冠。标高、背墙与部分屋顶依据照片估计。[照片与登记资料](../../../source/precise/huangpu-four-banks-savings-building/README.md) · [既有125处的几何排重](existing-map-coverage.json)

主地图原近景的六座建筑共用一份模型文件，其中2602对应联合大楼，北侧的东亚大楼1782属于另一组。原始建模的北端与该组立面相交0.264平方米。调整东北端20厘米后，近景和远景模型与东亚大楼的投影均无重合。后备矢量的33米建筑集合包含18个多边形，更换联合大楼只裁其中一处，保留总计30,795.59平方米。东亚大楼和爱建金融大楼原有可见面积都保持一致。[北端修改数据](north-edge-revision.json) · [落位契约](final-placement-contract.json) · [矢量实测](vector-source-checks.json)

正式登记前再与现有129处精细模型比对。具备正式替换轮廓的建筑使用其多边形，较早的40处用全模型边界计算保守外接圆。此前已登记建筑均与此处无交叠。[129处复核](existing-map-coverage-129.json)

可编辑文件的默认镜头从四川中路与汉口路口同时取两面街墙，门脚、上层窗和整座八角塔冠都在画面内。重开Blender后核查64个网格物体的512个边界角点，最小画框留白超过5%。35处独立表面探针分别检验原始、网页和远景三份GLB，130处场景的457项文件已从实际端口逐项核对。[默认取景](native-camera.json) · [表面探针](surface-probes.json) · [HTTP字节](final-snapshot-http.json)


## 主地图实测

130处版本从黄浦区目录点选后，桌面和390×844手机都进入四川中路261号。桌面灯牌遮住门脚右侧一小段，手机将全名放在楼顶上方留白。近看时可辨石门廊、放射形气窗、八角塔的四瓣孔和两面窗墙。页面近景使用47,752个三角面，拉远后使用39,632个。[默认桌面](main-desktop.png) · [默认手机](main-mobile.png) · [拱门和气窗](arched-portal-and-fanlight.png) · [八角塔冠](quatrefoil-octagonal-crown.png) · [四川中路邻楼](sichuan-middle-road-and-retained-east-asia-bank.png) · [全区远景](distant.png)

十个实地碰撞测点全部通过。三个路面点可以通行，五个银行内部或墙体点和两个原生邻楼点保留碰撞。实际近景文件含六个来源建筑，只有2602进入四行储蓄会的裁剪范围。四件下载及原始近、远街区资产的字节与清单一致。[地图与下载实测](main-map-browser.json) · [截图目检](map-visual-review.json) · [185份地图输入与四份登记数据复核](main-map-input-verification.json)

首轮桌面渲染进程内存不足而退出。完整复验用同一场景，在城市详情目录首次超时后重读详情索引，随后真实六栋近景组加载成功。额外保存的原生窗口画面可能跟不上相机切换，塔冠机位的原生窗口图仍显示前一机位。上述六张图均取自最终浏览器视口。[首轮记录](first-browser-attempt.json)

登记前的129处场景仍显示原来带格窗的灰色建筑。照片中的街角原体、五栋同组邻体均未裁切，也没有四行储蓄会灯牌。130处场景只更新四行储蓄会对应的2602。两个版本读取的是同一份原始六栋近景文件，SHA-256 为 `5e119d8b46aa1b3aa39d89193258ea5569f6d87bd455a0d912bc0d7ae8f33421`。[登记前主图](map-before.png) · [前态来源及实测](before-browser.json)
