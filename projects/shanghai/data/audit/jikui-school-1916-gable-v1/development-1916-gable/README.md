# 缉槼中学教学楼山墙1916纪年与百叶通风口

荆州路42号教学楼的2014年照片可见两个带纪年的山墙。这里取左边较近的一端，制作坡檐、嵌于屋脊下方的小百叶通风口、四位纪年及三扇窗的楣部。
