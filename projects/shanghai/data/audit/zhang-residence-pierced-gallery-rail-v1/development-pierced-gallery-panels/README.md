# 三林塘张氏宅二层廊栏的连续红色透花栏板

Fayhoo于2015年4月25日拍摄东林街65弄7号张氏家宅。院照中，二层廊前的深色横栏夹有一列窄长红色透花栏板。本件取其中四格，用成对卷线、纤细竖条和中央的突起花结表现栏内的空隙。
