# 东汉阳路205号花园住宅右翼女儿墙花环垂饰

Fayhoo的2016年2月6日庭院正照显示，花园住宅的左右两翼各有一块屋顶饰面。本件取画面右翼一块，复原向中央下垂的叶花、左端短叶坠、两头的卷带和直凹线边框。
