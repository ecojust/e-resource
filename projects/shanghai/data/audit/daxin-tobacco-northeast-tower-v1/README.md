# 观渡庐东塔的几何与地图核验

从花园一侧看，塔身上层朝向镜头的一面有两道封闭砖拱，转到角部后，窗洞、窗框和后退的玻璃变得正对镜头。两面之间的折线一直延伸到灰色塔帽。俯视时可看出平屋面低于外圈围边。近、远两档均在十个相同的视角下检查，塔脚与顶端在两张全景中均可见。[南侧盲拱](preflight/full-views/blind-brick-panels.jpg) · [角部开窗](preflight/full-views/corner-opening-and-parapet.jpg) · [围边内的屋面](preflight/full-views/six-sided-coping-and-flat-roof.jpg) · [远档花园侧全景](preflight/lod-views/garden-side-blind-arcade.jpg)

短翼的一对窗拱有压低的拱顶，窗格在拱肩附近由横档分开。窗台下的两台空调可辨风扇和侧边通气口。塔身中层窗内还可见一条较浅的窗帘，首层的栅条在窗框前面。近档有21,500个三角形，远档有13,116个，14种材料。源模型的795个部件按名称归入183个可编辑组。[端墙双窗](preflight/full-views/two-segmental-arches.jpg) · [窗券与设备细节](preflight/full-views/radial-brick-arch-and-fan.jpg) · [窗台与栅格](preflight/full-views/yard-grilles-and-plinth.jpg)

原始网格和解码后的近、远档各用118条射线检查。塔身五个外侧面分别检验窗格、窗帘、砖壁和灰围边；东端还核了窗下设备、首层格栅及窗外截断线以外的空处。一处从短翼方向射向塔窗的射线会先碰到短翼砖墙，该遮挡保留在实测记录中。嵌入的砖纹及灰围边纹理逐字比对原图，逐三角形核对贴图坐标。[三档首个交点](preflight/geometry-rays.json) · [纹理与编辑组核验](preflight/surface-textures-and-editable-groups.json)
