# 旧上海市博物馆江湾馆舍：独立检查说明

本轮独审只解码新增馆舍的三个 GLB、只读重开其 Blender 文件，以及增量检查实际所属的原城市场景组。没有重跑历史模型资产矩阵，没有修改原城市资产。

`independent-geometry-review.json` 直接读取索引、顶点、法线、材质和 Meshopt 数据。raw/full 各 96,016 个三角形，LOD 为 48,348 个；每档执行 261 条独立选择的实体与空洞射线。raw/full 的有向 FLOAT32 位置、法线及材质三角多集完全相同。剖面凸包只说明外部体量，不替代空洞射线或真实占地检查。

`independent-native-reopen.json` 记录独立 Blender 只读重开，按材质比对实际原生三角形与 raw，且确认原生文件未修改。`independent-native-visual-review.json` 的八张 PNG 均已逐张实际打开；不是根据作者自检、文件名或缩略接触表推断。

`independent-prototype-recovery.json` 保留 v1 共面重复面、v2 新出现的 0.38 米水平间隙和 v3 的实际回归证据，绑定最终 raw/native/manifest。前两次问题没有被最终通过状态抹去。

`independent-original-city-projection.json` 与 `independent-near-contacts.json` 使用独立直接解码的原始城市三角形。所属 near 组有 8 个 owner、122,780 个实际三角形、5,528 个实例。near 没有逐面 owner 标签；所有几何上可能属于 510/1262 的三角形均保守保留，2,468 个归属有歧义的三角形没有被强制归类。主源约 1.023 平方米接口残条是明确保留的结果。

`independent-placement-review.json` 从三档实际三角形裁切 z=0–2 米，独立复算碰撞范围。只对一个完全位于主源内的闭合室内孔作保守导航填充；采用 0.03 米外扩、0.025 米简化，再从新增余量扣除两处保留源。实际低位面没有遗漏，凹院保持开放。105 个闭合环点、3 条实取道路与 4 个既有精模的保守包络均已核验。

物理源轮廓零交叠不等同原 near 所有装饰零接触。报告分别记录高位檐口投影和可能属于原连接体的低位勒脚接触上界；后者有归属歧义，不能改称仅有高檐重叠。共享接口最终外观还须由独立浏览器会话检查。

北接口的首轮网页近景暴露了高出保留源 1262 的细竖/斜片；当时的有限接受已撤回，截图与观察记录保留在私有修复前归档。最终补充两块仅用于 GPU 的高度裁剪，二维源修正、碰撞和四个模型资产不变。`independent-height-clip-review.json` 汇总完整三角支持、严格 bbox、cross 容差、所有可能邻源保护和真实 Float32 行检查：40 条二维行加 4 条高度行，本馆 44 条，全局 262/288；旧 218 条及修复前全部 258 条均逐字节保持。数值误差界小于 3 毫米几何余量，1262 的高度保护仍超过 5 毫米。该 CPU 证明不宣称认证 GPU 透视插值；最终必须使用新的 `height-fixed-final` 浏览器画面确认两处残片消除和邻源屋盖保留。

源照片只支持西正面、现代两层翼部和门楼等可见外观。所有高度和细部尺寸均为估计；东中后厅只采用简化低体量，510/1262 的身份与年代仍待查。`sh-historic-b2-012` 不作为整项完全完成。详情见独立来源记录及正式来源三份 JSON。

配套检查脚本读取既有冻结输入、独立解码输出和最终文件。大型中间三角数组与原型资产留在私有工作区；公开报告记录其哈希，`independent-city-source-check.mjs` 可从已绑定的原城市文件重新生成。原始城市四文件的 Git 基线与字节证据见 `independent-source-git-bindings.json`。最终目录、README 导航修复例外和真实 QA 图像绑定由后续轻量 metadata / prepublication 报告检查，不能由本说明替代。
