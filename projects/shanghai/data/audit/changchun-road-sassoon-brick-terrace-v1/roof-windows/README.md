# 长春路沙逊楼群北立面的七座屋窗

北立面两端各有两座陡坡三角山花，中间三座矮屋窗向屋坡内退。山花下白色抹面外露，深色木柱承接檐头，两座之间可辨横向木构。正面能数出窗扇，沿街斜照还可看见两道朝向中部的短侧墙窗。专题图用建筑模型从三张公开照片的视角重画。[屋窗三视图](roof-windows-three-views.jpg)

从区文旅照片的左端算起，前三座三角山花保有深色木窗；模型保留照片中推开的窗扇。最右一座使用浅色细框，横向分格较少。三座矮屋窗的格数、宽度和前后位置也各异。2015年照片记录了不同时间的窗况，具体开扇角度和遮挡部分的木作进深均为估计。[虹口区文旅部门公布的长春路照片](https://www.shhk.gov.cn/qyfwy/030002/030002002/030002002005/20230308/10447587-89ab-4422-a788-bf19e49a6f77.html) · [高参88图记中的沿街照片](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102vtah.html)

从第三张街景拟合相机时留出了四座山花尖。模型投影与照片尖点的差依次为7.0、5.4、5.1、2.5像素，图宽796像素。真实网格检查覆盖各扇玻璃、横梃、山花抹面、木柱、侧窗及七处屋顶。最右山花下方的木柱还按区文旅照片的透视方向单独复查，便于和正前方的检测区分。[逐件射线及照片机位检查](three-role-first-hits.json) · [三视图投影及文件校验](roof-windows-three-views.json)
