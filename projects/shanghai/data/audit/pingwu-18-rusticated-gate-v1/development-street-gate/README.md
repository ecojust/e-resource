# 外国弄堂平武路18号院门分段石柱与弧顶铁门

两根石柱自灰色柱脚向上收分。宽窄交替的石带在迎光处形成浅边，在柱面转角留下深色凹线。两扇黑色铁门在中间会合，上部细竖杆随门顶浅弧依次变高，下部为带竖筋的实心门扇。近看还可见左柱的绿牌以及柱顶小块浮饰。柱头细刻受枝叶遮挡，模型保留可辨的外轮廓。
