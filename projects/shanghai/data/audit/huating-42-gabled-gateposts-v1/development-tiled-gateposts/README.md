# 华亭路42号三座瓦顶门柱与铁栏

2018年2月7日Antigng拍摄的华亭路42号住宅街门有三座浅灰框、淡黄心的尖顶门柱，左柱挂绿色42号牌。两段黑铁栏一繁一简，本展取三柱与相接的铁栏。
