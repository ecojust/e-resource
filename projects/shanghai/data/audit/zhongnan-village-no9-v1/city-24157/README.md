# 中南新邨9号木门与气窗的正式城市实图

沿24156原有街景的同一机位打开24157，可以在原有两扇底图窗之间看到新木门和格形气窗。桌面与手机默认画面均能辨认门扇轮廓；深色门扇与原住宅在近景中的阴影较重，9号牌的字形以单体近景核对。远景城市视野实际切换至980面模型，稠密街区中的门牌无法从这一级画面读出。[原街墙](before-lane-detail.png) · [新门近景](after-lane-detail.png) · [斜面接墙](after-oblique-detail.png) · [桌面默认](after-desktop-default.png) · [手机默认](after-mobile-default.png) · [城市远景](after-distant.png)

两阶段分别运行一个实际浏览器。后态先用390×844触屏点选，再在850×650桌面验证默认入口、正斜两种近景及远景。近景网页模型1,580面，远景980面。公开独立页的两种屏幕6幅图和4个实际下载与本轮HTTP输入对应。重新打开的可编辑工程包括17组网格和7种材质，原始GLB及两档解压模型各54条表面射线都通过。[实机前态](city-before.json) · [实机后态](city-after.json) · [单体与正式字节对应](standalone-24157-http.json) · [原生重开和几何](native-release-binding.json)

637号原住宅和同组18栋邻楼保留，原住宅底图两个靠墙探点在前后皆受阻。7个地面测试中，最靠近门扇的外缘点（向巷内1.5厘米）从可通行变为受阻。向巷内5.5厘米、25厘米、60厘米和门侧空地仍可通行。桌面与手机渲染均未出现 WebGL 错误。24156所绑定的1,042份文件共979,727,395字节，24157的1,050份共980,508,916字节，两个全量HTTP收据与实拍快照均已核对。[截图、逐文件签名及两代目录](signed-scenes.json)
