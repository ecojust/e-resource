# 淮海中路1634号花园住宅东入口

从街区目录进入本栋，保持「城市俯瞰」，收起左侧导航，用右键拖动转向院内，再用加号放大。左键拖动可把台阶移到顶部状态条和底部地址卡之间。三张近图的缩放级别均为22.53，截图保留完整操作界面。[街区目录](../../../../landmarks.html) · [本栋城市视图](../../../../index.html#landmark=xuhui-huaihai-road-1634-residence&mode=overview)

石阶连接院面和抬高的入口。斜扶手沿石阶上升，棕色下层门开在石阶右边。接近正面时可逐级看踏面，向侧面旋转可同时看见门槛的高差和廊柱的位置。[楼梯与下层门](session-223/east-door-and-lower-entrance.png) · [近正面石阶](session-223/east-door-and-stone-steps.png) · [斜向扶手和两道门](session-223/east-door-stair-handrail.png)

这三张城市近图各有三个采样点清楚。前两图的顶部状态条覆盖上层门的一部分，第三图的地点光标压住扶手采样点。独立页选择「庭院斜视」可看完整石阶、抬高入口和下层侧门。[独立模型](../../../../huaihai-road-1634-residence.html) · [桌面院内图](../viewer-desktop-courtyard.png) · [手机院内图](../viewer-mobile-courtyard.png)
