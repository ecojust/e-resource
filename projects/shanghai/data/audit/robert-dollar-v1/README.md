## 可见构件

2015年2月的原照从西侧斜望广东路南侧。沿整排数得九道拱。各门拱肩之间的花岗石缝从水平方向折起并向门楣发散，二楼窗下有连续卷草带；上部按层排列成对钢窗。较上层的长阳台由石托座承挑，前后有深色铁栏。粗石高柱在东邻街墙另计。上部实际标高、阳台深度及被车挡住的门扇均按照片比例估计。[远端拱门](east-end-arched-openings.jpg) · [石缝细节](wedge-shaped-stone-joints.jpg) · [长阳台](upper-balcony.jpg) · [摄影署名](photo-credits.md)

原始和网页近景均为63,960三角面，远景为45,774。Blender重新打开34个可编辑网格，与原始GLB逐材质比较定向三角面。三份实际GLB每份独立检查158处开口、钢窗、拱肩石、铁花、阳台与街面。[原生及压缩核查](geometry-native.json) · [实物表面检查](surface-probes.json)

## 地块

官方名录2A032列广东路51、59号。冻结源14-13720-6694/2245与当前OSM w378107108@5均具名大来大楼。临街侧登记边长约46.77米，模型向南截取约9米。城市近景保留59.66%源面投影，远景保留59.70%。沿西侧2418号邻楼共界保留很窄的原墙边带，西端与后缘两个实际切口按冻结城市标高25.60米封口。两种源网格的同组邻楼面积裁入均为零。[几何配准](footprint-review.json) · [地面碰撞与显示范围](final-placement-contract.json)

## 主图实测
