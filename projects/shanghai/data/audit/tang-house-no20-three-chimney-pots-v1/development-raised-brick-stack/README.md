# 唐氏花园住宅20号山墙三孔砖烟囱

Antigng于2018年拍摄的愚园路838弄20号住宅，上层黄褐砖山墙的屋脊处立着矩形烟囱。三只短圆烟管排在同一道叠线浅色压顶上，烟囱两侧山墙的斜向压顶相接于不同高度。
