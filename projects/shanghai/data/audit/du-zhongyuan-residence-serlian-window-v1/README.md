# 杜重远寓所南花园西端帕拉第奥式窗

从淮海中路1897号寓所的南花园看，底层中央敞廊的左手有一组窗。中窗为半圆券，两根圆柱分隔中窗与两侧平顶窄窗。2018年张龙的斜俯照片可辨通长窗台和侧窗，2021年刊出的花园正面照片能辨扇形窗、深色木框和凸出的卷涡券心石。市房屋管理局将这处花园住宅列入第四批名录，编号4D007。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [新民晚报现场报道](https://news.sina.com.cn/o/2018-04-30/doc-ifzvpatr4954367.shtml) · [东方网花园照片](https://m.thepaper.cn/newsDetail_forward_14158238)

本件独立展示西端窗组。按照片比量，中央券净跨约2.22米，两柱中心距约2.47米。树枝遮住部分檐角和券脚，改用相邻可辨边缘时，净跨估算为1.88至2.71米。窗台和柱心相对城市底图的位置仍缺测量依据。[位置审查](preflight/placement-review.json) · [照片比量记录](../../../source/precise/xuhui-du-zhongyuan-residence-serlian-window/measurements/garden-window-photo-scale.json) · [来源与图像权属](../../../source/precise/xuhui-du-zhongyuan-residence-serlian-window/SOURCES-LICENSE.md)

原稿与网页近景各含10,016个三角面，远景含3,768个。三个版本各以83条射线检查窗框、券石、柱身及孔隙。近、远景各保存七张观察图，可比较券心石卷回遮住下部石块的边缘，以及圆柱、窗扇和窗台的形状。[作者验收](preflight/model-review.json) · [逐项几何检查](preflight/geometry-rays.json) · [十四幅图的对照记录](preflight/visual-comparison.json) · [花园正面近景](preflight/full-views/garden-front.jpg) · [券心石远景特写](preflight/lod-views/scroll.jpg)
