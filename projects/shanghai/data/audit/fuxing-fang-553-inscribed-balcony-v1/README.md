# 辣斐坊复兴中路553弄过街楼题名阳台核验

三处2021年街面照片交会确认正板宽约1.69米，中心高约4.5米。题名「復興坊」在2015年照片中为三枚红色繁体字；百叶与正面之间还有约0.8至1.0米的退深。几何覆盖中央过街楼的折面阳台与背后双叶木百叶。近档保留逐块砖面，共5,964面、35个可编辑组。远档以连续的砖面和凹缝表现各砖皮，共4,720面、35组。原始、近、远三档各核197条石、砖、木构、漆字和空隙射线。[正面](preflight/model-front.jpg) · [斜面](preflight/model-oblique.jpg) · [实测记录](preflight/surface-rays.json)
