# 邬达克旧居与第四批优秀历史建筑4M032

番禺路129号的邬达克旧居已在上海全局地图开放漫游。可编辑 Blender 文件、原始 GLB、近景和远景从固定提交重新下载，四份文件共14,300,972字节，各自的 SHA256 与 Git 对象摘要均与发布记录一致。现有近景模型85,101面，远景8,945面，范围为主宅、北侧门廊和附属连接体。[进入邬达克旧居](https://raw.githack.com/ecojust/e-resource/ae55637ce1d7cbc4d21fd94934c8309aca1dcd09/projects/shanghai/index.html#landmark=changning-hudec-residence&mode=walk) · [逐件核验](existing-model-and-register.json)

项目现有地图与纪念馆资料使用番禺路129号。市级第四批名录的4M032写作“邬达克住宅，番禺路135号”。长宁区规划和自然资源局发布的《番愚路127号邬达克住宅》记载邬达克亲自设计、建造并居住于此，约建于1930年。三处门牌按各自原文记录，具体改号时间有待查证。制作队列中的同名条目引用既有城市模型，本次城市模型数量增加0。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [区级史料](https://www.shcn.gov.cn/col7698/20211207/1151481.html)

上海市地方志办公室刊载的《上海名建筑志》附录把“邬达克旧居（名人故居）”列在番禺路129号，年代约1930年，补充印证了现有地图使用的门牌。[地方志原表](https://web.archive.org/web/20160326003528/http://www.shtong.gov.cn/Newsite/node2/node71994/node81772/node81779/node81794/userobject1ai108898.html) · [原文记录](gazetteer-129.json)
