# 中苏友好大厦南广场序馆与中央塔楼

上海市第四批优秀历史建筑登记表4B001列延安中路1000号。本次以地方志所载原中央大厅46米见方的平面，对照南广场正面照片和卫星影像定位今日的序馆。向北接续的原工业馆后称中央大厅。两处旧称与今名分别记录。[市级名录、上海建筑志和实照](../../../source/precise/jingan-sino-soviet-central-foyer/reference-review.json)

广场一侧的主拱带斜向石纹，门窗位于柱后。两侧小亭的金顶之下，中心窄拱与两侧浅柱分开。主塔列柱后的中轴有上下开口，塔冠有鎏金尖塔和红五星。原始和网页近档各129,052面，远档51,424面。三档共399条实物表面射线。钢塔110.4米的文献标高与修缮采访所称114米星顶分开标注。石雕植物纹、栏杆细节和冠层深度按照片估计。[原始摄影配准](../../../source/precise/jingan-sino-soviet-central-foyer/source/photograph-calibration.json) · [三档首交](preflight-surface-checks.json)

城市底模969的近远景与12栋邻屋均经原始文件复读。替换限于方厅占地，台阶与檐石的外挑部分另由模型呈现，后侧接续及东西翼保留。两档原屋面在东西侧和北侧连续，向南广场没有接续。近档旧屋面较名录边线稍向南伸出，裁线朝南留出0.12米，避免沿门前留下旧墙。近、远档各60个三维边缘测点分别核对保留与裁除的屋面，三段截面均位于侧后方。[原网格与接缝](generic-hall-edge-probes.json)
