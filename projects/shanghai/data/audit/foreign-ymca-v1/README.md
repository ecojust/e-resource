# 西侨青年会 · 上海体育大厦临街主楼

在南京西路150号，淡黄色墙面和深褐菱纹环绕三座两层高拱，中央双柱承托拱肩。上部两翼各有三列深窗带，中央退界通向后段。作品依据2004年完整正面、2013年两角度街面、2015年入口近照及2025年现状，采用市地方志详述的九层扩建后外形。左右邻楼和楼后体育场所另有边界。[官方及影像来源](../../../source/precise/huangpu-foreign-ymca/reference-review.json) · [建设范围](../../../source/precise/huangpu-foreign-ymca/README.md)

完整与简化模型分别为105,992面和57,004面。四件模型包含经重开验证的 Blender 工程，共116个可编辑网格。主立面、三道门扇、玻璃雨篷、双层长拱、塔楼与内庭高差均从最终模型读取。三份GLB各检查77个位置，共231次射线。渲染显示首稿塔垛偏细，随后按照片加宽，调整双拱装饰头并增加门廊砖缝、砖垛露头及后屋面接缝。[正式清单](../../../assets/models/candidates/huangpu-foreign-ymca/manifest.json) · [原生重开与等面校验](geometry-native.json) · [三档射线](surface-checks.json) · [首稿](preflight/draft-facade.png) · [最终外观](huangpu-foreign-ymca-preview.png) · [三联高拱与门厅](arcade-and-doors.png) · [塔楼和中庭](tower-and-court.png) · [与照片对照的目视记录](author-visual-review.json)

原底图中的2846号独立楼面沿南京西路长约27.11米，进深约33.30米。原源近远网格均完整收入单一四边裁剪区，保留东邻128号永新广场和西邻170号国际饭店。新模型与已发布国际饭店整体包围范围间隔约7.20米。地面碰撞约888.52平方米，在三道门扇前各留出退进空间。[逐源核验](placement-geometry.json) · [地图落位合同](final-placement-contract.json) · [独立查看器](../../../foreign-ymca.html)

真实101处站点同一视角的原楼为规则方窗的灰色体块。第102处接入后，街面可辨双翼砖垛、中央后退的窗带和菱纹拱廊。开流后近档组内含2846、2365两个来源，两个裁剪三角面只处理2846，国际饭店原有模型的哈希另行复核。5个新站视角和1个旧站视角采用真实 Chromium，分别取得105,992面和57,004面的交付资产。三处门前退界、人行道、墙内及三栋邻楼的8个地面见证均符合预期。手机首屏及近景保留选择灯牌，街面部分拱顶被标签遮住。[真实101原楼](map-before.png) · [桌面](map-desktop.png) · [390像素手机](map-mobile.png) · [近档街面](map-street-facade.png) · [屋顶](map-roof.png) · [远档](map-distant.png) · [逐张目视](map-visual-review.json) · [101对照](control-browser.json) · [102主图与下载](main-browser.json)
