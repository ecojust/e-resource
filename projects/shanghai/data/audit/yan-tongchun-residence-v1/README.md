# 延安中路816号严同春宅东宅街面

严同春是严家的沙船商号。严寿沄在2024年家属访谈中区分了严载如所住的816号东宅和叔父所住的830号西宅，指明1933年建造、设计者林瑞骥、1998年拓路拆除原第一进。市房管局2B025登记为延安中路816号花园住宅。模型以2022年7月23日的沿街原片为据。现街面具体建造时间、被树木挡住的门窗分格及实物尺度仍待查证。[来源及原片](../../../source/precise/jingan-yan-tongchun-residence-street-front/reference-review.json) · [独立查看与下载](../../../yan-tongchun-residence.html)

四根浅色砖柱分隔街面三开间。中央木门下部刻有成对卷饰，上方是玻璃门扇、方格气窗，腰墙上层有铁窗。门前凹廊保留通行空间。原始与网页近景各41,984个三角面，远景17,840个。独立重开的Blender文件含36个网格。每份可下载GLB均经98处射线核对门扇、卷饰、砖缝、气窗与楼上金属窗。[三档表面检查](surface-checks.json) · [原生重开](geometry-native.json) · [四件文件及校验值](../../../assets/models/candidates/jingan-yan-tongchun-residence-street-front/manifest.json)
