# 新场叶氏花行120号院内凹曲山墙与叠瓦压顶

Fayhoo于2015年1月27日上传的新场叶氏花行院照，图说为“叶氏花行（叶瑞生） 洪西街120号”。院内门旁绿牌可读120，后方白墙的脊瓦先升高卷起，再跌落为深凹弧，临院一端压有短小的山尖状线脚。
