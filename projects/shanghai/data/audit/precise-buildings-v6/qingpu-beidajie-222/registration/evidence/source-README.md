# 青浦朱家角北大街 222 号民宅前楼

本模型只复原门牌 222 号对应的两层、三开间临街前楼，采用 2022-07-23 可见的使用状态，以 2016-02-07 照片核对结构。没有加入邻铺 226 号、整排河房或未经确认的后进。

这是独立 `visible-v3` 候选。原 `aaf7f971…` 和 `visible-v2` 的模型及 native 历史均保留。v2 已修正字牌穿墙、上层大绿玻璃窗和瓦片排缝；v3 严格只修改右门玻璃，去除造成拼块感的四块异形实拍反射区域，采用统一的专属玻璃材质。中央草书原图匾保持不变。最终视觉通过仍须新 native 预览核验。

## 重建

```sh
python build_model.py --output output
python validate_model.py
```

依赖 Python 3.12、numpy、Shapely 2.1+、fontTools。发布布局为 `source/precise/{qingpu-beidajie-222,common}/`。`common/photo_architecture.py` 与 `common/sign_lettering.py` 是相邻的便携源码依赖；此处 staging 的 `next/` 层级也可自动找到同一 common。原 JPEG、输入、字体子集随白名单发布，构建不请求网络，也不需要 Blender。

输出为自包含 `output/qingpu-beidajie-222.glb`；原图仅嵌入一次。source 包不重复放 output、优化模型或 native 文件。固定视角渲染、native 文件及运行时注册由 root 统一验收；本次未运行浏览器或 Blender。

## 具体结构

- 保留原始四点轮廓，约 105.21m²、前沿 11.97953m。两层、三跨的分配采用独立相机分析的约 `0.3368 / 0.3446 / 0.3186`，未按透视压缩后的屏幕宽度分楼。
- 三个真实首层洞口及弧形肩部承托，独立二层木柱、后退 1.10m 的墙面、开放廊道、连续回纹木栏杆和实际楼板厚度。栏杆后方的天空不是玻璃贴图。
- 上层左窗按可见的四扇暗木叶、顶部方形木镶板、下部细回纹格制作；中窗采用照片可见的较密暗木格。玻璃只占独立小灯格，框和木板均为实体。栏杆挡住的下部格局、右窗部分格数和小尺寸明确属于有限推定。
- 首层中间为关闭木门；左侧有旋入约 72° 的玻璃门叶并留真实通道，右侧为两叶关闭玻璃门。简化的暗色内衬只遮蔽未知室内，不制作照片中的自贩机或人物。
- 带厚度的灰瓦坡屋面、1,800 片弧形盖瓦、40 段脊瓦、43 根挑椽、前檐 0.42m 投影和白色山墙翘头。后坡采用明确推定的朴素延续，未声称测得全部屋脊。
- 坡面各排瓦片有 15% 长度搭接和低端抬头，实体厚 12mm；相邻排不再共面退化为连续长肋。仅采用三种相近灰瓦色的确定性变化，没有用随机污渍代替搭接几何。
- 回纹栏杆为合并后的实体镂空构件；横带是有厚度框板与简化有机浮雕。双石狮具有台座、蹲踞体块、头、眉目、口、爪和鬃卷；不编造照片未证实的性别象征、背部尾巴或后方雕刻。这些装饰是有据简化，不是雕塑扫描。
- 三盏红灯笼、2022 年可见的左上空调机，以及门牌 222。邻铺招牌和外围消防物品不并入本楼。

## 高度与精度

源轮廓来自 **Overture 的 Zenodo / East Asian Buildings**，版本 `2024-11-01`，不是 OSM 建筑测绘。OSM 只参与门牌和街桥位置核对。原始闭合环逐点保留；脚本仅反向使用朝街边构造外向 Facade，未反转或改写冻结数据。

檐口 `7.54m`、屋面脊线 `9.20m` 是参数化推定：独立 Nikon 单面分析在原前宽条件下支持上廊木柱约 4.3m 的比例，模型采用楼板 3.24m 加上柱段。不同深度平面、遮挡及屋面坡度没有得到实测，**绝不能把这些小数当测量精度**；约 ±1m 仍是合理的解释范围。山墙压顶、瓦厚等会使最终几何略高于屋面脊线，实际边界见 `.geometry.json`。

原城市模型的 `8.579m` 是 100m 栅格 GHSL 均值，只保留为原数据记录，没有作为实测高度或约束强塞入新模型。`PHOTO_PROPORTIONS.md` 明确指出独立相机矩阵的零点是扶手，不是地面，不能将该 H 直接投到整栋模型。

后墙没有照片支持的门窗，采用朴素封闭墙；真实后部开口、宅基地归属、内部房间和 2026 年经营状态均未确认。

## 照片和牌匾

2022 原图为钉钉拍摄，4000×3000，EXIF Orientation 1、Samsung SM-A5160、1.74mm/13mm 等效。v3 右门的两片完整玻璃使用同一专属材质，不再拼贴反射场景照片；中央草书牌匾是模型中唯一的照片映射部件。

`glass-material-estimate.json` 记录两个已经确认无遮挡的小玻璃区域共 8,005 个像素的数值色调采样。原 sRGB 中位数约 `[0.514, 0.510, 0.400]` 转为 glTF 线性颜色约 `[0.227, 0.223, 0.133]`。这只是原照光照条件下的外观估计，**不是玻璃固有反射率测量**。这些小区域仅用于数值颜色统计，没有作为纹理拉伸到整片玻璃；原 JPEG 字节不改。

粗糙度 `0.38`、金属度近似值 `0.06` 是有记录的材质选择。无法可靠判定某些纸标是贴在外层玻璃、位于室内还是倒影，因此不添加这些未经确认的独立贴片；没有为方便贴图而虚构横梃或小窗格。旧照片观察文件保留研究脉络，但不代表当前右门使用照片纹理。

左门主牌采用可读的近似实体字形“上海市鶴龍美術館”，按照照片右向左排列，字体不是草书描摹。中央三大草书未可靠释读，保留原 JPEG 中独立内板面的文字图像，映在有厚度、倾角和卷端的实际牌板上；不猜造文字。所有照片材料使用 `PhotoFacade_` 前缀并附原始像素/EXIF 元数据。

左牌板整体移到前墙外侧，板后面 `d=0.025m`、前面 `0.155m`，字位于 `0.165–0.185m`。高度、文字和顺序未改。前后距离是避免穿墙且符合悬挂方式的明确推定，不能以换一个低视角掩盖实体相交。

玻璃有 20mm 建模厚度，均位于各自窗框厚度范围之内，框前退距 20mm。二层框/玻璃深度为 `[-.08,.01] / [-.03,-.01]`，右门为 `[-.25,-.16] / [-.20,-.18]`，开启左叶为 `[-.04,.05] / [.01,.03]`。这些是明确的装配推定，不是照片量出的槽口尺寸。

2016 年左首层显示关闭的木板，2022 年可见玻璃入口；可能是使用状态或装修差异，照片不能证明某年永久换门。详见 `evidence/visual-era-comparison.json`。

## 核验和许可

`validate_model.py` 检查实际 FLOAT32 实体闭合/正体积/无重复面、GLB 自包含、三角形和法向、玻璃入框、实际导出 UV 与声明采样一致，以及嵌入 JPEG 的逐字节相等性。保留原始实例身份 `macro 14-13701-6700 / localId 502`；同 near 中其他 27 个要素必须保留。

`compare_candidate.py --baseline /path/to/qingpu-beidajie-222-visible-v2 --original /path/to/qingpu-beidajie-222` 在临时目录逐字节复建 v2，再检查所有非右门部件完全一致；可直接核对原 aaf7 的同一组 349 个未改部件仍全部保留。比较涵盖实际顶点、三角形、材质名和 UV，并检查材质值只新增右门专属材质。该工具不写基准源、旧模型或主项目。
