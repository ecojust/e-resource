# 万宜坊韬奋纪念馆53号院门与南立面

53号院门左柱嵌绿色门牌，院墙横排五个金字“韬奋纪念馆”。院内的透明挑篷、二层绿窗和共用老虎窗的西半由街侧延伸到屋面。五字馆名以开源字形近似，窗扇角度和小院进深按照片估计。 [出处与建筑范围](references.md)

这份制作稿的近景网格有10,578个三角面，远景有4,324个。近景保存原始网格，远景来自简化版经过压缩、解码后的实际文件，两件均可由支持GLB的查看器直接打开。[近景 GLB](wanyi-no53-near.glb) · [远景 GLB](wanyi-no53-far.glb)
