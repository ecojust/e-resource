# 街面、铸铁栏与屋顶实测

一号楼北段有两层三跨阳台，十二组木门都开在真实的砖墙洞中。较早的南段图纸和晚期街景呈现出不同阶段的立面。模型展示修缮后南段两层各九扇的窗列和两种屋面。天华鸟瞰中的北端两排各三格红砖墙、绿玻璃挡屏及顶部格架，另以第三个视角核对。[模型投影图](frontage-and-iron.jpg)

159束剖射逐一检查玻璃、木框、玻璃门下板、石窗套、阳台悬挑板、铁轮、砖墙嵌板、透光屏、南段瓦坡和北段平顶。首次检验有一束射到南段第三开间的竖饰。对照2015年两樘窗的边界后，将竖饰移到实墙上并重建了三个网格。

修后正面及2015年街面分别按主观察平面拟合，像点登记的均方根残差约0.32与4.03像素。庭面照片存在进深差，若在木门前先碰上铁栏，逐点文件同时保留门前和廊外的两次首交。三幅图中余下的18个分歧集中在细梃和边缘、首层已经改变的店面以及高位视图中的石框。图28以北端短墙为测量平面，同一张倾斜照片中的屋顶高程另按范围估计。[原图像点与配准](../../../../source/precise/hongkou-gongyi-fang-1297-1311-sichuan-road/measurements/independent-image-probes.json)

近档有472个编辑组、770件闭合实体；远档464组、729件。对各实体焊合同位点后，所有边方向成对，体积为正。两份压缩档均单独解码，逐材质的有向三角面与对应原始网格一致。[编辑几何记录](solid-geometry.json) · [原始网格](raw.json) · [解码近档](decoded-full.json) · [解码远档](decoded-lod.json)
