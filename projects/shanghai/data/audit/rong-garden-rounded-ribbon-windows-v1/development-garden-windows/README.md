# 荣氏花园住宅园面双层圆端带窗

上海市第四批优秀历史建筑名录将荣氏花园住宅列于高安路18弄20号。2015年10月的花园照片中，左翼上下两道钢窗在一侧绕过外墙转角，另一侧以圆弧收口。灰色水泥遮阳板沿直线窗头绕向圆端，朝下逐渐收薄。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Fayhoo 摄，2015年，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Children%27s_Palace_of_Xuhui_District.JPG)

近景有8,464个三角面，远景有3,868个。两档各以38条射线检查钢框、玻璃、实墙中梃、弧形窗套和檐口。四幅模型图显示同一构件的正面、折回面和圆端细节。[近景 GLB](rong-garden-windows-near.glb) · [远景 GLB](rong-garden-windows-far.glb) · [对照记录](model-and-photo-comparison.json)
