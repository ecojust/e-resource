# 大洪村吴家宅19号正门的四块灰饰与层叠门额

市表5W039登记为吴氏民居。Fayhoo于2019年8月18日拍摄的同址街照题为“凌梦周宅 大洪村吴家宅19号”。本件取正门的白色门额，三块下部灰饰排成一列，上方另有一道长灰饰，最下为两端收折的石梁。
