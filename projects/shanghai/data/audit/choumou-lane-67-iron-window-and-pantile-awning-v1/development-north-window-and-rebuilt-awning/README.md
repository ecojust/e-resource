# 绸缪村67号北入口铁花窗与筒瓦雨厦

淮海中路1857弄67号北入口上方，矩形窗洞中嵌尖拱形铁窗。上部两条弯梃朝中央汇拢，拱肩留卷草铁花，下部双扇外有一排侧砖窗台。窗下向外伸出带重叠筒瓦的雨厦。
