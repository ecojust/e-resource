# 盐业大楼北京东路280号门罩与石栏

黄浦区第四批优秀历史建筑4A010。2014年1月27日 Livelikerw 的街照和2013年10月、2017年10月、2020年2月的街景可以互相对照。模型取中央门罩、两座外方墩、两根内圆柱、三处后退的券形门面和罩顶透孔石栏。尺寸由公开街照与原房足印约束。1931年初建五层，后期增至七层，本次制作以街面门罩现貌为依据。邻近北京东路270号中一信托另有独立足印和门牌。[照片来源及识别](../../../source/precise/huangpu-salt-industry-bank-entrance/README.md)

近档和原始几何各12,996个三角面，远档7,260个，29个建模组。用三份真实GLB检验共642条射线，覆盖方墩、圆柱、券门、檐口及透孔石栏。原创花岗石纹理使用128×128像素的可平铺图案，三档各核对798、792、558个带材质顶点的UV坐标。首稿从正面可见梁与后墙间一道0.155米亮缝，经旧照复核后封合。两旁墙面依实测接回原建筑。[三个几何文件实测](preflight/surface-rays.json) · [纹理采样](preflight/texture-coordinates.json) · [第一次修正](preflight/pre-correction.json) · [原建筑交界](preflight/retained-wall-join.json)

原房718近档18,529面、远档28面均保留，270号的1082以及同组其余原房保持原形。门前126个地面探点另加六个原邻楼探点。桌面、手机分别用真实城市相机查看12处构件；初选43°俯角时檐口挡住内圆柱的柱头，现选347°方位、67°俯角。两种屏幕和两档模型均通过，另查包括原房和街对面2676在内的城市近、远两档。[真实原房与地面](preflight/source-registration.json) · [城市相机](preflight/ordinary-camera.json) · [建筑构件视线](preflight/model-camera.json) · [邻屋遮挡](preflight/retained-source-camera.json)
