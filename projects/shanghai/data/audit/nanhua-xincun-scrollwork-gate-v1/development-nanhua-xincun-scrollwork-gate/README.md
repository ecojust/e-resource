# 南华新邨长乐路774弄入口尖矛花铁门

Livelikerw于2016年2月6日从长乐路街侧拍到774弄入口。取靠右侧「南華新邨」题名门墩的黑色铁门上段，重现两格门框、弯顶与透空花铁。
