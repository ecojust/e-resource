# 怡和医院旧址庭院立面可编辑工程

Blender 工程含 460 组可编辑网格、108,284 个三角面、39 种材质和九台相机。独立进程重新打开工程后，逐角点核对三组原创纹理、法线、重复尺度和两盏吊灯的发光参数。两台摄影相机保留2015年庭院远照及2018年门前竖幅的原视场与横滚。另有全部九台相机的原生渲染证据。

右侧石狮抬爪下可辨绣球、球心和放射纹。左狮下方受遮，只依据看得到的外轮廓重建。院向台基位置用照片投影及踏步作估算。
