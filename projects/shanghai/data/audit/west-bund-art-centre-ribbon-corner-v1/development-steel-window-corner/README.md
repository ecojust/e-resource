# 西岸艺术中心转角的两层钢格带窗与屋面采光窗

Fayhoo在2015年3月29日拍摄的龙腾大道2555号西岸艺术中心照片中，浅灰体量一侧的两排钢窗由实墙分成开间，绕过实体转角，另一侧接成两道长窗。屋顶轮廓上方另立窄条绿色采光窗。
