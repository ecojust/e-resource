# 大世界历史主楼与街角塔：集成记录

[全局主图直达](https://raw.githack.com/ecojust/e-resource/master/projects/shanghai/index.html#landmark=huangpu-great-world&mode=overview) · [来源与范围](../../../source/precise/huangpu-great-world/README.md) · [四资产清单](../../../assets/models/candidates/huangpu-great-world/manifest.json)

西藏南路1号大世界有界外观：地图主源1519的沿街U形四层主体、街角塔497及照片可见屋顶亭，按修缮后临街照片细化。高度、隐藏墙面和精细雕饰含估计；中庭现状屋盖未制作，独立2367共舞台／ET聚场及邻楼不并入，不开放室内。

原始与网页档分别为277,756和277,756个三角面，远景档102,124个；四资产共38,553,419字节，含可编辑Blender。模型最高约46.4米，为作者估计。

1917初建、名录1924、1928改扩建及2017复开分别记录；本件参照修缮后外观，尺寸和隐面含估计。2014内院白钢罩照片不作为现状屋盖的证明。 第三方照片仅作观察，不作为贴图或公开资产。实际读文及看图范围见来源目录的[文字记录](../../../source/precise/huangpu-great-world/documentary-review.json)和[照片记录](../../../source/precise/huangpu-great-world/photo-review.json)。

主源1519与街角塔497按各自owner分别替换，2367共舞台／ET聚场及其他邻体独立保留。 最终定位、显示替换和低位碰撞见[足迹核查](footprint-review.json)；其余模型登记与历史资产保留。

全局目录83处、16区，其中黄浦29处；40处保留原有漫游，43件候选使用俯瞰入口。两份README将本楼归入黄浦区，直接链接均指向主index。辅助页提供近景、远景切换与四资产下载。已交付的沿街主楼、街角塔和可见屋顶亭不再重复排队；中庭屋盖现状核查及完整内院补证仍留在完成范围记录及TODO。

本轮增量资产清单和地图合同由[目录检查](catalog-checks.json)记录；此报告仅验证文件与静态登记，不代替原生模型和网页图像审查。最终模型、浏览器及公开发布证据按实际完成情况另行追加。

## 模型与网页验收

[Root复核](root-review.json)实际查看7张来源图、8张原生图和12张浏览器图，并绑定最终四资产、源码与截图。原生文件已实际重开，隔离源码重建逐字节一致；[独立几何](independent-geometry-review.json)、[定位](independent-placement-review.json)及[元数据复核](independent-metadata-review.json)均通过。

[常规浏览器验收](browser.json)完成10个视图、近远景切换、四项下载哈希、83条目录／灯牌、实际鼠标与触摸、目标源与邻楼状态、8个地面探针；[整塔与宽屋顶补图](tower-supplement.json)另有2个主图视角。图像观察见[逐图记录](qa-pixel-review.json)与[独立浏览器复核](independent-browser-visual-review.json)。默认灯牌遮挡部分塔身，补图实际显示完整塔冠；未为截图隐藏灯牌。

显示裁剪容量由288扩至320，本楼新增23行、全局301行；[24项单元检查](clip-unit-checks.json)和[实际GPU边界检查](gpu-capacity.json)覆盖第319／320行、owner隔离、阴影材质和321行拒绝后的状态保持。[旧登记保护检查](preservation-check.json)未发现历史模型与记录被改写。最终碰撞已保守简化为合法256点单Polygon，未放宽通用校验；具体新增面积及邻体净空见足迹报告。
