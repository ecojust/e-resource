# 舟山路394号住宅二层弧形窗罩与六菱格阳台

虹口区舟山路394号住宅的正面二层，四列矩形窗上方留有浅色抹灰弧面，外侧是向前挑出的弧形窗罩。前沿石栏开出六个连续的菱形孔，上下保留矩形透孔。金红卫的正照和斜照均标有门牌；高参88另记院内正面拱窗、底层二柱和鹅卵石贴面。
