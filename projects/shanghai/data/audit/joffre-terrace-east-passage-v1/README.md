# 淮海坊茂名南路总弄题名过街楼

市级登记4C004以淮海中路927弄标示整个淮海坊。茂名南路100号是总弄的东入口。2015年1月Livelikerw在东侧拍到弄名和全幅街墙，2020年2月的四个实景站补足进深与两层窗框。测量受摄影基站绝对位置误差影响，地图另用北房墙角和总弄中心线校准。[官方名单与照片](../../../source/precise/huangpu-joffre-terrace-east-passage/reference-review.json) · [照片量测](preflight/photographic-registration.json) · [足印对照](preflight/source-lane-registration.json)

两档均保留三字题名、题名旁的半圆、两层四窗、南北窗间墙和每侧三道檐下托脚。近档也能看见砖皮分缝、突出的窗台和字上的细笔画。原稿与两个传输模型各验192处，近档4,960面、远档2,696面。临时横幅、架线和晾衣杆仅用于辨认照片，两侧住宅与北弄口另行登记。[正面](preflight/full-east.png) · [题名细部](preflight/full-title.png) · [窗墙](preflight/full-windows.png) · [三档表面交点](preflight/pilot-surface-checks.json)
