# 泰安路74号上海市质量协会门廊与弄侧山花

两樘拱肩门分列绿色74号门牌两侧，西柱悬挂七字竖牌。顶端凸徽与卷叶依据2015年两次街景重建。弄侧前四组宽窗通向第二座山花，之后是双V窗裙。近785个闭合构件、22,628面，远760个、17,136面。沿街面约11.74米宽，侧山花距街角约16.09米，来自不同时期街站的绝对坐标保留2–3米误差。此处独立建模，隔壁76弄院落单独登记。[实照原机位模型图](final/registration/registered-views.jpg) · [三角面与闭体](final/whole/solid-review.json) · [摄影及机构地址](../../../source/precise/changning-taian-74-quality-association/README.md)
