# 泰安路74号的双扇拱门、中央门柱与门罩

街景可分别看到东西两樘拱肩入口，各有双门扇及向拱边展开的扇形上亮。中央方柱悬有绿色74号牌。2020年2月两处站位将檐前中央罩尖定位在约4.68米，门弧顶约3.2米，底层墙向内退约1.2米；两条门洞底边射线的最大距离约0.26米。两期图像分别保留原像点。309个近景构件都具备闭合体积，共6,428面；远档282个、5,048面。悬牌和浮雕继续依2015年门前原照细化。[门廊近档](full-source.glb) · [三幅原机位模型图](../porch-inspection/registered-views.jpg) · [院门像点与交会](../../../../source/precise/changning-taian-74-quality-association/measurements/portico-two-views.json)
