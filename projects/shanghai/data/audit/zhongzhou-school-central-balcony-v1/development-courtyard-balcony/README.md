# 华童公学中州路校舍操场侧中央阳台与钢窗

学校旧网站照片005里，中央阳台打断操场侧的长檐。2017年高处拍摄的全景还可辨认栏杆下的红棕色边缘、两侧钢窗、短瓦坡及后方的高低屋面。[校方旧照片](https://web.archive.org/web/20061230112900im_/http://www.sdfz.sh.cn/sdfzweb/introduce/images/005_b.jpg) · [Legolas1024原照](https://commons.wikimedia.org/wiki/File:%E5%B8%88%E5%A4%A7%E9%99%84%E4%B8%AD%C2%B7%E4%B8%8A%E6%B5%B7%E8%99%B9%E5%8F%A3%C2%B7%E5%85%A8%E6%99%AF.jpg) · [市名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

近景5,688个三角面，远景1,452个。原始近景、压缩后解出的近景与远景各实测63个门窗、栏杆和边缘位置。模型按照照片比例取约8.49米宽的一段上层外墙。[近景GLB](zhongzhou-courtyard-balcony-near.glb) · [远景GLB](zhongzhou-courtyard-balcony-far.glb)
