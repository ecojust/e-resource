# 岳阳路265号东庐三层小挑台与弧端金属栏板

高参88发表的岳阳路265号花园住宅两幅实照中，三层钢窗前单独挑出一座窄阳台，端部圆转。浅色整片金属栏板与楼板之间有一条空隙，上部为细横杆。按这座小挑台制作。
