# 都城饭店转角主楼验收

江西中路180号在圆形路口东北角，西南朝向的正立面向建筑内凹。2013年日间正照和上海发布2022年刊出的整栋夜照展示了同一处三开间门廊、贯通的中轴客房窗、带拱窗的两肩、长券孔塔部和后退的塔冠。街口南边的福州大楼具有相似轮廓，位于另一个城市来源地块。[房管局编号和照片来源](../../../source/precise/huangpu-metropole-hotel/reference-review.json) · [街口示意](street-blocks.png)

正式成品的原始及网页近景均为31,408个三角面，网页远景为20,652面。Blender重开后核到168个可编辑对象、10种材质，按材质逐三角面对照坐标和绕序。独立解码两套压缩几何后，连同原始文件各做52条实体射线，核验各段开窗、两条街侧面、三处后退门、玻璃雨篷、两盏悬灯、三券塔部和四档屋面高度。[四项下载](../../../assets/models/candidates/huangpu-metropole-hotel/manifest.json) · [独立预览](../../../metropole-hotel.html) · [几何与原生工程核验](geometry-native.json) · [156次实体检测](surface-checks.json) · [正式渲染与照片对照](visual-review.json)

冻结源358及相邻八层来源724的地面轮廓相交1.96平方米，两栋处在同一无逐顶点来源ID的近景分组中。核验使用每个三角面的全部三个顶点，并对照五栋建筑的实有屋顶高度。102,792个同组三角面均至少匹配一个来源，最大最近顶点偏差0.103米；134个在共有墙处无法独占归属的低处三角面均纳入邻楼保护。724所有12,872个可能近景面与贯穿全高的裁剪区零面积相交。模型实体和邻楼实际近景间距0.31米。福州大楼1844另有独立来源，金城银行1708保留既有模型。[实名地块与航片](../../../source/precise/huangpu-metropole-hotel/footprint-review.json) · [近远景及地面实测](placement-geometry.json) · [地图合同](final-placement-contract.json)

原都城饭店的粗模通高44.80米，邻楼实测25.60米。交接处保留一段低墙，在其屋顶上方另以高度条件清除原主楼虚高部分，截口封面长约17.17米。街口、三处门廊的门前凹位可步行，实际闭合门扇和营业楼层归入建筑占地。实测13个地面位置均符合合同，城市模型和同组金城银行可见。

111处前态与112处后态均由真实浏览器访问。手机和桌面上能认出都城饭店的退台塔冠，默认桌面侧栏与街坊屋面会遮住部分底层。四档文件下载均与正式清单一致。最终112处目录的默认视角另行实取，地标登记与先前112处版本逐字段相同。附加会话在导航按钮等待时超时，保留了已取的默认视图。 [111处对照](control-browser.json) · [112处地图五视图](main-browser.json) · [最终默认视角](final-default.png) · [单体页与四份实取文件](viewer.json) · [逐帧校验与取景限制](map-visual-review.json)
