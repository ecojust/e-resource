# 亨昌里南过街楼的屋面和临街阁楼窗

愚园路1376弄南过街楼的黄色上墙有四扇朝街窗，平檐在两角转向。2020年2月22日的斜照可以沿着西邻灰楼追到画面更高的另一排窗。在2021年1月11日的东侧街照里，两道檐线有一段重叠。2018年2月10日的摄影记录了黄墙的四扇玻璃，照片左上裁去了部分顶缘。[Antigng 摄影及其 CC BY-SA 4.0 署名](https://commons.wikimedia.org/wiki/File:%E4%BA%A8%E6%98%8C%E9%87%8C%E5%BC%84%E5%8F%A3.jpg)

当代航片中，弄口临街处和靠内排长屋处各有一块蓝灰平盖，中间是赭色屋面。长宁区政府2025年刊出的高位照片还能看到北端平盖的四条边。东侧相接的街屋沿街约29.5米，低位红瓦披之上有九组开口，其中两处玻璃窗凸出墙面。最东端观察到另一道较高的砖山墙，重建范围收在第一段长屋的檐折处。[区政府刊载的街区影像](https://www.shcn.gov.cn/col314/20250805/1295665.html)

屋面构件分成126个可编辑组。近档的307个实体共有3,684个三角面，远档的212个实体共有2,544个三角面。逐实体合并纹理接缝后，两档所有有向边均有反向配对，最小实体的有向体积为0.001675立方米。[逐件检查](source-parts.json)

2022版的原始网格、独立解码近档和远档，以及2018版的原始和独立解码网格，分别验证了同一组固定样本。127条构件射线覆盖四扇顶窗、两侧端窗、九组阁楼窗、两道平盖、低位瓦披、主坡和屋脊。街照片的12个面内点中，10个击中预期材质，两个最东端点位于展示截面之外。19个细边点中15个首先击中檐边或瓦面。沿原相机反投，7个低檐边点与模型高程的平均绝对差约3.2厘米，12个高檐边点约4.7厘米。四期正射的66个样点中，63个先遇瓦面，另3个先遇突出窗体的金属罩。每个报告都保留首次交点及其材质。2016版底图在较低层级识别为2010年7月22日采集；比较同版不同层级后的亮度相关系数为0.953。[原照片点与分期航片边线](../../../../source/precise/changning-hengchang-li-yuyuan-road-gatehouse/measurements/roof-and-upper-gutter-observations.json)
