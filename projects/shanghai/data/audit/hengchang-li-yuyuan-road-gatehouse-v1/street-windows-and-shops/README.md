# 亨昌里弄口与东排商铺的两期实测

2018年2月10日，过街楼塔面有浅色大券、四扇下窗以及第二扇的落帘。到2021年1月，四扇矩窗已移至铭牌上方，楼下店面也换上银灰色饰面、卷闸和分别开合的门扇。2025年区方近照再次拍到窗台与铭牌上缘之间的墙面。两期图使用同一台虚拟相机，画面全部由各期三维模型绘出。[Antigng《亨昌里弄口》](https://commons.wikimedia.org/wiki/File:%E4%BA%A8%E6%98%8C%E9%87%8C%E5%BC%84%E5%8F%A3.jpg) · [长宁区2025年现场报道](https://www.shcn.gov.cn/col314/20250805/1295665.html)

沿街X从西向东。根据2021年街景完整的四个框角与2025年截取的下框和右框，修后塔窗总宽约2.80米，窗洞落在X1.04至3.84米、Z9.05至11.22米。区方近照的独立读数把玻璃下缘定在Z8.84至8.93米，与铭牌顶相差约0.17至0.22米。两张照片间的窗台估计差近0.2米。另有2018年的小青篷向街外挑，经实际出挑表面重投，原像素(724,928)在历史两件模型中均首中篷沿。

每份报告记录整栋三角网第一次实际交点及材质。2018年原件及独立解码档各有49个源点命中。现代原件、解码近档和远档各有61个现期源点命中，其中两张照片所见四扇窗的八条视线均先碰到玻璃。另以原来的三条2018下窗视线重查改造后的建筑，西侧视线先碰灰砖，其余两条先碰铭牌冠部棱线。公开的三个现代报告各保留这三条跨年对照，全数为64条。
