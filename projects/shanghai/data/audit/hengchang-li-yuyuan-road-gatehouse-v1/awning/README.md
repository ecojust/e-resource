# 亨昌里弄口的酒红折篷

2020年2月22日的东侧街照和2021年1月11日从东西两侧拍摄的街照都能辨认酒红色拱篷。区政府2025年刊出的近景还保留了右侧几道弓架汇合处及其下方的垂布尖。该近景裁去了篷冠与另一端。各图的尺寸、原像点、折篷的轮廓误差和构件尺寸均附在测量表内。[三站原像点与拟合](../../../../source/precise/changning-hengchang-li-yuyuan-road-gatehouse/measurements/refurbished-folding-awning.json) · [长宁区政府刊载的街区影像](https://www.shcn.gov.cn/col314/20250805/1295665.html)

四道浅色金属弓沿一对水平铰销转出，后缘另有一道固定弓。十一片布幅顺着弓架展开，前缘各带一片弧形垂布。模型两铰销中心距为5.12米，共同标高11.29米，向街伸出0.34米。后弓从铰轴上升1.70米，前弓上升0.68米。前弓和前缘布面分别伸至距街墙1.70米和1.746米。两档模型逐件闭合；后弓与三层石檐最小净距分别为169、79和44毫米。[三站原创投影图](folding-bows-three-street-views.jpg)

两两组合照片估得的后弓升高为1.64至1.82米。2021年西站、东站和2020年东站的篷顶均方根残差分别为4.37、8.27和10.13原像素，垂布前缘分别为3.49、4.74和9.13像素。图板上的点取自原照，折篷画面来自整栋模型的投影。较高的旧窗不能与低处门牌、矩窗的参照点同时准确重合，因而独立测量采用后两者建立局部尺度。
