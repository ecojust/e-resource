# 恒利银行河南中路天津路转角入口与竖窗立面

河南中路495号和天津路100号位于同一街角。1933年恒利银行迁入，今天的斜角门带有“南京东路幼儿园”门楣，河南中路另见503号酒店入口。2005年的保护牌、2020年4月逐门调查照和2021年1月街景共同确定了三个门的位置。模型的天津路侧有六轴浅色竖窗，河南中路侧有十八轴。两端的棕砖角、斜门、黄铜侧门、可核实的外机和退台均列入制作范围。[来源和历史门牌](../../../source/precise/huangpu-hengli-bank-henan-tianjin-corner/README.md) · [独立页与四件下载](../../../hengli-bank-henan-tianjin-corner.html)

三段街墙在原城足印上分别长15.82、4.36、29.21米。三台2021年街景对低檐的估值为18.06至20.18米，对可见高退台为27.26至29.93米，模型取19.35和29.2米。2015年旧照中的屋顶广告在2020和2021年已消失。室内、后院和屋面未能从街上辨明的部分仍待补查。[各站像素量测](preflight/street-height-measurements.json) · [照片来源、日期与作者](../../../source/precise/huangpu-hengli-bank-henan-tianjin-corner/reference-review.json)

原城编号2272与OpenStreetMap轮廓378107244的面积交并比为98.83%。七栋楼共用98,108个近景三角面。实际落入裁切范围的8,342个三角面，按原足印、分户远景与三顶点平均距离分别归属，三次均属于2272。屋后与909相邻边界的20个三角面存在分户差异，全部位于裁切范围外。三维近景保留原屋面投影的50.76%，远景保留50.91%。9段接面连接保留楼身。矢量底图194200050的51片中，仅第30片扣去291.48平方米。共测46处路面、门扇与保留后身及16栋邻楼。[真实落位与裁切记录](placement-geometry.json) · [逐片矢量复算](initial-vector-comparison.json)
