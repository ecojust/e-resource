# 新亚酒楼 · 上海新亚大酒店

天潼路422号的原新亚酒楼在四川北路口西北角。现状模型包含连续临街长翼、四川北路短翼、弧形入口和竖向「新亞」塔牌。名录与《虹口区志》辨明旅馆及其沿革。现状细部参照2009至2025年的七张现场照片，当前浅石底座和黄铜横招以2025年5月、11月照片为准。[资料、日期及许可](../../../source/precise/hongkou-new-asia-hotel/reference-review.json) · [现状模型查看器](../../../new-asia-hotel.html)

楼体以具名OSM和城市源3209定平面，屋面高度和窗洞尺寸依照片比例估计。后侧共墙之外的123号及马路对面的邮政总局另有独立边界。来源中的历史副楼及旅馆内部保留史料范围。[地图配准与三期屋顶影像](../../../source/precise/hongkou-new-asia-hotel/footprint-review.json)

## 城市源与门槛

近档的同组65,328面含四栋建筑。酒店与后邻共两条边，近档只有组级编号；另行验证了1,536个归属可能有重叠的垂直面。距它们最近的裁切边尚有0.274米，精确编号的远档保留0.350米。窄边在近、远档各保留44.34、44.13平方米。上一版模型有18个面在共墙两端合计越界0.041平方米，现有三档与邻楼的几何和碰撞面积交叠均为零。[原越界记录](preflight/shared-corner-overhang.json) · [修正后全部核验](placement-geometry.json)

实取OSM回退瓦片将整街区合并为22,441.42平方米。地图仅扣酒店处2,448.91平方米，保留其余19,992.51平方米，马路对面的邮政总局没有被扣除。主入口有约7厘米高的门槛，实测三份模型在11厘米至1.85米穿行高度内，所有三角面与门前可行带都相离。越过门扇仍有建筑碰撞。152个独立灰缝投影相距主体最远1.71厘米，步行碰撞采用相连的台基与门扇。[最终落位及碰撞](final-placement-contract.json) · [可复查脚本](verify-placement.py)

真实113处目录增加16个分配给3209的裁切三角面，全市共459个，分到10张宏块纹理，单张最大167个。相邻邮政总局、123及道路用独立见证点核对。[生产运行时报告](runtime-placement.json)

独立页的正面按钮显示「天潼路立面」。桌面和390像素手机实点真实按钮，近远景各留一图，同次请求验证全部四个下载的长度与SHA-256。[桌面近景](viewer-desktop-full.png) · [手机远景](viewer-mobile-lod.png) · [浏览器操作与下载](viewer.json) · [修正前的按钮记录](preflight/front-view-label.json)
