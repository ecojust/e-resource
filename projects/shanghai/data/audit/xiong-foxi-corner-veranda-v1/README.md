# 熊佛西楼院内东南角

华山路630号院内，南长廊向北折成东侧围廊。2014年5月与8月两位摄影者拍到了方柱、斜撑、两层铁栏及水平百叶。东南斜照能辨认转侧的通风孔，树影及车辆下的部分基座以连续段合理估计。未见的内装与主楼其他立面保留在原始场景范围内。[官方名录、照片及测量](../../../source/precise/jingan-xiong-foxi-building-corner-veranda/reference-review.json) · [透视配准](preflight/photographic-registration.json)

近档13,700面、远档3,808面，原稿与两个下载模型各有176条射线复核。圆孔穿过灰色基座，后方另有暗面；两层木柱之间均可看见廊内和墙上窗洞。[近景图](preflight/full-corner.png) · [远档及通风基座](preflight/lod-plinth.png) · [实际三角交点](preflight/pilot-surface-checks.json)

原城的2769号楼对应东南廊。面积约18.72平方米的外角裁切以外，原楼其余约95.3%面积继续显示。同片邻房、院内实验剧院以及道路对面已经制作的美国学校均保留。地面碰撞包括高出铺地约0.86米的廊座；访客可从外侧走道观察转角。[原城切片与邻房](map-replay/original-mesh-witnesses.json) · [宽屏与手机的实际三角视线](actual-camera-city-triangles.json) · [31273真实基底回放](public-31273-map-runtime.json)
