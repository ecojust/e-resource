# 建国西路598号花园住宅临街转角钢窗与赭砖窗垛

2018年2月的街面照片把598号的院门与后方两层转角窗收入同一画面。每层正面钢窗分三跨，上有通长横亮。临街面和短侧面之间的窄窗垛贴赭色砖。徐汇区政协的建筑记录说明，598号原有两栋各自成院的同式住宅。[2018年原照及署名](https://commons.wikimedia.org/wiki/File:建国西路598号住宅.jpg) · [徐汇区政协记录](https://m.thepaper.cn/newsDetail_forward_14319144)

近景模型含3,464个三角面，远景含1,592个。两档均保留上下层三跨钢窗、窄侧窗和折转挑檐。各36条射线核对玻璃、横梃、砖面、窗台及挑檐的实际交点。[近景 GLB](jianguo-598-near.glb) · [远景 GLB](jianguo-598-far.glb) · [检验数据](model-and-photo-comparison.json)
