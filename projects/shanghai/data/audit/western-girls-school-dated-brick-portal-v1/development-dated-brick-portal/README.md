# 工部局西童女子学校双年份砖券门

1893和1894两块凸字年牌并置在门券和带双窗格的山花之间。Fayhoo于2014年9月14日拍摄的庭院照片可读门券红灰砌砖、两侧曲线矮栏和山花的两块卷枝饰板。高参88于2015年刊出的走访记载1893年兴建、次年竣工。[2015年走访](https://blog.sina.com.cn/s/blog_5d1bdf480102vxb0.html)

模型门面按该照片校正透视，门后留出真实通道。[原始照片](https://commons.wikimedia.org/wiki/File:Gonglijihanbilixitongnvxue.JPG) · [市名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [模型与原照](model-and-photo-comparison.json)

近景7,916面，远景4,752面。两档各实测55个位置，其中八个分别落在八枚年份数字上，九条贯穿门洞。门面采用约3.41米的展示宽度。[近景GLB](western-girls-dated-portal-near.glb) · [远景GLB](western-girls-dated-portal-far.glb)
