# 两版查看器的普通网页实测

桌面和手机首屏均能看见门槛、券洞和尖顶。近、远档的特写都能读出门洞上方左右两块浅色题记，左为1893、右为1894，和本件采用的2014年照片相符。

两版查看器分别在1060 × 730的桌面及390 × 844的手机上打开同一份页面。每组记录首屏、近景三个镜位、远景三个镜位，共28张实图。每个桌面版本均实际保存原始、网页、远景和Blender文件并核对文件名、大小和SHA-256。四组均通过一次清单请求失败后的正常重试。[全部镜位对照](comparison-403.jpg) · [逐图、页面响应及下载记录](browser-comparison.json)
