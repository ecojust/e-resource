# 南林师范学校旧址排窗面的山花、石栏和挑台

左山花的叶丛之间能看见一扇带两根竖梃的玻璃窗，右山花的同一高度是一幅石框卷草板，底下另有较矮的横饰带。左右各有两个向下收尖的小石托。两段瓶栏的栏身、栏顶和栏脚分开制作，栏间保留空隙。树枝遮住右端个别瓶栏的中下部，这些位置依据露出的方颈和相邻杆件的间距复原。

挑台檐下的三个竖向支点承接两组木弓。弓间的金属卷纹、垂饰与下方直栏按原照勾出。挑台面自墙向外约0.85米是展示剖面的估计值。图上檐唇和栏杆前缘通过原相机等效27毫米镜头的视线回投。照片缺少标尺，树下栏脚和两端回栏的实际构造仍有不确定性。

从两档可编辑构件各查167个闭体与正体积，再将原片中92处可见部位投到整楼，另用12道剖切射线穿过回栏、挑台板和檐罩。屋冠使用局部立面图的垂直剖视，挑台使用带镜头方向的斜射。
