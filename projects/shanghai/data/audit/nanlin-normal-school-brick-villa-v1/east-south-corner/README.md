# 南林师范学校东南转角

东面临河，可见深色挑台、九处上层门窗及其砖券。向南转角后，连续七个券口面向铺装前庭。两面共用同一东南角和上下砖带，可以检查盲券与南侧第一根廊柱的关系。[两立面合看](southeast-corner.jpg) · [排窗正面](whole-window-wall.jpg) · [券窗细部](upper-sashes.jpg)

这个版本保留两面相接的局部。近档98,380面、1,496个闭合实体，远档56,384面、1,384个闭合实体。四期航片上的长边为28.8至29.8米，短边为21.7至23.0米，这里取29.50米与22.30米。南廊两柱列之间的可见尺度与东窗面的跨层砖带联合估算，层高取4.45米。[近档 GLB](near.glb) · [远档 GLB](far.glb) · [近档几何复核](near-closure.json) · [远档几何复核](far-closure.json)
