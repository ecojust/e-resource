# 原南林师范学校南侧七跨券廊和西南盲券

两张修复后照片分别沿廊斜看和自对侧看全排。七跨之间的八道墩、上层砖券、下层阶形门楣和中央三角门眉在两幅照片中可连续对号。第三张从另一角度拍下荒置时的建筑，西侧紧邻廊端的一堵墙上仍能辨认砖砌盲券、浅色石楔和两处肩托。照片没有注明拍摄日期。渲染图显示恢复后的廊身，荒置照片提供相机及遗存形状。模型图中的灰砖封实拱腹，两层廊口可见后墙与楼板。

## 量测范围

房屋短边由四期航片估为21.7至23.0米。整模采用22.30米，两端墩轴之间约21.55米，七跨的轴距有差别。修复两照分别给出常规柱跨距与层高的比例，折算层高约4.07、4.39米。结合转角处与临河墙在同层延续的砖带，整栋采用4.45米。旧照的水平消失点较远，无法单独确定层高或精细测定盲券前后起伏。砖楔及外挑面采用15至125毫米范围内的估计。

三份成品都实际读取全部三角面，以相同81个南向像点和18个西墙像点分别求第一交。每一份南向74点和西墙16点与最初预记的材料或通廊深度相符。最靠东的红色终柱在初版正面与灰墙仅相隔约一微米，初版像点(515,143)先碰到灰墙。灰墙末端退入后，该点在三份成品均首先碰到红柱，第一交距约13.961米。

## 复核文件

从项目 shanghai 目录运行模型源测量目录中的 check_arcade.py 和 check_west_arcade.py，各传入三个实际GLB和 --output。两份命令的JSON保留每一条射线、原像素、实际材料、击中点及模型摘要。refit_arcade.py --output 可单独从登记像点重算三幅照片的正面单应矩阵。render_arcade.py 输入解压后的近档GLB和输出目录，重建本页的模型图。每个像点均使用同一坐标系，不因材料检查结果而移动。

照片出处、作者信息、拍摄年代边界和实收文件摘要见源测量 arcade-sources.json。公开图板使用原创模型生成，原照片权利归相应权利人。[南林师范学校图册](https://wapbaike.baidu.com/item/%E5%8D%97%E6%9E%97%E5%B8%88%E8%8C%83%E5%AD%A6%E6%A0%A1/16818276)
