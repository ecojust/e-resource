# 南林师范学校可编辑工程

Blender 文件把墙身、南面券廊、门窗、山花与挑台、四翼屋檐和天井分组保存。九台透视相机对应独立展页的九个观察位置。灰砖、红砖和黏土平瓦使用三张原创可平铺纹理，纹理已嵌入文件。
