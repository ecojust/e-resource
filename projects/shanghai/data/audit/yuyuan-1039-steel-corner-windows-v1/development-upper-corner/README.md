# 愚园路1039号住宅转角钢格窗与下槛铁花

2018年2月的街照可见转角两面均有黑色方格窗。靠左的一面在窗下有一排直杆，转角右侧短面的窗套为浅灰色，其下栏心留有四段曲线围成的菱花。
