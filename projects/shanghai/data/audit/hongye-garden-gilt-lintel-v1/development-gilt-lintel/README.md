# 宏业花园1088弄门额与砖柱柱头

从巷外看，四枚金字从右向左排列。斜面可见檐口在两根内柱处加宽，砖柱中央收进，两侧凸出。首稿颗粒偏暗，复稿减小了额心的明暗差并加厚字形，使字与白底更易分辨。
