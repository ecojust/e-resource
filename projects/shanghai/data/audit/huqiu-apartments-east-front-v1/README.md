# 虎丘公寓虎丘路东立面

[独立模型](../../../huqiu-apartments-east-front.html) · [上海地图](../../../index.html#landmark=huangpu-huqiu-apartments-east-front&mode=overview) · [照片、日期与来源](../../../source/precise/huangpu-huqiu-apartments-east-front/reference-review.json)

虎丘路131号原青年协会大楼在1920年9月落成，1924年扩建。虎丘路一面有南北两翼，中央门楼退入街墙。2014年照片可见红砖窗间墙、钢窗与北翼加层，2022年发布的门前照片可辨双柱、金色“虎丘公寓”匾额、木格门和绿色131号门牌。门楼、折面、两翼街窗及浅色檐带均可独立编辑。层高、抹灰装饰进深与柱身断面据照片估计。后部、内院及完整屋顶另列待核范围。

初稿在门楼屋檐和第一层上窗之间露出四处空隙。按2014年原照补好横向砖墙后，又在两端和匾额两侧逐点对照。[初稿几何预览](preflight/before-portal-head-oblique.jpg) · [修正后的几何预览](preflight/after-portal-head-oblique.jpg)
