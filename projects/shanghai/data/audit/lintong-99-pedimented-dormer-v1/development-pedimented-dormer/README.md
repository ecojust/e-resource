# 临潼路99弄住宅三角檐老虎窗与挑篷

上海市第四批优秀历史建筑名录4F030列临潼路25–89号、99弄为住宅。2014年发表的东南角照片与2018年署名街景均拍到两榀并排的老虎窗。展品取2018年照片中较近的一榀，从深色下檐到三角压顶中央的短圆脊尖。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [yiyi01831sh，2014年5月5日发表](https://blog.sina.com.cn/s/blog_55c85ddb0101fvm3.html) · [Livelikerw，2018年2月16日，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Lane_99_Lintong_Rd._Shanghai.jpg)

赭红色封檐板位于浅褐压顶之下，浅色粉刷山墙包住一对浅色直框窗。窗上金属挑篷的前缘有折边，两侧小铁撑抵住篷底。模型的外墙纹理与斑驳漆面为原创；进深、篷撑厚度及绝对尺寸按照片比例估计。
