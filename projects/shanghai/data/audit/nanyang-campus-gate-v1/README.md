# 交通大学徐汇校区老校门

华山路1954号老校门是市房管局第二批名录2D015所列校园建筑中的正门。校方档案记载1898年初建木牌坊，1934年校友捐资，次年改建现存宫门。2010年从华山路看到两面砖墙、朱红柱与四灯悬挂的门道，2015年园内反向街景可辨两翼各一排红框窗。2021年街景拍到门扇全部关闭，模型选择2010年和2015年均可辨认的中央通行状态。[沿革和影像来源](../../../source/precise/xuhui-nanyang-campus-gate/reference-review.json) · [制作范围](../../../source/precise/xuhui-nanyang-campus-gate/README.md)

青绿瓦坡依照片表现出排瓦、四角翘檐、正脊兽吻及四条垂脊。门前两尊石狮各有独立台座，右侧白匾的四字校名分别挤出。屋脊最高约8.91米，饰件、狮像和门扇尺寸均据照片估计。校园侧红框窗、门内横梁、打开的门扇及门扇铜钉也可独立编辑。原始、网页近景各136,652个三角面，远景46,052个，原生文件重新打开核对112个网格。[原生检查](geometry-native.json) · [华山路立面](xuhui-nanyang-campus-gate-preview.png) · [彩梁及竖牌](east-painted-gate.png) · [石狮](stone-guardian.png) · [校园一侧](campus-reverse.png)

三档GLB各通过100项实际表面检查，包括向内、向外共40条贯通视线，以及前后两面的砖墙、墙裙、红框窗、东西屋脊、石狮和字牌。独立模型页用1250像素桌面和390像素手机分别切换了近、远景，原始GLB、网页近景、远景及Blender文件的四项下载均符合清单。[三档300项检测](surface-checks.json) · [独立模型页](../../../nanyang-campus-gate.html) · [手机近景](viewer-mobile-full.png) · [下载和画面](viewer.json)

地图上实名建筑1575来自OSM w173582274@2。原始轮廓约200.58平方米，其20.9米旧高度来自10米栅格内两个样点。地面碰撞保留两间侧房和两尊狮座之间的独立空间，27处地面见证包含中央通线、两侧门扇、狮座边及外侧小径。高处飞檐覆盖的面积与地面占地分别计算。[地块和三期影像](../../../source/precise/xuhui-nanyang-campus-gate/footprint-review.json) · [正式落位](final-placement-contract.json) · [网格与通道](placement-geometry.json)

南邻797的原饰边与旧校门的原饰边部分重叠。七个裁剪三角形覆盖实名建筑的整个原底面，近景保留0.059平方米的旧饰边投影（约0.029%），远景完整移除旧门楼。保留部分只涉及南侧靠街约2.38米的一段，实际相交旧面的顶点最高20.9米。裁剪区域距相邻实际近景至少1.5厘米，新模型距相邻网格约0.32米。同组17,472个近景及56个远景邻楼面保留。[南缘残留测量](southern-edge.json) · [27个步行点](map-case.json)

桌面和手机可从地点目录进入老校门。实际键盘步行穿过门洞、进入校园并退回华山路侧，独立检查覆盖中央通线、两侧狮座和四栋保留邻楼。[162→163处城市实测](final-163-map/README.md)
