# 交通大学徐汇校区老校门城市实测

## 城市地图与步行

正式地图从162处模型的同一位置进入163处新版。旧图中是20.9米高的灰色原门楼体块。新版从地点目录直接打开时，390像素手机和870像素桌面均可看清青绿屋顶、中央开间和两翼红墙。低角度街面图的前景灰色体块遮住两尊狮座下部，屋面图可看见主脊、两坡及校园侧抱厦。远景使用46,052面简模。[旧版原位](map-before.png) · [桌面默认](map-desktop.png) · [手机默认](map-mobile.png) · [临街角度](map-street-facade.png) · [屋顶](map-roof.png) · [远景](map-distant.png)

从华山路侧的普通地图步行入口开始，用键盘走过中央门洞。采样以原门面为纵轴零点，起步-2.72米，门下5.35米，校园内12.99米，再退回街侧-2.72米。77个不同的实际移动帧均处于开放地面，网页近景模型保持可见。校门专属步行按钮遵循该模型原有设定。另测27个通线、侧门、狮座及周边地面点和四处保留邻楼，31处均符合预期。[门内实走](walk-under-gate.png) · [校园一侧](walk-inside-campus.png) · [各次按键、坐标及地面碰撞](walk-browser.json)
