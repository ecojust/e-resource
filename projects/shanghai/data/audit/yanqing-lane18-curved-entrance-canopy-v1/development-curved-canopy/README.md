# 延庆路18弄10号弧托雨篷与圆形端饰

2018年2月7日Antigng的署名照片拍到延庆路18弄10号住宅的入口，灰色平雨篷从门上挑出，两边各有一道曲托。曲线沿下缘从门侧上翻，近端的侧面可辨圆饰。
