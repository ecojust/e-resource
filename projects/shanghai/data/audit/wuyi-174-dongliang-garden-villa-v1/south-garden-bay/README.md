# 武夷路174号南园阳台与店面

2024年10月18日发表的两张照片记录同一座灰石弧形阳台。园门远景能看见正面下层玻璃有一扇打开。近照中下层关合，中央四列落地玻璃向两侧各折三面，最外两面有石横档。阳台上可分辨五段卷花、四段密竖铁花和两翼短返。三个木门各有左右两扇，浅色布篷下仍能辨认两列细格。门扇上头部分被布篷遮住。 [2024年开业图组](https://www.sohu.com/a/817721282_121286085)

从后墙算，圆弧前缘采用2.12米的进深，航片给出的可行范围约1.7至2.5米。阳台面采用2.96米，石厚缘约0.56米。图08里有石面竖向深浅纹，成品采用自主生成的灰色纹理。三道布篷的下摆用近照中央原点(522,192)投算。屋顶滴水沿由两张照片、建筑北侧窗口尺度及航片屋脊控制，模型落在后墙外0.30米、高5.52米。黑雨槽、浅色挑篷和木门分别成件。照片无独立光学标定，屋脊和后部附属的高度随假定进深变化。

三十八个原像点均保留。近照26点残差中位2.62像素，最大4.95像素。远照12点中位5.77像素，最大14.47像素。近照的20条材质射线逐条命中三道布篷、深色木门、卷花、玻璃、窗梃和灰石。远照8条中4条在指定像素命中。其余3道铁栏和1道钢梃最近能直接看见的位置分别相距13.28、5.07、6.46及0.42像素。两档源网和两份解码网结果一致。

全楼首版有3条照片中指向布面的射线先撞瓦面。调校瓦沿和相机以后，3条在四份终网上都首先碰到布面。后墙8束短射检查确认，上层三洞内是木格或玻璃，下层开口穿通。近照三点滴水沿固定像素首先碰到深色檐带。远照两点碰到雨槽，最东一点碰到灰墙，该点保留在四网记录中。

模型图上青圈是原采样点的正确材质首交，红圈保留误差。两张照片均来自同一篇开业报道，照片仅用于测量。图板从本项目GLB绘制。
