# 郭氏花园住宅折坡山墙木阳台

从庭院仰看，红色木栏板前伸，密排的竖槽允许视线穿过。窄栏杆上方露出后墙白窗和深色木构架。阳台底面以一排木梁托住，屋檐下可见深绿色封板。栏板花孔、托梁和斜坡檐口均保留立体厚度。
