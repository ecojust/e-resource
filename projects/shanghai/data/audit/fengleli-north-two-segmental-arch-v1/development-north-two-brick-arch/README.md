# 丰乐里北贰支弄红砖券与浅色券心石

四川北路1999弄丰乐里的一条支弄口，在祥子g的2016年图文中标明“丰乐里北贰”。本件取低弧红砖券及两侧起拱段，正中有浅色凸缘、内面下凹的券心石。
