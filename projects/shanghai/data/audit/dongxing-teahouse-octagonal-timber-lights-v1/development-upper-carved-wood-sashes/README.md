# 庄行东兴楼茶馆书场八角玻璃花窗与透空裙板

庄行东街17号东兴楼茶馆书场位于进入第五批名录的沿街商铺民宅范围内。Dragon在2023年11月24日拍了这座茶馆的临街正面、东兴楼门额和沿南桥塘的一面。本件取临街二层左组窗中央相邻四扇，描出窄木梃、上下两排切角玻璃和下方穿空的木裙板。
