# 东亚大楼四柱门廊及转角立面

四川中路299号的模型覆盖四柱门廊、五道主窗带、两层退台、小方冠和两侧临街首间。街角轮廓以2013年12月19日街照为据，门廊以2019年报道刊出的修缮后近照为据。小方冠顶的33.28米是模型估值。长翼、远端屋面和门后室内留待补证。[模型来源](../../../source/precise/huangpu-bank-of-east-asia-corner/README.md) · [独立模型页](../../../bank-of-east-asia-corner.html)

## 城市底图与地面

模型只占用宏区块 `14-13720-6694` 内建筑1782的街角。用真实近景和远景三角面分别裁切后，原建筑保留的水平投影面积为89.61%和89.67%。裁切范围与附近15栋建筑均无交叠。八个裁切三角形对应街角轮廓，六段断面封住原体与新增街面的接缝。[底图核对](source-cut.json) · [几何验收输入](map-case-geometry.json)

地面有27个门前与墙脚探点，另选原楼内部一个保留点，合计28处。街角近看和顶部取景分别对准模型高9.65米和27.62米；两处只作专门检查，普通地图初始视角另行取证。[地面坐标和取景参数](map-case-geometry.json)

## 四柱和转角窗带的几何复核

三份模型均已导出并独立解码。四根石柱、石框、门后阴影、五道弧窗带、两层退台窗与小冠深槽都参与近侧材质和深度检查，每份186处。近景为30,684个三角面，远景为17,980个。门楣石纹、柱础和门旁宽石面依入口照片复核后做了修订。[四向导出几何图及哈希](preflight/model-review.json) · [558处表面检查](preflight/exported-surface-checks.json) · [灰石纹理坐标](preflight/exported-uv.json)
