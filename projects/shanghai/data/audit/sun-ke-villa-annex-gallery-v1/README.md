# 孙科住宅附楼三券通道与七跨木廊

番禺路60号园内附楼的临院面可见七跨红木栏廊、三道扁券和方形通道。2021年修缮专题的园口指示牌照片还记录了错台檐沟接水斗、穿堂梁和右壁三对圆饰。以两站原照重建正面和通道后，近景有225个闭合构件、7,538个三角形，远景有179个闭合构件、4,002个三角形。49个独立点有48处正中，另有6个据第二张照片定位的圆饰复核。园口的一束玻璃射线打在钢窗梃上。[来源与分期](../../../source/precise/changning-sun-ke-villa-annex-gallery/README.md) · [两个摄影机位的模型](registration/registered-gallery.jpg) · [近景逐点结果](registration/full-source-dual-view.json) · [远景逐点结果](registration/lod-source-dual-view.json)
