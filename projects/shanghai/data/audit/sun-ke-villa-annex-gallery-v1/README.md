# 孙科住宅附楼三券通道与七跨木廊

番禺路60号园内附楼的临院面可见七跨红木栏廊、三道扁券和方形通道。2021年修缮报道的另一张园口照片还能认出檐沟接水斗、穿堂梁和右壁三对圆饰。这里保留两个摄影机位的模型渲染与原像素定位。逐面复算近景225个闭合构件、7,538个三角形，远景179个闭合构件、4,002个三角形，均无重复面。[来源与修缮年代](../../../source/precise/changning-sun-ke-villa-annex-gallery/README.md) · [两站对照](registration/registered-gallery.jpg) · [近景各点实际命中](registration/full-source-dual-view.json) · [远景各点实际命中](registration/lod-source-dual-view.json) · [构件闭合与可重复生成](working-geometry/solid-review.json)

两个机位的49个独立点中有48处正中，另记录六处据照片定位的圆饰。一处钢窗棂与预读的玻璃点有偏差。分期影像的屋面投影会压到原建筑，暂以独立模型呈现附楼；主楼精细模型和西侧原建筑均保留。[园区总图和两期航片测读](../../../source/precise/changning-sun-ke-villa-annex-gallery/measurements/2024-siteplan-and-orthophotos.json)
