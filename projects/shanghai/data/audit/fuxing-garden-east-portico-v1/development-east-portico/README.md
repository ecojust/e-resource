# 复兴中路471–477号花园住宅北栋东门廊与圆窗

两根方柱托起平檐，上层百叶所在的凸墙向西转折，返面留一扇圆窗。左邻窗跨在照片中较宽，模型保留有限的墙面。 [历史照片与出处](references.md)

近景模型有24,038个三角面，远景模型有5,736个。两份下载均为内嵌全部资源的 GLB，可直接在支持 glTF 的查看器中打开。[近景 GLB](fuxing-north-portico-near.glb) · [远景 GLB](fuxing-north-portico-far.glb)
