# 上海邮政总局历史主楼与钟塔：集成记录

本轮制作北苏州路上海邮政总局的有界历史主楼、东南角钟塔和按已见影像估计的中庭弧形网格屋盖。南、东立面采用贯通下三层的巨柱、绿色窗间板与顶层敞廊，北侧区分红砖墙面；钟塔为单正面钟盘、侧向弧鼓、八柱透空亭、铜绿曲线顶及简化的两组三人像。雕像、字牌、屋顶设施与隐蔽构造均为原创几何解释，不是雕塑翻模或完整室内复原。

地方志总高49.5米、旗杆另8.2米作为名义约束，保留百科51.16米异文；各段高度、柱距、院落平面与屋面细部包含作者估计。276号地址、250号文保牌及天潼路395号博物馆入口分别记载来源，不当作三栋建筑。

## 原生图与最小修正的证据边界

修正前 raw `82a935ab11bf0caa912ed8525c3169942124464fed6ea4188881b1f529e4a83e` 的8张广角及细节图保留在 [revision-82a935ab/native.json](revision-82a935ab/native.json) 及同目录截图。Root与独立复核已实际查看这8图，随后发现钟塔两处窄暗面板埋入实体且朝向反转，旧图不能冒充最终资产图。
