# 徐家汇圣母院旧主楼庭院中央山花立面

市房管局第二批名录2D032登记漕溪北路45号。Fayhoo于2016年8月6日拍摄的院景注明后用门牌201号，是这次重建立面的主要依据。2013年和2026年的街侧照片用来辨认建筑。1869年是修会机构沿革中的年份，关于现楼建造时间另有1926年和1929年两种记载。[照片、来源与日期](../../../source/precise/xuhui-zikawei-convent-central-front/reference-review.json)

庭院正面上层可数出四条窗轴，中央山花有拱头窗、两侧方形小窗和顶尖下的窄孔。模型沿左右各收入一开间退进窗墙，底层收入树冠间清晰可见的西侧两开间玻璃廊。树后其余廊间、整段侧翼和附楼仍待资料。绝对尺寸和窗台、灰塑、屋面进深按影像估算。[作者源码](../../../source/precise/xuhui-zikawei-convent-central-front/source/convent_front.py) [单体与四件下载](../../../zikawei-convent-central-front.html)

近景12,252个三角面，远景6,548个，Blender原件重开后有36组可编辑网格。每档模型都核验了58处表面。在西侧的两个窗轴，露台栏杆位于下排窗台前方，正面射线先击中栏杆。[原件与网格验收](geometry-native.json) [三档174处实物检查](surface-checks.json)

城市配准以院侧屋面中段为锚点。仅在第673号旧楼庭院一侧、高约5.48至15.91米处裁入局部模型，近远两套源模型的平面均保留逾93%。原一层墙体在此高度以下保留。30个地面位置核查了闭合玻璃廊、前方庭院和原墙。原来正对山花时右侧窗受第223号邻楼遮挡，从庭院西南侧斜看时，桌面与手机的八个观察点均通过原地块及高度检查。[屋面定位](../../../source/precise/xuhui-zikawei-convent-central-front/roof-location-review.json) [限高裁口及地面](placement-geometry.json) [相机遮挡复核](camera-sightlines.json)

另将两个普通目录视口的观察点逐一投向原近、远城市网格，包含同组七栋。限高裁剪后，选定方向的32条射线在真实源面上均可见，较正面的备选仍受相邻楼体遮挡。[近远实网格射线](source-ray-sightlines.json)

## 正式城市地图复核

在旧城与新城的同一庭院镜位，新增立面紧靠既有灰楼。新城可见红瓦斜屋顶、浅色三角山墙和绿色百叶，隔壁原楼的窗列仍在。西端近照显示玻璃封廊的竖挺与水平分格，另一幅近照可分辨山墙中央小洞口及两侧较小开口。手机目录和图钉均抵达同一庭院立面。桌面地图图钉实点后出现该建筑名称，远景可以读到所在街区。两种屏幕上的独立页均显示近、远模型，山墙、成排百叶与封廊分格在两个档位都能辨认，四种文件逐件实际保存并复核。
