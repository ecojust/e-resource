# 武夷路100号街门与绿色门牌邮箱

2018年2月13日Antigng署名原照中，「100 武夷路」门牌贴在临街红砖洞口右边，下方是同号绿色邮箱，门头有一排竖砖。市表5M017登记武夷路100号住宅，现名为机关事务管理局。本展截取可由门牌确定的街面入口。
