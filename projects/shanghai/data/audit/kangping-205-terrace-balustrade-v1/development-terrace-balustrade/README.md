# 康平路205号花园住宅露台瓶栏与檐托

模型依据徐汇区绿化和市容管理局发布的花园正照和露台仰照制作。两图能相互定位转角方墩、瓶柱、石扶手和檐下阶形托。[区档案原文](https://web.archive.org/web/20160305202631/http://lhsr.xuhui.gov.cn/Article.aspx?ChannelID=0&ClassID=62&ArticleID=310) · [正照](https://web.archive.org/web/20160330055449im_/http://lhsr.xuhui.gov.cn/CMS4xhlhsr/Article/UploadFiles/201106/20110601223951560.jpg) · [仰照](https://web.archive.org/web/20160330060444im_/http://lhsr.xuhui.gov.cn/CMS4xhlhsr/Article/UploadFiles/201106/20110601223952464.jpg)

近景有18,336个三角面，远景有4,992个。两档分别用43条射线核验瓶身、束颈、贯通孔隙、扶手及檐托，最大首交差为0.96毫米。模型在转角两侧截取十一根瓶柱。没有实尺资料的部位按照片比例估算。[近景 GLB](kangping-terrace-near.glb) · [远景 GLB](kangping-terrace-far.glb) · [逐项对照](model-and-photo-comparison.json)
