# 东体育会路老3号花园住宅的红瓦顶与老虎窗

正面屋顶从舒缓的瓦口转为陡坡。单座老虎窗的深色棚檐下有两片玻璃、一根中央木梃和左右两块浅色实板。左扇上方横向的深色块随照明改变，模型按玻璃阴影处理。檐角的卷瓦、逐皮叠口、棚顶、木窗台和两侧颊板均可单独编辑。[三相机模型图](red-tile-roof-and-shed-dormer.jpg)

以庭墙宽8.40米为展示尺度，屋顶专项逐档检查了60个构造点，原始网、解码近网、解码远网各60个均命中。36束穿过窗洞前缘，分别落在两块灰板、左右玻璃与中央梃。另16束落在洞口左右连续瓦面，8束核棚顶和台下倾斜瓦裙。[实网构造射线](physical-opening-and-clay-returns.json)

刘恩惠发表的庭院正面图41中，53处观测有46处的首击与所辨材质相同，包括玻璃与灰板的全部12点。2015年高参88近庭相机为13/22。05巷侧相机与另一巷角共用六条实砖缝、四处窗点重新标定，屋身深度取12.388米。按相同24处像点重测，三档均为12/24。前瓦口偏差约1.5像素，最高脊端偏差约22.6像素。此前单巷侧相机在原始网与解码近网为14/24，解码远网为13/24，脊端约偏18.7像素。逐个变换进深后，图41所标左前脊中段仍不能同时吻合两张2015年实照，坡形保持图41里轮廓最清楚的一段。树遮檐口、窄木框和瓦脊边缘的差异均保留在逐点记录中。屋背照片只支持外缘，中央上部采用瓦面封口。[照片逐像点检查](three-real-meshes-and-three-views.json) · [2020年图41](https://www.thepaper.cn/newsDetail_forward_8327982) · [2015年建筑实照](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102w8ds.html)

图板由实际模型渲染。红瓦表面为程序绘制，0.72米见方的重复单元有四垄三皮。屋面轮廓像点、相机与纹理源码保存在同一建筑的制作目录。
