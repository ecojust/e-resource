# 东体育会路119弄老3号住宅的木扇和螺旋柱

2015年10月6日的三幅外观照片记录了庭院木门的八块凹板、带扇形上亮的底层券窗、二层对开木扇以及四处螺旋石柱。2020年刊图拍到了老3号题牌。2023年网文重用了部分2015年底片。这里将门窗形制限定于能看到的拍摄年代。现有资料无法为每扇门窗单独断代。

每档沿整栋外墙法向测211处，近档209处首先击中指定材料，计入图中可见的前景构件为211处。另用三张原照的40个原位置复核，初判吻合29处。放大原图重读七个细部，其余位置保留原判，近档共36处吻合。各档的实测值及窄木档、框边和暗玻璃间的差异均见摘要。

后三组券口和窗沿可在两张互为反向的照片中比较。后墙上层为藤蔓掩蔽，照片只能证明两扇下窗。巷侧最前窗的窗台被车辆遮住，四扇上窗的窗头有部分用同层关系估计。尺度以庭面8.40个模型单位为基准。所有专题图只渲染原创几何。

两侧朝向相反的镜头都拍到了后角两侧灰缝。借相邻的两扇券窗核对层数后，六道缝与四个窗缘点给出进深约12.4米，条件是庭院面宽取8.40米，估计误差约0.5米。此前单用窗缘的两个解为11.10和13.08米。
