# 上海公共租界工部局历史主楼交付

[主地图直接查看](https://raw.githack.com/ecojust/e-resource/master/projects/shanghai/index.html#landmark=huangpu-shanghai-municipal-council&mode=overview) · [来源与重建](../../../source/precise/huangpu-shanghai-municipal-council/README.md) · [四资产清单](../../../assets/models/candidates/huangpu-shanghai-municipal-council/manifest.json)

本件表现北、东及南翼东段的历史街面外观，含北西短回翼；东北柱廊与圆挑阳台、西北高拱窗与双柱、东南通院拱道分别制作。现状整圈街坊只作部分替换，现代西侧、未核接缝、庭院独立楼及现代屋顶亭台不并入。

## 来源和估计

[文献复核](documentary-review.json)实际读取地方志工部局章节、2024年更新报道与设计方项目页，保留汉口路153／193–223号、1919名录年与1913／1915动工、1924／1922竣工等不同口径。[图像复核](photo-review.json)实看9张照片、3张图纸／图示和1张方案效果图；效果图未当作建成现状，图纸未当作测绘结果。照片与全文不随库分发。

文献50米塔楼属于取消方案。作者四个地上层段为0／4.9／9.75／14.6／19.25米，强檐14.6米，直翼顶缘约19.8米、最高角部20.2米；以照片和设计剖面10米标尺作比例参考，均非实测高度。后退现代亭台约23.5–25米的剖面估读另列而不建入本历史主体。原范围4832平方米与现状地图尺度不同，未强行缩放；设计方四分之三和新闻三分之二建成比例不用于反推接缝位置。

v1审查发现东南地面拱未贯通院墙且含玻璃，底层街窗还需弧顶；v2补为真正通院开口、完整拱窗和较清楚的跨层柱式，保留全部过程图。东南通道双向穿透、拱肩实体与拱上玻璃各自核验；简化的通道侧壁、顶板及地面为估计，不等同于已开放室内漫游。[独立几何检查](independent-geometry.json)另行解码三档，各34项射线通过，RAW／网页严格Float32有向位置和材质摘要一致。

## 主图范围和保留源

[定位合同](footprint-review.json)绑定原源`building / 86e8b002-5e0e-4912-9807-086c2afeb27c`，宏块`14-13720-6694`、localId1554。现状源是现代更新后完整围合，历史模型按当前街界、正确时点OSM拓扑、设计方平面与旧新照片共同划分，不能用旧拓扑配被挪动后的新节点，也不能将旧新图的差集直接定性为拆建。

作者切面为局部y≥36或x≥−18所组成的历史子域，约5056.082平方米；切面为近似接缝，端墙仅作朴素模型封闭。保留原源2158.607099平方米、实际近景投影约2174.135164平方米，其中两条3米宽未核接缝带约120.341平方米可能仍含老墙，不能把整片保留体都认定为现代。四处保留屋顶均另用原far／near真实三角面射线核验；原粗略19.2米屋顶不作为真实建筑测高。

原近景屋檐边界需0.13米有界外扩，只在历史子域内裁剪。替换轮廓26点、24个三角，总预算137；未扩大现代侧裁剪。模型投影约5271.289362平方米；与66个80米邻域源、自组及6个外部近景组（共7组）、保留余体及3个庭院空区均按数值精度核验。保留接缝不因檐口或基座外挑被占用。碰撞轮廓作完整包容的保守简化，闭合64点，保持C形院落，位于实际投影外0.55米内，不用填满庭院的凸包。

源东南粗折线与照片引导的凹曲面有局部小差别：显示裁剪边界密采最远约0.901米，完整裁剪包含于实际投影外1米圆缓冲；超0.55米的约2.065平方米已单独定位。这个局部凹角解释不作为放宽其他楼栋精度的通用容差。

## 网页取证过程

单实例Chromium实际验证了完整／远景模型、辅助手机页、主图默认桌面与手机图及庭院范围图。主图初始适合窗口镜头低于near启用的17.3级，随后补拍17.5级近景庭院图：原1554组的24项裁剪与1754独立组的零裁剪在同一实际可见场景中核实，原源HTTP字节与哈希逐件对应。图中四处西侧保留屋面、1754／211大楼及院内小体均可见；部分南院探针被名称牌盖住，该点不作可见像素证据，三处空院另有实际几何负控。

过程保留三项修正：预检先误将完整placement字段当作精简catalog字段，按实际schema改正；HTTP服务退出后恢复并加启动前实字节健康检查；初始镜头取证不足时保留六图并追加近景图。后续320尺寸检查遇到单帧60秒超时，实际采样显示页面可见、各尺寸相同、GL未丢失且队列为零，render持续推进；暂停并发Blender渲染后按真实render事件继续，仅补剩余灯牌阶段。等待采用统一总预算及进度记录，仍要求至少三帧、连续两次相同布局和加载队列为零。失败报告、检查脚本及恢复说明均保留在本目录。

最终[浏览器报告](browser.json)已完成且Chrome关闭；[根代理实际看图记录](browser-visual-review.json)绑定全部9张图。320×568下76个灯牌独立命中，最坏标题净区另用实际320×548画面检查：22×18像素、12像素字号、零重叠／零回退；普通窄屏为22×20像素。原生触屏从峻岭公寓跳转到工部局，地址hash、名称、中心位置和目标资产可见性均改变。WebGL2实际支持8192纹理尺寸；192行裁剪纹理已真实编译渲染，完整／远景／手机／近景后GL错误为0且上下文有效；控制台、警告及HTTP错误列表均为空。全部9图、失败过程和恢复链分别保留，全部冻结输入通过末尾哈希复核。
