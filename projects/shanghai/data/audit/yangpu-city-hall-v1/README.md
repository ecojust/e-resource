# 杨浦绿瓦大楼主楼与独立阶桥

[全局主图直达](https://raw.githack.com/ecojust/e-resource/master/projects/shanghai/index.html#landmark=yangpu-former-shanghai-city-hall&mode=overview) · [来源与重建](../../../source/precise/yangpu-former-shanghai-city-hall/README.md) · [四资产清单](../../../assets/models/candidates/yangpu-former-shanghai-city-hall/manifest.json)

本件为清源环路650号旧上海特别市政府大楼（上海体育大学内），与黄浦公共租界工部局“老市府”分开。制作主楼三段歇山顶、红柱格窗、浅色端部和基座、侧拱门阳台、北面低入口及南侧独立阶桥；校园其他楼栋、地下与室内不并入，当前提供全局俯瞰。

## 来源与估计范围

[文字审查](documentary-review.json)实际阅读4份资料，[图像审查](photo-review.json)实际查看11张照片，包括2018年立面转载、2019年4月施工报道和2019年10月完成状态高位图。施工时的灰基层、脚手架和瓦堆不进入完成模型；参考照片、整篇文章均只作私人研究，不作为贴图或随库分发。

文献93米长与冻结主图源约96.31米不同，25／20米按与平面相容的中部／翼部进深解释，未相加成65米正面宽。原文8982平方米总面积与百科8928平方米占地口径未解决；1930／1931开工、1933竣工、1934迁入和名录1935年分别保留。地图22米来自CNBH栅格，不能作为实测屋脊高。

中央屋脊26.7米、翼脊23.2米、最高脊饰约28.36米、南平台4.3米和桥宽10.4米均为作者估计。北门门槛、被树遮挡的侧面与隐蔽构造采用有界概括，未将南面门厅镜像到北面。桥与主门按正面及高位照片对中；OSM步行线轴偏约4.1米，未当作精测桥轴。

## 主楼替换与桥下道路

[正式定位合同](footprint-review.json)识别源`building / 3904106e-f668-46d4-a302-a13ccd00866a`、localId525、宏块`14-13722-6690`，主源面积约2446.765平方米。原near组含7个独立owner；只对525裁剪，其余6个保持独立。主源外扩0.12米覆盖旧外檐，外加约29.778平方米；主源、实际far和near在替换区的残留为零，未扩大到南桥、道路或其他校园楼。

[范围示意](source-and-ground-collision-plan.png)将主源替换、架空桥面和地面碰撞分别展示。完整桥面投影不能直接用作二维地面阻挡，因此先将真实三角精确裁到z=0–2米并投影，再仅在原主源525内部补约173.190平方米保守室内阻挡；最终经有界外扩与简化形成两个闭合外环，分别58／25点，无内环。主楼未开放内部通行，外部道路和桥面不采用该室内填充。

三档低位实体均被碰撞覆盖，桥下全X方向道路及±0.38米肩线无阻挡；2323个外部源与同near组6个真实邻体均无误裁／误碰。[独立定位复核](independent-placement-review.json)再次验证上述范围。初稿内部孔超顶点限制、极小metadata孔转换为WGS后退化的问题已修正；清理的4个退化孔总面积约5.68e-29平方米，只是浮点精度碎片，不改变模型、显示裁剪或最终道路碰撞。

源映射在旧基线实际读取，交付基线`c5eadbea297bb9d23d0658b2244d1e17034bbcb6`逐一确认这些源Git blob未变。桥下几何与地面碰撞测试不等于已经开放桥面、楼梯或室内漫游。
