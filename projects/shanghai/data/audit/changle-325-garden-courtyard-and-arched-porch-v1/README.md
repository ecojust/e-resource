# 长乐路325号院内弧窗、立杆与红瓦券廊

院内窗前立杆与带斜肩的多面石座根据Fayhoo的2015年4月原照制作。原照顶部裁去杆尖，2015年4月、12月和2020年2月的街景给出三次顶点高度估计。石座顶面约高出脚面0.60米。弯管从窗上方圆孔伸出，经过弯折后伸向挑檐。原照中穿口、套节、管线和被杆挡住的间隙共20点，两档模型全部首先命中对应实物；杆身、石座、绑绳另16点也全部正中。[院内原照](https://commons.wikimedia.org/wiki/Special:Redirect/page/39388838) · [近景逐点实测](working-geometry/full-conduit-and-pole.json) · [远景逐点实测](working-geometry/lod-conduit-and-pole.json)

杆身深度的街景自由拟合值与窗前遮挡约束相差0.35米。模型保留院内照片中遮住挑檐的先后关系，四街景的水平残差约0.3–21像素。2013年树叶遮住顶端，另外三个机位给出的顶端高差为0.31米。[各站像素与拟合值](working-geometry/pole-registration.json)

近景有632个闭合构件和48,324个三角形，远景有630个闭合构件和25,752个三角形。十级石阶、两侧碟形与球形石饰、十六个完整圆瓦面以及两扇玻璃门均保留独立复核数据。[石阶与栏杆](working-geometry/full-stone.json) · [陶瓦及遮挡](working-geometry/full-tiles.json) · [玻璃门及五金](working-geometry/full-doors.json) · [弧窗四街景及院内照片](working-geometry/full-wing.json)
