# 总弄口的地图位置与通行

2021年2月22日的新闸路街景从三个位置拍到两根黑色铁柱。沿新闸路北沿，从保护范围西南角向东39.24米，再向弄内0.86米，是采用的门心。三站测得柱轴距4.03米，另一组读图为3.93米，模型取3.94米。两种街景坐标换算的结果在同一拍摄站相差约1.5米，因此保留约1至2米的绝对定位误差。[像点、方位与公开瓦片](../../../source/precise/jingan-qinyuan-lane-entrance/measurements/entrance-registration.json)

西侧原城住宅100和东侧住宅724分列弄口两边。原图三维近景组六栋展开88,134个三角面，远景72个，距门体最近分别为2.09与2.16米。回退地图的1,875个建筑轮廓中，最近一个距门体43.73米。落位只增加铁门和西侧三牌墙，原房与街面保留。[原网与地面测量](placement-geometry.json) · [回退地图原图块](fallback-buildings.json)

碰撞范围由原始、近景、远景三个网格在地面以上6.0、9.0和10.2厘米处切片取得。西墙、两柱柱脚和斜开的东扇在地面形成两片联合范围。77个点核过门柱、墙边、铁扇两侧与街口到北面院路。此次验证的连续通道宽1.57米、长10.4米。2.70米在墙端处起拱，双层主拱中央上缘约4.19米，模型最高处包括上方铁花。[落位与碰撞](final-placement-contract.json)

普通目录相机沿街向内，方位−15.12度、俯仰37度。按两个实际视口复算，桌面与手机可看到柱身、悬木匾、东门扇和西侧三牌；三档网格的60次首个可见三角面检查均命中对应材质。较高的俯仰角会让手机目线穿过街对面的1784号底图建筑。[两端可视性](overview-sightlines.json) · [近远材质命中](model-sightlines.json)
