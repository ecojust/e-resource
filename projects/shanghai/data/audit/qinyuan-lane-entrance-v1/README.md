# 沁园邨总弄口核验

西墙的绿色弄号、花框纪念牌和上拱的三枚红字在街侧可辨。椭圆木牌挂在前后拱之间，东门扇向院内斜开。模型按2021至2022年照片中的通透铁柱制作。2015年街景中的实心柱和2023年修缮立项分别保留为历史证据。[照片与门牌核对](../../../source/precise/jingan-qinyuan-lane-entrance/reference-review.json)

原始网格和近景网格均为63,384个三角面，远景为34,244个。近景有685个零件，按186个可编辑组组织。两张原创纹理分别配给木牌和西墙水泥面。三档分别实测115条射线，其中31条验证门洞、柱格或打开的门扇之间的空隙。西墙下方的横向窄带与西柱外缘相接。[近景](preflight/full-views/xinzha-street-entrance.jpg) · [两道弧形铁框](preflight/full-views/wooden-sign-and-scrolls.jpg) · [三块铭牌](preflight/full-views/three-street-plaques.jpg) · [原始及两档网格检查](preflight/geometry-rays.json)

原城两侧的街屋相互独立，近景88,134面和远景72面完整保留。对77处地面样点作了区分，能从人行道走过门洞并沿北侧弄道继续10.4米，核对的连续净宽为1.57米。桌面及手机的目录视角都能看到牌面、铁拱和通道。[配准图形与测点](placement-geometry.json) · [原城视线](overview-sightlines.json) · [交付前检查](placement-checklist.json)

现场实测采用项目规定的制作顺序。原生文件二次打开、独立页面四件下载、逐栋主图检查和公开提交的结果，随对应阶段留档。
