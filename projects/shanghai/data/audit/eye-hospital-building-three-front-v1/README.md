# 市眼科医院3号楼西南弧窗与山墙

[制作资料](../../../source/precise/jingan-eye-hospital-building-three-front/README.md)记录院内3号楼的辨识与2014年两次拍摄。城内建筑712沿停车院的一端是本次精细化范围。建筑底部6.48米的墙段决定落位，檐口两端各再挑出约8.5厘米。两层弧窗和三层石扶栏采用不同曲率，保留了向院地挑出的石窗台、窗框凹口、栏杆之间的空隙和接入原城墙体的两段剖面。[落位说明](placement-notes.md)

| 本地核验 | 实测结果 |
|---|---|
| 几何和纹理 | 原始与网页近档各25,226面，远档9,660面。两层窗和上层门扇共48个玻璃三角面具有真实UV，每种玻璃只读归属自己的照片色样。[纹理与UV](preflight/glazing-uv.json) |
| 开口和材料 | 对三种文件各投射141条检查线，含12处花瓶栏杆间隙和6处山墙上方天空。其余检查覆盖木窗、窗间石柱、门牌、保护牌和山墙。[逐条首击](preflight/mesh-rays.json) |
| 近远外观 | 每档按8个院地、侧向和高处机位渲染，检查整栋比例、楼号、玻璃明暗、栏杆、屋面与墙面交接。[逐图观察](preflight/visual-review.json) |
| 地图 | 38个地面点和12栋邻楼经检查。78条射线检验精细构件，156条检查原城网格与其遮挡。将原城712细分后，近远档两段封面的位置差为7厘米。[落位检查](placement-checklist.json) |

原始楼冠及远档轮廓可在[几何核查程序](verify-export.py)中复算。[照片取样校验](verify-finishes.py)核对每档嵌入的PNG和索引UV坐标。编辑版的六个相机分别用于院面全景、楼号、第二层弧窗、曲栏阳台、山墙和屋面回接。
