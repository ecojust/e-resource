# 王伯群住宅南花园双层弧廊

这处弧廊位于长宁区愚园路1136弄31号长宁区少年宫的主楼南面，1934年落成。模型可从花园方向比较三道下层敞拱、中央较宽的五扇上窗，并可绕到侧面检查双向下行的花园梯。
