# 源源长银行江西中路473号圆徽砖立面

该楼在上海市第四批优秀历史建筑名单的编号为4A004。市房管名单登记原名源源长银行/东方企业公司，现用住宅。现场保护牌记载“约1930年代建”。2020年2月与2021年1月的两条公共街景路线均能辨认通高壁柱、横翼圆徽和北端大窗。东面门牌、建筑照片是本次范围依据。[原始资料、日期及图权](../../../source/precise/huangpu-yuanyuanchang-bank-jiangxi-front/README.md) · [独立页与四件下载](../../../yuanyuanchang-bank-jiangxi-front.html)

源地2729东面宽19.05米，原网格高6.4米。新作的墙面最高14.17米，摄影位置与原城足印的平面配准误差约2至3米。只切临街一段，原生近景保留原房面积的97.43%，远景保留97.65%。门前三层台阶可接近至关闭的绿色双扇门。沿两端巷道、墙后原体及门口实测32个地面点和18个邻房，原城屋面切口由1个截面封闭。[原城近远与地面](placement-geometry.json) · [街景像素与测高](../../../source/precise/huangpu-yuanyuanchang-bank-jiangxi-front/street-photometry.json)

近景4,848个三角面，远景3,068个。Blender重开44个可编辑网格，嵌入一张1024像素的原创棕砖纹理。原始、近景和远景各109条首交射线核验凹槽、门窗、圆徽和半圆墙冠。独立页的手机触屏、桌面鼠标实拍六帧和四件实际点击下载均完成。[真实原生重开](geometry-native.json) · [三档表面射线](surface-checks.json) · [棕砖与UV](brick-texture-checks.json) · [实拍与下载](viewer.json) · [进程退出](native-and-viewer-exits.json)
