# 五原路289弄两栋住宅首版

五原路289弄西侧为两栋联立式花园住宅。具名门牌照片可辨北栋1–2号和南栋3–4号。此版已区分两个进深不同的木构山花，并制作红砖外梯的下段、转角平台、上段和两侧弧形砖砌回墙。1号牌在拱门右侧，3号牌在另一栋拱门左侧。外梯上层入口、烟囱与花园侧的敞廊按1935年建筑师相册和后来实景估读。两栋的米制尺度和北侧弄口仍在结合图像细化。
