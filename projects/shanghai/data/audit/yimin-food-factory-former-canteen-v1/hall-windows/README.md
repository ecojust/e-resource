# 益民食品一厂旧食堂展馆的门窗

[专题板](registered-window-study.jpg) 左上使用 Coolmanjackey 于2013年7月30日拍摄的西北端墙局部，裁切范围与像素尺寸载于[图版记录](registered-window-study.json)。照片局部及本图版按 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 提供。[原照与署名](https://commons.wikimedia.org/wiki/File:%E4%B8%8A%E6%B5%B7%E7%9B%8A%E6%98%8E%E9%A3%9F%E5%93%81%E4%B8%80%E5%8E%82%E5%8E%86%E5%8F%B2%E5%B1%95%E7%A4%BA%E9%A6%86.jpg)

其余画面由本项目几何渲染。西北端与东南端各有四开间，临河面和沿街面各有十四开间。中间的宽玻璃门和沿街两樘实木门据不同照片建模。每樘实木门有两扇，每扇有三个凸芯板，门扇中缝两边各设拉手。

[成品校核](window-review.json) 记录三档模型各1,080个几何样点和独立的51个原照测点。首轮整网中，临水第11轴两层的6个几何样点曾先碰到落水管。最终三档的1,080个几何样点均先碰到预期窗门构件。临河照片原像素 (439,348) 靠近第3轴窗框，影像判作玻璃反光，三档模型最先碰到木梃。此处保留两种读数。三份逐点结果见 [原网](whole-raw.json.gz)、[解码近景](whole-near.json.gz) 和[解码远景](whole-far.json.gz)。
