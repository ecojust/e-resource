# 陕西南路222弄20号院门

2016年两张照片中，20号门牌、双门环、暗色长方形横额和三段有退进的卵形浮雕，可彼此对应。模型的正面尺寸使用估计的门牌宽高作为尺度。门扇内退取0.12米，檐口和柱头的前挑分别估为0.32米与0.24米。两台相机的视点很近，进深较难直接量出。摄影原件在高参88的文章中查看。此目录中的图像均为原创模型渲染和数值标记。[作者原文](https://blog.sina.com.cn/s/blog_5d1bdf480102whoy.html) · [两幅照片机位的测点](2016-gate-controls.jpg)

近景148个闭合构件、25,858个三角面，远景148个闭合构件、12,314个三角面。Blender重新打开后含85组可编辑网格、20种材质和九台相机。门扇、灰柱、浅色围墙各有独立程序生成的色图与法线图。2018年的弄口照片可帮助辨认公共弄堂，20号院门的复原依据为2016年的两幅近照。[檐口](2016-cornice-model.jpg) · [双兽面环及门铃](2016-hardware-model.jpg)

原始近景、网页近景解码和远景解码各自的46束卵饰照片射线均首先击中对应浮雕；另18个檐边控制有16个首先击中檐体。27个五金和门牌测点均命中，穿过左右两个环孔的光线均到达门扇。照片06的卵饰中心偏差中位数9.51像素，照片07为1.47像素，原图宽度均为690像素。[门牌](2016-number-model.jpg) · [检验源码](../../../../source/precise/xuhui-shaanxi-222-no20-residence-gate/measurements/check_gate_frieze.py)
