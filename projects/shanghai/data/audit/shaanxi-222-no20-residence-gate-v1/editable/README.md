# 陕西南路222弄20号住宅院门可编辑工程

本工程以米为单位，含 85 组可分别编辑的部件、25,858 个三角面和 9 台透视相机。工程使用 20 种建筑材质，其中 3 种使用内嵌的原创颜色图，3 种另有切线空间法线图。

Blender 保存工程并退出后，另一进程重新打开文件，与本次原始 GLB 核对各材质的有向三角面、线性颜色、金属度、粗糙度、贴图文件和逐角 UV。重新打开后也核对了法线节点的非颜色空间、贴图坐标、强度和通往主着色器的连线。近景模型与远景模型分别重新解码，核对了 1,728 和 1,152 个贴图角点。原始网格、网页近景、网页远景及可编辑工程的 SHA-256 见 [four-role-manifest.json](four-role-manifest.json)。
