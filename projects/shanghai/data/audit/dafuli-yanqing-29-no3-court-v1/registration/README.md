# 大福里3号临弄院门和露台

2016年照片可辨3号院门前柱、绿色地址牌、后方的铁栏露台及上下两处绿框开口。另一个年份的街道摄影确认了门柱和阳台的前后位置。模型用两面独立的弯铁及蓝衬板恢复2016年可见的样式。几何到内院的可见剖段截止，相邻4号、弄口总门及20余户的整组屋面另计。[2016年原照与模型](2016-court-comparison.jpg) · [原片题名及许可](https://commons.wikimedia.org/wiki/File:Dafu_Li_Shanghai.JPG)

原始近景含325件封闭构件、19,788个三角面。远景含257件、10,844个三角面。Blender重开后有203组网格、20种材质及九台相机。门柱的灰粉抹灰和窗墙的红砖都有原创色图和法线图。照片中可辨的砌层行高约0.054米，长砖约0.205米。牌高0.20米和摄影眼高1.56米均为估计；窗墙相对门柱的进深误差约半米。[材料与地址](../../../../source/precise/xuhui-dafuli-yanqing-29-no3-court/measurements/court-three-identity-and-surfaces.json)

三份交付GLB在固定原片像素上的结果一致。35个铁艺和衬板测点中30个精确命中；其余5个最邻近的预期材料相距2至18像素。柱、门、窗上的26个原始测点有21个精确命中，偏差集中在陶色凸件、金属折边和玻璃旁的窗棂。下部门楣和立柱有5个点中的3个精确命中，其余两点先与门柱帽、遮蔽边缘相交。下层门面遮挡处采用无装饰的封闭剖面。[铁栏细部](2016-terrace-comparison.jpg) · [门头与柱面](2016-gate-comparison.jpg) · [窗头与砖缝](2016-window-comparison.jpg)
