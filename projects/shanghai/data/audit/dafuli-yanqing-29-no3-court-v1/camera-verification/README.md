# 大福里3号院门与露台的九个观察位置

总览收进院门、露台及绿框窗。沿弄的一镜沿用2016年摄影位置，画面转向3号门柱。另七个机位分别查看门牌与柱帽、深色门扇、露台全宽、转角铁花、绿框窗、露台底面和窗楣齿饰。

每个机位核对三个构件，总览另查院门之后的绿门楣，门牌近景另查柱身小陶块，共29处。报告记录它们在成图里的相对坐标、光线首先碰到的三角面、材质以及命中点与预定点的距离。铁栏的坐标取扁铁中线，外表允许相差35毫米；其他点落在构件表面，允许相差8毫米。这些距离用于检查显示与遮挡，模型的绝对尺寸受门牌高度和两张相片视角限制。
