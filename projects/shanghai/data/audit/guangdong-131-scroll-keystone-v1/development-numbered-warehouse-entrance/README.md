# 广东路131弄券门与卷形拱心石

依据Livelikerw在2019年7月11日拍摄的广东路街景，取右拱脚有绿色131弄铭牌的通道入口。造型包括水平分缝、扇形券石、转折的石雕卷托及券底阴影。
