门廊的定位点为东经121.46005273°、北纬31.22531869°，位置估计误差0.85米。原建筑在宏块14-13719-6694内，编号369。核验逐项检查门廊裁切的实际平面和高度，近瓦中相邻建筑编号242的原几何也参与校核。
