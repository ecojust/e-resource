# 中德医院旧址庭院中央门廊与露台

延安中路393号的具名楼体对应市级4C001。庭院开向巨鹿路，2017年Fayhoo从花园轴线上拍到铁门、石柱、挑台和露台，2021年实景车从园外两个方向拍到中央窗组、露台和屋顶。两侧翼部以及延安中路一侧的突出阳台保留在原有城市模型中。[登记和独立实照](../../../source/precise/huangpu-sino-german-hospital-courtyard-loggia/reference-review.json) · [图像量测](preflight/photographic-registration.json)

近档25,424面、远档8,148面，原稿与两个传输文件每档各检查171条射线。院门铁花透空，从前栏之间能看见廊后中央双扇玻璃门和两旁较窄的玻璃开口。近档另外保留细铁花、花槽表面格纹、柱头刻线与梁上的拉丁字招牌。两档都保留露台与前方花门之间的退深。[近景正面](preflight/full-south.png) · [铁门特写](preflight/full-gate.png) · [露台远档](preflight/lod-terrace.png) · [原稿与下载模型交点](preflight/pilot-surface-checks.json)
