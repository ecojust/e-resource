## 正式城市地图复核

旧城同一街面镜位可见矩形窗列。切到第228站，南向庭院立面的两端各有浅色弧顶窗和一段矮瓶栏，中段后退，橙红色折坡屋面连过中央窗带。前廊特写真正看到柱后较暗的玻璃门窗。右侧邻屋的阴影落在东端，桌面信息卡遮住部分首层。手机和桌面的目录卡、地图标记都能实际进入延庆路130号；单体页在两个屏幕、两档模型中都保留了双弧顶的轮廓。

同机位对齐的76,800个像素中，37,086个的RGB最大通道差超过16。16处碰撞实测与原表逐点一致，包括前庭和侧通道的空地、保留的后段以及相邻建筑。独立页四次实际保存覆盖原始、近景、远景和Blender文件。

远景证据分两次采集。第一轮拍下720×510的正常城区地图，确认远档网格加载与WebGL画面，并核对三个文件的HTTP字节。它在最后读取输入设备时退出，状态码为1。第二轮在相同视口用鼠标实际点击普通查看页，再将四份下载逐件保存并核对摘要，退出状态码为0。远景图中可以辨认街区布局和地图标记，细部见前廊和屋顶特写。
