# 襄阳公寓顶层折纹饰带与悬垂边柱

取襄阳南路254号公寓的屋顶局部。两根较高的墙墩夹着一列重复下折纹样，饰带下为密布短托的深暗水平缝。墙墩石帽以下各有三条长短不同的垂饰。
