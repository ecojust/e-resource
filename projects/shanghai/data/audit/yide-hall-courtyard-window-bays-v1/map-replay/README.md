# 宜德堂重建院窗地图回放

在完整项目的本目录运行 `node check-runtime.mjs 311 before.json` 及 `node check-runtime.mjs 312 after.json`。需要 Node.js 22.15 或更新版本。程序用两期各自冻结的城册和校验过的原始地块、原瓦片、运行模块和模型实际重放六种载入状态。缺失的公共底图、网页模块按固定提交下载并核验 SHA-256。另一个本地项目副本可用环境变量 SHANGHAI_MAP_SOURCE_ROOT 指定。

前期从可编辑工程对应的公开三维模型生成试放，后期读取正式城册。报告逐状态记录2107户在6.11至13.84米之间的遮挡、邻户、矢量与地面通行的核查结果。
