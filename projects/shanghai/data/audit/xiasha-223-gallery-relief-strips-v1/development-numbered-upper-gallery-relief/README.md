# 下沙街223号楼廊竖饰板的长框与菱花

Dragon于2020年9月20日拍摄下沙街219至223号住宅；一张近照同时拍到了清晰的223号绿牌和二层楼廊。栏面深色横条之间排列着窄长的红褐色饰板，顶部有短卷纹，上段带收尖的细框，下段有两个菱形小饰。
