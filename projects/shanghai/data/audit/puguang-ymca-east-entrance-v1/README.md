# 浦光大楼四川中路门头核查

两个限高裁片分别覆盖首层门头与两侧店券、上层三条窗轴，从原城的近景和远景三角形逐面确定归属。同一绘制组内共有六栋楼。两个裁片均只接触2382号浦光大楼，保留原楼上部和独立邻栋。[源城裁切检查](source-cut.json) · [源码和史料](../../../source/precise/huangpu-puguang-ymca-east-entrance/README.md)

门套、阴刻、店券和窗墙在原始、近景与远景网格分别经过162个正向首交点检查。门套专项另核三档的钟面罗马数字、时针分针、门扇以及下探窗。两道街面高度裁片保留原始矢量。35处地面点覆盖人行道、关门后的室内位置、原栋后部及左右留存的街面开间。[门套独立检查](stone-entrance-rays.json) · [制作预检](preflight/model-review.json)

公开相机沿四川中路对准钟门。过高的视角会让门券挡住表盘，过低的视角又会受到街对面927号楼遮挡。采用52°俯仰角后，桌面和手机各能看见16处已在网格上定位的受检构件，包括铭额、钟面、两座石山花、两侧店券与中央窗扇。[可见范围和模型资料](../../../source/precise/huangpu-puguang-ymca-east-entrance/reference-review.json)
