# 永嘉路 19、21 弄共用门屋

上海市第五批优秀历史建筑名录以“西爱村，恒爱里”登记两弄。街面铭牌的字形分别为“西愛邨”和“恒愛里”。近景和远景图板各含六个由交付模型绘制的视角，附档记录 GLB、图板与机位参数的 SHA-256。

门头阶肩与打开的高窗依据 2015 年街景，门洞内的两扇值班室窗采用 2017 年的斜侧视图。2020 年正面和近距机位能看到两块弄名牌、下方弄号与东牌前的落水管。牌面字形使用经许可的开源字体重建。地面小井盖按其亮边拟合为圆，外缘实测径向均方根偏差约 3.7 厘米。

图板及其几何为本项目原创。两款字形的 SIL Open Font License 与字体来源记录见模型 source/fonts。街景照片仅用于测量。
