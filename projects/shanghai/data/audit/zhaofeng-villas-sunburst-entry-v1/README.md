# 兆丰别墅长宁路入口

长宁路712弄的两面入口墙已有六处摄影机位。东墙保留阶梯状日升纹、四个铸字、半圆壁灯、两块铭牌和花台；西墙保留门牌绿底与白字、凹槽和相配的壁灯。街景三站量得入口宽约5.0±0.35米，右墙入内较深，黑色铁门分别向内打开约80度及103度。模型覆盖弄口，弄内住宅列入后续逐栋范围。[出处和量测](../../../source/precise/changning-zhaofeng-villas-sunburst-entry/README.md) · [四个模型视角](final/registration/registered-views.jpg)

近档255个闭合构件、20,384个三角面，远档235个构件、10,972面。两档分别从源代码复造并检查有向边、正体积和重合面。四种饰面的颜色和法线图在解码后逐张核对。[闭体检查](final/whole/solid-review.json) · [三角面和UV解码核对](final/mesh/mesh-decode-comparisons.json) · [饰面图核对](final/mesh/decoded-gate-finishes.json)
