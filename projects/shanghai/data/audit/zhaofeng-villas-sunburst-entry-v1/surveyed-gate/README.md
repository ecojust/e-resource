# 兆丰别墅长宁路入口的街景量测

2021年1月11日的三个街景机位基线分别为5.10、7.19与12.27米。灯具、门柱内口、铭牌和日升纹冠顶的11组控制点联合重投影均方根误差1.88像素。各对机位分开计算，入口净宽约5.0±0.35米，东侧题名墙可见前缘约2.8至3.0米，冠顶约4.0至4.2米。东墙较西柱靠内约0.5至0.7米。入口中点比地址查询标点南移约4.3米，绝对地理位置仍留2至4米余量。[三站原点与留验](../../../../source/precise/changning-zhaofeng-villas-sunburst-entry/measurements/surveyed-street-gate.json) · [街口灯具、门柱及花台](../../../../source/precise/changning-zhaofeng-villas-sunburst-entry/measurements/metal-leaves-and-plinths.json)

本稿把东墙、铸字、两侧壁灯、西侧绿牌墙、打开的铁门和花台按这些尺度并置。各档156个闭合构件，近景12,204面，远景6,884面。门扇展开角度会随使用而变，街景里的红灯笼为临时悬挂物。门口各排住宅需逐栋另外认定。[近景](full-source.glb) · [远景](lod-source.glb) · [四处机位模型图](registration/registered-views.jpg) · [闭体与重合面检查](solid-review.json)
