# 复兴中路492号住宅浅弧窗湾与瓶形栏杆

取市第五批名录复兴中路492号住宅院面的一层浅弧窗湾。Antigng于2017年8月2日拍摄的正面照片可辨两根浅色圆柱，中间较宽的窗和两侧窄窗下方分别留出短段瓶形栏杆。
