# 大雄宝殿在城市地图中的前后对照

前一版有180处地标，从同一殿前镜位看到原有的多层粗楼。加入大雄宝殿后，桌面和手机目录各有181处地标，从目录打开即可看见两层灰瓦屋面、飞檐以及中央石阶。桌面默认镜位和手机默认镜位都较高，屋檐间的四块额匾在默认尺寸下很小。[同镜位原图](map-before.png) · [更新后的殿前](map-street-facade.png) · [桌面默认](map-desktop-settled.png) · [手机默认](map-mobile-settled.png)

斜看屋顶时可辨正脊和两层屋面的交接。拉近到南侧，画面下部可辨台阶、栏杆及中央入口，深檐仍遮住部分格扇；正看格扇和两端圆窗的取景见单体页。远景真实载入13,354个三角面，地标灯牌仍可点选。近景为43,102个三角面。[屋面](map-roof.png) · [石阶近景](map-wooden-screen-and-front-steps.png) · [单体正面](../viewer-desktop-full.png) · [城市远景](map-distant.png)

本项只替换2017年平移后的大雄宝殿屋面所对应的地物979。27个行走位置的实测结果均符合预期。殿身、前台基、石阶挡住行人，左右檐下、侧通道与旧址前庭可以通行。原地物同组17幢仍在，逐点复核涵盖普贤殿、文殊殿、卧佛殿、钟楼、地藏殿、鼓楼和天王殿。寺内其余屋宇沿用原城底。[行走记录及近远景](main-browser.json) · [旧版现场](control-browser.json) · [平移实证与原城核对](../README.md)

原有尺寸复核在两侧檐下分别记录了位于裁剪范围内、行人可以通行两个属性。专用输入依据每个原始量点逐项补全裁剪期望，保留原经纬度和行走期望。各点在实际地图与独立程序中的结果均已核对。[原始测点](../placement-geometry.json) · [补全依据](cpu-cut-collision-witnesses.json) · [复算输入](cpu-map-case.json) · [独立复算](cpu-runtime-placement.json)

两站分别逐文件通过935项与943项签名核对。两份浏览器报告均无脚本错误、请求失败或WebGL错误，四项成品下载和实际近远景资源均记录了字节数和SHA-256。[两站签名与七图指纹](signed-scenes.json) · [预检](two-real-sites.json) · [浏览器程序](check-jade.cjs)
