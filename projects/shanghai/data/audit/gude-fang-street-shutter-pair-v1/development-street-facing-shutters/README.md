# 顾德坊沿街两窗的红白百叶与褐色木叶

Antigng于2017年8月19日拍摄的襄阳北路68至72弄住宅街面上，相邻两扇底层窗打开百叶板，左窗红色叶片间隔以白色横档、外缘为浅色，右窗用褐色细密横叶。两窗均带浅石窗台。
