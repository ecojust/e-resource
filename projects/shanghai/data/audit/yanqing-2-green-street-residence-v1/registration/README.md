# 延庆路2号临街住宅影像复核

2015年6月21日，Fayhoo从富民路方向拍摄了绿色圆券门所在的街面。两个“2”号牌的位置、弧形楼梯间的三道上升窗、菱形和折面凸窗可以在实拍与同机位模型之间相互辨别。[整幅街面](2015-street-comparison.jpg) · [入口及号码牌](2015-entrance-comparison.jpg) · [楼梯间](2015-stair-comparison.jpg) · [阳台](2015-balconies-comparison.jpg) · [窗组](2015-window-bays-comparison.jpg)

2020年2月22日的另一个站位可以看清三角山墙、两组阶梯形烟道、圆弧檐线和北端屋面的转坡。冬季图为本模型在该机位的新渲染。树木遮住的屋面进深，另经四期正射影像约束。后墙只表达临街短翼的测量范围。[夏季实拍与屋顶复原](2015-roof-comparison.jpg) · [冬季机位模型图](2020-street-model.jpg) · [两视角数值测量](../../../../source/precise/xuhui-yanqing-2-green-street-residence/measurements/2020-roof-two-view-fit.json)

同机位对照中的摄影为 Fayhoo 所作，CC BY-SA 3.0。照片裁切及拼图沿用同一许可。模型只含原创结构和纹理。[原始照片及许可](https://commons.wikimedia.org/wiki/File:Yanqinglu_2_Hao_Zhuzhai.JPG)

最终近景有25,076个三角面，远景15,816个。三份发布网格均核对门口32处、折面窗50处、右侧上窗14处和此前出现端坡缝隙的33个屏幕位置。门口与端坡全部对上。折面窗有一束击中绿色内框旁2像素的白边，右上窗有一束击中玻璃旁的窄钢梃。九个视点均使用本版本实物检查。[入口及右侧窗的逐项报告](green-entrance-and-upper-sashes-three-assets.json) · [较早端坡开口](earlier-hip-opening.json) · [订正后的实测](hip-opening-after-correction.json)
