# 虹桥路舞蹈院团花园住宅群院内错台窗间与灰石基

从院中看过去，灰石基座上是浅色抹灰墙。窗间往里退进一层，水平檐线在此两次转折。下层窄窗的位置比帘影所见的宽窗高，细部视图可查看窗套、浅色帘褶和基座错开的石缝。
