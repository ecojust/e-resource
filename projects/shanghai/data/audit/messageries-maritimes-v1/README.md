# 法国邮船大楼 · 浦江大楼

中山东二路9号位于延安东路以南、金陵东路以北。市房管局名录2A001原名栏写“法国邮船大楼”。上海档案工作者记载这座1939年落成的建筑在2003年改建为档案馆。市档案馆外滩馆于2004年开放，2022年1月结束对外服务。入口按开放期间可辨认的街照表现。建筑材料的记载为水刷石，模型中大块浅色外墙、蓝灰色窗裙与黑色门楼均按照照片区分。[史料、照片和门额的年代](../../../source/precise/huangpu-messageries-maritimes-building/reference-review.json)

该楼的临江正面宽约26.8米。中央的三组三联窗延伸至高处，两侧双窗翼各低两层，北侧可见中间一级退台。近远景均保留完整窗洞和门楼的深度。中心冠部约43.1米、旗杆最高约45.7米，均为比例估计。楼层使用资料另记档案馆有11层楼面。历史建筑资料所称12层指中央最高部。西面侧窗和屋顶退台的深度缺少原始尺寸。[制作范围](../../../source/precise/huangpu-messageries-maritimes-building/README.md) · [总览](huangpu-messageries-maritimes-building-preview.png) · [档案馆时期入口](archive-portal.png) · [退台上部](riverfront-crown.png)

原始和网页近景各49,900个三角面，远景45,052个。原生文件重新打开后核对了66个可编辑网格。三份GLB分别以241条独立射线检验实际表面，共723项通过，覆盖中央十排窗、侧翼八排窗、窗裙、入口的双门和两扇侧窗、花岗石柱、三层屋面与建筑周围的空域。门楼早期稿有一条石檐遮住金字上缘，最后一版升高檐口，分开六个字。新增的17处检查点覆盖每个字的上下笔画和五处字间花岗石。[原生文件检查](geometry-native.json) · [近远三档表面结果](surface-checks.json) · [门额修正记录](portal-revision.json) · [原生画面复核](native-visual-review.json)
