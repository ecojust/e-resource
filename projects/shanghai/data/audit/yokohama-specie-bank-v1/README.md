# 横滨正金银行大楼

外滩24号的东立面有三道门、两根爱奥尼克式巨柱和退后的六层。原始版、网页近景和远景均在每个版本完成52条首碰射线检查，覆盖铜门、柱身、窗洞、栏杆及顶层开口。可编辑场景含69个网格对象。人物雕饰、后翼窗序和设备尺寸有估计。[资料与照片](../../../source/precise/huangpu-yokohama-specie-bank/README.md) · [几何实测](surface-probes.json) · [原生相机](native-camera.json)

原生数据在14-13720-6693的1571号记录中单独标示24号。近景、远景与同组其余业主的最近间隙分别为1.552米和1.622米。另一底图把24号、26号及相邻建筑并入一个要素，按24号范围扣除后仍保留另27块几何。此前登记的怡和洋行及格林邮船大楼保有各自的处理范围。[四周边界](placement-geometry.json) · [矢量数据实测](vector-source-checks.json) · [登记合同](final-placement-contract.json)

登记前的150处建筑均已复查。外滩23号的原始模型与银行最近，实测模型投影相距3.93米。怡和洋行原址轮廓距离23.67米，均未与本行重叠。[150处正式地块比对](existing-map-coverage-150.json)
