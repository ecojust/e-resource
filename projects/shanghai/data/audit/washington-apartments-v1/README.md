# 华盛顿公寓衡山路街角与高安路48号入口

市房管局登记2D021西湖公寓，原名华盛顿公寓。地图原楼131和现行OSM地块的原名、现名和英文名相合。2016年街角实照、徐汇发布的2020年门牌近照和徐汇区房管材料共同确定北端街角及高安路48号入口。1930年原有地上九层，1982年增加两层。模型采用可见的十一层外观，窗间墙、三面凸窗和门额花纹按照片比例制作。[制作与来源](../../../source/precise/xuhui-washington-apartments/README.md) · [旋转模型](../../../washington-apartments.html)

## 四件交付与几何核验

网页近景和无压缩原件各82,076面，远景65,732面。模型保留商铺层、八层外凸窗面与顶部两层平窗的差别。高安路48号绿门后退，门上是矩形浮雕门额；其上的窗间饰板为束腰形。三个序列化GLB共做372次几何探测，分别触测前窗、两块斜侧玻璃、窗框、凸窗底面、冠部、门扇、门牌与卷花；并检查屋面和院侧空地。原生文件经Blender复开，按物体和材质复核后输出渲染。[48号门口细节](48-gaoan-entrance-detail.jpg) · [三档首交记录](surface-checks.json) · [原生与压缩验证](geometry-native.json) · [原生全景](xuhui-washington-apartments-preview.png) · [四件签名](../../../assets/models/candidates/xuhui-washington-apartments/manifest.json)

## 原楼、街面与院内

高安路入口沿原生墙线距北端转角约31.35米。配准结合原生楼131、具名地块、三个街景位置和单独门牌点。街面后方的院落及衡山路西翼继续显示原楼。近档原楼投影966.66平方米，裁入256.79平方米、保留709.87平方米；远档对应953.63、251.16、702.47平方米。邻楼2018、2513、642、4120均为零裁入。30个地面点核对两扇关闭门前可进的深度、入口侧墩、沿街墙体、院落及四栋邻楼。[足印、邻楼和地面](placement-geometry.json) · [登记参数](final-placement-contract.json)

选定主图默认方位218°、俯角38°。按真实870和390像素宽相机与底图近、远档三角面计算，两个尺寸上48号门口、街角凸窗和顶部冠饰清晰面的样点均无前方原楼遮挡。整栋后墙、其余屋顶、衡山路两个住宅门牌和室内仍待进一步查证。[相机射线与候选角度](camera-preflight.json)
