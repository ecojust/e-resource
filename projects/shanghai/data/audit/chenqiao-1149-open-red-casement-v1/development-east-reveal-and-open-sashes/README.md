# 陈桥村1149号东墙外开红窗与水刷石窗洞

Dragon在2023年5月21日拍摄陈桥村1149号，原文把东立面与相邻1156号分节。东墙近照显示左扇向外开启，右扇合拢，露出的固定细杆在窗扇后面。两扇红漆木框各有两道细横档，窗洞侧面呈青灰色粗粒表面。
