# 宝庆路9弄住宅红瓦坡面的双扇老虎窗

Fayhoo于2015年9月4日署名的宝庆路9弄2号、3号合照中，左栋红瓦坡面前伸一扇双格老虎窗。浅框窗扇两侧是暗灰色侧板，上沿挑出一道黑色薄檐，周围保留有清楚的波形瓦列。
