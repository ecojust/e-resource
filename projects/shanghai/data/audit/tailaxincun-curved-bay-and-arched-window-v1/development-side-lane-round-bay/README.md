# 台拉新村支弄弧墙上的圆首钢窗与白色檐带

建国西路365弄支弄照片中的黄色弧墙，凹入的圆首钢窗、下层白色腰线和檐下圆端小齿。2017年署名街照可辨瓦端、三道横窗梃和上部扇形细钢条。
