# 第四批优秀历史建筑 4D006 资料核对

上海市房屋管理局第四批优秀历史建筑名单将4D006列为“花园住宅”，登记地址为淮海中路1414号1号楼。相邻的4D005为愉园，4D007为另一处花园住宅。该表提供编号、名称、登记时使用单位和地址，未附4D006的历史照片、图纸或建筑细部描述。[上海市房屋管理局第四批公布名单](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

截至2026年11月21日，以中文门牌和“1414 Avenue Joffre”检索Open Library书目，以及Internet Archive所收1850至1955年资料的题名与描述，均返回零条。法文路名与该号段历次编排仍待年代明确的门牌对照表核实。两项检索只覆盖已编目的字段。现有出处尚不足以确定任何一期的窗式、门廊或其他构件，本条登记为待补史料。[书目与档案检索记录](./archival-catalogs.json)
