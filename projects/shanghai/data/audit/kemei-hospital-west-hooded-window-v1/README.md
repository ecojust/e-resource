# 克美产科医院旧址西墙挑檐窗

市房管局第四批名录把重庆南路139号的2号楼列为4C008。2020年与2021年街照可辨西面上层窗头斜挑出的砖色雨篷、后退窗框、栏墙压顶和上方砖檐。2021年两站的交会量测保留了每组点的高程差，最大约0.85米。2015年署名照片另见浅色柱式，未用作本窗的造型依据。[原始照片与登记](../../../source/precise/huangpu-kemei-hospital-west-hooded-window/reference-review.json) · [交会量测](preflight/photographic-registration.json)

模型沿墙宽约2.43米，近档7,424面、远档440面。窗框藏于砖面之后，挑檐上表面倾斜，底面可从斜下方看到。原稿及两个传输模型各验207个几何交点。[正面](preflight/full-front.png) · [挑檐底面](preflight/full-canopy.png) · [砖檐与栏墙](preflight/full-cornice.png)

窗跨从离地7.32米起，切面止于11.54米。原城458的地面轮廓与同片邻屋在两个距离等级上保留，72个原始地面点均已复核。桌面默认镜头可见8个构件，手机可见8个。另从窗前的狭窄采光井取四个局部机位，检查玻璃、中央竖框和栏墙两端，两端各12个构件均至少有一个无遮挡机位。[各机位与原城遮挡](combined-window-visibility.json) [原城与相邻实体](map-replay/original-mesh-witnesses.json) · [实际网格视线](actual-camera-city-triangles.json) · [六种装卸状态](public-31273-map-runtime.json)
