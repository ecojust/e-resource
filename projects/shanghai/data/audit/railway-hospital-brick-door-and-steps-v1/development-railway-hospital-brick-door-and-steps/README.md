# 上海铁道医院虬江路红砖长楼玻璃门与三级踏步

Fayhoo于2016年2月10日在虬江路1057号拍摄了红砖长楼临庭院的一面。模型取画面右端的双扇玻璃门、浅色门楣、三级踏步与台旁小通气口。
