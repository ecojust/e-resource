# 爱麦虞限路9号宅绍兴路拱窗与挑篷入口

沿街大拱窗与挑篷下的双扇门共用一条轴线。玻璃分四列，窗下有四枚红菱，篷底中央有圆灯。门楣字样据原照可辨部分制作，较暗处的中段按照片留缺。 [出处与建筑范围](references.md)

这份制作稿的近景网格有15,271个三角面，远景有12,660个。近景保存原始网格，远景来自简化版经过压缩、解码后的实际文件，两件均可由支持GLB的查看器直接打开。[近景 GLB](shaoxing-9-near.glb) · [远景 GLB](shaoxing-9-far.glb)
