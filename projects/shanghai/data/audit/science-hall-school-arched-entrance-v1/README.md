# 胶州路601号1号楼端墙

上海市科学馆旧址的1号楼在院门内。石券门、三列钢窗、小阳台和砖山墙自下而上处于同一轴线。2021年街景的两条观测线与2024年院中近照给出的山墙尖高度相差0.63米，模型采用17.94米。外侧院门和现代校舍保留原貌。[来源与年代](../../../source/precise/jingan-science-hall-school-arched-entrance/README.md) · [照片标定](preflight/photographic-registration.json)

近档5,388面、远档1,960面，近档保留三个券环、钢窗细格、阳台细杆及逐级退进的山墙饰线。原稿与两个下载档各有121条射线检查门的退深、材料、开口和轮廓。[实测记录](preflight/pilot-surface-checks.json) · [近档石券门](preflight/full-portal.png) · [远档山墙与小阳台](preflight/lod-balcony.png)

原城切片包含1524在内的七个近档户主。新增实体以12.79平方米的局部裁切接入，南侧1933的外缘与该裁切相距16.15米。正式31273基底用于预演切换、裁切、原城恢复、地面和矢量碰撞。宽屏和390像素屏各检查12条视线。[原城与模型切换记录](public-31273-map-runtime.json) · [两屏遮挡检查](actual-camera-city-triangles.json) · [正式摆放](final-placement-contract.json)
