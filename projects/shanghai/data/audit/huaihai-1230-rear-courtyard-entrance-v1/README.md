# 淮海中路后排1230号入口与东西叠台

模型从西端砖角延至入口东侧窗墙，包含西侧四层叠台的窗裙、敞廊和凸窗，以及东侧四层逐层变化的开敞和封窗构造。两组叠台之间是绿底1230号牌、红色壁柜与内凹门洞。屋外金属笼和八台空调保留2016年1月所见状态。[模型互动查看](../../../huaihai-1230-rear-courtyard-entrance.html) · [两拍摄位置的模型自渲](registration/registered-courtyard.jpg)
