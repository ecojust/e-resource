# 门牌、二层四格窗和窗外金属笼

在早期照片的原坐标上提高并缩窄1230门牌，重做二层窗三道竖梃与横梃，按2016年院内图增设两处金属笼及可辨认的空调外机。近景464件、10116面，远景382件、8544面，所有部件均已验证闭合且体积为正。近网和远网分别有29与30个原像素直接命中预期表面，两档31点全部落在事先登记的容差内。近景2016年栅条遮住2013照片中的一个玻璃点，偏左两像素可见原窗。

本次同机位自渲还显示西侧底层金属笼有约2.18米超出本版的墙面截取范围。西侧叠台与相连窗墙将按2016年原图补建。此处保留发现问题时的模型。[双机位自渲](registration/registered-courtyard.jpg)
