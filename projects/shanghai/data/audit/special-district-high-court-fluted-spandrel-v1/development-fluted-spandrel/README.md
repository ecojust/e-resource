# 浙江北路高等法院旧址卷首壁柱与几何窗间墙

壁柱的两道卷首围住一段下弯的弧面，柱颈四条短槽接着柱身的八条长槽。两层钢窗之间的折线和横肋围着中央暗色小方口，斜视和细部视图可以看清它们的起伏。几何从2016年实照量取相对比例。
