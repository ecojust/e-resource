# 朱斗文公馆侧门柱廊与弧窗

上海市第四批优秀历史建筑 4B015 对应康定路759弄。庭院照片里，两根方柱托住侧门平台，旁边的木格凸窗沿弧面转折，上方各有石瓶栏。门廊与弧窗处在原城 817 号主宅的东侧，窗边的石质圆花、台阶和墙角隅石也进入本次模型。主宅南面大圆柱廊、院中其他楼房和屋内空间保留原状。

两个时期的航片与现存足印给出约 6.7 米的平台宽度及 1.6 至 2.4 米的进深。窗套与卷托的高度、凸窗曲率和圆花雕刻依照片估计。资料出处及署名见[制作记录](../../../source/precise/jingan-zhu-douwen-residence-side-porch/README.md)。

近档有 28,212 个三角面，远档有 16,856 个。每档在 96 处对真实三角面进行射线验收，附有五个方向的近远网格图。底图保留 22 处邻屋，行走验收包含 20 处地面和另外 6 个邻屋参照点。默认视角从院侧同时看到两柱、弧窗、窗上瓶栏和墙面圆花。点入独立页的「正看券门与弧窗」可见门套；院侧的邻屋遮挡了默认视角中的部分券门。[几何与地图验收记录](preflight/model-review.json)
