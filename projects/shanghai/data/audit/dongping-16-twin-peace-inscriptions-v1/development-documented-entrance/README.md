# 东平路16号和平官邸双题牌院门

市表5D002和平官邸涵盖东平路14、16号。ShanghaiMansion上海豪宅发布的16号封面照，院门两边各有一块黑底竖牌，均写「和平官邸」。旁侧门牌可见16。模型取两根砖柱、球形柱灯、竖牌和中部上缘隆起的双扇铁门。
