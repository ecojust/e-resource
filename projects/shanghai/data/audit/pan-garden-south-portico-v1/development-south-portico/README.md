# 潘氏花园住宅南楼柱廊立面

两根通高圆柱立在弧形石阶上，中央门廊向内退进，两端折面凸窗夹着二楼石栏。 [历史照片与出处](references.md)

近景模型有40,652个三角面，远景模型有20,672个。两份下载均为内嵌全部资源的 GLB，可直接在支持 glTF 的查看器中打开。[近景 GLB](pan-garden-portico-near.glb) · [远景 GLB](pan-garden-portico-far.glb)

[南立面](test-front.jpg) · [二楼石栏](test-balcony.jpg) · [圆柱与弧阶](test-door.jpg) · [东端凸窗](test-east.jpg)

南面21.9米、整座主楼檐高11.8米见2013年建筑记述。窗轴、柱径与台阶进深按照片比例估算。模型截于前檐后的第一段屋坡。 [实物测读记录](reference-review.json) · [网格核验](mesh-review.json) · [可编辑源码](source/build_model.py)
