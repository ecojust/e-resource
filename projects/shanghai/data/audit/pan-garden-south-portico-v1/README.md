# 潘氏花园住宅南楼柱廊立面

市表4B024的地址为武定西路1498弄。院面约21.9米，檐口离地约11.8米。原城2572的花园边线长22.00米；富于层次的前部由两期航片和2008年、2014年照片交叉定位。按两幅2013年刊出的照片估计，柱间中心距4.24米、凸窗间廊口宽9.26米。近档40,652面，远档20,672面，共137个可编辑部件组。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2013年图文及近照](https://blog.sina.com.cn/s/blog_5d1bdf480101c253.html)

三份模型各以25条射线实查石柱、石栏、门窗、弧阶与短檐。南面只替换原城2572的一段，距西北另一幢396留有空隙。原屋保留部分沿用底图26米的概化高度。以原网格对两端两个分辨率实测，改过的院内概览能看到十处构件。二层栏后留有约2.56米的真实模型空隙，后门比两根柱子的前沿深约3.05米。落位使用35个地面样点和18个周边原户。朝向与细部以实际图片和本文件夹的交点记录核对。
