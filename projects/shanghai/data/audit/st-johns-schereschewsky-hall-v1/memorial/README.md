# 韬奋楼南院邹韬奋半身铜像
 
1995年11月15日，学校为纪念1921届校友邹韬奋百年诞辰，在怀施堂中庭为其铜像揭幕。本件以2004年背面、2024年正面及2026年斜前方照片核形。台座前面有“鄒韜奮”和“1895—1944”，上部可辨圆眼镜、两边西装驳领、交握的手与斜向卷件。正面题字按Noto字形近似，背碑文字未辨。四层黑石台、红石座与人物总高约3.57米。头顶按2004年机位投到原图(496.7,471.8)，原图识别点为(499,471)；各构件已查边闭合及正体积。[出处和尺寸](../../../../source/precise/changning-st-johns-schereschewsky-hall/measurements/sculpture-evidence.json) · [近景](statue-full.glb) · [远景](statue-lod.glb) · [题字许可](../../../../source/precise/changning-st-johns-schereschewsky-hall/measurements/sculpture-lettering-LICENSE.txt)
 
两端照片与校方斜航拍共同约束南院东西廊的十一跨和距街面约46.4米的对面横翼。校方照片中可直接辨认八段侧廊，十一跨总数另由院深、侧廊节距和两机位留验推算。两座北院并排，中央短翼末端与北横翼之间的屋檐空隙为2.7至3.8米。[院深推算及各跨对照](../../../../source/precise/changning-st-johns-schereschewsky-hall/measurements/school-court-station.json) · [北院屋缘](../../../../source/precise/changning-st-johns-schereschewsky-hall/measurements/north-courts-roof-limits.json)
