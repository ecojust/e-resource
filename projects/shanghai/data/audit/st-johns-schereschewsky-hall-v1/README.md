# 怀施堂（韬奋楼）

怀施堂于1895年落成，现为华东政法大学长宁校区41号楼。模型可以从临街券门穿过钟楼进入南院，查看面向院内的钟盘、东西两侧十一跨券廊、邹韬奋半身铜像，以及对面横翼的白色中舱。北面两座小院和临河横翼按屋缘复原。近景987个封闭构件、145,120个三角面，远景954个构件、98,072个三角面。[查看模型及八份下载](../../../st-johns-schereschewsky-hall.html) · [三处实拍机位的模型图](final/registration/registered-views.jpg) · [实物与历史来源](../../../source/precise/changning-st-johns-schereschewsky-hall/README.md)

原始网格与两档网页网格解码后分别检验三处照片的90个材质点。Blender工程独立重开，含185组可编辑网格、四组原创彩色及法线纹理、十台相机。FBX、OBJ、STL分别导回核对145,120个三角面。源码在新目录中重新生成八张纹理、两档原网及三份交付GLB。[照片逐点记录](final/registration/registered-materials-three-deliveries.json) · [十台原生相机出图](editable/ten-native-cameras.jpg) · [源码复建](source-archive/changning-st-johns-schereschewsky-hall-source.verification.json)

城市底图把编号1840的南院填成整块屋面。新模型的北墙比原地块北边中点向北约3.47米，与其余3,706个建筑轮廓均分开。当前以独立模型展示；滨河外墙和北院门窗数量仍待照片核实。[城市网格与相邻边界量测](../../../source/precise/changning-st-johns-schereschewsky-hall/measurements/all-1840-neighbors-and-rays.json)
