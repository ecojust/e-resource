# 永嘉路39弄街门与院内横屋

[近景图版](yongjia-39-court-and-gate.jpg)与[远景图版](yongjia-39-court-and-gate-lod.jpg)上排左图是 Antigng 于2015年9月9日拍摄的《郑家弄》裁图，上排右图为同机位模型。下排三图均由模型渲染，分别表现街对面看院内横屋、斜看开启的铁门，以及东门柱的彩绘牌。原作及含有其裁图的两张图版采用 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。[照片原件与署名](https://commons.wikimedia.org/wiki/File:%E9%83%91%E5%AE%B6%E5%BC%84.jpg)

同名 JSON 记录原照、渲染输入、图版的 SHA-256 以及各视图机位。院内机位前方几何保留原顶点、索引、材质及纹理。街景照仅用于标定，下排不含街景原图像素。

门柱、铁门和彩牌在三个版本中各核对123个原照采样点，其中90点在原像素直接命中、119点在各自预定容差内命中。其余4点前方可见的是邻墙的面砖或灰缝。
