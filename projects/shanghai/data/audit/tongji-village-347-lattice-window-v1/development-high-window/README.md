# 同济新村347号高窗与方形花格

2015年8月2日，Fayhoo在彰武路45弄拍到同济新村347号这面高窗。窗两侧细长的固定窗格一直落到窗台，中央两扇窗向外支起，窗顶有一段短瓦檐。两边墙上各有上下两块方花格，能透过水泥格孔看见后方。模型保留了两扇窗的不同开度和四块花格的透孔。[347号原照](https://commons.wikimedia.org/wiki/File:Tongji_Xincun_347_Hao.JPG)

同一作者稍早拍摄的88甲是同弄教工活动中心。347号这一件独立展示，窗墙的整体尺度、窗扇开度及格孔深度按单幅照片估计。[88甲对照照片](https://commons.wikimedia.org/wiki/File:Tongji_Daxue_Jiaogong_Julebu.JPG)

近景含6,368个三角面，远景含5,024个。两份导出文件分别检验84处几何交点，其中16条视线穿过四块花格的格孔。正面看窗格分段，斜面看窗扇开度，花格特写可看清外框和中部连接。
