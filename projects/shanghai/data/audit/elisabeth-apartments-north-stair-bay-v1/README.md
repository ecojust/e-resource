# 伊丽莎白公寓北立面主楼梯间与雨厦

复兴中路1327号的伊丽莎白公寓现名复中公寓，列入上海市第四批优秀历史建筑，编号4D011。模型覆盖北立面中央楼梯间、入口雨厦及左右各一跨窗。入口两根圆柱支起方形雨厦，向上可见两道浅色竖带、转折的钢窗、砖砌窗间墙和梯间冠顶部的多道折角檐带。[市级登记表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [原始立面图与现状照片](https://www.thepaper.cn/newsDetail_forward_24151077) · [模型查看页](../../../elisabeth-apartments-north-stair-bay.html)

原图左侧从地面至翼楼檐口标注47英尺7½英寸，折合14.5161米。另一处3英尺9英寸的标注折合1.143米，可独立校对图上比例。柱径、门洞深度和转角窗出挑量依据照片估算。具名建筑轮廓与街区模型中1005号房的平面重合度约96.4%，整体轮廓无法单独确定北门各处的出挑量。[立面尺寸换算](../../../source/precise/xuhui-elisabeth-apartments-north-stair-bay/measurements/north-elevation-dimensions.json) · [场地比对](../../../source/precise/xuhui-elisabeth-apartments-north-stair-bay/measurements/site-comparison.json) · [来源与图像权属](../../../source/precise/xuhui-elisabeth-apartments-north-stair-bay/SOURCES-LICENSE.md)

原稿与网页近景各含20,316个三角面，远景含10,908个。近、远景分别保留114和98个编辑组。三档各以116条射线检查建筑表面和留空，近、远景各保存七幅图，可对照楼梯间折角与冠顶收边。[作者验收](preflight/model-review.json) · [逐条几何检查](preflight/geometry-rays.json) · [十四幅图的对照](preflight/visual-comparison.json)
