# 东方饭店西端主楼核验

西端狭面、两个转角和各自邻接的临街近段形成19米纵深的局部模型。三组爱奥尼柱跨越三、四、五层，三至五层的窗口有开口和退深，上部两层带横向窗带。中文横榜和1929铭牌采用独立立体字形。底层正门按近年实照表现矩形门洞，两面转角保留券窗。前期资料、修缮后的现场与门头会随展陈更换的记录见源档案。[照片与书目](../../../source/precise/huangpu-oriental-hotel/reference-review.json) · [原生视角](huangpu-oriental-hotel-preview.png)

原始GLB与压缩近景各55,252个三角面，远景33,136个。Blender 4.3.2重新打开176件可编辑网格，模型按材质计算的三角面与原始GLB一致。压缩模型另行解码核对；射线分别检查三组石柱、阳台踏板、转角券窗、入口玻璃、楼层横档、顶部石屏和开敞人行道。[逐个三角面与原生文件](geometry-native.json) · [各档模型射线和铭文检查](surface-probes.json)

城市远景和近景均保留约86.4%的原2313号地块投影。两条长翼的大部分、五层副楼及院内余部保留原城市体量，模型截面与原建筑相接的线长约25.37米，按精细城市瓦片的实际高度闭合。最近其他独立地块与替换面相距6.69米。高度和可见局部尺寸均为估计。[配准合同](final-placement-contract.json) · [城市源网格与相邻地块](footprint-review.json)

111项真实站的单体页已在桌面与手机分别核验，均能显示两档模型并下载四份符合散列的资产。[独立页报告](viewer.json) · [桌面近景](viewer-desktop-full.png) · [手机近景](viewer-mobile-full.png)
