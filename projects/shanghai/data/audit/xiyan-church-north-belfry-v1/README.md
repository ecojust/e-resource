# 息焉堂北侧独立钟楼

四张实照配准了台阶窄窗、两面三联尖券和折角灯亭。黄赭拉毛和券石采用原创色纹与法线，门前碑身、铁十字和横向百叶分别成组。近景393个闭合构件，远景261个闭合构件；50个材面点中近景44处、远景47处正中，最大偏移2.24像素。2016年六月十字最上端的形状点存在11.8像素余差。塔脚宽3.60米为条件尺度。[模型制作与史料](../../../source/precise/changning-xiyan-church-north-belfry/README.md) · [四机位模型](registration/four-station-models.jpg) · [近景材面点](registration/full-source-four-stations.json) · [远景材面点](registration/lod-source-four-stations.json)
