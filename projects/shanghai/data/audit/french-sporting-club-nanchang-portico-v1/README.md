# 法国体育总会南昌路门廊与券窗阳台

南昌路57号列入上海市第四批优秀历史建筑，编号4C005。2005年挂出的铭牌记载建筑建于1931年，砖混结构。高参88在2014年发表的正、斜两张照片显示同一道铁格门、金色“上海科技发展展示馆”题额、两根有槽圆柱和上层镂花砖阳台。2015年冬天的街景补足了阳台后方白色券窗、檐下砖饰和屋顶曲线。门牌与院内另外两幢建筑的辨别详见来源记录。[市房管局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [高参88拍摄的入口](https://blog.sina.com.cn/s/blog_5d1bdf480101gxl2.html)

原城2366与具名底图轮廓的交并比为97.98%。四个2023年街景机位测得两柱中心相距约2.85米。模型选择7.36米宽的门廊和上方券窗，近档与远档分别有22,754与6,035个三角面；编辑工程按40组构件组织。原楼其余部分沿用底图，门廊后的旧屋面概化高度为20.5米。窗框进深、瓦棚各坡和阳台侧栏花格按照片估算。建筑师的署名在目前材料中存在出入。

近、远档均核过八个相同构件在两种屏幕视角的首交。地面35点包括门前浅阶、闭合的铁门、门廊内空地与保留的原房。另有20个邻屋对照。南昌路47号已建的科学会堂1号楼具有独立足印，与57号之间相距76.95米。
