# 法国体育总会南昌路门廊与券窗阳台

两根竖槽柱承托红筒瓦短棚。上层栏板的条形孔与宽券窗相叠，门扇与题额位于下方。 [历史照片与出处](references.md)

近景模型有22,754个三角面，远景模型有6,035个。两份下载均为内嵌全部资源的 GLB，可直接在支持 glTF 的查看器中打开。[近景 GLB](nanchang-portico-near.glb) · [远景 GLB](nanchang-portico-far.glb)

南昌路侧两柱的位置与尺度由2023年四个机位交会估计。柱头到旧墙的进深、檐口高度和花格孔径按公开实照校正。 [实物测读记录](reference-review.json) · [网格核验](mesh-review.json) · [可编辑源码](source/build_model.py)
