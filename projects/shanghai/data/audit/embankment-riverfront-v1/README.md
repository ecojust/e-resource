# 河滨大楼临河立面核验

北苏州路的临河面跨西南长翼与东北折翼。实证包括2013年河岸远照、2020年修前俯拍、2022年修复完成后的正面与庭院图，以及2025年5月的圆弧窗细部。[史料与制作范围](../../../source/precise/hongkou-embankment-building-riverfront/README.md) [旋转查看](../../../embankment-riverfront.html)

原始与网页近景各130,980面，简化远景62,394面。重新打开的原生工程与原始模型逐材质、逐三角面相同。对三份实际文件各做162次射线检查，覆盖四组楼梯窗及砖带的九排楼层、三处弧窗和下部混凝土横带、庭院三面窗墙与屋顶亭六处贯通开间和支承。[预览](hongkou-embankment-building-riverfront-preview.png) [原生与网页一致性](geometry-native.json) [三档实测](surface-checks.json) [现场图与原生渲染逐项对照](riverfront-visual-review.json) [原生相机构图](native-camera-bounds.json) [四个下载文件](../../../assets/models/candidates/hongkou-embankment-building-riverfront/manifest.json)
