# 密丹公寓武康路与湖南路转角立面

上海市房管局第二批名录以2D037登记武康路115号密丹公寓。2013、2015和2026年三位摄影者的街角照片共同显示顶层两樘窄竖窗、两层横窗、入口上方的深窗和两侧阶形托块。此次重建从切角向两街各延伸约6米，商铺参照2026年的门窗位置，后部和内部结构待查。[照片与研究依据](../../../source/precise/xuhui-midget-apartments/README.md) · [模型与四种下载](../../../midget-apartments.html)
