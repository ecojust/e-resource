# 沪南钱业公所古城公园南门楼验收

北施家弄133号是公所原址。现址门楼位于人民路、安仁街的古城公园内，市房管局将原址与现址同列于第四批4A039。2014年门额近照、2015年地面与西面高处照片、2020年南面航照分别核定六字题额、三道券门、三组瓦檐与身后的院落。[迁建经过和照片来源](../../../source/precise/huangpu-south-money-guild-gucheng-gate/reference-review.json)

近档79,240面，远档29,818面。原始和网页两个等级均以真实射线检查152处，包括门石、黑木门、双环、阶石、门额六字、灰瓦上下表面与门前空间。高处斜视能分出最高的中央檐和两侧较低的附檐。正视下字额较浅，原照可逐字确认。字形用近似字体，人物与花叶带概括凹凸，小牌文字未转录。[正面](preflight/gate-front.jpg) · [斜视](preflight/gate-oblique.jpg) · [三档表面](preflight/surface-rays.json)

原城14-13721-6694的1173号建筑在门前作局部裁切。近档原投影保留94.47%，远档保留94.67%；一道封口接回原屋。近景同组其余103,230面与12栋邻屋继续保留，77处步道、三道门与房屋位置均核验。游客可走上台阶直到已关闭的门扇。普通目录相机在两种屏幕各复核12个目标。矢量底图的50个子建筑中，只裁去该门楼的一段，余下49个子建筑及4个同层建筑组保持原样。[切面与地面](preflight/city-meshes.json) · [矢量对照](preflight/vector-comparison.json) · [双屏视线](preflight/ordinary-sightlines.json)
