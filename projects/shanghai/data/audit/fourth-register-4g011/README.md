# 中国航空协会飞机楼

上海市第四批优秀历史建筑名录4G011为中国航空协会飞机楼，登记地址长海路174号。馆藏模型已收录其修缮后的外观。Legolas1024于2013年6月16日的照片显示，西圆塔顶部有三重逐层收小的圆栏；这些栏杆、栏孔和顶层圆亭在原作中均已建成。名录第439项关联原作，城市清单和模型数沿用第438项。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Legolas1024署名原图](https://commons.wikimedia.org/wiki/File:中國航空協會舊址.jpg)

原作也保留机翼形的前楼和三个高度的窗带，门框浮雕有简化。制作资料记载1935年奠基、1936年落成，模型展示修缮后的外观。[普通查看页](https://github.com/ecojust/e-resource/blob/81bdda5009c1fd62afbfef645e443722b47c606c/projects/shanghai/aviation-building.html) · [原制作与运行核验记录](https://github.com/ecojust/e-resource/blob/81bdda5009c1fd62afbfef645e443722b47c606c/projects/shanghai/data/audit/aviation-building-v1/README.md)

此次关联逐一复核了原生工程、原始网格和近远两档，共10,057,090字节。近档106,192面，远档60,384面。文件签、原审图以及登记表见[核查记录](existing-model-signed-assets.json)。
