# 沙逊别墅辅楼院面与老虎窗

依据1937年沙逊自摄影集与2014年辅楼修缮设计图，建成院面砖墙、外露木架、退进的入口、前坡三座老虎窗和左返侧坡的两座小窗。近景有1,106个闭合构件、19,252个三角形。远景282个闭合构件、5,092个三角形。近远景均按原机位复查砖、瓦、木架和石灰填板；逐点记录保留实际所见和偏差。草坪尽端的住宅主楼和同址酒店其他楼栋仍单独登记。[资料与范围](../../../source/precise/changning-sassoon-villa-service-wing/README.md) · [近景原网](working-geometry/full-source.glb) · [远景原网](working-geometry/lod-source.glb) · [两处登记机位](registration/two-dated-views.jpg) · [院墙逐点核查](working-geometry/full-courtyard.json)
