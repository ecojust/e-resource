# 沙逊别墅辅楼院面木构与老虎窗

虹桥路2409号沙逊别墅包括起居主楼与后勤用房。1937年沙逊摄影影集能辨认辅楼正面三座老虎窗、深色木架与中央入口。2014年修缮设计单位公开的透视图另外显示左返墙和右侧低连廊。模型包含两面窗墙、前坡三个真实窗洞、侧坡两个窗洞、曲木山花、木架斜撑及保护设计中的红砖和瓦面。1937年左返墙中部的小暗窗另有独立网格，两幅资料的差异可用同一组机位检视。[原始资料与精度](../../../source/precise/changning-sassoon-villa-service-wing/README.md) · [两期资料的同视点对照](registration/west-return-comparison.jpg) · [1937年窗段](registration/west-return-1937.glb)

近景1,135个闭合构件、19,628个三角形，远景291个闭合构件、5,236个三角形。独立页面可下载原始、网页近景、远景、Blender、FBX、OBJ/MTL、STL和源码。Blender有118个可编辑网组，含九个机位。源码包内89个文件用于独立重建，四张程序纹理、两份原网和三个交付模型的字节全部一致。[模型与八项下载](../../../sassoon-villa-service-wing.html) · [两次配准的模型渲染](registration/two-dated-views.jpg) · [九个原生机位](editable/nine-native-cameras.jpg)

正面屋窗的43个检点在三档网格中均落在目标材质1像素以内。2014年图上四处窗帽檐的投影误差为0.21至0.41像素，1937年另读的三个模糊脊顶误差约8至11像素。右侧连廊另有18处读点，近、远模型均首先命中对应瓦、砖或深色门洞。主院窗墙34个点中25点正中，各项逐点保留。2013年至2019年间园内屋面曾有明显变化，现有证据可确定宅园，北侧候选服务翼的约15米檐段仍待与原建筑图逐一对位。[连廊逐点核查](working-geometry/full-link.json) · [院面与砖木](working-geometry/full-courtyard.json) · [屋面时期对比](../../../source/precise/changning-sassoon-villa-service-wing/measurements/2013-2019-roof-periods.json)
