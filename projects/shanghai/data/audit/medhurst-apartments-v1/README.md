## 正式城市地图复核

在前后两个正式目录（31193、31194）用同一机位对照，旧城是均匀的深色方窗。加入转角模型后，中央出现沿窗列上升的竖肋，两翼的金属窗格和浅色水平腰带逐段转向南京西路、泰兴路。五段临街面的各三个取样点均符合街外可通行、墙内受阻的预期；后半楼三个点和四栋邻屋也保有原有碰撞。

390×844 触屏和 740×548 桌面各从目录打开地点卡，另各从同孚大楼的地图用手指或鼠标点中泰兴大楼灯牌。两条入口都回到同一地点。近景能辨翼部折角、深窗框和层间带；仰角较高的原图中，屏幕上方导航挡住冠部一截。以模型最高处 40.4 米重新取景，五道挑脊的间隔、投在平屋顶上的阴影和层叠檐口均可见。楼下商铺在街面照片中有地点卡遮挡。

街区远景实际载入 37,860 面模型，邻近还可见美琪大戏院和同孚大楼的灯牌。这个比例尺下，地点标签会遮住部分建筑，窗格与挑脊的细节见近景。浏览器实取原始 GLB、网页 GLB、远景 GLB 和可编辑原生文件，四件字节数与 SHA-256 均与登记一致。首次屋顶检查曾把地面灯牌的点选要求套在高空机位，原始退出记录与复测结果已一并保存。[首次屋顶检查及复测](archived-browser-attempts.json)
