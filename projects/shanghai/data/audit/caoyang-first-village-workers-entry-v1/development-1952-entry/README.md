# 曹杨一村工人住宅折角门廊与窄窗

门篷和主屋的瓦片逐排叠放，斜看可以看到屋檐下的暗部。低窗一扇自立面向外转出，位于门侧的高窄窗退在墙内。首层低水泥勒脚沿转角连续。
