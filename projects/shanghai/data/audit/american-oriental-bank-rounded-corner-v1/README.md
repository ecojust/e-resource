# 美丰银行转角模型核验

原始网格、解码近景和解码远景均逐道检查街面、门窗、砖墩、招牌、外机、弯管与女儿墙。砖纹检查读取 GLB 内嵌贴图及实际 UV 坐标。模型的中央门口在首交射线上可见约0.09及0.27米两个高差，照片仅能约束底部深色基座上缘的相对高度。三个位置的砖纹沿街视线受真实落水管遮挡，邻近的无遮挡面仍可核对材质。[网格射线](preflight/rays.json) · [七个检查视角](preflight/views.json)

地图回放在先前完整的城市数据层检查装入、隐藏、远近切换和卸载。临街裁剪只影响2839号原建筑，模型后方的主体和相邻屋保留。默认视角从路口看向建筑，每个建筑特征用九个面上位置检查；桌面和手机均能看到十三组特征，每组至少三点可见。[实际场景回放](preflight/runtime-31258.json) · [相机视线](preflight/map-camera-proof.json)

## 城市主图中的弧形转角

在河南中路与宁波路交口，桌面与手机都能从目录或地图标记点选美丰银行。地图目录从 309 处增至 310 处。核验覆盖弧形店面、中央入口、上部钢窗、女儿墙和远景切换，174 个碰撞检查点全部符合预期。手机触摸标记后成功回到本模型，同时记录了一次地图控制台的请求失败提示。独立模型页保留两种屏幕尺寸共六幅画面，原始、网页近景、远景及 Blender 源文件均已实际下载并复核。[城市图像与逐幅记录](city-31275/visual-review.json) · [地图中的店面与入口](city-31275/map-rounded-shopfront-and-corner-door.png) · [独立模型页检查](city-31275/standalone/viewer.json)
