# 公济医院后勤楼的檐口和屋顶

乔争月的街角照片拍到东北角红砖高体的两个完整上沿和临街中段砖方体。方体在红砖墙上有两处清楚的外挑暗线。2015 年天潼路另一视角也能辨出上端薄盖与半高的石束带。高体后方的多道黑色格栅属于相邻屋顶。[乔争月的建筑报道](https://www.citynewsservice.cn/articles/cns/lifestyle/iconic-red-brick-facade-reminiscent-of-former-glory-of-innovative-hospital-in-city-rkla75jm)

戴走军的院侧照片给出了另一排栏柱的间距，以及屋上砖房立面的一扇方窗。照片中开着口的石瓶栏、连续檐线和檐下牛腿都可单独辨认。院侧部分窗和屋面受相邻建筑遮挡，屋面进深及方体距街墙的距离保留为估计。[戴走军的院侧照片与文章](https://www.thepaper.cn/newsDetail_forward_6786793)

两张照片对应的原像素、图幅和实际量得的尺寸存于制作源的 `measurements/roof-photo-observations.json`。专题图依照这两个视角绘制发行网格。逐束报告保留每一条射线的首交材质和坐标。檐下剖面和瓶栏的截面检查分别以实测纵断和栏柱分段为基准。
