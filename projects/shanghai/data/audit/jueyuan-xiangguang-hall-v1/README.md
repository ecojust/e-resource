# 香光堂东院木廊核验

2017年揭匾照与2025年临院正照共同确定厅名和廊面。[照片及来源](../../../source/precise/jingan-jueyuan-xiangguang-hall/reference-review.json) · [阴影方向](photographic-orientation.json)

原城西瓦的354号建筑对应香光堂，东瓦的邻房也纳入取景检验。此次仅替换临院木廊占用的东带。原城粗模的其余体量、北面三进与相邻房屋均保留。双来源二维切割的细微面积差异详载于实测文件。[原城三角切割](source-cut.json) · [双源实测](preflight-vector-31270.json)

原始、近景和远景各有121个首交探针，核对门匾字形、柱后格扇、阶面、瓦檐与装饰木格。地图用83个局部地面点和一处原屋保留点检查裁口及邻房。桌面和手机分别在两档模型上对11处可见构件取样。摄影方向与城市地块位置分别有来源。[构件首交](preflight-surface-checks.json) · [位置与地面](placement-geometry.json) · [西侧原城遮挡](actual-camera-city-triangles.json) · [东侧原城遮挡](east-neighbor-ray-check/actual-camera-city-triangles.json)

屋后现存的通用体量高度仍按原城数据表现。朝向、外檐进深及廊间部分边界按来源有限的细节估算，尚缺实测剖面与东西两端街道近照。
