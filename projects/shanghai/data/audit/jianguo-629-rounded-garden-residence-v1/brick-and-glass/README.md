# 中央砖芯、窄窗和立面题字

2019年3月11日刊载的花园立面照片显示，中央三组宽窗均夹有一块清水红砖。上层砖芯以直线收头，中层与下层砖芯的顶边随窗楣轻微拱起。砖面横向平直，采用错缝顺砌。紧挨圆角的窄窗带同样分三层，每层上下两段透光，中间夹砖。照片中可见每段三列玻璃砖。顶部方砖分缝较模糊，下层底部受花木遮挡，最末一皮按可见边缘补齐。原照的拍摄日期未载。[2019年刊载照片与地址说明](https://www.sohu.com/a/300473463_120103574)

Antigng在2017年8月2日拍摄的照片中，上述窄带的亮部是带深色框的整片玻璃。独立的[2017年窗样](2017-brick-and-glass-study.glb)展示这一做法，保留同位置的夹砖和中央砖芯。六扇的固定或开启方向无法逐扇确定，样本采用闭合的窗面。[Antigng原照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:建国西路629弄.jpg)

右列四字为“立言、立思”，左列从较低处起排“立行、立志”。2017年照片可清楚辨读右列的笔画和投影，2019年刊载照片可读两列的相对高度和字界。2022年访问记录的正文两次列出四词。模型书体为独立绘制，每个字按其在照片中的字宽、字高和位置排布。字面至背面厚度为2.6厘米的展示估值。[2022年访问记录](https://www.meipian.cn/4jlr2uud)

[原创构造对照图](brick-glass-and-inscription.png)仅绘出上述装饰。数值复核逐个检查主模型中的玻璃砖、横竖灰缝、三块宽幅砖芯、窄窗边框和夹砖。独立2017年窗样的35个截面样点均命中预期材料。[2017年窗样复核](2017-study-verification.json)
