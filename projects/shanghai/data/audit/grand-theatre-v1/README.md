原始／近景10,832面、远景5,080面。网页0.21 MB、Blender0.37 MB。本件包含临街入口、大幅玻璃、雨篷、竖肋及后退屏墙、灯塔与相邻圆角墙带片段；后部影厅、整排商铺及邻楼未建，背面是候选截面封闭体。30.5米为选用的高度解释，16米记载及计高端点继续待核，所有平面尺寸为估计。

- [作者几何](geometry.json)：196／152个构件分别闭合、正体积、绕序一致；有限顶点、零退化面通过。12条射线穿过竖肋间并命中退后玻璃／窗框，另1条确认圆角墙带窗洞已切穿墙面。构件未整体布尔合并。
- [最终压缩解码](packaged.json)：逐件实际解码GLB，核对有限顶点、零退化面、绕序、面数和退后窗面。近远景外包一致，约23.85×9.31×30.5米；四件资产均以字节数和SHA256绑定清单，单件小于100,000,000字节。
- [Blender重开](native.json)：4.3.2导入、保存、重开后建筑10,832面、1个网格，几何哈希与候选范围元数据相同。摄影棚地面、光与相机不计入建筑。
- [网页检查](browser.json)：近远景切换、相机、四件下载字节及SHA256均通过；W键实际前进0.10米后松键，连续8帧位置不再前进；Escape返回、390×844手机触控前进0.30米及松手通过，错误数组为空。沿用默认35米模型范围及46米漫游边界。本次未修改共享漫游运行代码。

[文献与照片复核](reference-review.json)实际查看2010年Pyzhou照片、未定年历史入口近照和未定年修缮后夜景。海报遮挡的中部玻璃由后两图补充，不能把不同照片当作同一时期。[原生图复核](visual-review.json)对照三张渲染，保留比例与隐藏面限制。

初版上部肋顶18.6米偏低，复核后改为前端22.5米、后端21.5米，并加入顶高21米的肋后退进屏墙及横带。改动依据可见轮廓的视觉比较，**未将像素比例转换成实测尺寸**。本目录渲染、原生及几何记录均对应修正版。

玻璃为不透射纯色近似，不能由暖色夜照证明日间材质；灯塔字形、窗网、雨篷底部格栅及圆角均有简化。未复原电影海报、精确历史字体、完整屋顶或室内。
