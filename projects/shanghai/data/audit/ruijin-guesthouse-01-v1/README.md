# 瑞金宾馆1号楼验收

业主2013年总平面在北庭院南侧直接标出「1#」，和北面的「2#」、往西接出的连廊及新的酒店主体各有边界。四期航片均可辨识1号楼的端部凸湾和朝庭院伸出的矩形门廊。开放街图路口套合与后续局部的屋面微调分别记录，实地位置保留约3至5米估计误差。[实名总图和照片来源](../../../source/precise/huangpu-ruijin-guesthouse-01/reference-review.json) · [原址配准控制点](../../../source/precise/huangpu-ruijin-guesthouse-01/footprint-review.json) · [庭院与分栋示意](site-plan.png)

原城市模型把主宅的一部分识别为1250，把庭院门廊识别为2335，已有高度分别为22.55米和16.037米。1号楼为两层，庭院门廊的上部为石阳台。模型将这两个粗模片分别裁剪，并保留原同组的西侧零散体799、连接廊3003、现代主体2513等九个来源。独立解码近景中，剩余72,972个三角面距新模型至少2.80米；远景的192个三角面相距至少2.88米。两段实际地块与模型范围相交，裁剪范围按对应源界外扩0.36米。[双源配准合同](final-placement-contract.json) · [逐源近远景实测](placement-geometry.json)

北侧院面的窄石端窗、成对小窗、五组西侧花园窗、塔司干双柱、后退门扇与四座烟囱分别以射线检查。室外草坪和门廊步道保持通行，封闭的主楼、实际双扇门和柱脚进入碰撞轮廓。独立预览页可查看近、远模型或下载原始 GLB 和编辑工程。[实体射线](surface-checks.json) · [Blender 与 meshopt 核验](geometry-native.json) · [模型下载](../../../assets/models/candidates/huangpu-ruijin-guesthouse-01/manifest.json)
