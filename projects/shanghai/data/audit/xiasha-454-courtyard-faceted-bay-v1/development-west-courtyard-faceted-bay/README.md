# 下沙街西段院内住宅南面折角凸窗与仿石隅饰

市表登记此住宅在航头镇下沙街西段，2020年9月20日Dragon实拍的上海市优秀历史建筑公布牌标下沙街454号，牌文描述南立面西侧为六边形凸窗、墙面由青砖砌成且转角饰砖砌仿石。院内正照可见凸出的西侧窗面及其右方内凹入口、二层露台。本件截取凸窗上层照片能辨明的三面，包括灰砖、交错角块、窗台及红褐木扇。
