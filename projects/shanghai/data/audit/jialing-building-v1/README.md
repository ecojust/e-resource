# 迦陵大楼南京东路北立面

市房管局2A026列南京东路99号嘉陵大楼。地方志同时记载四川中路346号，北端为八层。2014年照片中的建筑为北端较矮的一段，方窗、竖肋、赭色檐带、两侧深色饰板和石基凹入门洞构成本次模型。资料中英文照片文件名存在歧义，已按中文说明、保护门牌、地块和三段层数交叉核对。[建筑身份](../../../source/precise/huangpu-jialing-building/README.md) · [原始照片与官方资料](../../../source/precise/huangpu-jialing-building/reference-review.json) · [透视依据及图像核对](visual-review.json)

原始和网页近景各24,248个三角面，远景14,464面。Blender重开后检查29个可编辑网格，并逐材质比对原始GLB与两个实际解码版本。每档分别投射104条检测射线，涵盖全部36扇窗、横档、檐口、三道竖肋、上下金属饰板、入口门架和四级石阶，合计312项通过。[四份资产](../../../assets/models/candidates/huangpu-jialing-building/manifest.json) · [独立页](../../../jialing-building.html) · [原生工程逐面核验](geometry-native.json) · [真实渲染](huangpu-jialing-building-preview.png) · [检测明细](surface-checks.json)
