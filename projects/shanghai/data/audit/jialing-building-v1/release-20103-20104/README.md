# 迦陵大楼原版城市目录实拍

本轮从145处目录打开原公共租界英国领事馆，以迦陵大楼的取景点拍摄旧街区；随后在146处目录打开迦陵大楼。前后两站的目录分别以20103和20104端口独立提供，实取响应、脚本、PNG与下载文件的签名均已保存。[两代网页和模型响应](release-bindings.json) · [十幅截图和原始报告签名](capture-files.json) · [145处对照](map-before.png)
