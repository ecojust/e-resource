# 铜仁路257号主楼车廊

原城以一个35米高的概化体表达主楼、北附楼及两者之间的部分铺地。局部裁切只作用于编号1584，自两幅相反方向的署名照片补入院内车廊。原有平面保留96.76%，同组另5处房屋的近、远裁切纹理均与原状态逐项相同。保留部分仍为原城概化外观。

近景15,568面，远景9,736面。原始与两档各115条射线覆盖三券、方墩、玻璃、百叶、弧首花板与屋檐。真实31269模块在载入、隐藏、恢复、远档与卸载状态逐项核对180个地面位置及1,210个裁切高度采样。车廊两侧可以穿行，主楼门扇位置关闭。默认镜头在桌面和手机的12个实物目标中各看见11个，另一角度的细节可在独立页旋转查看。
