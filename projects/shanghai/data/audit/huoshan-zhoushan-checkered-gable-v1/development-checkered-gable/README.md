# 霍山路舟山路转角住宅双券窗与棋格山墙

两扇高窗各有深灰色辐射砖券和一圈窄红砖，窗台各自出挑。窗顶棋格中红砖横放、灰砖竖置，下缘收成较短的错缝横砖。模型据2012年正面和2015年斜面照片制作；圆钝峰顶、两级肩部及中央浅色饰块均可从两期照片辨认。[2012年正照](https://commons.wikimedia.org/wiki/File:Shanghai-Ghettoviertel-16-2012-gje.jpg) · [2015年斜照](https://commons.wikimedia.org/wiki/File:Central_Business_Area_of_former_Shanghai_Hongkew_Getto.JPG)
