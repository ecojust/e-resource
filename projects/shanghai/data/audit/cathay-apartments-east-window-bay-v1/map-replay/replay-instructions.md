# 国泰公寓东窗地面与限高裁切复算

在已启动相应历史城图普通服务的机器上，31328 提供入城前版本，31329 提供入城后版本。脚本用两个真实 HTTP 源读取目录、地面、裁切及模型加载模块，按两份比较清单核签。31328 将正式模型副本临时放在本地回环端口，31329 直接读取该期正式模型。近景和远景均通过当期 Three.js 与加载器解析。

在项目根目录执行以下命令。环境需要带有同步模块钩子的 Node.js、Python 3 及 Pillow。图像适配器从内嵌图像字节实际解码尺寸，此项核验覆盖几何与状态，并不产生屏幕图像。

```sh
python3 data/audit/cathay-apartments-east-window-bay-v1/map-replay/repeat-runtime.py
```

每期各核对25个地面点、6种状态及每状态1452个高度样点。运行器要求重算报告与随附的两份原报告逐字一致。两个端口、各项模型和模块的读取记录见各期报告。
