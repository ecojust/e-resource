# 武进路225弄9、11号双门上窗

9号为闭合白框，两片短上亮配两片长窗，长窗下段露出褐色帘。蓝色小篷下可见四道边框和支架。11号为深红色上亮，两片外开木扇均分成三格，左扇外侧保留红漆，右扇背面露浅色漆。两扇之间能看到褐色上挡板和向侧面拢起的灰白布帘。绿色小篷的波纹沿墙面横向排列。

2015年高参88发表的第04张原照覆盖两扇窗，第08张独立曝光覆盖窗脚。两台相机均采用同一门9横档和地面基准。两照能在11号红扇自由边下段测得约0.32米的前出，白扇的完整边缘只在第04张内，模型估计其最大前出约0.55米。米制数值以模型取用的9号门净宽1.43米换算。两张照片只用于量测。专题板使用成品几何渲染。[高参88原文](https://blog.sina.com.cn/s/blog_5d1bdf480102vysd.html)

源目录中的 `measurements/upper-window-observations.json` 保存原图像点、相机、各面深度和两照下口的成对读数。`measurements/check_upper_sashes.py` 以91条未筛选材质的射线核对每档成品，`measurements/render_upper_sashes.py` 可由近远两档生成专题板。两者都按命令行的位置参数读取网格。
