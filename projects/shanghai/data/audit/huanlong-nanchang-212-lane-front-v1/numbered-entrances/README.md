# 南昌路两处入口的实景与模型

[近景版](nanchang-212-and-244.jpg)和[远景版](nanchang-212-and-244-lod.jpg)并列展示南昌路212弄的2015年照片和同机位模型。照片来自 Antigng 于2015年9月9日拍摄的《南昌路212弄》；本图版裁取了门楼及门牌，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 署名并以相同许可发布。[署名原照](https://commons.wikimedia.org/wiki/File:%E5%8D%97%E6%98%8C%E8%B7%AF212%E5%BC%84.jpg)

下排另附冬季机位的212弄模型，以及约85.6米外244弄的西侧弄牌、窄窗、门槛与铁门。244弄的定位依据包括隔壁242号店的门牌。图版没有街景原图像素。两处展示各从成品网格读取原始几何、材质与纹理。

三个版本的街门图像检验各有134个采样点，依据同一套预定容差逐点记录。细铁件与柱框的未命中记录也已保留。图版同名JSON给出原图、三维网格及图版的哈希值，另有每个取景的像素数和三角面数。
