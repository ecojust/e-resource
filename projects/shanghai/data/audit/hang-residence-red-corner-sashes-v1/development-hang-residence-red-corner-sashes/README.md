# 杭氏住宅舟山路455号上层转角红框窗

杭氏住宅后来作舟山路幼儿园。Fayhoo摄于2014年11月23日的舟山路455号照片中，上层窗面在街角折回；一道粗红横档沿两面延续，横档以下的窗格有较细的竖梃，窗脚由浅色石台联结。
