# 乌鲁木齐中路一侧的旧车库门

这两樘门位于白赛仲公寓截角入口右侧，在原麦琪路一翼。Harrison Forman 的硝酸底片同时拍到截角入口的逐级门套、墙上方牌和翼面两樘宽门。2018 年的对比文章给出同一位置的街景，画面上“乌鲁木齐中路”的路牌和门上的阳台可用于定向。房管资料记载原设计的“底层原为汽车间及附屋”。原底片馆藏日期为约 1932–1937 年。[馆藏 fr212568](https://collections.lib.uwm.edu/digital/collection/agsphoto/id/16659/rec/11) · [历时对照图](https://avezink.livejournal.com/120834.html) · [徐汇房管资料](https://m.thepaper.cn/newsDetail_forward_22555305)

远格两侧门板的宽斜压条在中缝会合。上方可见窄长的方折铁花，下方为竖向拼板。近格左侧露出的门面也有这两种细部，右侧部分受街上电杆、车辆与行人遮挡。复原在此处留暗，不能据照片确定车库的内部陈设或可动扇开启角度。记录中性灰、灰褐色材质，对应黑白照片的明暗。原图由威斯康星大学系统董事会持权。此处发布的几何和线描均由尺寸及构造重新绘制。

两樘门与现状模型共用地面原点。以沿街方向自截角向后计，采用历史底层平面的 1.15–3.51 米、4.25–6.62 米两个开口。门扇厚度、铁条截面及被遮盖的门底深度为估计。选择历史构件后，暗衬遮住现状店窗，边框、竖板与铁花均有独立厚度。独件可单独下载，也可在普通页选择叠入。

原片两段门平面用各自可辨的边缘配准。对同一束立面法线同时测历史独件和现状整网，19 束全部先遇到历史构件。近格 7/8、远格 8/11 束击中预判材质，另四束落在板面或斜条相邻的暗口。较远一扇的角度以及遮挡部分仍有误差。实际三角面首击及原片坐标见 [逐点记录](historic-and-contemporary-first-hits.json)，共面展开见 [门扇正立面](garage-elevation.svg)。
