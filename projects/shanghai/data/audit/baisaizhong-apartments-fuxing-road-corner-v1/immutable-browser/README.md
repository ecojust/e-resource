# 白赛仲公寓在线复核

在固定GitHub提交打开公寓独立页，桌面和手机分别使用12个机位、近远档和五个下载入口。两端均能在原位切换当代店面与旧式汽车间门扇，切回后图像与首次打开时逐字节相同。已下载文件分别核对清单中的长度和SHA-256。浏览视角和下载结果见同目录 checks.json。
