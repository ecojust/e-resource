# 白赛仲公寓建模与核对

历史首层平面给出五边形外墙、后部楼梯和两条长度不同的街翼。1934年报纸图、2015年街角照片与房管局修缮记录用于逐层核定四个三角形凹阳台、入口、两翼外凸窗和阶状牛腿。模型保留五层主体、局部第六层、水磨石楼梯及扶手铁花。公开影像对四期屋顶轮廓提供交叉比照。屋顶绝对高度和后部封闭侧面为估计。[图纸与出处](../../../source/precise/xuhui-baisaizhong-apartments-fuxing-road-corner/README.md) · [2015年实景与模型](registered-corner-and-stair/2015-photo-and-model.jpg)

馆藏汽车间照片能辨认三片门扇及上方气窗。浏览页可在同一视角比较早期门扇和当代店面。近侧门扇遮挡部分保留暗口。两种门面均有独立几何，馆藏影像仅作研究。[门扇立面与底片](garage/README.md) · [双期网格检测](garage/historic-and-contemporary-three-roles.json)
