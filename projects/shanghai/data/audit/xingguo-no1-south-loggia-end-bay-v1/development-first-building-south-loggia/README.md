# 兴国宾馆一号楼南立面端部双柱敞廊

长宁区融媒体中心刊出的近照在图下标出1号楼。模型截取南面图左端的一个敞廊开间，包含两根浅色圆柱、柱间瓶栏、转角侧券、出挑檐和带接缝的浅绿色坡顶。
