# 五原路372弄6–9号栖霞村可编辑工程

Blender 工程含 374 个独立网格、13,240 个三角面、28 种材质与九台相机。四台照片相机读取2016年实拍的原始光轴及横滚方向。另一 Blender 进程重新打开工程，核对原网有向三角面、材料和相机。

两种玻璃分别用于6号白框移窗和7号深绿封廊。近景与远景分别实解码，重新打开的原生场景也逐材质核对 Principled Alpha。颜色与法线贴图按作者源文件、采样坐标和逐角 UV 核验。
