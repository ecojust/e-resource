# 栖霞村院面近景核对

站17–20依次为6号、7号、未见清晰单户号牌的成组钢窗和9号。四幅JPEG来自同一套近景几何，按各自照片的视角重新渲染。四宫格底部标注对应站位。原始实拍、拍摄日期与作者链接见模型源码目录中的SOURCES-LICENSE.md。

以650×487的原图网页像素计算，四站16个跨图共见点的重投影误差中位数3.95像素、最大9.13像素。相机控制文件保留了每个观测的位置和误差，便于另外复算。

6号的白窗和红棚、7号的绿色封廊和开敞栏板、9号的挑板和细铁栏分别有射线命中记录。单个像素处于边缘时，记录同时给出偏差与邻域检验。分辨率、植物遮挡以及未知的墙面和院门进深均会影响结果。

完整和远景网格的逐构件封闭性摘要在同目录的full-closure.json、lod-closure.json。可见立面以外的屋面、背面、室内未作完整复原。
