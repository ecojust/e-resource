# 公益坊3号楼的阳台与花铁

四川北路975至987号的沿街立面在二层、三层各有一条通长阳台。上海章明建筑设计事务所2018年12月整楼斜照可从南到北认出十个石墩、九跨栏杆。修后街照拍到北段连续五墩，板缘、墩帽与板下成对的弧托亦可辨。[设计方图文](https://m.thepaper.cn/baijiahao_31065777)

2018年2月11日的原片可看清铁件的连接方式。每跨中心的圆花有六根辐条，横带穿过中心，左右两根长竖条在圆周收头。两旁共四组方折铁件，中间间以直杆与小环。墩帽下面有浅框和三道弧形坠饰。铁条厚度、石饰背面和弧托截面用照片可见比例估计。拍摄者为 Antigng，原片采用 CC BY-SA 4.0。[原图及许可](https://commons.wikimedia.org/wiki/Special:Redirect/page/66322895)

专题板的铁花照片保留原摄影署名，经裁切和透视校正。其余画面直接渲染自交付模型。含原照的对照板按 CC BY-SA 4.0 提供。[许可全文](https://creativecommons.org/licenses/by-sa/4.0/)

## 原片和几何检查

- Commons原片里，上层第二跨的花心映到下层同跨四角后，预测与独立点读相距3.81像素，占下层净宽约0.36%。三张照片的图源、原始分辨率、SHA-256和原生像素落点在源码的 `measurements/balcony-photo-traces.json`。有署名的2018年12月图6和修后图15分别对位，跨号从南端数起。
- `measurements/balcony-photo-registration.py` 由两层石墩的原像点拟合各自的正面平面。图6留出四道墩轴两层检查，中位投影偏差2.56像素、最大4.84像素。图15留出两道墩轴两层，中位1.93像素、最大3.36像素。修后照另十个板前缘检查点的偏差为0.15至3.73像素。
- `measurements/balcony-mesh-check.py` 对实际导出的GLB逐层逐跨发射光线，记录第一交点的材质、位置和距离。每档有460个构件检查点，包括六辐环、透空、横向石扶手、板前沿、墩头和双托间隙。另从修后照片的实际机位投射10个可见墩面，单独记录首交。
- 初读曾将校正图第345、74像素判作透空。原三层近照放大可见该点在圆心右上辐条。程序保留原点并核铁条，同时核相邻第339、73像素及两处竖条收头后的透空。首轮18处错误判读在同一拍照点重复于18跨。

`whole-raw.json.gz`、`whole-full.json.gz`、`whole-lod.json.gz` 各自绑定所测模型。重新生成专题板可运行 `measurements/balcony-study-board.py`，依次传入解码近网、解码远网、Antigng的5312×2988原图和输出JPEG路径。
