# 公益坊三号楼修后屋面

2025年4月18日WV03影像呈现临街长板屋面、中部浅褐平台、两端的浅盖面和暗色地带。北部暗区里有两排较浅的窄条，其间有深色间隔。2021年11月25日的另一景影像也可辨认长条、平台和两端盖面，但当时中央有临时覆盖物，两期的亮度与阴影不同。用途和实际屋面标高仍未确定。

在2025年影像固定33点，正下方首个模型材质与照片所判分区相符的有28点，距原像点两个像素以内可找到的有32点。2021年影像固定28点，相应有22点、27点。两幅原图各自使用同景的檐口南北端标定位置和方向，不同年代的像点单独留存。原始、压缩近景的独立解码与压缩远景的独立解码均得出以上计数。
