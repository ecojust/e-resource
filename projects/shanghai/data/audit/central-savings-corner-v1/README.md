# 中央储蓄会大楼天津路江西中路转角塔楼

市名录4A012登记天津路2号、江西中路349号为同一建筑。江浙银行大楼旧影和两幅可定位的近年街照都能辨认八排三联轴线、两道高出檐口的竖肋以及分级退后的街翼。现状钢门的圆章、楔形穿孔、“中國光大銀行”横排和阶梯形塔冠分别用实体网格表达。两期照片独立估算切角檐角约35至36米。钢门细孔、浅浮字及短街翼折进尺度保留推定范围。[来源、许可和异址辨析](../../../source/precise/huangpu-central-savings-society-corner-tower/README.md) · [独立模型](../../../central-savings-corner.html)

修订前钢门开孔较稀，横排名称与石材的关系偏深。依据门前原图取消深色独立招牌，补宽门洞侧面收边、门楣和中央圆章两侧矩形穿孔。上部窗内横梃由两道调整为三至四道，并根据塔顶特写分节收窄两道突出竖肋。[首稿入口](initial-gate.jpg) · [复核后入口](refined-gate.jpg) · [塔冠近图](refined-crown.jpg)

原始和近景各40,052个三角面，远景19,060个。三档分别从门洞、真实穿孔、圆章、窗内横梃、顶端和四级踏步测235条射线，合计705条。原生工程保存后重新打开比对编辑网格。[三档射线](surface-checks.json) · [工程重开](geometry-native.json)

局部替换原城市单体1455。远模仍留446.02平方米，近模型估计保留449.40平方米。同组另外五个建筑的三角面在两档均保持，另核对十七栋独立邻屋。两条街和石阶的31个地面点、真实截面与两尺默认相机均已复核。[原模型及邻屋](source-cut.json) · [地面边界](placement-geometry.json) · [双端相机](camera-sightlines.json)
