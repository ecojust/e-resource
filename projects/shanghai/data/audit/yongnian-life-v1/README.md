# 永年人寿保险公司大楼

广东路93号保险营业楼1910年建成。模型复原转角门廊、方门内的扇形气窗、两面券窗、上层通高柱和窗楣。屋顶局部四层、背侧和高度依据有限影像估计。1908年印刷构想图上的人物和高纹章不在本次复原范围内。[原始资料](../../../source/precise/huangpu-yongnian-life-insurance-building/README.md)

西侧共墙第一版的压顶越过留存底图最多9.5厘米，重叠约0.52平方米。将这段压顶与墙的两个西侧端点共同向内收20厘米，并保留同一地理锚点、其他街角和全部片区坐标。[可编辑建模源](../../../source/precise/huangpu-yongnian-life-insurance-building/source/yongnian_geometry.py)

新模型与保留的西侧13栋建筑实测最近10.61厘米，重合面积为零。原生六栋组另五个业主继续使用底图。矢量源为29体合并，替换后保留13,897.10平方米；西、南、北四处邻体面积均已核对。48处射线检查分别在原始、网页与远景GLB上完成，61个Blender网格的488个边界角点都在默认画框内。[接墙修订](west-party-wall-revision.json) · [原生实证](placement-geometry.json) · [矢量实测](vector-source-checks.json) · [射线](surface-probes.json) · [镜头](native-camera.json)
