# 福绥里，建国西路146号

上海市房屋管理局第五批优秀历史建筑名录将福绥里列为住宅，登记地址为建国西路146号，编号5A065。保护铭牌的范围为建国西路144至148号双号。铭牌记载三幢独立住宅，其中146号、148号为江南传统二开间民居格局，144号、148号有独立花园。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [保护牌照片](https://store.is.autonavi.com/showpic/2b8a39d1c7edcaea1db64a6660f3b04a)

本轮复核了名录原页和署有建筑说明的保护牌照片。铭牌记载K.C.Chen建筑师事务所于1925年设计，三幢采用砖木结构、平缓坡屋顶和带红砖装饰的清水青砖墙面。附近机位和门号点保存在观察表中。确定146号窗门与单栋边界仍需能辨认该户的外观照片。[原表核录](municipal-source.json) · [铭牌和机位记录](address-and-station-observations.json)
