# 东平路住宅弧形铁阳台与彩玻圆首门

市第五批5D026住宅，早期公布地址为东平路1弄。Fayhoo于2015年1月拍到住宅墙面凸出的弧形铁阳台，圆拱有多重细线脚和居中楔石，扇形亮窗及双扇门都留有彩色花叶玻璃。
