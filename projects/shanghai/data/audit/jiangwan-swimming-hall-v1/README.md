# 江湾游泳馆接入主地图

[全局主图直达](https://raw.githack.com/ecojust/e-resource/master/projects/shanghai/index.html#landmark=yangpu-jiangwan-swimming-hall&mode=overview) · [来源与重建](../../../source/precise/yangpu-jiangwan-swimming-hall/README.md) · [四资产清单](../../../assets/models/candidates/yangpu-jiangwan-swimming-hall/manifest.json)

本件为江湾体育中心内独立游泳馆的有界外观，北侧为浅石阶梯单拱入口，南侧为折角砖墙，池区上方为现代宽浅屋盖和抬高中央采光段。它与已建的室外主场、独立体育馆分别登记，周围白色轻型棚房及其他独立源不并入。

## 来源与年代

1934董大酉原设计明确为露天泳池，50×20米是池体尺寸，不是馆外包或建筑高度。泳池文字、透视、底层平面及立剖图分别查看，历史看台和内部分区只约束形制，不冒称已制作室内。2006-12-29新民网转载青年报范彦萍同期报道明确记原泳池已加一顶“帽子”、拟作恒温泳池，能说明当时已有加盖，不能确定具体施工起止、竣工日或材料。

旧KIC运营站“游泳馆”页面由站点导航及图片引用建立身份；2011存档北入口照可见浅石阶梯体、中央单拱及上排窄窗。归档年份不是摄影日期，未把相邻体育馆的三拱门面移来。2013高位原照显示现代屋盖、南折角砖墙及北附体池侧红砖与小尖顶；北外侧和池侧是不同立面，不镜像同一入口。2024低分辨率高位图用于中心分区与大轮廓，不逐窗定尺寸。

地图原源外包约54.531×92.753米，面积4258.263平方米；源25.918米为预测高度，不当实测。模型高程、遮挡开口、屋盖曲率和装饰尺度分别在作者参数中标明估计。参考照片、整页网页与PDF只留私有研究缓存，不作为贴图或随库分发。

## 独立源与地图

仅替换宏块14-13722-6690的泳馆1666，UUID `b9c92109-e268-4f45-bf51-22dc951a6c22`。该真实near组有5个owner，另4个邻体保留；泳馆北侧体育馆1558与西侧主场分别保持原有细化模型。原始城市数据及GLB不修改。

18顶点的原源显示掩膜产生16个新增裁剪三角，全目录使用218／224行；原202行12,928字节不变，无需再次扩大生产GPU容量。地面碰撞仅依据最终三档真实低位几何，未开放室内若需保守导航填充单独记述，不把现代屋盖压到周边地面。西北路段接近源边界，不能套用上一栋建筑的道路宽度或虚构大台阶。

## 最终模型与原生检查

最终原始／网页模型28,590个三角面、远景19,430个，四资产共3,715,151字节，最高约12.872米，属于作者估计。源码独立目录重建、压缩前后有向FLOAT32三角比较、实体构件绕序和序列化射线分别核验。Blender从最终raw导入，保存后实际重开，再对同一文件输出八个角度；Root逐张实际查看，见[native-visual-review.json](native-visual-review.json)。

原生入口近景曾暴露北端高低屋面间两窄端及相邻转角未封闭，已由实际射线定位并补实体收口后重出最终资产与全套图片。早期私有版本不作为最终通过依据；独立审查与作者修订记录保留问题和修复范围。

地面使用真实三档0—2米几何及单独声明的未开放室内保守填充。道路紧贴边界，因此采用0.05米数值余量和0.02米保拓扑简化，未收缩真实低位构件。另有两处道路控制点与保留原源1870本身相交，作为上下文排除点记录，不宣称整片现有地图道路全通。最终面积、探针、邻源及相机参数见[footprint-review.json](footprint-review.json)。

## 目录与剩余任务

按区目录80处、16区，杨浦5处、黄浦28处。原40处保留既有漫游，40件候选提供近似定位的全局俯瞰；README所有模型“查看网页”入口均为index主地图。灯牌沿用同一登记与12像素编号布局，视野内常显并可独立点选。

34项已交付制作任务及46项库存退出重复制作，10条已完成主楼不重复列入；活动名录／构件仍1048条。本源不在原1036条具名快照内，具名关联仍19条、待查1017条。b1-021仅移除已完成的泳馆任务，已列主场局部边界和门台细部调查保持原文，不关闭整条体育中心名录；其他完成范围及原始名录不变。

下一项是旧上海市博物馆江湾馆舍（长海路174号，今长海医院内旧馆舍）；与人民广场上海博物馆及四川北路复馆旧址分开。已做文献和2011外观照私预研，现代两层翼与历史单层方案、地图栋界和原设计高程仍待逐项核对。
