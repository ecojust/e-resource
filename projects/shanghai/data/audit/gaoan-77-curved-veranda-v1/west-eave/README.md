# 西墙六个木檐托与烟囱胸墙

正面两根主要木柱的间距用独立街景估为约3.13米。按此比例校正侧照，西墙两端石托的中心相距约4.64米，石托中心高约9.32米。木架和窗框的相对高度仍受拍摄俯仰、镜头和树木遮挡影响。

六个木托各有水平横木、斜撑和下端石座。斜撑与横木之间的空隙可以透见背景。2012年11月及2018年4月的侧照均可辨出这一构造。烟囱中段灰白石腰的厚度由四张照片边线分别反算，统一尺度后为0.21至0.22米。石腰宽端下方的小石托依照片近似收进，石腰另一端下接红砖。

`three-roles.json`汇总原始模型、网页近档独立解码与远档独立解码的结果。四张照片上的76个原像素包括24个用于平面配准的石座中心。其余52点选在砖、斜木、石腰等部位。三档的首个交点分别有73、73、74处与记录的材料一致。余项涉及砖缝、石座与浅色墙面交界，可在各档的`*-photo-pixels.json`逐点复核。另对六处木托分别穿过斜撑、横木和开口，三档各18项均符合。短截面记录在`*-sections.json`。

组件源码、像点、四张侧照的相机拟合与复查脚本位于本栋`measurements`和`source`目录。文章刊于2022年，所用侧照与2013年8月31日的拍摄属同一底片，只计一站。
