# 隆昌路362号街门

2012年12月23日的外部照片同时拍到两扇浅绿铁门和右侧“362 隆昌路”绿牌。左扇中间另有一条较粗的竖管。右门套上段出现斜向浅缝，底部刷浅色。两门扇的展开程度由同一张照片的十四处横杆、竖杆、杆尖位置估计。采用净洞宽2.80米时，重投偏差中位为1.48像素，最大4.53像素。照片没有给出门洞完整净高，模型取3.05米。[2012年照片及摄影者署名](https://www.flickr.com/photos/jch-00/8299072261/)

实测从图中选了左右铁扇的前后竖管、门套石面与刷白基脚、门牌绿地与白字和中央空隙。两档各有86个独立闭体。逐位置的首击材质和进深见[两档判读](entrance-component-rays.json)。
