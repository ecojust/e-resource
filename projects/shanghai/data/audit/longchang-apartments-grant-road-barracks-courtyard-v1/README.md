# 隆昌公寓北院的模型复核

原始模型含107,952个三角面，远景含66,648个。近景5,617件、远景4,010件立体逐一通过闭边、面朝向和正体积检查。两幅原创重复纹理用于砖面与水刷石。压缩文件经独立解码，按材质核回每个三角面的顶点与方向。[可编辑实体](editable-solids.json) · [压缩复核](mesh-decode-comparisons.json)

2012年院内短端照选取28个栏板、檐边与铺地像点。原始及解码近景各21处首先落在预期表面，远景22处；差异主要在前景梯塔的外挑尺度，另有一处近景铁架遮挡。单座梯塔的独立斜照选取30个点，三档各25处吻合。余下五点位于斜梯栏缘或上檐附近。原照控制点的中位拟合残差为短端1.53像素、梯塔1.72像素，两张照片均为1024像素宽。[逐束测量](court/three-role-photo-check.json)

三档外街面各388处首次命中符合预期，覆盖127个窗玻璃、127个窗台、127个邻砖位置及七个实墙或屋顶边界控制。362号门套另有每档15处，共45处吻合。沿街门位取模型中点，是依据幅宽作的展示安排。[外墙测证](street-and-returns-three-roles.json) · [门套测证](west-entrance/README.md)
