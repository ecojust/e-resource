# 两版查看器的普通网页实测

手机和桌面首屏均能完整看见半圆山墙、中央弧窗、两侧窗及墙根。正面镜对称显示中央窗左右凸饰，专项镜只取弧窗上部和上方三组凸砖。两版查看器切到远档后仍保留中央竖梃。

两版查看器分别在1060 × 730的桌面及390 × 844的手机上打开同一份页面。每组记录首屏、近景三个镜位、远景三个镜位，共28张实图。每个桌面版本均实际保存原始、网页、远景和Blender文件并核对文件名、大小和SHA-256。四组均通过一次清单请求失败后的正常重试。[全部镜位对照](comparison-415.jpg) · [逐图、页面响应及下载记录](browser-comparison.json)
