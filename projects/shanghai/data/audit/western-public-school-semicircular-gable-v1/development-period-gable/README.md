# 西童公学北四川路校舍半圆山墙与三联窗

原图中，北四川路校舍一端有一面宽半圆山墙。中窗抬高，略拱的窗楣和中央突出的楔形构件与两旁的平窗有所区别；两肩后方能看见黑白瓦坡。图版出自1930年第三版《Shanghai of To-day》，馆藏编目为1928年影像。[原版图29](https://www.virtualshanghai.net/Photos/Images?ID=15111) · [书目](https://www.virtualshanghai.net/References/Bibliography?ID=408) · [官方名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

近景模型3,824个三角面，远景模型2,304个。三份交付网格各检验85处窗框、玻璃、冠顶饰、弧檐及其外的天空。绝对尺度、看不见的背面厚度与瓦面进深据影像比例估算。[近景GLB](western-school-gable-near.glb) · [远景GLB](western-school-gable-far.glb)
