# 上海建筑轮廓数据 · Overture Maps

在线建筑轮廓来自 Overture Maps 官方 PMTiles，按视野请求数据。已实测奉贤、青浦、松江、崇明等外围区域存在大量建筑轮廓，补充 OSM 稀疏覆盖。

- 数据坐标：WGS84 / EPSG:4326。
- 当前核验版本：2026-10-21.0；在线端应从 STAC 获取最新版本，旧版瓦片约保留 60 天。
- 瓦片图层：`building`、`building_part`，源最大缩放级别 14。
- 建筑主题许可：ODbL 1.0。需保留 © OpenStreetMap contributors、© Overture Maps Foundation 署名。
- 上海大量轮廓来自 Qian Shi 等人的 East Asian Buildings，DOI:10.5281/zenodo.8174931，原数据采用 CC BY4.0。
- 官方许可说明：https://docs.overturemaps.org/attribution/#buildings

## 本地样本

按 16 区各一处已核验道路起点提取约 1 × 1 公里建筑样本，共 **8322** 个建筑/部件要素。按轮廓质心选择，保留完整轮廓及孔洞；跨瓦片切片按 Overture ID 合并。这些本地文件是区级中心街区样本，不代表离线保存了整个区。在线页面仍可按需浏览上海其他位置的建筑。

多数建筑没有实测高度或层数，页面和 GLB 中的默认高度属于示意估算。数据版本日期也不等于建筑实测日期。模型用于城市可视化，不用于测绘或工程计算。

本地提取脚本：`fetch_overture_neighborhoods.py`；依赖 `pmtiles`、`mapbox-vector-tile`、`shapely`。每个 GeoJSON 保留逐要素来源和高度属性，便于复核。
