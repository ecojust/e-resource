# 外滩近景几何诊断与逐栋替换依据

用户看到“小方块”的判断准确：原工程完成的是城市覆盖和LoD1体量，并未重建普通建筑的建筑构造。

## 为什么现有模型看起来是方块

- `build_district_models.py::Mesh.polygon`只在同一height生成平屋顶、底板和竖直墙，沒有体块退台、柱廊、拱窗、凹窗、屋顶亭、穹顶或檐口。全域平均每个建筑/部件仅15.04个三角形，接近最简单挤出盒子的12面三角形。
- `build_fullcity_models.py`中的roof变量只按高度选择三种屋面材质，并不解析`roof_shape`、`roof_height`、`roof_direction`、`roof_orientation`等几何属性。网格压缩保留了已有三角形，不能把缺失建筑构造恢复出来。
- 海关500m内341个源要素只有3个building_part、1个显式height、1个roof_shape。指定十栋中仅中国银行东塔有一个part，其余无部件。准确地面轮廓不足以重建屋顶与立面。
- 旧流程将OSM楼层数乘3.2m并先于外部高度估计采用。它把汇丰全体压成22.4m、和平北楼压成35.2m等单一体块；历史建筑高层高、局部塔楼/穹顶、地下层与实际地上层数的差异都没有表达。
- 通用窗格shader只改变像素颜色；不会产生真实凹窗、檐口投影、柱间空隙或屋顶轮廓。不能用更多城市格网或仅细分平墙来解决。

## 可用数据与坐标

`bund-candidates.json`给出10栋实时OSM轮廓、庭院孔洞、OSM门牌、Overture UUID、parts、现有高度代理、源owner格和高度证据。`bund-candidate-footprints.geojson`可直接在GIS中复核。OSM与原Overture量化足迹IoU在0.981–0.991；二者均为WGS84，无GCJ02偏移补偿。

局部模型坐标使用与现有viewer相同的WGS84 Mercator差值×cos(锚点纬度)：二维`[east,north]`映射glTF`[east,height,-north]`。EPSG32651只用于面积和MRR标量长度；UTM网格北不能作为模型旋转。134个顶点经独立pyproj往返校验，最大局部误差2.70e-9m，front-edge角仅有0.000466°舍入差。

## 必须按建筑分别处理的几何

汇丰需要五层主体、中央七层/穹顶与三角山花、六根通层爱奥尼柱，并保留后部与庭院；海关保留现有79.2m官方尺寸分段与前楼/后翼范围；华俄道胜需要真实柱式门廊/山花而非统一网格窗。字林西报需要底部粗石巨券、上下分部、强出檐及顶层双亭；麦加利需要照片可识别的柱式与拱窗层级。和平南楼的转角亭、长南京路侧面及屋顶必须独立于和平北楼的阶梯塔身和铜绿金字塔。中国银行需区分临江东塔与西翼，恢复上部退台及中国式檐口。总会的六根巨柱、五组三联拱窗和双端开敞亭，以及有利大楼的双街面、东北角亭与不同楼层窗型，都需要真实几何。

中国银行有一个数据陷阱：命名主footprint只覆盖约28×20m的东塔，唯一part带错误的旧名Sassoon House；西翼另为OSMway177998983/UUID5ffad866-ee1e-43e1-8665-fa818bac102b。该西翼在candidate.related_geometries中提供，与东塔使用同一anchor；只在作者确认已建模时合并其替换ID。西翼OSM9层与建筑文字4层冲突，保留为未解决证据，不伪造准确层高。

## 精确替换与验收

九栋新增模型及既有海关集中在owner格14/13720/6693与6694。只有在模型作者确认完整覆盖候选footprint、GLB存在且头部/大小合格后，`build_bund_city_patches.py`才会合并原五地标exclusions并重建受影响源格；不得按80m或任意半径删除周边建筑。中国银行西翼是需要明确确认的optional group。

验收应看同一机位的近景对比：屋顶外轮廓、柱间空隙、窗洞深度、檐口投影、真实开间节奏、街角入口与既有地图边线。不能用文件数、覆盖建筑数或仅提高三角形数量替代这种视觉与几何验收。所有照片估计的高度和构件尺寸应在元数据中标明，公开来源未给出的尺寸不声称实测。
