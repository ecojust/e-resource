# v9：龙华塔逐栋复原

本版[龙华塔漫游](https://rawcdn.githack.com/ecojust/e-resource/72f845db12482c0c7a3c1fccca3f2dd4fb4b8336/projects/shanghai/index.html#landmark=xuhui-longhua-pagoda&mode=walk)对应应用提交`72f845db12482c0c7a3c1fccca3f2dd4fb4b8336`，精选导航25项、逐栋街区建筑6栋。实际验收只覆盖记录的模型、机位及加载过程；[验收范围](../../data/audit/precise-buildings-v9/longhua/README.md)。

塔身七层八面，第二至七层形成六道高架回廊。贯通门洞与盲壁龛分别建模，逐层门向转换不等于其地理朝向已经证实。曲檐、斗栱、回廊栏杆和七重相轮依据现代照片及官方记述构造，未把照片的光影作为贴图。

40.64m采用官方志书公布的名义总高，并非本项目实测；门洞朝向的地理相位、层间比例和隐蔽处仍有推定。官方材料还记有40.6m和41.4m等口径，基准未说明，不将其平均成测绘值。原城市栅格高度也不作为塔高实测。保留原唯一源轮廓，塔与龙华寺及周边楼分开；原八角轮廓究竟对应塔身、檐线或台基仍有限制。室内、被遮挡底部及不可见构造不声称已复原。
