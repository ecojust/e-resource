    Description
    Orientation of the roof surface(s) as the direction of the roof ridge.

    roof:orientation specifies the orientation of a roof shape specified with roof:shape=*. This tag describes the direction of the roof ridge, not the roof surface(s) themselves. In most buildings, this roof ridge runs parallel to the longer of two building edges, which means along.

    In contrast, the alternative roof:direction=* describes the orientation of the roof surface(s) itself. In the case of pent roofs (skillion) and square buildings, capturing with roof:orientation is not suitable; roof:direction must be used here. These two tags are alternatives, it is sufficient to use one of them.

    Values

    Value Description Example Count
    along The roof ridge runs parallel to the longer of two building edges.
    across The roof ridge runs perpendicular to the longer of two building edges, parallel to the shorter.

    Rendering

    The default value differs depending on the 3D application. Osmbuildings.org changed the default focus to across in 2021 (example).
