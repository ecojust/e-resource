OSM Tag History
The key
roof:height
=*
describes the height of a building's roof (excluding antennas, spires and other equipment mounted on it).
Don't forget that roof:height is a part of the total building height. For example a building might be 5 meters tall with tag
height
=
5
and have a roof:height of 2 meters with tag
roof:height
=
2
. This would describe a building with a 3m façade and a 2m roof, totalling 5m from ground to the tallest part of the roof.
Tagging
The height of a
building
=*
or
building:part
=*
roof is added with tag
roof:height
=*
.
Units
The
default unit
is meters. No need to add the unit if you are using this unit.
For height values with decimal places, use the
period character
as decimal separator.
Incorrect
Explanation
Correct
roof:height=4m
The space between value and unit is missing + unit is useless.
roof:height
=
4
roof:height=0,8
The comma is used as wrong decimal separator.
roof:height
=
0.8
