# 全市逐要素复原台账

本台账逐条记录 **1,796,419 个基线渲染要素**，覆盖16区、1,708个宏块。每条记录可追溯到源建筑／部件唯一标识、宏块、局部编号和原始要素表的 SHA-256；不是从导航入口数量推算出来的覆盖率。

这是一份身份与登记关系台账，**不是新增的精细复原验收**。已复原源要素数量和完成百分比仍为未知。照片、尺寸、几何、材质、地面及实际漫游需要按对象继续核验；台账不会把历史目录里的 accepted 声明自动升级为本次验收。

## 文件与查询

- [index.json](index.json)：所有输入哈希、区级分片哈希、宏块索引、40个模型与源要素的对应关系、五个独立候选和地面水系状态。
- `310101.jsonl.gz` 等16个按区压缩分片：每行一个渲染要素，保留完整源 ID，不存复制的几何。
- [source-roles.json](source-roles.json)：早期地标替换排除的源要素、不可渲染父体及父体剩余表示。

在 `projects/shanghai` 目录执行：

```bash
# 查询孙中山故居：可查询已登记的主楼替换与漫游模型关联。
python tools/feature_restoration_ledger.py --key building:9bbed57b-ae4b-4abc-be77-0b5444bf0a9a

# 重建（需要全部要素表与 READY 文件；缺文件会报错，不跳过）。
python tools/feature_restoration_ledger.py

# 全量重建到临时目录，逐字节比较已发布结果。
python tools/feature_restoration_ledger.py --check
python tests/feature-restoration-ledger.test.py
```

稀疏检出至少需要 `assets/city-detail/macros/*/feature-table.json.gz` 和 `*/READY.json`，以及脚本引用的清单、普通精模目录与候选清单。查询已发布台账只需要本目录，不下载模型。Gzip 时间戳固定为0，重建结果可复现；完整检查通过后才写入发布目录。

## 如何理解记录

| 字段 | 含义 |
|---|---|
| `key` | 原始 `building:UUID` 或 `building_part:UUID`，不能用建筑名称代替 |
| `macro`、`local_id` | 在哈希绑定的源要素表中定位原记录；其中保留来源版本、许可、高度依据和几何 |
| `residual` | 是否为不可渲染父体生成的剩余足迹表示，不是新增楼宇 |
| `parent_building_id` | 源数据提供的父建筑标识；缺失时为 null，不猜测关系 |
| `height_quality` | 源高度质量分类；遥感、楼层推估和默认值不当作实测 |
| `representation` | `baseline-generated` 为生成底图；`registered-precise-replacement` 为已有精模替换登记 |
| `model_id` | 替换登记对应的模型；必须通过源 key、局部 ID、宏块及基线哈希核对 |
| `candidate_ids` | 只有明确源身份的独立候选才关联，候选不改变基线表示或验收状态 |
| `acceptance_revalidated` | 本次均为 false：只核查身份与清单，不冒充重新验收模型 |

两个历史接入途径分别保留：26个精模替换登记对应26个基线源要素；14个早期地标对应103个被排除的源标识（98个可渲染要素及5个不可渲染父体）。这129个关联源标识不是129栋建筑，也不是129项本次复原完成记录。它们共同对应当前40个导航模型。

孙中山故居和徐家汇藏书楼南楼已转为精模替换登记；五个未接入的独立候选仍不分配到相邻建筑或整个院落。候选的尺寸、局部模型范围和缺失资料继续以各自模型说明为准。

## 数量守恒与地面水系

源唯一地上记录 **1,796,667**，其中不可渲染父体 **551**。基线生成过程中排除 **98** 个可渲染地标源要素，并为父体生成 **401** 个剩余足迹表示：

`1,796,667 − 551 − 98 + 401 = 1,796,419`

551个不可渲染父体由401个生成剩余表示的父体、5个随地标排除的父体和145个没有生成表示的父体组成。不可渲染父体全集与剩余表示、部分地标排除记录存在重叠，不能把这些集合直接相加。脚本核验集合关系、全局唯一键、局部 ID 顺序、各区数量，以及精模登记哈希；遇到重复、身份漂移、缺块或损坏会失败。

16区地面／水系共410,447个三角面，仍是地图水面及非水域的平面代理。没有实测垂直基准、地形高程、河床及岸线工程断面，不能声明地面与江河已精细复原。完整的后续验收还需要逐对象绑定照片、测量或明确标注的估计依据、几何与材质检查，以及地面、碰撞和实际行走证据。
