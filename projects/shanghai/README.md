## 漫游与模型使用

各表的“查看网页”从该建筑已登记的起点进入第三人称漫游；地图和远程模型需要联网。当前供室外观赏漫游，门廊、露台和台阶的外观不表示已经支持精确登阶或室内游览，部分边缘的行走阻挡可能与模型不完全贴合。

新增长宁区**哥伦比亚乡村俱乐部主楼**，已接入第三人称漫游并通过模型与本地浏览器验收。按建筑师平剖面和照片分别构造北门厅、圆端楼梯间、南拱廊和后退山花、露台、红瓦屋顶及保留的东侧增建。
