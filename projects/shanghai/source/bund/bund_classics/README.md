# 上海总会、有利大楼与字林西报大楼

这是基于真实 OSM 轮廓、历史建筑志以及实景照片的独立建筑模型。窗洞有凹入玻璃、门窗框、窗台和侧壁；柱廊、檐口、阳台、屋顶亭均为可见几何。没有生成随机窗格，也没有把参考照片当纹理贴到立方体上。

- `shanghai-club.glb`：外滩 2 号上海总会历史楼。中央六根爱奥尼柱，五个中央主开间、两端翼部、五组三联阁楼拱窗、两座开敞风亭、深色变形芒萨尔屋顶。官方地方志确认地上五层、地下一层。报道高度 26.9 m 没有说明终点；模型将屋脊设为 26.9 m、风亭顶设为 35 m，二者组合是照片比例解释，不能作为精测高度。
- `union-building.glb`：外滩 3 号有利大楼。保留东北角切角轮廓、临江与广东路双立面、主楼六层、四/六层拱窗、出挑主檐、铁栏阳台、四角双柱亭和葫芦状塔冠。45.75 m 来自次级资料，主檐及塔顶分段均为估计；部分入口窗拱按近年照片与地方志文字不一致处采用可见实景。
- `north-china-daily-news.glb`：外滩 17 号字林西报大楼 / 友邦大厦。临江实际边线只有 17.415 m，保留不等宽窗轴、底部两层粗石券窗与槽柱、五层主窗、人物托座、凹入敞廊及双塔亭；侧面沿真实约 53 m 深地块。OSM 的 10 层与文字资料的 9 层口径不一致，按照片层级制作。40 m 为模型高度估计，未获得实测高度来源。

两栋均以最新 OSM 地块的质心为经纬度锚点，坐标已烘焙为 glTF 的东/上/南方向。`footprints.json` 保留完整来源、真实边界和替换 UUID。只替换对应 UUID；不能按半径删除临近建筑。地块局部坐标为与浏览器一致的 Web Mercator 差值乘锚点纬度余弦，避免 UTM 网格北造成额外旋转。

`architecture-evidence.json` 列出地方志原文、报道数字、已确认结构与未知项；`reference-photos.json` 列出照片作者、许可和原页。模型没有嵌入参考照片或外部纹理。OSM 衍生轮廓应保留 © OpenStreetMap contributors / ODbL-1.0 归属。

用 Blender 运行：

```sh
BUND_CLASSICS_OUTPUT=./output blender --background --python build_classics.py
```

`BUND_CLASSICS_RENDER=0` 可只导出模型。脚本依赖同目录 `mesh_utils.py` 和 `footprints.json`，无需网络或绝对路径。渲染背景平面、灯和相机仅用于检查，不导出到 GLB。`.blend` 为无验证场景的原生模型。

17 号使用 `build_news.py` 和 `news-footprint.json`，共享前述两个 Python 文件；调用方法相同。`validate_glb.py` 用标准 Python 与 NumPy 检查导出后的有限坐标、法线、零面积三角形、地面高度、文件大小与独立加载所需资源。

小型浮雕、石材纹样、完整背立面及内部空间未测绘；本模型属于建筑辨识细节重建，不是文保实测成果。
