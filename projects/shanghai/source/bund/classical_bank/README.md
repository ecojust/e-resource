# 外滩古典银行精细样板

包含汇丰大楼（外滩12号，现浦发银行）和华俄道胜银行大楼（外滩15号，现中国外汇交易中心）的独立建模文件。

`hsbc/` 与 `russo/` 各有原生 `.blend`、未压缩 `.glb`、正立面/斜视/街面细节渲染和 `model.json`。`sources.json` 记录照片、原立面图、OSM轮廓及各自许可；照片原件保存在 `references/`，便于逐项对照。

## 模型结构

- 汇丰：三个拱形入口、六根独立通高爱奥尼柱、后退3.1米的柱廊背墙、五层主体立面及翼楼底部独立夹层窗、檐口托牙、栏杆、方形鼓座、曲面穹顶与顶部构件。OSM外轮廓和中庭孔洞保留。
- 华俄道胜：五开间、中央两根圆柱、三组下层拱窗与上层大窗、两翼窄窗及山花、凸出门廊、券石/拱肩浅浮雕、密集托牙及屋顶女儿墙。
- 窗洞实际从墙体中留空，墙厚0.62米，玻璃后退0.57米；窗框、窗槛、曲面拱券、圆柱和栏杆都是几何。没有在不透明实体盒子前贴一张窗户图片。
- 街道玻璃、窗帘、金属窗框、石材和凹缝分材质。石材颜色和风化没有逐像素仿真；装饰卷草是依照照片辨识的几何解释，不能当作雕塑测绘。

## 坐标与精度

GLB为米制，**X东、Y上、Z南**，原点对应 `model.json` 的WGS84锚点，地面为0。原生Blender使用Z向上；导出器已转换坐标轴。使用City代理给出的viewer兼容真东/真北局部米制坐标，未直接把UTM网格北当作真北。

沿江正立面宽由OSM边线确定：汇丰约83.375米、华俄道胜约34.688米。OSM并非测绘级图纸，但这些宽度/朝向有可追溯几何。**目前没有核验到可靠的垂直测量资料，模型的楼层、檐口、穹顶和总高均为照片比例推定**；不能把来源中的楼层数乘以通用层高冒充实测。现状照片优先于1920年的汇丰原设计图。

侧后墙开窗节奏、不可见装饰深度及简化卷草明确属于推定部分。没有重建银行室内、汇丰镶嵌画、铜狮的准确雕塑形态或真实的窗户纹理。

## 重建

使用Blender 4.3或兼容版本，无第三方Blender插件：

```sh
blender -b -t 4 --python build_classical_banks.py -- --building hsbc --render
blender -b -t 4 --python build_classical_banks.py -- --building russo --render
```

可加 `--output /你的输出目录`，或设置环境变量 `CLASSICAL_BANK_OUTPUT_DIR`。所有输入仍从脚本所在目录读取，输出在指定目录下的 `hsbc/`、`russo/` 中；目录可整体搬迁。

`geometry-input.json` 已包括归一到建筑局部坐标的轮廓、庭院孔洞、屋面三角化和原始来源；不需要联网或私有缓存。`assets/inscriptions-subset.otf` 是随附的Noto Serif CJK铭牌字形子集（SIL OFL许可同目录），中文铭牌最终转为网格。GLB不依赖外部字体或图片纹理。

渲染的地面、灯光和相机仅用于展示，不导出到GLB。模型为街面可近看的独立建筑样板，尚未接入主项目或修改Git仓库。
