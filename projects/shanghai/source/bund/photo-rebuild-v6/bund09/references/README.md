# 外滩9号照片来源

三张JPEG原图均经`view_image`实际查看；下载字节数及SHA1与Commons API一致。元数据、许可URL、下载记录和本地SHA256见 [manifest.json](manifest.json) 及各`*-source.json`。不要把上传日期当摄影日期。

1. **Suicasmo，2025-05-01，CC0**：[Commons来源页](https://commons.wikimedia.org/wiki/File:China_Merchants_Building,_Shanghai_20250501.jpg)，[原图](bund09-20250501-suicasmo-original.jpg)。现状外观主参考，显示正面与树遮挡的南侧；许可为[CC0](https://creativecommons.org/publicdomain/zero/1.0/)。
2. **Legolas1024，2013-12-29，CC BY-SA 4.0**：[Commons来源页](https://commons.wikimedia.org/w/index.php?curid=71693405)，[正面原图](bund09-20131229-front-legolas-original.jpg)。用于廊跨、柱身与后墙窗孔计数；许可为[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。
3. **Legolas1024，2013-12-29，CC BY-SA 4.0**：[Commons来源页](https://commons.wikimedia.org/wiki/File:%E8%BD%AE%E8%88%B9%E6%8B%9B%E5%95%86%E5%B1%80%E5%A4%A7%E6%A5%BC%C2%B7%E4%B8%8A%E6%B5%B7%E5%A4%96%E6%BB%A9.jpg)，[北向斜视原图](bund09-20131229-oblique-legolas-original.jpg)。用于北侧三窗轴、屋面构件与空间关系；许可为[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。

[inspection-front-upper-columns.jpg](inspection-front-upper-columns.jpg)是第2张的检查裁图，裁切原图像素框`[950,850,4250,1450]`并重新编码JPEG，没有透视校正或几何标注。原作者Legolas1024，改动为裁切，继续按CC BY-SA 4.0标注。裁图可辨上层12处柱身，其中中央8处为四组双柱，两端各2处；有些是紧贴砖墩的柱身，不能全部称独立柱。

公开分发这些照片或其裁图时保留相应作者、来源、许可与改动说明；若把BY-SA照片用于派生纹理，还应落实相应许可要求。可优先用CC0的P01作当代照片纹理，旧照片作有日期的几何观察。

许可仅覆盖此清单所列Commons作品。官方历史文章可阅读不代表其照片获得开放许可；本研究没有下载官方网页照片。上级目录HTML/TXT仅是内部研究缓存，不是默认可公开素材。2013照片中的店招、橱窗人物和街景广告也不能当作2025固定建筑细节。
