## 历史与尺度

[乐活外滩2019阅读建筑文章](https://www.sohu.com/a/295022095_683080)可直接访问，记述德和洋行设计、1925建成、钢筋混凝土框架；并明确1–2层拱券与方窗交错、3–5层贯通壁柱、5–6层深挑檐。它是具名街区文化栏目经搜狐发布的二级资料，不冒充政府测绘。[商务旅行杂志/新浪2010](https://style.sina.com.cn/lei/travel/2010-07-29/153665248.shtml)另支持1925建成及德和洋行设计。

维基中英条目给出6层、占地1280㎡、建筑面积5484㎡，仅作二级尺度对照。其英文参考的[2009建筑站存档](https://web.archive.org/web/20090304021704/http://www.chinese-architecture.info/BUND/SH-BU-004.htm)却写late1921完成，**年代冲突保留，不能包装成已核实的单一史实**。没有找到可引用的绝对总高测量值；高度必须注明照片比例估计。

现有主项目`bund-candidates.json`只有原10栋、没有05，不借用邻楼尺寸。冻结公开OSM way178408821（中山东一路5号）面积约1309.72㎡，边界包围约61.55×24.94m（UTM量度，仅地图精度），POI476151248在轮廓外约6.89m，不能当模型中心。真正建模采用父任务冻结`../geometry-input.json`的Mercator米制坐标与**20.142632898m临江边**，保留原16节点与退台。OSM标7层而照片临江面可数6层；未经核实不能增加第七个完整临江层。

## 可观测与推定

详见`geometry-evidence.json`。正面必须包含四大开间、两侧各贯通三层的三面凸窗、中央三层通高壁柱、双三角山花及弧顶六层窗、中央两小窗及石栏杆、下部双拱窗与两侧门柱。北侧近前部是大面积盲墙，不复制南侧成排阳台。南侧较远开间遮挡与透视较强，不能声称全部数量已实测。

绝对高度、墙厚、凸窗投影深度、雕饰小尺度和后部屋顶仍为估计；柱头采用照片里可见的简化卷曲/平板结构，不添无据的繁复花叶。照片并非消光照PBR材质；本阶段优先复原三维构件，不整面投射街灯、行人和汽车。
