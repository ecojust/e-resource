## 历史和尺寸依据

上海市地方志办公室《上海名建筑志》2009-10-22 条目，由 Internet Archive 保存的原官方正文实际读取。文章明确地址、通和洋行设计、1906 年开工次年建成、四层以及五个中央方门；原文 URL 和存档 URL 见 `OFFICIAL_GAZETTE_2009`。该资料没有提供实测檐高、楼顶剖面或石材种类。英文维基另述 1905 年火灾、1908 年开业，属于不同事件和次级来源；不将这些日期直接合并。724 m² 也是次级资料的占地说法，不能替换冻结 OSM 轮廓面积 705.54 m²。

`../geometry-input.json` 由独立地理核对冻结。保留原五边、版本及城市要素对应；现有城市模型 22.4 m 来自 7 层属性估算，而四层主体由照片和官方文字共同确认。后续建筑高度采用照片尺度校准并给出误差范围，均非测绘级尺寸。
