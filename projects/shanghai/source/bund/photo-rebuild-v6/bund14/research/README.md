# 外滩14号交通银行大楼：逐栋照片建模资料

本资料包以 **2025年5月1日的东立面照片**为当前外观基准，用2007—2014年的斜视与2010年俯拍补充稳定几何。8张原图均已实际查看，均有Commons许可记录；本目录没有生成模型。逐项证据见 [observation-ledger.json](observation-ledger.json)，完整来源、作者、日期、许可及SHA见 [sources.json](sources.json)。

## 可以落实到几何的特征

- 正面四排规则层是 **8个窗轴，1+2+2+2+1**：两端窄窗、两翼各两宽窗、中央两宽窗。低层中央为合并的大入口，不能每层机械排8窗。
- 可辨四排规则窗、一排高窗带和黑色低层；文献相互印证为 **6层主体，中央另加2层塔体**。塔窗是两排狭长窗，与主楼宽窗不同。
- 宽墙肢、窗间和塔冠上有连续窄凸脊及浅沟；窗洞有退距、深色细框、上横亮和竖梃，薄窗台向外挑出。细部应有实际几何厚度。
- 中央塔冠逐级收窄，轴心竖柱更高，两端也有薄片式高起构件和阶梯收头。轴心两组圆弧凸出饰件带水平分节，下组更长，**功能未核实**。
- 入口有高矩形黑色大框、多重内退边、金色纵格栅及重复节点，下面为深色双扇门；字牌为“上海市总工会”，小门牌为14。
- 文字资料称**底层门框黑色大理石，其余墙面白水泥粉刷**。照片显示浅色平滑墙面；不可把全部前后墙铺成石块纹理。照片暖/冷色受天气与相机影响，不是材质测色结果。

## 侧后部与地图尺度

2010南斜视可以确认长南翼向西延伸。2012北斜视和2007南斜视显示中央塔有实体进深、侧窗和回墙。2010东方明珠俯拍中，14号在左下，可通过阶梯塔冠、黑色大入口定位，能看到塔部和部分后翼屋面。它补充了三维体量，仍不能数清西端后立面的全部窗列，也不能证明2025屋面设备与2010相同。

北侧相邻的现代 **外滩公共服务中心是另一栋建筑**。精确地理输入在 [../geometry-input.json](../geometry-input.json)：OSM way **178405872 v7**，目标要素 **building:930b1722-187d-4727-ad8b-303698ad37ee**，宏块 **14-13720-6694**。应保留原轮廓的西伸长翼和北侧凹口，不填成整块矩形，不按邻近半径删除其他楼。

冻结正面边长计算为 **23.174494470346758m**，适合作为照片拟合横向尺度；这是地图投影计算结果，**不是现场毫米级测量**。本目录早期 [osm-plan-metrics.json](osm-plan-metrics.json) 用近似投影，仅供交叉检查，建模坐标应遵循冻结geometry-input。

**尚无可核实的实测檐高或塔冠总高。** OSM的7层与旧全市模型22.4m为标签/层数推估，不能覆盖照片和文献的6+2体量。若以地图宽度和多张照片比例拟合米高、凹槽深度、后窗间距，应把值及控制点记录为推定，不能说成测绘。未核实搜索摘要中的“约30m”等不作为证据。

## 文献交叉核对

- [阿基米德FM / 搜狐号，2022-09-08](https://www.sohu.com/a/583498467_120539115)：主体6层、中间8层、钢筋混凝土框架、白水泥墙与黑大理石门框；1946开工、1948完成，鸿达洋行设计、陶馥记营造厂施工。它是二手介绍，不是施工图或测绘档案；同文“中间多一层”的措辞与6/8层表述有出入。
- [TravelChinaGuide，2026-02-13更新](https://www.travelchinaguide.com/attraction/shanghai/bund-architecture.htm)：再次明确6层主体+2层塔、白水泥与黑大理石门框。其“W-shaped”屋顶文字不宜替代照片中的阶梯剪影。
- [MOFBA，2021-06-04](https://www.mofba.org/2021/06/04/bank-of-communications-building-bund-no-14/)：补充C. H. Gonda、Art Deco及1948完成的历史线索，不提供尺寸。

现楼与Commons中1908年德华银行旧楼不同，旧楼古典构图不用于现楼建模。2012/2014旧照的上海银行招牌、线缆和泛光灯状况不能不加说明地与2025正面拼合。
