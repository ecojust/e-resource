# 14号逐窗玻璃照片采样

来源是Suicasmo于2025-05-01拍摄的Commons照片，CC0-1.0：[原始页面](https://commons.wikimedia.org/wiki/File:Bank_of_Communications_Building,_Shanghai_20250501.jpg)，[原图](../research/commons-164811484.jpg)。原JPEG字节未修改，嵌入模型只一次；本目录联络图是注明用途的研究分析图，不是替代立面贴图。

初始定位使用 [独立相机校准](../calibration-independent.json) 的3×4投影和真实玻璃退距0.31m。[初始联络图](initial-window-contact.png) 显示32个窗口各自的偏移，不能把整张照片按同一墙平面直接贴上。随后逐窗人工检查范围/横梃位置，分格选择可见玻璃，用四角拟合单独映射。[最终联络图](selected-window-contact.png) 的绿色轮廓是实际采样边界，均已逐项查看。

采用28窗、137个分格。第4层轴3、第3层轴3被灯杆/摄像头遮挡，第3层轴1接近照片裁切边界，第4层轴6有明显灯杆状反射/影，因此整窗保留材质玻璃。另17个小分格未得到足够大的保守玻璃区域，同样保留材质；没有补画被遮内容，也没有借用邻窗冒充对应窗。

选样边界只在玻璃内；侧边至少留3源像素，顶部/底部至少留5源像素，并用41×81点网格验证仍处于对应可见玻璃连通区。透明玻璃内部的真实百叶和反射保留，实体外框、竖梃和横梃不从照片复制，因此不产生第二套黑框。对不可可靠辨认的局部宁可保留材质，不随意声称完整纹理复原。

每个已有玻璃实体的顶点以独立四角单应矩阵映射。映射前后几何摘要相同，墙、窗洞、框厚、退距与层高均不改变。全部分格共享`PhotoFacade_Bund14Glass`材质和一张原图，模型报告列出每格四角和矩阵。

EXIF为6：存储5184×3456，显示3456×5184。UV按原始存储像素计算：`raw=(display_y,3455-display_x)`、`uv=(raw+0.5)/rawSize`；材质元数据含`rawSize/exifOrientation/uvConvention`。主项目现有`correctPhotographicTexture`按实际解码尺寸修正。静态检查会核对UV及原图SHA；实际浏览器/Blender解码方向还须由统一发布检查确认。
