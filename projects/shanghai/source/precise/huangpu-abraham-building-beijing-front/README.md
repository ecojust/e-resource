# 益丰洋行大楼北京东路西端券窗与切角

上海市房管局第二批优秀历史建筑名录在 2A018 行写“洋行／圆明园酒家／北京东路81号”。北京东路31–91号是工作名录所记的沿街门牌范围。2012 年重新开放时的报道以圆明园路88号称呼同一建筑。历史门牌另有独立线索。研究者据 1929 年 7 月的英文行名录追溯卡尔·克劳公司的办公室，把当时的 47 Peking Road 对为今天的北京东路81号。东侧怡和洋行单独成幢。[名录、历史门牌与报道原文收据](reference-review.json)

2012 年 5 月 17 日《劳动报》报道了修缮中恢复的孟莎式屋顶、门洞和砖墙线脚。模型取修缮后的外观。Livelikerw 于 2014 年 1 月 27 日拍摄的 4912 × 3264 街景中，可以沿底层的券窗从浅凸窗数到街角，在斜切角相邻两面辨出两枚圆窗。另一幅沿北京东路拍摄的街景用于核对建筑和街道的方位。原照和照片署名、许可、图幅及校验值见收据，分发的模型使用原创几何和材质。[主照片](https://commons.wikimedia.org/wiki/File:Yifeng_Galleria.JPG) · [街道对照](https://commons.wikimedia.org/wiki/File:East_Beijing_Road_near_the_Bund_2.jpg)

本次描绘浅凸窗至街角约 21 米的底层券列、上部砖壁与窗列、券石、切角上的两枚圆窗，以及屋面前缘和三处老虎窗。券石的凸出尺寸、门窗进深和细部标高依影像估计，店内陈列、长立面东段、东端转角、屋架内部和后侧商业扩建体仍留待独立取证。北京东路长墙的底图基线约 119 米，不能用此局部模型覆盖整栋。[地块、街墙轴线与相邻来源](footprint-review.json)

可编辑构件位于 [beijing_front.py](source/beijing_front.py)。[构建程序](source/build_model.py) 从同一组参数生成三档 GLB 和可单独编辑的 Blender 工程。独立的射线核对分别在原始、网页及远景网格上检查券顶、窗洞、檐口与转角。
