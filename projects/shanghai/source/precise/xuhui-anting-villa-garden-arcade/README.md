# 安亭别墅1号楼花园券廊

市房管局第四批优秀历史建筑名录把安亭路46号1号楼列为花园住宅，编号4D037，现名安亭别墅1号楼。同一张名录还将安亭路43号金司林公寓列在上一行。[第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2013年6月1日，Legolas1024从草坪拍下1号楼的花园正面。三孔券廊中间和画面右侧露出两道奶白色拱边、三处柱头、檐口红筒瓦和两盏几何形吊灯。后墙券门的弧顶比外层廊券低，前面隔着瓶形石栏。模型取这两跨。原照采用CC BY-SA 4.0授权；模型使用独立制作的实体和材质。[原片与署名](https://commons.wikimedia.org/wiki/File:No.46,_Anting_Rd,_Shanghai.jpg) · [许可](https://creativecommons.org/licenses/by-sa/4.0/)

两处券心在原照上相距约72.5像素。用原城521的27.16米长边粗校立面比例，取券心距约2.56米。廊深和栏板与柱列的距离为估计。原底图只给出整栋轮廓，庭院柱线尚无单独测量，本件作为局部模型浏览。[读图与比例](reference-review.json) · [原城坐标](placement-review.json)
