# 沁园邨新闸路总弄铁艺拱门与西侧铭牌墙

新闸路1124弄的总弄口通往1932年建成的沁园邨。街侧西墙的三块牌从左到右依次为优秀历史建筑牌、绿色弄号牌及阮玲玉故居纪念牌。故居本身在弄内9号。上海市第四批优秀历史建筑4B009登记还包含新闸路1106–1134号双号。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

## 建模范围与年代

模型保留两道有进深的花铁拱、两根通透的方铁柱、开启的东门扇、红色“沁園邨”立体字及木纹椭圆吊匾。西墙建至三块铭牌以外的一小段，墙脚红砖按层错缝。故居牌的花冠、奖章、槽柱与花饰托底均以几何建出。牌面的小号正文仅表现行列位置，标题、街名和弄号取自照片。

2015年12月影像中的两柱有浅色实心柱身和深色方饰。2021年2月街景与2022年唐敏拍摄的照片均显示通透铁柱。2018年的近照能辨认花铁、红字和木牌。独立的西门、沿街住宅、门房、弄内住宅与道路设备留作其他范围。[2018年总弄照片](https://commons.wikimedia.org/wiki/File:沁园村总弄.jpg) · [2021年铭牌照片](https://sghexport.shobserver.com/html/baijiahao/2021/04/26/417857.html) · [2022年街口照片](https://news.qq.com/rain/a/20220926A04SZ000) · [2023年修缮批复](https://www.jingan.gov.cn/govxxgk/JD4/2023-09-01/e803bf48-fc4b-43d2-b306-dfd6a706e0dd.html)

## 尺度与位置

独立的两站和三站街景交会分别得到柱距3.93米和4.03米。模型取3.94米，估计误差约0.5米。街对面整景与西墙近照分别反算的绿色门牌宽约0.60米。模型的花铁主拱高约4.19米。柱深、开启角、铁材截面和隐面厚度均为照片估计。门心取东经121.450172491°、北纬31.234945136°，绝对位置约有1至2米误差。[照片和来源](reference-review.json) · [图像校正与像点](measurements/photo-rectification.json) · [底图配准](footprint-review.json)

## 源码与许可

使用项目的建筑打包工具生成网页模型、远景模型、原始网格及可编辑Blender文件。重新量取像点可运行 `python measurements/rectify_entrance.py`。使用已安装的Blender、gltfpack和Open Image Denoise，可运行 `python source/build_model.py --out <输出目录> --audit <核验目录>`。纹理由源码生成，字体使用随附的Noto Serif CJK子集。项目许可证适用于原创几何和程序。研究照片的权利归各自作者，模型使用原创建模表面。[模型源码](source/build_model.py) · [字体许可](source/fonts/OFL.txt) · [地图边界与照片许可](reference-review.json)
