# 陕南邨西南转角住宅

陕西南路与复兴中路交叉口东北角的这座四层住宅属于原亚尔培公寓（King Albert Apartments）。上海市房屋管理局第二批表第71行列为2C010，原名与公布名均写“陕南村”，地址写陕西南路157–187号。黄浦区政府存档记整个组团为陕西南路151–187号。陕西南路213号的白尔登公寓另列第三批3C006。[房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [史料、原片和授权](reference-review.json)

黄浦区政府记载，十六栋蝶式点状四层住宅在1930年竣工，由列文设计，立面采用清水红砖和淡黄色水泥拉毛，屋顶铺红瓦。上海市地方志另记普爱堂于1932年投资建造，并描述主要居室朝南、端部设多边形窗间、北面为佣人及服务用房。两个年份沿用各自来源。[黄浦区政府存档](https://web.archive.org/web/20140221052803id_/http://www.huangpuqu.sh.cn/shhp/InfoDetail/?InfoID=0d6f041b-98de-45df-b227-ec12bf39171e&CategoryNum=018001001001003) · [上海市地方志《环境幽雅的陕南村》](https://web.archive.org/web/20141018122612id_/http://www.shtong.gov.cn/Newsite/node2/node71994/node81772/node81776/node81788/userobject1ai109120.html)

2012年1月4日的路口实照可辨四层折角窗、夹在两端之间的砖饰立面和三角山花、浅灰黄栏板及屋脊外伸的方形烟囱。航片用于复核南侧凸窗的外缘和后部两翼间的凹口。其余2010及2013年同组照片帮助辨认砖带、金属窗扇和墙面菱饰。近处树木遮住的门窗、屋面坡度和后翼位置按照片及航片比例估算。[2012年路口原照，Pyzhou，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:ShanNanTown.jpg) · [分栋、道路与屋面定位](courtyard-and-corner.json)

地图上的181号楼点落在地物5464内，183号、185号在另外两栋。2012年照片未清楚显示门牌，成品用“西南转角住宅”命名。院墙、树木、住户附加设备及其他十五栋的细部留给后续工作。[原生地物及附近住宅](footprint-review.json) · [查看单体及四件下载](../../../king-albert-corner-house.html)
