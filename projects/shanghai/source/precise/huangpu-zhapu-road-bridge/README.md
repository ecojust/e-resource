# 乍浦路桥

乍浦路桥连接苏州河南岸虎丘路与北岸乍浦路。上海市房管局第二批优秀历史建筑名录登记编号为2A013。《上海市政工程志》记载，1927年建成的桥长71.94米，中跨36.58米，两侧跨各17.68米。车行道宽12.9米，两侧人行道各宽2.2米。模型采用志书记载的尺寸。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [地方志桥梁表第三行](https://web.archive.org/web/20160627185318/http://www.shtong.gov.cn/Newsite/node2/node2245/node68289/node68296/node68348/node68354/userobject1ai65878.html)

2010年从四川路桥向东拍摄的照片可以对上三个河孔及墩位。2014年的河岸照片显示两处墩头向上收分，淡色实心栏墙沿桥面延伸。上游面中央四块绿色字牌依次为“乍浦路桥”。近景保留字牌、墩头、路缘、步道分缝及沿梁下缘的压线，远景保留三跨轮廓、两侧步道、四块牌面。志书将其结构记作钢筋混凝土单悬臂梁加挂梁。[2010年照片，kgbkgbkgb](https://commons.wikimedia.org/wiki/File:Zhapu_road_bridge2010_01_07.JPG) · [2014年照片，Legolas1024](https://commons.wikimedia.org/wiki/File:Chapoo_Road_Bridge,_Shanghai.jpg) · [照片许可与原图摘要](reference-review.json)

桥轴及两岸接续位置由具名道路与桥面轮廓交叉核对。底图道路和桥面覆盖的范围包含两端接坡，比志书记载的桥梁跨度总长更长。水面标高、墩头与梁下缘断面、桥面起拱和铺装依照片估计。隐蔽构造与基础仍待查。模型只在上游面制作照片可辨的桥名牌，字形采用开源字体近似。[具名道路](https://www.openstreetmap.org/way/144965773) · [桥面轮廓](https://www.openstreetmap.org/way/815631995) · [底图核对](frozen-bridge-layer.json) · [字形许可](source/fonts/OFL.txt)
