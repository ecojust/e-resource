# 大生公司大楼菱纹窗间墙与成列木窗

5A031在市表登记为大生公司大楼，门牌九江路230号。市房管局登记九江路230号为大生公司大楼。依Livelikerw于2019年7月11日拍摄的同址街景，制作街面相邻两开间的菱纹窗间墙、深色窗框和檐下曲托。

两层矩形窗之间有细边框的横向浅浮饰，三道狭菱纹延伸至边框，四个角留下短斜条。不同开间重复同一图案。 相邻窗间由通高竖墙分隔，细窄竖线落到下排窗底。上部檐底在每道竖墙上方有曲面托件。 2019年街照可见若干深色窗扇开向街面。图上的电线、电杆、商户门头与底层另行区分。

2019年照片页面把该处题作中菲大楼。模型采用市房管局第五批登记名，大楼沿革不由两种题名推定。檐托深度、浮饰截面、窗扇倾角和立面绝对尺度无实测。
