# 保定路410至448号住宅成对老虎窗与瓦顶斜脊

5F013在市表登记为住宅，门牌保定路410-448号（双号）。Fayhoo于2017年1月28日从高处拍摄保定路410至448号双号联排住宅。大坡屋面分作多段，取紧邻左侧大山墙右边的两扇老虎窗，各有向前收尖的小坡、两侧瓦面及短脊。

两座窗帽在同一片主屋面上并排凸出，左右与前坡的交线有浅色斜脊。原图可分辨前坡逐层横向瓦缝，较长主坡的瓦色更暗。 两扇窗的窗面均立在各自窗帽的前檐之下；右侧窗框最清楚，直竖分格窄，顶部另有横档。

原照片题到整排双号，无法逐窗指定是哪一户。以照片左侧大山墙向右计，取紧邻山墙的下一组双窗；屋面瓦片尺度、窗洞深和屋后不可见处作比例估计，窗外晾衣架与空调未做。
