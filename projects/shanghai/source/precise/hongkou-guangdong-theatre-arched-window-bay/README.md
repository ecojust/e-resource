# 广东大戏院临街右翼三层窗带与砖券

上海市第四批优秀历史建筑名录将四川北路1552号登记为广东大戏院／虹光大戏院，现名群众影剧院。模型取正面对街立面中观者右侧的一条窗带。[上海市房屋管理局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

龙钢在2025年发表的照片和2026年3月的正、斜两幅照片显示，外侧浅色券框从三楼层窗洞两旁一直升至圆弧顶部。上窗有半圆亮窗，中、下窗呈矩形。两块窗间墙上各有两条短砖竖线。伸出的横檐和较深的金属窗框形成了斜看时可辨的阴影。2022年修缮前照片已能辨认券框及三窗，窗间面层和上部檐线与修缮后有差异。[龙钢照片与文章](https://www.xinhuanet.com/ent/20251205/806ed6c293fc42bda865c08d7cc3416e/c.html) · [历年照片及说明](https://www.thepaper.cn/newsDetail_forward_32823912)

模型采用修缮后照片比例，暂以约3米楼层间距估计绝对尺寸。三档网格、材质、程序和预览图为原创并按MIT许可提供。第三方照片见各自出处。[照片与标定](reference-review.json) · [原始构件程序](source/wing_window.py)
