# 中国实业银行仓库南面高段双层钢窗与折纹窗楣

市级名录将北苏州路1028号登记为中国实业银行。市住建管理委介绍，这座仓库建于1931年；今名苏河皓司。北苏州路1040号的中国银行仓库另有其址。 [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [人民网所载市住建管理委图文](https://sh.people.com.cn/n2/2026/0604/c134768-41601453.html)

实拍近景把中央高段的钢窗、窗间三块饰板和最上方的折纹拍在同一画面内。近档正视能分开两层钢窗及窗间三块凹板，上列浅色外翻扇与蓝色固定玻璃有明度差。斜视时能看见开扇和窗楣折纹的出挑。简化档保留两层窗的开合、下窗顶端连续亮子和窗楣中央圆饰。 所绘为发布图中可辨的修缮现状。洞宽暂取4.40米以定比例，型钢截面、开扇角度、窗楣凿刻深度与背面按照片推定。

北苏州路1028号地址点、同一建筑当代名称和邻址1040号的中国银行仓库分别比对。公开照片能辨认高段两个窗层的开扇、几何窗楣和三块窗下裙板，未给出绝对楼层标高、窗间距与现有仓库楼壳的测量对应。独立展出这两层窗，原城各仓库楼体、屋顶及地面全部保留。
