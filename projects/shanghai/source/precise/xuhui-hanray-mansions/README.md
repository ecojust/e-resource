# 亨利公寓（淮中大楼）

八层公寓位于淮海中路1160至1164号。南立面朝向淮海中路。中央窄窗和竖向砖带向上延伸，两侧是较宽的成组横窗。七、八层逐层退入，连续的圆角露台沿街展开。[市房管局登记表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [建筑沿革和俯视照片](https://www.thepaper.cn/newsDetail_forward_13706875)

本次建模范围从商铺玻璃、中央弧墙门口到上层露台。窗洞、钢窗格、门口弧线和露台栏板均由几何构成。2013年实拍与地面近照用于校准立面，2022、2024与2026年三期屋面影像用于区分前部退台和原楼后体。层高、曲线半径和面砖颜色按照片比例估计。[2013年原始照片](https://commons.wikimedia.org/wiki/File:Henry_Apartments.JPG) · [逐照记录](reference-review.json) · [屋面影像](aerial-register.json)

底图3240与独立实名OSM建筑495913750的轮廓交并比为97.958%。沿街两处窗带的实际投影决定模型朝向，后部屋面和邻楼保留。屋顶花园设施、车库、北立面与内饰仍有待取证。[地址与楼体](building-identity-review.json) · [城市近远层](footprint-review.json) · [街面视线](camera-preflight.json)
