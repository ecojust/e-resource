# 安福路284号悬挑窗楼与原城屋身

在上海项目目录，用 Python 3、NumPy、Shapely 2 和支持 module.registerHooks 的 Node.js 执行下列命令。原数据已在本地时核对摘要后直接使用，缺少的网格按 signed-files.json 中固定的公共提交取回。

```sh
python source/precise/xuhui-anfu-284-timber-jetty/measurements/city-contact/measure.py --project . --output jetty-and-garden-shell.json
```

1948年号图、同期航片和从花园俯看两处山墙的照片均见上一级目录 parcel-and-roof.json。庭院树冠遮挡木托垂足，旧地形只保留整栋屋面。在朝花园的南边沿从西向东的四分之一、中点和四分之三位置，分别试边界及向内外各1.10米三条线。九处试位旨在检验接合是否唯一，各检查两档154处视线。建筑原户3868的地面、立面和全高由原网格保留。屋侧和高于窗楼的原壳也单独记录。原公图、航片和实景照片归来源权利人。
