# 新华路211弄16号花园住宅老虎窗与相邻山墙

市表4M035包括新华路211弄16号。中国の風景在2016年1月15日的同一组照片中，拍到了门口的绿色16号牌和侧屋面。门牌近照有红框圆券门，侧面照片可见一窄一宽两处山尖。新华路329弄17号另有其既有模型。
