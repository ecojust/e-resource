# 公平大楼滇池路巨柱柱头与三槽檐带

上海市黄浦区滇池路105号。滇池路街面巨柱的上端有石刻竖槽，圆形柱颈上承曲面的柱头和方石板。两根相邻柱头之上的檐梁留有成组三道的短竖槽，顶缘分层挑出。

取相邻两根巨柱的上端和其间一跨檐梁。柱径按照片估约0.55米，柱距约1.78米；竖槽的数量、石材颜色和线脚深度按街面可辨轮廓近似。此为局部细节，未测整楼尺寸。
