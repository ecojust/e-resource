# 愚园路754号住宅

市房管局第二批表以2M011登记这处住宅，原名、现用途均列“住宅”，地址为愚园路754号。2015年3月的里弄实景在同一个绿门和院墙上拍到了黄色754号牌与市级建筑铭牌。向西约700米才是愚园路1136弄31号王伯群住宅，俗称汪公馆。750弄的愚园新村另列第四批4M013。建筑始建年、设计者和最初主人有待查证。[市级表、门墙和来源](sources-and-identity.json)

Antigng 于2018年2月13日拍到院内低房的圆拱窗、卷枝铁栏、方形排风口、灰泥叠弧纹、绿釉筒瓦和退后的两层拱窗阳台。2015年从里弄两头拍摄的全景还显示两扇绿门与院墙短边。模型分开制作了开口、薄壁筒瓦、刻纹、镂空石栏和门牌。未辨明的铭牌小字留白。室内和院后医院另列。[2018年近照与许可](../../../data/audit/yuyuan-road-754-v1/photo-credits.md) · [制模源码](source/build_residence.py)
