# 明复图书馆明复楼门厅中国科学社社徽双柱

陕西南路235号的明复图书馆于1931年1月1日开放。图书馆院内分明复楼、会心楼和乐乐楼。上海第四批优秀历史建筑名录登记为4C022，当时的今名为卢湾区图书馆。明复楼门厅正对入口的两根方柱各有社徽，铜色边线和蓝底之间可见山峦、天文望远镜、天平与书本。厅外另一处黑色门头题“乐乐图书楼”，该楼于1993年获捐建。[上海市第四批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海住房城乡建设管理馆史资料](https://m.thepaper.cn/baijiahao_13725937) · [建筑可阅读现场说明](https://www.thepaper.cn/newsDetail_forward_18473453)

门厅正面照片记录了两柱的相对位置、上部梁头和冠线。近照可分别读出柱头外缘的扭绳、方形板面四角的扇纹、圆形铭带、中央望远镜和天平的悬盘。模型保留“格物致知”“利用厚生”“中國科學社”的题字；铸字笔形和饰件厚度按照片估计。大厅的临时展板、查询屏和活动展柜不作为固定构件。原馆外墙、书库、会心楼与乐乐楼列入后续范围。[2018年大厅正面照片](https://commons.wikimedia.org/wiki/File:明复图书馆一楼大堂.jpg) · [照片记录](reference-review.json)

两方柱中心距约2.08米，计算采用柱身宽0.64米的估值。独立场景在照片下沿截断柱身，真实地坪高度仍待核。建筑轮廓在 OpenStreetMap 中带有4C022、1929年与三层的登记，门厅双柱在楼内的位置仍缺实测依据。[双柱比量](measurements/lobby-proportions.json) · [建筑轮廓与定位依据](measurements/building-footprint.json)
