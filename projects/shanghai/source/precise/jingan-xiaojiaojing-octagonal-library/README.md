# 新闸路1321号小校经阁

市第四批优秀历史建筑4B010同时登记刘氏花园住宅和小校经阁。管继平记载，刘体智家的四层住宅在院西，专供藏书的两层八角阁在院南。市区模型采用后者的独立位置。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [《上海静安》，2024年6月2日](https://m.thepaper.cn/newsDetail_forward_27610500)

《静安文博勾沉》记载小校经阁建于1912年，两层共214平方米。按每层107平方米与正八角形估算，两平行墙间约11.36米。两期航片上可辨的八个檐角给出屋顶半径约7.37米。八角边缘在配准中的最大径向残差为0.47米，实际地图位置另受屋顶投影影响，预计误差0.7至1.5米。[《上海老底子》，2020年3月29日](https://m.thepaper.cn/newsDetail_forward_6743933)

朝院照片给出敞开的视线，可辨双扇门、窄亮子、上下檐与折面窗墙。另一张斜俯照给出飞檐和屋脊走势。檐口近照清楚显示圆兽面瓦当和叶形滴水交替。本模型以绿瓦几何、原创灰泥材质、凹入的木框玻璃和独立阶石表达这些细节。照片的视角不足以逐一数清背面窗格、层高和瓦垄数，此类尺寸按比例估计。[照片与图注记录](reference-review.json)

地图中央点为东经121.44673649度、北纬31.23328426度。原城2544与西侧住宅的公开足印重合约97.64%，两者与八角藏书阁在院内分立。十座邻楼、原城近远网格及向量均保留。施工图与室内陈设缺少测绘依据。[位置与航片](registered-location.json) · [原城身份](footprint-review.json)
