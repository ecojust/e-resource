# 周氏花园住宅弧窗厅木圆柱与格扇

这幢约建于1930年的住宅曾属金城银行创办人之一周作民。区规资局刊载的室内照片可见一排朝向花园的格扇，两端各有带凹槽的木色圆柱。 [长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211207/1152634.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

正面可辨两端棕色凹槽圆柱、叠起的柱头及中间四扇格窗。斜视可见四扇沿弧线转折，最近的圆柱遮住外侧长窗梃。远档简化柱身曲面后保留了各层柱头。 以可见内窗宽约3.5米定展示比例。平面弧度、柱径与画面外的框底为估计。 [1015号外立面照片](https://www.thepaper.cn/newsDetail_forward_16580844)

1015号门牌点落在市图2655号原屋内，另一轮廓380相距9.51米。室内弧窗的端点和方向未测定，模型独立展示，原屋和地面均保留。
