# 新华路248号住宅的南向花园阳台与转角窗

第三批优秀历史建筑3M015包括五处住宅。规划图4的4号为新华路248号；图12上排中间的照片单独标出这幢住宅。高参88在2014年先后发表本户的街门、花园侧仰视和落叶季正视照片。三层住宅的缓坡黑瓦屋面、二层钢筋混凝土阳台、钢栏和两根混凝土圆柱另有文字记述。规划表记住宅建筑面积680平方米、用地887平方米，访记记684与904平方米，两组数值保留原口径。 [第三批市级名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [社区复兴规划图4与图12](http://www.dayuehs.com/pdf/xmyh02.pdf) · [高参88的三张题注照片](https://blog.sina.com.cn/s/blog_5d1bdf480101ifu3.html)

落叶季正面可见近端一层弧形连续玻璃窗，二层阳台的悬板和栏杆绕过弧端。上层挑檐下可读到一扇圆窗和一段带窗。规划照片从另一端看见上下两层均有转角玻璃，入户门与小挑蓬在侧墙；夏季近照可见平台、柱身及阳台板底。模型基于这些可见关系复原南面和两端转折。后立面及尾部树下轮廓按外壳处理，坡度、轴距、层高与阴影中的尺寸为估计。 [原照尺寸、散列与题注](measurements/photographic-sources.json)

规划图上的定位点位于原城市建筑2491内，距边缘约5.64米。此粗轮廓面积约203平方米。定位与原城市数据的高度分别处理，三层外观及估计层高取自照片。 [规划位置与近邻轮廓](measurements/garden-location.json)
