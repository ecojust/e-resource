# 朱家角天主堂钟楼中段双菱形砖花与叠层盲拱

5X002在市表登记为朱家角天主堂，门牌朱家角镇漕河街317弄27号。朱家角天主堂位于漕河街317弄27号。Fayhoo于2016年2月7日从正面记录钟楼。中层两侧红灰相间，中轴两旁排列成对浅凹盲拱，下部各有一道阶梯形菱花，中央另有一枚短横砖。它们与上一层真正敞开的百叶窗分处两段。

下层两片浅拱落在中央短柱及两侧支点，红灰券石交替。上部再有一对较扁的盲拱和四个小拱，逐级缩小。 成对菱形由短红砖逐皮错出再收回。墙两侧的红砖腰线和上下棕色檐带连贯，部分表面风化露出浅灰。

截取中段正壁至上部挑檐，不延伸至钟室内或旁侧的塑像。灰砖规格、砌体深度、浅凹尺寸与砖色依照片估计。
