# 广东路306号洋行旧址

市房管局第四批名录4A032以“洋行”登记这栋建筑，当时使用单位为上海东方音像有限公司。江南游1971在2014年12月20日拍下南立面和现场保护铭牌。铭牌记载钢筋混凝土结构、1930年代建成，并指出其装饰艺术派特征。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [具名街照与铭牌](https://blog.sina.cn/dpool/blog/s/blog_70dd482a0102v8g1.html)

广东路一侧有中央六个窗轴和两端各一个窄轴。三楼长阳台由连续金属栏杆围合。两端的四个小阳台使用实心折线栏板。红色贴面带、窗间纵向三联饰块和低层的菱形饰带从街面可辨。2020年2月的街景还记录了底层两组三开间门窗，每组三扇中的中间一扇是门。2024年4月1日，新展馆在此启用。展馆报道的照片记录室内及活动，现阶段外墙模型依据前述两期街照。[2020年2月街景站点和原片编号](reference-review.json) · [上海黄浦刊发的新址启用报道](https://www.thepaper.cn/newsDetail_forward_26947708)

具名地块w378107091的沿街边界约15.49米，与城市底图原楼2074的投影交并比为98.48%。模型按照片估算各层标高和阳台出挑，折线、菱纹、三联饰块、栏杆、门窗与贴面均为可编辑几何。旧洋行商号、内部装饰、院内与两侧建筑面另待可核资料。[地块与实测底图](footprint-review.json) · [沿街坐标](street-registration.json) · [模型制作源码](source/streetwall.py) · [独立预览](../../../guangdong-306-trading-house-front.html)
