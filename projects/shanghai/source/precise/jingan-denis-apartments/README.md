# 德义大楼临街立面

上海市房屋管理局第二批表以2B002登记德义大楼，地址南京西路778号。《静安区志》记1930年、十层39.7米，另叙德义大楼为周边式公寓，底层租作商铺。现行实名足迹与778门号点在石门二路、南京西路交叉口西北侧。同孚大楼在斜对面，门牌801及803号，两处最近相距约35米。[名录、区志与照片](reference-review.json) · [具名地块及邻楼](footprint-identification.json)

Livelikerw于2013年12月9日连续拍摄正面和南京西路侧面。2014年Legolas1024的独立照片复核了上层两根浅色细浮饰。2019、2020的街景补充两条街上的商铺、街角石带、深色窄窗、空调搁架和伸出檐线的砖墩。2021年2月实景可见包围建筑的脚手架。模型按这些外观制作，转角顶层窗间的细长浅色浮饰与资料提到的已拆人像分别识别。街面构件、楼层高度分配及起伏檐线以实照比例重建；4.85米为可见街面的截面深度。暂未独立确认住宅总门，租户招牌、内院、历史立像和未见屋面不在本次细化范围。[照片许可](../../../data/audit/denis-apartments-v1/photo-credits.md) · [可编辑参数](source/parameters.json) · [制模源码](source/build_facade.py) · [三维页面](../../../denis-apartments.html)
