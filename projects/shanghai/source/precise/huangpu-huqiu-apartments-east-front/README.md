# 虎丘公寓沿虎丘路的东立面

原青年协会大楼登记为上海市第三批优秀历史建筑3A013，位于虎丘路131号。黄浦区档案馆记载，1919年动工，1920年9月落成，1924年扩建。1919至1924年为工程分期范围。位于圆明园路的女青年会大楼及四川中路的另一座青年会建筑各有独立地址。[市房管局第三批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [黄浦区档案馆](https://web.chinamcloud.com/shhpdst/tzypc/dacl/27020558.shtml)

东立面由中央内凹的门楼、两个折面和前突的南北街翼组成。2014年1月照片给出两翼的红砖壁柱、窗间板和上层檐带。2022年发布的正面照片可见两根圆柱、门楼匾额、格窗和木框双门。现存楼高与装饰进深依据图像估计。北翼顶层仅制作可见部分，背面、内院及楼梯留待独立资料。[逐张照片与许可](reference-review.json)

城市底图建筑2591与具名OSM地块446934777第4版的足印交并比为98.45%。配准以中央门楼墙线为基准，正北和正南两翼分别向虎丘路伸出。南苏州路颐中大楼和路对面的光陆大楼各有独立足印。[位置核对](site-identification.json) · [东立面边线](source/frontage-registration.json)
