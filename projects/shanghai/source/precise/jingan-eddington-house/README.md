# 爱登公寓（常德公寓）

常德路195号现入口有「常德公寓」四字与绿色门牌。市第二批优秀历史建筑登记号2B022，现场铭牌记1933年开工、1936年竣工。2013年近照记录门廊横向深浅条纹、三片水平檐板及相邻高窗。2013年街面照、2020年高位正面照、2025年和2026年两端街面照可交叉辨认两翼长阳台、中段四处浅阳台及顶层退台。英国的同名公寓照片另行排除。[现场、日期与六个独立馆藏记录](reference-review.json) · [名录与位置](building-identity-review.json)

本次制作常德路东立面、两侧圆角阳台及背后窗扇、两级退台、砖色窗间墙、门廊与题字。入口窄柱的分带在转入门洞的侧壁延续。2020年高位照片进一步辨清了四条连续砖窗带、四个浅阳台上方的整块浅色竖墙与屋顶阶梯形冠饰。临街面根据登记地块和独立地址点配准，宽约41.46米。层高、构件断面、后部凹口和屋面各处边线按比例估计，室内及历次修缮范围仍待进一步考证。[底图与尺度](footprint-review.json) · [屋面与影像版本](aerial-register.json) · [桌面与手机视角](camera-preflight.json) · [可编辑源码](source/apartment_elevations.py)
