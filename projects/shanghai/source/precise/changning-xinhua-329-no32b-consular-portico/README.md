# 新华路329弄32号乙花园住宅入口

市房屋管理局第三批名录3M013的门牌是新华路329弄32号乙。门廊正面近照左柱脚可读出蓝色的“32乙”，木门、两柱及檐部的开间也与庭院远景相符。同弄36号是另有登记的圆形住宅。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [庭院、门廊及室内四张照片](https://www.sohu.com/a/145677223_391447)

第三批名录的补充表列1925年、砖木二层、普益地产公司设计建造。2010年记者转述住户所指的铭牌，称1930年、盛重颐曾居。2017年社区介绍另称1936至1947年为瑞典驻沪总领事官邸，并提到邬达克。三份来源的年代、设计和使用记载分别保留。[2010年住户访谈](https://news.sina.com.cn/c/sd/2010-09-03/101521031797_2.shtml) · [2016年弄堂说明牌摄影](https://4travel.jp/travelogue/11098068)

本次先重建可辨认的庭院入口。两根素面圆柱下有独立方墩，上承带浅浮雕的檐枋和八个瓶形栏杆。退进处为半圆砖券、石门套、铁花亮子与红色木门。柱间纵深和被遮住的后背有待尺度核实。室内楼梯及地面方形格栅虽有照片，和门廊之间的平面关系仍待查证。参考摄影版权归原作者；公开文件记录读点、来源、哈希以及独立重建的网格。[来源与原图指纹](reference-review.json)

规划图第4页把32号乙标为12号，第10页列建筑面积1,066平方米、用地面积2,033平方米，并分别记载开发单位普益地产、设计者邬达克、施工单位柴顺记营造厂。该页记述其1936至1947年间用作瑞典驻沪总领事官邸，Malte Pripp于1940至1945年居住。照片可见的三扇外窗、院墙铭牌和门楣券砖已分别建模。侧后墙、东侧凸部的完整进深和屋面仍在核对。[《上海市长宁区新华路老洋房社区复兴综合规划》，第4、10页](http://www.dayuehs.com/pdf/xmyh02.pdf)
