# 建国西路618号住宅挑阳台与窗列

上海市房屋管理局第二批优秀历史建筑名录2D019以“住宅”登记此处，地址为建国西路618号，公布时使用单位为波兰驻沪总领事馆。批次工作名录注明三层、砖混、1948年。关于1966年迁入的记载属于使用沿革。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [工作名录、地址和沿革](reference-review.json)

波兰外交部旧馆网页保存了一张3872×2592原片。照片EXIF记2013年7月10日10时24分，相机为Nikon D3000。2016年为原图存档年，2017年为说明网页存档年。左侧树隙能看见挑阳台右端、板底、实体栏板与扶手下的窄空隙，下方窗列的两块横气窗及较窄的开启扇也可分辨。[馆方旧页](https://web.archive.org/web/20170313204827/http://www.szanghaj.msz.gov.pl/pl/konsulat/) · [档案原图](https://web.archive.org/web/20160626181509im_/http://szanghaj.msz.gov.pl/resource/8f9adf6a-ff1d-4773-9d80-4fdedcd31e7e:JCR)

模型截取这一段楼上外墙。两层窗框各自嵌入墙体，阳台板、板底、栏板、扶手和侧向收口分件制作。跨度、板深、窗料厚度、树影遮住的分格和表面颜色根据照片估算。初建时的门窗材质及分格仍待1948年前后图纸或照片佐证。历史标记采用取到三位小数的街区位置，展件在独立页打开。[生成源码](source/build_model.py) · [阳台与窗列](source/balcony_window.py) · [实解码核验](source/check_surfaces.py) · [独立查看](../../../jianguo-618-historic-front-history.html)
