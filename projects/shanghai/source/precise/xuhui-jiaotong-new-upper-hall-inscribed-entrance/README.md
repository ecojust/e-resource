# 交通大学徐汇校区新上院题名门廊

本件取华山路1954号新上院南入口。上海交通大学的修缮记录将新上院建成年代定为1954年。市表4D024还登记工程馆（恭绰馆），两者位于校园内不同位置。

2012年修缮后的正面照片第19幅能看到题名石匾、外挑叠檐、两侧浅浮雕石墩、灯具、曲线托角、门后的三樘木作及四道踏步。2008年园内实拍与校方南立面图共同约束门廊相对于整面立面的宽度。中门按照片留通道，两侧木门带上亮。题字和浮饰按照片描形后挤出。

投影宽约13.1米，檐顶较门前地面约6.1米。墙厚、花饰和凹进尺寸按照片估算。校方图纸和照片另列出处；下载的模型只包括独立创建的几何与材质。
