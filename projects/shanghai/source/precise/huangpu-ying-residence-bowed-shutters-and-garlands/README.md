# 应公馆园侧弧形百叶凸窗与垂花窗裙

高德地图应公馆地点照片的EXIF拍摄时间为2026年3月17日。园侧右端凸窗可以辨认左右两组百叶，胸墙垂花呈两道下垂弧线。照片上方的弧形瓶栏透出后墙与窗影。 [市房管局第五批名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [高德地图“应公馆”地点照片，公开页面未列摄影人原照，用于可见外观的考证，图像著作权归原权利人](https://www.amap.com/place/B0FFM7ZOO1)

近档可见两组实心斜置百叶、上冒头小百叶窗与浅色横楣。斜视能沿弧形窗台看出中段前挑、两串垂花和独立瓶栏，远档保留窗洞与栏间空隙，减少百叶片及花叶数。 依门窗习惯尺寸估算两开间总弧长约3.60米。墙后进深、瓶栏背面和被树遮挡的叶片由可见边界估计；地面层、山墙和中部敞廊保留在取景范围以外。

市表采用凤阳路338弄。常用地图的凤阳路338号门牌点落在原楼1689，院内应公馆实名点落在原楼336，两处分别约25.8与30.3米高。原照片只能辨认右端凸窗局部。独展保留两栋建筑和整个庭院的原地面。
