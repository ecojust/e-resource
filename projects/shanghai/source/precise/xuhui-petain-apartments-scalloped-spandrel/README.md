# 贝当公寓临街窗下圆珠与弧带浮饰

衡山路700号在上海市第四批优秀历史建筑名录中登记为贝当公寓，现名衡山公寓。市政府设置的铭牌将建成年份记为1934年。模型记录临街面左端一跨窗下在2013年的外观。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [建筑铭牌](http://www.shwfjz.com/imgs/image/20200930/2020093015250513513.jpg)

Livelikerw于2013年12月18日拍摄的原片里，左端平窗下有一块浅色窗裙，两侧弧带各在两个高度折转。在弧带之间，大小相间的凸圆片填满了竖向空隙。模型按校正后的窗裙图逐一描出26块圆片，并保留窗台、上方的浅色四列窗扇及下方一截红棕色窗头。墙面和浮饰使用两种程序生成的颗粒尺度。[原图与作者署名](https://commons.wikimedia.org/wiki/File:Petain_Apartments.JPG) · [照片许可 CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

2017年的现场记述分别提到临街面中部和两端的窗间装饰。修缮单位所刊仰拍照片可见，多折面凸窗下还有另外一组横向珠带和圆齿。修缮图没有给出端部窗裙逐件换修的时间。[2017年现场记录](https://www.sohu.com/a/164999063_649794) · [修缮图册](http://www.shwfjz.com/m/showcase/12) · [凸窗下的另一组浮饰](http://www.shwfjz.com/imgs/image/20200930/20200930152768566856.jpg)

窗裙宽取2.05米作为比例基准。浮饰进深、玻璃反光及饰面色调依照片近似。外部实照通过原刊链接查阅，模型材质和预览图由项目生成。[读图坐标与资料](reference-review.json) · [构件源文件](source/spandrel.py)
