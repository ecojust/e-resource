# 元芳弄原沪宁铁路局东南角塔楼

上海市房屋管理局第三批优秀历史建筑3A011登记“沪宁铁路总公司／元芳弄”，地址为四川中路126弄（5、21号）。市政府1999年保护牌将其记为1911年竣工的铁路局办公处，用“东南转角处设塔楼”定位。唐乙隽2022年实地报道的开场镜头完整保留了这块保护牌，正文分别走访两栋建筑并记载其连廊。[官方名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [实地报道与保护牌](https://www.jfdaily.com/wx/detail.do?id=515473)

Livelikerw于2015年2月6日拍摄的原图可见转角的双圆券、两面小阳台、无窗折面和退进的短方窗塔冠。两道深色砖檐在转角贯通。三块同名足印中，380339832坐落在建筑组东南端，原城号1674。另两块476、2732和组内山墙是独立的实体。现有资料尚不能把这座转角塔落实到5号或21号某一门牌。塔柱截面的尺寸、被遮挡的细部、灰缝及颜色取估算值。[具名街照](https://commons.wikimedia.org/wiki/File:Former_Shanghai_-_Nankin_Railway_Admin_Office_Building.JPG) · [参考资料、作者与许可](reference-review.json) · [原房与已建邻居](prior-models-and-osm.json)
