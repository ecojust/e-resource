# 余庆路80号双圆阳光房花园立面

上海市徐汇区余庆路80号院内，主楼有两处圆弧阳光房。靠西南的一端底层是双柱敞廊、木门和侧墙拱券，可从另一端透过拱券看到木门。东北端的弧墙直接落地，下层也开有成排深色钢窗。两端之间是带实心栏板的长挑廊，第三层的阳台较短并向内退。模型保存这些可从花园辨认的差别。

两张原始照片从相反的方向观察立面。照片4的拍摄日期为2013年9月14日，测点使用1,080×711像素的等比工作图。照片6以934×700像素原图为准。模型采用米制局部坐标，X向东北，Y向楼内，Z向上。西南和东北圆心分别取X=−8.13米和+8.13米，廊内地坪取Z=0米。

2021和2025年两期正射图独立测得的圆心距约16.53米和15.93米，向东北的长轴方位约50.3°和51.4°。窗墙半径由实拍中的窗角和弧线约束，屋顶挑板的外径较大。资料未提供实测施工图，遮挡处、廊内进深及屋缘尺寸保留估计误差。院内其他楼房、室内与背面尚待另行取证。
