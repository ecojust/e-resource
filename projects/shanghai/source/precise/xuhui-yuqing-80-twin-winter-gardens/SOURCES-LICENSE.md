# 余庆路80号花园立面资料与许可

上海市房屋管理局公布的第五批优秀历史建筑名单中，5D075为余庆路80号住宅，使用功能为办公。院内牌同时记载了余庆路80号住宅二、三号楼。门牌本身不能区分各楼。本模型选择花园方向有两处半圆阳光房的楼体。[市级名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

高参88图集中的照片4从花园东北侧看向住宅，照片6从西南侧看向住宅。照片4在线原档有4,912×3,231像素，EXIF记录拍摄时间为2013年9月14日15时35分54秒，机身为Sony DSLR-A580，镜头焦距16毫米。照片6在线文件有934×700像素，未保留可核实的拍摄日期。同组图5记录并列的两块建筑铭牌，图13是历史院区示意。[图集及来源说明](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102ze0a.html)

徐汇政务文章的门口照片可辨80号门牌，另一幅双圆立面照片与上述照片4的构图相同。文学城的院面照片补充了西南端下层的木门、侧券和敞廊。两处半圆的绕窗和它们下层不同的构造也能在正反两个主机位相互核对。[徐汇政务图文](https://www.thepaper.cn/newsDetail_forward_21735319) · [补充立面照片](https://bbs.wenxuecity.com/memory/618885.html)

分期正射影像记录在 measurements/roof-arc-registration.json 中，包括2010、2019、2021和2025年元数据、服务地址与图块SHA-256。门牌坐标用于找院区，双圆屋面的轮廓和两份照片用于认楼、定向和估计尺度。院内另有坡顶建筑，现有资料不足以将各楼及建造年代一一对应。

建模脚本、控制点、原创几何、程序色图、法线图与模型渲染图按仓库MIT许可证发布。原照片及商业影像的版权归各权利人，公开模型包中只附来源与数值观测。
