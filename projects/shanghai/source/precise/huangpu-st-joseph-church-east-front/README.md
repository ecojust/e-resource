# 若瑟堂东立面与钟塔

模型面向四川南路36号院内，取2009年及2017年可见的东立面。上海市房屋管理局第二批原表第48行的编号为2A045，原名称与公布时使用单位都写「若瑟堂」。历史资料中的洋泾浜圣若瑟堂、圣若瑟堂指向此处。1847年取得教产用地，1850年设小堂，1860年今堂奠基，1861年首期启用，1868年完工，立面和钟楼又在1877年完成重修。英文文献另记1862年祝圣。当地堂区在1966年关闭，1986年恢复开放。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [逐条来源与原图散列](sources.json)

## 东立面

1908年出版的原书照片可辨中央大门、两侧圆券小门、四座带雕像的小龛、上层左右两组双联盲拱和中央大圆花窗。2009年两张院内照片和Fayhoo于2017年10月8日拍摄的正面保持这些位置。2017年原图有旋转标记，核对细部时已转正。门额外侧为三角形，内部实为半圆券、扇窗和木质双扇门。外侧各门上方各有一龛，另两龛分置主门两旁。照片能看见雕像位置及大致衣褶，未能确认每座雕像的身份和手中器物。[1908年照片](../../../data/audit/st-joseph-east-front-v1/east-1908.jpg) · [当代门扇、龛像和花窗](../../../data/audit/st-joseph-east-front-v1/east-details-2017.jpg)

主圆窗由八块外瓣、八块内瓣及蓝色圆心组成。外圈能区分红、紫、绿、黄及一片浅色玻璃。窗下的两组圆券分别由两道盲拱和一只带放射纹的小圆孔组成。2009年室内组图的两幅人物玻璃窗和另一幅透光花饰在本研究中只作为室内来源。外圆窗用2017年正面照片建立独立几何。[2017年原图与署名](https://commons.wikimedia.org/wiki/File:St._Joseph_Cathedral.jpg) · [模型构件源码](source/build_east_front.py)

1908年照片中钟台前缘是交叉纹栏板，中央塔座拱口宽敞。2009年和2017年照片中的钟台有直杆栏、赤褐色百叶和深色尖顶。中央主尖顶两旁各有一座可直接计数的空心尖亭，主尖顶下部另有小型尖券构件。模型采用当代可辨的塔座形式。文献记最高处三十余米，模型的36.5米十字架顶标高、各层标高、钟台纵深、屋面坡度和雕像轮廓均由照片估算。[2009年院内正面](https://commons.wikimedia.org/wiki/File:Yangjingbang_catholic_church.jpg) · [尺寸与拟合范围](source/parameters.json)

## 地图配准

冻结城市源14-13720-6694/2923来自具名的OpenStreetMap w446934320第5版，与当期原始节点序列和门牌相符。冻结底图与OSM在两种面积分母下均约99%重合。东侧院内边长22.27米，面向约69.90°，对应东端横向门面。中文资料页脚的通用坐标与这一实际有名地块相距约500米，定位采用门牌及已核实的源多边形。近邻1301号与2730号分别另有独立轮廓。Esri现行影像可辨后部堂身和东侧院场，影像日期未定；只用它判别先后关系与屋顶朝向。[具名源与相邻楼宇](registered-shape-study.json) · [两档城市原始文件](footprint-review.json) · [底图影像来源](aerial-source-receipts.json)
