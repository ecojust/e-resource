# 派司公寓两层钢窗与临街砖墙垛

5B012在市表登记为派司公寓，门牌常熟路100弄1-8号。取Antigng于2018年2月7日从常熟路拍摄的派司公寓立面，截取相邻两层叠置的矩形钢窗与右侧通高砖墩。

原照片清楚记录两层窗的平直砖过梁、褐色顺砖墙与连续收进一段的水平灰缝。 右侧整条砖垛凸出窗面，受光转角明显。画面中的空调、线路及晾晒物遮挡部分砖缝，局部研究仅表达可辨的固定墙窗。

原照可辨深色窗框、浅色天空反光和玻璃前的分格。玻璃与砖墙的绝对进深未经测量，钢窗分格在遮挡处按相邻可读部分延续；不将这开间指定为1–8号中某一户。
