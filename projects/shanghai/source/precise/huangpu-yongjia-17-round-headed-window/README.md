# 永嘉路17号住宅大弧窗与分层券脚

5A063在市表登记为住宅，门牌永嘉路17号。市表5A063列永嘉路17号住宅。依据Antigng在2015年9月9日拍摄的题名原照，取浅墙的大弧窗、叠券、券脚和较窄侧窗。

主弧窗高于横档，券边连续数道浅色压线，在两侧基部转为水平短檐。 扇光下为竖长暗色窗，浅框横档和中挺均可辨。右边留一扇尺度较小且年代未定的券窗。

2015年照片仰拍，绿色多边形构架与树木遮住局部；模型仅复原可连续读取的墙面和拱边。窗内反光、绝对尺度及后期摄影设备遮挡处无独立实测。
