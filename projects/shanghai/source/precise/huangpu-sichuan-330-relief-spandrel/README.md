# 四川中路330号深色浮饰窗间板与通高窗列

5A039在市表登记为Bank of chosen/上海市直接税局，门牌四川中路330号。市表5A039登记四川中路330号为Bank of chosen／上海市直接税局。按Livelikerw在2016年2月18日拍摄的临街面，截取两个相邻窗列及其间两段深色浮饰板。

同一轴线的暗色窗、成对带边框的浅浮饰和下一层钢窗上下衔接，浅色墙体有细窄水平灰缝。 原图可分辨各暗色板内两幅带矩形外框的近方形凸饰。四支纹样从中心向四角卷转，各支向外分出成扇的尖叶。

浮饰以实照可分辨的外框、双心饰、卷枝起伏表达。面板金属种类、原面漆和每片细纹题材没有材料检验；现场店招、线路和树枝另行区分。
