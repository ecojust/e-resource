# 长乐邨93号丰子恺旧居

陕西南路39弄93号位于长乐邨南部的一排住宅中。丰子恺于1954年迁入，在这里生活至1975年。二楼朝南的梯形窗上有一块天窗，可见日月，因此取名“日月楼”。上海市第二批优秀历史建筑名录以2C009登记整个梵尔登花园，列陕西南路39弄1至103号及长乐路197至247单号。[上海市地方志《上海名建筑志》](https://web.archive.org/web/20200218190752id_/http://shtong.gov.cn/newsite/node2/node71994/node81772/node81776/node81788/userobject1ai109110.html) · [市级名录摘录与照片收据](reference-review.json)

模型由南侧小庭院望向93号。三阶短梯通往深色双扇门，门上为菱格气窗，雨棚下可见两件深色托架。2022年3月记者拍摄的门口照片与丰家旧合影都能读到“93”；照片也记录了两旁窗、墙上的保护牌及二楼外开窗。历史弄口照片指认了这户的尖顶。[澎湃新闻图文与视频](https://www.thepaper.cn/newsDetail_forward_17240864) · [2014年实地报道](https://www.chinanews.com.cn/cul/2014/10-21/6702059.shtml)

在底图排屋1452的南边界定位这一户，按照片比例取宽约6米，交付单元庭院立面及前段约5.1米深的屋面。窗口、采光玻璃、前门、铁栏和牌号均为原创网格。邻接住宅、后楼和室内另列。现场分户测绘仍有缺口，屋面与檐高为估测。2015年常见的长乐邨角点照片右侧门牌能读到38，住址在本户北面约140米。[地块和门牌核对](footprint-review.json) · [作者尺寸](source/parameters.json)
