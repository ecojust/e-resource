# 来源与许可

北门的年代观察、字牌间距、铁栏转折和门扇开合根据百度地图在武胜路拍摄的历年街景测量。公开文件列出拍摄日期、站点标识、原服务链接、坐标和测量结果。照片像素留在原服务。网页纹理来自项目自制的红砖颗粒程序。模型、程序和原创纹理以项目 MIT 许可提供。[现场数据与站点](measurements/street-sign-sources.json) · [MIT](https://opensource.org/license/mit)

名录采用上海市房屋管理局公布的上海市第五批优秀历史建筑名单。原地图轮廓来自 OpenStreetMap 贡献者，按 ODbL 提供。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [OpenStreetMap 版权](https://www.openstreetmap.org/copyright)
