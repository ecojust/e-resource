# 三菱洋行大楼西南圆塔与拱门

广东路102号落在广东路、四川中路交叉口东北角，西南圆塔面朝路口。市房管局将三菱大楼与美孚大楼合列为第三批3A012，地址栏合写广东路94—102号、四川中路109号。高亦寒按黄浦区文物普查分别记录两楼，102号三菱洋行列为1914年、设计者福井房一，94号美孚列为1912年。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [三菱洋行](https://www.meipian.cn/4ifapyuc) · [美孚火油公司](https://www.meipian.cn/4ifap7a4)

1947年照片著录旧址为86 Canton Road，标注后来为广东路102号，视线朝东北。图片下部是一樘正对路口的高券门。上部三条弧面窗轴依次出现矩形窗、半圆券窗和矩形窗。顶层圆鼓另有一圈出檐。2015年1月2日16时28分的102号照片可见同一组构件及屋顶栏杆。两张照片共同决定模型的外轮廓，细部和黄褐色饰面采用2015年1月所见。2015年和2016年的报道记载了后续外墙喷涂。模型留出了两侧街墙及室内。[1947年照片](https://pastvu.com/p/783933) · [地点考释](https://avezink.livejournal.com/202635.html) · [2015年原图](https://commons.wikimedia.org/wiki/File:102_Guangdong_Rd._Shanghai.JPG) · [后续外墙报道](https://www.yicai.com/news/5014609.html)

同日16时25分另一张照片实见红色斜切角和平直窗墙，对应94号美孚建筑记录中的二层拱窗和高层柱饰。维基文件标题与两楼照片存在交叉。原城市地表的825号还把两楼名称并写在西北角。圆形屋顶的航影、照片视线和东北角的街墙交点共同指向独立源302。九江路36号原三菱银行有独立门牌、轮廓和既有模型。逐件来源、影像散列、两楼地块交并比及地址异文详见核对表。[94号对照照片](https://commons.wikimedia.org/wiki/File:Former_Mitsubishi_Corporation_Shanghai_Branch.JPG) · [核对表](reference-review.json)
