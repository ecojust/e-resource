## 摩西会堂庭院首层三连砖券

复原长阳路62号庭院立面画面左侧三个首层券洞、四处砖柱及上层走廊下沿的通长线脚。拉比诺维奇图纸的外楼梯立面标柱宽2英尺6英寸。现存砌体的券跨、起拱高度及墙厚由庭院照片估算。
