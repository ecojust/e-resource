# 愚园路541弄2号木构山墙与弧窗百叶

半木构山墙的两道宽梁和竖木，阁楼双扇各三片玻璃。下部凸窗的四组浅色百叶随弧转向，窗头、窗台和中间石框有不同出挑。右端被枝叶挡住，保留相片中能辨的外沿。

名义山墙宽4.1米；木框用照片像素迹线，凸窗半径1.82米为近似。右侧百叶细部有树遮挡，同组叶距参考中央两组。
