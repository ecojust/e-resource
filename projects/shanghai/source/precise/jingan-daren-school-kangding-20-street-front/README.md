# 康定东路20号原大任小学校

市房屋管理局的第五批优秀历史建筑名录把“大任小学校、上海市私立大任小学旧址”列在康定东路20号。2015年的街角照片可读到绿色20号牌，2026年街景写生视频清楚记录了十四孔砖券、中央橙色门和屋顶三个小山墙。西邻28号有独立的尖塔住宅。原城2852的临街边长约26.54米，作为模型的长度参考。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [2026年现场视频](https://www.bilibili.com/video/BV1MeFVzqEiJ)

上层钢窗长廊与下面的券洞各有十四个开口。十四个钢窗逐个从视频正投影取边框，2020年两个街面机位复测窗框的退进深度，四个相关性较高且位于测量区间内部的结果为0.06至0.33米，实体采用其中值0.155米。三峰前窗面在主墙后约3.45米。西端原照里的水平檐线与临街照片右端斜瓦脊确定了前后斜坡和两端的斜脊。后墙、背坡和被树木设施遮住的底层窗间用简化形体收合。[钢窗量测表](measurements/gallery-opening-controls.json) · [街面相机](measurements/street-front-cameras.json) · [西端窗和屋面](measurements/school-west-return-and-roof.json)

橙色门前的平台向街面伸出。四个栏柱顶可以从三个机位交会定位，三个栏段分别辨出十五、二和十四根石瓶。更靠街的屏墙在2026年照片里有三道填实砖券。旧街照只露出端帽，东端跨年定位相差约1.5米。模型按2026年的画面和可核范围表现这段园界。背后的底层、道路绿化和院墙之外的建筑分别保留各自边界。[露台与三峰的交会](measurements/video-terrace-and-roof.json) · [园界屏墙](measurements/courtyard-screen.json)

运行 `python source/build_model.py --output daren.glb` 导出完整原网，添加 `--lod` 导出远景网。近景包括逐块排列的券砖、真实窗洞、钢框、瓦垄和可数的栏柱。相机、压缩网和检查程序共同用于复算网页中的两档模型。[模型图板](../../../data/audit/daren-school-kangding-20-street-front-v1/school-court/school-street.jpg)
