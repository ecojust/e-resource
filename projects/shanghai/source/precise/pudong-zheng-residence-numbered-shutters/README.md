# 郑生官宅190号沿街木排门的八块编号板与圆边横档

5W015在市表登记为郑生官宅，门牌新场镇新场大街190号。Fayhoo上传的新场大街街照显示，190号绿牌装在门扇上，其右一间有八块连续的竖向活动排板。板面从左到右可读浅色数字1至8；下端齐落在横档后，横档两头留有凸起的挡块。

190号门牌与前景较清楚的188号相隔一根木立柱，另一端还有一根砖柱。沿街立面应按原照辨号。 数字排在木板下部，圆边横档带两个突起的挡块。其下另有较矮的木板及一道深色压线，最下为白色墙基。

前景最近门牌为188。本件只取正标190的门扇右侧与该号同开间的八块板，按照片恢复编号和木构关系。凹槽深度、木种、整栋进深及绝对尺度未测。
