# 复旦公学登辉堂正厅朱漆格扇

华山路1626号。登辉堂正厅两扇相邻的朱漆格扇。上半扇的深色方格木棂留有通孔，下半扇为凹入的板心、抹头与边梃。

根据长宁区文化数字地图的正厅照片估算两扇合宽约1.18米，格扇通高约2.88米。格条的具体排法依可辨图形简化，边梃的进深、倒角和背侧属于估算。两端石鼓、上悬题匾、其余门扇、登辉堂西侧迁建的门楼及力学堂另留研究。

区文化地图的实景图只作署名参照并保留原链接。发布图片为本项目原创几何的独立渲染。
