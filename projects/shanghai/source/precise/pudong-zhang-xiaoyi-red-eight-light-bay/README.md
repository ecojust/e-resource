# 张小乙宅临街浅凸窗的八扇红框四格窗

5W019在市表登记为张小乙宅，门牌新场镇新场大街283号。2015年1月10日的署名正照显示，新场大街283号张小乙宅门廊上方设浅凸窗。临街一面有四组双扇红框窗，每一扇由三道细横梃分为四格；窗下竖木板表面露出深浅不一的旧红色。

临街共有八扇高窗，成对布置。每扇有四格玻璃，玻璃与细红横梃相隔，边梃宽于横梃。 成排窗扇下侧为旧红竖板与一道横向窗台，上缘有灰黑两道出挑的檐口，随着整排窗弯折。

照片正对凸窗，窗带的折线、红框分扇和横梃可辨。侧面的转角深度、铰链直径、旧漆状况及绝对尺寸按此估计；不外推上部栏杆、室内及邻接房屋。
