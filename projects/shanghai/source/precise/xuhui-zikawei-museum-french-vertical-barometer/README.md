# 上海气象博物馆藏法国垂直气压计

《气象知识》刊登了杨阳拍摄的展品照片，图注为“垂直气压计（法国，1850年左右）”。照片中可以看见红褐色木柜、玻璃门、同心波纹金属盘、铜色支架和下方带方格的纸卷。中国气象局的馆藏介绍也提及垂直气压计。[《气象知识》图文](http://www.qxkp.net/tjzx/202606/t20260625_7880742.html) · [杨阳摄影原图](http://www.qxkp.net/tjzx/202606/W020260625336052472111.png) · [中国气象局馆藏介绍](https://www.cma.gov.cn/ztbd/2024zt/20240930/2024093003/202410/t20241005_6625085.html)

模型将木柜高度取为一个展示单位。原图第419行可分辨六道连续的金属亮峰，模型分别制作这六道起伏、中央安装面和外缘。纸面格线为原创纹理。单张照片保留了正面与右侧可见轮廓，柜深与背侧的尺寸为估计；纸上的气压读数和铭签文字未能辨清。[逐点像素记录](museum-reference.json) · [查看三维展品](../../../zikawei-museum-french-vertical-barometer.html)

原创网格、程序和展品示意纹理以 MIT 许可提供。照片版权归摄影者和原发布方。近景和远景可分别运行 `python source/vertical_barometer.py --output full.glb` 与 `python source/vertical_barometer.py --lod --output lod.glb` 重建。
