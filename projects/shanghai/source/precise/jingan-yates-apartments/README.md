# 同孚大楼 · 原中国银行西区分行

上海市房管局第二批2B003记录原中国银行、公布时中国工商银行、南京西路801号。住宅从南京西路803号进入。1994年2月15日上海市人民政府发布的优秀历史建筑标牌可在建筑门边的照片上逐行辨认。标牌记设计者为陆谦受、吴景奇，承建人为大昌建筑公司，1936年竣工。[上海市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [标牌、照片及原表记录](reference-review.json)

旧上海的南京西路、同孚路和斜桥路在此围成一块街角用地，后两条街今称石门一路和吴江路。外墙沿半月形边界展开，原有银行使用底层和地下室，上方八层出租作公寓。《静安区志》表列1934年、九层、高34.45米、建筑面积2,887平方米。《上海名街志》记1935年中国银行建，占地0.59亩、建筑面积2,916平方米。模型年代采用现场标牌的1936年。露台两排八根立柱和旧供暖圆柱见《时光里的家园》的街坊记录。[区志、街志与街坊资料](reference-review.json)

具名OSM w1199797046与城市源1964相合，两个独立地点查询分别落在801号银行和803号公寓一带。维基条目的经纬度偏向东南方另一地块。冻结轮廓约509平方米，比街志所记占地面积大，故外弧和纵深仍有估计误差。本件包含公寓窗、连续横线、近现代空调外机、现状银行门牌、住宅入口及屋顶两端形状。背面的服务窗列、楼梯塔内部和原公寓套型缺少实测资料。西邻和路口对面的德义大楼沿用各自原形。[源面与分栋](footprint-review.json) · [独立模型页](../../../yates-apartments.html)
