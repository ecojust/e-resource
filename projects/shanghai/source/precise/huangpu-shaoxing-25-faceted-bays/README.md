# 绍兴路25弄住宅双折角凸窗与横槽窗间墙

5A051在市表登记为住宅，门牌绍兴路25号。市表5A051简记绍兴路25号。高参88于2024年11月16日发表的图5拍到上海市人民政府铭牌「绍兴路25弄（1–4号）」，并注明1933年。取图4铁门后住宅上部两排格窗、两端凸窗及中部相连的双组横槽。

左右两端的窗面向前，弯折的平檐在两端突出，中间退进。每处转角可读两块斜侧面。 中间双开间之间有实柱，楼层间浅色横面留成对的三道深槽，两侧中段装有后加空调。

铭牌记两幢住宅。图4能确认院内这面窗墙，但各户的门牌与单片窗之间尚无测量图。深度、绝对宽度与百叶槽回深按图估算。
