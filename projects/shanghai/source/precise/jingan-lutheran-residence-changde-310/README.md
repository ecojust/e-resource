# 常德路310号信义会住宅

上海市第五批优秀历史建筑名录5B021列为“信义会，住宅，常德路310号”。临街立面中央塔身有三层成对窄券，偏北两层各有一对宽券。南边翼部折回，带窄侧窗的凸出开间和带陶饰的圆券各有实照依据。三期街面实景的同窗交会与地图原屋边仍有距离，保留普通城市原建筑，用本页单独展示。[市级登记与独立摄影](reference-review.json) · [位置复核](measurements/footprint-review.json)

前灰砖面取Y零。北跨与塔身按高参88的正、斜照和2015、2020年的街面影像定形；nina于2021年2月的庭院照片又约束了石柱券门、两侧曲栏和南翼回墙。南翼两平面进深分别估约2.5、4.0米，背坡与遮挡的侧后墙采用简化轮廓。院内铺地相对整栋标高约−0.43米。原照片里外露的是两只小山墙、烟囱、出挑檐口和塔顶四坡。[窗墙控制点](measurements/large-and-wing-window-pixels.json) · [翼部相机](measurements/south-wing-camera.json) · [净洞和进深](measurements/residence-wall-sections.json)
