# 永嘉路630号花园住宅二层拱窗与菱格阳台

上海市第四批优秀历史建筑名录将永嘉路630号列为花园住宅。中华书局2024年版《海上遗珍：永嘉路》收有钱宗灏专写630号的《集仿主义建筑的拼图》。高参88的2013年11月实地摄影记录将其建造年代记为1925年。[中华书局书目](http://www.zhbc.com.cn/zhsj/wap/news/info.html?newsid=297ec13d91c0a75c0191c52c462d004c) · [2013年照片](https://blog.sina.com.cn/s/blog_5d1bdf480101fcvi.html)

独立展示的构件是二层阳台。支承拱罩的是一对短圆柱，券内有盾形装饰。后方的白色分格门窗与两侧小窗组成三段。前栏正中是相交双环和斜向交叉的细杆，两端菱格有向内收曲的四边。斜照能辨侧面栏板、柱后的凹入空间及出挑的券身。模型据正面构图4和18、斜面11重绘，窗扇按近正面照片的关闭状态呈现。绝对宽度和进深属于估计。[逐图来源与尺度说明](reference-review.json)
