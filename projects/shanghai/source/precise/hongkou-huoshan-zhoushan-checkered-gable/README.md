# 霍山路舟山路转角住宅双券窗与棋格山墙

上海市第四批优秀历史建筑名录将霍山路71–95号、舟山路21–81号登记为住宅。2015年的路口全照可同时读到93、95两个绿色门牌和舟山路蓝色路牌。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Livelikerw，2015年2月3日，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Central_Business_Area_of_former_Shanghai_Hongkew_Getto.JPG)

在Gerd Eichmann于2012年拍的正面照片里，两扇小券窗共处一榀山墙，相邻右榀只有一扇大券窗。双窗各有突出的浅色窗台，窗券外圈为深灰辐射砖，内沿有窄红砖圈。上方红灰色砖块的砌向交替，靠近窗券时过渡成横向短砖，峰顶磨圆，中间嵌一条浅色竖饰。[Gerd Eichmann，2012年11月11日，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Shanghai-Ghettoviertel-16-2012-gje.jpg) · [同日街面全照](https://commons.wikimedia.org/wiki/File:Shanghai-Ghettoviertel-15-2012-gje.jpg)

展品取双券窗及山墙，绝对高度约5.9米为估算。窗下衣物所遮的细格与墙背进深采用简化推定。[出处与图上尺度](reference-review.json) · [位置说明](placement-review.json) · [原创制作程序](source/checkered_gable.py)
