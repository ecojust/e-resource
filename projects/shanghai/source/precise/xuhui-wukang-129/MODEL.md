# 照片特征模型候选

当前为预览后修订v2；具体范围和不变性证据见 [REVISION_V2.md](REVISION_V2.md)。首版源码和raw仍在相邻原目录，未覆盖。

`output/xuhui-wukang-129-raw.glb` 是待视觉核验的真实三维候选。它没有贴整面照片，也没有复用全城通用窗格块；模型结构来自本栋两张原图和独立分面观察。原 Overture/OSM 四点轮廓、地理锚点、local3733及17个相邻要素保留契约没有修改。

## 已实现

- A：左侧三角山墙，两扇不同宽度上窗及一扇三分格下窗，平面灰色斜檐带。
- B：斜向后退侧返墙，单独拟合朝向，两扇不同宽度格窗。
- C：照片可见低体末端及灰色斜沿；其平面关系采用明确标注的近前平面假设。
- D：后退的上层中央墙、独立低门厅与斜瓦罩；红色拱门、灰色多重拱套、实体129牌与门五金、两侧窄窗。
- E：真正弯曲的墙壳和穿透的拱形洞口，拱窗扇形上亮、弧形铁栏及外鼓竖杆、层叠曲面托座、曲线檐口与半圆端瓦帽。
- 有限厚度的凸盖瓦和凹底瓦逐排搭接；照片可见雨水管和右门旁空调采用克制的构造估计。没有将行人、树、临时衣物或向日葵作为楼体细节。

所有窗采用单一连通框格和真实洞口；20mm玻璃位于自己的框厚范围内，离框前脸20mm。圆墙按弧长分带生成共享边界的前后表皮，分带之间不生成封闭盒体的内部面；真实洞口保留窗侧返回面。相邻独立装饰构件没有被冒称为全楼布尔并集。

## 相机与尺度的实际含义

`calibration/calibration-independent.json` 使用2026年原图实际1800×1200像素、EXIF24mm、Canon官方35.9×23.9mm传感器规格。A平面横线拟合RMS约0.70px；B和D各自拟合水平朝向，不能把全楼拉成一个平面。`comparison.png`是标注分析衍生图，原JPEG没有修改。

全屋14.2006m源边长只作为**条件包络标尺**。两端真实墙脚部分不可见，源四点轮廓没有分辨圆角/退进，2026图也经过软件处理。B/D相接处受树遮挡。这些条件意味着低像素重投影误差不等于实测尺寸，更不构成摄影测量精度声明。2017图用于形体和门窗核对，不直接比较两张图的像素高度。

采用的条件参数包括左檐5.18m、左山墙6.516m、中间上檐5.60m、圆端墙顶5.95m、圆端半径1.65m。后退约1.67m的右瓦帽尖按3D投影修正为约7.03m且向右偏移；它不能从图像高度直接落到前墙平面。所有这些数字均为重建参数，不是测量值。旧GHSL18.602m只保留在研究输入中，未用于本模型高度。

完整后墙、后部屋面、圆端背面和低体确切延伸尚不可见。后侧采用闭合的保守形体和无新增窗格的墙面，并将其标为推定。C低体、圆端形状和右帽顶退距尤其需要 parent 的同相机渲染检查。

## 验证和复现

```bash
python build_model.py --output output
python check_model.py
python calibration/calibrate_facades.py
```

`common/` 中两份 helper 为原项目已审工具的字节一致副本，方便搬移重建，没有修改原公共工具。依赖 Python、NumPy、Shapely（支持 constrained Delaunay）、Pillow、SciPy、Matplotlib；不需要 Blender、浏览器或网络来生成 raw。

`output/structural-check.json` 检查每个部件实际 FLOAT32 顶点的闭合边、绕向、退化三角和正体积。`output/independent-model-check.json` 读取真实 GLB，对10处窗洞作穿墙射线并以邻墙作负对照，检查实际玻璃深度、法向和源归属。7组窗四角的条件投影最大误差约2.49px；左右屋顶控制点约0.04px/0.60px。这只验证所声明的条件相机和模型之间一致。

`output/portable-model-check.json` 在不依赖原公共目录的新临时位置完整重建，要求raw逐字节相等并重新运行GLB检查。`camera-2026.json` 提供建议原生审核相机的ENU矩阵、K、焦距和像素纵横比，勿用另一次look-at覆盖拟合的roll/pitch。本任务没有运行该相机的Blender或网页渲染。
