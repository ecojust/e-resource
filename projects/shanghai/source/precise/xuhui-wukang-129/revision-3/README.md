# 武康路129号德利那齐宅

市房管局第五批优秀历史建筑名录中的德利那齐宅位于武康路129号，登记编号5D091。街面照片可辨绿色“129”号牌，左为山墙，中部有低矮的门厅，右端为带弧形铁栏的圆墙。这三部分已在城市对象 xuhui-wukang-129 中合建。此次细化沿用同一地块、建筑坐标和已有模型，范围集中在两处拱形开口。

临街门厅有一道灰色拱套。2017和2026年的原照都能辨认从直段转过拱顶的连续斜槽，内侧还有数道光面窄边。灰套内露出的红门比背后的原粗洞更窄。弧阳台的红色门扇向街面打开，扇形上亮固定。两年的树叶和临时物分别遮挡部分构件，2026年冬季照片最适合辨认门扇、拱边和浅色墙面。模型按2026年的状态制作，门扇的打开角度属于从照片估算的值。

两期照片上，绿底“129”门牌折算到同一门面后的中心相差约1厘米。模型采用宽18.5厘米、高14.6厘米的门牌，数字轮廓按2017年原件测读，9字的中孔露出绿色底面。下排三个浅色字组只能看清外轮廓。门牌下方的小拱顶饰板、右侧把手和2026年可见的横向信口均做成有厚度的构件。两期的太阳位置分别用于同机位渲染；2026年照片的原始时区换算到上海为13时57分。

在两张实拍预留的20个位置，近远景各有19处直接命中对应材质，余下的2017年左拱肩偏1个原图像素。2017年六个数字笔画点、9字内孔及牌上木面共8点，在两档均直接命中。阳台旧式铁栏保留原模型的位置；独立抽查中的8条视线只有1条直接吻合，该处的栏杆曲线仍待重测。

[打开三维模型](../../../../wukang-129-arched-door-and-balcony.html)可查看两处原摄影站及七处建筑视角。街面宽度沿用已有模型的14.20米外围估算。后墙、屋坡及被遮挡的细部保留已有处理。栋界来自既有 Overture / OpenStreetMap 建筑要素，毗邻店铺单独登记。

程序使用与原模型相同的东、北、上局部坐标。旧版原始模型由2026年10月26日发布的脚本及输入确定，SHA-256 为 `c0915a9d76761865b4020d31397b8ef66ddb6efc4112bbee150264119754afa9`。可在父目录运行 `python build_model.py --output /tmp/wukang-129-original` 重建。此目录下的 `python source/build_model.py --output house.glb` 生成修订版，加 `--lod` 生成远景。源码包还包含发布压缩与校验程序。近景有4,174个保留构件、188,546个三角面与旧版的位置和法线逐项一致。远景保留4,042件盖瓦与底瓦的布局，并简化各件截面。
