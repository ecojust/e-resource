# 身份与可见形体研究

## 身份对应

1. 2017年 Antigng 原图和2026年 Windmemories 原图都显示同一红色拱门上的“129”门牌。左端山墙、中部退进、右端圆墙、弧形铁艺阳台和红瓦檐口一致。不是仅凭文件标题认楼。
2. 上海市规划和国土资源管理局2015年9月22日《上海市第五批优秀历史建筑名单》徐汇区条目明确为“XH-J-091-V 德利那齐宅 武康路129号”。原页面的公开归档、响应 SHA、最短事实摘录见 [official-address-record.json](evidence/official-address-record.json)，未复制官方全文到分发包。
3. 2026年原图右侧、即西南邻楼的店招为 LE LABO。真实 OSM POI `node13937894401@1` 位于另一栋 `way582319149@1` 内；沿武康路紧邻其东北的独立低层红瓦楼是 `way582319150@1`。原始节点和真实轮廓见 [location-context.json](evidence/location-context.json) 与 [osm-way-evidence.json](evidence/osm-way-evidence.json)。辅助航拍仅作屋顶关系的私人视觉交叉核查，像素不在本包，也未据其描绘几何。
4. 当前 Overture `2026-10-21.0` 要素的真实 `sources` 记录直接包含 `provider=osm`、`record_id=w582319150@1`。因此可桥接到 GERS UUID `e73638a1-a217-47f7-a17b-151902f0fece`，再通过当前 feature table / ownership 精确锁定 macro、local ID 和 near owner。

照片 GPS `[121.435278,31.208889]` 只是拍摄位置线索，可能位于道路上，不是住宅地址点，也没有用作锚点或“最近建筑”匹配依据。OSM 目标 way 本身没有129门牌标签，文档没有给它补造地址。

原 OSM 节点多边形和当前 MVT 导出的轮廓存在约0.3057m Hausdorff差异，符合现有坐标离散化；两者的对应记录是直接来源关系。冻结的仍是当前城市真实原环，而非重新下载的原 OSM 环、卫星重描或包围盒。

## 可落实与不能证明的细节

可见：两层主体；左端三角山墙及矩形窗；中间红色拱门、灰色线脚、窄侧窗和退进上层；右端弧墙、半圆券高窗/门与扇形上亮、铁艺弧阳台、红瓦盖与灰色层檐；浅米色抹灰、灰色墙脚与窗台、深色窗框、雨水管。逐项记录见 `visible-details-and-gaps.json`。

未定：高度、圆弧半径、退进量、瓦坡、隐藏后墙、完整外侧立面、后院产权和室内。2026与2017年空调和遮挡不同，后续优先重建2026状态；无法观察的位置保持保守并标注。当前 GHSL 18.602m不能用于把照片里的两层小楼拉成高楼。

## 精确替换与本轮验证

候选唯一源键对应 local3733。将来运行时只能屏蔽该ID、近景重建只能省略该源键；同近景其他17个要素全部保留，不按半径、整微块或邻楼包围盒删除。真实邻楼 LE LABO /公寓不是本栋模型的一部分。
