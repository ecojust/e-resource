# 巨鹿路314号住宅弧券门架与铁花双扇

市房管局把5A057登记为巨鹿路314号住宅。具名相册正面及两幅斜照可相互校对，绿牌“314 巨鹿路”位于正视入口时的右侧门墩。 [第五批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

门墩上部各有一座叠线墩帽。两扇红色院门嵌在弧券下方，门上的卷草纹以对向弯曲的细铁条构成。 [幸福里巨鹿路314号小区外观相册 未标日期](https://m.xflapp.com/xiaoqu/sh-6846584683107451143.html) · [幸福里巨鹿路314号小区外观相册 未标日期](https://m.xflapp.com/xiaoqu/sh-6846584683107451143.html) · [幸福里巨鹿路314号小区外观相册 未标日期](https://m.xflapp.com/xiaoqu/sh-6846584683107451143.html) · [百度地图街景 20200221](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122002211507190925O) · [百度地图街景 20210110](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122101101030270557I)

白灰弧券两端落在方墩上。券底与铁门上沿留有透空，每片红底门扇有回卷的黑色铁条，中部可见对向交叉的菱形。 按双扇院门净宽约2.45米推算。墩柱后侧、券体进深和门板厚度依据正照、斜照估算。

五幅具名外观照片的两次侧视可清楚辨认314号绿牌。正照显示弧券门架、方墩和两片红色铁门，背后主宅被围墙和门扇遮挡。沿街对照到的多层白楼与图中单独院门相邻。保留原片区全部楼体、院墙与地面，独立展示临街门架。
