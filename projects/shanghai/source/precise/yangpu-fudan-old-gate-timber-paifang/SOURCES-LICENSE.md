# 现址、名单与照片

复旦大学英文校史图文明确指出，这座老校门的原门建于1921年，1950年代拆除，现物于2004年底在原址重建。市房屋管理局名录4G008仅在同组建筑中写「校门」，未给具体校门坐标或摄影。项目二手发现清单中对应子条目的年代为「1950年代」。本件确定的是燕园旁这处有校方照片和地理轮廓的2004年复建物。该实物与保护名录中「校门」的对应仍待标明位置的正式档案。 [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [复旦大学校方说明](https://www.fudan.edu.cn/en/2020/0422/c1092a104775/page.htm)

Whw 的《Fudan-building3.jpg》在 Wikimedia Commons 标示 PD-self。另两处校方发布图片及 Dreamstime 编辑照片的版权各属其权利人。数字角点、线距与结构轮廓是此次公开的量测成果。公开的摄影机对照图只渲染模型，源码包包含两组程序纹理。 [Whw 原文件](https://commons.wikimedia.org/wiki/File:Fudan-building3.jpg) · [招生站原图文](https://gsao.fudan.edu.cn/2d/a9/c1792a11689/page.htm) · [反拍的编辑照片记录](https://www.dreamstime.com/shanghai-china-june-historical-old-gate-handan-campus-fudan-university-yangpu-tourist-attraction-heritage-image385286136)
