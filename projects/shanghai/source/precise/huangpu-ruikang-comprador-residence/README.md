# 瑞康洋行买办住宅（贝润生宅）历史庭院立面

上海市房屋管理局第三批优秀历史建筑名录将瑞康洋行买办住宅列为3A020*，地址黄陂南路25号乙，并注明“于2000年左右灭失”。2000年11月《新闻晨报》在拆迁争议期间采访贝家后人，记下宝安里5号的三层旧宅及其1999年入选名录的情况。黄陂南路旧宅与南阳路170号贝轩公馆分别考证。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [《新闻晨报》当时的现场报道](https://news.sina.com.cn/c/143685.html)

瞿凯拍摄的庭院照片于2019年7月再刊。第二篇文章也将同张照片署为“瞿凯摄”，称其为贝润生家族在黄陂南路的老宅。底片日期待考。两张另一个角度的旧影补出下层中央三券和侧返腰线。[2019年再刊及摄影者署名](https://weibo.com/ttarticle/p/show?id=2309404389672812996115&mod=zwenzhang) · [马尚龙的署名图说](https://www.sohu.com/a/458152160_120053387) · [不同角度与街坊图](https://www.meipian.cn/326q6zt4)

模型刻画五段庭院面，两段双券廊后退，围合中央叠券。券脚落在独立的石柱上，石栏有透空。两端配有较深的双窗和浅色窗下墙，中央山花保留半圆窗罩檐和屋顶细杆。旧航片估出的立面宽约30米，楼高、窗扇分格和露台栏杆的细部按照片估计，庭院与背面留待原图。各份影像只作为参考，模型用原创几何和材质表现。[形制与图像档案](reference-review.json) · [可旋转的历史模型](../../../ruikang-comprador-residence-history.html)
