# 协进大楼沿街五格透花石阳台与挑托

市级名录载基督教协进会大楼，地址圆明园路169号。Livelikerw于2014年1月27日拍下这段沿街深色砖立面，中央石阳台与灰白色端部和相邻塔楼可分辨。 [第五批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

灰砖立面的中间挑出一座浅石色阳台，五格放射状透栏夹在方柱之间。两只石托从外缘逐渐收回到墙侧。 [Livelikerw 2014-01-27 15:23:02](https://commons.wikimedia.org/wiki/File:Associate_Mission_Building_Rockbund_Shanghai.JPG)

正看可数五格，每格有八向石杆和周边透空。转到侧面能看到围栏转角和承托板底的两道内收曲线。 以栏柱估算栏板通高约0.8米。浮雕倒角、托臂下部弧度与阳台背面按正斜两侧的透视比例近似。

市表、协进大楼具名照片与圆明园路169号的地址检索相符。沿街上部石阳台只有一段外露挑托，原建筑的墙、窗、屋顶、地面和临近独立建筑均保留，拍到的五格透花石阳台独立展出。
