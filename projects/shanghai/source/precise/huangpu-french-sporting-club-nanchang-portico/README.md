# 法国体育总会南昌路门廊与券窗阳台

上海市第四批优秀历史建筑4C005登记为法国体育总会，地址南昌路57号，登记时使用单位为科学会堂。门侧的市政府牌记载建筑建于1931年，砖混结构，采用红瓦屋面、曲线形山花和红砖叠涩装饰。已交付的南昌路47号科学会堂1号楼位于本栋东北方，两者原有足印相隔约77米。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2014年刊出的正面和斜面照片中，入口两根白色竖槽圆柱支承三坡筒瓦短棚，铁门后的玻璃隔扇与街上的门扇有进深。上层阳台前栏镂出横长花格，侧栏上的孔较短，背后的高窗有宽浅色券框。门前黑底字牌写作“上海科技发展展示馆”，显示拍照时的用途。[高参88的门前近照和市牌](https://blog.sina.com.cn/s/blog_5d1bdf480101gxl2.html) · [思苽2016年的旧址回访](https://blog.wenxuecity.com/myblog/21273/201608/1215332.html)

2015年12月冬季街景露出树后完整的券窗扇、横檐和后侧山花。2023年6月四处街道机位对两根石柱作直线交会，得到中心距约2.85米；门轴在底图临街边中点向西南约2.32米。照片不足以精确量得门槛进深、每块砖的尺寸或院内屋面形状。模型保留门廊、门后首跨立面与阳台，南部主体、门两侧外伸街翼、街边独立铁栏、街树和相邻各栋仍用原城记录。
