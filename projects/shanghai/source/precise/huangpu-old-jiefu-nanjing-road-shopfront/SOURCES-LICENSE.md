# Source photographs and licence

The reconstruction depicts the street fronts of the Old Jiefu building at 257 Nanjing East Road, Shanghai. The measured window proportions, steel patterns, parapet contours and building edges were interpreted from the photographs below. The architectural geometry in the raw GLB, both web GLBs and the editable Blender file is distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The project scripts and the original procedural facing-brick texture use the project’s [MIT licence](../../../../../LICENSE).
