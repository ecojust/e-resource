# 思南路48号住宅院侧曲纹窗间与白色贴条

5A059在市表登记为住宅，门牌思南路48号。市表5A059登记思南路48号住宅。取Antigng署名的2018年7月30日院照中，上部窗间两行白色曲纹与细竖条。

上带中央两道曲边围起尖叶形，外侧有斜条和竖向分隔。 下带宽开间的曲纹围出内凹圆角矩形；中央较窄处两道圆弧相接，上一层两扇的洞口尺寸不同。

白色贴条之后可见赭黄色粗墙。绝对尺寸、木材或抹灰配方、旧漆色及窗内布局缺少测绘；从同相原图取各片轮廓。
