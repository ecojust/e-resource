# 中华基督教女青年会大楼

上海市房屋管理局第二批优秀历史建筑表第2A024条，依次列出「女青年会大楼」「市政设计院」「圆明园路133号」。李锦沛设计的这幢楼面向圆明园路，主体采用褐色清水砖与花岗石，出入口及窗间装饰融入中国传统纹样。地图中的北邻是另有独立编号和门牌的149号哈密大楼，沿街共墙位置保留既有城市数据。[名录、设计沿革与出版资料](reference-review.json) · [独立地块与门牌核对](footprint-review.json)

东面有七组竖向窗，南转角朝小通道开窗。六层街墙上方可看到逐步后退的两层。中央入口的门额从右向左写「中華基督教女青年會全國協會」。模型分别绘制回纹石框、两侧蓝色长灯、窄幅琉璃瓦檐、三组菱花门楣和花岗石窗裙。现状沿街店铺的轻型遮篷按照片表达，店铺商标另计。[2019年正面与入口特写](https://www.sohu.com/a/337320107_391448) · [2026年街口斜视与历史照片](https://www.thepaper.cn/newsDetail_forward_32727599) · [独立照片](https://commons.wikimedia.org/wiki/File:Y.W.C.A_Building.JPG)

2026年刊载的历史回顾记1930年开工、1932年建成，1940年代末加建一层。2019年建筑介绍记1933年竣工。模型按近年照片可见的临街轮廓表达，后部加层范围仍待核实。[两篇史料与早期照片出处](reference-review.json)

U形底库地块1891在东翼与北侧149号共墙处存在约十厘米的平面重叠。模型取临街约12米进深，在最后一组北端窗口以外留出约0.8米的原城市边带。院落、西翼和北邻各有原有城市几何。立面高低、上层退台尺寸及遮挡部分按照片比例估计。[原生城市几何记录](footprint-review.json)
