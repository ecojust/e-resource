# 延安中路816号严同春宅东宅街面

上海市房屋管理局第二批优秀历史建筑2B025以“花园住宅”登记延安中路816号，公布时使用单位为市仪表局。2024年家属在A楼重访故宅，严寿沄回忆东宅816号由父亲严载如一房居住，西宅830号由叔父一房居住。报道记载1933年建造，由林瑞骥设计。“严同春”是家族沙船商号。严应钧为严家经营者。2015年12月18日《解放日报》迁入816号办公。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [家属访谈与1949年后的沿革](https://www.jfdaily.com/wx/detail.do?id=824221) · [迁入当日的报道](https://www.shobserver.com/wx/detail.do?id=8194)

1998年延安路拓宽时，原沿街第一进拆除，主楼和花园得到保留。2022年7月23日，Shwangtianyuan从街道拍到浅色砖柱、浅进深廊下的棕色门扇、气窗、铁窗与带饰件的石质窗下墙。本件取这些相互连接的街面构件。院内主楼在2024年报道中另有正面照，可见门阶与数层木窗门廊，两处立面在资料中分别标明。2022年沿街构件的复建日期和1933年原样仍待图纸核定。[2022年街面原片及许可](https://commons.wikimedia.org/wiki/File:816_Middle_Yan%27an_Road-20220723122541.jpg) · [建筑和影像记录](reference-review.json)
