# 公和洋行大楼切角圆章与卷草檐带

上海市第五批优秀历史建筑名录的5A005记为公和洋行大楼，现名一栏写华德大楼，地址为四川中路650号。三行后的5A008另列四川中路620号华德大楼。两个门牌点在原城市图上分别落入1939号、199号建筑。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

Antigng于2015年7月20日14时40分拍摄《公和大楼》，切角上方并列两方圆章，可沿侧面数出四块同形卷草板。相隔92秒的《华德大楼》记录了另一栋有连续阳台的建筑。[《公和大楼》，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E5%85%AC%E5%92%8C%E5%A4%A7%E6%A5%BC.jpg) · [《华德大楼》，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E5%8D%8E%E5%BE%B7%E5%A4%A7%E6%A5%BC.jpg)

正面两方圆章之间有竖缝，左边四方随外墙折去。转到斜面能看到卷草绕着平滑圆心，檐底和红色木窗之间留出阴影，近远两档都可辨认纹饰的排列。 中央两方饰板总宽暂设1.9米，纹饰深度与侧面转角均按照片比例估计。截面止于可辨的上檐和窗上段。 独立观察页保留六方装饰及其转折。
