# 严家花园愚园路山墙红砖烟囱

上海第四批优秀历史建筑名录4M011将严家花园列在愚园路699号。Antigng于2018年2月13日从街面拍摄了这处住宅，枝叶间清楚可见贴山墙的红砖烟囱、灰色粗石墙面、棕红封檐板和上方红瓦。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Antigng的署名照片，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:愚园路699号住宅.jpg)

模型取露出围墙的构件。烟囱自砖胸经两级台肩收窄。灰色斜压面把雨水引离立面，砖在转角处错缝。屋面单元上边压入上一行，山檐的浅灰包边和下方红色封檐板各有厚度。

构件尺寸按砖模数和单幅照片比例估算。顶口受树冠遮挡，模型终止于可读上段。侧面进深、瓦的断面和材质分布为估计。原照的树木、电线和围墙位于构件前方。几何、程序纹理和本项目渲染均为重绘。
