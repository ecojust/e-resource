# 青云里襄阳北路22弄入口叶饰石柱头与圆盘

5B048在市表登记为青云里，门牌襄阳北路22弄。取襄阳北路22弄入口左侧石柱的上部。高参88于2023年8月5日发表的正面和斜面照片同时显示凹槽柱身、叶饰柱头、方块上的凸圆盘与上方石檐，图中可读22弄门牌。

叶饰与柱颈间有两层浅横线，叶尖上方有小卷叶。转角照片显示叶形装饰也延伸到右侧面。 叶饰上方是贴方石表面的浅凸圆盘，最上方两枚小托块支撑外挑檐口。市标牌给出22弄12–30号及44弄1–6号，模型的具体位置另以正照中的22弄路牌核对。

两张照片均为门外视角，叶纹在石面上风化，纹的根数和石材成分未经检测。背面、门内和44弄另一个出入口未进模型。
