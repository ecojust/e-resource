# 花园住宅群南昌路124号半圆券门与街柱

上海市房管局第四批名录把南昌路124号编入4C007花园住宅群。124号街门向南昌路开，绿色门牌钉在右柱圆饰下方。东面约34米处是另列4C006的上海别墅110弄。两处共享一片原城粗模型，124号只细化了自家门前。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

Fayhoo 的照片可见券套的两道浅色线脚、后方分格气窗、暗色街门和前方两根方柱。2020年冬的正街影像补足了柱帽和圆饰，2023年6月从门前东西两处核对两门柱和拱顶位置。近照中两根街柱正面各有一条浅灰色竖带，模型按分缝逐层还原。[Fayhoo 原照片](https://commons.wikimedia.org/wiki/File:Park_Terrace.jpg) · [现场定位与尺寸](measurements/measured-facade.json)

门券顶高约4.0米，西、东两街柱分别高约2.5米和2.6米。两个测量站的交会角约87°；光照、树干和底图偏差使轮廓位置有约0.2至0.5米的不确定度。后门进深、门板厚度和街面下方的截面取估计值。楼上、其他门与后院仍保留原城模型。
