# 西童公学北四川路校舍半圆山墙与三联窗

市房屋管理局第四批名录4F018列西童公学为四川北路2066号。1930年上海Kelly and Walsh出版《Shanghai of To-day》第三版，图版29题为“Shanghai Public and Thomas Hanbury School for Boys, Hongkew”。Virtual Shanghai馆藏将图像编为1928年。摄影者在馆藏记录中未署名。[市名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [图版29](https://www.virtualshanghai.net/Photos/Images?ID=15111) · [书目信息](https://www.virtualshanghai.net/References/Bibliography?ID=408)

画面左端的宽山墙以两道弧形压边收顶。中窗比左右两窗高，窗头略拱，外面有一条上扬的窗楣。边窗的水平挑檐各带一块突出的楔形饰石。模型保留顶饰、压边和两肩可见的一小段瓦坡，材料明暗以黑白印本为准。[原图取点](reference-review.json) · [展示范围](placement-review.json) · [建模程序](source/school_gable.py)

同一馆藏的1916年汉璧礼男校照片标为Haskell路，另有Boone路的西童校舍长廊。两者的街名与图像构图均另有记录。[Haskell路校舍](https://www.virtualshanghai.net/Photos/Images?ID=2006) · [Boone路校舍](https://www.virtualshanghai.net/Photos/Images?ID=282)
