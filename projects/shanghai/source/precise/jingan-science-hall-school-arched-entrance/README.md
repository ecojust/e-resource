# 上海市科学馆1号楼石券门与山墙小阳台

上海市第四批优秀历史建筑名录将4B019列为「上海市科学馆」，门牌胶州路601号，名录现名静安区业余大学。2015年1月22日，Livelikerw从院门外拍到红砖山墙；2024年「微不足道」发表的校门及院内两幅照片分别可读601号和教学楼1号楼标识。两组照片中的中轴钢窗、铁栏小阳台及山墙肩线相合。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2015年署名照片及许可](https://commons.wikimedia.org/wiki/File:601_Jiaozhou_Rd._Shanghai.JPG) · [2024年署名游记](https://www.meipian.cn/57uah7e2)

模型从底部三重石券至山墙尖约17.94米，包含门内暗面、浅色石框、两层三列窗、上部窄窗和有底部托架的铁栏小阳台。2015年远照提供外廓，2024年院内照提供券环与栏杆细节。2021年2月22日胶州路上两处街景为窗轴和山墙提供位置。平面估计误差约0.50米，绝对高度约0.65米。券环退进与栏杆厚度依外观估计。三组原图均只作判读，下载模型使用原创材质。[资料与原件摘要](reference-review.json) · [照片坐标与双站交会](../../../data/audit/science-hall-school-arched-entrance-v1/preflight/photographic-registration.json)
