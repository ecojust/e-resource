# 范园8号李铭住宅三联券窗与波形老虎窗

华山路1220弄8号。2002年照片中8号主立面顶层三樘券窗、窗下浅饰板、坡顶陶瓦与中央波形老虎窗。

三联窗所在墙的宽度按比例估计为4.64米。红瓦坡面和压顶的进深由斜视比例估计；建筑底楼、两翼及相邻10号均在模型范围以外。

照片按原作者题注分开辨认8号与10号。外观照片只提供链接和署名，本页九张图均为独立原创模型的渲染。
