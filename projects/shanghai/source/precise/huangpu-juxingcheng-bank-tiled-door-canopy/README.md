# 聚兴诚银行大楼入口瓦门罩与檐下斗栱

上海市第五批优秀历史建筑名录将聚兴诚银行大楼登记在江西中路250号。Fayhoo于2015年9月3日拍摄的照片也标注该门牌；入口上方的传统瓦门罩横跨街角石门。参照物是这张上海现地照片。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Fayhoo原照，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Juxingcheng_Dalou.JPG)

正面可辨前坡细密的圆垄、整排瓦当以及檐下六组斗栱。斜看可见斜脊从檐角抬升至正脊，短侧坡向后收窄。圆垄间的瓦面、屋脊盖板和斗栱间的阴影壁在三档中均用深度和材质区分。 门罩沿街宽暂定6.80米。坡深、遮蔽的背面收口、瓦径与斗栱出挑依照片估计；仅处理门罩以上的构件。 檐下招牌遮住门头的一段，作品结束在斗栱下缘。

250号门牌点距原屋2778约0.21米，同角邻近257号原屋。门罩的平面坐标和进深尚无实测尺寸，独展保留原楼、原入口地面及邻房。
