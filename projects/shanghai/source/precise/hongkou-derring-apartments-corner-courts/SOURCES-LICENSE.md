# 德邻公寓资料与许可

建筑、钢窗、石门面、屋顶、面砖贴图和展示预设由本项目制作。程序及原创模型采用[仓库许可](../../../../../LICENSE)。面砖贴图由固定随机种子生成，第三方摄影和航空影像只作判读资料。公开平面图呈现从多个来源归纳的尺度和轮廓。
