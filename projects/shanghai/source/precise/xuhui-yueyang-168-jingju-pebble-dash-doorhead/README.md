# 上海京剧传习馆1号楼鹅卵石墙与门楣双圆饰

5D042在市表登记为上海戏曲艺术中心，门牌岳阳路168弄（1号楼 、2号楼）。徐汇文旅2021年3月的《1号楼抢先看》照片中，“1号楼”标字就在鹅卵石墙面上。其左侧门套有两枚扁圆饰，往上接门柱的折线柱头和向外逐级挑出的收边。本作截取门楣右部与旁边一小段干粘石外墙。

2021年近景带徐汇文旅水印，门头压线内有两枚圆饼，侧柱身带三条分缝，顶上浅灰多级挑边高低依次转折。 2022年建筑可阅读报道明确这栋1921年三层住宅采用干粘五彩鹅卵石，并有颗粒特写；模型用独立生成的五组石色和实体凸粒表现粗面，与门套平面区分。

5D042登记岳阳路168弄1号、2号楼。本作仅依能指明1号楼的门套近景。原照仅见门的一段，模型高度为截取范围，石粒颜色受光照影响，粒径、圆饰厚度和挑出长度均为估计。
