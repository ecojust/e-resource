# 元培楼红砖转角窗与叠檐

长宁路865号。二层元培楼的临角三樘窗、清水砖与浅色竖向线脚、转折檐口及外置雨水管。

长立面节选约4.28米，转角返回约2.12米，高约3.13米。砖缝和型材深度属比例估算；朝向和实尺尚缺测绘控制。

元培楼与杏佛楼分址辨读，选取1930年两层元培楼，文章图注明确。实景摄影仅按来源署名引用。
