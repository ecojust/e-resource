# 庄行东兴楼茶馆书场八角玻璃花窗与透空裙板

5Z001在市表登记为庄行东街沿街商铺民宅，门牌庄行镇一新路95-97号（单号）、庄行东街6-50号（双号）、庄行东街17-43号（单号）。庄行东街17号东兴楼茶馆书场位于进入第五批名录的沿街商铺民宅范围内。Dragon在2023年11月24日拍了这座茶馆的临街正面、东兴楼门额和沿南桥塘的一面。本件取临街二层左组窗中央相邻四扇，描出窄木梃、上下两排切角玻璃和下方穿空的木裙板。

每扇中央的两道细横格过角后与短竖格相接，上下留出两块长八角形玻璃。两侧的梃料比格条宽，吃光后呈灰褐和暗红两种层次。 裙板上、下通长横木之间是一排短落柱。细缝从前到后贯通，斜视时能辨出裙板与上面窗扇不在同一平面。

房屋开间比这四扇窗更宽。玻璃的亮色反映拍摄时的天空，木框截面、前后厚度和绝对尺度按照片比例估计。
