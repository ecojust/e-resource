# 愚园路1055号黄家花园住宅

从愚园路1055号向院内望，可以看见弧形阳台和深红色木门。门后花园正面沿南北向展开。阳台下方的三个折面各开一组窗，旁边的方柱撑起带齿饰的入口。南端另有一座两层日光室，平屋顶栏板上的横、竖和斜条围出八个三角孔。屋顶东坡有两扇凸出的老虎窗，北侧还有一扇贴近屋面的斜天窗。

## 地点与时间

上海市第五批优秀历史建筑名录以5M014登记这处住宅。黄氏家族记述把建宅放在1924年婚后。家族相册照片已经出现花格平露台与弧窗，两处的形态都能与当代照片对应。模型主要依据高参88于2016年6月拍摄的院内照片，另用较早的花园全景量测檐高与柱距；该全景拍摄日期未核定。弧台上的薄金属雨篷在2016年两张近照中可见。

## 尺度与范围

地籍图南边以约13.5米配准，拟合主檐7.45米，东门廊两根方柱中心距约2.93米，弧窗外半径约2.37米。四个尺度都受单幅照片的透视和地籍图配准误差影响。模型保留花园面开口、外廊、两侧次墙与屋顶。树丛遮住的窗格取相邻完整窗的构造；后部采用地籍轮廓，实照没有覆盖的墙面保持平整。展件使用本地米制坐标。
