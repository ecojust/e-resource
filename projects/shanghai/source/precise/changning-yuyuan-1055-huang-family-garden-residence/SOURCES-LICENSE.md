# 黄家花园住宅资料与许可

- 上海市房屋管理局公布第五批优秀历史建筑名单，长宁区条目5M014给出愚园路1055号与住宅登记。[市房管局](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)
- 高参88的现场组图记录门牌、弧形阳台、方柱门廊、花格露台和地籍图。原始尺寸、日期及文件摘要见本项目照片登记。[高参88照片](https://blog.sina.com.cn/s/blog_5d1bdf480102zefw.html) · [照片登记](measurements/photograph-register.json)
- 媒体刊出的屋顶近景用于辨认两樘老虎窗和浅色斜天窗。同组另一张花园正面图片与高参88刊载的全景为同一快门，两次刊载只计一个观察方向。[屋顶照片](https://m.thepaper.cn/baijiahao_16580844)
- 赵馨源、华安《历史烟尘中的愚园路1055号》记述黄氏一家婚后购地建屋、战后在宅内生活及1951年出租的经过，附家族相册花园合影。合影的具体拍摄年待考。[上海长宁文章](https://www.thepaper.cn/newsDetail_forward_19553743)
