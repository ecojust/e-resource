# 派克公寓455弄双拱题名门廊

上海市房屋管理局第四批名录4C012把“派克公寓（花园公寓）”登记在复兴中路455号。街面小绿牌写455弄；2015年Antigng的原图清楚显示石带上的四个旧体字“花園公寓”。左券洞通向院内，右券洞设深色铁栅，两洞共用红砖墩。正面照片和院落鸟瞰分别用于确定构件和楼栋。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Antigng，2015年，CC BY-SA 4.0](https://upload.wikimedia.org/wikipedia/commons/4/49/%E6%B4%BE%E5%85%8B%E5%85%AC%E5%AF%93.jpg?utm_source=commons.wikimedia.org&utm_campaign=imageinfo&utm_content=original) · [Legolas1024，2020年，CC BY-SA 3.0](https://upload.wikimedia.org/wikipedia/commons/6/6b/%E8%8A%B1%E5%9B%AD%E5%85%AC%E5%AF%93%C2%B7%E6%B4%BE%E5%85%8B%E5%85%AC%E5%AF%93%C2%B7%E4%B8%8A%E6%B5%B7.jpg?utm_source=commons.wikimedia.org&utm_campaign=imageinfo&utm_content=original)

2021年1月8日的两处实景站提供拱肩、拱顶、墩底、门槛和栏杆共14个对应点。左洞交会净宽2.72米，右洞可见宽约2.31米；根据正面照片的两孔宽度比，右边遮挡处补足至约2.61米。栏杆和金属字都是新绘的模型几何。门后的公寓室内和院中独立红瓦宅未纳入这块立面。[测量与误差](reference-review.json) · [原城地块](footprint-review.json)
