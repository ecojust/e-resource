# 华童公学中州路校舍操场侧中央阳台与钢窗

市房屋管理局在第四批名录4F010中将华童公学、汉壁礼男校及光华大夏大学附属中学列在中州路102号。Antigng于2015年拍下旧址铭牌。[市名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [铭牌原照](https://commons.wikimedia.org/wiki/File:%E5%8D%8E%E7%AB%A5%E5%85%AC%E5%AD%A6%E4%BC%98%E7%A7%80%E5%8E%86%E5%8F%B2%E5%BB%BA%E7%AD%91%E9%93%AD%E7%89%8C.jpg)

校方旧网站的「现校区部分校景」从操场正看一排三层窗。中央楼段的浅色檐头高出两侧长檐，下方一对门扇通往短阳台。图片005在2006年12月已存档，拍摄日期未署。Legolas1024于2017年从上方拍到同一段立面，能分清浅色栏杆、棕红边缘及瓦坡上两级高度。[校方旧站](https://web.archive.org/web/20070616142514/http://www.sdfz.sh.cn/sdfzweb/introduce/oldschool.htm) · [校方照片005](https://web.archive.org/web/20061230112900im_/http://www.sdfz.sh.cn/sdfzweb/introduce/images/005_b.jpg) · [2017年全景](https://commons.wikimedia.org/wiki/File:%E5%B8%88%E5%A4%A7%E9%99%84%E4%B8%AD%C2%B7%E4%B8%8A%E6%B5%B7%E8%99%B9%E5%8F%A3%C2%B7%E5%85%A8%E6%99%AF.jpg)

模型据2017年照片，在阳台两侧各取两窗。瓦檐、栏杆、窗格、门边和阳台底面分别建模；连续的灰瓦坡从中央檐头后方经过。展示宽度约8.49米，由原照比例估算。树冠遮挡的下层与操场其余楼栋留于影像资料。[照片取点](reference-review.json) · [置地说明](placement-review.json) · [作者程序](source/courtyard_balcony.py)
