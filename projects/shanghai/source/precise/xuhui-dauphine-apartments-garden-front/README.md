# 道斐南公寓南向花园立面

建国西路394号原为福履理路394号。上海市房屋管理局在第二批名录2D016记为“道斐南公寓”，公布时使用“建国公寓”。徐汇区文化局记1935年建造、赉安洋行设计、九层，市地方志亦列为1935年建成的一字型公寓。《上海建筑施工志》记安记营造厂承建，但在姚长安传中计作十层。模型以朝南的九层外墙为依据，屋顶附属层的历史计数仍待原始图纸说明。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [徐汇区文化局2006年记录](https://web.archive.org/web/20141108123650id_/http://whj.xh.sh.cn/xhwh_website/HTML/xhwh/xhwh_wwbh_wbdw/Info/Detail_25738.htm) · [上海住宅建设志](https://web.archive.org/web/20190415152444id_/http://www.shtong.gov.cn/newsite/node2/node2245/node75091/node75095/node75115/node75127/userobject1ai90867.html)

天平街道文化中心保留两张该楼的南面实照。直幅照片带有2008年8月18日的原始相机日期，横幅近照仅有2012年4月5日的文件编辑日期。Livelikerw于2014年1月24日拍摄的照片可核对中央凸窗、翼部圆窗、悬挑弧形阳台与主入口扁圆雨棚。树木遮挡的窗扇格数、层高和阳台进深按可见部分估计。仅重建南面及其后方约4.7米的楼身。[天平街道文化中心原幻灯片](https://web.archive.org/web/20140502032004id_/http://tianping.xh.sh.cn/html/xh_tpwhzx/Flash_yffb/you/you-6.swf) · [2014年署名照片](https://commons.wikimedia.org/wiki/File:Dauphine_Apartments.JPG) · [图片与发布信息](reference-review.json)

地名点落在院内。核对四期航片以及2020年2月22日建国西路两个站位，可见南面中央凸段的交会位置落在原城市要素1470内，其正面浅色挑板与历史照片相符。东侧1545的长红坡屋顶属于另一排房屋。保留西侧邻楼、原院内要素1261和楼体北部，仅切开主楼南面；门前道路与绿化沿用底图。[街景测向与实体定位](frontage-location.json) · [底图来源](footprint-review.json) · [独立查看与模型下载](../../../dauphine-apartments.html)
