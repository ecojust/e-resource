# 虹口救火会

哈尔滨路2号是市房屋管理局第二批优秀历史建筑名录2F011登记的地址。吴淞路560号见1994年上海市人民政府颁布、2011年拍摄的沿街保护牌。牌上记载该建筑由工部局设计，于1917年竣工。地方史文章记1915年迁建，沈家湾早期救火队另有原址。虹口另有1888年早期瞭望塔记载，各资料写34.2米或36米；现塔沿用早期构件的范围与测量口径尚未查清。2019年与2026年的照片可以对照吴淞路、武进路交叉口现存的凹弧轮廓和砖塔。[市级名录、现场牌照片与建筑史](reference-review.json)

本次制作西南街角的三层楼、四开间弧面、双层开敞长廊、红砖端翼及方形瞭望塔。现照片中，四门的上部为红框玻璃、脚部为蓝色，牙子下的弧形檐面写有 HONGKOU FIRE STATION。两层栏杆透空，黑色小方牌在栏间重复。塔部有白石券顶窗、金属围栏和多边形小亭。塔顶收分、门窗尺寸与屋顶小瓦坡据公开照片估计。[2011年立面与塔的照片](https://commons.wikimedia.org/wiki/File:Hongkew_Fire_Station_@2011.jpg) · [2019年街角高位照片](https://commons.wikimedia.org/wiki/File:虹口救火会·上海虹口·俯拍.jpg) · [2026年街景](https://commons.wikimedia.org/wiki/File:20260208_Hongkew_Fire_Station.jpg)

整体单位用地和临街建筑各有独立地图对象。建筑模型随14-13720-6693内3165号楼体配准，东向长翼余段、旁侧其他建筑及后方独立钢架保留既有城市表现。历史建筑照片只用来核对外观，模型采用手工网格和材质。[地块、街角归属与影像](footprint-review.json)
