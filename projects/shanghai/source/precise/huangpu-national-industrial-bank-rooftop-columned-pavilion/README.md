# 中实大楼屋顶方亭双柱与弧饰额枋

2014年冬日照片从街口仰视中实大楼，可见圆转角之上的方亭。两根圆柱与左右方墩间有阴影，檐板下的弧饰分作五组。 [市房管局第五批名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Livelikerw原照，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:National_Industrial_Bank_Building_Rockbund_Shanghai.JPG)

正视可逐一识别两圆柱、两方墩、五组弧形浅浮雕及柱后退进。斜视能看见柱径、外挑檐和屋顶栏杆的两个圆角。远档保留这组结构并减少圆柱与弧饰的曲面分段。 以两端方墩外缘间约4.65米为比例。后墙、柱径、柱后进深和檐板后段由正面与少量侧面可见尺度作估计；模型下沿止于圆角楼面题字以上。

北京东路130号门点和中实大楼实名点均落原楼3122。163号北京公寓位于另一个原楼760。圆转角上各层没有经测绘定位的切面，本件独展，主楼及其他建筑保留。
