# 中苏友好大厦南广场序馆与中央塔楼

延安中路1000号旧称中苏友好大厦，1955年建成，现为上海展览中心。第四批优秀历史建筑名录编号4B001。本次制作取南广场尽端的正方形序馆，中央大券、两侧小亭和塔身两层列柱均能在2018至2026年的正面与斜面照片中对应。

《上海名建筑志》记载当年的中央大厅边长46米，鎏金钢塔标高110.4米。2022年修缮采访另记顶端红五星距地约114米。照片量取的层位、窗框、门洞收口和侧面纵深为估计。2024年正照上的临时展陈横幅和入口前独立雕塑另行区分。塔后长厅是原工业馆，今天也称中央大厅。两侧展厅、整座庭院柱廊及北侧友谊会堂留待后续调查。
