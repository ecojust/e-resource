# 巨福公寓公共楼梯马赛克踏步

乌鲁木齐南路176号的巨福公寓，市级名录4D033也列作安康公寓。华东建筑设计研究院有限公司历史建筑保护设计院发表的修缮记载，配有底层平面、典型层平面和楼梯细部照片。该照片记录了深灰色小方砖铺心、两边茶褐色饰带，以及前沿一线浅色的圆钝踏鼻。[保护修缮记录](https://www.sohu.com/a/978971150_121124642)

模型取照片中连续四级台阶和少量侧墙。最近一级的可见格缝支持约40格总宽，两边各约6格。历史典型层图中，楼梯井两侧的净宽约18至20像素。以原城两条长墙37.92和38.52米标定图宽，楼梯净宽约1.00至1.12米。模型取1.08米，折合每格27毫米。原图边线各有约两像素的读数误差。室内共有两部楼梯，照片未注明其中哪一部，因此保留独立展示。2013年Livelikerw所摄的两份外观另作同址核验。[2013年街景](https://commons.wikimedia.org/wiki/File:Defour_Apartments.JPG)

楼梯几何、色块与灰缝均为原创。近景分出小方砖，远景保留中央铺心、级鼻和两侧色带。[资料及量测](reference-review.json) · [原城核对](placement-review.json)
