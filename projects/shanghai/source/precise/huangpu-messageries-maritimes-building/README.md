# 法国邮船大楼 · 浦江大楼

上海市房管局第二批名录2A001列法国邮船大楼，公布时使用单位“住总公司机电设计院”，地址中山东二路9号。郭红解2003年在《上海档案》写到这幢1939年落成的法国邮船公司旧楼正在改建作档案馆。上海市档案馆外滩馆于2004年开放，2022年1月结束对外服务。建筑主体于1937年开工，1939年2月竣工，建在延安东路以南的原法租界外滩。1861年的公司产业范围远大于本件所覆盖的现存主楼。[房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [《从法邮大楼到档案新馆》](https://web.archive.org/web/20190609075836/http://mall.cnki.net/magazine/article/DASH200305035.htm) · [外滩馆告别时的报道](https://news.qq.com/rain/a/20220131A023LG00)

临江正面三组三联窗嵌在蓝灰色窗裙和浅色水刷石墙面之间。两侧窗组在中央冠部以下两层结束，北侧面能看到另一层退台。2015年Livelikerw摄的原照可核实上部窗列。2021年1月的街景清楚显示档案馆时期的黑色门楼、深门洞、两侧长窗和金字。模型保留这一时期的入口。2023年夏季街景有树叶遮挡，当前门额文字仍待现场核对。[上部立面原照与许可](https://commons.wikimedia.org/wiki/File:Former_Compagnie_des_Messageries_Maritimes_Shanghai.JPG) · [街景、年代和使用记录](reference-review.json)

2006年的参观资料记改建后共有11层楼面，总建筑面积9,270平方米；建筑沿革资料记中央最高12层、比两侧高两层。各层净高、退台深度、隐蔽的后墙窗位及精确屋顶高度均为比例估计。模型地面取独立的894平方米源面，行政保护地址、具名地点、临街形状和相邻建筑可交叉定位。光明金融大厦在南侧，金延大楼在北侧。[源轮廓和三期影像校准](footprint-review.json) · [独立模型页](../../../messageries-maritimes.html)
