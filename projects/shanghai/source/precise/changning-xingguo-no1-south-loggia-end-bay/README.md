# 兴国宾馆一号楼南立面端部双柱敞廊

5M025在市表登记为太古洋行大班住宅，门牌华山路1245号。长宁区融媒体中心刊出的近照在图下标出1号楼。模型截取南面图左端的一个敞廊开间，包含两根浅色圆柱、柱间瓶栏、转角侧券、出挑檐和带接缝的浅绿色坡顶。

端部两根窄圆柱退在两道宽墙墩之间；顶端能看见向两侧卷出的柱头轮廓，扶手从两柱下部穿过。 侧面券口通向廊内；绿色坡面的凸缝沿斜坡汇向上缘。长宁区原图另有题作2号楼的红瓦双山花，与此浅色敞廊清楚可分。

市名录以华山路1245号登记整个兴国宾馆，文内分别指认1号、2号和6号楼。瓶栏局部受树枝及柱础遮挡，完整瓶数、柱头小纹饰、屋面实际材质、廊深与绝对尺寸按照片近似。
