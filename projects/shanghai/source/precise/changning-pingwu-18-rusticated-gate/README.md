# 外国弄堂平武路18号院门分段石柱与弧顶铁门

上海市第四批优秀历史建筑4M031包括番禺路三条里弄和平武路五个门号。中国の風景2016年1月15日的街头图录在连续照片中分别标注了平武路2号、8及10号、18号。本件依据18号照片右侧院门，在左门柱保留绿色门牌。另一组同名“外国弄堂”列在新华路，登记为4M035。
