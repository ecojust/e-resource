# 胶州路561号电力部住宅门廊与砖山墙

上海市第四批优秀历史建筑名录4B018记为上海市政委员会电力部住宅。2024年10月24日发表的署名街道记录将照片与561号门牌、两层砖木住宅直接相连。作者记1926年建，并附记1928年的另一说法。[上海市房管局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [微不足道，《胶州路 那场大火 那个军营》](https://www.meipian.cn/57uah7e2)

2015年冬季的公共街景可对上较低山墙中的窄竖阁孔、成对白窗、外挑花栏与檐肩浅石。小门廊由两根独立方木柱支承，前缘木板沿双坡有连续卷饰及中央垂饰，门扇后退。2024年街道记录的画面左缘树冠及相邻高山墙遮住另一翼。模型保留这段可见外观和短屋面，其余建筑继续使用底图。[街景原记录](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300001501281631293585Z)

四个有日期的摄影位置给出两座不同山墙的屋冠。与具名地址点和航片重叠检查后，采用原单体2157。大山墙顶与原轮廓吻合，右端较低山墙顶在粗略北边界外约2.6米。正面观测范围与后部原房分别保存。门廊进深、挂落雕纹、砌缝与屋顶厚度按图估计。登记详见同目录的来源与放置资料。
