# 扬子饭店汉口路主门与三列花台
上海市房屋管理局第四批4A030条登记扬子饭店，曾用名申江饭店，地址为汉口路740号、云南路287号。汉口路南面直墙的七列阳台中，第五列正对下方的主门。两处2021年街景分别将该轴定位在距西端21.85米和22.20米处。[双街名录与署名照片](reference-review.json) · [两站配准和尺寸](dimensions.json)

取主门所在列及左右各一列，三列各做四层花台。每座阳台有斜切前角、开敞金属栏杆及板下的两只托臂。主门有两弧面玻璃侧灯，中央的双扇门退后，入口外侧有带镂空饰带的波形雨篷。近档保留两层V形金属纹、花瓣色差、玻璃横格及顶部竖线。以2024年春季的红花布置为参照，2025年的同一街面曾改挂粉花。

其余四列、云南路长翼、两路交会的斜角、后侧高层和大厅均保留现状。弯玻璃、花盒、雨篷挑出尺寸和贴面颜色来自街照估计。[原楼足印与同组邻房](footprint-review.json) · [可编辑几何](source/hankou_front.py)
