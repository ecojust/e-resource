# 汾阳路海关俱乐部木屋

市房管局第二批第2D045项将这处院宅登记为「住宅」，地址为汾阳路9弄3号。2017年拍摄的现场保护牌载明海关俱乐部木屋、1898年建造。2018年《文汇报》门牌及俯瞰照片和2020年带定位的航片互相印证。文献对赫德私人居住与设关员俱乐部的叙述有差别，名称沿用保护牌。

模型以花园南敞廊和屋顶为重点。五个柱位架起前梁，中央台阶从庭院通向架高的前廊。南坡中央多面凸出的通檐窗，与东坡前后两扇小翘檐窗分开。背面和树影中的构造、木板宽度、开间与各处高度按现存影像估算。附近汾阳路20号的犹太俱乐部、45号的副税务司官邸均有独立门牌。
