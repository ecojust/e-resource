# 国立上海医学院东一号楼

东一号楼位于复旦大学枫林校区东院。上海市房屋管理局将其登记在东安路131号东1号楼，编号2D035，项目发现名录采用医学院路138号。地图分别标记了东一号楼、明道楼和门诊大楼。东一号楼对应地块中心约为东经121.447391、北纬31.199582，原生楼体2076覆盖同名当代地块的99.19%。[登记、校史及实照](reference-review.json) · [三栋实名建筑和各自的地块](footprint-review.json)

复旦百晓生所载校史记1936年9月校舍落成，1937年4月举行上海医学院校舍及中山医院开幕典礼。复旦大学医学宣传部公布的典礼合影、落成时外观与2017年校史实照，可以分别核对院落布局和门窗变化。2024年12月24日闻玉梅捐资修缮东一号楼。复旦于2026年3月和6月分别公布全过程投资控制服务和绿化搬迁工程的成交结果。本次外观依据修缮前见诸校史的照片，后续工程变化留待竣工档案确认。[复旦大学医学宣传部校史](https://news.fudan.edu.cn/2023/0125/c244a133786/page.htm) · [2017年校史与实照](https://shmc.fudan.edu.cn/news/2022/0302/c1899a130347/page.htm) · [2026年绿化搬迁公告](https://xxgk.fudan.edu.cn/f1/30/c13508a782640/page.htm)

礼堂长翼沿东北偏东方向展开，北侧两端凸向草坪，在中央形成凹院。2017年正照能辨三座拱门、浅色立墩、红柱、浅色镂空栏板和中部小檐。主屋设十一开间、歇山屋顶，两端方亭采用四角攒尖，之间有窄屋廊。南面斜照可数到九个老虎窗，中央凸出的浅色楼梯间朝向另一处实名建筑明道楼。二维足迹和三期航片分别用于地面边界和屋顶构型，屋顶视差在影像收据中保留。[实名地块与图幅](footprint-review.json) · [航片核查](aerial-check.json) · [屋顶、窗廊与方亭](source/roofs.py)
