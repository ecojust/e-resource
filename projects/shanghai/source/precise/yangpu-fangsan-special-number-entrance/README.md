# 纺三小区特号住宅门廊与石阶

许昌路227弄原为公大纱厂住宅区，后称纺三小区。市第四批优秀历史建筑4G001在登记地址中单列“特号”。海隽2021年介绍了挂牌的前纺三住宅，周仰在同篇报道里拍下特号住宅面向圆形绿地的门廊。门旁绿色号码牌的两行字为“特号”“许昌路二二七弄”。[澎湃新闻，2021年7月2日](https://www.thepaper.cn/newsDetail_forward_13393611)

## 照片所见

七级石阶逐级通向后退的暗色门框。雨篷由两根前方柱承托，檐底能看到成组竖肋。层叠的檐板与门上红棕钢窗在2012年远景与2021年所刊近照中均可辨认。建模按照片比例估计柱、台阶、窗框及门洞进深。分栋坐标未能由原照片与地图共同确认，公开独立页展示门廊及其一开间墙面。

## 模型源码

在上海项目根运行 `python source/precise/yangpu-fangsan-special-number-entrance/source/build_model.py --out out --audit review`。水刷石墙面的颗粒由固定种子独立绘制。纹理和 UV 坐标保存在三份成品中。门牌手工排字，用 Noto Sans CJK 生成字形，字体署名及 OFL 许可证见 source/OFL.txt。摄影权属、原始影像摘要和地址对照见 reference-review.json 与 site-review.json。
