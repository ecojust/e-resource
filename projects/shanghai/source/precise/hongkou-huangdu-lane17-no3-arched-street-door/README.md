# 黄渡路17弄3号住宅临街双层砖券门

5F009在市表登记为住宅，门牌黄渡路17弄3号。Fayhoo于2015年4月12日拍到黄渡路17弄3号临街小门及院门。模型取灰褐色外墙中的拱门，门右有绿色3号牌；可见两道前后错开的红砖券、淡色砖门脚和深色双扇铁门。

红券拱脚向两旁伸出，深浅两道券之间有实在的退台。两侧门墩底部换作浅色薄砖，上方有凸缘。 门顶铁花在拱内另起曲线，中央竖向分开，其下为直格双扇。门牌在右侧较高位置，露出绿色底与浅色3字。

竖向边界取带3号牌的小门，旁边独立的大铁门及其山墙未做。砖券深度和铁花截面按门旁的透视估算。
