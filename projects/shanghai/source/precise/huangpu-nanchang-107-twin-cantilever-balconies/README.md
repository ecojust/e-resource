# 南昌路107号住宅三层双挑台与铁栏

5A011在市表登记为住宅，门牌南昌路107号。按Fayhoo在2014年12月9日从街口拍摄的照片，重现南昌路107号三层斜切墙面两座分开的挑台、成对石托、深色细铁栏和各自的玻璃门。

斜切面三层两扇门下各设一座独立挑台，两者之间的深褐砖面留空。 每座板下可辨两只托件。外缘转角柔和，栏杆细于脚边的石材，较厚的上扶手和下一道横杆分开。 三层上缘的浅色横带转向街道两侧。正面材质采用自主生成的紫褐砖错缝与浅灰勾缝。

门牌与建筑有摄影者题注；绝对高度、挑台进深、细杆数量和室内窗背均无实测。两端仅截取转角短段。
