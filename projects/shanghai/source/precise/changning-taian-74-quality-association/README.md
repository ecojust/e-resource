# 泰安路74号上海市质量协会临街面

从泰安路76弄口向东看，白色三层楼面向马路的一端有浅三角山花，两侧各一组四格凹板，中央的两层窗之间夹有一块深色栏板。2015年12月街景可见门廊左柱悬挂的上海市质量协会竖牌。协会公布地址为上海市泰安路74号。市文旅部门将这栋楼的局部照片刊在介绍亦村的一节内，同一组图还包括门牌为4号的另一处院门。[协会的联系地址](https://www.saq.org.cn/xhjs/lxwm) · [上海市文化旅游局组图](https://sh.people.com.cn/n2/2023/0106/c350122-40256938.html)

2020年2月的两处公共街景交会得到外挑檐口水平跨度约11.74米，西端高度约12.81米，中央三角尖约13.78米；两站射线的残差约0.29–0.40米。2015年12月另一组交会得到西檐12.82米，楼层腰带4.31米。首稿以两道水平线纠正文旅斜照的透视，建立六处窗洞的内壁、木色金属窗框、独立玻璃、凹板及出挑檐线。净墙宽11.40米为条件尺寸。[正面窗与凹板像点](source/front-features.json) · [分期交会及原始像点](measurements/street-cornice-intersections.json)

亦村在市级名录中的保护编号是3M006，地址为泰安路76弄。74号临街白楼与院内的1至14号分开建模。既有城市粗模715的14.63米短边是该长条轮廓的外包尺寸，目前保留实物的局部展示。建筑后段、内部与产权界线有待更具体资料。[保护条目与图像边界](reference-review.json)
