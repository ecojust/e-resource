# 泰安路74号上海市质量协会临街面

从泰安路76弄口向东看，白色三层楼面向马路的一端有浅三角山花，两侧各一组四格凹板，中央的两层窗之间夹有一块深色栏板。2015年12月街景可见门廊左柱悬挂的上海市质量协会竖牌。协会公布地址为上海市泰安路74号。市文旅部门将这栋楼的局部照片刊在介绍亦村的一节内，同一组图还包括门牌为4号的另一处院门。[协会的联系地址](https://www.saq.org.cn/xhjs/lxwm) · [上海市文化旅游局组图](https://sh.people.com.cn/n2/2023/0106/c350122-40256938.html)

2020年2月的两处公共街景交会得到外挑檐口水平跨度约11.74米，西端高度约12.81米，中央三角尖约13.78米；两站射线的残差约0.29–0.40米。2015年12月另一组交会得到西檐12.82米，楼层腰带4.31米。首稿以两道水平线纠正文旅斜照的透视，建立六处窗洞的内壁、深色窗框、独立玻璃、凹板及出挑檐线。净墙宽11.40米为条件尺寸。[正面窗与凹板像点](source/front-features.json) · [分期交会及原始像点](measurements/street-cornice-intersections.json)

亦村在市级名录中的保护编号是3M006，地址为泰安路76弄。74号临街白楼与院内的1至14号分开建模。既有城市粗模715的14.63米短边是该长条轮廓的外包尺寸，目前保留实物的局部展示。建筑后段、内部与产权界线有待更具体资料。[保护条目与图像边界](reference-review.json)

2020年两处街景中，门廊下可以分别看清两樘拱肩入口，每樘有双门扇和三道扇形上亮。两站把门罩尖定位在4.68米，门洞拱顶在3.2米左右；下层入口比楼上墙面退入约1.2米。2015年4月和12月门罩近景同时显示椭圆凸徽及两侧卷叶，西侧门柱竖牌可逐字辨出“上海市质量协会”。2020年2月中央石柱上的绿色门牌可直接读出“74”。细部采用几何表达，微小字笔画与花纹按原图可辨程度归纳。[双门原照交会](measurements/portico-two-views.json) · [两次门罩、挂牌和门牌摄影记录](measurements/portal-original-details.json)

弄侧从窄角窗进入四条有矩形窗裙的窗轴，再到第二个三角山花。大窗朝街一侧紧邻六格凹板，朝弄内一侧则是两组V纹。2013年10月18日两个站位分别定出侧山花顶，两条射线的距离各为0.117米，峰顶高约13.17米。深处地面被遮挡的部分只留连续墙体与分层构造。街侧与弄侧站位的跨期零点仍有漂移，绝对放置保留约2至3米不确定度。[西墙山花位置及窗轴关系](measurements/side-gabled-window-position.json) · [临街与弄侧的实体判读](measurements/tai-an-74-physical-address-and-sides.json)

在2021年1月的一张连续街照中，从街角到窄角窗为1.14米，四条常宽窗轴依次在4.06、7.38、10.58和13.73米；第二至第四轴都看得到三列两行凹板。靠近街角的一组树枝遮挡较多，细分按估计表达。[同一画面的窗轴、消失点与区间](measurements/chainage-of-west-side-windows.json)

最终近景有785个闭合构件、22,628个三角面，远景有760个闭合构件、17,136面。四组成对的原创色纹及法线分别表现浅灰抹面、浅色线脚、门罩金属和红色台阶铺地。竖向名牌和绿色74号牌可以分别查看。历史院号的考据不占用这个临街实物的定位。[四组现场色样](measurements/finish-readings.json) · [拱肩与凸徽的源图像点](measurements/portal-original-details.json)

原始GLB和分别解码的近景、远景文件都按69个独立照片像点检查最先撞到的三角面。每档有57点直接落在对应构件上，全部69点都在原图4像素范围内找到对应表面。三档的颜色和法线图解码后与源图逐像素一致。[69点的三档首击核对](../../../data/audit/taian-74-quality-association-v1/final/registration/independent/registered-material-validation.json)
