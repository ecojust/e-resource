# 广协书局大楼转角阳台圆环铁栏

上海市黄浦区四川中路528号。转角阳台临街的一段铁栏，含六组圆环、环内四瓣内凹曲线、中心小方框和贯通的扶手。圆弧形石板压顶位于黑漆铁栏下方。

六跨长约2.76米，取自2015年署名照片和现场街景的可见比例。栏高、转角半径和型材厚度为估计值。
