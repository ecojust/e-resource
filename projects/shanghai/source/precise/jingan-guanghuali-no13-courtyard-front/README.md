# 光华里13号院门、三面凸窗与露台

巨鹿路786弄属上海市第五批优秀历史建筑，编号5B025。模型取13号这一户的院墙、门柱、带灰色窗套的三面凸窗、相邻阔窗与上方露台。言衣草从弄内拍摄的同一幅照片可以读到12号和13号两块门牌。13号窗框呈深褐色，其上方为水平钢管栏杆。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

高参88在2015、2016年拍摄的院门、窗台及砖缝，与言衣草2018年的两个反向上层视角共同约束本户外观。模型收录窗后退深、三面窗套、侧窗台的短托、四道水平栏管和后方小屋的可见坡面。院墙挡住底层窗的下部，模型只标出照片里露出的窗头。[高参88摄影](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102xexh.html) · [言衣草摄影](https://blog.sina.cn/dpool/blog/s/blog_a598306e0102zsrf.html)

院门柱临巷面为进深零点。模型把阔窗所在砖墙放在门柱后方约3.49米。三个观察位置按每皮砖65毫米反算的中值分别约2.94、3.30及3.12米，另一个门牌机位约3.64米。砖皮高度和相机位置都带来不确定性。凸窗正面的一扇木窗按照片上的外开姿态重建，约48度为近似值。[院深与露台定位](measurements/terrace-placement.json) · [反向视角的砖皮读数](measurements/courtyard-opposite-wall-courses.json)

GIS的13号和14号点位都在原有街坊轮廓2774内，两点沿排屋相距约7.55米。13号在独立模型页展示。[原轮廓与各门号](measurements/footprint-review.json)
