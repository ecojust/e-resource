# 胶州路450号花园住宅

2020年两张庭院照片可以对上三跨完整的砖券、第四跨的外缘、廊后的门和窗，以及六扇百叶老虎窗。沿胶州路看，西山墙的中层三处开口和阁楼两处开口之间有凸出烟道。西返石栏下的一道短券，只有券顶和上部放射砖露出街墙。

南廊采用左首外角作坐标原点，X沿庭院立面向右，Y向楼内，Z以园侧平台面为零。砖皮节距、三跨券顶与灰缝分别从庭院原图读出。西山墙定位另用两个街景机位与短侧栏杆交会。庭院照片中的瓦坡和屋脊推得脊顶标高约18.77米，西山墙街景独立估到19.57米。脊线在两个估算中的进深相差约1.64米。第四跨远端、被街墙遮住的拱脚和北坡依可见范围收合。

2015年公布的保护牌写1940年代、砖木结构。《阅读静安》词条另记1924年，2024年《上海静安》报道写作砖混。几何取2020年至2024年可见的建筑状态。地图库中的近邻轮廓与实测西墙存在3.1至5.3米错位，本页可独立查看。邻近康定路759弄朱斗文公馆另有保护编号。
