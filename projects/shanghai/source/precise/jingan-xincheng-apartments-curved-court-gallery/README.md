# 新成大厦院内弧形外廊与菱格铁栏

5B056在市表登记为警察公寓，门牌成都北路337号。成都北路337号新成大厦的小区资料保留两幅院照。本件截取靠楼梯的一层外廊，橙褐色廊板自侧廊向院心弯出，栏框沿同一边缘转折。

院心所见廊板先内收，继而向庭院弯出，再绕回另一边。深色圆扶手在廊板内沿随弧转向，竖向栏框之间可见透空菱格网。 两张照片有不同的遮挡，合看可辨下缘的橙色压边、浅灰色板底与楼梯间暖色墙面。晾晒物、后接管线及旁楼均未作为模型尺寸依据。

两幅院照均未署名或标拍摄日期，栏网孔径、廊宽、墙厚和栏高为图上比例估计。院落有多幢建筑，模型只展示两照均可辨的外廊一跨。
