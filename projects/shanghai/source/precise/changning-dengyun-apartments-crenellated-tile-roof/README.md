# 登云公寓翼楼红瓦坡顶与齿形女儿墙

登云公寓建于1929年，初名又斯登公寓。区规资局刊载的俯摄照片中，左翼红瓦屋顶围着一圈浅色女儿墙，临街一侧的深色垛口间有一座较高的方墩。 [长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211215/1206809.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

两档斜上视图均可追到红瓦屋面的四条斜脊，前缘有深色垛口和高出的方墩。檐下各托块与下层窗组分开建模。近档瓦块排得较密，远档保留了连续的屋面底层和转角檐线。 屋面平面和高度取自两个相交檐面的相对比例。背后受遮挡的坡度、材料厚度与绝对尺寸为估计。

公开照片确认2068号及其左翼的瓦坡和齿形前墙。屋面是可辨的一部分，前后两大段屋身以及毗邻房屋均保留。
