# 原教会公寓南苏州路入口石三角山花

上海市黄浦区南苏州路79号。79号公寓入口门上的三角形石山花。层叠的两道斜向石线在中央合拢，山花墙心分层砌筑；水平底线在两边门柱上方折出，底下接石门楣与柱头。

门罩节选估宽约3.4米，三角山花估高0.95米。比例来自正面和斜面街摄，石材品种、背面深度和绝对尺寸待现场实测。
