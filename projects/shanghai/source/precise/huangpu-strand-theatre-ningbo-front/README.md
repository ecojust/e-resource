# 新光大戏院宁波路圆券与菱格砖立面

宁波路586号的新光大戏院由陈伯藻出资，哈沙德洋行设计，杨瑞记营造厂承建，1930年11月21日开幕。上海图书馆记载其为三层钢筋混凝土剧场，并记下南立面的两层通高圆券、螺旋壁柱和红黄菱格拼砖。上海市房屋管理局第四批名录将586号列为4A028，将旁边宁波路588号、贵州路160至170号的中国大饭店列为4A029。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海图书馆剧场资料](https://data.library.sh.cn/entity/theater/en35d3v0eud14egz)

宁波路南墙与东端斜角在城区底模上分别长20.81米、4.56米。图书馆所述的大券对应中央石色拱框及带小石栏的上层窗口。下部三个高窗、两侧各一对矩形窗和三联窗在2015年、2020年与2024年图中对应。临街墙分出四道绿色花饰竖带，波纹腰檐折向东端，斜面挂着“新光影艺苑”五个金色立字。[2015年现场](https://commons.wikimedia.org/wiki/File:Strand_Theatre_Shanghai.JPG) · [2024年4月局部](https://commons.wikimedia.org/wiki/File:Strand_Theatre_%E6%96%B0%E5%85%89%E5%A4%A7%E6%88%B2%E9%99%A2_(2024)_-_IMG_02.jpg) · [地块、源瓦片与相邻建筑](footprint-review.json)

2024年12月的街拍显示东侧门面已改为亚朵酒店。酒红色墙面、拱形双扇门与旧影院腰檐同时可见。早年的“新光电影院”横招和2020年的其他店招保存在参照资料中。酒店订房页的首幅效果图省略了中央圆券，立面细节据有拍摄日期的街照和实地照片绘制。[2024年12月实拍](https://www.sohu.com/a/838017433_121124773) · [照片、作者与资料来源](reference-review.json)

高度依据2020年宁波路两处街景和2021年路口的独立拍摄位置估算。腰檐上缘约6.35米，主檐底约16米，临街女儿墙顶约23.55米。上层在檐后退进，从路面向上看有遮挡，顶部标高约有1.4米的不确定范围。两色砖的图样、灰石卷纹和花饰均由程序绘制，五个金属字的字形依据实拍按近似字体制作。本次范围为南墙和东端斜角。原影厅内部、后身、侧面长墙、屋顶平面和邻近的4A029另行记录。[照片标定与逐点高度](source/street-registration.json)

2015年与2024年折角近照都能读出竖排的“新光影艺苑”。模型分别刻出五个字，放大前两字，并依据近照表现深色字侧和金色字面。字形使用开源字库近似。折角主檐以上为素色浅砖，菱格拼砖延续在沿宁波路的退层墙面。2024年街面实拍还可辨认深色“亚朵酒店”店额和两道圆头玻璃门。[图像及原始出处](reference-review.json)
