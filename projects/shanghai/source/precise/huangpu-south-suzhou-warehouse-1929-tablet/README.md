# 南苏州路955号仓库临河立面的1929纪年牌与钢窗

上海市黄浦区南苏州路955号。临河砖墙上方的浅石纪年牌，上宽下窄，两侧各有一小方脚。牌面上深色的1929数字与下面实心过梁、深进的横列钢窗及凸出的窗台一起展出。

按照2015年的具名照片估算开窗约宽2.96米，以窗洞、牌面及数字的相对尺寸确定比例；墙深、数字凸起程度、窗后玻璃和玻璃分片为近似。
