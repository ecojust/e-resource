# 惠罗公司大楼沿街竖带与横梃格窗

上海市名录确认为南京东路100号惠罗公司大楼。1930年Gonda表现图带Whiteaway Laidlaw上海英文图签，Antigng的2015年实照与2019年沿街街景可对看浅色连续竖带、成对窗洞和窗框。 [第五批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

营业层上方的两层窗各有一对深色钢窗，横向细梃与粗横框区分上下窗格。相邻开间的浅色壁带在窗间墙外连续上升。 [高德地图具名地点照片 未标日期](https://www.amap.com/ssr/place/B0FFMEY5PU) · [高德地图具名地点照片 2025:11:24 10:35:48](https://www.amap.com/ssr/place/B0FFFWUMC9) · [百度地图街景 20190518](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300121905181458473067I) · [Antigng 2015-07-20 15:08:15](https://commons.wikimedia.org/wiki/File:%E4%B8%8A%E6%B5%B7%E6%83%A0%E7%BD%97%E5%85%AC%E5%8F%B8%E5%A4%A7%E6%A5%BC.jpg) · [Gonda 1930-01-21](https://commons.wikimedia.org/wiki/File:Whiteaway_and_Laidlaw_Drawing_Gonda.jpg)

近档和远档均可数出上下两组双窗。斜视时，壁带向前挑出，凹窗显出侧壁。短竖梃止于粗横框下，顶部狭长窗格贯通。 以一层窗宽约1.4米估算。立面净高、壁带前突、深色内框与玻璃后的形态为相对尺度近似；店招与现代广告未建模。

名录、惠罗公司照片与南京东路100号定位相符。模型保留两层成对的深窗和竖带。原屋及其余立面、道路照原，独立展示所见窗间。
