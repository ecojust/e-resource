# 复兴中路599号住宅二层格窗阳台门与细铁栏

上海市黄浦区复兴中路599号。599号院内住宅的二层露台。狭高的暗红色门上半分成两组格窗，下半是四格浅凹门板；门外挑台的铁栏向侧墙折回。

以Antigng在2018年拍摄的原图量门框四角，并校正斜视读格。按门洞约宽1.02米、高2.74米估算，铁栏各根的间距、进深及其他被枝叶挡住的部分为近似。
