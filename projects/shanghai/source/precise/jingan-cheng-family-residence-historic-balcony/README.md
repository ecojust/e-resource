# 南京西路1550号历史门楼

程谨轩、程霖生父子旧居及协进初级中学列入上海市第五批优秀历史建筑，编号5B033。此处复原旧街照能辨认的临街门楼二层。以门楼中央两扇长窗为中心，沿街可见五樘窗、三面折转的穿花阳台、中央切角石额和东侧卷肩石冠。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [建筑地段和门号](measurements/footprint-review.json)

《档案春秋》刊出的近照及2020年重刊的较清晰版本来自同一底片。采用后者的640像素图幅定位窗下槛和东侧折面。原片未注明摄影者和日期。高参88于2018年6月27日拍摄的同面街照保存着两处石额和花栏细部。左折面窗已接近旧照片裁边，其后续墙面及栏后遮住的窗扇下部只能估算。[旧照及同页对照](https://kknews.cc/zh-sg/history/yae3gmg.html) · [较清晰的重刊](https://card.weibo.com/article/m/show/id/2309634498573621329963) · [2018年参照](https://blog.sina.com.cn/s/blog_5d1bdf480102y3oa.html) · [重刊配准](measurements/two-prints-one-negative.json)

阳台地坪为零高度，中央两窗所在墙面为零进深。相机比例基于花栏高0.96 ± 0.12米的假定。东端方窗在旧刊所见比2018年街照窄约0.3米；以旧窗的可辨边缘制作，并保存两个时期的各自坐标。灰调玻璃、深色木框和浅色石套根据原片的相对明暗绘制。[窗洞投影与尺寸](measurements/upper-wall-returns.json) · [历史机位](measurements/historic-balcony-period-camera.json)

原始和近景模型各7,180个三角面，远景6,092面。三个网格各有136条墙窗和东端石额的几何检查、140处切角石额观测及164条花栏实体检查。历史照片的30个花栏点中27个首击符合标记；另外24组边界有15组在原刊±2像素内跨过轮廓。五窗与邻墙的40个历史照片部位中31个直接命中相应表材，其他点的实际首击也列入记录。[花栏核对](measurements/released-balcony-verification.json) · [窗面的40个原始像点](../../../data/audit/cheng-family-residence-historic-balcony-v1/elevations/historic-window-pixels-raw.json) · [建模源程序](source/build_model.py)
