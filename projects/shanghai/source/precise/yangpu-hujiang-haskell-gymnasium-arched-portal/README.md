# 沪江大学北体育馆历史入口石券

哈斯科上校捐建的体育馆于1918年建成，1919年1月11日开馆，机械学院时期称北体育馆，后来用作学生活动中心。上海市第四批优秀历史建筑名录4G005在军工路516号校园内分别登记了体育馆和健身房，后者对应南体育馆。[上海理工大学历史建筑档案](https://buildings.usst.edu.cn/2018/1002/c882a30392/page.htm)

署名上海档案馆的正面照片记录了主入口。券顶略尖，三道浅色石线脚向门内逐级收进。拱下的上亮窗设竖梃，深色双扇门后退于门框。模型以双扇合计约1.75米作尺度假设。进深、门扇板缝、灰缝和颜色均为近似。[历史正面照片](https://buildings.usst.edu.cn/_upload/article/images/fc/3c/33117f90407ca63eb3edd647f8ad/de0a91e3-9327-4518-828f-d23643a52204.png)

校园里有两栋建筑同样标作学生活动中心。旧地图中两者分别对应原1265和644，已建的1937年大学礼堂为原2357。本页单独展示历史门口，地块比对见 site-review.json。校档照片仅列出处与摘要。
