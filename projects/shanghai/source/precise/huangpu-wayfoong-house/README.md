# 新汇丰大楼 · 四川中路职员宿舍

四川中路220号是原汇丰银行经理和职员的宿舍，1928年落成，由公和洋行设计。上海市房管局第二批优秀历史建筑名录以“汇丰大楼”、四川中路210–220号双号登记，编号2A048。上海市欧美同学会记述其后曾用于上海市档案馆、市政府参事室，2021年在二层设留学人员之家。外滩12号为原汇丰银行总行，两处建筑分别定位。[市房管局历史名录、同学会及新华社](reference-review.json)

沿四川中路可见两端入口、下部深色铸铁窗裙、贯穿四层窗带的壁柱及向外挑出的托檐。中段每层五组三联窗，上段又有两层，左右端亭分别高出中央屋顶。这与该楼八层的历史记载相符。2013年原始照片与2023年同路段实景用于确定门窗分组、上下层关系及端亭的位置。临街翼后两处采光井的分布据三期影像概化。[照片及现状记录](reference-review.json)

实名建筑轮廓419定位于四川中路东侧，测得沿街边长约41.56米。原城市源表估算十层、32米，正式模型按照片比例估计檐口、端亭及采光井高度。受遮挡的后墙采用简化素面。南侧建筑1787与旧轮廓交叠7.86平方米，现状低邻的屋面独立保留。[源轮廓与航片](footprint-review.json) · [打开模型](../../../wayfoong-house.html)
