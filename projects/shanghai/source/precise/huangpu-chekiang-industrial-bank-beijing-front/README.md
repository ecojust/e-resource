# 浙江兴业银行（浙兴大楼）北京东路西端窗跨

北京东路230号现存六层楼。言衣草的北京东路街照可见，西南切角以东的第一个完整开间，两侧是红色贴面竖墩，中间为浅色墙面。大窗上方两块方形浮雕各有一对转折回纹，以上四层每层三窗。Fayhoo的街角全景可同时辨认两向街墙和斜角。依据上海市银行博物馆刊出的建成方案与首层平面，北京东路长墙有九个主要窗跨。本次取西端一跨，宽约6.15米，实物尺寸按原楼足印及照片比例估计。

第四批名录4A007和现存保护牌确认本址。华盖建筑事务所1935至1936年间的银行楼从原拟十层改为五层，模型以上述现状街照为依据。已建的浙江第一商业银行在江西中路与汉口路口，沙美大楼在北京东路190号。这里保留底层营业空间及其上招牌、斜角、其余长翼、屋顶和内部。空调、架空线和临时店招均取原城现状。

源网格以当地建筑底图、两组现状照片和博物馆图纸确定窗跨的位置和开间。细档保留红砖墩的横竖缝、方回纹的细边、窗框和上檐，远景保留回纹实槽和实窗洞。现状色泽、石饰深度及各层标高均依图估计。[足印及原组](footprint-review.json) · [图源记录](reference-review.json) · [建筑组件](source/bank_window_bay.py)

局部原点位于西端首个窗跨沿地面的中点。正X轴沿北京东路向东，负Y轴朝街，标高零点对应独立模型的下边缘。原城放置将该下边缘抬至地面以上3.04米。
