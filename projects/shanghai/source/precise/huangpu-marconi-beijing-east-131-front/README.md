# 北京东路131号马可尼公司住宅

上海市第五批优秀历史建筑登记号为5A076。1947年《上海电话簿》商业分类和公司字顺索引均将马可尼公司列于131 Peking East Road，电话11466。现城市底图将129号和131号画在同一轮廓里，本研究按两年照片能识别的街面范围展示131号及与它相接的宽开间。[商业分类](https://archive.org/details/shanghai-telephone-directory-1947/page/n241/mode/1up) · [公司索引](https://archive.org/details/shanghai-telephone-directory-1947/page/n406/mode/1up)

临街照片提供了红券、灰腰线、木窗、暗绿铁门、屋面和两座老虎窗的相对位置。绿色铁门相对主墙后退约0.865米，三位数字均来自实照可辨的轮廓。窄跨下层的两扇按2017年照片开启。照片中的两个附柱脚用于缩尺，间距估算1.959米，尺度误差约0.13米。院内和相邻街坊的其他立面仍需进一步资料。[两站相机](measurements/marconi-front-cameras.json) · [三位门牌的进深](measurements/grille-stereo-depth.json) · [地块与邮址](measurements/footprint-review.json)

七个视角包含门牌近景、三樘弧窗、宽开间的窗扇与山墙屋檐。模型使用独立材质与几何绘制灰砖、红砖和铁格，砖纹由重复程序绘制。原始、网页近景及远景模型均测试了113处街面和商铺构件、249处木窗，以及141处门、牌、铁格与留空。[构建程序](source/build_model.py) · [来源与许可](SOURCES-LICENSE.md)
