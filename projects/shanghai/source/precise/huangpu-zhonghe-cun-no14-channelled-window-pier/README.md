# 长乐路272弄14号住宅转角横槽墙墩与木格窗

上海市黄浦区长乐路272弄14号。中和邨14号住宅一处外凸转角。水泥墙墩一道道横槽绕到侧面，旁边木窗的玻璃分为上下格，浅色窗台有数道挑边。

参照Antigng于2017年拍摄的署名原照估算可见七道墙身分层、三格木窗及窗台。每一层约高0.39米；槽深、窗扇进深及枝叶后的窗格以可见部分为准。
