# 中南银行大楼汉口路南立面中央柱列

上海市房屋管理局第三批优秀历史建筑原表以3A006登记中南大楼，地址为汉口路110号。1917年8月马海洋行为里斯公司设计办公楼，1919年《The Shanghai Times》已报道汉口路7号新楼动工。1921年建成后中南银行在此使用。署址图和当代实照把这栋楼与东面四行储蓄会、北面大陆银行和东亚大楼分开。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [上海城建档案资料](https://finance.sina.com.cn/jjxw/2024-06-15/doc-inayvkue1911282.shtml)

本次制作南立面中央三开间。二至四层的四根通高多立克柱属于早期构图。原图的底层门廊只有一个入口，1997年两侧各增一门，四根光面门柱增为八根。模型采用2023年修缮报道中可见的四对门柱、三个门位与巨柱后方九樘窗。2013年照片同时记录了修前的巨柱位置。两翼凸窗、后期改造的五至七层和后部楼体保留城市底图。柱径、门深和窗饰比例依据照片估计。[2013年街照](https://commons.wikimedia.org/wiki/File:110_Hankou_Rd.-_Bank_of_Tianjing.JPG) · [修缮项目与历年图像](https://www.thepaper.cn/newsDetail_forward_25342592) · [来源及底图比对](reference-review.json)

修后门廊近照还能辨认两扇闭合入口，每个门扇有纵向排列的镂空金色饰件和下部垂饰。细部照只支持近似轮廓。底层门楣上的八字依据修缮后近照转录，用开放字体近似表现。模型的石材、门窗及铸字以原创几何构成。[字体说明](source/fonts/provenance.json)
