# 来源与许可

- 2015年第五批上海市优秀历史建筑的5D019项逐字列出“花园住宅／住宅／五原路289弄1-2、3-4号”。原规划名录对应 XH-J-019-V。市级介绍还记录了锯齿形外梯、红砖弧形扶手、花园尖券门廊和砖烟囱。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [房管建筑介绍](https://m.thepaper.cn/baijiahao_16359621)
- 俄罗斯建筑师 Vladimir N. Dronnikoff 的相册藏于旧金山俄罗斯文化博物馆。Building Russian Shanghai 展示题作1935年的“East Elevation”和“The Whole Block”。后者也有 PastVu 的较大图像。历史研究将公和洋行这项设计与 Dronnikoff 和 Ilarion Tomashevsky 关联。模型由照片测读后重新绘制。相册和 PastVu 照片版权归相应权利人。[相册原页](https://brs.russianshanghai.city/architects/a-l/v-n-dronnikoff) · [施工原照](https://pastvu.com/p/1374738) · [建筑史说明](https://avezink.livejournal.com/420002.html)
- 高参88文章中的门牌、铭牌、窗扇、红砖梯墙和住宅照片用于识别地址、比对机位。另一张能读到3号和4号的南栋照片由 Building Russian Shanghai 署名“上海新里洋房”。发布资料含自行测量的点位、重新绘制的几何及模型画面。[高参88原页](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480101esph.html) · [南栋取景资料](measurements/house-three-reference-sources.json)
- 弄口照片《五原路289弄住宅》由 Antigng 于2017年8月19日拍摄，采用 CC BY-SA 4.0。对照图旋转、裁切并提亮原照，照片和对照图采用同一许可。三维铁门使用原创几何和材质。其他研究照片只作测量参考，GLB 与 Blender 未嵌入这些照片。[作者与原图](https://commons.wikimedia.org/wiki/File:五原路289弄住宅.jpg) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- 北栋与南栋的航片、城市轮廓和归属依据在逐期记录列明。四次拍摄日期是2010-07-22、2019-11-09、2021-11-25和2025-04-07。平面配图为对测读结果的重新绘制。[定位与影像记录](measurements/paired-house-placement.json)
- 网格、砖纹、瓦纹、抹灰纹理与建模脚本采用项目 MIT 许可。[项目许可](../../../../../LICENSE)
