# 资料与许可

华东政法大学校园建筑档案《22号楼 东风楼 / East-Wind Building》以中、英文记载原名西门堂、1923年末奠基、1924年12月13日落成及历次用途。本项目在该校17幅不同影像中，以院内廊下、东风楼门额与全院俯瞰三张作投影配准。其余用于核对券形、青红砖分色、正面开间与石刻。学校原图由原发布方持有，本包只列原文链接、原件摘要、手读坐标和模型自渲图。[华东政法大学校园档案](https://www.ecupl.edu.cn/2022/1101/c13514a193952/page.htm)

市优秀历史建筑名录中西门堂归在2M006圣约翰大学旧址名下，项目名录项为 sh-historic-b2-060。长宁区政府和文汇报的沿用资料与校史互证。同校另有1919年体育馆，其校舍与本栋分立。[长宁区政府](https://www.shcn.gov.cn/col6991/20210301/867409.html) · [文汇报](https://wenhui.whb.cn/third/baidu/202112/27/440841.html) · [校方体育馆档案](https://www.ecupl.edu.cn/2022/1101/c13514a193950/page.htm)
