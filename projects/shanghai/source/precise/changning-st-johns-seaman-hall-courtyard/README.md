# 22号西门堂院廊与东风楼门额

原圣约翰附属中学高中部使用的西门堂位于万航渡路1575号华东政法大学长宁校区。学校档案照片中的隅石清楚刻有「ST. JOHN’S MIDDLE SCHOOL」「SEAMAN HALL」和「A.D. 1924」，门楣现题「东风楼」。校方记载1923年末奠基，1924年12月13日落成，1925年起作高中校舍，1952年至1956年间由华东师范大学数学系使用。隅石铭文中的人名首字母与其所在墙角仍待确证。[校史与原照片](https://www.ecupl.edu.cn/2022/1101/c13514a193952/page.htm)

模型绘出青砖两层长立面、红砖弧券与腰线、中央通道、院内低廊的拱券和柱头、石台与踏步、两侧返廊及校方俯瞰照中的四坡屋面。市级名录编号2M006同时涵盖校园其他楼，本独立版本聚焦22号院落。用木色实体窗梃、青色玻璃、原创灰砖与红券砖两套色图及法线区分材料。校方原照中的树木、人、车辆和露天家具均未作为建筑构件。室内分隔缺乏可核资料，外廊背墙和屋后深度取照片与院界约束下的近似值。

模型使用以米计的本地坐标，X沿临街长面向照片右，Y入院，Z向上。长面以已登记地物的约71.93米作尺度参考。三张校方照片采用独立相机。俯瞰、门额和院廊三站的控制点误差中位数分别为4.22、2.09和2.99个原像素。每站另留三处像点，最大误差分别为10.2、3.8和6.9像素。门额近照约束中段开间，最外侧开间及檐后屋顶的细部误差较大。两片北侧低廊与两侧高廊的归属以航片与庭院走向对应，廊下拍摄点落在哪个开间仍属条件定位。

重建入口为 source/build_model.py，参数为 --output 和可选 --lod。source/seaman_finishes.py 可重新生成四张原创纹图，measurements/fit_seaman.py 按原像素重解三组机位。其余资料与许可见 SOURCES-LICENSE.md。
