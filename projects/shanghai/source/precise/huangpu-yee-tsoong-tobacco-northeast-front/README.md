# 颐中大楼南苏州路北面与东北抹角

上海市第三批优秀历史建筑3A010登记“颐中大楼／英美颐中烟草股份有限公司”，门牌南苏州路175号。市历保中心与上海交通大学建筑文化遗产保护国际研究中心记载大楼建于1920年，原为英美烟公司大楼，中国福利基金会曾在此办公。个人调查另有美商晋隆洋行1908年建楼、英美烟草公司后承租的说法，尚缺与该门牌吻合的产权原档。西邻南苏州路185号为1917年原英商上海电车公司办公大楼。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [两栋办公楼的分别考证及实照](https://www.thepaper.cn/newsDetail_forward_33464022) · [另记年代和租用沿革的调查](https://www.meipian.cn/49td5lni)

北面七道长券窗贯通二、三层。每道窗的券头有浅色锁石，顶灯带圆环，中央为不透明深色窗裙。四层用双联长方窗，挑出厚檐、托件和退后的一层贯穿临街三面。东北抹角的入口和两侧相邻窄跨有券门，各面上部都有三联窄窗。北面地层东段有四道大橱窗，西段两扇带实墙窗台的矮窗分列矩形门两侧，西翼末端还有一扇处在放射形砖缝下的小门。模型窗扇及墙体使用独立几何，门窗进深、材料颜色和檐口尺度按图像估计。[2015年1月25日上传的街角照片，摄影Fayhoo](https://commons.wikimedia.org/wiki/File:Yee_Tsoong_Tobacco_Co._Building.jpg) · [2026年发表的立面、街角及长券窗照片](https://www.thepaper.cn/newsDetail_forward_33464022) · [原图签名与日期性质](reference-review.json)
