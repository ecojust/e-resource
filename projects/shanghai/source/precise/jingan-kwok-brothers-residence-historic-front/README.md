# 郭氏兄弟住宅弧形檐廊

市房管局第二批优秀历史建筑2B006以“花园住宅”登记南京西路1418号；上海市政府2014年公布的文物保护单位名单第29项写作“南京西路1400－1418号住宅”，记建于1926年。郭氏兄弟住宅是这对房屋的常用名称。本件取两张街景照片中能够互认的弧形檐廊。[市房管局登记](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [市政府文物保护单位名单](https://www.shanghai.gov.cn/shanghai/download/gongkai/hff1429.pdf)

Fayhoo于2014年7月12日拍摄的照片同时摄入两栋住宅，左栋一个石栏上部清晰可辨。圆弧中部有一座实心饰墩，正面为圆形徽饰；下方有层叠小托座。弧线两旁为透空栏杆，下缘可见逐个突出的小檐齿。树冠间露出一根浅色柱的柱头和上部柱身。MNXANL于2019年7月3日从另一个位置拍下同一处饰墩，圆弧、栏杆和檐齿的位置吻合。照片分别以CC BY-SA 3.0和4.0发布，模型为独立绘制的几何。[2014年原片与说明](https://commons.wikimedia.org/wiki/File:Nanjingxilu_1400-1418_Hao_Zhuzhai.JPG) · [2019年原片与说明](https://commons.wikimedia.org/wiki/File:201907_1418_Nanjing_Road_West.jpg)

截取范围约宽8.0米、高4.0米，尺度、栏杆转角、被树叶遮住的栏杆间距与材质色调均按照片估算。中央圆饰的内部纹样难以辨读，模型保留其圆形边框及凸面。柱身在枝叶遮挡高度截断。地址按两栋共同登记范围引用，精确到哪一门牌、哪位兄弟居住的对应关系仍待历史总图核查。上海展览中心所在的旧爱俪园地块在南京西路对面。[来源、资料日期与制作边界](reference-review.json)

现有照片反映2014年至2019年间可见的细部，1926年初建外观图仍待查证。市区图用历史地点标记打开这件局部，四种文件均从独立页面提供。[弧形檐廊查看页](../../../kwok-brothers-residence-history.html) · [建模源码](source/bowed_gallery.py)
