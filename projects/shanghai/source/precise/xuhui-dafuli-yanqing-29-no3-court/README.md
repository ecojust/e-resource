# 大福里延庆路29弄3号院门与露台

上海市徐汇区，上海市第五批优秀历史建筑5D059。2016年的弄内照片中，近端石柱的绿色门牌上可读“3”和“延庆路二十九弄”。本模型记录这个院门、后方蓝衬铁艺露台、灰白边梁和绿框窗在照片中可辨的部分。相邻4号、弄口过街门及整排住宅分别建档。[身份及材料核对](measurements/court-three-identity-and-surfaces.json) · [出处和许可](SOURCES-LICENSE.md)

照片有24毫米等效焦距记录。以门牌正面为基准，从两张不同位置的照片估计露台及窗墙的进深。蓝衬栏杆前沿距门牌平面约0.65米，窗墙约1.36米，两者的绝对进深均约有半米不确定度。尺度采用0.20±0.04米牌高和1.56±0.15米摄影眼高。地图建筑轮廓包括3、4号两户，不能据此恢复单户的完整屋面或后院。[相机控制](measurements/court-camera.json) · [双照片进深](measurements/terrace-depth-crossview.json) · [地图定位](measurements/court-block-placement.json)

运行 `python source/build_model.py --output court.glb` 从本仓库重建近景几何。加 `--lod` 生成远景。运行 `python measurements/check_mesh.py 输出目录` 重建两档并检查每件封闭体。
