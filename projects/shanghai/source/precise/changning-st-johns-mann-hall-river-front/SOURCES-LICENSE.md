# 思孟堂的来源与许可

上海市房屋管理局第二批名录2M006把校政厅、怀施堂、思颜堂、思孟堂、科学馆和西门堂列在一个保护组内，现用名一栏分别列4、41、40、43、42和22号。地名登记时的门牌为万航渡路1175号，华东政法大学今用1575号。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz1/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [校园建筑目录](https://www.ecupl.edu.cn/xyht/list.htm)

学校2022年11月1日发布的《思孟堂》记载了1908年奠基、1909年9月竣工。文中临河日景、临河夜景和沿河俯斜照三幅分别用于独立相机拟合。原页未单列个人摄影署名、照片日期或开放许可。读者可从原页查阅，源码包仅附来源网址、原文件SHA256、量读坐标和原创渲染。夜景对应图用同一日光材质展示几何关系。两张历史庭院照片用于区分另一侧的敞廊。校史页中的双红柱门头尚未定位到临河窗墙。[华东政法大学《思孟堂》](https://www.ecupl.edu.cn/2022/1101/c13514a193941/page.htm)

OpenStreetMap署名参与者提供具名思孟堂的建筑轮廓w494666675。两条沿河边界约37.65米，侧边15.66米。该要素的建造年份标签写1899年，校方提供了1908年9月19日奠基和翌年9月落成的具体校史记录，故模型采用1909年。底图数值摘录、邻域及来源对照沿用ODbL 1.0。原城市宏14-13717-6694内建筑400按原版保留。[OSM原要素](https://www.openstreetmap.org/way/494666675) · [OpenStreetMap版权与许可](https://www.openstreetmap.org/copyright)

原创几何、数值测量脚本及两组程序纹理依仓库MIT许可发布。灰砖、灰瓦的色图和切线法线来自随机场、物理重复尺度和照片小块的通道中位数，纹理中不含校方图像像素。模型中窗玻璃用0.73的可调不透明度表现受环境光影响的暗窗。
