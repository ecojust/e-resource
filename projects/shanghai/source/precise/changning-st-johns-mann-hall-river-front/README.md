# 圣约翰大学思孟堂43号楼临河窗墙

思孟堂在华东政法大学长宁校区。圣约翰大学于1908年9月19日为该楼奠基，1909年9月竣工，以教员孟嘉德（Arthur S. Mann）命名，作为高年级宿舍。1947年改为女生宿舍，1951年改称和平堂，1952及1979年先后编为二号、五号学生宿舍，1998年6月恢复原名。校园现址万航渡路1575号，市房管局第二批名录的原登记地址为1175号。市名录号2M006涵盖多座圣约翰大学旧建筑，思孟堂的校内建筑编号为43。[华东政法大学校史](https://www.ecupl.edu.cn/2022/1101/c13514a193941/page.htm) · [校方建筑目录](https://www.ecupl.edu.cn/xyht/list.htm)

校史记十开间清水砖墙。临河日景、夜景及俯斜照片都能看见突出的楼梯塔，塔额圆窗，沿河两侧五列和四列普通窗，两道砖腰线区分三层。夜景另露北端券窗。复原范围到前屋坡屋脊及两端可见回墙。西院拱廊、被树遮处的窗内陈设、全楼内部和沿河附属楼都超出本次量测范围。地图具名建筑w494666675与旧城楼体400吻合，保留原城股。西边40号思颜堂、41号怀施堂、42号科学馆、22号西门堂与4号楼均另有建筑身份。[名录与底图](https://www.openstreetmap.org/way/494666675)

沿河两角的底图间距37.65米，相邻侧边约15.66米。三张照片分别拟合透视相机，日、夜及俯斜站参与点中位残差约2.1、5.3与1.5原像素。九枚窗点留出独验。昼景遮树的开间使用夜景的窗列位置，夜照受灯光晕影响的线脚以昼景校正。实地未测窗格截面、楼梯间投影深度与屋脊绝对高度，都保留条件尺度。

原创模型与程序采用MIT许可。校方未在该页逐张列出摄影者和拍摄日，校档原照片只供读者循链接核对。代码和成品均由几何轮廓与独立表面生成。
