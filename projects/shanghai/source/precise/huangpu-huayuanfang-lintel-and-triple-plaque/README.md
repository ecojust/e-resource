# 花园坊瑞金二路三字额与叠梁弄门

上海市第五批优秀历史建筑名录5A061登记花园坊，地址为瑞金二路129号。具名照片中的三字由右至左读作“花園坊”；2020年街景也可见沿街横额、门楣及其下行人弄道。 [第五批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

这处弄门将三字题额架在宽门楣之上。额板两侧各有短竖槽，浅色额面衬出红色题字。 [高德地图花园坊具名地点照片 未标日期](https://www.amap.com/ssr/place/B00155R07Y) · [百度地图街景 20200220](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122002201357047205O)

正面能看见三字题额和门洞。斜面可以辨认压顶外挑的深度，以及额下开口中分别架起的三条水平细铁。 按门洞净宽约2.70米推算。题额笔画按正照轮廓概括，门柱背面及檐顶止于题名墙所在的一跨。

第五批优秀历史建筑名录表列瑞金二路129号花园坊。具名现状照片的题字自右向左为花園坊，2020年沿街照片也能看清题额、叠梁与弄道。多个门点分布在同一住宅组团，门楣标高和院落各栋高度缺少统一基准。保留组团原屋、沿街店面与地面，独立展示题名弄门。
