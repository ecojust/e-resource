# 盛世花园临街双联钢窗与铁花架

上海市第四批优秀历史建筑名录登记原名“盛世花园”、现名“华园”，地址为长宁区万航渡路540号。拍摄者Antigng在2014年4月20日摄下了武定西路路口的两层双联窗。蓝色路牌、山墙转折和几道烟囱能帮助认出临街这一栋。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Antigng原照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E4%B8%87%E8%88%AA%E6%B8%A1%E8%B7%AF540%E5%8F%B7%E5%8D%8E%E5%9B%AD.jpg)

窗外的花架安装在下排两个窗楣上。上沿是连续的小圆环，下方铁杆略微外鼓，墙侧的托架支承两格花盆架。四扇窗各有灰色凸窗楣和外挑窗台，深色百叶、竖梃及各排分格可以对照2013年的近照。2021年街景中的底层铺面已经改变。[2013年近照记录](https://mapsv0.bdimg.com/?qt=sdata&sid=01000300001310111122499705Y) · [2021年街景记录](https://mapsv0.bdimg.com/?qt=sdata&sid=0900030012210112131617686HH)

窗宽暂以1.02米估算，灰泥、深色窗扇和铁件按照片估色。两处2013年街景的方向均经过原城1435屋壳，但同窗的方向线没有在两台相机前方形成共同交点。原城保留整栋街屋和地面，窗带通过本页单独查看。[定位记录](site-review.json)

在上海项目根运行 `python source/precise/changning-shengshi-garden-paired-windows/source/build_model.py --out out --audit review`。原创灰泥纹理由同目录的 `make_roughcast.py` 生成。
