# 浦西公寓蟠龙街26号题名券门

1931年建成的浦西公寓在上海市房管局第四批名录中登记为“批亚斯公寓”，蟠龙街26号与乍浦路199–215号、塘沽路411–429号同属4F004。顺塘沽路往东的387–401号另列4F005小浦西公寓。[上海市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

高参88在2024年的图集中将街面正照题为“蟠龙街26号为公寓主入口”。四个红字“浦西公寓”沿水泥门额横排，顶端有一列小齿饰。门额以下有突出券心、数层浅券线。红色扇形窗的分格条从较小的内弧展开。门洞中央敞开，左右各留一扇窄木门，下部是嵌板，上方是细格窗，26号绿牌装在右侧。2014年图集另拍自内侧，能够辨认院内轴向。[外侧正照及图题](https://blog.sina.com.cn/s/blog_5d1bdf480102zexp.html) · [2014年图集](https://blog.sina.com.cn/s/blog_55c85ddb0101g01c.html)

模型截取外侧门套至横额齿状檐口，中央通洞贯穿。门洞宽以2.96米为建模基准，券高、边扇宽度和题字间隔随照片比例推定。门额字形采用Noto Serif CJK SC近似重排，门口其余题字张贴物未纳入本体。预览图由实际两档网格渲染。[照片原图](https://s15.sinaimg.cn/mw690/001HIrzOzy8imPJbB4529&690)
