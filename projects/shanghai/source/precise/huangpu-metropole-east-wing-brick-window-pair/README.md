# 都城饭店东楼福州路双色墙角与双券窗

上海市第五批优秀历史建筑名录将都城饭店（东楼）登记在福州路106号。2015年12月和2021年1月的沿街照片都能辨认门边浅色转角石、上层连续的浅弧券窗和绕角水平带。现地招牌在两次拍摄之间已有变化，模型取两期均可辨认的二层街面。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [2015年街景](https://map.baidu.com/?panotype=street&pid=09000300011512071412081118D&heading=333.23&pitch=12) · [2021年街景](https://map.baidu.com/?panotype=street&pid=09000300122101081122561857I&heading=15.38&pitch=12)

近景正面可见两扇浅弧形窗头和沿左边交替出头的角石。斜面能看见角石转回侧墙、窗前细杆与退后的玻璃。远档减少券边曲线分段，上下两条水平檐线仍绕过墙角。 以两扇窗净宽约1.12米为图像比例基准。券面和墙垛进深、窗扇内侧构造及墙面片段高度是外观估计。

福州路106号的门牌点及其同址商业点位均在旧城市楼壳2085。江西中路180号门牌点在既有都城饭店主楼358。东楼的二层墙段独立展出，楼壳2085、主楼及邻房保留原状。
