# 新华路329弄17号花园住宅

市房管局第二批优秀历史建筑登记中，2M003的地址为新华路329弄17号。2014年图录收录的保护牌记1936年竣工，由邬达克设计，区规划资源部门的旧版介绍和后续转载则记1925年。1994年2月15日为公布保护的日期。两种建年均保留，尚待原始营造档案核对。[原表、保护牌和照片出处](reference-review.json)

从西侧弄道看，左侧是窄红门，中间是带浅尖券的四扇车库门，右侧的砖券主人入口有灰红筒瓦雨篷、白色曲线托座、内退铁花门和绿底白字17号牌。2014年12月Livelikerw的原片可读门牌。其文件说明曾写作36号，文件名、2014年6月组照和保护牌描述均对应17号。独立拍到的36号有圆形外墙。[西入口原照](https://commons.wikimedia.org/wiki/File:17_Alley_329_Xinhua_Rd._Shanghai.JPG)

花园侧底层有连拱，二层铁栏露台通往高出的方形房间。塔楼最上层有三组细格窗，两旁设百叶，檐上为矮四坡筒瓦。区政府所刊与2014年图录里的花园照片为同一视角。模型中，树后连续开间、阁楼侧面、北侧和东侧轮廓、屋脊与墙深根据外观和地块估配；尚缺室内、花园全景和原设计图。窗口、砖券、雨篷、数字门牌、铁花、瓦垄和露台栏杆均为原创几何。[区政府花园照](https://static.shcn.gov.cn/cncms/2024/02/08/961e9125-fe48-4d1b-99fb-e7a61804cbab.jpg) · [可编辑几何源码](source/spanish_villa.py)
