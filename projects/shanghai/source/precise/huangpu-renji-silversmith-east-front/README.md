# 仁记珠宝银楼中华路东立面

中华路5号位于方浜中路南侧。上海市第四批优秀历史建筑名录将其列作4A035“仁记珠宝银楼”，使用名称为“瑞源珠宝等”。隔着方浜中路的4A034原中国银行南市办事处在人民路1号，街角有圆钟。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

冯立记载，裘天宝银楼1916年在路口重建，1946年在原址成立裘天宝仁记银楼无限公司。工作名录将建筑年代记作约1920年代，具体完工年份仍待原始施工档案。早期街照中，东立面上方竖着一个覆曲面四坡顶的亭冠。该亭冠后来消失，楼内另有一座红瓦四坡采光亭，刊于2024年的街景仍可见。[《文汇报》](https://www.whb.cn/commonDetail/916501) · [早期路口照片](https://pastvu.com/p/674130)

东面中央是高起的卷草山花和大盲券，其下三扇小窗中间较宽。下一层的宽券窗两边有窄平头窗，券眉伸出短横肩。两翼各设一段透空石栏。临街底层依2021年1月的关闭铺面制作。2015年有商铺招牌，2021年已经撤下。门后的商店、消失的东亭、中庭采光亭和方浜中路长街翼还有待进一步调查。[2015年2月21日实照，Legolas1024，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E4%BB%81%E8%AE%B0%E7%8F%A0%E5%AE%9D%E9%93%B6%E6%A5%BC.jpg) · [出处和街景原始输入](reference-review.json)

四个街景站投射的102个像点对应26处外观特征。以两站露出的店门门槛定地面，估算山花顶高16.19米，中央盲券顶高13.88米，两翼窗轴相距7.55米。光线到拟合特征的距离中位数为0.12米，九成在0.30米以内。石雕局部、转角收口和各窗的凹入深度为照片估算。现有门牌和匾面不足以恢复历史题联。[配准参数](source/frontage-registration.json)
