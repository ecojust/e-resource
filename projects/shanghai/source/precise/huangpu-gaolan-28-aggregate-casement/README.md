# 皋兰路28号住宅庭院侧石粒墙与分格木窗

5A027在市表登记为住宅，门牌皋兰路28号。按Antigng于2018年7月30日自庭院拍摄的皋兰路28号住宅照片，取上层一樘棕色分格窗、浅色颗粒粗面墙、挑窗台和上方暗色檐缘。

粗粒状墙面由浅色基底和密集深灰颗粒组成。中央在窗台上横置成对棕色窗扇，可辨左窗两列、多道横格。 窗台前缘投下细阴影。屋面下方为深色檐口与间隔出现的浅色小端面。 照片右侧另有被棕榈遮挡的斜向构件，其用途不能从单张照片确认，建筑研究范围止于中央窗两侧的粗面墙。

树枝遮去右扇的大部分分格。右扇借左扇证实的构造补齐；窗扇启闭方式、石粒种类、两侧庭院墙深度和绝对高程未实测。模型仅呈现院侧窗间一段。
