# 长阳路50弄15号圆饰山墙与双层砖券门面

按2015年2月3日实照复原弄内15号门牌所在的一开间，包含花形砖圆饰、逐级叠出的山墙檐、二层弧顶窗、一层砖券、绿色号牌及三阶石级。照片左端门牌能读出15。三阶入口、砖券、上层的浅色弧窗和山墙圆饰在同一竖轴上。市表4F028共列15至31号。本模型截取15号的单开间，其余住宅和长阳路62号摩西会堂另有登记。

摄影者Livelikerw于2015年2月3日留下庭院视图。上海市房屋管理局2020年的资料说明馆区扩建与民居修缮的背景。隐蔽的内门和砌体厚度按照片估计。

[2015年实地摄影](https://commons.wikimedia.org/wiki/File:Alley_50_Changyang_Rd._Shanghai.JPG) · [修缮报道](https://fgj.sh.gov.cn/gzdt/20201215/fb5292d834d44284ac403e29245c9d01.html) · [依据与摄影许可](reference-review.json)

2015年原片可以辨认右侧窗扇朝庭院开启、内门后退于砖券，以及三阶石级的踏面和暗色立面。圆饰和门牌的位置直接依据照片。开窗角度、石阶尺寸和门洞深度按画面估计。现今馆区包括多栋建筑，地图保留各原屋体。
