# 陈望道旧居花园立面

国福路51号坐落在国顺路650弄复旦第九宿舍东侧，是沿国福路排列的三座旧居中最南面的一座。中央悬挑阳台前方没有落地支柱。站在花园里，能看见右侧两层弧窗分成数块平面钢窗，左侧黄墙上开着两只横向通风孔，更高处是逐级退后的绿色瓦檐。[花园立面独立预览](../../../fudan-jiuyuan-chen-wangdao-former-residence.html)

上海市房屋管理局第五批优秀历史建筑名录列出国顺路650弄1–78号住宅群（5G018）。住建部门的修缮回顾将国福路51号明确记在复旦第九宿舍内。2020年建筑遗产保护利用示范项目介绍记载房屋始建于1937年、建筑面积352平方米。2018年修缮后作为《共产党宣言》展示馆开放。向北相邻的两座楼分别是苏步青旧居和谈家桢（陈建功）旧居，2021年重新开放。两楼各197平方米，均有红瓦坡顶；它们的资料另列在分栋记录中。[市房屋管理局第五批名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [陈望道旧居修缮回顾](https://m.thepaper.cn/baijiahao_7025717) · [三座旧居的排列与分期](https://m.thepaper.cn/baijiahao_13467959) · [示范项目所录年代和面积](https://m.thepaper.cn/baijiahao_8127666)

## 照片与模型

Fayhoo于2019年11月9日拍摄了花园正面。住建部门发表的修后远景提供了第二个观察角度，修前照片还记录了后来拆除的阳台支柱。模型保留两层曲墙、弧面窗的折面玻璃、矩形窗扇、灰色窗台、通风口、绿色瓦肩和高部烟囱，后部在照片能辨别的脊和墙后收束。[Fayhoo原片，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Residence_of_Chen_Wangdao.jpg) · [照片与模型对照](../../../data/audit/fudan-jiuyuan-chen-wangdao-former-residence-v1/garden-comparison.jpg)

登记资料给出了建筑面积。各立面尺寸采用两张照片估算，门槛至上亮窗顶暂取2.75米，所有相对测点和投影矩阵均可复查。窗台与弧窗背后的收边、阳台纵深、树冠遮挡的瓦脊仍有深度不确定性。近远两档各有468个闭合可编辑部件，分别有11,936和9,800个三角面。照片射线以首击材质校验：2019年照片39点中38点正中，余下1点在2像素内；住建部门远景31点中25点正中，2点在2像素内，另4点落在烟囱轮廓、左翼瓦檐和弧形窗台附近。[两站配准与误差](measurements/garden-front-registration.json) · [弧窗两站记录](measurements/garden-bay-two-stations.json) · [三档逐点检验](../../../data/audit/fudan-jiuyuan-chen-wangdao-former-residence-v1/registered-photo-rays.json)
