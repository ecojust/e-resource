# 瑞士国总领事馆旧址阁楼百叶圆窗与石饰圈

5B032在市表登记为瑞士国总领事馆，门牌陕西北路80号。取陕西北路80号瑞士国总领事馆旧址的灰砖山墙中段，重建阁楼中央百叶圆窗、石圈和上接三角线条。

灰砖上有一圈浅石圆套，四枚较厚的楔石自上下左右跨过较细的圈线。窗内实际为一片暗色水平百叶。 圆套上方有短直石带接两个相背的三角空纹；三角纹下另有沿山墙斜升的细带。

窗径、深度和石材色值为单张斜向照片估算。原图能辨水平百叶的方向，暗部的叶片总数不可逐一确认。所在院墙、楼侧入口与场地绝对位置未纳入。
