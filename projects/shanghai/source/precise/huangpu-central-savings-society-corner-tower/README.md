# 中央储蓄会大楼天津路江西中路转角塔楼

上海市第四批优秀历史建筑名录将天津路2号、江西中路349号同列为4A012，建筑名为“中央储蓄会/广东银行”，使用单位为光大银行。黄浦文博记载江浙商业储蓄银行于1934年委托通和洋行设计此楼，约1935年迁入。1936年银行合并后楼内曾为中汇银行分行，中央储蓄会总会亦于当年设在这里。宁波路52号另有广东银行大楼。现存的河南路中汇银行大楼也有独立地址与模型。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [黄浦文博图文转载](https://www.sohu.com/a/1005319047_121123854)

现场转角宽约6.39米。沿窗的两道竖肋穿过顶檐，石墙向两条街逐次降低。两期照片各自以切角两端墙脚和顶肩校正透视，得到约35至36米的檐角视高。屋顶短竖肋、板块深度和门前踏步按可见尺度估计。作者在临近两条街的原墙上分别取5.15米及5.35米的局部，街翼余部沿用原底图。[配准参数及像素位置](source/frontage-registration.json)

Fayhoo上传的正面照能读出当时的“中國光大銀行”六字及其下分成双扇的深色金属门。每扇中部有圆形饰件，上下穿孔板可见多列相向的楔口。模型用实际开孔与门后暗面表现透空关系，孔数及浮凸量为估计。黄浦文博旧影的题名和门侧装饰不同，旧影仅用于复核两街翼和塔身轮廓。店招、线路与车辆没有进入模型。[正面摄影及许可](https://commons.wikimedia.org/wiki/File:The_Bank_of_Canton.jpg) · [照片签名](reference-review.json)
