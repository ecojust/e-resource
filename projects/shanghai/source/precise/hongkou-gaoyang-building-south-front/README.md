# 高阳大楼东大名路双塔正立面

上海市第二批优秀历史建筑名录将虹口区2F006登记为高阳大楼，地址东大名路817号。市住房城乡建设管理委、市历保中心记载，瑞士建筑师罗德于1920年设计，建筑于1921年竣工，原作南洋兄弟烟草公司办公楼及第四工厂。早期名录汇编将建造年代记为1915年，本次沿革采用记有设计及竣工时间的资料，并保留两种记载。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [市住建委、市历保中心供稿，人民网转发](https://sh.people.com.cn/n2/2026/0420/c134768-41557840.html)

东大名路南立面为五层，两侧前突，中段后退。两座塔亭的方形底座向上收窄，留有弧形窗罩、栏杆、小亭和旗杆。1937年的两张照片分别可见双塔、弧形转角，以及办公楼旁的独立厂房。1949年4月杰克·伯恩斯的照片拍到旧门廊和两翼。本次门廊、四柱、券窗及三排长方窗采用2012年两向街照、2013年署名实照及2026年公布的正视、斜俯照片，门廊的现代装饰与1949年所见有差异。[1937年图刊照片](https://pastvu.com/p/2576594) · [威斯康星大学密尔沃基分校馆藏](https://collections.lib.uwm.edu/digital/collection/agsphoto/id/14447/rec/30) · [1949年街面照片](https://artsandculture.google.com/asset/chinese-retreat-from-banking/_AHTgqaqqPLbmg) · [2012年东西两向街照](https://blog.sina.com.cn/s/blog_a598306e01017o81.html) · [2013年原图与署名](https://commons.wikimedia.org/wiki/File:Nanyang_Brothers_Tobacco,_Shanghai.jpg)

城市底图852的南缘宽约51米，正中有约4.1米退进。比对OSM 1267699489和两期屋顶资料，整块底图面积约2,899平方米、深约59米，沿街办公楼之后还有较低屋面、后翼和附属房。模型取临街一段，东西塔、南窗、门廊及可见侧面按实照，后翼、独立厂门和其他工厂建筑分列。东大名路378号红砖办公楼在本栋以西约732米，雷氏德工学院在本栋以西约548米。窗框截面、檐高和屋顶标高为照片估计。[地图地块与相邻模型](footprint-review.json) · [2015至2021年六个街面和院内相机](street-reference.json) · [两期屋顶来源](roof-reference.json) · [原照片登记和辨栋记录](reference-review.json)
