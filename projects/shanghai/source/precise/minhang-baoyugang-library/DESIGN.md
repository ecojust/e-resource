# 包玉刚图书馆：2021 重开外观重建设计 v2

本模型独立替换 `minhang-baoyugang-library` 的主馆201。保持源18点、多边形、GERS和OSM身份不变；东侧信息楼375独立保留。采用2021建筑团队外观、鸟瞰、楼层轴测及F1/F6平面作研究参照；2010/2013的CC照片仅作历史体量参照，不混入旧入口顶棚。

## 体量与方位

建筑局部u向东偏北5.840506°，来自源南侧长边10→9；v向北，负v为临思源湖的正面。源轮廓约97×40米、2291.70㎡只是整体占地/所有权线索，不是六层统一墙线。六个独立估计轮廓描述西侧斜肩、低层中央入口凹进、四层连续长带，以及五、六层逐级后退。北面采用轴测/平面可见凹凸，不镜像南立面。

初始层底z为0.45/4.55/8.65/12.75/16.85/20.95米，主屋顶24.85米、主体最高女儿墙25.70米，包含低矮屋顶凸起的整体最高点27.40米。全部是重建估计；官方/设计文本只支持六个编号使用层，无实测高度或可读米制尺寸。CNBH 25.4米仅粗略参照，不作为测量证书。

## 需要实做的构件

- 低层西端的斜玻璃带采用上下缘错位的实体薄玻璃、深框和拼接，不在墙面贴深色矩形；沿折线方向延续窗带。
- 南中段入口凹进约5.8米，通高约前三层。两根独立圆柱支承四层前沿，柱脚、柱头与上下构件有实际接触。通廊中间保留空域，不用实心盒子封住。
- 门厅设真实门洞和玻璃门扇；玻璃门厅顶采用弧面分片厚壳、金属拱肋及边梁，按2021照片处理。
- 东端为实体红色墙体，分层布置小窗洞，墙材由外轮廓减窗形成，所有洞口具有侧壁和窗台深度；玻璃、窗框、墙体独立语义。
- 五层退台设连续开敞廊，六层前退台设黑色长格栅棚。顶棚肋条、横梁和独立柱保持空隙，不用一整片黑板。
- 外墙小红面砖视觉由小幅材质变色与有限实体细缝组成。真实墙洞和退台优先于大量细砖。窗格横竖框、栏杆、扶手保留实际空隙。
- 屋面有女儿墙、压顶、落水及有限机房壳体；未见屋顶设备不凭空密铺。只重建为外观成立所需的室内楼板、柱和进深，家具/书架不冒充真实内装。

## 交付源码与检查界限

构建器使用numpy/Shapely生成封闭分件，再将局部建筑坐标旋转至源ENU，导出glTF轴为[east,up,-north]。每个构件保留label/material与三角面范围，便于检查实际导出结构。原生Blender场景由同一raw导入，预置全景南西侧、入口近景、东北/屋面三视角。源码不运行Blender；root唯一执行实际构建、原生渲染与验收。

LOD保留所有层轮廓、开口、退台、柱、玻璃顶、格栅棚、窗深框与栏杆；只允许减少重复面砖细缝、细小五金和非主要背面微细节。目标raw<45MB/web<20MB/native<30MB，每个文件必须<100MB。

后续实际检查必须测导出的封闭性/法向、实际窗洞与玻璃/框负控、通廊射线、柱与楼板/地面接触、棚柱/梁/肋接触及未侵入375。任何生成前的CPU草图/参数有效性检查均不能写成raw/native/browser PASS。

2021六张图片为私有研究材料，不复制到源码、不做纹理、不公开重分发；公开源码仅含URL、短事实、CC历史参照和自有建模代码。研究源和失败记录保持不动。

## v2形体补充与证据限制

经作者与独立研究复核2021图，F3/F4西端分别收至u约−37/−31.8米，F5/F6继续收至约−27.7/−24.8米。保留下层轮廓形成露台结构板，而非把西侧裁掉；两处侧端实体墙采用真正五边开口，具体轮廓/数量是对当代可见开敞段的有限估计，不冒充2010历史箭头开洞完整清点。2021鸟瞰仍可辨东部低矮屋顶突起，因此加简化多角屋顶凸起和浅斜帽；八边、四窗、27.4米顶高均估计。具体立面可辨数量与估计规则见facade-schedule.json。

## geometry-v2 实体接合修订

实际v1报告表明常规框外周内缩造成与墙/台的空隙。本修订只扩大这些框的外围实体，保持墙洞和光学内格原样。另两根棚架纵梁端部各延长0.10米，使最外侧原肋得到实体搭接。允许改动件由actual v1 roles导出的change-scope.json定义；所有其他件需导出后逐件一致性比较。棚柱经实际铺装→结构板链路已可连接，不因直接找板请求漏层而修改。

额外有界修复：v1三视图中六根F5廊柱顶与F6铺面共面，实际Float32高程均20.979999542236328米，造成规则深色圆斑。仅将这六柱顶部降至20.70米，在结构板底20.65米内保留50毫米嵌入；柱底/截面/位置、铺面及14棚柱原样。总允许265件改变，另2988件必须实际逐件一致。新raw仍需柱顶净距和正体积接触审核。
