# 乌鲁木齐南路180号住宅山墙烟囱与阁楼双窗

5D038在市表登记为住宅，门牌乌鲁木齐路180、182号。市表并列180、182号。2018年署名180号住宅的原照片显示，临街红砖山墙中央有一宽矩形烟囱高出两条深色斜封檐；两边的窄白框阁窗与烟囱位于同一端面。

烟囱方顶外挑，深色封檐分别从左右两侧接入其下半部。露出的烟囱面与山墙同为红砖。 左右各有一扇偏窄且退入洞内的浅色窗框，右侧之外更暗的开口被树枝遮挡。模型只取清楚可见的两扇。

房屋局部有枝干与电缆遮住，截取可追踪的烟囱顶部、山墙斜边和两侧白框。未独立认定182号的部件。背面、烟道内腔、墙厚与屋面进深缺乏实测，截面尺度按照片比例。
