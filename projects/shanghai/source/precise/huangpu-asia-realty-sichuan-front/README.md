# 四川中路106–110号普益大楼街面

第三批优秀历史建筑3A004记为“普益大楼/普益地产公司”，列用单位上海电气集团总公司。现行OSM w378107167仍标上海电气集团总公司、旧名普益大楼、同一门牌及1922年。1921至1922年兴建，设计者为德和洋行（Lester, Johnson & Morriss）。修缮资料所记建筑面积约7000平方米。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [建筑修缮资料引述](https://www.thepaper.cn/newsDetail_forward_8138151) · [2006年摄影档案题名与建筑师资料](https://www.flickr.com/photos/23268776@N03/10514313524/)

临街一面朝西南偏西。2015年1月2日的实照能辨认中央五组三联窗、两侧双窗翼、顶层较小的双窗、成对承托和齿饰。窗按各自洞口建模。基座两组大窗前有实柱，成对的柱轴比玻璃向外伸出。中部门比南端街门小，南端门扇有圆形金属花饰，拱上气窗深入券口。[街面照片及摄影许可](https://commons.wikimedia.org/wiki/File:Former_Asia_Realty_Co._Building.JPG) · [来源与估计范围](reference-review.json)
