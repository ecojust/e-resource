# 愚园路749弄65号花园住宅红砖圆转角

区规资局公布的街面照片可见红砖沿圆弧连续转向，底层窄窗有竖砌砖过梁和外挑砖窗台。两道浅色线脚随圆弧转到邻面，顶部又收为直角挑檐。模型保留这处几何变化、上层狭窗、落水管和左侧三扇窗。[长宁区规资局原文](https://www.shcn.gov.cn/col7698/20211207/1151493.html)

原稿和网页近景各有35,122个三角面，远景有4,696个。近景砖皮有实际厚度与凹缝，两档使用同一幅程序生成的错缝砖纹。原始照片长438像素、高678像素。按窗角、雨管、台基、两道线脚和挑檐取25处控制，另留出4个窗角，重投影误差为1.5至4.5像素，均方根约2.7像素。带状构件只比较影像中的高度。单张照片不能提供绝对尺寸，半径与纵深以局部比例估算。

打开[模型独页](../../../yuyuan-749-no65-red-brick-corner.html)可转看街面、上层折角和底层砖窗。原始GLB保留详细网格，网页和远景GLB采用Meshopt压缩。Blender文件把砖皮、线脚、窗、管道和屋顶分组，贴图随文件内嵌。
