# 新华路329弄36号双层圆形住宅庭院面

上海市房屋管理局第三批名录的3M014登记为住宅，地址为新华路329弄36号。长宁区2024年的居民口述报道将这座建筑辨认为双层圆形砖木住宅，记载占地905平方米、建筑面积543平方米，内外两层承重砖柱形成环形排架。同一篇报道另有40号的院照。上海日报所刊黑白照片给出36号和独立的庭院视点，两份报道均未注明照片原始摄制日期。[长宁区原文](https://www.shcn.gov.cn/col7343/20241227/1275366.html) · [上海日报图文转载，照片署名 Ti Gong](https://www.meet-in-shanghai.net/en/guide/xinhua-road-a-witness-to-urban-life-development-over-past-century-160847/)

模型范围是庭院门、左右玻璃砖采光窗、上层三开间阳台、圆弧转折的砖壁和可辨的瓦檐屋坡。源照片仅用于测量。后庭和内圈客厅的喷泉没有可复测的外观资料。正门门槛至横档2.12±0.14米为条件尺度。屋面半径参考公开面积，投影误差和真实照片尺寸可从控制表复核。

在仓内运行 python measurements/fit_garden.py 及 python measurements/make_garden_cameras.py 可重算摄影机。python measurements/check_mesh.py 输出目录 可生成近远二档，报告三角数与逐件有向边闭合。几何及程序构建采用 MIT 许可。
