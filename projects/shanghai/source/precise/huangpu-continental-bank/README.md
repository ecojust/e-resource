# 大陆银行上海旧址

九江路111号。第二批上海市优秀历史建筑名录2A041登记为大陆银行，使用单位一栏为上海信托投资公司。基泰工程司设计，1931年5月开工、1933年11月竣工。底层及夹层为银行营业空间，上部含办公出租层。四川中路261号的四行储蓄会是另一处建筑。当前OSM地块w446966514@4列上投大厦并保留大陆银行别名，冻结城市中业主为1718。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [楼宇史与修缮图文](https://web.archive.org/web/20231220014736/http://news.cjn.cn/zjjjdpd/sh_20054/202212/t4377732.htm) · [地块](https://www.openstreetmap.org/way/446966514)

## 九江路北立面

中央石阶在门洞内向上伸入。入口有两盏带金属边框的八角长灯，巨大的石质门额显示「上投大厦」「SITICO」，靠地处两个「111」门号清晰。基座上方黄褐色泰山面砖，整体向上收分。靠两翼的砖窗墙各有四列，上部中央后退七列，可分为两、三、两列相邻窗。窗下浅色石板、折线浅浮雕和女儿墙强调竖向。模型取临街约8.4米，只将实际有资料的北面与门洞做成完整细部。[2015年实照](https://commons.wikimedia.org/wiki/File:Dalu_Building_Shanghai.JPG) · [2022年正立面和入口近照](https://web.archive.org/web/20231220014736/http://news.cjn.cn/zjjjdpd/sh_20054/202212/t4377732.htm) · [本体和边界](footprint-review.json)

1931年入口方案图有未按图实施的构件。当前采用两份街照共同能确认的已建几何，另将近照中的现用铭牌标为当代状态。同济设计院的整修记录说明，1992年后加的瓷砖被拆除，使用多种配色重新铺贴泰山面砖，2013年设计、2015年竣工。新闻资料记原建10层；当前城市记录以13层估高41.6米。估算的沿街部分不用于解释整栋层数和屋顶分期，后部仍保留城市来源。[修缮设计方](http://www.tjad.cn/project/329) · [原照及文件散列](reference-review.json)
