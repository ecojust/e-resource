# 高桥蔡宅阶梯封火山墙的两级瓦头与三角灰饰

5W027在市表登记为蔡宅，门牌高桥镇季景北路714弄11号。Fayhoo于2015年5月9日拍到高桥蔡宅封火山墙。端头随墙身分级增高，白色窄端层层叠出，三角形小面内有浅浮弧纹；上方的深色瓦盖和脊尖向上翘起。

近端与后一级都清楚见到三角浅色封面、数道叠线脚，和两侧黑瓦的端部。近端下方的墙体被屋面遮挡一部分。 高一级的三角面可辨成排短弧状灰饰，屋脊最前片向上扬起；相邻建筑和满铺坡屋面在本件范围以外。

市表为季景北路714弄11号，照片另列北街104弄11号。摘取能在原照区分的相邻两级；墙端饰纹细小，浅浮弧纹、压瓦搭接、背面和绝对尺度按可见比例估计。
