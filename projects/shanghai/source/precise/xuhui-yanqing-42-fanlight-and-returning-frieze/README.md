# 延庆路42号住宅扇窗与转角灰饰腰线

D50102在市表登记为住宅，门牌延庆路42、52号。Antigng于2018年2月7日拍摄的延庆路42号住宅照片中，街面浅绿拱口内有米色辐形扇窗。灰蓝饰带从扇窗上方延伸至外墙转角；两面的短横纹列在同一高度。

上段弧框中有一弧梃和三根较直辐梃；浅绿券脚下有深灰色叠线的方柱头。 窗上腰线有多层浅色出挑线脚；灰蓝色粗面带上、下各一排短饰，下排几道横纹由短变长。图中转角两侧均可辨。

名录同列42号、52号，现场照片题注明确为42号。本件止于一樘扇窗和它正上方的转角腰线；后续开间、52号和一层实体门板未由此图推定。边缘宽度和灰饰凸出深度为照片比例估算。
