# 英华书馆双色砖券窗与镂花裙板

第四批上海市优秀历史建筑名录在4F009行将英华书馆登记在武进路412号，名录中的现名为海军托儿所。2015年高参88发表的门牌及外楼照片把院墙与灰砖红券的楼体放在同一组记录中。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [高参88的照片](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102vz70.html)

Legolas1024于2011年9月8日拍摄的近照显示，两道颜色不同的砖券框住一孔窗。左右侧亮以两道横档分隔，中央一对窗扇有细竖栏和上亮。透视校正可见窗下镂花裙板分为三格，两外格各有两组卷花，中央窄格一组。模型保留窗边起拱的短檐、外圈深色砖和灰砖墙的部分，窗宽约3.12米为按照片比例估值。[原始近照](https://commons.wikimedia.org/wiki/File:Anglo-Chinese_School%27s_Window.JPG) · [标定与来源](reference-review.json)
