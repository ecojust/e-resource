- 名义总高42.65m、底层砖身边长6m来自文献；7.85m塔刹出自其他章节，未核共同高程口径。

- 层高、收分、檐出、厚度、隐藏立面及12柱对称下廊均含估计，不是现场测绘。
- 实际有限瓦面/脊座检查与root支承准则须按原报告解释；不能把中心线接触扩写成全宽连续接合或全塔无碰撞。
