# 真如寺大殿 · 普陀区

这是上海第三人称漫游项目的独立建筑源码。对象是 `putuo-zhenru-main-hall`，城市分块 `14-13716-6693`，源对象 `1947`。只替换真如寺正殿，不把后方佛塔、天王殿或侧廊并入模型。

模型按2025年正面照片组织深色木墙、六扇格子门、两处火焰形直棂窗、单檐歇山屋顶、厚瓦、正脊鸱吻、椽子、斗栱和石阶。2013年斜面与历史背面辅助理解结构。北面现状、总高度和具体开间未测绘；158平方米原文的面积口径也不明确。请一并阅读 `DESIGN.md` 和 `calibration.json`，勿将估计尺寸解释为测量结果。

`geometry-input.json` 保留真实源对象、四角、朝向和九个邻接对象。它用于唯一映射，约20米的源四边形不直接当作墙线。模型在米制东、北、上坐标中构造，再导出为glTF坐标。

## 构建

需要 Python 3、NumPy、Shapely 2.1或兼容的约束Delaunay三角化接口。输出目录必须不存在，防止覆写已有证据。

```sh
python3 build_model.py --output /absolute/new-run
blender -b -t 2 --python render_previews.py -- --glb /absolute/new-run/putuo-zhenru-main-hall-raw.glb --output /absolute/new-native --samples 48 --threads 2
```

构建程序输出原始GLB、几何记录和资产元数据。Blender脚本从实际GLB建立可编辑原生文件以及全景、正面细部、后侧三张预览。中性地面、灯光和相机放在独立预览集合中；它们没有并入GLB。预览不代表人审或相机标定通过。

每个交付文件必须严格小于100,000,000字节。原始GLB、原生文件和网页资源分别以60MB、50MB、25MB为工作目标，最终大小必须在实际构建及打包后检查。网页与远景版本由项目已有独立打包工具生成；不用拆开一个模型的内部GLB缓冲区来规避文件限制。

## 检查范围

生成阶段核对每个真实Float32构件的闭合边、退化三角形和正体积。后续必须独立读取实际导出的GLB，检查屋面、瓦片和脊底接触以及真实门窗开口，再审阅原生预览和网页漫游。局部射线与有限接触检查不等于整栋建筑无碰撞，不提供室内通行保证。源码准备时没有实际导出、原生或浏览器PASS。

`source-freeze.json` 是作者源码及选定参考的明确白名单。`independent-review/` 由独立审查者维护，单独冻结，不属于作者源码冻结。运行产物应放入新目录，不写回已冻结源码。
