# 真如寺大殿：构造与证据边界

本目录只制作真如寺正殿；背景佛塔、天王殿、两侧二层回廊、庭院香炉和花盆属于其他对象。模型采用2025年正面照片所见外观，2013年斜面与2019年照片辅助核对结构，历史背面只能说明旧状，不能证明当前背面完全相同。没有主殿中央塔刹：正面照片中的尖塔是后方独立佛塔。

原始城市轮廓和唯一源对象完整保留在 `geometry-input.json`。约427.68平方米的映射四边形不是已确认的墙脚或檐线。官方记载“面阔三间，进深三间，带正方形，面积158平方米”，未定义该面积是净面积、墙脚还是其他口径。因此以面积平方根约12.57米形成的方形主架只是可复现估计，不强行将墙体拉伸到20米源四边形。

主架采用四乘四柱网，形成三乘三开间。16柱、金柱6.45米/直径0.40米、檐柱4.28米/直径0.32米来自官方文字；柱础标高、具体开间宽、现代构件断面和柱倾方向的空间布置仍估算。文字中金柱内倾0.16米、檐柱内倾0.08米不能扩大成全部构件经测绘确认。其他页面的9.96米高、13.9米阔、9.5米深是邻近天王殿的数据，本模型不采用。

屋顶为单檐歇山：两个主坡、两个下部山面斜坡和两端木山花分别成形。长正脊、两端鸱吻、垂脊、戗脊、角端小饰与瓦面分别建模；脊底与真实坡面接合，瓦片有实体厚度、覆盖关系和承托，椽子与斗栱独立存在。曲率、外挑、总脊高和装饰细部是照片约束的估计，不写成实测或精确元代复原。官方明确现代屋面装饰经历重塑，不声称保留了元代原装饰。

南面构造六扇格子门与两处火焰形直棂窗，门窗是实际开口和木框，不以黑色平面代替。门扇开启角度和未被香炉、绿化遮挡证明的下部细节仍估计。北面六门依据文字与历史图作有限重建，现状未完全核验。侧墙粉白、檐下及正面深色木构、灰石基座和台阶按可见外形处理。不制作未经核实的佛像、室内装饰或内部通行路线。

图片仅供结构观察，不复制进模型贴图。原图和许可逐件保留；模型几何采用CC BY-SA 4.0，代码MIT，OSM/Overture源轮廓保留ODbL署名。所有模型资源严格小于100,000,000字节。

制作后必须另做真实导出几何检查、瓦/脊有限接触检查、门窗射线检查和三张原生预览人审；这些尚未发生。网页和目录接入由root后续验证，不从源码准备推导PASS。


## geometry-v2 修正

原生预览揭示原版的斗栱木端穿出瓦面，以及四条垂脊跨越高低屋面不连续处形成遮挡木山花的大块陶质侧壁。新版本只修改120根斗栱臂、20个承托座与4条垂脊；保持标签、16柱、门窗、山花、全部瓦与屋面不变。斗栱整体降低并缩短外伸臂，保留与檐枋及承托座的连接；承托座顶部逐点随真实屋面倾斜，进入基底25毫米。垂脊内侧仍承托于高主坡，外侧足点沿高主坡边界，避免错误下降到独立的低山面。实际不穿顶、连接与非修改部分字节一致由独立新原始模型检查证明，不能直接沿用旧原生PASS。
