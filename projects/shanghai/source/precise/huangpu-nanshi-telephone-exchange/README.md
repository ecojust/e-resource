# 上海电话局南市总局中华路钟楼立面

中华路734号列入上海市第三批优秀历史建筑，编号3A024。街前保护牌记载原楼于1920年竣工，采用钢筋混凝土框架，正面钟楼立在方形基座上。2019年发表的名牌近照可与市房管局表中的原名和门牌逐项核对。[第三批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) [名牌、历年街照与照片署名](reference-review.json)

2017年3月19日的完整街照用来校正街墙、穹顶和栏檐的比例。2019年发表的正面及两侧街景上，可以数出钟面左右各两根柱、带花饰的柱头、弧形屋顶的分缝，及下层半圆窗外侧成对的券肩装饰。模型取沿中华路的22.12米，保留三层窗墙、中轴钟台及入口台阶的街面关系。[2017年原照](https://commons.wikimedia.org/wiki/File%3AShanghai%20Telephone%20Exchange%2C%20South%20District%20Branch.jpg) [2019年发表的照片](https://blog.sina.com.cn/u/5d1bdf480102z0zh)

同址两个具名街屋位于一长一短的相邻地块。对照旧街坊图和路口窗列，钟楼属于较长的东楼，地图要素1473与该楼OSM轮廓重合98.2%。西侧942、其余街翼与后排旧屋继续保留。2017年街墙基线测得细杆顶端投影至街墙面的视高约26.9米。另以2019年近正面照片的201像素塔檐宽复核62像素穹顶，穹顶高约1.73米，模型细杆顶高约24.86米，街翼和塔基纵深根据正面与斜照估计。[街缘测量及尺寸区间](source/frontage-registration.json)
