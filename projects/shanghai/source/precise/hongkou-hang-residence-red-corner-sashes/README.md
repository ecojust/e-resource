# 杭氏住宅舟山路455号上层转角红框窗

5F021在市表登记为杭氏住宅，门牌舟山路455号。杭氏住宅后来作舟山路幼儿园。Fayhoo摄于2014年11月23日的舟山路455号照片中，上层窗面在街角折回；一道粗红横档沿两面延续，横档以下的窗格有较细的竖梃，窗脚由浅色石台联结。

朝左的一面有连续竖梃，较短的右面在横档以下再分开。交角处是可辨的粗红立梃。 窗脚浅色平台沿折线转向；窗上及两侧大部分墙身被枯藤与架空线遮住。两根电线穿过照片中的窗格。

仅按照片中未被藤蔓遮住的上层窗复原。窗框涂层的成分、窗后使用情况及墙厚没有实测数据，窗台进深与角度按原照估计。
