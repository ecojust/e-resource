# 柳林别墅51号

愚园路532弄的柳林别墅列入上海市第五批优秀历史建筑。院门右侧铭牌写有“愚園路／532弄51號”。高参88从门外拍下带铭牌的铁门，又从院内拍下同栋住宅的双层弧廊和两翼三层凸窗。两张原图的EXIF记为2014年6月2日，相隔约二十秒。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [高参88《愚园路532弄柳林别业》](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480101ilpi.html?cid=97400)

模型以一层柱轴的横向中点为原点，院地为零标高。两台相机分别由同名砖缝、檐口和栏杆基准求得位置。灰砖尺度用于定标，门后两层墙估在柱轴后约2.28米和1.75米。可辨的十五樘翼窗分布在凸窗正面及斜面，左翼中层按两扇打开的姿态制作。屋檐后的红瓦至庭院照片可见范围止，烟囱进深和被遮住的窗下缘为估计。[两机位与尺度](measurements/no51-house-cameras.json) · [凸窗位置与洞口](measurements/no51-wings-and-window-surrounds.json)

院门与住宅采用同一坐标。门的初始安置会挡住院内照片里的主入口，复查以门外照片的门廓及院内照片的无遮挡区共同限制院门位置。门脚在两张照片中均不可辨，其下端按庭院铺地补齐。[院门定位与原始控制](measurements/garden-gate-placement.json)

原城市图中51号地址点对应轮廓2212。市表同弄另六个门号各自保留。[七个门号的对照](measurements/footprint-review.json) · [位置要素](measurements/seven-house-addresses-and-footprints.geojson)

原始与近景模型各140,120面，远景模型75,584面。程序分别建立石柱、木窗扇、院门铁艺、灰砖女儿墙、地坪和屋面，保留可编辑的部件标签。[源程序](source/build_model.py) · [许可](SOURCES-LICENSE.md)
