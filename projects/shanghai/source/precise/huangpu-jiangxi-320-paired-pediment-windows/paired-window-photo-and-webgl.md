# 道达大楼的临街窗楣与垂布

江西中路 320 号的两扇窗各有一座三角窗楣。2015 年的照片可见，四片侧布长短和蓝赭条纹间距各有差异。对照图左侧取自照片，右侧是普通网页的整组视图和左窗近景。[查看照片与网页对照](paired-window-photo-and-webgl.jpg)

首版网页从街面看时会剔除部分侧布和石檐的背面。修订时校正了四片布与斜檐的三角面朝向，并把布面材质设为双面。下表将原照中保留作复核的 31 个蓝色点投到浏览器实拍截图，记录落到蓝色像素的点数。观察角度、遮挡和缩图会影响逐像素计数。[完整观测](paired-window-webgl-samples.json) · [逐面射线核查](measurements/visible-surface-comparison.json)
