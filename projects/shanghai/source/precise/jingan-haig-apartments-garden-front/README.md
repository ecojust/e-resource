# 海格公寓主楼南向花园立面

2025年6月6日，上海市历保中心和上海市建筑装饰工程集团公布了修缮后的实拍。图0所见的南面包含四列阳台、门廊左右的三窗竖向凸出带、成对的浅山墙和两端的三跨石柱敞廊。图3给出弧形铁栏、贝壳状托座和中部灰泥徽饰，图16可辨敞廊的两根独立石柱。1948年3月照片可以核对四列阳台和中央券门。现状模型采用修缮后照片里的屋顶、门窗和栏杆。 [修缮实录](http://www.shjsjtdw.cn/node2/n59/u1ai15520.html) · [新民晚报修前、修后对照](https://www.jfdaily.com/wx/detail.do?id=936489)

市房管局第二批优秀历史建筑2B018列海格大楼，现名静安宾馆，华山路400号。静安区转载的建筑史与现物业使用华山路370号。哈沙德洋行在1925–1934年间设计、修建公寓，1977年改为静安宾馆，1992年加建两层。2022年开始改造，2025年以海格公寓重新运营。区建筑史记载加建后九层，2025年报道写十层；修缮实录有明确的9楼露台和38米楼高。 [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [区建筑史](https://www.jingan.gov.cn/rmtzx/003008/003008005/20220218/97dcf8c2-714c-42a1-9e3a-2b11e9a08ed9.html) · [重新开业](https://www.shobserver.cn/wx/detail.do?id=868222)

底图14-13718-6695的1554号楼体位于草坪北侧。冻结南墙长52.84米，沿东偏北方向展开，外法线方位164.89°。2016年航片可见主楼白色南面、后凸双单元和中央门廊。2024年的同位屋顶仍可匹配，2026年的斜视投影使东侧高楼屋顶盖住草坪的一部分。酒店兴趣点在草地上，离主体约44米。北面的昆仑酒店、西侧上海宾馆和东侧弯折高层均有各自的实体。 [足迹核对](footprint-review.json) · [照片、航片及署名清单](reference-review.json)

门匾“海格公寓／HAIG COURT”用独立可编辑的实体字形制作，字形源及授权随模型提供。南面窗格、开间、石阶、阳台出挑、灰泥徽饰及柱头的尺寸按图片估算；北面、室内与草坪保留原有场景。照片仅作目视比对。 [字体来源](source/fonts/provenance.json) · [SIL OFL](source/fonts/OFL-and-attribution.txt)

