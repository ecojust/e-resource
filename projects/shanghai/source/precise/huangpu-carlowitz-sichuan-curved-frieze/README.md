# 礼和大楼弧形转角花饰腰线与砖齿

上海市黄浦区四川中路670号。红砖圆转角上的白色花饰腰线，石带分缝、凸起的连续小垂弧和挑出压顶，底下紧邻一列凹凸相间的红砖齿。

位置和饰纹节奏据2016年2月18日实照。节选展开长约4.56米，栏带及上下砖层约0.94米，曲率和各层前后距离为照片比例估计。
