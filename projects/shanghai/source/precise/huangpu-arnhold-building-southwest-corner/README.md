# 安利大楼西南转角入口与两街红砖窗带

建筑在四川中路、九江路交叉口东北角。第四批优秀历史建筑4A017登记安利洋行，地址为四川中路320号、九江路80号。1907年5月奠基，1908年12月封顶。档案馆记录它采用早期现浇钢筋混凝土框架，2005年保护牌将结构概括为砖混。[市房管局第四批原表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海市城市建设档案馆史料](https://www.sohu.com/a/357557307_120056521)

文旅部门将原建筑主入口记在转角。沿四川中路往北数个窗跨，现有灰白色半圆门标320号，楣上有金字“安利大楼”，旁边的保护牌同时列两个门牌。2019与2020年的照片可见角部白色晶通公司招牌，2023年9月12日路景已换成蓝色弧带。九江路另有切石半圆券门。模型以2023年街貌为主要依据。[市文旅局建筑导览](https://www.thepaper.cn/newsDetail_forward_22086178) · [2019年街口原照](https://commons.wikimedia.org/wiki/File:80_Jiujiang_Road_Shanghai.jpg) · [2020年春的门牌和两街原照](https://www.meipian.cn/2wis2f38)

西南角红砖窗轴在七层内连续展开。白水泥腰带绕过折角，六、七层之间为层叠出檐，顶部保留可见铁栏；凹入窗框、窗上挑起的蓝色雨篷和临街的设备仅按能辨认的位置处理。四个2023年摄影点得到屋顶实墙高度25.69至27.44米，中位数26.59米。肩部进深、窗框细部和屋面退距由影像估计。[逐层窗高量测](../../../data/audit/arnhold-building-southwest-corner-v1/preflight/vertical-survey.json) · [屋角和门洞交会](../../../data/audit/arnhold-building-southwest-corner-v1/preflight/axis-survey.json)
