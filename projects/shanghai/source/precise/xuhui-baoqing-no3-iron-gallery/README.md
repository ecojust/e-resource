# 宝庆路20号花园住宅三号楼三跨铁栏廊

四根红砖柱分出三跨。靠前的铁栏由横杆、竖杆和中央相交的斜杆组成；白色窗格退在栏杆之后。

上海市第四批优秀历史建筑名录4D013将院内3号楼、4号楼并列登记。本模型以3号楼署名照片中的南面中央三跨为界，两旁转角和底层前厅另属主楼。开间与石带按照片比例估计。 [municipal register](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [史博臻，文汇报；上海市住建委](https://m.thepaper.cn/baijiahao_6986155) · [老房子爱好者](https://m.toutiao.com/i7058536127912821251/) · [云中游子](https://www.meipian.cn/5q8ow8z1)
