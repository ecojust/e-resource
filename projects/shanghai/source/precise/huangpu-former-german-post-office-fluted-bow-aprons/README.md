# 原德国邮局转角弧窗下的竖槽饰板

上海市黄浦区四川中路200号。四川中路与福州路转角的上层圆弧窗下，正面饰板的细竖槽连续排列，侧面一段随弧墙折转。两组饰板之间是平整的墙柱，窗台石沿弧线向外挑出。

模型选取正面一段及照片左侧可见的一段。中间一段按照片比例估宽1.36米、高0.92米；槽数按可辨亮暗线近似，曲率和槽深未经现场测量。
