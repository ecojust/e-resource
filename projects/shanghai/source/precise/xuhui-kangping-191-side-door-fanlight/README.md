# 康平路191号边门的双道弧梃与五辐扇窗

5D094在市表登记为住宅，门牌康平路187-191号（单号）。高参88在康平路187、189、191号的逐幢图录中，把一张拱形深褐木门的照片题作“康平路191号边门”。其扇窗有五根放射梃和两道同心弧梃，门框上缘在中央轻微隆起。

五根黑褐色斜梃自中央小半圆向外展开，穿过一道较大的半圆弧，最外侧嵌入厚木框。木框外可辨数道很窄的浅色灰线。 扇窗底下深褐横木中央高，两侧较低；右扇门的碰缝竖梃顶在中央横木下。

市表5D094并列三个单号，本件按照片题注仅归191号边门。射线夹角、白色灰塑凸出深度和窗框进深依照片估计，下部木门与门内空间不在所取局部中。
