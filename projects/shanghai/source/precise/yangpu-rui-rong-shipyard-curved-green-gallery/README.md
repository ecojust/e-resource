# 瑞瑢船厂旧址转角双层绿铁栏外廊

5G013在市表登记为瑞瑢船厂旧址，门牌杨树浦路640号。杨树浦路640号临街建筑的圆转角上，两层外廊各有连续绿铁栏。取圆角上的数扇窄窗、上下阳台板、交叠菱格和下垂弧杆。

圆弧楼板沿街转过墙角，两层栏高、竖杆间距与交替的菱格大体一致，细杆围住呈U形下垂的铁条。 墙上深色窄窗的上部有横梃，开间由横向成带的浅色壁柱分隔；突出檐线下可见排列的小齿。

两层栏杆按2015年照片在街角处可读的重复单元重建。曲率、栏杆背面和构件实际厚度为比例估计，未将此立面扩展至其余船厂用地。
