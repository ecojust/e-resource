# 参考与估计范围

- [新华社，2015-09-03](https://www.xinhuanet.com/politics/2015-09/03/c_128194603.htm)：史料馆设在瓮城和城楼内，帮助确认建筑身份。
- [同济大学建筑设计研究院项目 672](http://www.tjad.cn/project/672)：地址南安路87号、园区分区及改扩建项目资料。项目总面积不是城楼单体尺寸。
- [文旅金山，澎湃政务，2021-06-02](https://www.thepaper.cn/newsDetail_forward_12962670)：正面和斜俯视照片用于辨认砖拱、双重檐、门窗、围合外墙和外梯。未发现开放再分发许可，照片没有进入本源码、材质或模型包。
- Esri World Imagery：用于人工估计围合上缘角点及相对朝向，影像拍摄日期和正射偏差未知；不把影像像素作为贴图，也不把估计角点称为现场测量。
- OpenStreetMap `way1074070665` 把近乎整园范围标为 `building=ruins`。其源 UUID 只用于根项目研究错误粗模型的替换关系，不能当作本城楼的独立外墙轮廓，也没有被本作者修改。

`source/design-input.json` 保存根项目接受的作者阶段估计设计；其中研究文件路径与 SHA 是溯源标识，不是运行建模脚本所需的外部依赖。本目录只保留最终合并设计，不要求私有研究图片存在。

高度约 18.9 米、墙体收分、内向面标高、精确瓦列与窗格计数均为估计。外梯可见下段位置由照片和影像约束；其遮挡上段沿外墙上升，再在墙顶接入，属于避免穿墙的几何合理化，未声称已经观察或测量到该连接。

相对上一未接受作者草模，当前修复了步道、梯踏、平台与帽石的重叠水平表皮，保留最终顶面高度；主门拱券改为与灰青砖接近的相对灰阶。均不构成新的现场测量。

楼阁地坪为9.05米、内向低面为8.45米。两者相交处补充0.60米灰砖台基，限定在楼阁足迹与低面交集，并去除被占据的低面及穿过房体的内沿压顶；已有墙顶步道不再叠加台基。背侧可见的台基是避免房体悬空的隐藏结构合理补全，不是新增观察事实。

上部栏杆的转角由连续管形构件形成，避免重复立柱与转角表面；木柱在上枋底部结束。屋脊细部的横带和短柱保留真实小开口，属于简化推估，最高卷曲脊饰高度未改变。

上枋与两檐之间四面木填充的相交平面在挤出前合并，保留原占据体积，并去掉转角重复表皮。拱券和门侧砖块自墙外表面开始向外凸起0.13米，与墙体门洞内缘分段衔接，未改变原门洞轮廓。
