# 长乐坊337号院门与相邻临街窗墙

模型定位于上海市徐汇区长乐路337号。2017年原照提供临街赭色墙面、两对深绿木窗、下层两片外倾挡板和退进侧翼。2015年街景给出院门上337号绿牌的位置，以及门柱、双扇金属门和连向住宅的围墙。两座低瓦檐从街窗上方向院内收坡；其后是有白框滑窗和外开绿扇的高层。

局部坐标以临街左上窗中轴落到人行道的点为原点，X沿街向西南偏西，Y向院内，Z向上。相机标定采用约2米高的小门作尺度先验。屋顶、退进墙面和门牌在不同机位上可见的范围不同，各类测量包含自己的误差记录。百叶箱的三个冬季机位中，两个2015年机位间距约16.34米。三个机位交会测得百叶前缘从主窗墙向院内退约2.84米。335号院门位于另一端，单独保留为同组待作范围。相邻327、329号住宅已有单独模型。

从仓库根目录运行以下命令可重建近景及远景网格，检查所有组件的有向闭合边及正体积。

```sh
python -B projects/shanghai/source/precise/xuhui-changle-337-courtyard-gate-and-street-house/measurements/check_mesh.py /tmp/changle-337-mesh
```
