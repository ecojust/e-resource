# 国泰公寓南楼东端临街窗组与砖檐

黄浦区淮海中路的国泰公寓分南北两栋，上海市房管局列为第四批4C003。名录地址含816弄1—40号、818—832号及850—860号双号。按两栋各自的城建足印和淮海中路街景，本件选南楼院口西边最东一组二至四层的窗。870号国泰电影院和锦江饭店的原华懋公寓分别有独立地点记录。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [两个楼栋与原城市几何](footprint-review.json)

Baycrest于2007年2月沿淮海中路向茂名南路拍摄的照片可辨棕砖南楼、浅色窗框与进退交错的角石，整排烟囱从西向东延伸。2015年12月和2021年1月的近街影像在院口西边同一面墙上显示上下三组四联直窗、金属窗框、两组向街外挑的围栏和东端上檐。黄浦最上海记为公和洋行设计、1928年建成，南北各四层。文中提到的北立面窗与本件分处两栋。[Baycrest原片，CC BY-SA 2.5](https://commons.wikimedia.org/wiki/File:Huaihai_Road_(M).JPG) · [近街各站与像素](reference-review.json) · [黄浦最上海，2019年](https://www.sohu.com/a/291955393_186647)

模型沿街宽约5.5米，最低构件距街面5.55米，最上部短坡檐距街面16.41米。两处独立拍摄点的反投影用于测窗与窗间墙。街景绝对坐标按已签原城东南角校正，窗标高误差约0.46米，檐部约0.85米。栏架出挑和檐后的截面仍按短距离估计。底层店面、院路、北排与其余屋面均列作后续范围。[量测与误差](measurements/measured-facade.json) · [原创建模源码](source/build_model.py)
