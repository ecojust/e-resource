# 宝庆路9弄住宅红瓦坡面的双扇老虎窗

5D066在市表登记为住宅，门牌宝庆路9弄1-6号。Fayhoo于2015年9月4日署名的宝庆路9弄2号、3号合照中，左栋红瓦坡面前伸一扇双格老虎窗。浅框窗扇两侧是暗灰色侧板，上沿挑出一道黑色薄檐，周围保留有清楚的波形瓦列。

两扇浅色玻璃窗呈并排长方形，中央立梃清楚，深色短檐超过两侧板；临街斜角可见侧板随大屋面不断收窄。 红瓦连续横排，瓦沟与瓦冠成起伏，屋面下边缘露出多层浅色檐带。

图注同时列2号与3号，无法单凭这张图确定画面左栋的独立户号。市表5D066还包括1至6号其余住宅。现代空调遮住窗台中段，本件据两侧显露的金属泛水估计进深；主屋脊、其他房屋、设备与院落均在本次细部取景之外。
