# 外白渡桥

外白渡桥跨苏州河口，连接中山东一路和大名路。市房管局第二批优秀历史建筑名录将它登记为 2A012。上海市地方志「跨苏州河桥梁一览表」列建造年份为1907年，两跨各52.12米。车行道宽11.2米，两侧人行道各宽3.6米。模型采用这些尺寸。桥面之外的街道接坡保留底图原有范围。[市房管局登记](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海市地方志](https://web.archive.org/web/20160627185318/http://www.shtong.gov.cn/Newsite/node2/node2245/node68289/node68296/node68348/node68354/userobject1ai65878.html)

2011年斜侧照与2019年河岸侧照给出了双跨交会、中央桥墩、桥面的菱格边饰和栏杆。2018年桥上取景能辨认横向门架、转角的弧形托架和与车行道分开的步道。三幅分别署名 Legolas1024、kallerna 和 Bgelo777。另据 HLBB75 上传于2007年的桥头照片核对桥墩与对岸的关系，其实际摄制日期待查。[2011年照片](https://commons.wikimedia.org/wiki/File:Waibaidu_Bridge.jpg) · [2019年河岸](https://commons.wikimedia.org/wiki/File:Waibaidu_Bridge_Shanghai.jpg) · [2018年桥上](https://commons.wikimedia.org/wiki/File:Garden_Bridge_in_Shanghai.jpg) · [桥头旧照](https://commons.wikimedia.org/wiki/File:Garden_Bridge_Shanghai.JPG)

桥轴取自具名的道路和桥面轮廓，取两者共同覆盖的河段中点定位，辅以冻结底图的同名线核对。杆件截面、门架高度、变动水位下露出的墩身、栏杆间距与材料颜色依据照片估算。水下部分、隐蔽构造和桥头铭牌留待补证。[照片署名、许可与下载摘要](reference-review.json) · [具名道路](https://www.openstreetmap.org/way/27498117) · [桥面范围](https://www.openstreetmap.org/way/815631996)
