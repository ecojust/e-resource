# 虹桥路2275号历史住宅山墙与屋顶

上海市房管局第二批优秀历史建筑名录在长宁区表中列“2M009*、住宅、虹桥路2275号”。同表脚注为“*于1996年左右灭失”。《长宁区志》记第二批于1994年获批，并将此宅称为“有特色的花园住宅”。现有两份登记资料未给出建造年、业主或设计者。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [长宁区表行及同表脚注](municipal-table-extract.html) · [《长宁区志》存档](https://web.archive.org/web/20160326061534/http://www.shtong.gov.cn/Newsite/node2/node4/node2249/changning/node15354/node42164/node62988/userobject1ai27741.html)

胡家康、底谓所著《上海老洋房》由学苑出版社于2015年10月出版，ISBN 9787507748666。出版社于2020年3月2日重刊选页，图版下方署“虹桥路英式花园别墅（虹桥路2275号）”。两年分别指初版和重刊时间。画稿依据哪一年的外观及纸本页码仍待查证。[书目信息](https://book.douban.com/subject/26974486/) · [出版社署址选页](https://www.163.com/dy/article/F6N3PCHF05149LBV.html) · [署址图版](https://nos.netease.com/dingyue/2020/0302/d2d0b0a0j00q6jmqu001bc000hs00bhm.jpg)

模型表现树篱上方的高山墙、成组窗、相接的两翼坡面和两根烟囱。墙体下部在画中受到遮挡。模型的灰调、坡面进深及窗格取自透视比例，实际尺寸和历史色彩仍待查证。2017年转载所配的半木构住宅照片另与虹桥路2310号罗别根住宅相符，该图的地址存在冲突。[逐项证据和原件哈希](reference-review.json) · [罗别根住宅资料](../changning-luobiegen-garden-villa/README.md)
