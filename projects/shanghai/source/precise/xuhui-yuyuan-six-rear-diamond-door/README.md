# 愉园6号后门菱窗与卷草铁艺

上海市房屋管理局第四批优秀历史建筑名录登记愉园的范围为淮海中路1350弄2–16号。徐汇区公开的照片中，同一扇后门有全景和近景。铜牌上方为“6”，下方为“一三五〇弄后门”。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [徐汇区照片与原始门窗详图](https://www.thepaper.cn/newsDetail_forward_25896580)

上海市城建档案馆公布的愉园营造图表把D1柚木门标为3英尺3英寸宽、7英尺6英寸高，换算约0.99米和2.29米。照片中的门扇宽高比例与该门型相符。由此估算菱形玻璃对角线约0.46米，中心高出门扇下端约1.53米。右侧卷草被临时张贴物局部遮住，模型依可辨的连续铁条线段收口。木扇、玻璃、铁件、门框、门牌及石门槛各自成形。[尺寸与照片量测](source/dimensions.json) · [参考图出处](reference-review.json)

独立页提供整门、凹廊、菱窗和门牌四个角度。现有底图同一建筑块涵盖5号与6号附近的住宅，尚不能把这一扇后门落实到可复核的墙段。地图保留原建筑轮廓及地面通行。[定位记录](placement-review.json)

门牌文字由项目逐笔绘制，木面和铁艺采用原创几何与材质，按MIT许可提供。摄影及档案图使用原发布方链接。[模型源文件](source/door.py)
