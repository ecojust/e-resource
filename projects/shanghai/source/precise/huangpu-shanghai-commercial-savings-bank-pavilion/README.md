# 上海商业储蓄银行宁波路主楼重檐歇山楼亭

上海市房屋管理局第四批优秀历史建筑名录将上海洋行／上海商业储蓄银行列为4A011，门牌为宁波路40、50号、江西中路368号。上海市银行博物馆的陈培卿记载，银行于1931年迁进宁波路50号的新大楼。黄浦文博刊出1932年3月30日的街角旧照，今天还能从街角辨认深红砖、水平石线脚和屋顶轮廓。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海市银行博物馆](https://www.sohu.com/a/729775414_121124391) · [黄浦文博](https://www.sohu.com/a/757462633_121123854)

这次制作的是宁波路一翼屋顶的重檐歇山楼亭。街侧可以看到上下两层出檐、红色格扇、檐下梁头、翘起的瓦角与带镂空的浅色脊饰。近档逐列制作瓦行与街侧圆瓦当。原照深处读不清的脊饰只取轮廓。背墙保留素面，主楼其余街墙、天井、前景黄墙、中楼和小楼沿用现有底图。[2015年2月23日街角实照](https://commons.wikimedia.org/wiki/File:Former_Site_of_Shanghai_Commercial_%26_Savings_Bank.JPG) · [Fayhoo街景](https://commons.wikimedia.org/wiki/File:Shanghai_Commercial_%26_Savings_Bank.jpg)

屋顶所在的城市原楼为14-13720-6693的2363号，含一个天井。它与同时带市级编号及原行名的OSM关系16213630平面重合98.30%。两种航片以南侧高位檐线为参照，测得楼亭全檐长约17米、宽约9米。估计中心在沿街方向有约4米不确定度；下檐与格扇的相对比例依据街侧近照。近、远两档各45个实测点均位于原屋顶25.60米处。请分别参见[原始照片与出处](reference-review.json)和[双环轮廓、落位及测量](footprint-review.json)。

模型使用原创几何与材质，无嵌入照片。可编辑原件以米为单位，正X沿宁波路向东，负Y向街，Z为高程。公开网页展示屋面上方的单体；主地图保留楼体原有的地面和天井。
