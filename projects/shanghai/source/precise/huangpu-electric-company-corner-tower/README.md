# 电力大楼南京东路与江西中路转角塔楼

南京东路181号登记为上海市第三批优秀历史建筑3A008。上海市文化和旅游局记载，现存电力公司大楼建于1929至1931年，原设计九层，实际建成六层。路口斜切面上从底层主门至塔冠可以连续辨认，窗上暗色铸铁饰板与两侧赭色面砖构成竖向窗带。[市房管局原名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [乐游上海建筑沿革](https://news.qq.com/rain/a/20230114A015EV00)

本次制作转角本身、江西中路侧约6.9米与南京东路侧约7.25米。街角正视与斜视照片用于核对五层窗、塔冠的多层装饰、浅色花岗石基座及门口两侧灯具。门牌181的细照显示两幅不同的带太阳、人物和电光图案的金属门饰。2013年街翼旧照可核对窗带和砖墙。[照片逐张观察、署名与范围](reference-review.json)

原底图建筑编号235，匹配具名OSM地块380339852第6版，足印交并比为98.81%。街角正视照片右后方的高楼属于其他建筑。楼高、细饰深度与窗洞尺寸含估计，楼内、屋顶后部和其余街翼保留待查。[地块及邻屋](site-identification.json) · [转角配准](source/frontage-registration.json)
