# 江川大楼（德华银行九江路营业楼）

九江路89号位于四川中路与九江路交叉口东南侧。1994年上海市人民政府现场铭牌称「原为江川大楼，曾为德华银行」，1916年竣工，1988年加建两层。市房管局第二批名录2A042另列「物业供应站｜市医药供应公司｜九江路89号」。劳动报记载，德华银行在1920年代返沪后选择这里。早期银行曾用外滩14号，两处楼址分别有自身的建筑史。[市房管局表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [铭牌及2015年街面组照](https://blog.sina.com.cn/s/blog_5d1bdf480102vg6v.html) · [劳动报](https://wap.51ldb.com/shsldb/xf/content/0184e6b31170c0010000df844d7e124a.html)

2013年的完整街面与2015年的两街细照显示，西北切角为单门，门楣上有巴洛克式山花。北、西两翼都有贯通三层的科林斯巨柱、从柱后退进的窗带、底层券窗和上部并列窄窗。早期照片可辨早期第四层，现代照片中其上还有1988年的两层。每组柱头花叶、门上雕饰和环形纹饰由原生网格独立建模，标高、背面与屋顶保留估计。[2013年全貌](https://commons.wikimedia.org/wiki/File:Deutsch-Asiatische_Bank.JPG) · [资料和使用范围](reference-review.json)

原生建筑源14-13720-6694/1064与四川中路261号联合大楼2602位于同一个六业主近景文件内。九江路89号、四川中路294号和该楼两处西门定位都指向同一江川大楼地块。三份GLB及Blender文件复用项目的MIT模型发布流程，照片仅供外形研究。[原址资料](footprint-review.json) · [建模源](source/jiangchuan_geometry.py)
