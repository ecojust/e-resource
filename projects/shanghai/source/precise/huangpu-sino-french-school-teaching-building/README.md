# 光明中学教学楼（原中法学堂）

市房管局第二批优秀历史建筑名录以 2A054 登记淮海东路70号。校方沿革记载学校创办于1886年，1911年改名中法学堂，1946年改名中法中学，1951年改称光明中学。1913年，学校迁到敏体尼荫路一带的新校舍，今为西藏南路。西段先建成三层，1923年7月东翼扩建，将原先的凹字形平面延为山字形。此模型的原点在正对操场的中央教学翼。淮海东路门牌指向学校南门。[校方档案、历史照片及访查记录](reference-review.json) · [Virtual Shanghai 建筑档案](https://www.virtualshanghai.net/Data/Buildings?ID=39) · [看看新闻校史报道](https://m.kankanews.com/detail/RXyO4MdvAQV)

校园正面横向约84.9米，进深约24.3米。三处凸出的翼部之间留有两段开敞廊前空间。中央翼两端各有两道通高的窗轴，中央三开间阳台由后墙、转折面、柱间栏杆及楼板围合。历史正面照与2021年电视画面可以逐段对照开间。2024年近照可读到中央曲线形匾上自右向左的“光明中學”，上有五颗星。西藏南路端墙依照早期照片的五开间及顶层拱窗复原。三层均保留可见外廊深度，教室门窗后为建筑外壳。[历史正面照](https://www.virtualshanghai.net/Photos/Images?ID=1367) · [西端历史照片](https://www.virtualshanghai.net/Photos/Images?ID=1601) · [现状近照](https://news.qq.com/rain/a/20240705A00UDX00)

冻结的城市建筑源1709覆盖1617.5平方米。现行OSM外环与冻结面交并比约0.982。北侧和东侧多层校舍保留各自的地图几何。楼层高度、纵向开廊进深、栏杆及屋面附属体尺寸为估计。三期影像均显示深色低坡屋面，地面照片未提供屋面设备的详细结构。照片仅用作几何和材质的参考。校名以经许可并改名的字体子集生成实体字。[地块、保留建筑和坐标](footprint-review.json) · [建模源码](source/school_geometry.py) · [字体授权](source/fonts/OFL.txt)
