# 康平路196号住宅

上海市房屋管理局第五批优秀历史建筑名录收录此处住宅，编号5D031。2019年2月23日的具名外观照片记录了灰色临街墙、两组宽百叶、中央分格门扇、横窗、浅色灰塑和齿状檐口。构件使用以米计的局部坐标。窗缘的跨视角尺寸约束和原片标点见 [measurements](measurements)。

## 重建与复核

在仓库中运行 `python measurements/check_mesh.py output` 可生成近景及远景GLB，并逐部件检验封闭性与方向。入口檐带、窗扇及卷草灰塑均有实际厚度。窗框的宽和高由照片中可辨识的边缘定出，灰塑和檐线的凸出厚度按明暗变化推定。
