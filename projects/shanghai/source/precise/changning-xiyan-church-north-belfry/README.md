# 息焉堂北侧独立钟楼

市级名录2M010「安息堂」登记虹桥路2381号，上海教区正文用可乐路1号，通讯地址用17号。教区记“堂北面有大钟楼一座，内有铜钟四只”。模型以院前、隔河共四张照片交叉定位钟室、塔身和塔顶。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海教区堂史](http://www.catholicsh.org/DetailMap.aspx?ID=4) · [照片作者、许可及原图](reference-review.json)

2011年冬照中，沿两面逐级升起的小窗在落叶树后清晰可见。2016年5月两张照片记录了钟室的尖券石框、横向百叶和折角灯亭。六月院前照片另可辨黄赭色拉毛、碑身收肩、碑顶小十字及塔檐的压顶。模型采用六月无金字状态。隐蔽侧钟室按对称关系收口，小碑铭文与四只铜钟形制仍待内外详照。[四机位模型对照](../../../data/audit/xiyan-church-north-belfry-v1/registration/four-station-models.jpg) · [原像素机位与保留点](measurements/tower-stations.json)

暂取塔脚3.60米宽，推得檐高16.57米、十字顶20.68米。四张照片共60个形状读数，8处单独留出，误差约0.5至5.0像素。六月正立面十字顶读点与联合解相差11.8像素。两档网格分别为393及261个闭合构件，逐面复算无重复。50处独立材面点中，近景44处正中、远景47处正中，其余均在2.24像素内。[近景逐点回投](../../../data/audit/xiyan-church-north-belfry-v1/registration/full-source-four-stations.json) · [远景逐点回投](../../../data/audit/xiyan-church-north-belfry-v1/registration/lod-source-four-stations.json) · [两种饰面实照取色](measurements/finish-readings.json)

教区将设计归潘世义，另载1930年筹墓。研究转录将1930年8月2日的三钟祝圣、1931年8月29日的圣堂祝圣分别列出；原刊对应页仍待查。1925年见于照片说明。2008年4月5日复堂有教区直接记述。墓园约4.96万平方米，旧大门在马家桥东堍，桥西题「上天之门」。1968年约4000平方米改作校舍，1974年其余改作库场。1944年1∶50,000区域图可读附近水道、村落和道路，墓园完整界址仍待更大比例的地籍图。[堂史、引文及历史地图读数](measurements/church-cemetery-and-reopening-history.json)

现有钟楼点距主堂原始地块2.52米、距精细主堂水平外缘约2.56米。2019年及2025年正射影像中，主堂铜顶表观中心与已登记垂直轴均相差约5.99米。塔脚四角未能可靠辨清，当前单独展示钟楼。[地块、两期航片和条件距离](measurements/tower-and-church-orthophotos.json) · [既有主堂](../changning-xiyan-church/README.md)
