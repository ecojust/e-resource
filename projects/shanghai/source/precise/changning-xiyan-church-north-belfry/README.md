# 息焉堂北侧独立钟楼

教区记“堂北面有大钟楼一座，内有铜钟四只”。名录2M010「安息堂」用虹桥路2381号，教区正文用可乐路1号，通讯地址为17号。主堂、墓园与钟楼各自有不同的轮廓和历史范围。[教区原文](http://www.catholicsh.org/DetailMap.aspx?ID=4) · [主堂模型](../changning-xiyan-church/README.md) · [照片、许可和来源](reference-review.json)

模型取院前和隔河共四张照片。2011年冬季裸树后露出相邻两面台阶窄窗，2016年5月院前和隔河两张近照可读钟室的三联尖券、水平百叶、叠起的石檐、短灯亭和铁十字。2016年6月院前照片又拍到了塔脚的深色小碑。立面以六月状态为准，五月另有金色题字。四只铜钟仅见文字记载，未获可辨的内部照片。[四机位与读点](measurements/tower-stations.json)

四机位共60个形状读点，8处留作检验。模型暂取3.60米塔脚宽，檐高约16.57米，十字顶约20.68米。按同一组照片求出的这些尺寸随条件底宽等比例变化。共有393个近景闭合构件与261个远景闭合构件；原门前纪念碑及背侧障蔽处的文字和开口另待实测。[近景模型](../../../data/audit/xiyan-church-north-belfry-v1/working-geometry/full-source.glb) · [近远景几何检验](../../../data/audit/xiyan-church-north-belfry-v1/working-geometry/solid-review.json)

2008年4月5日金主教主持复堂。原墓园约4.96万平方米，教区还记大门在马家桥东堍、桥西题额及1968、1974年的土地用途变更。教区记设计人为潘世义。旧名录照片的1925年、教区1930年筹办公墓的叙述和其他建堂年款分别保存。墓园原墙线、钟楼塔脚精确外廓尚需历史地籍图。[教区网页存档](https://web.archive.org/web/20240423212747id_/http://www.catholicsh.org/DetailMap.aspx?ID=4) · [现有地块及钟楼点](../changning-xiyan-church/tower-exclusion.json)
