# 国泰电影院西南街角

上海市第二批优秀历史建筑2C004位于淮海中路870号，原名国泰大戏院。地方志记载1931年竣工，1932年元旦开业。Virtual Shanghai 建筑293使用旧门牌870 AVENUE JOFFRE，历史照片1463可见斜向入口、阶梯塔和纵长窗列。[上海市房管局](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海名建筑志](https://web.archive.org/web/20190415083238id_/http://www.shtong.gov.cn/newsite/node2/node71994/node81772/node81774/node81784/userobject1ai108968.html) · [历史影像](https://www.virtualshanghai.net/Photos/Images?ID=1463)

影院2022年暂停营业，2024年1月5日重开。重开现场和2025年5月4日的正面照均显示简洁的矩形红砖门罩、罩上方五个中文立体字、横排与塔身竖排的CATHAY字样。早期游客影像记录了另一款红金卷花罩。模型按2024–25年入口及可见相邻两段街面制作；旧罩、完整影院和室内另计。[上海市政府的重开报道](https://www.shanghai.gov.cn/nw4411/20240106/d74cdc9f66c342e3acc35b6bee1a6579.html) · [同期现场](https://www.thepaper.cn/newsDetail_forward_25926340) · [2025年正面](https://commons.wikimedia.org/wiki/File:Cathay_Theatre_20250504.jpg)

斜角宽约11.51米，站点2706号轮廓与实名OSM建筑445267150对应。原生粗模高9.6米，街角高塔及旗杆根据影像比例估计；纵深至切面约9米。保留影院后部及相邻独立街屋。门罩、标字、灯具、竖窗玻璃、面砖和白色窗边分别建模。[定位及固定数据](footprint-review.json) · [照片与使用许可](reference-review.json) · [建模源](source/build_model.py) · [字体子集](source/fonts/README.md)
