# 下沙街西段院内住宅南面折角凸窗与仿石隅饰

5W035在市表登记为住宅，门牌航头镇下沙街西段。市表登记此住宅在航头镇下沙街西段，2020年9月20日Dragon实拍的上海市优秀历史建筑公布牌标下沙街454号，牌文描述南立面西侧为六边形凸窗、墙面由青砖砌成且转角饰砖砌仿石。院内正照可见凸出的西侧窗面及其右方内凹入口、二层露台。本件截取凸窗上层照片能辨明的三面，包括灰砖、交错角块、窗台及红褐木扇。

正面窗左半的浅木格与右半的暗开口并列。右侧折面窗红褐颜色较浓。各个折角处浅色仿石块由短横缝隔开，隔层长短交替。 图11的右边保留内凹阳台，图12近摄阳台和楼下一层入口，图25、29、32记录巷门与454号市级挂牌。正中那道斜搭的近代遮棚遮住下窗。

院内另有航头刘氏宅区级保护牌，作者从巷口回拍同院。挂牌和两组视角共同指向院内主体，街门、其他附房及附近门牌的地籍关系未据此划分。壁厚、转折角、绝对尺寸和背面依照片比例估计。
