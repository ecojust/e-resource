# 渔光邨尖顶烟囱与三联排烟孔

屋顶浅色粗粒抹面烟囱。长面三条高低错落的尖券排烟孔，端面一孔，下接方筒与折边金属泛水。

长宁区报道和建筑史记载均采用“渔光邨”。名录采用“渔光村”。四条平行里弄共享登记，同型烟囱出现于多处。

长面1.4米，窄面0.5米，建模高度约2米，均按照片比例估计。排烟孔外轮廓与抹面可辨，烟道内部深度未有施工图可核。
