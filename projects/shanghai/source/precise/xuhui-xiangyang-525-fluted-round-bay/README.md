# 襄阳南路525号住宅弧形窗廊与椭圆饰墩

5D034在市表登记为住宅&上海尚朵文化传播有限公司，门牌襄阳南路525号。2018年署名实照中的住宅上层弧形窗廊，三根浅色嵌柱间并排两扇分格钢窗。各柱脚下有红色椭圆饰面，窗顶外伸檐口可见浅黄托块。

白柱的上下端可辨浅竖槽，中段在阴影中较平。灰色方墩中央是竖置的暗红色椭圆，转角处继续沿弧线排布。 两扇可见窗各被深色竖梃分格，窗梃比柱细。檐口顶和下缘带暗红线，檐下方块相间。

弧墙只取原照正面三柱和中间相邻两跨。实际半径、钢窗厚薄及刻槽深度按图估计。左侧被植物遮挡的小瓶栏与屋顶栏杆另属其他范围。
