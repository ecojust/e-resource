# 格林邮船大楼

中山东一路28号的上海清算所占用原格林邮船大楼。市房屋管理局第二批优秀历史建筑名录以北京东路2号登记，历史使用名称为上海广播电视台。两条街在本模型的东南圆角交会。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html)

## 建模范围

沿中山东一路从东面查看五轴立面。中央三扇门间有两根石柱，门额上为带拱饰的石牌，楼上能辨出两根长壁柱、中央两层凸窗、露台石栏和檐口齿饰。北京东路入口一角的曲面逐段建模。屋顶多边形塔楼分层内收，现存中英文上海清算所铭牌采用实体字。模型向西约15米，后翼仍用城市底图。楼高、屋顶背面、南侧被遮挡窗列与建筑进深均含推定。未重建室内。

1927年资料可比对圆角、凸窗和塔冠的早期外形。2014年Livelikerw的街景及2025年Suicasmo与Supanut Arunoprayote的实照用于核对现状。原图、作者、许可、时间与文件哈希见[照片记录](reference-review.json)。摄影图未作为模型贴图。主地块采用Overture及OpenStreetMap数据，登记要素为1332号。隔街怡和洋行与北邻东方汇理银行各有独立要素。[地块配准](footprint-review.json)
