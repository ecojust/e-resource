# 光陆大戏院 · 光陆大楼

沿虎丘路走到南苏州路，旧戏院入口对着西北侧街角。上海市地方志记载，鸿达洋行（C. H. Gonda）设计，1925年动工，1928年2月25日建成。剧场使用楼下空间，包含楼座和包厢；楼上为办公室和公寓。[地方志、档案与照片](reference-review.json)

现状主立面依2019年高处实景和2025年河岸照片建模。较高的入口塔和较低的南端塔在1928年照片中已出现。市档案记扇形平面、矩形钢窗和窗下浮雕，第四层附近有腰线。档案和《上海名建筑志》记九层，《解放日报》专文记八层，现状图像可辨八道主要洞口带。楼层用途的历史称谓独立于可见外墙的窗带数量。[建模来源](reference-review.json)

具名轮廓定位于冻结源2457。其东侧现代退台单体2770与旧楼有共墙，南面广学大楼位于虎丘路128号，两者各保留独立边界。瓦片的16米估值低于照片可辨的两座塔，模型的层高、塔帽和背面采用估算。[地块、三期航片及独立源](footprint-review.json) · [查看模型](../../../capitol-theatre.html)
