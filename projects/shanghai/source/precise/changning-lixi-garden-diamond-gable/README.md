# 利西路花园住宅菱形砖饰山墙与方烟囱

利西路30、32号的花园住宅约建于1935年。区规资局把两个门牌同列，照片中左侧那面红砖山墙有上下同轴的菱形砖饰，旁边的方形砖烟囱戴灰色顶盖。 [长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211207/1151473.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

窗间红砖、两道灰色线脚、压在灰色边条里的尖山花，在正面近远两图均可辨。与照片复看后加深了外菱边缘，斜面图可追到砖烟囱的多层顶盖。 山墙净宽暂取4.5米。照片同列30和32号，无法独立给画面左侧山墙指定其中一个门牌。窗脚以下和完整屋面未测绘。

区规资局原照同列30、32号。两门牌分据不同位置，照片的左侧菱饰山墙没有门牌，未作足印替换。
