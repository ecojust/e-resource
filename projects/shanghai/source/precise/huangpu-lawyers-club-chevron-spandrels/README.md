# 上海律师公会会所双列钢窗与人字纹窗裙

2015年第五批优秀历史建筑名录5A069列原上海律师公会会所，现名银行博物馆，地址复兴中路301号。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

入口上方三层各有一对钢窗，两列窗沿中轴上升，在屋顶各有一块压顶。窗下反向的斜纹在相邻区块相接，形成人字。 具名地点照片可以同时辨认门牌301、银行博物馆题字和上方窗裙。出处未列拍摄年月。[银行博物馆具名照片](https://www.amap.com/ssr/place/B0FFGLW6WA)

2020年2月19日街景拍到转角另一侧的斜纹墙面与金属门。模型依据具名照片复原中央窗列。单窗宽约0.92米是显示比例依据，窗裙与压顶的进深由可见边线估算。[百度地图街景](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122002191251411735O)

独立查看模型可选择正视、斜视、屋顶或窗裙细部。原城区建筑继续保留。
