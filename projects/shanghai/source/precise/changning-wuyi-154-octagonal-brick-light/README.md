# 武夷路154号住宅山墙八角砖窗与横档

5M009在市表登记为住宅，门牌武夷路154号。在2018年冬季的武夷路154号街照中，后排红砖墙有一个平顶、平底的八角形开口，八边沿口均有朝洞口排列的红砖。深色洞面中央留有一根横档，上方檐下是竖砖带。

八角开口四边近水平或竖直，余下四角斜切。相邻方向的红色立砖在八处转角收拢，外侧墙身的砖行仍水平。 窗腔里看清一道暗横档，画面近处的另栋坡顶遮到其右下墙面，未遮住八角洞轮廓。上面一带立砖与窗之间仍有几皮横砖。

原拍摄位置低于开口，无法辨认其深处是否另装玻璃或百叶。模型采用暗底表示照片中可辨的深色平面，尺寸及进深是近似值。
