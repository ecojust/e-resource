# 光远坊内院三联木窗与分层窗台

上海市黄浦区北京西路256号。内院照片中的一组三联木窗，含两根深色木梃、凸出的双层窗台、窗下浅圆饰和两侧墙面分格。

窗洞宽约1.72米、净高约1.21米。比例来自改造前的内院题图，绝对高程、做法和构件深度待现场实测。
