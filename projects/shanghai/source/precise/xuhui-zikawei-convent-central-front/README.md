# 徐家汇圣母院旧主楼庭院中央山花立面

市房管局第二批名录2D032登记漕溪北路45号。2016年照片说明同列旧门牌45号和后用201号，实地餐厅名为上海老站。2013年、2026年的两张街侧照片可以对照同一端墙的高山花、圆顶和相邻矮翼。曾在此营业的餐厅于2023年歇业。[市名录与三张照片原始记录](reference-review.json) [2023年报道](https://sghexport.shobserver.com/html/baijiahao/2023/07/23/1080490.html)

1869年是修会迁入这里、形成圣母院的机构沿革。现楼年份有1926和1929两种记载。模型按2016年院景可辨的中央大山花、四开间竖窗、红瓦斜屋面和西侧两开间玻璃廊制作。山花中央拱头窗两侧有小方窗，靠近顶尖另有一枚竖向小孔。树冠后遮住的底层和左右小山花另留待考。照片没有作为纹理嵌入。[2016年院景，Fayhoo摄](https://commons.wikimedia.org/wiki/File:St._Ignatius_Convent.jpg)
