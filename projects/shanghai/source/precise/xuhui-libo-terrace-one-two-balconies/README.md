# 丽波花园南排一、二号分户双阳台

衡山路300弄里有两排各住四户的连排住宅，列在第四批上海市优秀历史建筑名录4D027。南排从临街一端依次为1至4号，北排为5至8号。2021年发表的高位照片越过衡山路向西北看，近处右侧的分户墙下方就是南排1号和2号各自的阳台。照片与1948年图上的两排端墙、现状屋顶和八个具名门牌相互吻合。[市级登记表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [院内的两排住宅与栏杆近照](https://m.thepaper.cn/baijiahao_13881095) · [门牌与屋顶](measurements/eight-addresses.json)

两扇上层阳台门的中心距约2.45米，每块阳台板宽约2.10米。分户墙跨过两片坡瓦，从檐下露出端头。两户各有独立的铁栏、短挑板和带斜肩的门洞。近景中两片短斜边托起一段平直的浅色挑眉。两户上层门洞按照片分别取约2.28和2.17米高，屋前树枝遮挡了部分底层。门高、层高由六组摄影参数和三种墙面退距估算，阳台进深和屋顶截取位置也为估计。[门窗与阳台的像素控制点](measurements/southern-pair-dimensions.json) · [摄影方向](measurements/street-and-row-direction.json)

近照中，每面铁栏分成两格。格内的方饰片上下排列，细铁条从片旁成对蜿蜒。狭窄的竖向分隔由四组套环左右交错组成。整面铁栏的左、中、右三条窄带各有四枚套环，两组方饰分别位于窄带之间。中带把套环的交错方向反了过来。方片与成对细波纹各有一层矩形小框，框的两根竖杆一直连到栏杆顶边和底边。方片中央的浮雕辨识度较低，模型只刻出能看清的外框。[全宽的三条套环带](measurements/grille-front-two-cells.json) · [铁栏近照取点](measurements/grille-controls.json) · [不同年份的图像与使用范围](measurements/photographs-and-road-bearing.json)
