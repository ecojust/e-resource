# 五原路258号自由公寓南立面

市房管局第二批优秀历史建筑名录2D040登记自由公寓，地址为五原路258号。徐汇区文化局2006年4月4日刊载的建筑介绍记建于1933年，杨浦区图书馆馆藏文章记落成于1937年。两份资料都描述了九层点式公寓。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [徐汇区文化局介绍存档](https://web.archive.org/web/20140426234018id_/http://whj.xh.sh.cn/xhwh_website/HTML/xhwh/xhwh_wwbh_wbdw/Info/Detail_25748.htm) · [杨浦区图书馆介绍存档](https://web.archive.org/web/20140426222554id_/http://www.yplib.org.cn/structure/jdsh/bnsz/jz_73602_1.htm)

Livelikerw 于2013年12月25日拍摄的正面照片可见中央两列白色窗框、三道高出女儿墙的竖肋和两边低一层的楼体。2020年2月及2021年1月五原路上五个取景位置可复核中央凸部的短返面。两翼外端受树木和邻屋遮挡，模型在此以简化墙面收边。原照片署名许可为 CC BY-SA 3.0，本模型使用独立制作的几何和材料。[2013年照片](https://commons.wikimedia.org/wiki/File:Liberty_Apartments.JPG) · [逐件来源与摄影记录](reference-review.json)

中央凸部到切线进深约6米。粗石基座、南面通道和三级踏步见文字资料，下部墙窗位置、窗扇分格、檐高、饰带深度及踏步尺寸为估计。模型范围限于南立面及邻接的返面。院地、车库、后部楼翼和室内仍可另作考证。

五原路258号的地名点位于冻结建筑3297内部。OSM原建筑 w1204088729@1 与冻结平面的交并比为97.64%，三期地图影像版本可以核对南沿凸部、两翼收进和独立东邻。原屋面来自城市底图的15.35米估高，正面九层高度另按照片比例估计。[地址与屋面对照](frontage-location.json) · [固定城市底图输入](footprint-review.json) · [可重建源码](source/build_model.py)
