# 中兴银行前楼（福州路与四川中路圆弧窗墙）

市房管局第四批4A022登记中兴银行、申达大楼，门牌为福州路89号。2011年孙玫的修缮论文记载，1927年改建成形的六层前楼沿街折成L形，五层后楼原作仓库，另有连接体和西侧连廊。工作名录将前后楼分别系于1927年和1934年。地图具名轮廓存有整个登记地的1934年字段。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [孙玫，2011年，第16期](https://www.zhangqiaokeyan.com/academic-journal-cn_urban-construction-theory-research-electronic-edition_thesis/0201237354529.html)

2015年2月6日，Livelikerw从两街交口拍下前楼，三组方窗、浅陷窗裙、顺弧转折的通长檐和成对托臂可辨。2022年10月31日图文刊载的直翼近照可读到89号门牌，也能辨认浅灰窗裙、窗间石梃与上亮；该照片拍摄日期未载。模型在街角止于圆弧和直墙的接合处。[2015年街角照片，Livelikerw，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Former_Zhong-Xing_Bank_Building.JPG) · [2022年刊载的街面近照](https://www.sohu.com/a/601433736_121123673)

原城位于14-13720-6694，具名建筑2362与福州路89号的OSM轮廓重叠97.972%。五个转角点拟合出的曲率半径约9.73米，覆盖弧长13.05米，节点最大径向误差约7厘米。层高和窗间距由街照估算，粗模的19.2米不作为正式测绘高度。立面细纹为自行生成的矿物颗粒纹理，窗玻璃、金属窗框、勒脚和浅色腰檐分别赋材。[建筑轮廓与门牌](https://www.openstreetmap.org/way/380340012) · [图源与分期](reference-review.json) · [圆弧拟合](source/frontage-registration.json)
