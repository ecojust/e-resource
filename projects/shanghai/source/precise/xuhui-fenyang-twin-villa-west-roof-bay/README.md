# 汾阳路152–154号并立花园住宅西端折坡瓦檐与阁窗

上海市第四批优秀历史建筑4D010将汾阳路152–154号、156–158号列为两组并立花园住宅。2020年2月2日的同帧照片能辨出两幢相距约46.3米、朝向一致的住宅。汾阳路154号毕勋花园的公开地点落在南栋足印内，另一个同门牌地点也位于南栋。南栋西端凸出的墙面朝南，原城和具名足印所测宽度分别为8.16与8.27米。[市房屋管理局第四批名单](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [154号艺术空间展览](http://jianzhujia.net/app/33-view-12124.shtml) · [南栋足印](https://www.openstreetmap.org/way/1199512408)

原照中，西端红瓦屋面从高处向四角落下。顶坡前缘到阁窗上口终止，窗下有一层向外挑的浅瓦檐，窗左右仍保留斜向瓦面。下方浅灰墙上的两组窗以宽墙垛分隔。修缮项目的两张近照可辨成对木牛腿、深色檐底、拉毛墙和红砖之间的浅色腰线。模型的近景与远景分别保留两处坡度变化、内退横窗、突出窗台与两组支托，瓦面由错缝的几何瓦片组成。拍摄者为Legolas1024，2020年照片以CC BY-SA 3.0发布。模型采用原创几何与材质。[2020年署名照片](https://commons.wikimedia.org/wiki/File:%E5%B9%B6%E7%AB%8B%E8%8A%B1%E5%9B%AD%E4%BD%8F%E5%AE%85%C2%B7%E4%B8%8A%E6%B5%B7.jpg) · [照片许可](https://creativecommons.org/licenses/by-sa/3.0) · [152–154号修缮工程](http://www.shwfjz.com/showcase/14)

照片与足印约束了开间、檐口与横窗的相对位置。修缮资料将高度写为约9.3米，未指明测量端点；原城20.9米来自两个低分辨率网格采样。模型估计了绝对檐高、屋脊高和背部截取深度。修缮网页及2021年的建筑记述对建造年份记载不同，现阶段可确证的建筑描述与两组门牌已分别记录。[2021年建筑记述](https://m.thepaper.cn/baijiahao_13932102)
