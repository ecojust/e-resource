# 西摩路会堂院内柱廊与侧窗

上海市房屋管理局第二批名录2B014登记“西摩路会堂”，公布时使用单位为市教育局，门牌为陕西北路500号。世界古迹基金会2009年的现场铭牌照片可辨“西摩路会堂旧址，建于1920年”及英文名称Ohel Rachel Synagogue。南京西路722号的原上海犹太人总会南楼是另一栋已登记模型。[市房管局第二批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [世界古迹基金会项目与照片](https://www.wmf.org/projects/ohel-rachel-synagogue) · [地址、两栋距离与图源校验](reference-review.json)

会堂位于陕西北路一侧的校园内。世界古迹基金会实景航拍可见长向红瓦屋脊、入口前的平顶带，以及凹廊前方绕院的邻楼。与2022、2024、2026三期天顶影像比对，柱廊朝东，陕西北路在西。具名建筑OSM 206515891第5版与城市原件1701足迹交并比97.62%。中、英文百科收录的经纬度位于东南约472米，放置采用具名建筑和实际屋顶。[具名建筑](https://www.openstreetmap.org/way/206515891/history) · [足迹和邻栋](footprint-review.json) · [照片、航片与点位](reference-review.json)

2013、2015和2026年的院内实拍均可辨两根爱奥尼柱、退入的门面、带凿缝的两翼、上下对齐的圆窗与矩形窗、入口上方石刻及檐口。早期斜照和基金会的内部窗框照片可以互查侧窗上部的圆拱及铁条。照片给出构件比例，未量测的柱距、卷涡、瓦坡和门扇深度均作估算。后墙采用简面，未重建室内、院门、旧犹太学校和邻近办公楼。[早期入口斜照](https://commons.wikimedia.org/wiki/File:Ohel_Rachel_Synagogue_old.jpg) · [2015年正面](https://commons.wikimedia.org/wiki/File:Ohel_Rachel_Synagogue,_Shanghai.jpg) · [2026年正面](https://commons.wikimedia.org/wiki/File:20260209_Ohel_Rachel_Synagogue.jpg) · [查看和下载模型](../../../ohel-rachel-synagogue.html)
