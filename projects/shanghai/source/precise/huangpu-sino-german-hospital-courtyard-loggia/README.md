# 中德医院旧址庭院中央门廊与露台

市房管局第四批优秀历史建筑名录把延安中路393号列为4C001中德医院，登记时的现用单位是妇婴保健院。具名OSM旧址同录393号和4C001，标注建于1923年。将这个轮廓与城市底图14-13719-6694的第369号楼体相叠，两者的交并比为98.75%。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [OSM原始足印](https://www.openstreetmap.org/way/494956478)

庭院入口从南面的巨鹿路接近。Fayhoo在2017年11月26日从院内拍到中央铁花门、石柱、挑台和露台。两层后墙各见中央双扇玻璃门和两旁较窄的玻璃开口。门口的石栏使用有腰线的短柱，楼上的铁栏和花槽轮廓较轻。正面照还能看见栏后悬垂的浅色灯。2021年1月的两处街景实站提供正面与偏西的独立对照。2018、2024和2026年屋顶影像用于辨认院向、两侧突出翼和屋窗。[Fayhoo，2017年庭院正照，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Zhongde_Hospital.jpg) · [两处实站、原瓦片与标定点](reference-review.json)

模型截取中轴一个开间。门柱中心距约5.2米，模型两道楼板相差4.34米。铁门前后位置、门廊进深和石材剖面仍属按照片估算。左门柱的灯球、门扇曲线、腰栏、露台和分开的门窗保留为独立可编辑几何。近档另包含梁上可辨的拉丁文、花叶、栏杆铁花与窗棂。[模型源程序](source/loggia.py)

其余南翼、整屋屋顶、北侧街道阳台、树木和室内空间留待另外调查。2017年院门上的招牌只能证明拍摄时的外观。模型采用程序化材质，原照和街景版权分别归其来源。
