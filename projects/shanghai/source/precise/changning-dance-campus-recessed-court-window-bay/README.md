# 虹桥路舞蹈院团花园住宅群院内错台窗间与灰石基

长宁区规划资源局于2012年8月16日发布虹桥路1674、1650号花园住宅的院落照片。文中分别说明舞蹈学校与芭蕾舞团、歌舞团所用地址。画面中央的低楼有一处凹进院面的窗间，窗下灰色石块仍可逐皮辨认。市名录将相关住宅分列为六项，本图没有单独的楼号题注。
