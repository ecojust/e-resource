# 愚园路1112弄20号巷面与室内石阶

愚园路1112弄4号与20号均于1928年建成，同列上海市第三批优秀历史建筑3M009。2015年11月16日，中国の風景在同一次踏访中分别拍到两栋的门牌和建筑。20号近照可以读出白色数字20与下方路弄名。相邻两张照片记录了卷额巷面和室内石阶，第四张记录了区政府所立的保护铭牌。[现场图记](https://4travel.jp/travelogue/11082493) · [区规划资源局资料](https://www.shcn.gov.cn/col7698/20211207/1152658.html)

巷面摄影利用窗框、横腰线和竖边定向，以可见门洞高度约2.12米作为尺度条件，允许1.98至2.26米。楼梯摄影独立利用十四级踏步与右端栏杆反算。两幅照片之间没有可以精确联测的空间控制点，模型中的室内位置用于分别查看两个场景。门牌另存独立GLB，四枚固定件的位置来自近照。

从项目源码运行 `python source/build_model.py --output full-source.glb` 可重建近景网，增加 `--lod` 输出远景。`measurements/fit_views.py` 保存两幅原图的坐标约束。`measurements/render_views.py` 按两台摄影机生成同视角图。`source/number_plate.py` 从独立矢量轮廓重建门牌。
