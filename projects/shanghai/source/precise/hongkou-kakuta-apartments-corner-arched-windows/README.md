# 角田公寓转角两组双联拱窗

上海市房管部门第四批名录将此处列为4F008，原名角田公寓，现名闵行大楼。登记地址连跨闵行路171–181号、201–211号和峨眉路70–80号。虹口区政府的街名资料也记载了闵行路181号的公寓及战前旅馆用途。[第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [虹口区地方资料](https://www.shhk.gov.cn/zjhk/001007/001007002/20220916/d5dda7dc-c3c6-44ff-86ef-ee3184a20061.html)

临街西楼的圆头窗排列在原五层。站在两街转角看，浅色折柱两侧各有一对窗洞。每扇上端的弧形气窗下面有一根通长横框，下面是两片较高的窗玻璃。每对窗上方的罩板在中间分开，突出墙面的窗台沿下框收边。高参88的早期街景和2024年两位摄影者的照片均可辨出这两组窗。[早期街角实照](https://blog.sina.com.cn/s/blog_5d1bdf480102vxba.html) · [2024年4月街景与保护牌](https://www.meipian.cn/52r3cov8) · [2024年11月街景](https://www.meipian.cn/588hi09i)

模型截取原五层的两段窗墙。窗洞、拱边、玻璃、转角线脚和窗罩前后分层，窗户比例依2024年4月街角照片，净宽暂取0.888米。两段街墙的折角按西楼矢量外墙估算。空调外机、晾衣架和1977年增建的上面两层不在本次范围。[街角近照](https://ss-mpvolc.meipian.me/users/122623251/77993ae462fff8cb65fae5f6a96727ec__jpg.heic)
