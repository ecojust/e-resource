# 岳阳路320号在君楼

上海市第二批优秀历史建筑名录的2D030条列“中央研究院”，地址岳阳路320号。徐汇区旅游咨询中心的建筑条目称这座双院主楼为在君楼，记载建于1930年。上海市地方志记原上海自然科学研究所于1931年4月在祁齐路320号成立，中央研究院为抗战胜利后的使用单位。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [徐汇区建筑条目](https://web.archive.org/web/20080827235830/http://xh.qjtrip.com/oldhouses/house/yyl320/yyl320.asp) · [上海市地方志](https://web.archive.org/web/20160427193456/http://www.shtong.gov.cn/newsite/node2/node2245/node4454/node60357/node60391/node60397/userobject1ai54937.html)

区旅游咨询中心的斜俯照片把入口券廊、三道中央高窗、左右翼与两个内院纳入同一画面。Livelikerw于2014年1月拍摄的街照可独立辨认中央七券和高窗。瓦块14-13719-6696中的714号建筑含两个内院，现行OSM关系与冻结轮廓在扣除院落后交并比为98.91%。东侧715号窄轮廓与主楼相隔约4.66米。旋正三期航片后可辨二者之间的低廊屋面，2024年图层还能辨认前缘的柱列阴影。结合区档案的斜俯照片，715可定位为同一七券门廊和台阶。来源记录包括两个照片文件的哈希和建筑轮廓的计算结果。[斜俯照片](https://web.archive.org/web/20140504091054im_/http://xh.qjtrip.com/oldhouses/house/yyl320/1.jpg) · [2014年街照](https://commons.wikimedia.org/wiki/File:320_Yueyang_Rd._Shanghai.JPG) · [楼栋核对记录](identity-review.json) · [建筑轮廓、图层与判断修订](footprint-review.json)

东墙宽约95米。两翼各八个主要开间，中段三组双窗上有砖砌盲圆券，六根方柱和两端的支承围成七券低廊。前廊独立设有台阶、开放柱间与顶板。屋面围绕两个露天内院，西外墙和缺少照片的院壁保留素面。窗墙和屋顶均为原创几何，照片用于辨认结构和比例。[立面观测记录](elevation-study.json)

从项目目录可以重建原始GLB、网页近景和远景以及可编辑的Blender文件。环境需要 Python、NumPy、Shapely 2.1 或以上、mapbox-earcut、Node、gltfpack、Blender、ImageMagick 7 和 Open Image Denoise。

```sh
python source/precise/xuhui-yueyang-320-research-building/source/build_model.py \
  --out assets/models/candidates/xuhui-yueyang-320-research-building \
  --audit data/audit/yueyang-research-building-v1
```
