# 中央造币厂主楼中央门廊

上海市房屋管理局第二批表的2N001写“中国造币厂、上海造币厂、光复西路17号”，工作名录采用“中央造币厂”。中央造币厂公布的沿革记载，1920年在上海筹设、1928年改名、1933年正式开铸。石柱、题字和屋顶各次改动的年份仍待考。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) [中央造幣廠沿革](https://www.cmc.gov.tw/intro/history)

东方网转载的早期全景可辨居中山花、柱廊与水平展开的原主楼，摄影者及确切日期未详。Fayhoo于2016年1月9日拍摄的2144×1424照片能分清两根外柱、中间两组并柱、台阶和短窗墙。模型采用这次拍摄所见的石饰、题字和窗棂。后方高楼、庭院陈设、全长两翼及室内另留待考。[早期全景](https://commons.wikimedia.org/wiki/File:中央造币厂旧址.jpg) [2016年照片，Fayhoo，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Shanghai_Central_Mint.JPG)

模型以博物馆点所在的历史主楼长边和正面照估计约25.4米宽的展示范围。正前方山花门廊与全楼正立面比例参考早期全景。绝对尺寸、进深、石色均为估计。源码按组件分组，铭文采用注明来源的字体子集。[来源与文件校验值](reference-review.json) [落位依据](footprint-review.json)
