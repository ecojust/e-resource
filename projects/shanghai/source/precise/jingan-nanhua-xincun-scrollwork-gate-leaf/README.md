# 南华新邨长乐路774弄入口尖矛花铁门

5B060在市表登记为南华新邨，门牌长乐路774弄。Livelikerw于2016年2月6日从长乐路街侧拍到774弄入口。取靠右侧「南華新邨」题名门墩的黑色铁门上段，重现两格门框、弯顶与透空花铁。

顶横档与下方一条细档构成弯曲上带；矛尖沿上缘排列，带内有小菱形铁花。 中下两格有较大的卷草与菱形；门扇后地面和建筑可从两格的纵栏空隙看见。

照片里铁门斜向街沿、门底又被车遮住，门扇展开后的宽度与弧高为比例估计。卷纹按可辨的重复形制简化。下沿是本项的裁切线。
