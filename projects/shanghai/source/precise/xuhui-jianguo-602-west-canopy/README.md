# 建国西路602号花园住宅西门与攒尖雨厦

市房管局第四批优秀历史建筑名录将602号列为4D035花园住宅，公布时由上海医学科学技术情报研究所使用。东侧598号另列4D034，西侧618号住宅属于第二批名录。[市级原表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [相邻条目与原表校验](measurements/listing.json)

西入口位于退台下方。薄钢板雨厦从宽而平的檐口收至高尖，沿半圆边缘垂下一圈密齿。近照可量出雨厦宽约为门洞的1.62倍，门额凹线沿两侧连续落下。两级弧形石阶通向敞开的门，靠门的一侧留有放射状刻纹。[尺寸与照片选点](measurements/canopy-profile-and-eave.json) · [2013年近照](https://blog.sina.com.cn/s/blog_5d1bdf480101f68i.html) · [入口及踏步照片](https://m.thepaper.cn/newsDetail_forward_14543838)

尺寸来自摄影比例。未能直接观察的屋背、花园布局和内室陈设另待核对。[模型参数](measurements/building-dimensions.json) · [来源、日期与权利](reference-review.json)

研究所地图点靠近院内一幢平顶办公楼。比对两套航空影像后，保留该办公楼的原模型。历史住宅的入口以实照为据。[同址办公楼屋顶辨认](measurements/institute-office-excluded.json)

2013年照片中的旧版保护牌记载住宅建于1930年。2024年11月设立的新版保护牌将其记为原克罗坎宅，建于1924年，由赉安工程师设计。[两版保护牌记录](reference-review.json) · [新版保护牌及院门照片](https://www.meipian.cn/5ectjifo)

两套航空影像均在绿双门车库东侧辨认出花园住宅的复合红瓦屋顶。原城市底图2402只覆盖所见屋顶约38%，西入口墙面受遮挡。模型保留同院办公楼和庭院的原城市几何。[街门交会与屋顶比对](measurements/compared-courtyard-and-roofs.json)
