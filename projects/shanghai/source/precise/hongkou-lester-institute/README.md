# 东长治路505号雷氏德工学院旧址

上海市第二批优秀历史建筑2F004登记原名「雷氏德工学院」，当时使用名「海员医院」。修缮设计方与现使用方写作「雷士德工学院」。保护类别为三类。市表另有2B024「雷氏德医学院」，在北京西路1320号，属另一处建筑。[市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) [区政府](https://www.shhk.gov.cn/xwzx/002008/002008040/20230731/bc7b6847-8f1f-4efe-9e7a-c77c614ab4da.html)

亨利·雷士德（1840–1926）遗赠支持上海的教育与医疗事业。雷士德基金会出资兴建这所工科院校，1934年2月16日动工，次日奠基，10月1日开学。首任校长为李赉博（Bertram Lillie）。项目早期工作表所记1927年与奠基记录不符。校址后来由上海航务学院和上海海员医院使用。2021年5月启动修缮设计，2022年12月竣工并由上海创新创意设计研究院入驻。上海北外滩（集团）有限公司为本次修缮建设单位，华东建筑设计研究院有限公司负责修缮设计。上述文件交代了历史出资和现代使用关系，现行权属登记仍缺依据。[华东院修缮回顾及项目表](https://diis.org.cn/Cn/Data/View/492) [现使用机构校史](https://diis.org.cn/cn/data/list/xygs)

## 足印与朝向

具名冻结楼栋在14-13721-6693，编号1131，源头w1317964106@2，面积3126.80平方米。直接读取OSM当前原始多边形，面积3124.57平方米，与冻结轮廓交并比99.19%，最大边界偏差0.30米。历史地标与现用机构两个独立名称的地图定位都落在这块多边形。现状正射另能辨认北向伸出的锯齿形采光带、穹顶和夹角折翼。OSM和冻结多边形具有共同来源，建筑身份另以修缮照片、1934平面及定位点核实。[当前具名OSM多边形](https://www.openstreetmap.org/way/1317964106) [修缮图文](https://diis.org.cn/Cn/Data/View/492)

按正北为0°，中央园侧短边的朝外法向为193.74°。由北部伸出处两条长边反推园侧方向，为198.06°及198.44°。东西向总包围尺寸约96.89米，南北约70.88米。中央门廊具体坐标仍须按穹顶、翼端和图纸联合校准。两侧建筑折向草坪，并非一条平直的全幅街墙。场地位于商丘路与东长治路转角，现状南园、路缘和环形步道应可通行。

具名轮廓未与北侧749重叠，最小间距0.67米。西侧小块1577仅余0.26米。25.114米高的匿名粗源块115距主楼边界3.28米，投影落在南园一带，2022年修缮照片展示了该处的公共草坪。文献明确记载修缮阶段退让被占绿地。115的实物身份与年代仍未明确，建主楼时独立保留这条底图记录；参与碰撞的范围限本栋实体墙体和实际地面轮廓。现有证据不支持依整院地块挖洞，也不足以将匿名的115命名为某栋院楼。[冻结足印、道路和邻栋距离](footprint-source-review.json)

## 可据实制作的外部构件

- 1934前立面图、落成历史正面照、2022正面合看，中央门廊为七孔尖拱。宽翼各五开间，普通三层，每间以三樘钢窗成组，强竖向墩分隔。中央楼身更高，局部翼部退台。可分别制作门廊内回折、窗台、石窗间墩、女儿墙、盾饰和立面层级，保留真实开口。
- 圆穹下方的中央塔正面有竖窗和尖券，顶部有密列高肋，与两侧平屋顶及次要尖顶相接。1934图纸和30年代照片可定轮廓，修缮资料还辨明塔内的锅炉烟囱。尖拱科学仪器盾饰包含圆规、天文仪器、机械图案。铜饰双扇入口取法历史博物馆收藏原件，2022年已复制安装。图案可从原图抽取形状，避免用一组徽章填满所有盾位。
- 现状主面为花岗石、泰山毛面砖与斩假石，修缮钢窗采用深绿色面漆。历史黑白照片仅作几何判断。新旧修补颜色和损伤程度可用修缮后细部校准。
- 顶部原绘图室锯齿天窗向东北取光，后方采光带在正射及正侧图可辨。1934项目叙述记主体三层，四层职工寓所，塔内局部五层。2022项目表另列19.220米、地上主体三层、局部六层。该表没有给每层标高及中央穹顶顶点独立高度。地图源29.6米为粗略楼高，不能据此标定全部屋面。
- 外景中可观察园侧门廊与双翼外立面、模型后部屋面转折。主入口后各室、地下烟道及北面局部都会涉及估算，此阶段不据其立面编造可进入空间。修缮图志对入口、圆穹和门廊的资料不代表所有背面细部均有测绘。
