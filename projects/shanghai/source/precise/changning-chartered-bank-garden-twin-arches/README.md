# 麦加利银行襄理住宅花园侧双石券与中柱

江苏路796号是英国麦加利银行上海分行襄理的旧住宅。长宁区规资局记载花园约9000平方米，住宅约927平方米，1976年改为房地局职工医院。花园一侧的双石券顶着一道抹灰栏板。蓝色“1”号出现在规资局刊载的照片中，模型保留了这枚后来使用的楼号。[长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211207/1151489.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

两个券洞共用中柱。放射状石块沿弧面转入券底，起拱处有一道向前挑出的石带。黄力炯的斜角写生也画出了双券、上方栏板及左右凸出的窗体。此模型聚焦双券、承托石柱与上沿栏板，左右窗体留在参考图中。[黄力炯，《科学生活》2018年第7期](https://www.fx361.com/page/2018/0806/12063689.shtml)

模型以单券净跨约2.4米作比例估算；中柱截在原照所见的柱身中段。住宅门牌点落在市图1077号轮廓内，OpenStreetMap的相应足印与之交并比为0.978889。花园侧双券端点缺少原址测量，在独立页可正看放射缝，也可斜看券石进深。1980年代旧照记录的是同宅临街一侧。[上海长宁刊载的旧照](https://www.thepaper.cn/newsDetail_forward_32641181)
