# 储康里红砖墙三角窗楣与双菱铁栏

5D062在市表登记为储康里，门牌长乐路401弄。2017年8月19日Antigng拍摄的储康里弄内原照，左侧红砖墙近处的一扇窗有三角形石面窗楣，窗前灰色铁栏的两条横带之间排列同心圆和一对交叠菱形。本作截取窗头、格窗和这一段铁栏。

窗楣内外各有起线，三角形中部较平，梁下可见竖向窗梃和两种明暗不同的玻璃。 窗前细铁柱连续通过横档，中间的两个菱框相互搭接，左右各有同心镂空圆环。

市表5D062记长乐路401弄。照片中另有一块8号牌属于右侧另一栋，本作左窗不附户号。原始门窗用途、翻修年份、墙厚和铁栏前后间距均未见独立测量。
