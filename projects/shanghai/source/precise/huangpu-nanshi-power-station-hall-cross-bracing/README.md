# 南市发电厂主厅右侧上下两层钢交叉撑

花园港路200号主厅的一个墙跨，两层深灰钢斜撑、连接两段的横向工字梁、两侧柱面和灰色分带。两层交点均可辨认；上部左端被梁遮住，模型在照片可见处截止。

原照记录等效焦距24毫米。取两侧柱间约4米作为名义尺度，单照反投影给出两层净高合计约5.22米。开间、型钢厚度和杆件前后错位均待现场测量。
