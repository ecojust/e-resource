# 联市联谊会中华路东立面

上海市第四批优秀历史建筑名录4A036登记“联市联谊会”，地址中华路55号，使用名称为“上海双工缝纫设备开发公司”。同一路口另有4A035仁记珠宝银楼和4A034原中国银行南市办事处，市表对三幢分别登记。市表没有注明本楼竣工年份。具名地图的1924年尚待建造档案核实。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [具名建筑轮廓和版本](https://www.openstreetmap.org/way/495101843/history/1)

2021年1月8日从中华路可见七开间东面。每个上层窗前有一座带交叉石栏的阳台，中央阳台较宽。下层通长露台的实心板与透空栏板交替。中轴三角楣后起一座小塔，两翼独立山墙各有两扇窗，窗间有上端圆收的盲饰带。铺面玻璃和门头以街照记录的状态制作。后进房屋、屋顶纵深及后立面的开窗还需其他角度的照片。[逐站原图地址及输入校验](reference-review.json)

将三处街景站位的110个像点交会，估得东立面宽约26.31米，七个窗轴相邻距离约3.6至3.7米。中央三角楣顶约14.85米，两端山墙顶约18.57米，塔正面上檐约19.29米。像点与拟合视线的距离中位数为0.11米，九成小于0.31米。横向用具名建筑的两个街角配准，公共摄影设备给出的绝对位置含约两米误差。石饰、窗深和短回墙的尺寸均为影像估计。[像点与拟合](source/frontage-solution.json) · [落位参数](source/frontage-registration.json)
