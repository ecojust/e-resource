# 绍兴路3号住宅曲面红瓦屋顶与双扇格窗

上海市房管局的5A053住宅条目并列绍兴路1号、3号及瑞金二路三个门牌。Antigng在2015年9月9日分别拍摄1号和3号。3号照片中的临街屋顶有两座窗头，取右侧能辨窗格的一座。 [第五批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

窗口两侧的红瓦从上部陡坡落向下缘的雨沟。深色双扇窗各分两列玻璃，外部檐口遮住窗头。 [Antigng 2015-09-09 14:59:11](https://commons.wikimedia.org/wiki/File:%E7%BB%8D%E5%85%B4%E8%B7%AF3%E5%8F%B7.jpg) · [Antigng 2015-09-09 14:58:23](https://commons.wikimedia.org/wiki/File:%E7%BB%8D%E5%85%B4%E8%B7%AF1%E5%8F%B7.jpg)

双扇窗背靠灰色立壁，窗外两带瓦坡向檐沟逐渐放缓，浅色收边紧贴最外瓦列。正面可见玻璃分格，斜面可见瓦片搭接和窗罩出挑。 以窗净宽约1.02米为比例依据。屋面坡折、前后尺寸和被树遮挡的上部檐口按照片估算。房间及屋顶后坡超出图像范围。

名录并列绍兴路1号、3号及瑞金二路三个门牌。Antigng相隔48秒拍下具名的1号和3号。3号的窗头在瓦坡上，1号是平直浅色墙面、百叶窗和转角。绍兴路东段原屋轮廓缺逐户门牌及窗头高程，维持原街坊和9号已核拱窗主楼的边界。
