# 拉摩斯公寓临街双拱窗与回纹窗楣

上海市优秀历史建筑第四批名录将拉摩斯公寓登记在四川北路2079–2099号，现名北川公寓。虹口区政府2014年公布的照片能看见临街券窗及相邻铁栏阳台。已经入城的上海鲁迅故居正立面与院门位于山阴路大陆新村。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [虹口区政府建筑资料](https://www.shhk.gov.cn/zjhk/001003/001003002/20140902/2c57bb46-db71-45bb-8ab4-20c2d779c45d.html)

Fayhoo于2014年5月1日拍摄的立面照片中，一孔大圆券下并列两孔小券，券上有圆形浮饰。其下是成对的长窗、浅矩形饰板和一对较短窗。短窗的下沿以五组方形回纹收边。这次建模以窗带两旁的灰泥墙为界，尺寸按照片中上层窗对的比例估计。[2014年原照与署名](https://commons.wikimedia.org/wiki/File:Beichuan_Gongyu_%28Lamosi_Gongyu%29.JPG) · [后续修缮报道](https://m.thepaper.cn/baijiahao_16853097)
