# 华侨大楼九江路上层拱窗与双石梃

上海市黄浦区九江路120号。九江路短立面靠转角的上层拱窗，两根直石梃将弧形窗洞分作三栏。中栏的横竖细框在石梃后，两侧窗头收成弧形；窗台挑出，墙面凹缝在拱顶处向上放射。

窗洞节选估宽约2.04米，两道石梃约宽0.13米。中栏玻璃分格、拱形侧光与放射缝参照2013、2018和2019年的照片；建筑经改建，本作记录照片可相互印证的外观，窗框材料及绝对尺寸待实测。
