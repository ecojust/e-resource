# 愚园路684号朱学仁住宅

南园廊和东入口采用局部米制坐标重建。南侧能穿过底层园廊望见另一端，前方五道弧形台阶通向中间一跨。上廊的宝瓶栏杆、方柱和挑檐按照片分段制作。东入口保留两根赭红柱、平雨篷、五级石阶及门北侧的弧形外墙。中央南券与后门按不同的前后平面登记，西、北背面和树荫下的屋盖转折保留简化。[打开单体模型](../../../zhu-xueren-residence-yuyuan-garden-veranda.html) · [来源、范围与授权](SOURCES-LICENSE.md)
