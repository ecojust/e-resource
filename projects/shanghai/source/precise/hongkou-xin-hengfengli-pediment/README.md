# 新恒丰里山阴路85弄门楼题额与盾饰山花

上海市第四批优秀历史建筑名录将恒丰里与新恒丰里合列，地址为山阴路69弄和85弄。2015年4月12日，Fayhoo拍下85弄入口，照片可见右读“恒豐里”的横额和带盾饰的三角山花。2014年12月Livelikerw拍摄的69弄照片记录了另一入口通往的街巷。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [85弄照片](https://commons.wikimedia.org/wiki/File:Xin_Hengfengli.JPG) · [69弄照片](https://commons.wikimedia.org/wiki/File:Hengfengli_Shanghai.JPG)

模型取85弄门楼上部。盾饰两侧的卷叶、斜檐和题字做成有厚度的几何构件。整体尺度与装饰厚度参照照片比例估算。2021年修缮报道记载了水刷石牌楼清洗，本次外观取自修缮前的照片。[虹口修缮报道](https://www.thepaper.cn/newsDetail_forward_12602899) · [照片标定](reference-review.json)
