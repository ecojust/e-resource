# 美伦大楼东楼椭圆花环与层叠窗裙

Antigng于2018年2月22日拍摄的原照题为“美伦大楼东楼”，图注同时说明原中央商场西楼。窗间壁柱有中央凸椭圆、边框上的卷涡及下部叶饰，两侧窗裙有不同数量的竖槽。 [市房管局第五批名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Antigng原照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E7%BE%8E%E4%BC%A6%E5%A4%A7%E6%A5%BC%E4%B8%9C%E6%A5%BC.jpg)

正视能区分宽窗和窄窗、石饰中央凸起的椭圆与两侧不同密度的竖槽。斜看可分辨卵形石心、围边、卷叶和三重窗裙框之间的进深。近远两档都保存每边的细槽和窗格。 以右窗净宽约1.70米为比例。花叶数量、背面和窗内侧按影像估计；本件是朝街窗间墙局部。

市第五批表把151号美伦东楼与161号西楼、南楼分列；相同区域另有四川中路355号中央商场登记。161号旧屋1562和市图完整街坊均保留。门牌查询中汉口路151号来自另一条道路，南京路步行街151–171号是一个地址范围，不能单凭该点裁掉原楼。
