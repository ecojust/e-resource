# 方建公寓 D、E 楼与庭院敞廊

方建公寓在第四批上海市优秀历史建筑名录中登记为「方建公寓／建成公寓」，现名建安公寓。建国西路641–645号属于五层北楼 D，高安路78弄1–3号属于四层南楼 E。两楼各有三个住宅单元，由一条平屋顶敞廊相连。赉安洋行于1931–1932年设计，1933年7月竣工。2020年徐汇区房管局实施保护性修缮。名录中的本项对应 D、E 两栋，高安路70号的 A、B、C 楼另有门牌。[市级名录](measurements/register.json) · [徐汇区房管局与城建档案馆图纸](https://www.xuhui.gov.cn/zfjg_qzfbm_fgj_bmdt/20250401/554629.html)

北楼临街中央的八字形阳台叠置四层，浅色圆柱承托挑板。每层栏杆下方有两道凸出的水平边带。两侧窄长楼梯窗上方的竖向墙肋超出屋檐。标准层平面和2025年北立面照片用于确定梯间、两端翼部和中央凸出的相对位置。2020年2月的三处街景用于估计阳台前缘宽约5.96米。东西视角给出的檐高有差异，模型层高取近似值。顶层院侧内退的位置结合档案、现状屋顶和庭院照片绘制。[北楼调查](measurements/d-north-plan.json) · [三站测量与误差](measurements/d-balcony-street-survey.json)

南楼院侧的三个楼梯间各有两列细长钢窗，窗间实墙、竖肋和屋面以上的收头分别成形。两端顶层露台保留较低的轮廓。敞廊从北楼院门接到南楼中间入口，园侧可以穿行。两列赭红色圆柱支承浅色屋盖，廊侧有石板地、低缘植床和一张带弧形木座的圆桌。院落家具位置、植栽边缘和零星被遮住的窗格依据可见照片估计。[南楼量读](measurements/south-block.json) · [庭院来源与位置](measurements/garden-court.json)

面墙使用原创可平铺的粟褐与暖黄色条带，深色窗带约占一层的44.5%。南、北楼按各自的窗台和层高设定纹理起点。阳台、栏杆、钢窗、柱头、顶层女儿墙和廊柱均为独立网格。2020年修缮前的街景保留在测量来源中，当前配色参照修缮后实照。[颜色与层位](measurements/wall-courses-and-colour.json) · [各张照片和档案的校验值](measurements/municipal-references.json)

两栋旧底模分别为建筑2247与533。两处足迹与同栋 OpenStreetMap 建筑的交并比分别为97.73%和96.63%。两栋之间原有近23米的开敞空间。街景和航片的投影存在偏移，檐口、阳台和原墙线之间的差值保留在调查中。两座公寓以各自的原建筑归属核对。[本地坐标与尺寸](measurements/site-frame.json) · [城市原图对照](measurements/city-comparison.json)

从源码目录调用下列命令可生成带分组的原始 GLB。Python 依赖及共用网格工具沿用上海项目。省略 `--lod` 生成近景几何。

```bash
python source/build_model.py --output foncim-lod.glb --lod
```

使用项目的 Meshopt 与 Blender 工具时，`python source/build_model.py --out build --audit audit` 会一并构建网页和可编辑资产。源图中的私人住房以外观取形，档案中的完整户内布局及室内陈设未纳入本次实物。
