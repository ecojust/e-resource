# 香港路85号卷首石托窗楣与外开钢窗

5A075在市表登记为美国陆海军青年会，门牌香港路85号。香港路85号红砖平立面下排三处相似高窗中，取中间一窗。Antigng在2017年8月31日拍下了左右两个卷头石托、上方出挑的线脚，以及下格向外打开的深色钢窗。

高窗上段的居中横、竖钢条透过薄反光可辨。下扇向街面外开，其最外竖边超出石边框以内的窗玻璃平面。 窄长的灰石门字边框包着向内斜收的窗揭口。两侧卷头托、内退小凹带和最上两重方口宽檐共同组成窗楣。

记录来源按门牌区分。2015年规划局名录为AlgarBuilding，市房管局第五批5A075在同号登记“美国陆海军青年会／海青大楼”。1927年建筑师学会会刊记Algar Building在Hong Kong Road，1936年广告写当时60号。旧60与今85的换号没有在现有资料中得到核实。四川中路630号的另幅实照和本窗分开登记，现无两正面结构相连的测绘依据。
