# 求新船厂厂部办公楼南立面铸铁外廊

原机厂路132号的这座二层砖楼建于1923年，曾作求新船厂法国大班办公楼。上海市第三批优秀历史建筑第3A023项同时登记了这座厂部办公楼和另一幢红楼。2021年黄浦区政府答复市政协提案时再次分别列出了两幢建筑。模型选取办公楼南面的两层铸铁外廊。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [黄浦区政府答复](https://www.shhuangpu.gov.cn/uploadfile/52192d6c-ad0c-4823-bbff-bca65a77bd64/%E9%BB%84%E5%BA%9C%E7%9D%A3%E5%A4%8D%E3%80%902021%E3%80%9110.pdf)

修复前，南廊局部封砌，首层铁花还有一部分从砖墙和临时门窗之间露出。修复后的照片显示，上下两层的铁柱、带叶饰的柱头和通透的挂落沿长立面重复，楼上栏杆带卷草纹。窗框和檐板为深红色，二层廊地板呈暖褐色。常青研究室曾研究初建时采用四坡屋面的可能性，实施方案保存了修复时已有的双坡顶。[修复团队项目记录及前后照片](http://cq-studio.com.cn/project_view.php?cate=1&project=94)

Fayhoo在2015年2月14日拍下了南立面和屋顶两座烟囱。施工材料遮住了首层的一部分。2017年9月的场内公开街景从三个位置拍到了办公楼、相邻厂房和围墙。二层内廊的近照还可以核对栏杆、柱脚及廊宽的相对比例。参考图像的作者、许可、文件摘要和拍摄序号见本目录的来源表。[2015年南立面照片，Fayhoo，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Zhongfa_Qiuxin_Jiqilunchuan_Zhizaochang1.JPG) · [来源与照片登记](reference-review.json)

## 尺寸与落位

南侧边线长20.99米，取自原城地块1300。2017年最近的摄影点距所量檐口的水平投影约11.5至19.7米。以摄影眼高2.35米估算，八个檐口点给出8.58至8.86米，另外两个摄影点得到约9.0米和9.9米。眼高、全景定位和地面高差都会影响结果，本模型取南檐8.85米。柱径、门窗、烟囱及廊深同样是影像估值。[边界、三个机位和逐点测量](footprint-review.json)

南面按实照表达成对铁柱、花叶挂落、红色檐板、楼上栏杆、木地板、背后的砖墙及红框高窗。铸花采用重新绘制的重复单元。东侧只处理靠近南廊的可辨窗段，后部保留简化外壳。楼内格局、被树遮住的细部、另一幢红楼和厂区其他建筑仍待分别核对。三维网格和材质均为本项目原创，模型中不含参考照片像素。
