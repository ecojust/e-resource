# 私立妇孺医院旧院临街楼梯间与阶梯钢窗

长宁区人民政府记载，原大西路212号妇孺医院由庄俊于1934年设计，长江营造厂施工，1935年竣工。长宁区规划和自然资源局的保护建筑条目给出现址延安西路934号、占地3128平方米、建筑面积5600平方米。区政府照片中，红砖主楼临街一面镶有“上海市长宁区妇幼保健院”竖字。[区规划资源局](https://www.shcn.gov.cn/col7698/20250526/1290741.html) · [区政府历史介绍](https://www.shcn.gov.cn/japan/col1756/20130502/523000.html)

本次首稿量取楼梯间四组随踏步升高的三联钢窗、底层圆窗、混凝土遮檐与屋顶腰线。输入为区政府原照的像素坐标。上组两窗头躲在檐下，勒脚上方的最低一组只露出小部分。首稿层间高度为条件尺度，尚待道路摄影复核。模型仅含照片可辨的临街楼梯间范围。官方照片仅用于量读。

运行 `python source/build_model.py --output output/full-source.glb` 生成近景，附加 `--lod` 生成远景。
