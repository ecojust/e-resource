# 新场中华楼临水檐口的弧形筒瓦与尖头滴水

5W023在市表登记为中华楼，门牌新场镇新场大街141-145号(单号)。Fayhoo在2015年4月18日摄下新场中华楼邻桥的长立面。临水一侧的檐口交替露出拱形筒瓦端与向下收尖的滴水，下面可见连续深色横木和间隔排列的小木端。

拱形瓦端高低相继，盖瓦下方为暗部。每两道盖瓦之间，滴水上沿凹成弧形，外缘进一步向下收成尖。 滴水背后露出木构端头，往下为连贯的深色横木，再往下才到窗格。

市表登记141至145号单号，原照题注145号。摘取照片清楚的一段檐边，九道盖瓦和八片滴水表示其重复构造。瓦道间距、坡面进深、色差和隐蔽搭接按照片估计。
