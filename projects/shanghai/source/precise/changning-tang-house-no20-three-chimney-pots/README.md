# 唐氏花园住宅20号山墙三孔砖烟囱

5M005在市表登记为住宅，门牌愚园路838弄20、22、30、32号。Antigng于2018年拍摄的愚园路838弄20号住宅，上层黄褐砖山墙的屋脊处立着矩形烟囱。三只短圆烟管排在同一道叠线浅色压顶上，烟囱两侧山墙的斜向压顶相接于不同高度。

放大原照片的烟囱顶缘，可见三只浅灰圆管，各自外缘略微突出。深浅线交叠的顶帽下还有一圈更宽的素面浅色带。 左侧陡坡边线到烟囱前略降一级，右侧另有一条较低的浅色斜檐在烟囱侧面交接。烟囱砖面同时可见宽边和窄边。

市表5M005还列同弄22、30、32号，此照题注只指20号。墙厚、烟道内径和作为尺寸参照的高度均从单幅斜照估计，照片在屋顶下方拍摄，未显示管内构造。
