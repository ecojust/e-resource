# 培明中学双列深色窗与浅色窗间板

5B040在市表登记为培明女子中学暨小学，门牌新闸路1607-1609号。依Antigng于2018年1月28日拍摄的校舍，取朝向镜头的两列窗带，包含上下两层双扇深色窗、浅色矩形窗间板、灰墙水平分缝和檐口。

两列浅色竖带各贯穿上下两扇窗，中部有单块略内收的矩形饰板。窗中央均有一道较粗的深色竖梃；上窗反射白天亮色，下窗较暗。 灰色墙身的水平分缝沿左端转角延续，檐底为密集横向细槽，深色檐缘连续越过两窗。

门前设施遮挡底层。照片只确定这处现貌，窗框材质依表面色泽估计，外墙深度与绝对尺寸未有测绘依据。
