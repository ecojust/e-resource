# 法公董局旧址 · 淮海中路保留立面

上海市房屋管理局第二批名录2C001载「法公董局、综合办公楼、淮海中路381号」。另一份项目工作名录C-Ⅲ-001列375号、公布用名中环广场。Fayhoo在2014年发布的正门实照可读「中环广场」，具名地图建筑及现状POI也指向381号。同街另一带375号的无名建筑部件留在原处。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [资料与照片签名](reference-review.json)

沿用至今的街面来自1909年法国公学一带的建筑，此后改作福煦兵营，1936年法租界公董局迁入。1999年建设中环广场时，大部分原建筑拆除，临街部分留作裙房，通过中庭连接新楼。老虎窗、檐口、门楼、木结构屋顶有保留及依原样恢复两类。现存资料未逐件注明处理方式。较早公董局的钟顶建筑为另一历史阶段。[2019年报道与街道史料](https://www.sohu.com/a/306691419_186647)

这件模型取石拱正门所在的北面，包含向街前出的中央及两端砖翼、两段凹入的上下层窗、紫红色店铺篷布、老虎窗和正门台阶。2020–2021年三处街景用于判断开间和前后关系，2022、2024、2026三个发布版的航片复核屋面。2026版可见中央浅色矩形屋顶与正门同轴。端翼位置存在约3米不确定度，尺寸、砖色、窗格和局部后切口为外观估计。1999年以前的庭院格局和现状高塔另行保留。[地块、配准与原有建筑](footprint-review.json) · [淮海中路模型](../../../french-municipal-council.html)
