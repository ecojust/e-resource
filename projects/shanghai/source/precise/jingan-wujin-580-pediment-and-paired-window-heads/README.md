# 武进路580号住宅临街小山花窗与双券窗楣

上海市第四批优秀历史建筑名录将住宅登记为“武进路580弄”。区文旅“阅读静安”把一张临街照片收在“虞洽卿寓所”条下，正文明确写作“武进路580号住宅”。模型依据这张照片，取左端小山花方窗和旁边两道砖券。[阅读静安原始条目](https://m.readja.com/nd.jsp?mid=625&id=142) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

正面能分辨小山花内第二道三角线脚、窄窗两侧的砖墩和较低开间的成对券形。斜看石色封檐越出砖面，窗楣下方仍可辨两个平直的木框窗头，简化档保留券形和窗洞。 各部尺寸取自原照相对比例，端部山花面宽约取2.60米。原墙赤色、石质封檐与窗框色来自区级资料中的街面照片，进深、券石分缝和窗后暗处为示意。

市级名录采用“武进路580弄”，静安区文旅资料将附图建筑单列为“武进路580号住宅”。580和588号位置在查询服务中均带“虹口区”前缀，属于服务返回的地址文字，区属仍沿法定名录。实拍图可辨左端砖山花面及其右侧双券，尚无同一时点逐窗控制把这段立面和现存库中的两处建筑完整配准。独展保留源城全部建筑与地面。 [2025年修缮后的唐宅资料](https://sh.people.com.cn/n2/2025/1107/c134768-41405095.html)
