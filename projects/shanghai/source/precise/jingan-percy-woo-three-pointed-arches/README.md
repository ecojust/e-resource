# 吴培初住宅三联尖券窗与双螺旋石柱

取红砖墙身中段的三道尖券、券下浅色窗头和退入的三樘窗。相邻窗之间保留两根螺旋石柱及柱颈、涡卷和方顶板。

以Fayhoo 2019年1月27日的正面照片为据。取单窗券内宽约1.01米为名义尺度，券高约0.76米；柱身起伏和盲券后退深度按照可见阴影估算。

Fayhoo，2019-01-27，《Former Residence of Percy Woo》，Wikimedia Commons，CC BY-SA 3.0。 图注记石门一路315弄6号斜桥弄巨厦。参考三道尖券的轮廓和扭柱的纹向，砖、石、玻璃和窗框以独立参数绘制。画面左侧的树干遮住一部分左券与左柱。 [照片原页](https://commons.wikimedia.org/wiki/File:Former_Residence_of_Percy_Woo.jpg)
