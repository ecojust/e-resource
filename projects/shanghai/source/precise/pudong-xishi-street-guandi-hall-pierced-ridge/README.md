# 西市街关帝庙正厅的镂空菱格正脊与卷端

5W003在市表登记为关帝庙，门牌西市街54、56号。Fayhoo于2015年5月9日从庭院正面对着西市街54号关帝庙正厅拍摄。正脊中央两侧各嵌一段菱格，两头还有较短的透空纹饰，翘起的卷端连接正面坡顶的灰瓦垂脊。

两个狭长镂空区均可见交叉斜梃，中间是较宽的实心脊面；两端较小的开口各有一中央隔梃及不规则雕纹轮廓。 两头的脊瓦回卷向上，正坡瓦垄向下铺开；瓦缝有前后搭接，垂脊顺坡弯出。

市表5W003并列西市街54、56号，原照片标54号。本次取院内正厅中部屋脊；窄小装饰在背光中只显轮廓，图案含义、屋脊背面、侧院和其余殿门均未据此推断。
