# 皇家公寓淮海中路、常熟路转角立面

市房管局第二批优秀历史建筑2D005登记原名「皇家公寓」，现名「淮海大楼、美美百货」，地址淮海中路1300–1326号。根据1947年《上海行号图录》，1326号是公寓正门，东侧1324至1318号的四个铺面由永隆食品店使用。八十年代起的加层和商铺更迭改变过外观，九十年代底层迎来美美百货。修缮后的门头题名仍为「淮海大楼」。[市房管局保护登记](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海党史网图录考证](https://www.ccphistory.org.cn/shds/shhm/content/6c7c4491-9b5e-4ab6-8e05-365cbefdac19.html)

徐汇区资料给出1931年动工、1934年初落成，中央原六层、两翼原四层，八十年代加层后分别为七层与五层。2020年启动新一轮修缮。修后淮海中路正面照片可辨底层商铺以上连续五道横窗，街角局部还有一道较高窗带。建模采取照片可辨的行列。住宅的内部层号、圆窗所在楼梯的实际楼板高程，以及商铺在各年代的租用边界，仍待查。 [徐汇区建筑介绍](https://www.peopleapp.com/rmharticle/30028893902) · [住建部门修缮报道](https://sghexport.shobserver.com/html/toutiao/2020/12/15/314612.html)

沿街L形主楼在冻结底图14-13719-6695中编号5455，原始OSM为w493695715@1，本次实取提供了淮海大楼、皇家公寓和Empire Mansions三名。两版足迹交并比98.426%。底图淮海中路一面长61.83米、常熟路一面长76.49米，外法向154.07°和230.68°。徐汇资料给出148°及227°。庭院内另有5277、4812等单独楼体。门牌、实景两翼相接的次序、两个独立地点及道路方向共同约束临街边界。 [足迹与冻结输入](footprint-review.json) · [出处、图片及文件指纹](reference-review.json)

2014年7月20日Legolas1024的路口实景可辨高转角、平屋顶、三道竖肋和浅墙深窗带，图片采用CC BY-SA 4.0。修缮以后，区级专题的街面照可辨三道竖肋顶部的分层折线、底部三层圆头挑砖、五排圆窗及其凸弧竖井、钢窗和浅色水平百叶箱。1326号门头的四字使用具有独立厚度的字形，凹入的门扇和门头下两根圆柱有实际深度。街角墙面的退台尺度、两翼窗带与金属窗扇的细分尺寸由公开实照估算。常熟路远端与底层铺窗被树、人、车遮住的开间沿用可见横带概括，商店招牌、室内和背院各栋留待补证。专题实照经公开转载取得，仅用于比对。[2014年路口实照与授权](https://commons.wikimedia.org/wiki/File:Huaihai_Mansion.jpg) · [修缮专题配图](https://k.sina.cn/article_7517400647_1c0126e4705903or96.html) · [字形授权](source/fonts/provenance.json)
