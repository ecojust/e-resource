# 永福路151号住宅南立面

上海市房屋管理局第二批表将此住宅登记为2D023。徐汇区政府引述市历史建筑保护事务中心材料，记载花园住宅由杨增化设计，1941年始建、1942年竣工。2013年公开影像中的市政府保护铭牌也拍到了“永福路151号”及1941至1942年。永福路181号另有1935年建造的沈家住宅，旧工作名录中的1935年与后者相符。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [徐汇区政府建筑史与南立面配图](https://www.xuhui.gov.cn/gzfw_tpdt/20260508/572838.html) · [2013年5月19日照片与保护铭牌](https://blog.sina.com.cn/s/blog_5d1bdf480101bvdg.html)

园侧正面由三个形制不同的部分组成。西侧半圆形窗廊上下贯通，螺旋柱在顶层围成开敞廊；中央为两层挑出的栏杆阳台，上方有成对的浅弧窗和起伏的灰泥女儿墙；东侧两排各三个圆拱窗，层间的檐口下设托饰。这些构件可在保护中心正面图和2013年另一组照片中逐项对应。模型呈现南立面、两层栏杆、窗间柱和照片所见檐缘，各立面进深与高度据照片估计。[图片来源、拍摄对象及两处门牌比对](reference-review.json)
