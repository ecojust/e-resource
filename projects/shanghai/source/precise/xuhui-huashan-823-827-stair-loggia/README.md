# 华山路823、825、827号院临街住宅三山墙与明梯

2018年2月10日，Antigng在华山路拍到院门后的三山墙住宅。门柱上同处可见823号和825、827号门牌。2015年和2020年的两个冬季街景都能辨认中央的开敞拱厅和楼梯。第五批市级名录以5D051登记整组住宅，本次优先建有连续照片可认的临街楼。院内更深处各栋的号码对应关系仍待核实。[照片原页](https://commons.wikimedia.org/wiki/File:华山路823号住宅.jpg) · [上海市级名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

中央拱边按原片的明暗交界拟合。在1300像素宽的工作画幅中，87个方向里有76处能辨，拟合残差中位0.64像素。拱下的混凝土栏板呈折线，先沿左侧平台平伸，再顺楼梯朝右侧较低平台下降。栏板遮住部分踏面，模型用估算步数连接两层平台。[取点与拱形](measurements/loggia-arch-control.json)

两翼各有上部扇光钢窗、罩篷、菱形和横长花孔。左侧另有四个长方形排气口。原片中的树冠挡住右山墙端部，用街景确认其形式。首个工作版本把各面的投影放在同一试算平面，用来核对孔位、扶手与钢窗。独立街景已观察到中央墙面的前凸，退台、翼部屋面和最终米制比例另行复核。[两翼可见点](measurements/wing-photo-readings.json)
