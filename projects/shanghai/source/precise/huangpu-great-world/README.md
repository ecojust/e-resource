# 大世界：来源与外观范围

模型 ID：`huangpu-great-world`；保护名录 `sh-historic-b1-022`。对象是黄浦区西藏南路1号、延安东路路口的大世界，与南京路新世界分开。

本轮范围为沿街 U 形四层主楼、街角递缩高塔和照片可见屋顶亭，对应地图主体1519及角塔497。院内北侧共舞台／ET聚场2367保持独立；新闻与街道条目将其作为独立剧场叙述，地图源边界另由足迹审查核对。中庭白色弧钢屋盖仅在2014修缮前俯照中可见，没有取得2017复开后清晰院内图或工程图，因此本次不重建屋盖并保留待核任务；省略不表示确认已拆除或现状敞院。

沿用前置已读的[澎湃2016修缮／试营运报道](https://www.thepaper.cn/newsDetail_forward_1585102)和大世界百科建筑段落；本轮实际补读[Time Out 2017开馆场所介绍](https://www.timeoutshanghai.com/venue/Around_Town-Cultural_Centre/43125/Dashijie-(The-Great-World).html)、共舞台百科历史及[新闻晚报2013剧场修缮预告（新浪转载）](https://ent.sina.com.cn/j/2013-08-08/17553983464.shtml)。1917创立／初建、名录1924、1928改扩建与2017复开分别保留，不混作同一施工日期。16800平方米为报道总面积，不是地图占地面积；没有取得可靠绝对塔高、实测平面或逐层标高。

参考人员实际查看7张图：2014高处图、2024年1月20日五张Commons街面／入口图，以及Time Out于2017年4月6日刊文的日光立面图。日光图拍摄日期未核。Root也逐张实际查看全部7张，依其明确回报登记。日光图支持浅米灰石色，2024夜间黄灯不作石材色样。后期图中连续栏杆、窗楣、入口巨柱与几何栏板明确，主塔有拱段、柱段和内退暗芯／窗，不能做成整座空笼。

四层主体的宽深依地图参考，塔高、层高、窗位、柱距、亭子尺寸与微小装饰按照片估计。后场、完整内院立面与院盖现状仍缺补证；不可称完整院落或全部建筑群已复原。屋顶亭只作照片可见构图，隐藏布置与设备不冒充逐面测绘。广告、临时霓虹、室内、树木和院外楼体不并入。

Root另实际阅读西藏南路、延安东路两条道路的导言、历史、交会道路及沿路机构段，核对路口与延安东路433号ET聚场线索；未逐一阅读引用原页或沿路机构页面，不代表1038条道路全部复核。此记录只作本楼背景，不改变原始街道索引。
