# 福德坊1号花园住宅

建国西路336弄1号是穿过福德坊弄口后、院门上钉有绿色“1”号牌的三层住宅。上海市房屋管理局第五批优秀历史建筑名录给出的编号为5D083，登记名称及使用单位均为“办公”。高参88记载住宅建于1930年，另一篇沿革记载为1931年。现阶段采用约1930至1931年。

院面有两对高低不同的圆柱。靠前的两柱托弧形阳台，后方两根通高柱托上层直阳台。两侧折角窗湾、窗间浅浮雕、门前弧阶及西墙百叶均有近照可对。地方坐标以短边门廊居中，X沿庭院立面指向约72°，Y指向楼内，Z为高程，单位为米。

照片03、04、05提供三个不同视角，02从带门牌的院门外记录了西墙。读出的照片像素、误差和复算程序见 measurements 目录。可编辑文件另含建筑总览、柱式、窗裙、檐口、西墙与门厅机位。所有纹理由程序生成。

两期航片与地块资料支持前段坡顶和北部较低的浅色屋面。屋脊高度、坡度、后部屋顶尺寸及门厅遮挡深度均为估算。模型范围止于1号住宅。临街弄口、院门、其他门牌、室内分间与屋架尚需各自的资料。
