# 襄阳南路351至355号街面窗框花饰与垂叶

5D054在市表登记为住宅，门牌襄阳南路349-355号（单号）。2018年8月2日Antigng拍摄的《襄阳南路351–355号住宅》中，红砖立面一层可见灰绿色窗框。窗楣有一行六朵小花，两朵花之间伸出带卷尖的对称垂叶。作品取原照里清楚的一段窗头和窗间饰带。

沿水平方向可见六个立体花头与两道较窄的平直压线。左边第一窗半遮，窗后可见横档。 右末两朵花借弧茎汇入窗间立带，下面有对称外翻的卷尖、小叶和中心滴形。前景的铁栏和门垛未收入窗饰。

市表5D054列襄阳南路349至355号单号，较早名录简记355号。照片可读的绿色357弄牌挂在前景院门。本作取后方住宅窗饰，现有证据不能进一步指定这扇窗的单独户号。深度和遮挡处只按可见形状估计。
