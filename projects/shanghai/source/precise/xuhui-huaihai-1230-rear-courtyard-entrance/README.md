# 淮海中路后排1230号入口与叠层阳台

从淮海中路标有1228、1230的共用街口进入内院，院北暖色砖楼的入口右侧仍能在高参88的照片里读到绿色“1230”门牌。本模型截取这段院向立面，涵盖门洞、红色壁柜、入户踏步、相邻钢窗及入口东边的四层叠台。下层从西侧窗墙延至东侧窗墙，右上部收在照片可辨的阳台端柱。各层有不同的矮墙开孔、金属栏杆和封窗状态。

徐汇区第五批优秀历史建筑5D095登记范围为淮海中路1222至1238号双号。内院照片支持的是上述入口所在的一段。临街白色楼的通道、背面和其他双号均在本次建模范围之外。2013年图文与2016年1月20日的院内照片提供两个不同视点，阳台围护以2016年可见状态为准。[上海市房屋管理局第五批名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

## 坐标和尺度

X沿院面向东偏北，方位约75.65°，Y向楼内，Z从院内地坪起算。以门扇高约2.10米定尺，允许约0.15米误差。六个未参加相机求解的控制点，中位投影偏差为6.72个原图像素。最大偏差21.01像素落在外挑滴水端部。图中可以分辨五道踏步前缘，最低一级位于画外，其进深和高度采用估算。砖行和砖长来自三个独立图像区域的透视校正，具体读数见 measurements/masonry-observations.json。

## 重建

在包含 projects/shanghai/tools 和公共建模代码的项目检出中，从该模型目录执行以下命令。输出目录将包含原始近、远两档GLB及各自的闭合和体积检查。几何使用米，纹理按建筑尺寸平铺。

```bash
python measurements/check_mesh.py /tmp/huaihai-1230-mesh
```

两次拍摄的原始链接、登记数据、相机和单独测读的像素保存在 measurements 目录。公开的透视图均由模型渲染，许可和出处见 [SOURCES-LICENSE.md](SOURCES-LICENSE.md)。
