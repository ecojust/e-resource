# 新场叶氏花行120号院内凹曲山墙与叠瓦压顶

5W007在市表登记为叶氏花行，门牌新场镇洪西街114-126号（双号）、新奉公路105号。Fayhoo于2015年1月27日上传的新场叶氏花行院照，图说为“叶氏花行（叶瑞生） 洪西街120号”。院内门旁绿牌可读120，后方白墙的脊瓦先升高卷起，再跌落为深凹弧，临院一端压有短小的山尖状线脚。

向院内看，灰瓦压顶两端一高一低，压顶下面隔段可见突出白墙的横瓦头；中间低点呈深凹弧。 靠近院子一端为窄白墙墩，墩头几道叠涩，其上另有小山尖形暗色压线。院内门旁绿牌的120可辨。

5W007覆盖洪西街114至126号双号并列新奉公路105号，本件仅按题注和同图门牌落在120号院。照片上传日期可核，确切拍摄日未见记录。山墙进深、背侧与瓦端伸出量按斜视估计。
