# 圣玛利亚女中礼堂山墙圆窗与拱饰

1923年迁入白利南路的新校园即今长宁路1187号。礼堂与钟楼相邻。老照片和方志上海标为2020年的中庭照片都可见礼堂正面的圆窗和两侧斜檐。模型配色和窗格以这张2020年彩照为据。2009年的报道记录了校园拆除中的钟楼和附近其它馆舍。
