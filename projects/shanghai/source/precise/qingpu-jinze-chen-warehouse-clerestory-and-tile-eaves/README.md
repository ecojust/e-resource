# 金泽陈家仓库层檐之间的窄窗带与小青瓦

5X010在市表登记为陈家仓库，门牌金泽镇下塘街16号。金泽镇下塘街16号为陈家仓库。Fayhoo署名街照显示，长白墙上有连续的暗色瓦头，靠后较高的瓦檐下露出狭长的分格窗带。取照片中墙顶和后方屋檐同时清楚的一段，建两道青灰瓦檐、两者之间的暗色竖框及下部抹灰线。

前排墙冠有一行重复的深灰色滴水头，白墙上有两条连续浅色压线。后一层屋面瓦色近黑，檐下红褐木横枋和窄窗竖框平行延展。 临街门、回收箱和相邻店面未进入截取的檐部范围。原图2014年10月15日上传，拍摄日无EXIF依据。

原照题注为下塘街16至17号，市表所列为16号。该照片可指认陈家仓库临街立面，未给整段墙内的分户边界。窗格内侧和各道瓦的进深、瓦形半径与绝对尺寸按单幅街照估计。
