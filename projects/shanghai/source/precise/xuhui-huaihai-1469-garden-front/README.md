# 淮海中路1469号历史花园立面

上海市优秀历史建筑第二批2D007著录淮海中路1469号花园住宅。2011年10月存档的馆方沿革明确记载，主屋建于1921年，采用法国文艺复兴风格，最早由怡和洋行使用。1980年4月28日是驻沪机构在该门牌重新开馆的日期。原记录另载1997年及2003至2005年的修缮。[房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) [馆方建筑沿革](https://web.archive.org/web/20111015005813id_/http://shanghai.usembassy-china.org.cn/consulate_history.html) [中文历史页](https://web.archive.org/web/20210224235205/https://china.usembassy-china.org.cn/zh/embassy-consulates-zh/shanghai-zh/history-zh/)

馆方两幅花园侧照片呈现不同构图和树冠状态。一幅宽幅全景最迟于2010年12月9日公开；另一幅正面照片于2011年10月15日存档，可以看到门廊配对支承、横檐、居中台阶、上下层外窗与连续的层间线脚。两幅照片均未记录拍摄年月。模型描绘照片所见外观，树木遮挡的窗格与装饰按相邻可见部分估计。树冠后方的屋面形制、侧后部及庭院分区保留为研究空白。[2010年公开照片](https://commons.wikimedia.org/wiki/File:US_Consulate_General_Shanghai.jpg) [2011年独立主屋图文](https://web.archive.org/web/20111015004639id_/http://shanghai.usembassy-china.org.cn/consulate_house.html) [两幅图像的原文件收据](reference-review.json)

主地图通过公开门牌附近的街区标记打开独立历史立面。各构件均采用独立着色几何，门廊和台阶仅延伸至模型截面。数据包提供原始GLB、网页近景、远景LOD和可编辑Blender文件。
