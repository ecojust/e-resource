# 复兴中路563号住宅山墙木格与悬挑百叶罩

5A055在市表登记为住宅，门牌复兴中路563号。市表5A055登记复兴中路563号住宅。取Antigng于2018年7月30日署名拍摄的旧住宅，范围从左侧坡檐至中央双扇窗、窗下浅色百叶罩及其金属托架。

左坡深色封檐从低处连续抬高，内部几个深色竖格落在同一道水平枋上。 白色双扇窗立于木格轴中；窗前下方有外悬的浅色横百叶与两侧支撑，2018年状态留在本研究。

木构件部分被树枝挡住，取照片能辨认的坡向、横竖分格和一段弧形支撑。绝对尺度、截面和托架进深为估算。
