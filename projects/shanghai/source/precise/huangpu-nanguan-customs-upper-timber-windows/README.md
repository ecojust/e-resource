# 江海南关办公楼临街二层红棕色木窗

上海市黄浦区外马路348号。临街二层的两樘红棕色长窗各有上亮和两扇下窗。右窗上亮留一道绿色木框，两樘白色石窗台向外挑出。

木框和格数取自2016年6月18日实照。窗高约2.0米，整段墙宽约3.36米；宽高比例取自原图，绝对尺寸、进深及内侧型材均待实测。
