# 沪江别墅长乐路613弄通道与挑窗

沪江别墅在上海市第四批优秀历史建筑中编号为 4D003，范围包括长乐路 613 弄和沿街 615 至 629 号单号。这件模型取 613 弄临街的单个开间。可从红褐色值守窗旁穿过底层通道，也可抬头看二层三列钢窗、竖条窗楣和上层挑窗。上层窗腹的水平凸条在两个前角连续绕回。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [地址和现场来源](reference-review.json)

五个视点给出的通道宽度约 4.09 米、净高约 3.30 米，挑窗宽约 2.54 米、出挑约 0.89 米。计算采用公开街景记录的相机高度。留出任一视点重算，通道宽度在 3.85 至 4.31 米之间。红砖色贴面和白色窗框按 2015 至 2021 年照片里的状态重建。值守处的深度和门楣后方看不清的部分按可见边界估计。[照片比量与逐站结果](measurements/observed-dimensions.json)

相邻沿街店铺、弄内住宅和更深处的通道仍需另作。地图原有建筑 5217 包含一整段沿街房屋，当前的门楣定位与它相隔约 5.29 米。[屋面与原有建筑](measurements/roof-identification.json)
