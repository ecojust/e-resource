# 武康路376号住宅断弧门楣与石瓶

5D018在市表登记为住宅，门牌武康路374、376号。市表5D018涵盖武康路374、376号。Antigng的署名照片明确标为376号住宅，院内侧翼门口两段石弧的中央留出缺口，一只瓶形饰件立于平檐正中。这里制作门楣、石瓶、左右托座与上亮窗。

断开的弧形边框后面可从缺口看见红砖，石瓶以方台、细颈、腹部和盖钮分层。横檐前伸，下方两侧保留卷形托块。 窗楣下为深色木横档，四面狭长玻璃由较密的深色木框分开。实图的右侧受百叶和灌木遮挡。

同项374号的其他门窗未见于这张原照。石饰各层深度和侧面转折按可见轮廓估算。门口下部被绿植遮挡，模型止于上亮窗下框。
