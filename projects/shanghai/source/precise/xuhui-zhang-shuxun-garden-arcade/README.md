# 张叔驯故居花园面三联钢窗券廊

上海市房屋管理局第四批优秀历史建筑名录4D044列天平路40号「花园住宅」，现名栏登记文艺医院。1934年建成的住宅原属张叔驯，花园面首层保留三道并列半圆券。[第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2024年12月20日播出的看看新闻节目从草坪拍摄正面。1.80秒的近镜能读出各窗的四列钢框、起券处的横档、两道同心圆弧、三根放射状窗棂。两窗间圆柱有方基座、翻叶柱头和分层方顶板。23.4秒草坪远镜可核三券属于同一幢粉色住宅。[看看新闻，刘晔、杜梦渊、徐华骏](https://www.kankanews.com/detail/xeyojao3R29)

比例取自正面画面。中央净宽151像素、拱矢76像素、窗下槛至起券246像素。建模采用1.56米的参考净宽，整件的绝对尺度和背后进深属估算。完整建筑的沿革另见娄承浩等《老上海名宅赏析》，2003年，第56页；刘嵩松、夏明2008年关于张叔驯故居的研究，第502–505页。[采样位置与尺寸](photographic-proportions.json)
