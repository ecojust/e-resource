# 慈修庵正院北殿与两厢木廊

从天井向北，三开间的红木厅面中央悬挂“大雄寶殿”匾额。东西两侧厢房向内伸出木廊，圆柱之间的空处可以通行，二层设宝瓶状木栏杆。2019年4月27日发表的现场组照可以从院内连续辨认梁下回纹、格扇、廊柱及钢架玻璃院顶，摄影者没有另列曝光日期。另有一幅沿中轴拍摄的全景，可比对北殿的三开间及两端的厢廊。模型按照片概括构件比例，大雄宝殿的匾字依右起次序另行建成几何。[2019年现场组照](https://blog.sina.com.cn/s/blog_5d1bdf480102z0z6.html) · [轴线照片及寺院沿革](https://www.baifodian.com/zixun/link.asp?id=101) · [逐图来源和指纹](reference-review.json)

榛岭街15号的门牌与上海市人民政府优秀历史建筑铭牌出现于同一张照片。铭牌英文记载1869年创建、20世纪初重建；2019年上海热线记载火灾发生于1917年，之后重建大殿三开间、两厢房，并增设韦驮殿。1983年获准重新开放。现存殿宇在1980年代又有修葺，玻璃院顶的安装年份尚无确证，但至2019年已可见。2022年1月、2024年1月发布的遥感影像可辨深色北侧屋面和较亮的院顶，2026年1月发布的影像内，周边已有工地，院顶外观也发生变化。交付件的钢架、透光玻璃、旧式北殿和两条厢廊均分别可编辑。[1994年铭牌照片所在原文](https://blog.sina.com.cn/s/blog_5d1bdf480102z0z6.html) · [2019年建筑报道](http://100.online.sh.cn/content/2019-02/23/content_9210115_5.htm) · [出版版次与逐瓦片查询](reference-review.json)

市房管局第二批名录2A056（原2E001）原文登记“秦岭街15号”，既有现场门牌、工作名录与具名OSM房屋采用“榛岭街15号”。正院原入口向西，天井以北为大雄宝殿，以南另设山门殿。方浜中路593号原有一所教育局小楼及院落，2001年起置换给慈修庵。那处另院、黄色街门、南侧殿、殿内陈设及未能核准的其余房屋都保留在本次建模范围以外。百度“南门”标记距榛岭街具名建筑的最近外缘约58米。[市房管局登记](../../../data/audit/municipal-heritage-register-2026-11-20/register.json) · [2001年置换及两院形制](https://www.baifodian.com/zixun/link.asp?id=101) · [OSM建筑与两处地点](footprint-review.json)
