# 何东上海公馆花园侧四柱门廊

陕西北路457号。上海市房屋管理局第四批优秀历史建筑表将此处登记为4B025「花园住宅」，现用栏列「辞书出版社」。本次制作面向花园草坪的中央四柱门廊，包含弧形三级台阶、四根通高爱奥尼柱、三樘拱券落地门、二层内凹铁栏阳台和返折至两侧的石檐。模型止于短返面。两翼、车行庭院一侧的单门、后部及室内空间仍待调查。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [项目总图与实景](https://www.shuishi.com/works/3079.html?major=8)

## 比例与开口

花园总图把何东旧居定位在草坪北侧。按原城与OSM轮廓，临花园一边长约22.36米。选取一张早期正面照，以及改造后的花园斜视、草坪远景两张照片，从柱脚、柱头、券顶、门槛和两翼立面记录41个控制点。按各自画幅独立拟合相机，三图重投影均方根误差约4.88、6.48和2.02像素。[照片与图件索引](reference-review.json) · [控制点、相机和残差](measurements/garden-photogrammetry.json)

| 部分 | 建模尺寸及观察 |
| --- | --- |
| 四柱 | 轴线间距约2.92米，柱头涡卷中心距地约6.25米。柱身下粗上细，各保留凹槽、柱础、卷涡和方形顶板。 |
| 门与进深 | 柱心至门墙约3.49米，三门轴距约2.81米，拱顶高约2.85米。中门留出向内开启的两扇，门上细棂和半圆内弧可从两面辨认。 |
| 阳台与檐 | 阳台地坪约4.24米，前侧与两斜边均有透空铁栏。檐上石栏顶约8.68米；栏柱、檐齿和廊顶亮孔都建为实体边缘与空隙。 |
| 地台 | 前缘在外柱两端连续弯回，三级踏面不同高。完整前缘宽约11.06米。 |

这些尺寸为照片拟合与局部资料估值。树冠遮住部分石栏，廊下仍有暗部。凹槽截面、装饰重复数、铁花纹样、门叶开启角度和檐后构造按可辨尺度补足。园内反向照片记录了一樘开启的双扇门，模型选择中央一对呈现这种状态。2016年Fayhoo所拍单门及贴墙壁柱属于另一朝向。项目摄影仅用来观察，模型以原创几何与程序材质表现石材、铁栏、木格和气窗玻璃。[园景与门内向外的照片](https://www.thepaper.cn/newsDetail_forward_27179376) · [Fayhoo的另一侧立面照](https://commons.wikimedia.org/wiki/File:Hedong_Gongguan.JPG)

## 原城配准

门廊依原城建筑1292的花园边对齐。近景与远景分别裁去约45.76和44.99平方米，保留两翼及后部原有体量。概化主体的原屋顶高29.50米，在院内视角会出现在8.68米的细化门廊后方。庭院地面保持柱间通行，中央门洞的局部裁切延至门叶后方。地图只开放已核实的总览机位。[配准与足印](footprint-review.json) · [局部裁切合同](../../../data/audit/ho-tung-garden-portico-v1/final-placement-contract.json)

## 模型文件与复核

近景63,648个三角面，远景24,060个，使用12种材质。网页模型通过meshopt压缩，逐材质比较实际解码后的顶点、三角面朝向、连接关系。每档以244条射线检查实柱与相邻空隙、台阶端部、开启门扇、门内外棂条、廊顶亮孔、栏柱与檐口。[重建脚本](source/build_model.py) · [导出与实物检查](../../../data/audit/ho-tung-garden-portico-v1/preflight/model-review.json)

在已安装 Blender、gltfpack、Open Image Denoise、NumPy 和 Shapely 的环境中，从本目录运行以下命令。

```sh
python -B source/build_model.py --out ./ho-tung-model --audit ./ho-tung-audit
```

原创模型和脚本采用仓库MIT许可。地图身份及足印记录保留OpenStreetMap贡献者署名和ODbL许可。图像原件及摄影署名见各来源页面。[制作页](../../../ho-tung-garden-portico.html)
