# 盐业大楼北京东路280号门罩与石栏

市房屋管理局第四批名录以4A010登记盐业大楼、盐业银行，北京东路280号。东邻中一信托登记在270号，编号4A009。两者在原城中分别对应718和1082。相关足印、原始地址、照片题名及数据版本见 [来源比对](reference-review.json)。

上海市文化旅游局资料记载，盐业银行在1931年建成的楼里营业，原五层，后来增至七层。报道刊出旧影与改建后外观，两张照片的拍摄年份尚未见说明。2014年1月27日Livelikerw街照和2020年2月街景都拍到了南向门罩。四棱外墩、一对圆柱、实腹挑梁、环孔石栏和中部圆牌能在照片间对照。街照上另有后来增设的商业招牌。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [市文化旅游局资料及对照照片](https://sh.people.com.cn/n2/2023/0621/c350122-40466589.html)

只重建从门面至石栏的外部构件，可辨的三扇拱头作浅退入处理。尺度按照片估测，圆牌石饰按可见起伏简化。玻璃后方室内、其余临街开间、后加两层和屋顶均未调查到同等精度。
