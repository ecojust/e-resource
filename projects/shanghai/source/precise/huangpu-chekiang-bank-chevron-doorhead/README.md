# 浙江实业银行大楼福州路入口折线门楣与串珠

上海市黄浦区福州路107号。107号矩形门洞的深色金属门楣，中央三层向下叠合的人字折线，下方见斜面，两边各有带圆饰与串珠的阶形垂板。

节选宽约2.44米，金属板宽约1.82米。前脸比例来自2017与2020年相同门牌的街摄；材质以照片中的暗褐金属表现，原有合金、厚度与背面尚待实测。
