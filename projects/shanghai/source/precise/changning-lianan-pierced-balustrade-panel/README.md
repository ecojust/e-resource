# 联安坊老住宅阳台水泥透花栏板

联安坊建于1926年。长宁区规资局在2012年和2022年的保护建筑介绍中刊载同一张照片，阳台水泥栏板上可辨出连续的透花。本件截取一组可辨的纹样。 [长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211207/1151469.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

正面可通视中间的细长孔和两侧四个卷叶孔。两张斜面图显示孔内壁与上下线脚的进深。原图像素只支持纹样大形。 照片中纹样约31×30个原图像素。可辨的五个暗孔沿轮廓离散重绘，板宽、深度和背面按比例估计。

来源只辨认一处历史水泥透花纹样，保留全市原地块。作品没有建筑平面、门牌分楼和现用场所的环境图。
