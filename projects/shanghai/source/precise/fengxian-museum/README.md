# 奉贤博物馆（2019新馆）可编辑外部模型

本模型覆盖A/B/C三片主体、二层短连桥、连续铜百叶外幕、分层内庭、屋顶环道及可见圆形构筑物。它是依据设计图和建成照片制作的几何复原，不是实景扫描或测绘成果。没有补造地下车库、展陈或不可见的室内装修。

源身份为 OSM `r20262808@1` / GERS `5d5723cd-61a0-4171-bf10-87dd0308285a`。锚点为 `[121.49800368075604,30.935963102552357]`。glTF坐标为东/上/南，Blender原生模型为东/北/上，单位为米。完整源外环和内环用于身份及粗尺度配准，**不作为一整片屋顶或楼板**。

## 包含的几何

- 首层分离体量、退后玻璃和白圆柱；二层通过三段短桥相连；三层/绿顶各自保留内缘和开敞扇区。
- 各层外缘与独立铜幕协调，楼板和梁端保持在外屏内侧；内庭边界不随这层外幕填满。
- 外层铜百叶与内部屋面独立，保留真实间隙。C侧少量矩形孔是截断百叶得到的真实缺口，不是黑色贴片。
- 幕墙横竖框、独立闭合玻璃门扇、门把手、透明栏板和细柱，以及连接外屏/窄外缘路径与主体的概括钢架。
- 高架环道、下方仍有净空的中央白圆台、两处可见下层白台、大圆筒封闭屋盖和两处小型开敞屏。
- 各叶不同的曲线路径、种植分区、细茎叶簇/小花簇及稀疏草簇，还有少量建成照片中可见的设备概括体量。

原生Blender文件中的建筑集合为 `Fengxian_Museum_Complete_Exterior`；预览地面、灯光和相机单列在 `Preview_Only_Excluded_From_Model_Exports`，不属于导出的建筑。

## 尺度与限制

总平没有可核定的图尺。注册采用均匀缩放/旋转/平移，不对图纸做非均匀拉伸；相对粗源外边界的双向RMS约2.09m、最大约9.57m。这个残差不是测绘精度。页面上方对应真北方位约338.13°，不是正北。

2018施工表列各栋18m，2020建成项目文给总体15–21m，其工程阶段和高度边界未统一。当前模型大圆筒盖试估21m，照片支持的小通风件概括高度再增加约0.47m；软件顶点包络为约21.47m，**不是实测21.47m**。层高、内庭边缘、圆台高差、门位、设备和百叶孔位均保留照片/图纸推估限制。

中央大环内部既有A绿顶舌部，也有低位白台与开敞空间。两处小圆白面不是贯通地面的黑洞；大圆筒顶盖不是孔。不可见的支承细部和构件规格采用概括几何，不能用于施工、结构校核或无障碍评估。

玻璃、铜、草地和植物使用原创PBR参数及实体细节，不是本楼表面扫描。花叶与草簇只表达照片中的低矮种植，不声称特定物种或逐株实测位置。任何私有设计/馆方图片像素均未嵌入模型或复制到此包。公开参考图片为Stevenliuyi于2019年拍摄的Commons实景照，按CC-BY-SA-4.0另列登记；它也没有作为贴图嵌入GLB/Blender。

## LOD与复现

LOD保留分层内庭、真实百叶间隙、外幕连续轮廓和圆构筑物类别，减少植物及栏杆/幕墙分段。百叶节距、宽度、深度同时按2倍补偿，额外深度向内延伸，维持远景铜色覆盖率；LOD加粗是显示近似，不能当成构件实测截面。

本目录保留作者工作树结构：代码在 `source/`，配准与屋顶分区数据分别在 `registration-v1/` 和 `roof-topology-v3a/`。使用Python3、NumPy、SciPy、Shapely2.1及Blender4.3.2。重建不需要私有照片像素：

```sh
python source/build_model.py --out rebuilt-full
python source/build_model.py --lod --out rebuilt-lod
blender -b -t 2 --python source/render_model.py -- --glb rebuilt-full/fengxian-museum.glb --out rebuilt-preview --samples 32
```

输出目录必须不存在，以免覆盖证据。完整压缩使用gltfpack保留浮点位置/法线，并在压缩后恢复 `asset.copyright`；JSON之外的BIN块保持不变，证明文件随包提供。

四项运行时资产及最终哈希由同目录 `model-metadata.json` 登记。最终独立验证与网页结果由项目验收记录另行给出。模型内可见楼梯/屋顶路径并不表示网页运行时具有任意室内或屋顶碰撞、登阶功能。
