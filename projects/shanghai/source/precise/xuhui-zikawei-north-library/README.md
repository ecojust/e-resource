# 徐家汇藏书楼北楼 · 原藏书楼

徐家汇藏书楼由耶稣会创办。地方志记1897年重建专门藏书的两层馆舍，上层藏西文书。南侧四层原神父楼已在同一地图独立展出，庭院夹在两幢之间。[地方志、徐家汇源旅游资料及报刊](reference-review.json)

漕溪北路80号街景可辨东山墙顶端的圆形气孔和底部三道拱。2015年12月、2021年1月，站在漕溪北路前后两个位置都能看到相同的山墙和拱口；景区近照显示南面一座较宽的拱，拱后通廊上方有斜撑。望庭院的高位照片同时显示南楼柱廊、北楼六道上层拱窗及其红瓦双坡屋面。地方志描述的清水砖墙属于建筑史；可见外表按修缮后的淡色粉刷、深灰台基和百叶窗处理。[定位照片与年代](reference-review.json)

北楼实名OSM与独立矩形单体667配准。南楼单体1595以及已发布四层原神父楼使用另一组可核对的资产。两座建筑的统一地址用于校园范围识别。模型层高、百叶开合、屋顶瓦距及隐蔽侧面按照片比例估计，馆内书架与原藏书分区保留文字说明。[实测轮廓与南楼资产绑定](footprint-review.json) · [模型查看器](../../../zikawei-north-library.html)

原始与网页近景各105,688面，远景54,672面，可编辑Blender含63个具名网格。东山墙的三道洞口与庭院一侧通廊都可从外部观察，铺地保留通行。独立射线和面积见证分别覆盖三档模型的廊口、实墙、百叶、屋面及街边墩柱。[三档独立射线与原生近照](../../../data/audit/zikawei-north-library-v1/README.md)
