# 东平路16号和平官邸双题牌院门

5D002在市表登记为和平官邸，门牌东平路14-16号(双号）。市表5D002和平官邸涵盖东平路14、16号。ShanghaiMansion上海豪宅发布的16号封面照，院门两边各有一块黑底竖牌，均写「和平官邸」。旁侧门牌可见16。模型取两根砖柱、球形柱灯、竖牌和中部上缘隆起的双扇铁门。

两题牌均自上向下读「和平官邸」。砖柱上有浅色球灯，黑牌的轮廓以细金边收口。绿色16号牌在右侧围墙上，未建入双柱截取范围。 双扇门上缘由中央向左右逐渐下降，上格较密的直棂，下格横分，铁门的美术细部取简化近似。

署名来自文章发布账号，照片未另列作者或拍摄年份。柱宽、铁门退深和花纹按单张街照估计；字体据可读文字采用公开许可矢量近似。这一局部不确认住宅建造者、旧主人、铁门设置年代。
