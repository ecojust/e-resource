# 杨树浦电厂汽机房及4号锅炉房

1926年黑白照片的原图题同时写了汽机房与4号锅炉房。杨浦区文物资料将“铁皮车间”明确指为汽机房，上海市房管局第二批2G001登记地址为杨树浦路2800号。美国国家档案馆保存的1935年3月6日北、东侧斜照能印证长短窗翼、檐口转角与屋冠。三维单体保留这一组历史外观。[1926年合影及题注](https://www.thepaper.cn/newsDetail_forward_17429374) · [1935年馆藏编目与背面题款](https://www.virtualshanghai.net/Photos/Images?ID=34894) · [杨浦区文物资料](https://www.shyp.gov.cn/shypq/shxd-gyyj/20231128/442695.html) · [上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html)

长窗翼下部受到前景遮挡，窗墙较远一端与其他建筑重叠。模型取八组主要窗轴、近端可辨的五道高窗、短面窗组、分层檐口、四处冠顶弧形构件及烟筒。墙厚、屋顶封截进深与外墙原色均为估计。模型只使用单独构造的材质和网格，照片在各自的原始图录中查阅。[照片、年代与授权说明](reference-review.json) · [局部像素范围](../../../data/audit/yangshupu-turbine-hall-v1/photographic-observations.json)

厂区内还保留开关车间、水滤房、循泵房和办公楼。沿江的三座改造灰仓与上述厂房可分别辨认。资料标记设在停用电厂的园区范围内。当前建筑底图保持既有形状。具体哪一段受保护厂房对应1926年合影中的某一侧，待有分栋名称的图面或现地档案确认。[厂区点位、范围与影像核查](site-location.json) · [查看历史单体](../../../yangshupu-turbine-hall.html)
