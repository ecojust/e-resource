# 皋兰路圣尼古拉斯堂主堂

上海市房管局第二批表2C013登记「东正教堂」，当时使用单位列「幸运城大酒店」，地址皋兰路16号。地方志区分此堂和新乐路55号圣母大堂：皋兰路新堂由亚·伊·亚龙设计，1932年12月18日奠基，1934年3月31日祝圣。1955年停止宗教活动，后期用于餐饮，2019年改作思南书局诗歌店。2020年设计方发表的改造资料附平面、剖面和轴测图，能辨十字形主堂、两侧厅、圆端和后来服务空间。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海地方志](https://web.archive.org/web/20190415154034id_/http://www.shtong.gov.cn/newsite/node2/node2245/node75195/node75205/node75325/node75333/userobject1ai92291.html) · [改造图纸、外观照片及设计方说明](https://www.archdaily.com/935282/sinan-books-poetry-store-wutopia-lab)

1942年前的照片能辨独立的侧顶，方志记全堂原有九顶。1995年西面可见绿灰色葱形主顶，2021年冬季照片已呈金色，低翼和主冠周围的小冠数量、收边也经历变化。本次依据2017、2020年临街正照和2021年西南侧实照表现当代主堂。南面门楼上部有一道实际的深拱口，下部门扇上方设扇形玻璃；门楼东侧是圆端楼梯间，西侧两处前墙有弯曲窗冠。正堂身的长拱窗、弧尖山花和主冠分层可见。院内餐饮和书店设施、部分背北房间与早期已失小圆顶留待分期研究。[历史与现况原照](photo-history.json) · [设计刊物取图收据与几何参数](source/plan-parameters.json)

OSM具名地物w206609489@8与城市宏块14-13719-6695的2197号对应，东邻4245属于独立房屋，两登记外廓之间约有3.32米。人工从2020年公开平面按同一比例提取主堂、门廊及东端圆弧，南面由皋兰路2013年、2020年街景及两期正照定位。OSM为简略四边形，公开平面缺少可辨尺寸标注，平面尺度和未实测的高度按照片及源图估算。三期航片只辅助确定屋顶和邻楼的相对位置。一个被归入上海分类的2025年照片实为美国朱诺，单列于出处收据。[具名地物和近邻](registered-shape.json) · [皋兰路街景收据](street-observations.json) · [三期屋顶图源](roof-tiles.json)
