# 原法国领事馆岳阳路11号楼露木山墙与双窗

上海市第四批优秀历史建筑名录把岳阳路319号11号楼列为「花园住宅/法国领事馆」，现名为中国科学院上海分院11号楼。此前研究的淮海中路1431号属于另一处登记。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

CyberCop在2000年的照片中直接标出门牌和楼号。白色山墙的三角木架下有一道上凸的过渡面，九条深色托木沿弧面伸出。中间的两扇棕色窗以窄木框分隔玻璃。Eecc于2004年从另一侧拍摄同栋，斜照确认窗框的退进、山墙的突出与檐边的厚度。[2000年正面照](https://commons.wikimedia.org/wiki/File:Old_French_Embassy_-_panoramio.jpg) · [2004年斜照](https://commons.wikimedia.org/wiki/File:SIAS_Shanghai.jpg)

山面宽约4.12米，两处窗洞均按约0.92 × 1.50米估计。木构位置按照片投影定比，构件厚度与玻璃分隔为近似复原。底图两个地名点指向同一附近屋体，现有资料仍不足以定位到这面山墙。[照片标定](reference-review.json) · [地块对照](campus-location.json)
