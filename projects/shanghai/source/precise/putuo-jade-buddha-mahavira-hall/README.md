# 玉佛禅寺大雄宝殿

2017年9月，大殿沿寺院轴线向北平移30.66米，再抬高1.05米。模型重建今天位于扩大的南侧前庭背面的殿身、石台、木格门、灰瓦重檐歇山顶和屋脊饰。两翼翘檐、黄色外墙与圆饰窗按照寺方正面实照建模，上层四块匾额自右向左读“大雄寶殿”。[寺方大殿说明及外景](https://www.yufotemple.com/view/152) · [寺院导览](https://www.yufotemple.com/cfzn.html) · [史料、照片及版本](reference-review.json)

2016年发布的航片记录平移前的位置。2019年11月9日和2021年11月25日拍摄的两期影像分别量得前檐移位约29.65米、30.46米，两期中心都落在城市数据的979号实体上。旧殿位置今天是前庭。两次新影像的前檐宽约28.9米、30.5米；定位受树冠、离地视差和影像自身精度影响。模型最高屋脊饰约13.74米，檐口和隐蔽侧背按比例估算。[航片原始地址、量点及两期套合](roof-registration.json) · [城市实体与同组邻殿](footprint-review.json)

三维几何由本项目原创，八个匾字采用SIL OFL字体子集，未嵌入实照。寺方大雄宝殿之外的前庭器物、卧佛殿、地藏殿、觉群楼等仍按原场景保留。可编辑工程保留各屋面、下檐翼角、匾、木构与台阶的独立网格组。[生成程序](source/build_model.py) · [源程序与匾字授权](source/fonts/OFL.txt) · [三维单体与下载](../../../jade-buddha-mahavira-hall.html)
