# 美伦大楼西楼南京东路西北转角

上海市房管局第三批3A007登记美伦大楼，使用单位为上海晒图厂等，地址为南京东路161号。第五批5A030原名称包括西楼、南楼，现名称为美伦大楼（西楼），同样登记161号。5A029单列151号东楼。项目早期转录的151–171号保留作历史门牌范围。本次对象是南京东路与江西中路交会处的西楼西北转角，覆盖南京东路街面和江西中路照片所见的短段。[第三批原表](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [第五批原表](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

2013年施工阶段的照片可辨转角切面、窗轴和原有檐口。2018年的近照与2019年同一街角的全景可辨山花、带浅浮雕的壁柱、石砌分缝、窗框和檐顶栏杆。檐口后的浅色加建体记录在照片中，关于1994年加建两层的说法来自次级登记。店招、内街与南楼各自留有来源。外滩中央项目2012年起分期改造，包含美伦的第一期于2017年开业；其后加设的玻璃穹顶覆盖楼间十字街区。[2013年照片](https://commons.wikimedia.org/wiki/File:Meilun_Building_Shanghai.JPG) · [转角细部](https://commons.wikimedia.org/wiki/File:美伦西楼转角处.jpg) · [2019年161号全景](https://commons.wikimedia.org/wiki/File:161_East_Nanjing_Road_Shanghai.jpg) · [街区分期](https://www.peopleapp.com/rmharticle/30023515053) · [玻璃穹顶工程](https://www.thepaper.cn/newsDetail_forward_13633286)

既有底图中的具名面1562面积约1,976平方米，与OSM建筑1156620261的交并比为98.89%。核对274处地点的既有登记，本楼与已登记的替换轮廓交叠面积为零。最近的既有替换面是礼和洋行九江路立面，相距66.67米，其次是南京东路99号迦陵大楼，相距73.50米。街角对面是第三批3A008电力大楼，门牌南京东路181号，两栋原有轮廓净距12.14米。第五批5A030后续登记应关联本次西楼街面，南楼及西楼其余范围继续保留。[具名轮廓](https://www.openstreetmap.org/way/1156620261) · [门牌、足印、照片及逐项依据](reference-review.json)

## 西北转角实物初稿

西北斜角在底图上由2.60米和3.27米的两条短边构成，两端直距5.52米。南京东路的整条源边长51.61米。照片能辨西北角石墩、斜面中间上下两组宽窗、两侧窄窗、下窗三角楣和檐顶山花。几何初稿按上述斜面、南京东路方向紧邻的两间店面约12.8米、江西中路方向约7米取形。两档初稿分别有12,476及4,948个三角面，各18条射线核对凹入的玻璃、窗台上部石线和两道山花。更远的拱窗与柱廊、屋顶后退部分仍需另行定界。[转角地面量取](corner-study.json) · [初稿透视](corner-study-view.jpg) · [构件射线](corner-study-rays.json) · [逐件源码](source/meilun_corner.py)

在2018、2021和2024年发布的三期航片中复看西楼的街角、屋顶外边和邻接内街。较新的图层可见内街玻璃格架。年份指图层发布，窗墙尺寸来自街面照片。[图层地址与散列](roof-reference.json)

## 独立模型

模型保留南京东路两间店面、江西中路一间店面和斜角凹入入口。街口两道山花、宽窄窗组合、檐口栏杆和石墩分别成形。近景14,444个三角面，远景5,236个。屋面只作檐口以后约1.44米的收水构造，后部沿用已核底图。临街入口的净深按实照比例估计。[模型浏览与文件下载](../../../meilun-west-nanjing-corner.html) · [源面及邻体](footprint-review.json) · [落位与实拍](../../../data/audit/meilun-west-nanjing-corner-v1/README.md)
