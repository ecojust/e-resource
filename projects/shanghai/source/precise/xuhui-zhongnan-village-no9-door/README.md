# 中南新邨9号木门与气窗

市房管局第二批名录以“中南新村”登记淮海中路1670弄，编号2D010。徐汇区房管局2024年11月4日采用“中南新邨”一名，据施工许可材料记载住宅建于1941年，由中南银行投资、五和洋行建筑师浦镜清主持设计，2019年曾保护性修缮。老售楼广告可读到“新造”“霞飞路”“中南新邨”和“五和洋行”。区房管局记述当时仍有十一幢。2015年Commons照片的说明写1907年，与区房管局的年代有出入，照片拍摄时间则可由元数据确认到2015年1月26日。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [徐汇区房管局所附施工史料和实照](https://www.xuhui.gov.cn/zfjg_qzfbm_fgj_bmdt/20241104/546672.html) · [2015年弄内转角](https://commons.wikimedia.org/wiki/File:Zhong-Nan_XinCun_Shanghai.JPG)

区房管局“三种门上铁艺”拼图右上角留有绿色9号牌，底行可辨“淮海中路一六七〇…”字样。中南新邨9号的木门和气窗依照这一格制作，含八道竖板、气窗玻璃、两根纵杆、一根两侧向下折阶的横杆、左侧锁具和拉把。照片中的红纸属于当时住户的装饰。门扇底段超出照片画面，竖板按已有板面延续。门的宽、高、厚度及铜色五金比例均为估计。照片发表日期为2024年11月4日，拍摄日期没有注明。[实照](https://www.xuhui.gov.cn/zfjg_qzfbm_fgj_bmdt/20241104/546672/c110532346b745435a94fcd0a45e8836.png) · [逐项档案与影像签名](reference-review.json)

9号和相邻8号分户点沿最南一排双联住宅北墙排列，9号点与该墙轮廓相距约0.76米。原建筑对应OSM建筑面790827014和冻结城市源637。2022及2026两个发布期的正射图均可核对连续屋顶、北侧支弄和南侧院落。门轴在北墙的具体位置按分户标点估配。“9号楼”兴趣点的地址字段写淮海中路1690号，另一个“湖南路9号楼”点位于北侧不同楼体。2015年弄内转角照片里无法辨认门牌。辛笛旧居在21号，另有营业门牌可与其北侧位置核对。[OSM楼面](https://www.openstreetmap.org/way/790827014) · [保护区界](https://www.openstreetmap.org/way/493695214) · [地址与各期影像](reference-review.json)
