# 上海音乐学院专家楼底层双券与毛石拱饰

第四批优秀历史建筑 4D008 在汾阳路20号登记两栋建筑。花园住宅曾作比利时领馆，旧门牌汾阳路30号，现称专家楼。原犹太俱乐部位于其东北侧。1948年街区图分别标出了两栋。现状高空影像与街区底图可按各自的屋顶轮廓辨认。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [徐家汇周到刊载的历史图、园面全景和近照](https://www.sohu.com/a/701169882_121123697)

模型刻画花园侧同一平面的两个半圆券。中墩连续横石、每券两侧分开的径向凿面石和券顶三块冠石在近照中可逐组辨认。后方木门与前方矮栏分别位于不同平面。现有照片提供外观比例，样模每券净跨取2.32米，券体厚度约0.43米。这两项为制作估计。[原始照片及比例依据](reference-review.json)

图中窗廊处的屋檐与底图库外边相差约8米，树遮住墩脚。项目将两券作为独立构件展示，保留两栋在城区的原体。全部几何和材质由项目制作，引用照片依原出处署名。
