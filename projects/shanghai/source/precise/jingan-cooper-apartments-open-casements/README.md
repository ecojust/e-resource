# 古柏公寓中段上层外开窗与瓦檐

5B028在市表登记为古柏公寓，门牌富民路197弄。取Antigng于2017年8月19日从院内拍摄的古柏公寓，表现中段凸出窗间顶层的两扇外开分格窗、浅色粗抹灰墙和外挑瓦檐。

照片左窗扇投影较窄、呈棕色，右窗扇反射浅色天空；两扇之间露出暗色室内。 檐口有连续深色披板，下面显出几处短椽，屋面前缘轮廓有浅波。

原照看得到每扇的两道横档和打开后的阴影。两扇开启角、真实木材种类、檐的绝对悬挑与屋面完整坡度均未经测量，窗下后装设备遮住的构造未推定。
