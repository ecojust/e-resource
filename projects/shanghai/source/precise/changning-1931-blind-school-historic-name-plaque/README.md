# 虹桥路旧盲童学校1931年“盲童學校”横匾

上海市城市建设档案馆发布的《上海建筑百年》第十四辑记载，学校于1931年12月迁至虹桥路。学校篇第7分33秒展示标着“1931虹桥路旧址”的历史照片，四字横匾就在画面上端。正面可从右向左读出四字，中央“童”的墨色比其余三字淡，两侧细小题署保留可辨笔迹。斜面可分开浅色匾板的薄边和周围砖缝。近远档均保留字内留白。 [档案馆发布页](https://web.archive.org/web/20200915114300/https://m.sohu.com/a/291454159_120056521/?pvid=000115_3w_a) · [学校篇影片](https://v.qq.com/x/page/p083071ree2.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

横匾宽暂取2米，长宽比按档案画面校正。墨字的实际施作方法、砖与底板的原色和深度无法从黑白原照测定。 两侧的小字不足以辨认姓名。项目保存整理出的几何笔画，原影片供读者在发布方页面查阅。
