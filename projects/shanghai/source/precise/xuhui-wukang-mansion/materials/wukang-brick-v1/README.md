# Original brick material

Generated by agent from periodic mathematical noise and a running-bond pattern.
No photograph is read, copied, sampled or embedded by the generator. The color,
brick dimensions and wear are illustrative estimates; this is not a scan or a
measurement of Wukang Mansion.

The generator and its three output maps are offered under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- `brick-basecolor.png`: sRGB color; use a white material multiplier.
- `brick-normal.png`: linear tangent-space normal; suggested scale 0.65.
- `brick-orm.png`: linear data, R = 1, G = roughness, B = 0 metallic.

One repeating tile covers 1.984 × 1.184 metres. Use horizontal facade distance
divided by 1.984 for U, and height divided by 1.184 for V. Preserve the local
horizontal direction around curved surfaces. The normal convention and exact
image hashes are in `material.json`; do not invert its green channel without a
matching change to the mesh tangent convention.

Embed the maps in exported GLBs and pack them into the Blender file. External
workspace paths must not be required to open a released model. A release may
use project-relative source descriptors while retaining the exact map bytes.

For a deterministic rebuild, copy `generate_material.py` into a fresh output
directory and run it there with NumPy, Pillow and SciPy available. It creates
`maps/` and `material.json` beside the script and refuses to replace an existing
`maps/` directory.
