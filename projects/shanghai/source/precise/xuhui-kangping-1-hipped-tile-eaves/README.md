# 康平路1号花园住宅街角红瓦檐

上海市第四批优秀历史建筑名录的4D041行将康平路1号列作花园住宅。现有高安路14号的阿麦伦公寓位于路口另一侧。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

Livelikerw于2013年12月31日在交叉口拍摄该宅。底层屋面转角上有圆弧斜脊，脊瓦搭接，两侧的红瓦端头和深色水平檐沟清楚可见。模型截取转角两侧各16个瓦垄。局部的落叶、树木与街边设施属于当时环境。[现场照片与作者](https://commons.wikimedia.org/wiki/File:1_Kangping_Rd._Shanghai.JPG) · [照片许可](https://creativecommons.org/licenses/by-sa/4.0/)

以0.192米估计瓦垄间距，两段檐口各取3.072米。屋面进深、坡度和瓦片搭接均为估计值。楼体缺少精确到该段斜脊的测量，本模型作为独立构件浏览。[照片标定](reference-review.json) · [街口位置](placement-review.json)
