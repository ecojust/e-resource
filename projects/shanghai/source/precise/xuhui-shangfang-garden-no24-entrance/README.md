# 上方花园24号张元济故居弄门

上海地方志记载，1916年的沙发私园于1933年售予浙江兴业银行。上方花园住宅在1938至1941年间分期建成。张元济于1939年3月8日迁入24号，其三层住宅每层有两间朝南的房间，南面有小花园。[《上海名建筑志》](https://web.archive.org/web/20180616231651/http://www.shtong.gov.cn/newsite/node2/node71994/node81772/node81776/node81788/userobject1ai109112.html) [上海档案信息网](https://web.archive.org/web/20190511104012/http://www.archives.sh.cn/shjy/shzg/201203/t20120313_12732.html)

本件表现北面临支弄的低墙、门洞、文保铭牌、圆牌、九个读数窗的电表柜、外露导管与通风雨棚。2020年12月10日发表的照片拍到同一门和相邻钢窗。另一组到访照片能读到石质铭牌上的“张元济故居”，确切摄影日期未注明。电表、雨棚与铭牌按照片所示的使用状态制作。铭牌上的五字取自实物，字形按开源字体近似。[2020年图文](https://m.ctrip.com/webapp/you/community/detail?articleId=9018911) [铭牌近照](https://poi-pic-gz.cdn.bcebos.com/pic_df309e26895d7822134973a8728c7898) [全景及同巷其他材料](reference-review.json)

24号分户标点在原地图1934号住宅之内。署名故居的地点标注在该户临北弄边界外约1.73米处，23号标注在西面的4670号住宅。两期卫星影像可辨这一排住宅和支弄。门洞中心依据故居标注估配，明确边界限于这段低墙及雨棚。主楼、屋顶、南院和邻户保留城市底图。墙高、雨棚进深与具体门轴均未实测。[分户及原地形记录](footprint-review.json) [OSM分户轮廓](https://www.openstreetmap.org/way/1333502190)
