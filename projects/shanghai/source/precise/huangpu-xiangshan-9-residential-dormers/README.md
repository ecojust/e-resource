# 香山路9号住宅

2018年4月，黄浦区融媒体报道写道，香山路9号这幢两层洋房曾作《解放日报》集体宿舍。上海市第五批优秀历史建筑把该处登记为5A080。照片中能辨认出东小西大两座山墙老虎窗，夹在两者之间的较低屋面上还有两扇连窗。[区署报道](https://www.163.com/dy/article/DENTLSLA0514IGIT.html) · [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

临街抹灰墙二层有五处宽窄不同的窗口。模型结合冬季无遮挡的街面影像和2018年夏季的署名照片复原短窗台、窗眉、双段红瓦前坡、院墙柱帽和四瓣铸铁花。树枝遮挡和视点差异会影响量测。按共同投影深度估计，西段瓦檐比东段低约半米。屋坡背后的收口及不露出的墙身厚度属于估计。[五处街窗](measurements/five-main-wall-windows.json) · [两段瓦檐](measurements/two-main-eaves.json) · [老虎窗实测](measurements/dormer-stereo-recalculation.json)

9号和隔壁7号孙中山故居分别有门牌及登记资料。现有底图将它们画在同一大轮廓中，因此本模型独立展示照片可见的临街部分。[地址核对](measurements/footprint-review.json) · [构建源码](source/build_model.py) · [摄影与许可](SOURCES-LICENSE.md)
