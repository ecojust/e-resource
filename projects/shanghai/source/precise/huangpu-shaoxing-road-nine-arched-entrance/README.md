# 爱麦虞限路9号宅绍兴路拱窗与挑篷入口

上海市第四批优秀历史建筑4C021登记绍兴路9号，原名爱麦虞限路9号宅，今名上海昆剧团。2024年《上海发布》的建筑记述将落成年份列为1935年。2013年剧团在四年修缮后回到原址，新闻中的俞振飞昆剧厅位于二层。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2024年建筑记述](https://sh.people.com.cn/n2/2024/0319/c350122-40781065.html) · [2013年重开报道](https://ent.sina.cn/xiju/sandd/2013-08-26/detail-icfkptvx3113936.d.html)

临绍兴路的大拱窗和折面挑篷上下对正。拱窗下部四列玻璃各有一枚红色菱花，半圆窗内的直梃、横框在外侧券石处收口。篷下的两扇门向内退，门叶有相对的斜撑，篷底中央有一只圆灯。两侧窄长竖饰的头部有平行卷曲线。2026年10月2日源義信的两张署名原照分别记录拱窗全高和入口近貌，原作采用CC BY 4.0许可。[外观照片](https://commons.wikimedia.org/wiki/File:2026-10-02_No.9_Shaoxing_Rd.,_Shanghai_%E4%B8%8A%E6%B5%B7%E5%B8%82%E9%BB%84%E6%B5%A6%E5%8C%BA%E7%BB%8D%E5%85%B4%E8%B7%AF9%E5%8F%B7%EF%BC%88%E4%B8%8A%E6%B5%B7%E6%98%86%E5%89%A7%E5%9B%A2%EF%BC%89_01.jpg) · [近景照片](https://commons.wikimedia.org/wiki/File:2026-10-02_No.9_Shaoxing_Rd.,_Shanghai_%E4%B8%8A%E6%B5%B7%E5%B8%82%E9%BB%84%E6%B5%A6%E5%8C%BA%E7%BB%8D%E5%85%B4%E8%B7%AF9%E5%8F%B7%EF%BC%88%E4%B8%8A%E6%B5%B7%E6%98%86%E5%89%A7%E5%9B%A2%EF%BC%89_02.jpg) · [许可条款](https://creativecommons.org/licenses/by/4.0/)

门上法文字样的首行可辨为「CERCLE DE LA POLICE」。下行首字「FOYER」与末段「& DU SOLDAT」在两张照片中可以对照，中段笔画处于阴影。因此模型只制作可辨的字组，字形由OFL许可的Noto Serif CJK字体子集近似。窗框、挑篷、门扇、檐下竖饰和外墙均可独立编辑。

2020年2月22日同一路段的三处公共全景可交会拱窗轴线，另用2015年视图复核。四站合算的位置误差约0.68米。模型以具名OSM建筑的绍兴路长边为朝向，实测门轴较原城粗面后退约2.68米。图内范围约5.7米，仅包含这段可核查的入口。侧翼、厅内和院内格局由原城资料表示。[原建筑足印](https://www.openstreetmap.org/way/494404354)
