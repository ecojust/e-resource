# 集贤村金坛路35弄南弄口

上海市第四批优秀历史建筑4A037登记名为“集贤村”，地址为金坛路35弄1至30号、32至44号。金坛路北侧的南弄口朝向街面。2015年12月和2019年5月的街景均可认出浅弧额、正中键石、三格题名和两盏壁灯。2021年12月的区级修缮报道留下临街正面照片。整组建造年代据黄浦区房管部门为1933年，门楼自身的确切竣工年代尚待核实。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上观新闻的现场采访](https://www.shobserver.com/wx/detail.do?id=424219) · [上海黄浦的竣工照片](https://m.thepaper.cn/baijiahao_15894173)

模型呈现两根带台基、浅浮雕和叠边柱头的灰色门柱、浅弧形门洞、起伏冠檐、头部三格“集賢邨”、两块深红色竖牌及铁艺双扇。以2021年照片中西扇半幅、东扇向弄内开启的状态确定通行位置。竖牌小字在不同时期的图像里有变化，模型保留可辨的底色和细框。题字用近似字形逐字建模。[照片出处与年代](reference-review.json)

两台街景交会给出约3.2米的门洞净宽。门冠总高估计在5.1至5.9米之间，模型最高处约5.57米。金坛路21号住宅和35弄内部各幢的门牌属于不同层级。区级报道同时涉及金坛路15、17号和21号，街口定位依据正面照片、金坛路摄影站和原城两侧楼体。住宅、院内以及室内另列。[测点与误差](street-registration.json) · [重算两台摄影站的像素交会](source/verify_survey.py) · [原城足印与楼群余项](footprint-review.json)
