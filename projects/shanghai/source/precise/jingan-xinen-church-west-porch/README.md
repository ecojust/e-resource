# 新恩堂乌鲁木齐北路尖拱窗与门廊

静安区乌鲁木齐北路25号的新恩堂旧称上海公共礼拜堂。上海市房管局第四批名录将新恩堂、上海公共礼拜堂和基督教新教堂列为同一条4B022。陕西北路375号怀恩堂另有登记与模型。[第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2015年12月26日Fayhoo拍摄的西面照片清楚显示红十字、灰砖山墙、三分尖拱窗和浅色门廊。门廊正面三处矩形开孔各嵌一块暗底红字，依次为“新、恩、堂”，上方两行英文为“SHANGHAI FREE CHRISTIAN CHURCH”和“EVANGELICAL”。斜向街景能看到门廊南北两侧各开一券。模型留出两券之间横向可通行的地面。[Fayhoo原照片，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Xin%27en_Tang.JPG) · [2015及2020年的街景站点](measurements/survey.json)

以五处街景和一张带焦距信息的照片联合测量，建模取门廊宽7.32米、进深6.36米、廊额顶5.30米，西面山墙顶16.09米、十字顶18.22米。绝对平面位置的不确定度约0.9米，门廊宽约0.6米，进深约0.75米，山墙高度约1.2米。旧城建筑3149为偏至西廊北半的简化方块。当前几何至西山墙背后的短返为止，未从街上辨清的室内、翼部、其余礼堂屋面列为待查。[照片联算与残差](measurements/measured-facade.json) · [原城定位](footprint-review.json)
