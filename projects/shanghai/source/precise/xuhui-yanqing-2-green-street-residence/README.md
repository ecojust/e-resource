# 延庆路2号住宅

上海市房屋管理局第五批优秀历史建筑名录以 5D067 登记延庆路4弄2–44号及沿街2–6号（双号）。本模型取两处绿色“2”号牌所在的街屋。2015年6月21日的具名照片提供街面基准，同年12月多个视角补充树冠遮住的窗洞和墙面转折。坐标原点在绿色圆券门前地坪，X朝照片右侧，Y进深，Z向上，单位为米。

第一版可见实物包括中央弧形楼梯间、依楼梯斜升的三组窗、上部菱形线脚、折面凸窗、两层阳台、底层铁门及铭牌。相机登记、可见范围和几何复核见 measurements。建筑外观具有透视估算误差，院内各户及室内尚待独立资料。

## 临街楼体与屋顶

沿街立面宽约21米。楼梯间依实测转折曲线建立，六扇窗依所在墙面后退，入口铁栅、号码牌、左侧折面窗和右侧阳台分别成组。屋面包括临街三角山墙、竖向装饰板、红瓦前后坡、两端转坡和两组阶梯形白色烟道。2015年6月与2020年2月两个机位可共同辨认山墙尖和烟道顶。后檐位置按2010–2025年间四期正射资料估计，范围到沿街楼体约12米进深。后墙按确定范围收口，窗洞、房间与深入4弄的相邻连排住宅待补充资料。

近景、远景均可独立浏览或下载。可编辑 Blender 工程保留窗扇、阳台、烟道、瓦面、栏杆的分组和九个摄像机。三组循环颜色与法线纹理在本地按固定种子生成。复建材料、未压缩几何、压缩模型及检查步骤见源码 ZIP 根部 README。
