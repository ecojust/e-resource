# 恒利银行河南中路天津路转角入口与竖窗立面

现名永利大楼。第四批优秀历史建筑市表4A014列河南中路495号、天津路100号。现场2005年市政府保护牌同时列河南中路503号。2020年街头调查拍到了495号单位牌、503号酒店门和这块保护牌。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2020年4月分门牌现场照片](https://www.meipian.cn/2x4vfr9h)

恒利银行于1933年8月迁入华盖建筑师事务所设计的新楼。博物馆所刊原图把较高的中段安排在河南路一侧，斜角留作主要入口。早期的铜门与今天门上的“南京东路幼儿园”分属不同时期。模型依据2020年及2021年的门面，采用可辨的现状标识。[黄浦文博、上海市银行博物馆](https://www.sohu.com/a/840226051_121123854) · [Virtual Shanghai历史门牌607](https://www.virtualshanghai.net/Data/Buildings?ID=607)

天津路浅色窗区有六轴，河南中路有十八轴，两条街各有棕砖边跨。模型保留低窗、金属栏条、砖面折角、门楣层次、窗间突起、正面可核实的空调机箱与两面可见的退台窗。斜面门牌以小字号金字刻出，南向高处有竖排酒店字。2015年曾可见大型屋顶广告，2020和2021年照片显示它已拆除。其余屋顶设施、后院、内部营业厅与隔壁地块另列。[2015年2月18日街角照片](https://commons.wikimedia.org/wiki/File:No.495,_Middle_Henan_Road,_Shanghai.jpg) · [各原始图像与授权来源索引](reference-review.json)

现场窗宽、成排关系及三条街墙长度采用照片和原城足印交叉校准。三台2021年1月8日全景用于估算斜角主檐约19.35米，最高退台可见角约29.2米。材料厚度、部分构件进深和看不清的门雕保留估计。程序生成棕砖材质，编辑场景和近远网格共用同一原图。中文招牌使用附有OFL许可的字形子集。[足印与原城绑定](footprint-review.json) · [逐摄点量测](../../../data/audit/hengli-bank-henan-tianjin-corner-v1/preflight/street-height-measurements.json)
