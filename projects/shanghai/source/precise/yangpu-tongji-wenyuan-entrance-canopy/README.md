# 同济大学文远楼正门雨篷与三柱门廊

第四批上海市优秀历史建筑4G006列入四平路1239号的同济大学建筑群，文远楼居第一项。门前平雨篷下的三根圆柱从2015年正面和2018年斜面均可辨。近档与远档保留后排柱、门楣亮窗和三道台阶。绝对尺寸为照片估计。
