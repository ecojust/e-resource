# 四行储蓄会大楼（联合大楼）

上海市房屋管理局第二批名录登记为2A049四行储蓄会大楼，登记现名化轻公司，地址四川中路261号。第一批1A013也曾称四行储蓄会大楼，南京西路170号现为国际饭店，是另一处建筑。[第二批官方名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [第一批官方名录](https://fgj.sh.gov.cn/yxlsjz/20200331/fe7b4d6f35774b708a2c5122849065bd.html)

大陆、中南、金城和盐业四家银行合力出资，四川中路这座建筑于1928年完工。两层高的白色石座托着四层褐砖窗墙。转角入口的拱洞、金属格栅、扇形气窗、石栏、上层券窗和八角塔冠，取形于2014年刊出的街面照片与2019年航拍。修缮报道还说明了石柱上的直槽、深色泰山砖和半地下室窗。[2014年街角与细部](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102vb74.html) · [2019年航拍](https://commons.wikimedia.org/wiki/File:联合大楼·四川中路·航拍.jpg) · [新闻晨报2024年实地报道](https://view.inews.qq.com/a/20240506A06AFJ00) · [来源散列与拍摄说明](reference-review.json)

长立面向四川中路，短立面向汉口路，八角塔下的斜切门廊朝交叉口。近、远两档都保留向内凹入的门窗、四瓣塔窗、挑檐和屋顶退台。约50米的总高采用文献值，层间标高与屋顶背部依照片估计。西、北共有边界作为素墙收口。模型涵盖建筑外观。[选址与五处同组邻楼](footprint-review.json)
