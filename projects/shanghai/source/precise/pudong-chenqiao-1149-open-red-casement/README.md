# 陈桥村1149号东墙外开红窗与水刷石窗洞

5W043在市表登记为住宅，门牌川沙新镇陈桥村1149号。Dragon在2023年5月21日拍摄陈桥村1149号，原文把东立面与相邻1156号分节。东墙近照显示左扇向外开启，右扇合拢，露出的固定细杆在窗扇后面。两扇红漆木框各有两道细横档，窗洞侧面呈青灰色粗粒表面。

打开的左扇可见旧红漆磨损处，右扇留在窗洞内。内侧三根细竖杆清楚露出，另可见横向连接杆。 窗顶有层层外挑的浅色压线，右侧粗粒窗洞收在凸出的窗台之上，外墙有仿块石的横缝。

1149号由独立章节、东立面题注与同组市级标牌共同定位。左窗开启角、窗梃和粗粒面的厚度按照片估计，屋内只用暗面表示透过格杆可见的暗部。
