# 新华村14号楼的四座老虎窗

上海市第三批优秀历史建筑名录将愚园路1320号新华村的长宁区政府14号楼列作3M004，同址的11号、12号与15号均有独立子号。长宁区规划和自然资源局记载这组英式花园住宅建于1925年。模型选取14号楼朝南的前坡、四座单坡老虎窗、三支烟囱和檐下上层廊栏。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [区级建筑资料](https://www.shcn.gov.cn/col7698/20211206/1118301.html) · [独立查看模型](../../../xinhuacun-14-dormer-roof.html)

高参88于2014年发表的文章将图16题为“长宁区政府14#楼”，原图281×270像素，拍摄日期未标。开诚布公在2026年发表的图21呈现相同的四座老虎窗、三支烟囱及后方两处高顶。后一期能辨出每樘四扇，单扇有一道竖梃、三道横梃。屋瓦在窗根折向披水，窗侧的三角灰面伸向后坡。前檐下可见砖墩、弯曲托臂及托脚。上层院廊在早期照片装窗，模型沿用2026年照片的敞廊状态。[带楼号题注的图16](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480101iqnm.html) · [院景图21](https://www.meipian.cn/5p7rb1d6) · [两图与楼号的数值出处](measurements/roof-photo-sources.json)

2019年及2025年的航片分别量得南檐约22.2米、22.5米，2019年可辨的四座窗最外两中心相距约14.8米。网格对应为22.13米及14.98米。两张地面照均接近正面，窗进深约1.66米、屋脊相对前廊线后退约5.74米，这两个尺寸取决于机位拟合。七个留出像点的偏差，旧照约1.4至3.2像素，新照约2.8至12.1像素。近网376个闭合构件、5,716个三角面，远网335个闭合构件、4,576个三角面。34处独立材料读数中，28处正中，32处位于五个原像素内。2026年第一窗右侧灰面和第二窗下槛两束落在瓦面上。[摄影机与留出点](measurements/roof-registration.json) · [独立材料读点](measurements/roof-material-checks.json) · [托臂近量](measurements/pier-bracket-details.json)

地图节点将保护编号M-Ⅲ-04与名称“长宁区政府13号楼”一同记录。该节点位于原城市户474内。11号楼的独立节点在1617号户，两户中心相距50.16米。两张地面照背后较高的红顶缺少独立高度与斜距，归属仍待核实。侧后面、下层院廊与室内留待后续测绘。独立页面可查看九个机位、两幅摄影位自渲图及八种下载。[原地图节点](https://www.openstreetmap.org/node/4812467689) · [两期正射与原户记录](measurements/number-14-and-owner-474.json)
