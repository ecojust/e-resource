# 良友公寓多边形楼梯井与折角木扶手

5D010在市表登记为良友公寓，门牌永福路68号、复兴西路91、93号。市表永福路68号、复兴西路91及93号良友公寓。上海房管的俯照、扶手侧照和台阶特写显示不规则折边的楼梯井、赭红木扶手、黑色细栏杆和马赛克踏面。据此截取一层连续的梯段与转折平台。

俯照能追踪赭红扶手沿狭窄井口折向，与平台相接的短边向内收。右侧和左侧梯段由栏杆和数道踏步分隔。 侧照可辨竖向黑铁杆、上下横杆和浅色混凝土梯梁；照片306.jpg近照显示踏步方形马赛克与前缘浅色横带。

俯拍存在透视收缩，模型的井宽、坡度、每跑级数以及楼板厚度按可见比例估算。公共墙面、其他两部楼梯和上层重复部分超出此次截取范围。
