# 新泰仓库东翼红砖壁柱与两跨券窗

新泰路57号仓库的东面由玻璃连廊分成两翼。右手六跨以短窗和长窗交替。这件模型取右端两跨，三层砖墙都有浅弧券。短窗下的红砖裙墙收在两端的砖脚上，旁边的长窗下接浅色石台。最外一根红砖壁柱转到端面，首层砖缝也绕过同一转角。[2020年城市考古文章和门牌照片](https://m.thepaper.cn/newsDetail_forward_8535508) · [高参88的新泰仓库组照](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102vrg2.html)

两跨净取宽约7.50米，檐顶约11.40米，端面保留1.12米。洞侧墙厚约0.485米。绝对尺寸与纵深均为照片估计值。底层最右侧受树木遮挡，门扇依据同翼可见开间，门把形状属近似。屋顶、后翼和室内属于本件截取边界以外的建筑范围。市级第四批名录将新泰路57号列为4H001。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

网格原稿与网页近景各18,962面，远景9,847面。作者根据2020年正照的砖柱轴线、洞顶和窗台定形，再在独立的690×518像素园面照片上，用窗外的门槛与腰线估摄影比例，比较四扇窗的12个券顶、横档和窗台。三档各自的竖向均方根误差都是1.36像素。每档另有182束射线实查玻璃、压条、门把、券砖、窗台以及端墙凹槽。[两期来源与遮挡记录](reference-review.json) · [独立照片测量](../../../data/audit/xintai-warehouse-brick-corner-v1/independent-photo-fit.json)
