# 月村江苏路480弄双号牌门柱

WQL于2018年1月25日拍下月村弄内入口。左侧方石柱上部黄铜色牌的黑字是“68”，其下小字是“江苏路480弄”。下方蓝牌末行另写“江苏路480弄66号”。本模型呈现照片拍摄时的两牌及其石柱。上海第四批优秀历史建筑名录将66、68号同列在月村八个门号中，另记90号新公房除外。[2018年原照及署名](https://commons.wikimedia.org/wiki/File:月村-上海市房地产协会.jpg) · [上海市房屋管理局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

门柱上端有斜帽、底面线脚和一层突出的腰带。黄铜色牌有退角、两枚凸起的固定件及两个黑数字，字面的周围发绿。石面横缝、柱脚潮痕和蓝牌下方的浅色残迹取自同时的影像观察。柱背和构件绝对尺寸按比例补足。两块牌各自的设置年代和院内住宅逐栋的门牌对应仍缺少资料。
