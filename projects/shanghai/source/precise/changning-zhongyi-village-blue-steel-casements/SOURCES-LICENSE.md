# 来源与许可

WQL拍摄的《Alley 46, Jiangsu Road.jpg》摄于2018年6月14日，许可为CC BY-SA 4.0。资料夹中的窗组图截取原照片像素范围（950，660）至（1920，1380）。三幅照片与模型并置图作了进一步裁切、缩放和排版，照片及并置图沿用CC BY-SA 4.0。模型的砖面纹理为程序绘制。[WQL原照](https://commons.wikimedia.org/wiki/File:Alley_46,_Jiangsu_Road.jpg) · [许可全文](https://creativecommons.org/licenses/by-sa/4.0/) · [裁切位置](measurements/primary-crop.json) · [三幅并置图记录](measurements/photographic-comparisons.json)

Antigng于2014年4月30日拍摄的《中一村3.jpg》用于核对住宅群的外观。照片采用CC BY-SA 4.0。46弄两樘窗的尺寸比例与开启状态取自WQL的照片。[Antigng原照](https://commons.wikimedia.org/wiki/File:中一村3.jpg) · [两张照片的原件摘要及相机记录](measurements/building-and-photographs.json)
