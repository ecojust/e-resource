# 中一村江苏路46弄住宅青色钢窗与立砖窗楣

2018年6月14日，WQL从江苏路46弄里仰拍了沿弄住宅。二层一扇绿钢窗向外开启，玻璃中映出灰绿色；它旁边闭合的窗扇后透出蓝色。弄内树木遮挡了其他窗位。上海市第四批优秀历史建筑名录把46、54、62、70、78弄共同登记为「中一村／中央一村」，编号4M004。模型选取主照中相邻的两樘窗，以及两窗之间的清水砖墙。[打开模型](../../../zhongyi-village-blue-steel-casements.html) · [2018年原照裁切](measurements/wql-steel-window-pair.jpg) · [资料、日期与作者](measurements/building-and-photographs.json)

两窗各有一段立砖窗楣。正射校正后，每段能读出17条边界，界定16块立砖。窗间墙每皮交替出现较短的丁砖与较长的顺砖，相邻两皮错缝。以右窗洞高1.55米估算，原照能分辨的14个砖皮间距中位数为8.19厘米，丁砖、顺砖连同灰缝的长度中位数分别约为16.5、34.8厘米。模型保留了各砖之间的灰缝、洞口内的砖边和斜石窗台。[窗楣砖缝](measurements/soldier-joints.json) · [窗间墙砖皮](measurements/brick-course-measurement.json) · [照片与模型并置](study-views/header-and-stretcher-pier.jpg)

## 窗扇与比例

照片保留了相机的28毫米等效焦距。根据右窗四角与两组立面消失点校正画面，左窗转轴和自由边的四个角给出约32度的开启角。在另外16条有清楚色差的水平扫描线上，投影中钢扇自由边与原照的均方根偏差为2.68像素，最大约4.48像素。窗洞实际高度仍待测绘，公制长度均随采用的1.55米窗高变化。把手、铰节、抹缝深度和隐蔽窗框厚度依据可见轮廓简化。[相机控制点](measurements/two-window-camera.json) · [窗扇独立对照](measurements/independent-free-edge.json) · [开启扇近照与模型](study-views/outward-leaf-and-rebate.jpg)

## 模型与位置

近景模型有14,900个三角面、94个可编辑组，远景有9,836个三角面、86个可编辑组。砖纹为程序生成。三个导出网格各做197次几何检查，覆盖立砖、灰缝、四扇窗的玻璃及横档、铰链和石窗台。两档各有七张核查视图。[建模源码](source/build_model.py) · [沿弄照片与模型](study-views/alley-and-window-pair.jpg) · [几何检查](../../../data/audit/zhongyi-village-blue-steel-casements-v1/preflight/geometry-rays.json)

中一村地图院界内有七处原有房屋轮廓。46弄地址靠近其中一排，照片尚不足以判定这对二层窗在该排的位置。因此模型单独展示，主图保留七处既有房屋。[地图核对](measurements/lane-46-and-original-rows.json) · [来源与许可](SOURCES-LICENSE.md)
