# 东照里八号门柱与菱形院墙

上海市第四批优秀历史建筑名录将山阴路133弄列为4F022，原名日照里，现名东照里。相邻名录4F021的地址为山阴路69弄、85弄。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

Fayhoo在2015年4月12日拍摄的弄内照片，近处右侧门柱的绿牌可读数字8。柱身有横缝，上端逐层出挑。左接的院墙有一块带浅斜边的菱形浮面，深色墙脚上另有窄压边。[原照片及CC BY-SA 3.0许可](https://commons.wikimedia.org/wiki/File:Rizhaoli.JPG) · [出处及取点](reference-review.json)

这段院墙按照片比例制作。门柱高度约2.41米，墙厚及石材背面据可见边估算。照片中的树遮住菱形面左端一角，小牌下行字也难以逐字辨认，展品只写可读的8。[位置说明](placement-review.json) · [制作程序](source/dongzhao_wall.py)
