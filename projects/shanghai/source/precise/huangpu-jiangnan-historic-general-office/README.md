# 江南制造局旧址总办公楼（西公务厅）

上海市第二批优秀历史建筑名录在黄浦区 2C014 项并列登记总办公楼、2号船坞、指挥楼和飞机车间。高雄路2号是原厂区门牌。市文旅局的建筑说明将西公务厅记作坐北朝南、两层砖木结构、凹字平面，东西约89米，南北约56米，两端各有挑出的门廊。原厂2008年迁至长兴岛，旧址随后纳入世博会浦西片区。上海市档案馆2025年记述确认总办公楼留在原址。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [市文旅局文物资料](https://www.meet-in-shanghai.net/cn/shanghai-cultural-relics-protection-unit/the-former-site-of-the-jiangnan-manufacturing-bureau-286306/) · [市档案馆资料](https://m.thepaper.cn/newsDetail_forward_30796895)

模型对应今天经六路与西藏南路之间、龙华东路北侧的三翼建筑。OSM 441873546 的2017年版本带有保护号 2C014，与上海底图 14-13720-6696 中的 1335 号相交面积占两者并集的98.74%。2021和2024年发布的航片均可见朝北开口的院落、三段连通的红褐瓦顶、南正面的两座小门廊。通用园区地图标记位于本栋以南约两百米。[原始OSM对象](https://www.openstreetmap.org/way/441873546) · [地块与方位](footprint-review.json) · [两期航片实取记录](roof-reference.json)

2013年9月26日、2015年12月7日和2021年1月6日的龙华东路照片可见浅色抹灰、两层窄窗、深色窗扇、方柱平顶门廊、檐下线脚和缓坡瓦顶。模型用有深度的窗洞、窗框、台阶、门廊柱和分面瓦坡表现这些特征。2021年图中树木遮住部分首层，窗距、树后窗列及院内回翼按可见部分估算。2003年报刊曾记载1921年的总办公厅，现存各翼的完整建造年代仍需逐栋档案确认。[街面原图实取记录](street-reference.json) · [高清立面细部](facade-photo-reference.json) · [几何估算参数](source/parameters.json) · [沿革与资料范围](reference-review.json)

登记点附带的2008年带五角星和古典柱式的照片，其原说明指向指挥通讯楼，2026年同题实拍亦标为海军司令部旧址。总办公楼本次只制作建筑外立面和屋顶，其他受保护建筑各自另有实体。模型的原创几何、材质及代码按仓库 MIT 许可发布，OSM 派生平面遵循 ODbL。照片以来源链接和摘要保存。[2008年原图说明](https://commons.wikimedia.org/wiki/File:A_southern_style_fixer_upper%3F_(2620460813).jpg) · [2026年图注](https://www.thepaper.cn/newsDetail_forward_33429182)
