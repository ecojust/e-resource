# 新华路236号住宅的木格山墙、双老虎窗与砖烟囱

上海市第三批优秀历史建筑名录以3M015合列五处花园住宅。本件对应新华路236号，在社区复兴规划的图4中为5号，在图12版面左上。邻户248号在同图中分别为4号和另一张照片。规划给236号的建筑面积为292平方米，用地766平方米，组表记建于1930年。高参88在2014年文章中记录建筑面积389平方米、占地772平方米，称建于1930年前；两个口径仍待原图纸核定。 [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [长宁区新华路老洋房社区复兴综合规划第4、12页](http://www.dayuehs.com/pdf/xmyh02.pdf)

2014年发表的花园入口照中门牌可读作236号。同期刊出的有叶、无叶两张斜面照片和规划册照片均可认出向花园伸出的木格山墙、小单坡老虎窗及其旁的较宽老虎窗。无叶照片还能辨出东侧高烟囱、两侧高低不同的坡顶与上层廊窗的横竖分格。窗式空调等后来添置设备另见原图。原照片版权归各权利人，公开测量使用源地址、摘要及人工标注像点。 [高参88原文与具名图片](https://blog.sina.com.cn/s/blog_5d1bdf480101ifu3.html) · [来源记录](measurements/photographic-sources.json)

2019年和2025年正射影像中，两期可读瓦面与原城市建筑3422分别重叠97.82和105.04平方米，各占该期所绘瓦面的83.40%和76.33%。原图编号与248号的相邻屋体2491可分别核对。两期均受树冠和影像位置误差影响。 [两期原影像和读点](measurements/two-period-visible-roof.json) · [原城建筑和规划图位置](measurements/236-and-248-candidates.json)

## 花园侧与屋顶的复核

向花园突出的山墙上部镶有深色竖木和斜撑，下面是有栏板的转角廊窗。较小的单坡老虎窗开在前翼坡面，较宽的一只开在稍后的主坡面，两者在屋谷两侧。无叶时可以辨认贴在高墙外的砖烟囱、缩颈和顶端叠涩。右侧低翼的山墙朝向不同于左侧木格山墙。低翼、烟囱与主瓦坡保留各自的屋脊方向和前后次序。后方和树冠下无法看清的墙面采用简化封面。

三组相机配准分别使用690×481、690×518和439×329像素的原图。无叶照片以14个像点拟合，5个留检点的均方根残差为5.52像素；有叶照片用10点拟合，5个留检点为15.04像素；规划册图版用8点拟合，4个留检点为16.27像素。高差以假定的6.40米檐高建立。三视角在角窗、檐线和老虎窗梃处仍有偏差。逐图投射到近远原网，各档33点中有25点首先命中所标材料，其余8点的实际命中随记录列出。 [三组相机与留检](../../../data/audit/xinhua-236-english-garden-villa-v1/control/three-photographic-stations.json) · [逐点首击](../../../data/audit/xinhua-236-english-garden-villa-v1/control/mesh-photo-check.json)

近档由192个闭合正体积构件、2,808个三角面组成。远档合并窗框及远处窗梃后保留142件、2,424面。屋瓦和烟囱顺砖纹理均由程序生成。可编辑工程独立重开后复核了192组、9种材质、924个纹理顶点角和6台摄影机。源码压缩包可在无网络环境重建两档原网，并逐字节得到相同SHA。 [普通建筑页](../../../xinhua-236-english-garden-villa.html) · [两档解码检验](../../../data/audit/xinhua-236-english-garden-villa-v1/assets/encoded-and-decoded.json) · [Blender 重开](../../../data/audit/xinhua-236-english-garden-villa-v1/assets/verify.json)
