# 华一印刷股份有限公司旧址竖槽女儿墙与砖填窗间

5G017在市表登记为华生印务公司/华一印刷股份有限公司，门牌榆林308-312号（双号）。2015年榆林路308号临街照片中，上层钢窗以上的灰色女儿墙布满竖向凸槽，窗下为灰色窄肋分开的红砖填面。这里取原照中上排相邻两扇窗及其上、下收边。

女儿墙顶的凸槽终点不齐，槽脚在钢窗顶边逐级收小。窗上部分以较深横档分成一排亮子。 窗台下的窄长红砖填面可见错缝，中间细混凝土肋贯穿砖面，较宽结构柱位于两窗交界。

资料将历史名称写作华生印务公司及华一印刷股份有限公司。取景可核到临街一面，截段宽高和凸槽进深为照片比例估算，空调机、店牌和线路不在建筑构件内。
