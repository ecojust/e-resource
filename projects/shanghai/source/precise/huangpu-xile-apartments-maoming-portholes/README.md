# 希勒公寓茂名南路三层圆窗与悬挑阳台

在茂名南路116号入口对面朝西看，二至四层有两列圆窗，之间为三层悬挑阳台。这个模型取南列的三扇圆窗，以及紧邻其北、仍为开敞空间的半跨阳台。原街面一层、两端立面、北半跨封窗、五层和屋面保留在主图原建筑中。

临街的小面砖做平缝排列。圆窗有仿石外圈、向内收的窗套、深色金属框和内嵌玻璃。阳台的浅色实心栏板向南侧折回，上方有两道细铁杆。阳台后墙离前缘约2.5米，门窗和邻接玻璃侧窗从斜向可见。三层楼的窗心分别高约5.87、9.14和12.43米。绝对位置、标高、构造尺寸均为照片估测。

第四批优秀历史建筑名录把茂名南路106–124号和南昌路179号登记在同一项。2024年上海黄浦资料中的俯视图将两幢建筑分别勾出，希勒公寓位于茂名南路西侧长形沿街楼，爱达公寓占南昌路口的切角。现用单元底图为 w488956321，原城要素为111。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [两楼位置及历史资料](https://sghexport.shobserver.com/html/toutiao/2024/06/15/1352037.html) · [高亦寒的街面与门牌照片](https://www.meipian.cn/49khinbe)
