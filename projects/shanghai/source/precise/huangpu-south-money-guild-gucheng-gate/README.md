# 沪南钱业公所古城公园南面三券砖雕门楼

沪南钱业公所1883年建于上海老城厢北施家弄133号。2000年旧改时，工匠测绘、拆解并编号保存构件。2002年建设古城公园时在园内复建，2004年1月底开放。模型位于迁建现址。上海市民政局记载的约80%是整座院落采用原构件的比例，单块门石的年代尚待构件档案指认。[市房管局第四批4A039](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海市民政局资料](https://mzj.sh.gov.cn/lnb-wsws/20250609/c158937974bb47a9b1ae440e54df9c6a.html)

古城公园南面有三道石券，正中门额六字从右向左读作“滬南錢業公所”。独立门额近照显示上下浮雕带、边框和逐字底板，公园南侧正视可见关合的双扇、双环、石阶和中央门枕。两处高视点提供门楼瓦垄、三组翘檐和后部厅院之间的关系。模型保留门楼和附檐，人物带与花叶按可辨剪影概括。前庭两座石狮、竹篱、室内和内院留待单独记录。[2014年门额近照](https://commons.wikimedia.org/wiki/File:%E6%B2%AA%E5%8D%97%E9%92%B1%E4%B8%9A%E5%85%AC%E6%89%80%E9%97%A8%E9%A2%9D.JPG) · [2015年南面正视](https://commons.wikimedia.org/wiki/File:Hunan_Qianye_Gongsuo_-_2.JPG) · [2015年西侧高视](https://commons.wikimedia.org/wiki/File:Hunan_Qianye_Gongsuo_-_1.JPG) · [2020年南侧航照](https://commons.wikimedia.org/wiki/File:%E5%8D%97%E5%B8%82%E9%92%B1%E4%B8%9A%E5%85%AC%E6%89%80%C2%B7%E6%B2%AA%E5%8D%97%E9%92%B1%E4%B8%9A%E5%85%AC%E6%89%80%C2%B7%E4%B8%8A%E6%B5%B7.jpg)

原城门楼所在建筑为14-13721-6694的1173号。南边长约19.41米，配准中心与开放地图主入口点平面相差约1米。照片估计三门轴间隔约4米，中央石券内顶约3.91米、门额中心约6.09米。2015年地面照片的12个边点重投影均方根约2.29像素。抬高的门楼正檐在门墙以外，高度区间比石券更宽。后部建筑和邻栋均沿用原有城区资料。[位置及底图输入](footprint-review.json) · [照片归属与时间线](reference-review.json) · [摄影标定](source/elevation-registration.json)
