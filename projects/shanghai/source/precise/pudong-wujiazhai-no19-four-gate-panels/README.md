# 大洪村吴家宅19号正门的四块灰饰与层叠门额

5W039在市表登记为吴氏民居，门牌川沙新镇大洪村吴家宅19号。市表5W039登记为吴氏民居。Fayhoo于2019年8月18日拍摄的同址街照题为“凌梦周宅 大洪村吴家宅19号”。本件取正门的白色门额，三块下部灰饰排成一列，上方另有一道长灰饰，最下为两端收折的石梁。

正对门额能见两块窄长竖饰夹着一块较宽的矩形灰饰，上方还有单独一块横条形灰饰。四块各有窄边。 灰饰下方横梁两头有翘落的石端，开门洞两旁为白墙。上方另有多道伸出的灰白线脚，本作截取到深色瓦檐之下。

名录与照片均写大洪村吴家宅19号，名称随各自来源记载。现有资料不足以说明吴氏与凌梦周的权属或居住关系。远照可辨灰饰数量、宽窄和边框，中心纹样仅表现灰面；不猜题字、图案和具体石种。
