# 襄阳公寓顶层折纹饰带与悬垂边柱

5D006在市表登记为襄阳公寓，门牌襄阳南路254号。取襄阳南路254号公寓的屋顶局部。两根较高的墙墩夹着一列重复下折纹样，饰带下为密布短托的深暗水平缝。墙墩石帽以下各有三条长短不同的垂饰。

边柱的帽口分成两道，柱心上缘稍高，三条竖饰的中央一条拖长。分隔窄条、台阶形顶沿和檐下间断托块将各面格连成整段。 饰带每格有多道折点向下的平行浅条，照片中侧光让凸面和退进的阴影分开可读。

2018年原照从街面向上仰拍，树冠和外搭雨篷遮挡下部。宽高、折条截面和支承进深均依可见比例估计。
