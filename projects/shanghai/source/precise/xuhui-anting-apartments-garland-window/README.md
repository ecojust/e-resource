# 金司林公寓安亭路底层南窗与垂花饰板

市房管局第四批名录4D036列「金司林公寓」，今名安亭公寓，门牌为安亭路43号。街道另一侧的46号安亭别墅另列4D037。这里选取43号底层两扇带弧形山花的窗中靠南的一扇。窗下的石饰板独立嵌在错缝褐红砖墙内。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

Antigng于2018年2月7日从安亭路斜拍整楼。南窗能辨两扇钢窗各两列四排透光格、山花两端的下垂端块及窗台。下方饰板上有两端系结的叶串，中央另有花饰。山花内中央的束腰形饰与两侧卷草，依照片可见的轮廓制作。架空线遮住的细节和雕饰厚度由相邻可见部位估计。[现场原片](https://commons.wikimedia.org/wiki/File:%E5%AE%89%E4%BA%AD%E5%85%AC%E5%AF%93.jpg)

2015年与2020年的沿街视图可对照山花、饰板和南墙角。2020年相距约10米的两处站点给出窗净宽约1.20米、窗高约1.63米、饰板宽约1.22米和高约0.55米。用同一墙体的南角校准，窗轴位于距墙角约2.65米处。石材厚度、窗框进深和材料颜色依据斜照估计。[街景逐点计算](measured-window.json) · [现场照片与日期](reference-review.json)
