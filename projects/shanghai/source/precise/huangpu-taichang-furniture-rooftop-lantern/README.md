# 泰昌木器公司转角屋顶亭的穹顶与叠檐

上海市黄浦区南京东路740号。南京东路740号转角的敞亭。低圆穹顶压在数层折线石檐上，街面几根细柱之间留空；柱下的斜台上有浅浅的折面装饰。

以2016年具名全幅照片及其屋面局部为几何依据。亭檐估宽约2.1米，曲率、进深及相邻柱距按照片比例近似。店侧街摄只能核门面；背面被遮的柱列、设备和广告牌均未复原。
