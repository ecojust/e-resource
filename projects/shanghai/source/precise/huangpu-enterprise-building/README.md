# 企业大楼 · 原中国企业银行大楼

上海市房管局第二批优秀历史建筑2A046在四川中路33号登记企业大楼，公布时使用单位栏为轻工业局。工作名录以“创业大楼”为公布名，现状入口也悬“创业大楼”四字，外墙与街坊轮廓均可对应同一栋建筑。[登记、历史资料与入口实照](reference-review.json)

上海市文化和旅游局「建筑可阅读」记载，1931年建成的八层办公楼采用黄褐色毛面砖，沿街七开间，由竖向壁柱联系各层。上海市银行博物馆介绍，哈沙德设计图名称为“Office Building For Lieu-Ong-Kee”，原先按刘鸿生办公楼设计，馥记营造厂承建。中国企业银行在一层营业，开滦售品处及工业企业等分用上层，1931年11月12日举行银行开幕典礼。维基及地图标签另记1920年、九层，项目保留此项差异。[历史来源和年代辨析](reference-review.json)

独立模型包含东向街墙、通高底层窗、中央后退门洞、窗裙几何凸纹及山字形阶梯女儿墙。2020年冬和2023年夏的四川中路实景、2015年照片与银行博物馆门面照片共同确定正面。市文旅局记相邻为会德丰大楼与经租大楼，对街后来建有联谊大厦。东面高楼给航片上后部屋顶的识别带来遮挡，背墙和屋顶服务带作简化。原银行大厅与长期租用者的内部空间另待资料。[具名地块、邻楼及三期航片](footprint-review.json) · [独立模型页](../../../enterprise-building.html)
