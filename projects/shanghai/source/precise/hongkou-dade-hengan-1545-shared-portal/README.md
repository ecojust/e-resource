# 大德里与恒安坊四川北路1545弄题名过街门

市房管部门第四批名录将永丰坊、大德里、恒安坊合列为4F012。四川北路1545弄的过街门由大德里与恒安坊共用，门额并排写着两处弄名。永丰坊另开四川北路1515弄。[第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [高参88的街门及弄内实照](https://blog.sina.com.cn/s/blog_5d1bdf480102vru7.html)

高参88的近照可辨石额上的六字、两侧绿色1545弄牌和下收的阶状曲托。Fayhoo在2015年7月5日拍的街景记录了同一入口在华煌书店与隔壁店面之间的位置。左栅门后方露出弄口。项目依两幅照片重建街面这一跨，采用2.64米的估算净宽。沿街其余商铺、弄内住宅及楼层空调罩均在模型范围之外。[2015年街景，Fayhoo，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Dadeli,_Heng%27anfang.JPG)

开放字体近似题额与绿牌的可读文字。石额、左右曲托、门垛、铁栅和铭牌各可在工程中单独编辑。绿牌的小号附注、门后纵深及背面室内缺少可辨资料。[比例与尺寸来源](photographic-proportions.json)
