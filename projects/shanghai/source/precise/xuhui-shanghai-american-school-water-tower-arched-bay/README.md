# 美童公学水塔顶层砖券窗与挑檐

上海市第四批优秀历史建筑名录将衡山路10号的宿舍楼及水塔列为4D026。同址的主教学楼另列2D020。校方记载1923年迁入贝当路校舍，1939–1940学生手册将两栋宿舍、管理楼、餐厅等分别列出。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [校方沿革](https://www.saschina.org/about-sas/our-history) · [学生手册](https://archive.org/details/shanghai-american-school-student-handbook)

水塔顶层的照片刊于上海市美国问题研究所2023年3月13日发布的《海派城市考古｜美童公学》。可见面中央是一扇细长砖券窗，上部装水平百叶，下部呈蓝绿色。两侧壁柱托住向外叠出的檐口，檐后露出低坡屋面。原文另刊1930年代校园鸟瞰图。[原文](https://m.thepaper.cn/newsDetail_forward_22259828) · [水塔原图](https://imagepphcloud.thepaper.cn/pph/image/242/310/170.jpg)

模型依照照片上檐、窗和砖壁柱的比例搭建。顶层墙宽取4.4米用于统一展示，券后深度、砖块尺寸和屋面局部进深为外观近似。现有影像未提供可核实的实物尺寸和朝向。作品为独立外观研究，砖纹由程序生成。外部照片仅保留原刊引文和影像摘要。
