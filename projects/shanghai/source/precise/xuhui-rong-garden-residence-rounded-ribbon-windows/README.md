# 荣氏花园住宅园面双层圆端带窗

上海市第四批优秀历史建筑名录以4D038登记高安路18弄20号荣氏花园住宅，使用单位列为徐汇区少年宫。同名的陕西北路186号住宅登记为4B002，高安路63号另列励氏花园住宅。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2015年10月7日，Fayhoo从花园草坪正面拍下主楼。正照左翼的两道水平长窗各跨一层。靠近中央阳台的一端以半圆收头，浅色窗套贴着圆端，上缘遮阳板绕向外侧房角。两段钢窗之间隔着一道较宽的浅色窗墩。2022年刊载的同一花园面照片保留了这组窗与中央凹廊的位置关系。[Fayhoo 的正面照片，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Children%27s_Palace_of_Xuhui_District.JPG) · [康康茶室的花园正照](https://static.oldkids.com.cn/upload/2022/11/11/blog_260846343_20221111134021999.jpg)

模型保留正照左翼上、下两层窗及其间的浅色外墙、屋檐和短侧面。窗框、玻璃、粉刷窗墩、窗套与挑檐都有独立厚度。窗高约1.25米、两层相距约3.11米，是按照片比例估算的尺度。树叶遮住的返面分格按相邻可见钢梃估计。[带像素坐标的读图记录](reference-review.json) · [可编辑几何](source/ribbon_windows.py) · [2026年刊载的外侧视角](https://finance.sina.com.cn/jjxw/2026-05-10/doc-inhxkxuc6019617.shtml)
