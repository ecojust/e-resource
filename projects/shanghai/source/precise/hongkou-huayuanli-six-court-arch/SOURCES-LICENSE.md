# 图像与几何的来源

- 上海市房屋管理局公布第四批优秀历史建筑名录，4F023对应花园里、山阴路145弄、1927年。[市级名录](https://fgj.sh.gov.cn/yxlsjzcs/20200414/b9946bf8508e4b9689671fcd4146bb86.html)
- 张国文《山阴路花园里秘闻》刊于《上海滩杂志》澎湃号，2020年7月19日。721号门牌图与725号院内立面图用于查证地址和提取画面中的结构点。原照版权归相应权利人。页面提供原文和原图链接，随项目分发的图为原创网格渲染或从数字量点绘制的图表。[原文](https://m.thepaper.cn/baijiahao_8312780) · [门牌](https://imagepphcloud.thepaper.cn/pph/image/78/162/721.jpg) · [院内立面](https://imagepphcloud.thepaper.cn/pph/image/78/162/725.jpg)
- 龙钢2024年9月30日回访山阴路145弄，对照花园里组团与曾联松旧居的关系。[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_28909276)
- 背景区位采用OpenStreetMap贡献者的标注及项目既有城市场景。院内墙脚的精确坐标待补。街区轮廓依据ODbL 1.0。[OpenStreetMap版权](https://www.openstreetmap.org/copyright)
- 模型、材质、渲染、测量图与生成程序由项目独立制作。灰色粗抹灰由固定随机种子生成颗粒、光影和细纹。[纹理源码](source/roughcast.py)
