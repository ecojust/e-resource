# 中新公司大楼沿街石券窗与铁窗栅

市房管局把荣氏家族三新公司总部登记为江西中路421号的中新公司大楼。地名搜索另给南京东路720号新新公司，故以421号实地址的两期街景作为形态依据。 [第五批优秀历史建筑名单](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

两期街景都有底层券窗、分缝石墩和细密铁栅。铁栅立在窗框之前，窗台以下留有横长的浅槽。 [百度地图街景 20151219](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300011512191424198748D) · [百度地图街景 20210112](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122101121454308717I) · [百度地图街景 20210112](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122101121454308717I)

模型图中可见灰缝横切石墩并转为弓顶放射缝。外侧细铁栅与后退的钢横梃在斜面交错，下方叠线窗台向前挑出。远档以较疏直杆保持钢窗净空。 窗洞按约2米宽估尺。石块面宽、灰缝宽、铁栅进深和杆径根据2015及2021两幅沿街原照的可见比例近似，后侧墙体限于可见窗洞厚度。

市表门牌与两个日期的沿街实景指向同段石券窗。仅从这两帧不能判定原地块中整面窗墙的精确范围；保留原屋、邻屋与人行道。
