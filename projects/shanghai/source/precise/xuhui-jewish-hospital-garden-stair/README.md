# 原犹太医院三德堂南花园石阶与半圆窗

上海市房管局将汾阳路83号的医院10号楼和水塔登记为4D009。复旦大学对老校舍的记述指出，三德堂建于1942年，南面室外大楼梯直通二层。水塔另立于花园中。[第四批市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [复旦大学校舍史](https://www.fudan.edu.cn/2019/0424/c426a95979/page.htm)

从花园上第一段石阶，到半圆窗前的半层平台，再向两端转身，上到中间带石栏的上层平台。较近的照片能分清扇窗的两道半环、放射状钢条和下半段矩形窗格，也能从相反方向看清楼梯如何折回。模型取这一组石阶、石栏和扇窗。[Dragon的现场照片](https://www.meipian.cn/4zodtkdr) · [Legolas1024的2015年外观照片](https://commons.wikimedia.org/wiki/File:Jewish_Hospital,_Fenyang_Rd,_Shanghai.jpg)

南面底图边线长35.57米。由全景与近照的相同栏杆两端估算，中央石栏宽4.74–5.66米，扇窗宽1.51–1.80米。模型分别取5.12米和1.62米。2024年航片还能辨出突向花园的梯脚，沿南墙量约在西南角以东18.2米。每一级的高度、两侧梯段深度以及楼梯与原墙之间的隐蔽交接按轮廓估计。[照片控制点和原图出处](photographic-registration.json) · [采用尺寸](source/dimensions.json)

此项包含楼前室外石阶与钢扇窗。水塔、院内其他楼、后方室内和现代设备另留研究。模型各级踏面、栏杆和铁件由项目原创，采用MIT许可。[模型源文件](source/garden_stair.py)
