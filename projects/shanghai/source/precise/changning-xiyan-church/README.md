# 息焉堂主堂

市房管局第二批优秀历史建筑表的2M010为「安息堂」，公布地址为虹桥路2381号。上海教区《圣母升天堂（息焉堂）》正文记可乐路1号，联系栏记可乐路17号。教区记述设计人潘世义、1920年代的设计及1930年开始筹办公墓；照片注释与现行地图的1925年和二手资料的1931年祝圣各自保留。主堂、北钟楼和墓园在教区原文中分别说明。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [教区原文存档](https://web.archive.org/web/20240423212747id_/http://www.catholicsh.org/DetailMap.aspx?ID=4)

院前两张2016年实照能辨黄赭色粗拉毛墙、尖券双扇门、连续上升的棕色叠涩框和高窗横铁条。河对岸2011年冬景与2016年5月侧影可辨三层收分、主冠十四尖券的可见一侧和低矮附属半圆体。十四券的总数及十米顶高取自教区，对岸照片提供外形核对。窗中玻璃按摄影颜色取样，反光、彩绘和室内对象的边界无法细分。[不同年份原照及许可](../../../data/audit/xiyan-church-v1/photo-credits.md) · [影像与航片收据](photo-review.json)

具名宗堂的OSM轮廓w502997517@3与V6宏块14-13715-6695的850号对应。教区公布建筑面积239平方米，当前外轮廓约357平方米；堂内使用面积、历史外墙及当代附属之间的界限还需测绘。三期航片中的圆顶直径估为9.2至9.7米，跨期屋顶的表观圆心可相差5.17米。地面朝向依据地块、前庭与河岸共同判断。东北侧独立塔点n4933533317位于宗堂源面外约2.52米，当前模型保留钟楼、墓园和河岸的原有底图。[独立钟楼的位置依据](tower-exclusion.json) · [具名宗堂地块](https://www.openstreetmap.org/way/502997517)

可编辑源码把前庭门窗、粗灰墙面、分层屋面、主冠十四券、铜瓣与临河半圆体分别分组。背立面开口、侧后收口、宗教彩窗细部和历史室内仍待实测。模型坐标及比例输入见[参数](source/parameters.json)，前窗可追溯的颜色取样见[色样](source/glass-colour-samples.json)。
