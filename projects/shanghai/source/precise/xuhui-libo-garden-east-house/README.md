# 丽波花园东主楼

市名录原行列为「2D038　丽波花园东主楼　市体育研究所　吴兴路87号」。现场双语保护牌记载1928年竣工，赉安洋行设计，英文题作 Residence pour L. London。衡复资料另载1940年及约1150平方米，徐汇政务文记824平方米。两条口径及其来源可在参考档案逐项核对。

模型取2020年公开照片中的花园南立面。主次山墙保留露木和四格阁楼窗，南平台下有五扇落地开间。西侧半圆挑窗、放射形红瓦和通风孔烟囱分别按侧面照建立。历史敞廊和2014年餐厅入口的形态另有照片。研究所西侧办公楼、花园草坪以及衡山路300弄排屋保留原场景。
