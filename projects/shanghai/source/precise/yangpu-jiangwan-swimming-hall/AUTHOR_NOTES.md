# 江湾游泳馆（历史池馆与现状屋盖）

This is an original, photo-guided exterior model of the independent southern swimming hall at Jiangwan Stadium. It includes the chamfered red-brick enclosure, the northern pale stone stepped entrance with one arch and five central upper slots, the distinct pool-facing brick annex and small pitched porch, and the modern broad shallow raised roof with lower wings and clerestory/end glazing. The neighboring tall barrel-roof gymnasium, outdoor stadium, external white shelters, landscape, interior pool, water and underground spaces are excluded.

The geometry uses the mapped outline of source 1666 in macro 14-13722-6690. Its local frame is longitude 121.51420476482666, latitude 31.308478420024482, heading 0 degrees. Source coordinates use east/north/up metres; the GLB uses east/up/south. The source's approximately 54.53 × 92.75 m building outline and the historical 50 × 20 m water body describe different objects. The source's predicted height is not an observed height and is not copied.

The 2013 Commons photograph establishes the current roof silhouette, the southern chamfered brick arches, green northern side covers and a separate low brick annex with a small pool-facing pitched roof. The archived KIC swimming-hall entrance image establishes the northern pale single-arch stepped façade; it is not the southern brick façade or the gymnasium façade. The archived KIC facility photo constrains only the roof form. A 2006-12-29 report says a roof was added to the former open pool; it does not establish the exact completion date or current cladding material. The 1934 drawings/perspective constrain the historical enclosure but are not treated as a present-day measured survey. Historical top urns and large ornaments that are absent from the modern entrance photo are not copied.

All heights, opening sizes, side-wall arch repetition obscured in the modern photo, surface colors, roof band spacing, northern roof transition levels and porch framing are bounded estimates. In particular, the selected main roof apex is 12.8 m, its edge 10.6 m, the perimeter wall 8.6 m, the northern public core 11.8 m, wings 8.0 m, pool-facing annex eave 6.7 m and small porch apex 8.5 m. Minor roof frames raise the asset bounds slightly above the nominal apex. The pool-facing exposed layer is estimated above the lower bounded central auxiliary cover; it does not describe a surveyed usable terrace or indoor access. No PTFE, membrane or other exact modern roof material is claimed.

The walls have actual cut openings, inset glass, opening-aware bands and bounded recessed gates. All original mapped wall corners use mitered inner returns. Roof-to-wall, low-wing-to-south-cover, north-wing-to-auxiliary-cover and green-cover-to-annex transitions have physical fascia/return meshes. At the northern end, the lower wings continue 2.5 m beyond the raised center; both inner sides and their narrow outer ends close down to the lower auxiliary cover as complete L-shaped returns. Low, middle and high rays explicitly test these interfaces. Gates end at dark backstops because the interior is not modeled. Separate translucent roof bands and clerestory glazing are not placed over an uninterrupted opaque roof. The sparse frames avoid dense decorative line patterns at map distance. Sills project only about 0.08 m; no broad steps or site slab are added beside the tight western footway.

`source/build_model.py` creates both uncompressed variants. LOD reduces curved profiles, glazing subdivisions and arch tessellation while retaining the same exterior scope and outline. `source/verify_author.py` checks each authored component's closed indexed edges, winding, positive volume and nonzero float32 triangles. Component checks are not a Boolean-union proof. `source/verify_serialized.py` independently reads actual serialized triangles and casts the specified material/depth/void rays. It also hashes oriented float32 triangles per material. Full compressed geometry must match raw exactly; compressed LOD must match the separate uncompressed LOD exactly. Meshopt encoding uses `-cc -noq -vnf -km -kn -ke`, preserving float32 positions rather than adding quantization.

`source/build_native.py` imports the actual raw GLB, saves an editable Blender file, reopens that exact file and verifies the imported model geometry hash. Preview lights, camera and ground are in a separate clearly named collection and are not exported to GLB. Final author visual review records bind each actually viewed render to its SHA256; earlier private prototypes are not delivery assets.

Portable build, from this directory (Python 3 with the pinned requirements, Blender 4.3.2 and gltfpack 0.25):

```sh
python -m pip install -r source/requirements.txt
python source/build_model.py --out build
python source/build_model.py --out build --lod
python source/verify_author.py --out build/author-geometry-checks.json
python source/verify_author.py --lod --out build/author-geometry-checks-lod.json
python source/verify_serialized.py --asset build/yangpu-jiangwan-swimming-hall-raw.glb --probes build/surface-probes.json --out build/raw-rays.json
python source/verify_serialized.py --asset build/yangpu-jiangwan-swimming-hall-lod.glb --probes build/surface-probes-lod.json --out build/lod-rays.json
blender -b -t 2 --python source/build_native.py -- --raw build/yangpu-jiangwan-swimming-hall-raw.glb --out build/yangpu-jiangwan-swimming-hall.blend --previews native --samples 12 --views annex,south,front,oblique,rear,roof,entrance,roofdetail
python source/package_assets.py --raw build/yangpu-jiangwan-swimming-hall-raw.glb --lod build/yangpu-jiangwan-swimming-hall-lod.glb --native build/yangpu-jiangwan-swimming-hall.blend --out assets --gltfpack /path/to/gltfpack
```
