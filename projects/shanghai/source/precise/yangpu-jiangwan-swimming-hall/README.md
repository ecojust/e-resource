# 江湾游泳馆：历史池馆与现状屋盖

[全局主地图直达](https://raw.githack.com/ecojust/e-resource/master/projects/shanghai/index.html#landmark=yangpu-jiangwan-swimming-hall&mode=overview) · [来源登记](source-register.json) · [文字审查](../../../data/audit/jiangwan-swimming-hall-v1/documentary-review.json) · [图像审查](../../../data/audit/jiangwan-swimming-hall-v1/photo-review.json)

本件为江湾体育中心内独立游泳馆的有界外观，区分历史红砖池馆周墙、北端浅石门楼和后来加建的宽浅屋盖。室外体育场、北侧综合体育馆、外围白色轻型棚房、院区其他建筑及道路分别保留。整体地址国和路346号／淞沪路245号来自不同资料，独立馆门牌尚未单独核实；单馆完成不等于整条优秀历史建筑名录 `sh-historic-b1-021` 全部完成。

## 实际读过的来源

本轮实际读取六份相关文字资料：董大酉1934《上海市体育场设计概况》、江湾体育中心百科条目、杨浦官方2021介绍、上海体育局2009介绍、新闻晨报转载上海体育的2024文章，以及新民网转载青年报的2006同期加盖报道。百科采用已取回的修订94750796页面，所列固定修订链接未另行抓取；没有将百科引文自动算作已读。

## 加盖与年代

1934原文明确泳池“露天式”。2006年12月29日09:03的新民网文章《70多岁江湾体育场“返老还童”》（来源青年报，作者范彦萍）已记：“原本的游泳池顶部添加了一顶‘帽子’，将来会成为恒温游泳池。”正文还说相关场馆将于二期竣工后开放。因此可以确认2006年底修缮报道已涉及泳池加盖，不能把现代屋顶写成1935原构造，也不能只依据“局部开放”认定泳馆当日已经营业。

报道没有提供单馆屋盖准确开工／完工日、材料、施工图或各部更换时间。2011归档运营照片和2013高位照片进一步支持已覆顶形态；2024发表的低分辨率全景支持大轮廓，摄影日期仍未知。模型采用这些现代证据所支持的外观，不声称2026逐面现场测绘。

## 五张现代相关照片与三幅历史图

实际查看五张目标相关照片：KIC北外入口照、2013大幅高位照、2024文章两张航空背景图，以及KIC池内照片；其中四张为外观／背景，一张为室内上下文。另有三幅1934设计图，数量分开记录。

北外入口照的右侧标牌明确写“游泳馆”，与运营HTML归属链一致。可辨浅石阶梯门面、中央单拱、拱套及中央上部约五条细窄窗，侧返面另有较高竖窗。310像素宽不足以精测窗宽、拱深或全部装饰，也没有证明历史门楼顶端雕饰今日仍在。这里不套用综合体育馆的三拱、三条长高窗和挑台。

2013年照片以泳馆为前景，显示红砖折角南端和大拱门、浅色勒脚／压顶、宽浅盖顶两侧低带与抬高的中央长带，南端中央采光段有多格浅弧立面。北端低长附房的池侧红砖面与中央小尖顶可见，它与KIC北外浅石门面为不同观察方向。后方高金属弧顶属于已建综合体育馆；前景外围白色弧顶轻型棚屋、树木、停车和球场不直接并入本栋。

池内照片仅辅助理解抬高采光带与覆盖面，不因此制作泳池水面、室内钢架、看台、更衣或淋浴间。外照浅白屋面不能单独证明其为膜、PTFE或某种金属板，材料与具体构造仍应按作者估计说明。

2013图由Coolmanjackey拍摄，描述与EXIF同记2013-08-06，按CC BY-SA3.0提供；本库不嵌入原图。KIC的2011为网页／图片归档时间，版权2008不是摄影日期；2024为文章发表日，不代替摄影日。运营站与新闻照片未查得自由分发许可，均仅作私人参考。

## 尺度、口径与未完成范围

50×20米是水池尺寸，不是整栋外包。1934历史水深约1.1—3.5米，现代运营文字写1.2—2.4米，均不推导屋顶高程。1934的5000坐席＋1000立席、官方2500观众容量、KIC同时300人游泳属于不同口径，不应强行合并。整馆平面与邻楼界限由冻结地图源及单独定位审查确定，高度、洞口、屋盖分段和遮挡立面仍含估计。

历史设计支持北端门楼附房、南端折角拱门环及红砖配浅石基脚／压顶的形式；后加屋盖、现存门窗与原露天设计分别处理。原方案内部空间、池深和看台不自动进入外观交付，也不用于开放室内或院区步行。

本栋有界外观完成后，已列主场局部边界／门台细部和完整名录范围调查继续保留。外围白棚、附属屋与整个体育中心的产权／保护范围未全部核验，不能将它们随本栋一并宣告完成。原创几何、代码、四资产清单与重建方法由最终作者资产说明绑定；参考照片与扫描不作为贴图或随仓库分发，地图参考遵循ODbL-1.0。
