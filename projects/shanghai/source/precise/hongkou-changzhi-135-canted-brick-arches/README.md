# 长治路135号公寓转角砖券窗与楔形券心石

5F033在市表登记为公寓，门牌长治路119-135 号（单号）、闵行路172号。Fayhoo在2016年拍下长治路135号街角的红砖公寓。顶层转折的两面墙各开一扇半圆头窄窗，外圈砖券在顶部托住一块上宽下窄的竖向券心石，两面墙的腰线与顶檐在折角处相连。

圆头内圈可见放射状砖缝，券心石比外圈更高，顶有一块横砖。分格横档以上为暗色半圆窗，下方两扇长窗由中央竖梃分隔。 转角有连续退进的檐线和两旁浅壁柱，取景时电杆遮住右窗的部分玻璃，但可从上下两侧辨认洞口全宽。

以照片估计转角与窗洞相对进深，缺少实测尺寸。范围只及转角顶层的一对窗，现场前景电杆、附装搁架及空调按照片另记。市表另列闵行路172号，单凭这幅图不能逐门定位。
