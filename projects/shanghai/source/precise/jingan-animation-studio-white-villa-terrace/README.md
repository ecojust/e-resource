# 上美影小白楼庭院弧形露台与四根圆柱

5B052在市表登记为住宅，门牌万航渡路618号。万航渡路618号原上海美术电影制片厂本部“小白楼”面向庭院处有弧形露台。模型取上观新闻2026年所刊照片中的外挑台板、四根细圆柱和台上向中间收拢的几何铁栏。

露台外缘是一道薄白边，下面另有厚而内收的弧形带。落地圆柱在白墙前独立排开，柱顶接在内带底面，柱脚落在圆弧形台面。 黑色栏杆上段有四条顺弧横杆。下段中央连续折线起伏，两侧嵌有折角及卷端花铁。

文章记录了作者2023年秋天的参访，照片没有单列拍摄日及摄影者。廊深、楼板厚和栏杆截面据照片比例估算，园区中其他楼房及近年展陈均不在取景范围。
