# 岐山村1032弄入口金字题名与石框

愚园路1032弄。街口石框的矩形凹槽、从右向左排列的三个金字、绿色路牌和四角固定件。

石框宽约1.68米，露出的上段高约1.08米。金字和路牌根据正面照片比例重新绘制，绝对尺寸与背面厚度为估计值。

公开照片署名来自原文文末。金字和门牌为根据原位文字重新构造的独立几何，照片均以链接列出。
