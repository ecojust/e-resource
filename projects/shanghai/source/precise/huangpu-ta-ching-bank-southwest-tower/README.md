# 大清银行上海分行旧址西南八角塔

四川中路268–270号和汉口路50号指向同一幢沿街大楼。上海市房屋管理局第四批4A018的在线地址栏写作“四川中路268–270号，”；汉口路门牌、两条街线和用地位置分别来自建筑报道与具名地图足印。该幢建筑于1908年落成，由通和洋行设计；中国银行于1912年2月5日在此成立，外滩23号为后来的另一处行址。[第四批市表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2021年建筑报道](https://www.thepaper.cn/newsDetail_forward_15219765) · [来源核查与原始地址栏](reference-review.json)

制作范围为面向街口的三个八角塔面、两街相邻的首个开间、低鼓座和矮铜穹。2013年12月19日Livelikerw摄的修缮前照片中，立面表面为灰色。2017年12月24日ScareCriterion12拍摄的照片中已显出红砖、浅色石框与绿铜屋面，三层上部开窗中，最低一层有三角山花。较高的另一座穹塔在汉口路正立面主入口上方。[署日照片与图像指纹](reference-review.json) · [修缮前后对照](../../../data/audit/ta-ching-bank-southwest-tower-v1/preflight/2013-and-2017-west-corner.jpg)

原城地块西南切角长5.324米。垂直尺寸和杆高按街照比例估算，模型以当地米制坐标制作，垂直顶点为19.35米。重新绘制的循环贴图用于表现修缮后红砖的灰缝和色差，模型不带现场照片纹理。[足印与同组相邻楼](footprint-review.json) · [作者程序](source/build_model.py) · [砖纹与坐标](source/brick.py)

汉口路长翼、高穹塔、院内和室内待另行考证。建筑报道中的设计师、建成年份和修缮过程均单列在来源记录中。[来源和图像](reference-review.json)
