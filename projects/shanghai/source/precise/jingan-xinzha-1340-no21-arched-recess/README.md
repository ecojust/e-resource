# 新闸路1340弄21号圆头深窗洞与重檐

5B008在市表登记为住宅，门牌新闸路1340弄21号。取Antigng在2018年1月28日拍摄的21号住宅墙面。较低的瓦檐覆盖狭长圆头开口，后方高墙的浅色檐带下有一排圆弧缺口。

开口上缘圆拱，右揭口从顶部延续到树冠后方；灰色颗粒饰面从开口周围连续转折。 后檐比前檐抬高并后退，浅色连续圆齿在上层瓦檐下能逐个分辨。

树叶遮住开口下半部分，照片只支持上段的拱顶、深侧墙和凹进的表面。模型在树冠遮挡线附近截取洞内；深度与墙厚由照片可见阴影估计。名录现用名为经济日报上海记者站。
