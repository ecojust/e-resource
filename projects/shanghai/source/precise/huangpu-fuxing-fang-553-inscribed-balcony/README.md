# 辣斐坊复兴中路553弄过街楼题名阳台

复兴中路553弄的通道从一栋砖楼底层穿过。通道上方有灰色折面阳台，正面保留红色繁体「復興坊」三字。上海市房管局第四批优秀历史建筑4C015将院内1至21号与两侧543至551号、555至561号一起登记为辣斐坊，现名复兴坊。东邻517至541号属于另一项4C014。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

本件取阳台三片石框、出挑板与底托，以及后面的中央双叶木百叶和窄砖垛。2015年1月的斜前照片能看清两个转折、石边的投影、百叶横片及红字；2015年12月、2021年1月和2023年6月的街景使同一通道与两侧店铺可相互辨识。通道、两柱、三楼、遮篷、左右店屋和院内其它楼另列。[2015年照片，Livelikerw](https://commons.wikimedia.org/wiki/File:Fu-Xing_Fang_Shanghai.JPG) · [照片索引与逐站参数](reference-review.json)

2021年三个机位同时交会，题名面板中心约在121.462324°E、31.216923°N。正面两转折间宽约1.69米，底边距路面约4.0米，顶边约5.0米。相邻百叶下缘向内退约0.8至1.0米。三处相机登记的镜头高度均为2.32米。阳台同一测点的三次高度估值相差0.39至0.64米，模型阳台绝对标高约±0.4米。百叶顶部各站估值相差最多0.91米，采用约±0.5米。折角向后深度约±0.2米。[三站交会数据](measurements/three-station-dimensions.json) · [复算十处实测点](measurements/reconstruct-dimensions.py)
