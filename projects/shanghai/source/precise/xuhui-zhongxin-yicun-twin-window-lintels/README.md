# 中信一村沿街双窗的连檐、曲肩与双层窗台

5D110在市表登记为住宅，门牌延庆路80、82、84号。Antigng于2018年2月7日摄下中信一村红砖街墙。两樘并排的深色双扇窗共用一条浅色水平檐线。每个窗头的两端弯收至细边框，窗底则各自伸出一块浅色阶形窗台。

窗头分两段，各有一块略下落的浅色中心饰块。外端轮廓先向墙面伸出，再以内凹曲线接入竖边框；上方整条横线通贯两窗。 黑褐窗框各有两片长玻璃和靠上的横档；每窗独立浅色窗台的下方再叠一层较短的长方垂板。墙面有红褐砖及浅色勾缝。

市表5D110把延庆路80、82、84号并列。摄影页面文件名为“延庆路82号住宅”，作者图像说明为“延庆路80号住宅”；本件以这排住宅的登记名称识别画中相邻双窗。护栏、电线和两侧树遮住部分窗面，窗框进深和挑出尺寸依可见边缘估计。
