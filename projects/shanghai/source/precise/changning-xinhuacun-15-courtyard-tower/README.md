# 新华村15号院面方塔与侧廊

愚园路1320号院内的15号楼在上海市房管局第三批优秀历史建筑名录中编号3M005。区规划资源局介绍这一带四幢英式花园住宅建于1925年。高参88在2014年6月11日发表的《愚园路1320弄新华村》将图17明确标作长宁区政府15号楼。原始照片的拍摄日未记。

本模型呈现图17中的方塔、短脊四坡红瓦、贴塔的高砖烟囱、三层庭窗、绿色地层双扇，以及一段斜接庭廊。侧廊在树木和邻楼遮住的最后一根柱旁收口。北面另一排三层窗和紧靠方塔的短屋面由同篇图13与2015年12月19日长宁路599号门内的实景约束。11号的院廊、12号题号山墙、14号的双处高屋顶均有各自的地址资料。

## 尺寸与照片

在2015年4月三个摄影站与12月两个摄影站中分别交会北面上层窗的四角，以同月上、下两条窗边的平均真长计，四月宽1.64米，十二月宽1.50米，高分别为1.14和1.17米。四月和十二月的独立解仍有约5米平面位移。不同月份的道路摄影方向误差足以影响地面位置，因此保留分期结果和被剔除的跨月解。屋面两期正射给出约17–19米的局部斜轴。

以该窗为标尺联解，塔正面宽约5.61米，条件性进深约2.91米。从模型院地参考标高至檐口约13.24米、至屋脊约15.87米。靠院地面与路面高差在原照片中缺乏同点。廊面和塔面轴线相差约31度，模型中三条廊边线的端高差控制在约0.13米。院廊背后的房间、遮树的廊端和相邻建筑内部未有本次照片测量。

## 原生与发行

普通独页提供九个视角、三站模型自渲和源码包。原生Blender、未压缩GLB、网页近景与远景GLB、FBX、带材质OBJ与STL分别适于编辑、展示和几何交换。原像素用于量测和数值对照，建筑表面采用本项目编写的卵石、红砖和灰红瓦程序纹理。

运行 `python source/build_model.py --output rebuilt/full-source.glb` 构建近景，加 `--lod` 构建远景。运行 `python measurements/check_tower_solids.py closure.json` 检查各组闭合、绕向和有向体积。运行 `python measurements/check_tower_surfaces.py MODEL.glb surface-check.json` 对照三个摄影站的原生像点。运行 `python measurements/render_registered_tower.py MODEL.glb output` 可在无原照片的条件下生成同机位数值渲染，`python measurements/register_north_window.py` 独立复算两个月份的三角交会。
