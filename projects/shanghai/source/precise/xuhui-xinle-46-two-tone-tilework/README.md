# 慎成里新乐路46号双色陶面砖与竖砖过梁

5D106在市表登记为住宅，门牌新乐路44弄（1-15号）、新乐路38-50号（双号）。新乐路44弄入口旁46号铺面上半部。深红和浅米色的面砖交替错缝，洞口上方改用竖砖，浅色抹面包住上沿和两侧。成排的面砖从街面转入弄口，较暗的砖带与橙色线脚收住墙头。

正视图能读到46号绿牌，牌下有一条较厚的浅色过梁，过梁上方的竖砖与两侧水平砖列方向相交。 斜照中可在右侧山墙继续看到相同的双色面砖。墙顶有燕麦褐色砖带，一道陶红腰线和较薄的灰色压沿。摄影者写“新乐坊”，现行市表列“慎成里”。

按金红卫两张照片概括46号这一跨。窗内后来加装的卷闸仅取上部横向阴影。沿街行道树、商业招牌、卷篷与管线未纳入；转角回折仅延伸至斜照可见处，尺寸和进深均为估计。
