# 皋兰路17号花园住宅临街灰卵石山墙与折窗

上海市房屋管理局第四批4C009以“花园住宅”登记皋兰路11至17号。皋兰路有三座住宅带这个登记编号。本项取17号门柱后、通道东侧、朝街的灰卵石山墙。对街16号圣尼古拉斯堂为另一处保护建筑。[上海市房屋管理局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2015年公布的街照中，白石柱的绿色门牌清楚写着17。灰墙夹着高低两层红棕色百叶，山尖下有外露木格与阁窗。底层凸窗有三面窗扇、短坡瓦罩和挑出的浅色窗台，罩顶上方另有一道浅红色弧形砖带。2015年4月和12月街景分别拍到开启和合拢的上层百叶，本次取后者。2022年夏所摄的街照补出门牌后通道的方向，西侧另一幢房屋距道路更近。[yiyi01831sh，2015年3月1日](https://blog.sina.cn/dpool/blog/s/blog_55c85ddb0102vfo4.html) · [2022年街影，2023年4月公布](https://www.sohu.com/a/668754525_121658298)

2020年2月20日两个街景机位观测到同一对二层窗。按相机离地约2.3米估计，窗台约5.1米、窗头约6.7米、山尖约10.9米。原城251西翼的概化外墙比实测窗面约退后3.23米；西邻487、东邻3281及教堂2197均保留。通长红砖廊、院门、后园、整栋背屋面和其余住宅仍待更多可定位的照片。所用外观几何独立绘制。
