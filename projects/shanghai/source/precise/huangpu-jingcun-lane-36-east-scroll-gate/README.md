# 静村绍兴路36弄弄口东侧透花铁门

上海市黄浦区绍兴路36弄。以街面右手完整可见的一扇铁门为范围，黑色框架围住上下两排长条透花和金色圈饰，上缘有七枚矛尖。

2020年2月两处街景相机的对应主梃间距约0.78至0.83米，估计完整门扇宽约1.6米。2013年10月影像已可见这种门框与透花。铁门的安装年代及花饰背面尚无实测。
