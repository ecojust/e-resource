# 五原路251号花园住宅山墙拱框百叶窗

市房管局第四批4D020登记五原路251号、永福路1号花园住宅。高参88在2013年9月24日的图集中拍到两个山墙，并从低处拍到右侧白色拱框及里面的百叶。2023年徐汇原片中的同一右山墙仍可见。模型取白色拱框、平底窗台、短直边、后退的水平百叶和窗边少量红砖。局部作为独立构件陈列。[市表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2013年图集](https://blog.sina.com.cn/s/blog_5d1bdf480101esnd.html?from=historic) · [2023年原图](https://imagepphcloud.thepaper.cn/pph/image/241/14/520.jpg)

邻近砖皮为估测比例提供参照。浅色框在照片校斜后的宽高比约1.53，外宽估计在0.84–1.24米。靠下五道叶缘可分辨，拱顶阴影内的叶片位置与叶片深度按下部节距估计。近景保留拱框转折和倒角，远景减少圆弧分段。两档都保有百叶间隙。[原照校核和比例](reference-review.json)
