# 太原路50弄并立式住宅东立面落檐双窗

上海市第四批优秀历史建筑4D014包括太原路50弄1–2号、56弄1–4号与64弄1–4号。50弄的绿色门牌可由2013年实照辨认，文章的旧地籍图在这一栋中间标有分隔线。模型选取50弄住宅共同的临街东面。公开资料未能将今1和2号分配到照片中的两扇窗。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [高参88的现场记述、户牌与旧地籍图](https://blog.sina.com.cn/s/blog_5d1bdf480101fi18.html)

2015年12月7日的两处街景机位相距约7.96米，测得较低两窗中心相距2.56米，东立面外法线约77°。2020年另一组街照用于复核。可辨认的部分包括两扇木框窗、上悬亮窗、窗罩与落水管，以及南侧略高的窗与瓦坡。屋顶后部超出双机位的可测范围，竖向绝对高程和窗罩深度采用照片估值。[窗位与檐线交会](source/registered-eaves.json) · [两期门牌与原户核对](source/independent-address-review.json)

历史建筑足印与原城1345的交并率为97.07%。近组中的三德堂、56弄和64弄其他房屋与50弄属于各自的原城实体。模型起于距地4.27米处，原首层及街面步行范围完整保留。矿物墙面为自绘程序纹理。[原城与模型范围](footprint-review.json)
