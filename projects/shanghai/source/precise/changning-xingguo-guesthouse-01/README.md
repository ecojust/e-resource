# 兴国宾馆1号楼

上海市房屋管理局公布的第一批优秀历史建筑表，第1M006条依次记载「兴国路住宅」「兴国宾馆1号楼」「兴国路72号」。太古洋行高级职员曾使用这座花园住宅，英文名为Hazelwood。中文历史条目记载它建于1934至1935年，由威尔士建筑师克拉夫·威廉斯-艾利斯设计。[首批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/fe7b4d6f35774b708a2c5122849065bd.html) · [建筑沿革](https://zh.wikipedia.org/wiki/兴国路住宅)

2007年冬，CyberCop从草坪西南侧拍到两层住宅，西转角下层为拱窗，上层为敞开拱廊。2015年春，Legolas1024拍到同一园侧正面。中央五扇落地长窗与两端各一扇组成七开间，二层廊柱成对排列，窄扶栏前方是一整道宽石阶。屋面上有五处阁楼窗，后方立两座高烟囱。两张照片分属不同作者，照片的像素保留在原始网站。[2007年照片](https://commons.wikimedia.org/wiki/File:Inside_Radisson_Hotel_Compound_-_panoramio_-_CyberCop.jpg) · [2015年照片](https://commons.wikimedia.org/wiki/File:The_House_of_Swire_Pacific_Ltd.%27s_House.jpg) · [来源记录](reference-review.json)

源地块337号位于园内大草坪北缘，登记为独栋「兴国路住宅」。模型依据航片表现主屋体和屋面大势，园侧和西转角有照片可据。北、东侧缺少清晰立面照，仅表现体量与连续线脚。檐口高度、退台与烟囱高度均属估计。周围宾馆楼宇和草坪由原城市图层表示，上楼后的室内另计。[地块与航片记录](footprint-review.json) · [OpenStreetMap地块](https://www.openstreetmap.org/way/293518764)
