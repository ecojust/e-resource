# 五洲大楼顶层五联券窗与阶梯式冠顶

5A019在市表登记为五洲大楼，门牌河南中路220号。按Fayhoo于2015年4月4日拍摄的河南中路220号正面，制作中央高塔最上段的五扇圆头窗、下方第二排方窗与连续上升的轮廓。

五个圆头窗中轴与下排方窗相接。两排之间的短竖条颜色较浅，较长的凸棱平行穿过各道窗间墙。 最高的一段在中轴，上设多道横槽；左右各有较低的小垛。不同高度的墙头保留实照的不平直轮廓。 下层商铺与左右两翼均在取样部位以下。

窗距、拱高、饰带厚度按照片相对关系估算，塔冠后侧及上方细杆不在本次范围。缺少把局部准确放入城市底图的实测位置。
