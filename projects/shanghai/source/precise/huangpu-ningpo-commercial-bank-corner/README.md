# 四明银行北京东路转角门楼

上海市房屋管理局第三批名录3A016将四明大楼登记在北京东路232–240号。方志上海刊出的邱力立街照标明路口西北角为四明银行，右侧为浙江兴业银行。此次制作南侧北京东路与东侧江西中路之间的斜切门楼，以及两侧各一个开间。覆盖范围沿底图分别为5.45米、5.93米、5.75米。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [方志上海的街口题图](https://www.sohu.com/a/288852659_534720)

模型按2014年街照的角门、双层柱式、椭圆窗与两道石栏制作。PastVu编目为1921年的正面照还可见屋顶穹亭。2014年街照中，顶部可辨的构件为曲栏、侧墩和两侧局部檐口。尺寸依据照片估计，背街部分及两翼其余开间留待续作。[2014年街照](https://commons.wikimedia.org/wiki/File:Former_Building_of_The_Ningpo_Commercial_Bank.JPG) · [1921年正面照](https://pastvu.com/p/776573) · [图证、地籍与许可](reference-review.json)

源码以米为单位，Z轴向上。负Y面向路口，X从北京东路侧指向江西中路侧。原始花岗岩纹理由Python固定种子生成。源码与原创模型按仓库MIT许可证提供，底图几何依各自来源保留许可。[足迹归属](footprint-review.json) · [三段街墙坐标](source/frontage-registration.json)
