# 哥伦比亚乡村俱乐部主楼：公开资料与使用边界

建模对象为上海长宁上生新所的哥伦比亚乡村俱乐部主楼，含修缮后保留的东侧增建、北门厅和南敞廊、露台。它与独立的泳池、体育馆、孙科别墅不同；不以主楼模型替换整个园区。

## 建筑依据

- [闵欣、宿新宝：《关照历史与面对现代：上海原哥伦比亚总会主楼保护修缮工程》，《时代建筑》2018年第6期](https://www.sohu.com/a/284527618_681890)。建筑师正文、两层平面、两幅剖面、航拍及修缮照片已实际查看。正文记载主楼1924年建成、2018年完成本次修缮、建筑面积2012㎡，并说明东侧历史增建保留、1980年代连接泳池的连接体拆除、南露台加透明玻璃栏板。2012㎡为建筑面积，不能当占地面积。
- [上海长宁2024年上生新所介绍](https://www.shcn.gov.cn/col3991/20241008/1269200.html)支持建筑现用途及园区各独立建筑的区别。现代店招字形为“蔦屋書店 / TSUTAYA BOOKS”；店招与2018照片存在年代差异。
- [OpenStreetMap way 864847881](https://www.openstreetmap.org/way/864847881)与冻结城市建筑来源用于识别替换对象。四边形轮廓约49×18.7m、917㎡，只是地图覆盖代理，不是墙线、屋檐或门廊的精确测绘。来源中22.1m粗估高度不作为本楼可靠高度。

建筑师网页没有可直接引用的数值高度。模型约53m主宽及分层高度来自图示比例尺、同一构件跨度和不同剖面分别标定；这是图纸推估，不是现场测量。不得把两幅剖面或不同分辨率平面的像素直接共用比例。北门厅8根石柱、三间拱廊有正文依据，但不等于北外面必有3个独立拱洞；可见成对柱头和侧通行口以照片辅助，遮挡面仍有推估。南曲线山花位于露台后退二层墙，近距离正面照片容易将其与较低前女儿墙投影重合。

建筑师图、无明确开放许可的政府及现代照片只供研究；公开交付不包含这些私有像素，不将其作纹理。

## 通用材质与模型限制

作者另行选择的CC0材质如压毛/抹灰表面样本，必须独立登记作者、原始下载地址、许可、字节、哈希和实际映射用途。它们属于通用表面样本，不是本楼现场扫描；不得列为真实建筑照片。是否实际采用及其强度、重复尺度，以最终模型元数据与图像白名单为准。

屋面、门窗、阳台、压毛饰面及局部装饰按资料构造；遮挡部位、风化、雕刻纹样和未有图纸支持的室内陈设可能简化。此项目是有照片与建筑师资料参照的外观模型，尚非照片级真实复原，也不是测绘或摄影测量成果。
