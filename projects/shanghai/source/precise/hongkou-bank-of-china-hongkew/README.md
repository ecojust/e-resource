# 虹口中国银行大楼的西南弧角

第二批上海市优秀历史建筑2F009列“四川北路894号”。《虹口区志》记载原中国银行职员寓所位于四川北路912—922号、坐东朝西，1929年建成，七层钢筋混凝土。2012年4月29日的地面照片能分辨海宁路口处的红砖圆角和浅石面横向窗带。对街四川北路875—895号的虹口大旅社是另一座建筑。

十六米多的局部研究取西南弧形街墙及四川北路上最靠近它的三个开间。匿名城市粗面2427内约200平方米的转角形状、四川北路和海宁路的方向、现存弧角及多个航片版本互相对应。完整历史用地约1000平方米，登记面无法证明整栋或北侧诸小地块的归属。高度和窗间距估自照片；末端高墙、屋顶标识、北段、后院和内部另待查证。[建筑身份](identity-review.json) · [影像及城市依据](reference-review.json) · [配准原始几何](footprint-review.json) · [建模源码](source/build_hongkew_bank.py)
