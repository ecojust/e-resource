# 中国银行仓库双扇阶格式金属大门

上海市静安区北苏州路1040号。两扇黑漆金属门各有四块横向实心框板。窄横档和短竖梃在框板间相接，形成能透视的阶梯形空格。

依据门扇修缮前后正面照片绘制。两扇合宽约2.0米、门扇高约2.1米，按照片估算；门后空间未测。
