# 国立音乐专科学校正校舍中央券门与四坡顶

1936年出版的《國立音樂專科學校校舍落成紀念特刊》把第17页的建筑题为「正校舍」。第19页另刊尚有脚手架时的照片，两图都能辨认中央高起的方亭和四坡顶。萧友梅在同书《本校校舍建築經過》中记述了建设过程。上海市第四批优秀历史建筑名录以「国立音乐专科学校主楼及辅楼」登记这处旧址，编号4G012。[历史名录与书内页码](measurements/municipal-and-historical-record.json) · [特刊目录与原件摘要](measurements/1936-commemorative-publication.json)

模型呈现落成时正校舍照片中的中央券门、亭顶及贴着门面的两段檐口。两侧的廊柱与檐部按画面截取。黑白模型沿用印本中的明暗关系，阴影深处用后退的暗面表示。方亭上层的窗格、门扇和原有颜色均无法从印本辨清。这里的年代指图像出版年代。[打开模型](../../../national-music-school-1936-arched-portico.html) · [落成照](study-views/arch-and-pavilion-1936.jpg) · [圆券局部](study-views/arch-head-1936.jpg) · [施工照与屋面](study-views/pavilion-under-construction-1936.jpg)

## 比例与照片复核

根据券面四角与半圆券头计算立面比例。绝对尺寸按照券口净宽2.64米估算。为让门顶和屋面出现在同一个正确视角，又使用屋檐的左前、右前、右后三个可辨折角校正相机。1936年印本没有相机参数，前檐出挑、进深与被遮住的背侧仍采用估值。[券面控制点](measurements/arch-plane-controls.json) · [相机与三个檐口折角](measurements/joint-camera-and-roof.json)

在第17页原图另取30个位置，测量浅色券面与深色门洞之间的边缘。与近景、远景模型的券内壁相比较，高差均方根分别约0.042米和0.041米，均依赖上述净宽假设。第15页所印为计划鸟瞰图，落成照片提供了此次建模的形态依据。[印本剖面对照](measurements/independent-printed-arch.json)

## 模型文件

近景模型包含26,592个三角面和143个可编辑组，远景包含9,176个三角面和107个可编辑组。四坡瓦面分片制作，门券有连续内壁、券脚、台基和后退的截面。三个导出网格每个经过165次实体检查。模型以独立历史展品发布。[源程序](source/build_model.py) · [实体与通孔复核](../../../data/audit/national-music-school-1936-arched-portico-v1/preflight/geometry-rays.json) · [资料与许可](SOURCES-LICENSE.md)
