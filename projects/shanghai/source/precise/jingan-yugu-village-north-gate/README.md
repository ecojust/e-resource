# 愚谷村愚园路北弄门

愚园路361弄北口的两根门柱都竖题“愚谷邨”。西柱上方有绿色门牌，东侧墙嵌框边金属牌，两侧墙面以折线和阶梯状竖线收边。上海市房屋管理局第二批优秀历史建筑名录将这处住宅群登记为2B011“愚谷村里弄住宅”。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html)

2017年9月、2019年5月、2020年2月与2021年2月的街景都能看见北口。模型采用2020年2月四格铁门闭合时的形态。门柱中心距估算约3.2米，高约2.8米。从不同年代视点分别估出的宽度有出入，铭文字形、铁件花纹、侧面深度和背面做了近似。2014年Livelikerw所摄照片是在弄内拍摄，照片中的房屋另列。南端南京西路1892弄及121号旧址也各有其位置。[街景定位与原始图像校验](street-registration.json) · [2014年弄内实照](https://commons.wikimedia.org/wiki/File:Yu-Gu_Cun_Shanghai.JPG)

三期Esri Wayback航片用于核对巷道方向和屋顶位置，日期为影像发布日。附近五幢原底图建筑保留。建模来源、影像时间和底图原件均可按登记记录复查。[三期航片](aerial-register.json) · [底图轮廓与原件](footprint-review.json) · [资料登记](reference-review.json)

原创几何与材质使用MIT许可。门牌采用更名的Noto Serif CJK子集，授权及字库来源随文件保留。模型未嵌入第三方照片。[字体来源和授权](source/fonts/provenance.json)

从项目目录运行以下命令可以重建三档GLB、可编辑Blender场景、原生预览和几何核验记录。

```bash
python -B source/precise/jingan-yugu-village-north-gate/source/build_model.py \
  --out assets/models/candidates/jingan-yugu-village-north-gate \
  --audit data/audit/yugu-village-north-gate-v1
```
