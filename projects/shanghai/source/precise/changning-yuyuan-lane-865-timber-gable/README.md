# 愚园路865弄花园住宅木构图案山墙与内凹门洞

1930年建成的愚园路865弄花园住宅有五栋。市级第四批名录列出30、31、32、33、35号，长宁区规划资源局的照片拍到其中一处突出的山墙和门洞。照片没有标注具体栋号。模型呈现这处山墙从屋脊到门槛的可见部分。[模型展页](../../../yuyuan-lane-865-timber-gable.html) · [长宁区建筑资料及原照](https://www.shcn.gov.cn/col7698/20211207/1152633.html) · [市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

深色竖材把浅色抹灰墙分成窄格。左侧屋檐较陡，右侧接近檐口处逐渐变缓。两根下部弯撑跨过短竖格，在中央钢窗两边展开。四道横档显示钢窗右侧玻璃向内折进。首层砖墙开着矩形石门套，木门的浅弧顶退在石套里面。左侧内壁的小门铃据原照可见。[屋脊和檐口](study-views/ridge.jpg) · [钢窗近景](study-views/glazing.jpg) · [门洞近景](study-views/portal.jpg)

单张斜照的比例以外门套前沿中央净高2.12米作假设。14组横竖线控制正立面投影，58个另行读取的屋檐位置用于检验两种细节等级。右侧墙面辨出36道水平灰缝，间距中位数折合约62毫米。五栋共有的用地约2415平方米、建筑面积约1426平方米取自区级资料。短段屋面、墙厚与门内进深保留估算。[相机与定标](measurements/front-plane-camera.json) · [钢窗测点](measurements/central-glazing.json) · [灰缝测点](measurements/brick-courses.json) · [屋檐复核](measurements/independent-roof-silhouette.json)

区内门牌点靠得很近，30号与32号的两个点相距约6.24米。已有资料还缺少将这个山墙识别到某栋的依据，展页保留独立位置，主图原建筑照常显示。[门牌与原建筑核对](../../../data/audit/yuyuan-lane-865-timber-gable-v1/preflight/final-placement-review.json)
