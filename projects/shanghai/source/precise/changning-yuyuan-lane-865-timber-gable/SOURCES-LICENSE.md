# 来源与许可

长宁区规划和自然资源局于2012年8月16日公布《愚园路865弄花园住宅》。页面和所附608×686像素照片用于核对建筑组的年代、规模和山墙构件。原件为68,314字节，已记录 SHA-256 摘要。图片的再分发许可未注明，仓库发布实测点、数值结果和项目自绘的模型视图。[区级原始条目](https://www.shcn.gov.cn/col7698/20211207/1152633.html) · [图片记录](measurements/photographic-source.json)

上海市房屋管理局的第四批优秀历史建筑目录用于核对4M016号与门牌。地图核对记录注明原建筑轮廓和门址索引各自的来源。深色木饰、建筑网格和浅色抹灰材质均由项目生成。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [OpenStreetMap署名](https://www.openstreetmap.org/copyright) · [原创材质代码](source/roughcast.py)
