# 华商纱布交易所 · 上海自然博物馆旧馆

延安东路260号在上海市房管局第二批名录2A053中登记为华商纱布交易所，公布时使用单位为上海市自然博物馆。门旁的市府保护牌记通和洋行设计、钢筋混凝土结构、1923年竣工。交易所于1921年成立，起初使用租来的场所，1937年8月停牌。上海自然博物馆于1956年成立，1958年迁入交易所。摄影师陆洁记录了旧馆从2014年5月闭馆至2015年10月间的搬迁；位于静安雕塑公园的新馆于2015年开放。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [自然博物馆沿革](https://www.snhm.org.cn/gywm/lssy.htm) · [交易所、迁馆和保护牌来源](reference-review.json)

一张商家标记为1943年5月13日的旧照片显示高架桥修建前的南面、穹顶塔、三角山花和街门轴线。2012年实照可见高架桥遮住立面中段。2020年的地面近照和高架路街景分别展示爱奥尼柱头、原馆书写门额、铁门中央对开的铜圆饰、成对花环，以及西转角穹顶下可透视的柱廊和圆窗。模型按旧馆时期的街门制作，门额采用重新绘制的几何字形。[2012年照片及许可](https://commons.wikimedia.org/wiki/File:%E5%8D%8E%E5%95%86%E7%BA%B1%E5%B8%83%E4%BA%A4%E6%98%93%E6%89%80%E5%A4%A7%E6%A5%BC.JPG) · [2020年沿街详图和保护牌](https://www.meipian.cn/2yaaucrc)

独立建筑源1602同时载有“上海自然博物馆旧馆”和“华商纱布交易所”两个名称。三个版本的航片显示中央及北端均有低于周边屋面的矩形区域。旧报走访记大交易厅由上部采光，模型只估计可见低屋面和围合墙体。通和洋行原始平面、真实柱距、院内各层标高及展厅内部仍缺少可核实的图纸。延河大楼473和中间的窄长建筑2040各自保留。[原建筑面、邻界及航片](footprint-review.json) · [独立模型页](../../../cotton-exchange.html)
