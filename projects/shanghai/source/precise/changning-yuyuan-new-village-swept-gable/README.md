# 愚园新村排屋灰砖山墙与弯折封檐

1930年，浙江兴业银行购下康有为“游存庐”旧址，建成愚园新村。沈钧儒曾住在弄内11号。照片没有给近景端墙标注楼号。 [长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211207/1151492.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

正面可辨两层窗、红砖带与左右转折的山墙封檐。斜视可见封檐后退到瓦坡的进深。两档均保留这三处轮廓，窗格玻璃和灰砖在阴影中明度接近。 两道砖带与屋脊高度按原照相对量测。取端墙净宽6.40米作展示比例，屋前草地及室内没有实测定尺。

门牌点周围43米内有17栋市图旧屋，近三栋为2729、2577和1101。已有的754号花园住宅属另一处登记。独立页面保留750弄这面暂不能落实楼号的山墙。
