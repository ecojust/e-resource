# 海青大楼顶层双窗与成对弧形檐托

市第五批名录列为“海青大楼/美国陆海军青年会”，四川中路630号。旧上海海军青年会宣传单也把馆舍标在四川路与香港路口。Livelikerw于2016年2月18日在街口拍摄的斜照可见红墙以上浅色的一层、中央并排的两扇窗、出挑的折角檐线和檐下成对的弧形托件。

模型按这张现场照片制作，取两组正面檐托和两侧各一组短转回。下层红墙仅保留一小段以说明分层。深色窗、各自的弧形篷、白色凸框、托臂及檐板分开制作。
