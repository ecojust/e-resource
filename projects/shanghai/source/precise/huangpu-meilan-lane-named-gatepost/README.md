# 梅兰坊黄陂南路596弄题名门柱与铭牌墙

市房管局第四批4C011号登记为“梅兰坊”，地址为黄陂南路596弄1–58号。街面望向总弄，左柱和右柱都题有“梅兰坊”。模型取左柱的石座、凹面、金字、顶部线脚，以及同侧相接的门牌和铭牌墙。院口、右柱、两扇铁门、沿街店面和院内各户保留。[房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2015年12月、2019年5月和2020年2月的黄陂南路街景提供同一街口的正面与侧向对照。2024年陆梁液近摄可读绿牌上的“596弄1–58号”和“黄陂南路”，下方是优秀历史建筑铭牌和竖向展示框。公开图源和摄影归属见附录。[携程实拍](https://you.ctrip.com/sight/shanghai2/1478261.html) · [图源、时间和建筑范围](reference-review.json)

两台同期相机以同一金色“兰”字定位。原城南侧房屋1429与柱面中心相距5.85米。柱宽约0.60米、高约3.71米，牌墙宽约1.18米、顶标高约2.34米。绝对平面定位误差估计约0.55米，高度误差约0.30米。柱背厚度与盖石断面按侧照估计，展示框内的细小临时文字无法辨读。[现场尺寸与像素](measurements/field-dimensions.json) · [原城网格与相邻地块](footprint-review.json)

三字题名取实物外轮廓，门牌和文保牌题头以矢量字形呈现。近档及远档均保留独立柱座、地址牌、铭牌、展示框和题名。[建模源码](source/build_model.py) · [字体许可](source/fonts/OFL.txt)
