# 觉园香光堂临院木廊

常德路418号觉园列入上海市第四批优秀历史建筑，编号4B008。简氏在1920年建园，1926年捐园。上海佛教居士林建会于1918年，之后迁入这里。静安区图书馆把西侧香光堂、西南厢房和北部三进道场分别著录。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [静安区觉园资料](https://www.jingan.gov.cn/jagl/006001/006001006/006001006001003/20061004/5b13f5c8-174d-425b-b53a-5cc406b85d56.html) · [静安区图书馆](https://www.shjinganlib.net/JaImpressionHistoryContent.aspx?ColumnNameEn=HISTORICBUILDINGS&id=196)

## 厅名与拍摄面

2017年6月18日香光堂修复竣工的报道拍到门上的黑底金字「香光堂」。陈伟铭于2025年9月4日拍摄的院内照片补足了中央石阶、前排木柱、柱后的格扇、上层菱格窗和临院檐下的雕饰。2024、2026两个地图版本的航片能辨出西侧屋顶、东侧院地和北侧三座独立屋面。[竣工报道与揭匾照片](https://www.guoensi.com/Item/15092.aspx) · [陈伟铭现场照片](https://www.meipian.cn/5fz1mckp)

第22张照片记录了上午10时03分59秒的拍摄时间。雕板上的浅色凸件向画面右下方投影，与西楼东侧长墙面对的太阳方向一致。正射屋缘、院地与这处局部阴影一起帮助确定拍摄面。照片自身的定位精度只到周边街坊。[照片与勘定记录](reference-review.json)

## 模型范围

模型沿约24.68米的东墙绘制临院双层木廊。首层可见前柱、四级石踏步、内退格扇和匾框。檐下挂落及上层窗扇采用原创木格与曲线构件。近景保留较细的窗梃、木雕与独立门匾字形，远景保留窗轴、挑檐、柱廊和阶面。最外开间的收口、廊进深、瓦坡及雕花的细分依据可见轮廓估计。西面、主体室内、南北端墙和园内其他屋宇留待补查。[模型与原建筑的对应关系](footprint-review.json) · [正立面记录](source/frontage-registration.json)
