# 上海汽车博物馆：当前模型与证据范围

本模型采用 geometry-v2 的59项完整作者源码。原 README、设计说明、历史失败夹具和待验收文档保留写入时的原文与路径；本说明以及 `evidence/` 中的实际报告记录后续结果，不把旧 FAIL 改成 PASS。

暂存研究目录完整保留原118项历史文件；公开源码清单只选择其中相关的原始FAIL报告、旧结构证明和完整历史清单。旧raw/native二进制及未纳入工具冻结的摘要生成器仅列出处与SHA，不声称已随公开包交付。当前6114/5114/20/25检查、构件保留证明、请求及问题映射均保留完整原始报告，不以汇总替代。

重建以2016年照片为主要外观基准，包含北部高体量、西南低翼、银色弯卷外壳、五条沿壳体转弯的玻璃槽、分层退入幕墙、折转饰带、独立百叶、入口门与标牌、外部楼梯和开放屋顶区域。五层有原始资料支持。32.45米是官方历史名义高度，基准未注明；局部层高、曲率、退台、板缝、内部支承及未见屋面为估计。2006年同济采访所述15米与TJAD项目所述17米结构最大悬挑同时保留，不把其中任一数字当成银框到玻璃的实测退距。

当前原始模型有528396个三角形、12378个语义构件和23种材质。实际导出检查证实12372个旧构件的三角位置、对应法向与材质完全保留；仅一块屋面板下表面降低1.5毫米，新增五个局部连接件。原查询中的四片4F玻璃与八根楼梯末端栏杆柱分别经真实C壳和平台接合，保留原直接查询失败记录及角色修正依据。新增连接件与原始建筑轮廓、相邻735/797对象及五槽玻璃的保守实体包络另有实际检查。

6114项有限几何问题、2557片幕墙的上下边共5114项有限面积接合、五槽共20条针对所有可能相交不透明构件的实际射线均有独立报告。这些是指定部位、截面和射线的证据，不能推论整栋结构安全、任意位置无碰撞、完整气密接缝或实测隐藏内景。

四个实际交付资产的大小如下，均严格小于100000000字节：raw为31951432字节，web与LOD各10347300字节，native为14653789字节。web与LOD采用相同的压缩几何，实际文件SHA相同；两者均保留528396个三角形，没有几何减面或简化的性能承诺。实际解码后的位置、材质、法向和三种表示的有限检查，以 `evidence/actual-decoded-package.json` 及注册器生成的摘要为准；打包成功本身不代替解码验证。

根审核者已实际查看当前full/detail/rear三张原生图。full是1.7米眼高、45毫米透视，按模型包络后退适配；detail/rear沿用原正交相机。相机均未照片标定，预览反射、光照及环境不等于真实现场。

原始owner身份与坐标保持不变。西侧前场EN约[-55,9]米为几何观察候选，实际新版构件包络与地基投影继承证据已绑定；这不是地图标注的馆入口，也未证明脚下地面、台阶、公共通行、完整人物运动或第三人称相机扫掠。实际MVT源观察、模型替换及网页漫游是后续独立验收范围。此模型包的 prebrowser 结论不等于已安装、发布或完成全区建模。
