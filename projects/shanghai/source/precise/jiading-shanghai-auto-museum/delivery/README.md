# 上海汽车博物馆 geometry-v2 交付草稿

此处为待验收的独立模型交付文档。59项冻结源码、五张许可照片和原始地理身份均已列明；实际v2几何差异、连接件接合、原生三图、压缩解码、导航及浏览器证据仍由后续真实结果提供。不要将草稿或源码检查视为模型发布许可。

建筑以2016年照片为主要外观基准，高北臂、低西南翼、银色卷壳与五条玻璃槽、不同退台的幕墙、饰带、楼梯及屋顶花园使用独立几何。五层有主资料支持；32.45米为官方历史名义高度，并非实测标高。15米与17米两种结构最大悬挑口径并存；局部层高、退台、曲率和内部支承为估计，不据这些数字声称测绘精度或工程安全。

geometry-v2计划修复五处已发现的局部接合问题：新增五个连接件，仅将一块面板底部下延1.5毫米，保持可见体量和原始owner。实际构件保留数量与变化范围尚需新raw独立核实。full预览采用1.7米眼高、45毫米透视；detail/rear保持原正交相机。所有视角均未照片标定。
