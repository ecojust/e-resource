# 泰兴大楼（MEDHURST大楼）南京西路与泰兴路转角

上海市房屋管理局第二批优秀历史建筑2B004记载原名MEDHURST大楼、公布时名泰兴大楼、南京西路934号。静安区政府2006年《泰兴大楼》列出南京西路930至946号、泰兴路199至203号，说明公寓得名于原麦特赫斯脱路，在路口朝向东南。批次名录和大楼专条记载1933年竣工、新瑞和洋行设计，南京西路沿线条目另记1934年。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [静安区档案](https://www.jingan.gov.cn/jagl/006001/006001006/006001006001/006001006001001/20061004/f2592994-25ef-4abf-b83b-031c7bff4d83.html) · [大楼专条](https://zh.wikipedia.org/wiki/泰兴大楼)

Livelikerw于2013年12月12日拍摄了转角全景，Windmemories于2026年2月9日拍摄同一街口。中央高段的五道竖棱在顶部越过水平线脚，在上部数层向前突出，底端还有承托饰件。两翼共有四个折面，深浅相间的横带绕过转角，宽窗保留细金属分格。下部商铺门窗和遮檐按两期可辨的轮廓概化。[2013年照片及许可](https://commons.wikimedia.org/wiki/File:Taixing_Apartments.JPG) · [2026年照片及许可](https://commons.wikimedia.org/wiki/File:20260209_Taixing_Building.jpg) · [原件与三期航片记录](reference-review.json)

城市源3089和OSM实名建筑w1199798135共同确定五段街墙。模型沿街面向内取约4.5米，中央取十二层、两翼取九层。南端回收约1.16米，以保留与原地图轮廓局部相交的独立邻楼1085和原楼共墙。量测缺口包括窗扇细部、板厚、檐部进深及精确层高。原后楼、室内布局和店招分期另列。[冻结地形与原建筑](footprint-review.json) · [独立查看与模型下载](../../../medhurst-apartments.html)
