# 宋氏花园住宅主楼东山墙与南园折角窗

陕西北路369号院内的灰色坡顶住宅，旧址为西摩路139号。《上海名建筑志》记初建于1908年，倪桂珍在1918年买入，后于宅西侧扩建。市房管局第四批优秀历史建筑表以4B003登记369号。相邻登记4B002为陕西北路186号荣氏花园住宅，虹桥路1430号另一座宋氏住宅列为4M038。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [《上海名建筑志》原页存档](https://web.archive.org/web/20201104033159/http://www.shtong.gov.cn/newsite/node2/node71994/node81772/node81775/node81786/userobject1ai109014.html)

从陕西北路隔墙看，深色木梁构成东山墙，下方是敞廊、双柱和闭合的百叶窗。沿南园绕到折角，可见另一组窗的三道斜面。窗上坡顶向内收起，坡面开有带百叶的老虎窗。Fayhoo于2016年3月28日下午先后从街侧和园内拍摄，为两组窗确定了相对位置。两张照片采用CC BY-SA 3.0，原图及其署名保留在文件页。[街侧照片](https://commons.wikimedia.org/wiki/File:Residence_of_Song_Family_-_2.JPG) · [南园照片](https://commons.wikimedia.org/wiki/File:Residence_of_Song_Family.JPG) · [照片许可](https://creativecommons.org/licenses/by-sa/3.0/)

地图采用原城557的东端。南宅呈数道短坡，南侧接花园，东北侧隔窄巷另立一栋红色长屋顶建筑。2024年1月和2026年1月两期航片均保留了这个格局。两栋在OSM中同名，模型以实物的坡面及院墙定位。东山墙轴和折角窗进深的平面估计误差约1至2米，檐脊及烟囱高度的估计误差约1米。其余宅体、西侧扩建、北侧红屋面1770和375号怀恩堂沿用原城。[位置与航片记录](frontage-location.json) · [原城几何与签名](footprint-review.json)

百叶、栏杆、木山墙、圆柱、砖缝、老虎窗和屋面接缝均以三维几何表达。米色粗抹灰纹理由程序原创。原始网格和可编辑工程采用MIT许可。[照片和尺寸依据](reference-review.json) · [制作源码](source/build_model.py)
