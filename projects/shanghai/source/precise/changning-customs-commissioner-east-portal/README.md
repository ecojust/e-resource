# 上海海关税务司住宅东门砖砌喇叭口与石券罩

上海市第四批优秀历史建筑名录将这栋住宅登记在长宁区江苏路162弄3号，编号4M005。东侧山墙的阶梯形壁炉烟囱下有半圆石券罩。高参88在正面与右斜角拍到同一门洞，左侧砖墙上的绿色门牌清楚写着“3”。黄力炯在2018年的钢笔画中亦画出山墙与此门。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [高参88的现场照片](https://blog.sina.com.cn/s/blog_5d1bdf480101ettg.html) · [黄力炯的钢笔画](https://www.fx361.com/page/2018/0806/12063689.shtml)

石罩沿弧边有多道线脚，由两端的曲线牛腿承托。罩后砖洞的两侧和顶部向内收窄，红砖在券心上方呈扇面放射。石阶向入口逐级收小，花岗色腰线沿两侧砖腮转入。灰泥上的砂砾由程序生成，砖皮、栏杆、券罩与每级石阶均为真实几何。[长宁区规资局的住宅全景](https://www.shcn.gov.cn/col7698/20260429/1308971.html)

模型以内门估宽1.20米作比例基准。券罩挑距、墙体进深、木门分格及石阶尺寸为相片估算。市图的原户1463与住宅轮廓吻合，3号门牌点位于轮廓内。入口的精确墙面与东侧院道仍缺实测，故以独立页面查看。第三方照片和钢笔画仅链接出处。
