# 龙门邨尚文路总弄过街楼

沿尚文路走到133弄，可以从石拱下进入龙门邨。拱上是一方浅底红字石匾，从右向左读作「龍門邨」。上部红窗两侧各嵌一条窄红砖带，中央百叶窗上方有「1935」纪年。中央高檐、左右低檐的灰瓦与木托分别建模。[2019年弄口记录](https://www.sohu.com/a/347833473_120022970) · [2023年正面街照](https://www.shobserver.com/wx/detail.do?id=683508) · [修缮报道和题额近照](https://www.thepaper.cn/newsDetail_forward_30887548)

本次制作总弄口过街楼。市房管局以3A022登记整处龙门村，黄浦区资料记有76幢民居。门楼进深、瓦垄间距、背面收口和门洞尺寸按街照估算。门匾用字体轮廓近似朱曙题字，字底下沉并做红色填饰。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [黄浦区融媒体中心街区介绍及1947年图录](https://news.qq.com/rain/a/20260903A03GX400) · [逐图记录](reference-review.json)

地图位置参考南门位置点、尚文路走向和2017年有拍摄方向的街照。外墙宽约6.05米，通道深约4.15米，拱洞净宽约3.82米。街道和弄内通道连通，邻房仍沿用城市底图。[Fayhoo的2017年街照](https://commons.wikimedia.org/wiki/File:Longmen_Cun.jpg) · [位置依据](site-identification.json) · [原城市网格来源](footprint-review.json)
