# 安和新村瑞金二路198弄金饰铁门与门牌柱

门在瑞金二路西侧。南墩挂的绿牌可读为「198弄1–20号」「瑞金二路」，再下方蓝字牌列「瑞金二路」「198弄」「1号–27号」。两块不同时期、用途不同的牌在同一张正面照片里清楚可见，本件保留各自字样。中间公告只表现牌面。[2021年10月24日现场照片，Dragon](https://www.meipian.cn/46bi5n4r)

市房管局第四批登记为4C019「安和新村」，地址瑞金二路198弄。市级说明牌将住宅组建筑年代记为1912–1936年。2015年照片中的铁门中央较高，2020年、2021年街景和2021年正面照则可辨本件所据的平顶双扇、金色卷枝与门枪头。200弄1–2号的另一张公共照片用于鉴别相邻门牌。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2012年市级说明牌，Chinaone](https://commons.wikimedia.org/wiki/File:Shanghai_An-he_Terrance_1.JPG) · [200弄1–2号，Chinaone](https://commons.wikimedia.org/wiki/File:Shanghai_An-he_Terrance_2.JPG)

以五处可复核的球面街景影像交会定门轴。门心约东经121.46185°、北纬31.21092°，净宽估计4.09±0.35米，水刷石墩顶约4.03±0.35米。南扇内嵌小门、开启器外框和横杆按2021年静止状态建模；门背深度和卷枝线形采用近似尺寸。院内住宅和相邻入口均保留。[交会测量记录](measurements/street-gate-survey.json) · [原城位置](footprint-review.json)
