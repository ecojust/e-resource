# 孔氏别墅园侧高低三拱窗罩与曲线托臂

虹桥路2258、2260号。园侧底层深色窗框上方的三道白色拱罩，中央挑出的拱顶较高，两侧拱顶较低，曲线托臂自窗边向外挑起。

依据题名照片估整组三罩宽约3.2米。拱罩各自有外皮、薄前缘和内弧，四个支承轴按可见边线估算。照片下部受花木遮挡，窗下及室内留待实测。

参考图片由长宁区虹桥街道提供。项目页面只链接来源，展图由原创三维实体渲染。
