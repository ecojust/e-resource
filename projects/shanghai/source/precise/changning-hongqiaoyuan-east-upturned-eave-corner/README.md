# 虹桥源一号东楼歇山顶翘角与瓦垄

迎宾三路298号。恢复东楼歇山檐角的一段，两向灰瓦在斜角脊下咬合，棕木檐板随屋角起翘，两边檐下可见逐根排开的短椽头。

根据照片估单边檐口取样约1.95米，截取角梁、短椽、两片坡面和其上的阴阳瓦。正脊端饰与西楼立面另行调查。

照片只作建筑识别与测绘依据。网页展图由原创三维网格渲染。
