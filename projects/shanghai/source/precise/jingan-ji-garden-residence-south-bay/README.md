# 纪氏花园住宅临街折角窗塔

市房管局第四批4B007将纪氏花园住宅登记在静安区北京西路1510号。区里的“阅读静安”记载住宅建于1929年，现为静安区人民政府会议中心。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [阅读静安](https://m.readja.com/nd.jsp?mid=625&id=121)

模型沿北京西路还原南端的三面折角窗塔。中部钢窗之间有带边框的花环浮雕，外挑檐底有连续托块；顶部浅拱窗随塔身转折，低矮的红瓦帽在2015年的冬季街景中可以辨认。园内另一面有内嵌式门廊。街门、围墙、住宅两翼与后部继续沿用原城。[DVC0128，2008年7月27日发布的组照](https://bbs.fengniao.com/forum/932567_1_1.html) · [Livelikerw，2015年1月22日街景](https://commons.wikimedia.org/wiki/File:1510_West_Beijing_Rd._Shanghai.JPG)

房身与原城14-13718-6694的3194号建筑重合，独立取回的OSM轮廓w490437231第1版与原城多边形的交并比为98.01%。临街三段折面宽约3.33、2.96、3.33米。由影像比例估计主檐高约13.1米、坡帽顶约17.4米，高度误差约1.4米。节点间的小偏移、被树遮挡的瓦缝和花环内部叶片为近似细化。[OSM建筑轮廓](https://www.openstreetmap.org/way/490437231/history/1)

三维几何、窗框、浮雕与石面纹理均为原创。照片许可、原始图片标识、拍摄与发表日期见 [reference-review.json](reference-review.json)。[frontage-location.json](frontage-location.json) 保存两期航片与配准， [source/photo-proportions.json](source/photo-proportions.json) 记录尺度。
