# 江苏旅社弄内南门与山花

福州路379弄50号位于福州路南侧弄堂深处。上海市房管局第四批优秀历史建筑名录记为「江苏旅社」，现用途栏为「住宅」，编号4A033。2017年调查从东侧的分区入口绕到南墙中央，拍下旅社正门。上海黄浦2023年报道该地块征收完成；门扇状态、窗色与门牌采用较早实照。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [现场记述](https://www.sohu.com/a/138644829_409256) · [上海黄浦报道](https://m.thepaper.cn/newsDetail_forward_22024719)

正门两侧的浅灰圆柱有成对涡卷柱头。绿铁栅门向弄内打开，面向门口的右手侧挂绿色50号门牌。门上方是浅色矩形饰板、红褐色木格窗和椭圆徽饰，两侧束柱延至阶梯状阁楼墙头。正面的三次刊图为主要造型依据。门净宽估计1.66米，山花最高点约9.66米，采用当地投影米制。模型止于一开间，门内可走约一米。东侧门、六院回廊、屋脊、外围弄口及住户室内均待另查。[2015年正门照片](https://blog.sina.com.cn/s/blog_55c85ddb0102w15l.html) · [2017年图文](https://www.sohu.com/a/138644829_409256) · [2019年门牌近照](https://blog.sina.com.cn/s/blog_5d1bdf480102ywc0.html)

具名住宅用地轮廓和三版航片给出南檐和门轴，落位误差约1.7米。2015年院内与2017年鸟瞰使用同一个维基共享资源文件名，已分别核对修订时间、作者、原照片和相机元数据。[档案照片修订历史](https://commons.wikimedia.org/wiki/File:Jiangsu_Lvshe.JPG#filehistory) · [原图核对](reference-review.json) · [建筑位置与底图](footprint-review.json)
