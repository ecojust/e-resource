# 巨鹿路334号院内尖山墙窗与双坡瓦檐

上海市黄浦区巨鹿路334号。巨鹿路334号院内临街可见的一开间尖山墙。两道红色斜檐在墙顶相交，浅色山面中嵌上窄下高的一组六格窗，窗台下有一段水平腰线。

2013年与2021年的街景均可见同一尖顶、矩形窗洞与右边廊柱。模型采用2021年浅色粉刷后的外观，按窗宽约1.30米换算可见比例。两站交会角仅约4.3–4.8度，院内楼号、原始建造年代、瓦的背面和进深尚欠实测。
