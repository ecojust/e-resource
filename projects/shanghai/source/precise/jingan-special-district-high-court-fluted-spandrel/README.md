# 浙江北路高等法院旧址卷首壁柱与几何窗间墙

第四批市名录把会审公堂、上海第一特区地方法院和江苏高等法院第二分院列在浙江北路191号。Fayhoo于2016年2月28日分别拍摄并题记同址两幢建筑。14时48分的照片将卷首壁柱立面题为1931年高等法院，早三分钟拍摄的是覆藤的旧公廨。此处取后一时期建筑的两根壁柱及其间的上下窗。
