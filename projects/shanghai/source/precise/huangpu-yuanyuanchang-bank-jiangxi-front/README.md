# 源源长银行江西中路473号圆徽砖立面

上海市第四批优秀历史建筑名录将江西中路473号列为4A004，原用名为“源源长银行/东方企业公司”，现用途为住宅。门旁上海市人民政府2005年公布的保护牌写着“砖木结构，约1930年代建。艺术装饰风格”，并提到对称构图和简化壁柱。私人走访正文另记1919年。本模型年代采用现场牌的说法。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [现场铭牌和两张街面照，图11至13](https://www.meipian.cn/2z8iva7q)

沿香港路向西能看见整段临街面。两根有竖槽的浅色壁柱托住阶状墙冠，棕砖墙中央的圆徽两侧有横向翼饰。它下方的一扇宽窗和两扇窄窗对应首层门口。Fayhoo上传的斜照还可辨南端店口和北端大窗。窗扇、门扇和卷门按实照外形简化。照片旁电杆的“43”为电杆标记。[Fayhoo，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Yuanyuanchang_Yinhang_Jiuzhi.jpg) · [引文、日期与图权记录](reference-review.json)

临街边取原城2729号建筑，方位沿江西中路向北偏西，长度19.05米。2020年2月香港路向西及2021年1月江西中路向北的街景共同确认这栋独立门面，与路对面的自力大楼及北边的自来大楼区分。摄影位置和原城多边形来自不同底图，街道方位拟合和边界约差2至3米。模型贴合原城东界，沿街墙冠的半圆尖取14.17米。窗高、雕塑凸出和门深是按照片估出的尺寸。[原城足印与资产](footprint-review.json) · [相机与球面像素](street-photometry.json)
