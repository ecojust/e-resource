# 四川北路2305号住宅弧券门头与双曲托

5F025在市表登记为住宅，门牌四川北路2299弄（1-3号）、2319弄（1-3号）、2339弄（1-3号）、2305-2345号（单号）。四川北路2305号署名街照中，半圆门券的两侧各有一枚收脚的曲线托座，上部托起平出门檐，檐底有一排小齿饰。模型取门券起拱线以上及两侧托座。

灰色粗面墙衬出浅色半圆券，券脚两端各有较宽的方块。正下方仍能看到深色门框横档。 门檐正面分为数层凹凸线脚；右侧曲托上部圆卷凸出，腰部内收，底部尾端又向外翻。左侧门托只露出一部。

拍摄方向贴近街沿，近处托座比远处大。现行名录覆盖邻近多弄及门牌，只有2305号作为本件原照所题地址。曲托的进深及左端被遮去的轮廓据右端估计。
