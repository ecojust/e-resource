# 仁记洋行大楼东南转角

市房管局第二批原表以2A017登记仁记洋行，门牌为滇池路100–110号。相邻的业广大楼位于滇池路120号，市表编号为2A016，另列四川中路444–464双号。工作清单第174、175行有不同的旧编号及使用单位，逐行摘录保存在本宅来源记录内。两栋街屋都在底图具名，独立占地没有交叠。[原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [来源与校验值](reference-review.json)

1908年出版物已摄得三层街墙与圆角的尖顶。2007年10月27日的两幅街面近照和Fayhoo原件所记2017年2月1日的路口全景均可辨识同一圆角和两侧窗墙。后两期资料显示鼓座上方低平。模型采用当时可见的下部遮阳篷、红砖贴柱、上层阳台石栏和鼓座窗，向两个街面各延伸一段。柱身、砖色和层高为照片估计。内院和其余街墙待查。[1908年出版影像](https://commons.wikimedia.org/wiki/File:Tcitp_d615_offices_of_gibb_-_livingston_%26_co.jpg) · [2007年街角](https://commons.wikimedia.org/wiki/File:100_Dianchi_Road_-_Gibb_Livingston_%26_Co._Building_-_panoramio.jpg) · [路口全景及版本历史](https://commons.wikimedia.org/wiki/File:The_Gibb_Livingston_%26_Co._Building.jpg)
