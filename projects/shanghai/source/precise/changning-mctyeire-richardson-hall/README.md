# 中西女中景莲堂（五四楼）

江苏路155号北楼景莲堂（今五四楼）建于1935年，位于大草坪北侧，市房管局在2M008号名录中合列北楼与东楼。1916年6月27日，中西女塾付清爱丁堡路新址购款，当年秋季高年级已在购入的二十五室住宅开课。市文旅推广网将迁校记为1917年。校长Martha E. Pyle记载，1922年9月12日寄宿部入住新宿舍Lambuth-Clopton Hall。Jennifer Bond的访校照片将它辨认为今五一楼，市文旅推广网称这座1922年的东楼为海涵堂。 [1916–17年报，第196页](https://archive.org/details/seventhannualrep01meth/page/196/mode/1up) · [1922–23年报，第305页](https://archive.org/details/thirteenthannual1923meth/page/305/mode/1up) · [Bond的访校记录与照片](https://eccleshistsoc.wordpress.com/2018/08/25/foreign-puppets-christian-mothers-or-revolutionary-martyrs-the-multiple-identities-of-missionary-school-girls-in-east-china-1917-1952/) · [上海市文旅推广网](https://www.meet-in-shanghai.net/cn/shanghai-cultural-relics-protection-unit/the-former-site-of-the-chinese-and-western-girls-school-788399/) · [原页与楼名核对](measurements/east-building-dates.json) · [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html)

草坪南立面有五段教室窗和两端平顶翼，中央为双层平缓尖券门厅。十一扇屋窗按四、三、四成组，每扇各有三坡小屋顶。红瓦前坡、端部女儿墙、石框十字窗和门头三联彩窗按文旅正面照和长宁区两张草坪斜照重建。主翼宽58.78米，2019和2025年航片给出的轮廓长度为58.09与59.50米。外墙采用按实照颜色取样的水泥砂浆仿石分格，另为红瓦和镶板木门分别制作颜色与法线贴图。[实照机位及原始像素](measurements/oblique-stations.json) · [倒T形足迹与两期航片](measurements/north-and-east-boundaries.json) · [饰面取色](measurements/finish-readings.json)

从主门进入，可见吊杆连接格栅顶板，十面金属灯冠下悬两层琥珀色玻璃。中央三樘木门之上为三道圆券楼廊，两旁接横向通廊。以照片中三樘门合计宽4.65米作条件尺度，左右门关闭时各留约1厘米中缝，中间右扇开启后可直通约0.57米。原照反投的通行宽约0.60至0.63米。两侧拱廊只有一侧完整入镜，另一侧据局部可见构件及长宁区对两廊的文字说明补齐。[门厅照片与机位](measurements/vestibule-station.json) · [长宁区建筑与修缮记录](https://www.shcn.gov.cn/col6991/20221017/1223835.html)

礼堂两侧分别设三组尖券花窗和楼座旁的矩形彩窗。近景保留红花窗心、蓝绿玻璃、铅条和楼座下券口。两组坐席之间的走道与门厅中门相通，格栅顶延伸至北端舞台。楼座前缘距主入口约25.79米，采用2017年室内照的中央走道灭点、门轴、楼座栏顶和侧窗共同拟合。座席行列、楼座标高及遮挡的舞台设备缺少竣工图，现有座位数量供模型表现。[礼堂透视与留出点](measurements/auditorium-station.json) · [彩窗原照取点](measurements/auditorium-observations.json)

另一张同日照片可辨侧门两扇外开的木门、右扇圆把手、券下亮子、卷边雨棚、落水管与两整一截窗。按净宽1.82±0.20米推算，门高约2.18米。依据现有照片难以确定侧门在主体上的具体位置，浏览器可单独切换这件构件。原生模型保留十一台主楼相机。近档主楼1,803件、120,652面，远档1,583件、80,052面，另有独立侧门近远两档。[侧门机位](measurements/side-entrance-photo.json) · [展示与下载](../../../mctyeire-richardson-hall.html) · [资料与许可](SOURCES-LICENSE.md)
