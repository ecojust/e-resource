# 中西女中景莲堂草坪教学翼

江苏路155号中西女中北楼旧称景莲堂、连吉生纪念堂（Richardson Hall），现称五四楼。市房管局名录2M008同时列北楼与东楼。上海市文旅推广网记1935年北侧建景莲堂，1922年东侧建海涵堂。两栋隔草坪相望，已有东楼模型独立保留。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海市文旅推广网与草坪正面图](https://www.meet-in-shanghai.net/cn/shanghai-cultural-relics-protection-unit/the-former-site-of-the-chinese-and-western-girls-school-788399/) · [东楼模型](../changning-mctyeire-east-building/README.md)

模型按文旅推广网1200×486像素正面图重建南面三层教室窗、两端城垛女儿墙、五段开间、四三四编组的十一扇屋窗及中央哥特式窗饰。窗中竖料、横档和门上的三片透光窗均可拆分。两期航片中整段南翼长58.09至59.50米，原城市733号地块的长边58.78米，红瓦部分约43米。用地块尺度把窗和檐的位置换算到米，纵向房间布局及室内层高另待图纸。[原照片与草坪机位](measurements/frontage-station.json) · [北楼与东楼足迹、航片](measurements/north-and-east-boundaries.json)

首版近景345个闭合构件、47,200个三角形，远景345个闭合构件、21,208个三角形。39个独立材面校核点中，两档各37处直接命中，另两处相差1像素。Ctny拍摄的五四楼门厅和侧门另有清晰照片，可供后续核对深度及构造。[近景模型](../../../data/audit/mctyeire-richardson-hall-v1/working-geometry/full-source.glb) · [实照机位模型图](../../../data/audit/mctyeire-richardson-hall-v1/working-geometry/lawn-model.jpg) · [照片和出处](reference-review.json)
