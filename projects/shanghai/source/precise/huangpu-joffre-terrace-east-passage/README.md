# 淮海坊茂名南路总弄题名过街楼

上海市房屋管理局将霞飞坊登记为第四批优秀历史建筑4C004，现名淮海坊，整片建筑的登记地址是淮海中路927弄。模型所选的总弄东口位于茂名南路100号。2015年东口正照中，过街楼的平梁上写着“淮海坊”。2020年两次街景采集的四个机位均能辨认同一平梁、左右半圆纹和上下两对窗。淮海中路北口另有宽拱与圆窗。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Livelikerw摄于2015年的东口正照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Joffre_Terrace_Shanghai.JPG) · [四个实景机位及来源](reference-review.json)

东口两层窗墙跨在总弄上方。底梁下缘按实景估为3.8米，跨宽约7.1米。下层两扇窗各用六列五行细框，上层南窗为两扇通高玻璃，北窗多一道横档。两块窗间板的做法也有差别，南块能看到斜折面。中央檐口高于两侧低肩，每侧有三只托石。窗扇、窗套、过梁底面和三字题名都作为独立网格制作。[照片控制点与测量误差](reference-review.json) · [过街楼分件源码](source/east_passage.py)

两期街景在沿街绝对坐标上有数米差异，街照用于确认比例，屋体落位另核原城楼体和总弄的朝向。窗框深度、墙厚和背面轮廓为外观估计。2015年照片中的临时标语、晾晒架、街道设备、两侧商铺和总弄内的各栋住宅留在本次范围之外。建筑材质和题名字形由程序绘制。
