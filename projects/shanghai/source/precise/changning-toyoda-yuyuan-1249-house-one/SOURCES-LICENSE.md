# 来源与许可

上海市房屋管理局第五批优秀历史建筑名录的5M022行为“丰田纱厂干部住宅”，原址“愚园路1249弄1号”。原相册说丰田纱厂于1921年开办，这一年只指厂史。住宅单栋的确切竣工年份尚待图纸或档案确认。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

Antigng的具名照片摄于2018年2月10日。原图同时收录联券长廊、转角端窗和三个侧面小券，公开许可为CC BY-SA 4.0。原片在园内的GPS记录为相机站位。[Wikimedia Commons原图页](https://commons.wikimedia.org/wiki/File:愚园路1249弄1号住宅.jpg) · [许可](https://creativecommons.org/licenses/by-sa/4.0/)

高参88相册记录了同弄两座干部住宅。2013年6月17日的侧面近照可以逐窗对回具名照片。2014年相册中另一正面照的门牌明确为2号。两栋的相近券廊需要借助端部及门牌分辨。原摄影权利归各自作者，网页只提供原出处。[高参88原文](https://blog.sina.com.cn/s/blog_5d1bdf480101iozf.html) · [原片登记与SHA-256](measurements/photograph-register.json)
