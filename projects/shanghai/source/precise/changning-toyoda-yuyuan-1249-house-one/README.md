# 丰田纱厂干部住宅（愚园路1249弄1号）

从长立面的一端可以数出四个连续的大圆券，三个共用支点为带柱础、柱头的圆柱。山墙下另有一扇较窄的红木窗，窗上方留有补砌的砖券。转到另一面，三座底层小券共用一根石窗台，旁侧门廊有一个宽扁券和一个回向小券。门廊深处的门、灰黄墙面上的圆孔和入口踏步取自2013年的实拍。住宅列入上海市第五批优秀历史建筑，市表原址为愚园路1249弄1号。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

两期照片分别用于量测。2018年具名转角照提供上部券头、圆柱、边窗、屋面和门廊的相对位置。2013年近照补足了侧门廊及三小窗的扇框、砖缝、窗台与入口。小窗净宽以砖皮为尺暂取0.66米。由此拟得的长墙约17.45米、侧墙约14.35米，数值随原砖尺寸、相机焦距和树木遮挡而变化。沿长墙的底层在具名照片中被附属低墙挡住；模型以实墙收口。背面采用简化体量。院内2号另有相似的圆券长廊，照片中的绿色2号牌用于区分地址。[照片登记](measurements/photograph-register.json) · [局部尺寸和屋盖参数](source/house-layout.json)

近景和远景均保留三个落地层窄窗、圆柱、门廊前后进深，以及上层独立窗格。红砖径缝、石柱、门框、铁栏和屋顶可在生成程序中分别修改。灰砖及瓦面均为原创程序纹理。[展示页](../../../toyoda-yuyuan-1249-house-one.html) · [几何与照片复核](../../../data/audit/toyoda-yuyuan-1249-house-one-v1/README.md) · [来源与许可](SOURCES-LICENSE.md)
