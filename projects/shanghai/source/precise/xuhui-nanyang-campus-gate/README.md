# 交通大学徐汇校区老校门

上海市第二批优秀历史建筑名录 2D015 将南洋公学的正门、体育馆、校办公楼、教学楼和图书馆列在华山路1954号。这里单独重建校史所述的1935年宫门式正门。1898年原门照片显示一高两低的三间木牌坊，校方在1934年筹建新门，1935年改建为朱门碧盖的宫门。1950年代校门外河浜被填，1998年道路拓宽时桥头灯柱在原处重置。[市府名录、学校档案和年代对照](reference-review.json)

2010年4月24日华山路正面照可见中间门洞开启、两侧砖砌墙、四盏红灯、白底黑字竖牌和成对石狮。2017年的斜照可辨绿瓦瓦垄、两端的吻兽、琉璃飞檐及狮座。2015年从校园一侧拍摄的图像明确显示两侧红色格窗、门前圆柱及通透的中央门道。2021年同一处街景记录三开门扇合拢。模型采用门道开放时的形态。[各角度照片与实际图像回执](reference-review.json)

屋面主体、主脊、四条垂脊、檐口和两端吻兽分别建模。近景另做部分砖缝、彩画纹样及狮鬃细节。门牌用独立挤出的四个汉字，字形使用经授权且改名的字体子集。瓦色、门扇、梁枋、门柱和石狮据实景估色。缺乏测绘尺寸的脊高、狮像、斜垄飞檐与彩画采用比例估计。[字体许可](source/fonts/OFL.txt) · [可编辑模型源代码](source/palace_gate.py)

具名OSM面与冻结地图源对应同一座门楼，投影面积约200.58平方米。低分辨率城市高度来自两处10米栅格采样。两座独立石狮位于地块前端，校园侧窗下保留灰墙裙，中央通行线穿过两侧房及打开的门扇。南邻797仅在源边界处极近，独立保留。门前桥头灯柱、向南北延伸的围墙及校区其他登记建筑在本件范围外。[地块与航片](footprint-review.json) · [模型页](../../../nanyang-campus-gate.html)
