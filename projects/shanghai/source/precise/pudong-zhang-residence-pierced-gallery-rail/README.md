# 三林塘张氏宅二层廊栏的连续红色透花栏板

5W011在市表登记为张氏宅，门牌三林镇东林街65弄7号。Fayhoo于2015年4月25日拍摄东林街65弄7号张氏家宅。院照中，二层廊前的深色横栏夹有一列窄长红色透花栏板。本件取其中四格，用成对卷线、纤细竖条和中央的突起花结表现栏内的空隙。

红色细边框沿上下横栏间分格，每个框的宽度明显小于框间高度。相邻小框之间留着直通的空档。 每小框顶端横格内有向左右舒展的短卷枝，中央贯以一串花结，下部有较长细卷线和靠近底边的窄横条。各框的深色上下横栏连续。

东林街65弄7号的院内照片能确认花栏的位置和重复形状。细线在低分辨率处有遮合，截面、表面材质和绝对尺度均为近似；墙后房间和全院平面未测绘。
