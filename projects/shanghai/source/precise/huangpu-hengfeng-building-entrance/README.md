# 恒丰大楼江西中路题名门罩与柱列

上海市房屋管理局第四批名单将恒丰大楼记为4A005，门牌为江西中路450至454号，列入当时用途的单位为上海航道局。444号、464至466号自力大楼、484号自来大楼均有各自的底图记录。恒丰大楼的具名轮廓为 OSM 495116056 第3版，与城市模型163号的足印交并比为99.23%。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [建筑轮廓](https://www.openstreetmap.org/way/495116056)

Fayhoo上传的街道照片可读出门楣上的“恆豐大樓”。绿色门牌的末两位“52”露在遮挡物右侧。照片于2015年1月19日北京时间上传，未标拍摄日。2013年10月10日和2021年1月12日的两期街景独立记录了门柱、柱座和凸出的圆弧山花，同街南侧相邻开间另标450。照片为资料引用，模型使用独立绘制的建筑几何。[街面原图与授权](https://commons.wikimedia.org/wiki/File:Heng-Feng_Building.jpg) · [两期街景、图像来源与实测记录](reference-review.json)

主要构件包括题名额枋、光面圆柱、柱头涡卷以及后侧凹槽大柱。圆弧山花内各有一排矩形齿与卵形饰，心形中心两侧可见对称卷草。山花里的红色数字按照片记入外观记录，其含义待考。二手资料称建筑于1931年竣工、初建三层，后来增至六层。官方名录没有提供增层年代；照片顶端只够辨认入口上方短檐。[建筑年代二手资料](https://zh.wikipedia.org/wiki/恆豐大樓)
