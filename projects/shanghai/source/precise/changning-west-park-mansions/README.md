# 西园大厦

上海市房管局第二批2M004条目记为「西园大厦／西园公寓，愚园路1396号」。长宁区规划资源局的2021和2023年记录均写1928年，建筑研究资料给出1927至1928年。二手索引的1912年与它们不同。楼层在不同材料中有七、八、九层几种口径，立面按可见窗层及屋顶格架制作。[市名录、照片与建筑沿革](reference-review.json)

南向花园面采用2014年2月的原片。三组宽浅拱、端间窗、屋顶两座透空花架在早期照片中已有记录。2014年的实照还显示有的阳台保持开放，有的已经封窗。北向长宁路一面依据2021年1月两个摄影站，建出端部和中央窄窗之间的两处上层窗井。井下可见店面及低檐；模型在各自的原楼轮廓内分别保留低体，进深和高度依照片估算，院外店铺另计。2022年市房管局记载了修缮工程，修缮后每户的窗式、背街井深和楼内平面仍需档案。南面后建沿街房、1382号住宅和院道均有独立位置。[底图楼体与街道](footprint-review.json) · [三期航片](aerial-editions.json) · [可编辑的参数化模型](source/mansions_geometry.py)
