# 中一信托大楼北京东路正立面与银行大厅彩绘天棚

北京东路270号的中一大楼是通和洋行设计的信托公司总部。1924年设计图的委托方为中央信托公司，后改称中一信托有限公司。上海市第四批优秀历史建筑名录以4A009登记本楼。西侧280号是另行登记的盐业银行。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [建筑沿革和二层平面](https://www.sohu.com/a/431529594_805742)

临街正面分为三个开间。原五层上方的大檐口仍完整可辨，20世纪90年代增建的两层位于其上。二至五层各有九条窗轴，每组三窗中央较宽。首层中央的两根槽柱立在门扇之前，门套以回纹围合，上楣的「中一大樓」四字从右起读。临街东翼还设一个落地侧门，西翼相应位置有石窗台。[2014年北京东路街照](https://commons.wikimedia.org/wiki/File:Former_Central_Trust_Co._Building_Shanghai.JPG) · [2023年门廊实照](https://imagepphcloud.thepaper.cn/pph/image/258/684/751.jpg)

前楼中央天井直通屋顶。彩绘天棚在二层与三层之间，站在厅内可以看到四道带圆心的装饰、铅条、绿色边带和回纹。由天井俯视，最先看到的是浅灰双坡护盖。两层玻璃分开制作，独立观察页可以切换两个方向。2023年一层成为蜂巢当代艺术中心，浅色金磨石面层下仍保存原有的部分马赛克地面。[2015年修复前后图与天井照片](https://www.sohu.com/a/431529594_805742) · [黄浦区关于展厅改造的报道](https://www.thepaper.cn/newsDetail_forward_23635231)

临街宽度按OSM轮廓估为21.24米。二层平面图与原城足印配准后，天棚估为5.69米宽、17.94米长。不同角点取样给出的宽度范围为5.44至5.99米，长度为17.30至18.24米。窗高、进深、门廊柱距、装饰细纹和隐蔽屋面均含估计。模型在前后楼相接处收束，后楼和办公房间仍待进一步调查。[平面配准](source/conservation-plan-fit.json) · [街面配准](source/street-window-registration.json)
