# 上海公库（原三井银行）九江路正门

上海市第二批优秀历史建筑2A043列九江路50号。原三井银行1934至1937年建造，公和洋行设计，钢筋混凝土结构，五层。四层高的花岗石柱廊面向九江路，战后曾作上海公库。2015年1月2日照片中，门楣的50号和中国建设银行的招牌清楚可读。[市级历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [楼史和相片档案](reference-review.json)

中央24.2米范围包含三组凹窗、六根切角巨柱、突出的大檐、两个长铁花窗和有三段八角装饰的双扇门。六柱按一、二、二、一排列，四层的每一排窗按二、三、二分组。柱头的切角凸饰与细竖缝、门扇中层凸起的椭圆饰件，可在原片局部检查。建设银行中英文招牌按照片所示的时点制作。石材分缝、柱身尺寸和进深按照片比例估计。[原片校正与观察点](photographic-rectification.json) · [制作源码](source/build_former_mitsui_bank.py) · [摄影署名](../../../data/audit/former-mitsui-bank-v1/photo-credits.md)

带九江路50号的建设银行点同时落在两个粗模地块内，两者共享南立面，内院洞口和高度不同。模型仅处理中央临街段。九江路36号原三菱银行有独立占地和实物照片，同一位作者在拍摄50号84秒后拍下36号。两端街墙、整块后部用房、天井及屋顶设备保留原有城市信息。[门牌和地块](identity-review.json) · [街墙坐标、来源和瓦片](footprint-review.json)
