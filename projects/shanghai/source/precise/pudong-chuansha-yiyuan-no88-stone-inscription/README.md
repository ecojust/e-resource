# 川沙以园北城壕路88号四字石额

88号门上方有一块横向浅色石额。槽内四组旧字留有阴影，匾外从高起的窄唇，经斜面、圆线和小凹线退入字面。模型保留在2018年和2021年两张照片上都能辨认的字形和框线。

2021年照片中匾高约九个砖皮。取每皮约6.6厘米作展示尺度，外框约1.86×0.60米；石额的真实厚度、浅浮雕深度及已磨失的笔端仍是估计。

2018年1月30日新浪新闻转刊的以园报道附刻石近照。行走江湖的土豆于2021年1月分享的照片同时拍到88号与原匾。报道按画面从左到右记为“宏德以道”。摄影作品版权归原权利人；公开模型采用独立绘制的断面与笔迹。 [2018石匾近照](https://k.sina.com.cn/article_6430516229_17f49e405001002jbj.html) · [2021年双匾对照](https://www.dutiger.com/thread-1171-1-1.html) · [陆家四堂沿革](https://m.163.com/dy/article/DCQCFDFU0525L0GC.html)
