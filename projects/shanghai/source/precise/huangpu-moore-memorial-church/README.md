# 慕尔堂（沐恩堂）

上海市房管局第一批优秀历史建筑登记 `1A018`，原名栏为「基督教慕尔堂」，名录现名「沐恩堂」，地址「西藏中路316号」。现址由邬达克设计，1931年落成，包括大礼堂、钟楼及四层附屋。1936年加装五米高的霓虹十字架。云南中路的早期礼拜堂在另一地点。[官方名录](https://fgj.sh.gov.cn/yxlsjz/20200331/fe7b4d6f35774b708a2c5122849065bd.html) · [中国基督教网](https://www.ccctspm.org/churchinfo/205)

2010年正面和侧面照片记录三处面向西藏中路的红砖山墙。中间的礼堂退在西北、西南附楼之间，西门上方有尖拱花窗和石色门廊。西南侧为方形钟塔，可见上下两级长窗、阶梯扶壁、平顶垛口与十字架。两侧附楼的带框凸窗随进深转入院中。模型按这些照片制作窗洞和窗框，东部附楼依建筑边界简化。2013年照片用来比对钟塔上层窗、门廊和十字架，另以2016年塔顶照片复核轮廓。[角度、年代及许可](reference-review.json)

OSM `w1197586458` 和当前上海底图宏 `14-13720-6694` 的第2297个建筑对象同时覆盖大堂与相连附屋。2018、2021年存档航片可辨三条屋脊和南侧塔顶；高楼视差会使屋顶偏离地面，布局另经街景与平面交叉检查。模型展示照片年代的静态外观，立面开间、屋顶坡度、窗花纹样与十字架高度均包含估计。交付含原创几何及材料，未嵌入影像。[底图边界与航片记录](footprint-review.json) · [OSM建筑](https://www.openstreetmap.org/way/1197586458)
