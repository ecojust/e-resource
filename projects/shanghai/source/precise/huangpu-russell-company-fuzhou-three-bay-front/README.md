# 旗昌洋行福州路三开间石墙与尖券窗

市房管局第四批4A021登记旗昌洋行，地址福州路17、19号，使用单位为上海市生产服务合作联社等。这座建筑位于外滩9号西侧，约建于19世纪中期。外滩9号的轮船招商局是1901年重建的三层临江建筑，在原城有独立的1580号足印。两处土地长期归同一企业所有。[第四批原表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2016年现场门牌与分栋调查](https://blog.sina.com.cn/s/blog_70dd482a0102w8c4.html) · [招商局地块沿革](https://www.thepaper.cn/newsDetail_forward_10472621)

2015年2月6日的原片及2021年1月8日的街景都可逐一定位福州路三开间石墙。底层自东向西为蓝色门、白色扇和深色扇，三孔都带圆券。楼上尖券框住凸窗，石墙上可见门窗套、砌缝、雨水管，出檐下排列托块。东侧有带铁栏的台阶，中央窗前为抬高的平台与种植槽。2021年西侧浅色加建门面有绿色17号牌。此次范围止于三开间石墙的两端。临街西段、南弄、院内及未见屋面留待另查。[Livelikerw于2015年拍摄的原片](https://commons.wikimedia.org/wiki/File:17,_19_Fuzhou_Rd._Shanghai.JPG) · [摄影站、作者及公开出处](reference-review.json)

原城1140与OSM 380340030的面积交并比为98.86%。短边长8.91米，三个门窗中心由三台街景摄影点交会。街景原始坐标与底图之间存在约一至两米的偏差。对2015年相片另用照相机EXIF焦距与三轴门窗进行透视拟合，1,000像素宽的参照图上均方根误差约2像素。中间白门平台至檐顶约9.2至10.2米。地面被花池遮挡；台阶、屋檐高及局部进深均为估计。[原建筑与邻房](footprint-review.json) · [三站交会](../../../data/audit/russell-company-fuzhou-three-bay-front-v1/preflight/three-bay-survey.json) · [独立照片的尺度核对](../../../data/audit/russell-company-fuzhou-three-bay-front-v1/preflight/independent-photo-height.json)
