# 培文公寓淮海中路街面与重庆南路圆角

上海市房管局第二批名录列“2C002 培文公寓 淮海中路449号”。Virtual Shanghai 将 BEARN APARTMENTS 登记在霞飞路453/469号。历史影像记录旧称，今门牌以市级表为准。工作名录列1923年，后出的建筑史料将1923年记作投资起始；黄浦区商务委员会与区融媒体中心合办的2020年图文记法商万国储蓄会投资、赉安工程师事务所设计、中法营造厂承建，1930年竣工。[房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [历史门牌](https://www.virtualshanghai.net/Data/Buildings?ID=1785) · [2020年黄浦图文](https://www.thepaper.cn/newsDetail_forward_9162556)

2020年图文中的历史全街照可辨长窗墙、凸窗、几次退台、阶梯塔冠以及底层商铺挑檐。该文未标注这张全街照的拍摄年份。另有 Virtual Shanghai 收录的街景，馆方将其年代估为1945至1949年。Legolas1024于2014年8月2日拍摄的东侧照片可见圆角顶层连续窗、塔冠小尖饰和屋顶商店题字。[历史街景](https://www.virtualshanghai.net/Photos/Images?ID=33288) · [2014年东端实照与署名](https://commons.wikimedia.org/wiki/File:淮海中路培文公寓.jpg) · [图片与时间收据](reference-review.json)

模型表现97号街边主楼约70米平直立面及东端约27米圆角。沿街主体通常为六层，东端升至七层，淮海中路中段升至九层。各层高度、凸窗展宽、退台进深、窗格和面砖色泽按影像推估。底层店铺依可见的商铺檐带和窗墙概化，保留2014年可见的屋顶商店题字。西端转入另一街面的翼楼、后方住宅、内部及近代天桥沿用城市已有资料。窗洞使用有厚度的墙体、内退玻璃和独立窗框，临街凸窗带有斜向侧窗。[地图源体与门牌](footprint-review.json) · [参数与作者文件](source/build_model.py)

源体97与院内另一栋具名同址公寓1180相隔约8米，院内另有独立979号配楼。三者逐栋区分。项目几何和材质为原创，字样使用经改名和裁取字形的Noto子集。[字体授权](source/fonts/OFL.txt)
