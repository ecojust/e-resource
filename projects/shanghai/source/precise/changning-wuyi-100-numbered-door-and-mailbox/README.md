# 武夷路100号街门与绿色门牌邮箱

5M017在市表登记为长宁区机关事务管理局，门牌武夷路100号。2018年2月13日Antigng署名原照中，「100 武夷路」门牌贴在临街红砖洞口右边，下方是同号绿色邮箱，门头有一排竖砖。市表5M017登记武夷路100号住宅，现名为机关事务管理局。本展截取可由门牌确定的街面入口。

竖砖跨在门洞顶端。洞口的左侧浅色灰泥返进墙中，最里面是一面深色门扇，廊顶可见两盏小灯。 绿色门牌的100数字下方有武夷路三个字，下方较大的邮箱有盖口与小锁。模型以公开许可字形重排数字和街名。

街门的修建年份未见于照片。院中可见多处红瓦建筑，照片不足以逐幢指认为登记住宅。门后深度、邮箱凸出和砖模数按照片估算。门内小字、右侧另设的小牌和前景临时器物未作辨认建模。
