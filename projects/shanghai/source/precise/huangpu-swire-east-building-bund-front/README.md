# 太古洋行东楼临江七开间红砖正立面

1906年建成的太古洋行东楼位于中山东二路22号，主入口朝向黄浦江。市房管局第四批4A025将其列为丰华大楼。2020年结构加固资料另有一幅分栋图，标出后部北楼与南楼；2022年10月报道记录了940天修缮后的临街面。模型取东楼向江的五层七开间。新永安路北楼、南楼、室内及各楼围合的中庭留待另行调查。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2020年分栋和结构勘查](https://www.sohu.com/a/381154987_795849) · [2022年竣工与外墙细部](https://www.sohu.com/a/601104622_121332532)

七开间的中轴首层是石券与铁门，二层门罩上是曲山花。上方两层的窄双券由柱头隔开，外侧三开间以单孔窗成组。2011年实照能看到部分开间向内退的廊壁。后来的独立街照和竣工照则清楚拍到玻璃窗框，原铁栏仍在。模型沿用现状的玻璃和铁栏，并按竣工局部照片绘制红砖、券石、柱头和檐口。窗内进深和铁件截面按可见比例估算。[Can Pac Swire摄于2011年5月15日](https://commons.wikimedia.org/wiki/File:Formerly,_Butterfield_%26_Swire%27s_Shanghai_Office_(thanks_to_Geoff-inOZ_for_the_info!)_(6057930726).jpg) · [Fayhoo于2015年上传的照片](https://commons.wikimedia.org/wiki/File:Butterfield_%26_Swire.jpg)

原城747与具名OpenStreetMap足印495105937的交并比为98.14%。临江墙边实测投影长30.76米。2011年照片保留了相机等效52毫米焦距。以墙边长度、各层窗台和券顶拟合相机后，主檐高约25.1米、女儿墙顶约26.2米、中央山花顶约27.7米。前景绿篱遮挡部分路缘，基准地面仍有约0.35米不确定度。原城该楼高度字段为16米，矢量聚合所报19米；本次仅用照片高度补出沿江一面。纹理为程序自绘，现场照片的作者、权属和图像散列分别列在来源记录。[原城分户与边界](footprint-review.json) · [照片量测与焦距敏感性](../../../data/audit/swire-east-building-bund-front-v1/preflight/photogrammetric-registration.json) · [完整来源与权属](reference-review.json)
