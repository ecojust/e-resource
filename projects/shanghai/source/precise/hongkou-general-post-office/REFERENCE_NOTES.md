# 上海邮政总局：参考与范围

本轮实际阅读5份正文，并实际查看14张参考图（10张Commons、4张上海邮政官方页面配图）。这是模型制作依据的记录，不代替最终几何、原生文件或网页验收。逐项来源、日期、哈希及权限见 [source-register.json](source-register.json)，逐图观察见 [photo-review.json](photo-review.json)，尺寸矛盾与范围决策见 [documentary-review.json](documentary-review.json)。

南面北苏州路与东面四川北路为巨柱主立面，北侧天潼路红砖墙不可套成相同柱廊。东南斜角是主入口与单正面钟；两侧弧鼓、八柱上亭、起伏檐线和绿色金属冠分别制作。四层主体、柱距、雕像和隐藏构造含估计。

《上海名建筑志》地方志原文记总高49.5米、旗杆另8.2米；百科的51.16米不含旗杆说法保留为异文。本轮采用49.5米名义高度，分段尺寸不视为测绘值。不同来源的占地、楼面与扩建面积不用于强行凑地图足迹。276号主楼地址、250号文保牌、天潼路395号博物馆入口均保留，不按门牌分别造楼。

官方介绍记2003起恢复性修缮、2006年1月1日正式开馆。中庭弧形透明网格罩由2010照片直接支持，本轮按该修缮后可见形态估计外罩；没有取得2026实测屋顶和完整院落施工图。最新2025街面照片左端的另一灰筒拱不自动当作主源1959的院盖。西侧独立源3148及完整内院/接缝仍待具体范围核对，现模型不开放室内。

第三方网页和照片仅在仓库外私存研究，不随模型再分发，也不作贴图。Commons每张图片保留自己的作者、拍摄日期与许可；官方页面未找到开放再分发许可。模型使用独立编写的几何与材料，不以照片像素生成表面。
