# 徐汇滨江海事瞭望塔塔冠的交叉菱格外网

5D090在市表登记为海事瞭望塔，门牌徐汇区龙华港、黄浦江河口。龙华港汇入黄浦江处的海事瞭望塔在Fayhoo于2015年3月29日拍摄的照片中，塔冠腰部外鼓，顶部收窄。两组浅银色斜杆沿曲面反向盘升，围出能透见后面暗色横带的菱格。

外层在肩部形成最大横径，向上收成钝尖。杆件之间透空，最上缘可见数个落在相邻斜边之间的菱尖。 收颈处的斜杆较陡，沿冠腹向上倾角变缓。暗横带位于网后，遮挡关系在肩部的斜窗格间反复可见。

本研究只取2015年照片中的塔冠外饰。外网杆数、杆的交叉前后和核心表面以该视角可辨的密度和轮廓近似，模型尺寸仅用来表示比例。
