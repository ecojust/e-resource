# 江湾体育场历史主场：来源与制作范围

[全局地图直达](../../../index.html#landmark=yangpu-jiangwan-stadium&mode=overview) · [来源登记](source-register.json) · [文字审查](../../../data/audit/jiangwan-stadium-v1/documentary-review.json) · [图像审查](../../../data/audit/jiangwan-stadium-v1/photo-review.json)

本件为杨浦江湾体育中心内历史室外主场的看台环及附着门台，保留开放内场。独立江湾体育馆、游泳馆及整个体育中心场地不并入；只交主场不能把优秀历史建筑名录 `sh-historic-b1-021` 全条标记完成。

## 实际参照

实际读了三份文字来源：杨浦区政府2021年介绍、江湾体育中心百科条目，以及董大酉《上海市体育场设计概况》（《中国建筑》1934年第2卷第8期）相关原扫描页。百科采用实际取回页面中的修订94750796，固定修订链接供查阅，未另外请求固定版。原PDF重点阅读11—15页，查看17页总鸟瞰及20—22页主场平面、立面、剖面；馆池图用于区分另栋，未声称阅读全部85页。

六张现代照片均实际查看：2013高位全景、2013三拱外门、2017主看台内面、2017环墙11号拱门、2018远景和2021三拱外门。四张主场设计图另列，不计作照片。2013外门当前文件是2020年处理版本；11号门页面说明中的“14/7/18”与日期/EXIF的2017-05-14不一致，保留差异。全部参考原图、扫描PDF和整篇网页只留私人资料缓存，不作为贴图或随库分发。

## 西门内外与开放看台

原PDF第21页、印刷第13页图题明确为“上海市运动场西门立面图”，分别画“外面”和“里面”。外面是三大拱、四个主要竖向墩塔及两外鼎，里面是双塔特别看台及下方三小拱。这与2021/2013外照、2017场内主看台照形成互证；最终朝向和地图源身份另由定位合同核对，照片本身无罗盘元数据。

普通看台为敞开的灰色阶梯，红砖环墙配浅色基座、压顶；局部大平棚属于西侧特别台。三拱近照不镜像为东侧或南北短端门。环墙小拱照片内可见铁门和上升楼梯，不是每个洞都同高直通场内；门洞要保留深度，不能只画黑色面片。

全景中2013年的高尔夫练习网、棚与2017赛事帐篷、广告牌、临时座位不列为永久历史建筑。场地中心不挤出成实心椭圆建筑，也不把全环加屋盖。

## 数值与年代边界

1934设计记看台周长约760米、宽约17米、20排座位；它们既不是高度，也不是当前现场测绘。百科的20米明确针对司令台，其原引页本轮未独立读到，不能用于整圈看台。当前米高、台阶列数、门洞净高与隐藏构造均按作者模型参数有界估计，最终值由随模型交付的 `source/model-parameters.json` 记录。

独立体育馆的1934原文是整体宽约46米、钢桁架两支点跨度42.7米（140呎）、屋顶最高约20米、两边外墙约12米；百科另称跨度46米。两种说法分别保留，均不用于本件室外主场。

杨浦官方记国和路346号、1934年8月始建、1935年10月建成投入使用；百科中心地址为淞沪路245号，正文记1935年8月底竣工、表格却写1934年启用。门牌、竣工/投入使用事件与设计预测分开，不强制统一。全体育中心360亩/约300亩、各阶段容量口径不同，不据此反推单座建筑体积。

## 后续核对

体育馆拟作为下一独栋制作；游泳馆继续单列。东侧和短端门的完整细部、隐面与历次修缮构造、当前场内附属物范围仍需按实际交付范围记录，不因主场完成而删去。当前提供外观俯瞰；资料不能证明门洞、看台下空间或台阶已开放为可步行场景。
