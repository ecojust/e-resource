# 刘氏花园住宅长乐路庭院露木山墙与折面凸窗

上海市第四批优秀历史建筑名录4B020同时登记长乐路786号和784号，门旁市级铭牌记为1930年代砖混结构英国式花园住宅。院内照片可分清左端的素山墙和右端带深色木饰的山墙。模型取右端，下部的折面凸窗在2015年和2018年均可辨认。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [街门与庭院组照](https://blog.sina.com.cn/s/blog_5d1bdf480101h97r.html) · [2018年庭院全景](https://commons.wikimedia.org/wiki/File:长乐路刘氏花园住宅.jpg)

高参88的网页首发于2014年。庭院近照的相机记录为2015年12月19日。照片可读出折面凸窗中央金牌的中文“上海华山康健医疗有限公司”和一行英文，模型按当时可见文字重新排版。玻璃中的室内陈设和树影随光照而变。[照片核对](reference-review.json)

按沿院边24.28米的原楼边线校准屋面，山墙宽约6.22米。墙脚、木枋和窗框确定2015年照片的立面透视，山墙尖约12.93米，二楼窗底和窗头分别约6.59米、8.25米。屋面影像倾斜、树木和凸窗遮挡使墙脚与屋脊位置仍有误差，作者估计山墙沿轴约±1.4米、法向约±0.7米。木框截面、凸窗进深、短返屋面和牌匾字体属于估计。[照片像点与量测](measurements/measured-facade.json) · [原城足印](footprint-review.json)

几何以米为单位，局部X沿庭院长边向东北，Y向楼内西北，Z向上。两档各有独立框扇、玻璃、折面窗檐、勒脚分缝与金属牌。近档保留牌匾的英文和较密的瓦接缝。正射网格、材质及字体均在源文件夹内可重建。[几何源](source/courtyard_gable.py) · [字体许可与来历](source/fonts/provenance.json)
