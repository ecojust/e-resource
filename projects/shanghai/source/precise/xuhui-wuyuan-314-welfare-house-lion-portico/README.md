# 五原路314号花园住宅石狮券廊

主券内退设有木门与铁花玻璃。两侧灯柱靠近门廊外沿，石狮安放在柱后的石座上。

市表4D021著录中国福利会和宋庆龄基金会。上海发布的现场照片标明1932年主楼与后来的临街杂志社建筑。主券净跨估为3.88米，误差约0.45米；树木遮挡了门槛和狮座的部分侧面。 [municipal register](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海发布，人民网转载](https://sh.people.com.cn/n2/2023/0223/c350122-40313340.html) · [independent open video](https://www.bilibili.com/video/BV1f84y1o7WQ)
