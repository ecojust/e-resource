# 湖南路280弄2号五层住宅临街窗墙与弧窗

4Travel摄影者「中国の風景」于2016年3月13日逐户拍摄湖南路280弄。照片43052474显示弄口的“280弄2号／湖南路”横牌，43052483记录楼门左侧的“2／湖南路二八〇弄”小牌。43052484摄入五层楼和西侧斜向弄墙，43052486从湖南路另一侧拍到同一处转角及临街窗墙。其余门号在同一摄影记录中另列。[原始摄影记录](https://4travel.jp/travelogue/11116083) · [房管局第五批名录5D115](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [照片编号、时间和逐站来源](measurements/photographic-sources.json)

2号的首层门洞退在弧窗下，门左侧为绿色小牌。二至五层的转角窗由三个朝向不同的平玻璃面组成，窗台与抹面沿弧线转折，三层窗扇有局部向外开启。湖南路一侧包括中宽钢窗、小窗、两组宽窗、首层铁栅及两个红褐色挑台。独立量取了内巷斜向立面的窗列、落水管、立面转折及室外机支架。表面纹理由粉刷层颜色统计和程序噪声生成。[原照片中的直窗和挑台](measurements/flat-window-observations.json) · [四层曲窗的双照量读](measurements/corner-photo-controls.json) · [房门、门牌和两侧墙](measurements/entrance-placement.json)

两张2016年照片和六个街景机位使用同一局部坐标。原点取临街首列窗西侧下方的地坪，沿湖南路东向为X正、进屋为Y正、向上为Z正。八站共使用272处读点。相机、建筑公制尺度以及受遮挡的一侧均为拟合值。首层退口让两处机位实际可见门左的2号牌。另用街东2015年和2020年的两个机位复核东端。临街东窗列上部向内转折约16.3°，尽端的弧形粉刷墙与东墙相接。东墙上部三扇小窗在冬季枝叶间可辨，最低两层仍有院墙与邻屋遮挡。四站交会估得实墙檐口高18.20米，两处近站因为正对圆角，投影约差13至15像素。屋面后部、室内和其余门号仍待实测。[相机参数](measurements/house-cameras.json) · [原始像点](measurements/house-camera-observations.json) · [东端折角与窗列](measurements/eastern-window-planes.json) · [四站对照檐口](measurements/eastern-roof-four-stations.json) · [东侧三扇小窗](measurements/east-side-apertures.json)
