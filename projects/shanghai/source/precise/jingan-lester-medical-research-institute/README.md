# 北京西路1320号雷士德医学研究院主楼

上海市房屋管理局第二批2B024原名“雷氏德医学院”，现用名栏记“医工院”，地址为北京西路1320号。静安区政府记录了2024年8月1日和睦家静安院区综合门诊部启用，明确门诊为1320号1号楼。章正元《静安文博钩沉》记录院内另有两栋二层小楼，1314号是院长住宅，1316号原作动物实验。Legolas1024的2014年照片的题注使用1314号，图中建筑的三层贯通窗列和中央高入口与医学研究院主楼相符。[门牌和各期资料](identity-review.json) · [静安区政府启用记录](https://www.jingan.gov.cn/rmtzx/003001/20240805/db69c875-0cdf-4a08-8cce-8dc5c5b49b9d.html)

上海市文化和旅游局记大楼于1930年设计、1933年竣工使用。静安区一则2023年报道并列有1932年建成和1933年竣工两种表述。2024年的竣工报道和现场记录能核对花岗石外墙、贯穿三层的窗列、入口深色门套和依历史照片恢复的两对卷涡纹铜灯。修缮后正照可逐一辨别中轴两侧各六列宽钢窗，靠中轴各另有一列窄窗。[30年代照片及市文旅局说明](https://whlyj.sh.gov.cn/gqfc/20230615/0a03500eabcf43f194d09081a8fe5505.html) · [2024修缮记录与实照](https://www.thepaper.cn/newsDetail_forward_26833339) · [影像尺度估计](front-measurements.json)

1320号1号楼有面向北京西路的对称长立面，背面两翼环绕凹口。2024启用航拍与2026影像图层均可见两翼平屋顶、中轴设备带、邻近的黑色矩形屋顶与蓝顶楼。该处地理轮廓为w490437625，中心约在东经121.445096、北纬31.230714。冻结地图中，260号源覆盖当代轮廓面积的99.11%。原始地理数据在此处还标注了另一项4B006“花园住宅／上海电气进出口公司”，并记南京西路1394弄2号。房管局对4B006记北京西路1394弄2号。这项属性冲突和院长住宅的门牌分别保留，便于后续逐栋复查。[冻结源及单栋面积](frozen-match.json) · [相邻地块与原始属性](ordered-lot.json) · [航片取图收据](landscape-raster-receipt.json)

修缮设计团队区分了南、东、西三面的花岗石与北面的水刷石。模型据此分别处理窗间柱、黑钢窗下墙与背面墙面。南立面每个窗洞带有实际进深，三层长窗保留分层钢窗和窗下板。正门与西侧门的两对铜灯按历史照片与2024年复原照片制作，灯身卷涡与灯罩折纹可单独编辑。局部树冠后的窗列、侧门在墙面上的精确轴位、屋顶后部设备及建筑绝对高度均属于估计。[修缮设计团队说明及摄影署名](https://www.thepaper.cn/newsDetail_forward_26833339) · [灯柱等细部原图收据](detail-photo-receipts.json)

修缮后的两个入口形制有别。南门采用宽阔的红色石门套和多级踏步。西门照片可见浅色窄门套、门楣矩形题板、入口两侧较低的灯座和紧邻的一对窄长窗。模型分别建立门扇、窗格、门套与灯体，西面树木遮挡处按可见窗列延续。[2024年西门与南门实照收据](photo-receipts.json) · [南门及复原铜灯近照收据](detail-photo-receipts.json)
