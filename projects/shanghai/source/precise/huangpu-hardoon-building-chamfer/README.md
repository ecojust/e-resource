# 哈同大楼（慈安里大楼）东南转角立面

南京东路98–114号。上海市房屋管理局第三批优秀历史建筑名录列为3A017，原名哈同大楼，公布时使用慈安里大楼。上海规划资源供图的建筑导读将始建年份记为1906年。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [上海市住建委建筑导读](https://www.thepaper.cn/newsDetail_forward_8982975)

本次取南京东路与四川中路交口的一跨斜面。Livelikerw于2014年1月14日拍摄的原片上，这两条路的街牌同时可读。沿着店面檐线向上可见宽拱窗、弧形带栏阳台、较窄的上层圆券和檐上的曲线老虎窗。2020年导读分别标注西南角和东南角，本次用后者确定红褐与浅色相间的老虎窗及上层浅色栏台。2014年照片还记录了较早的白色屋顶装饰和铁栏。Nicholas Hartmann于2008年8月7日的街景可辅助辨认沿南京东路的一侧。[2014年路口全幅](https://commons.wikimedia.org/wiki/File:Fu-Li_Building.JPG) · [2008年街景](https://commons.wikimedia.org/wiki/File:2008_Shanghai_scooter_traffic.jpg) · [2020年东南角照片](https://imagepphcloud.thepaper.cn/pph/image/86/280/276.jpg)

具名OSM轮廓同时记有南京东路98~114号、慈安里大楼和旧名哈同大楼。它与原城714号房的轮廓交并比为98.43%。斜面在原始底图上约长5.02米。高度、窗扇、阳台深度、老虎窗弯檐和砖色按照片估配。两侧各只延伸约1.55米，与原房相连。整条长翼、底层商铺、内院及114号纪念边门保留为原城建筑。嘉陵大楼、美伦大楼西楼及慈昌里大楼分属其他房体。[轮廓与相邻建筑](footprint-review.json) · [具名OSM轮廓](https://www.openstreetmap.org/way/380339993) · [逐份图像记录](reference-review.json)

灯光、三角网及材料由本项目重新制作。可编辑源文件使用米为单位，局部X由南京东路端指向四川中路端，局部负Y朝向街口。建筑脚本分别生成近景和远景，远景保留转角、真实窗洞、曲面栏台与老虎窗的轮廓。[建模源码](source/hardoon_chamfer.py)
