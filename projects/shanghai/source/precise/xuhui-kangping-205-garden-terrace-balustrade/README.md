# 康平路205号花园住宅露台瓶栏与檐托

上海市第四批优秀历史建筑名录将康平路205号花园住宅列为4D042。康平路1号另列为4D041。徐汇区绿化和市容管理局的建筑介绍将205号记作1923年建造，二层露台在底层敞廊上方。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [区绿化和市容管理局建筑介绍](https://web.archive.org/web/20160305202631/http://lhsr.xuhui.gov.cn/Article.aspx?ChannelID=0&ClassID=62&ArticleID=310)

正照可见转角的方墩、连续白色瓶柱及带凸边的扶手。仰照把一段栏杆与檐底摄在同一画面，可辨瓶柱上窄下鼓的轮廓、方形顶托，以及挑檐下一排逐层收窄的檐托。原网页标明2014年6月1日发布，图片的拍摄日期未载。[全景](https://web.archive.org/web/20160330055449im_/http://lhsr.xuhui.gov.cn/CMS4xhlhsr/Article/UploadFiles/201106/20110601223951560.jpg) · [仰视细部](https://web.archive.org/web/20160330060444im_/http://lhsr.xuhui.gov.cn/CMS4xhlhsr/Article/UploadFiles/201106/20110601223952464.jpg)

模型截取转角长边八根和短边三根瓶柱，转角用一块方墩衔接。栏间留有贯通空隙，扶手、下槛与檐口在转角处相接。栏高与间距依照照片比例估算，模型给出的米数为展示尺度。这段模型以独立展品呈现。[读图与尺寸](reference-review.json) · [几何源码](source/terrace.py)
