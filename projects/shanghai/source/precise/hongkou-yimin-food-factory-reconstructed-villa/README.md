# 益民食品一厂复建西班牙式小楼

香烟桥路13号的展示馆院内有一座红砖小楼。上部一对山墙高度不同，左侧山墙上有凸窗，右侧凸窗落到台基上。院子内的三道砖券之后还有一层退进的玻璃门，左边是缓坡与金属扶手。

原楼于1937年开工，1940年竣工，早期供外籍高级职员居住，后来作厂内办公使用。1985年工厂扩建时拆除原楼，今天的展示小楼在另一位置缩小复建。旧食堂改造的厂史展厅与易地复原的木质冷却塔在同一展示馆内。登记号5F022对应展示馆。 [虹口区企业服务云，2018年12月6日](https://www.shhk.gov.cn/qyfwy/030002/030002002/030002002002/20181206/43c1beda-cde3-4a3b-bc6f-858a999280d5.html)

## 照片和尺度

正面两翼的山墙、三道砖券、窗洞与凸窗根据2018年虹口区照片、2023年旅游部门照片和携程另一视角逐点校合。另有一张原厂黑白旧影，能辨出两端山墙和中间长屋脊。其拍摄年份与底片编号尚待考证。[三张照片的模型对照图](../../../data/audit/yimin-food-factory-reconstructed-villa-v1/photo-review/three-views.jpg)

模型以中券净宽1.75米为暂定尺度。三张照片在前墙与门窗交点处较为吻合，屋顶远侧的测量还有较大差异。后墙按航片轮廓收在院侧门廊线后约8.5米处，后坡、背墙和被树冠遮住的部位按现有边界简化。屋面框架、照片坐标、三张投影矩阵及量测误差在 measurements 目录。砖纹与瓦纹由程序生成。照片和历史尺寸的详细著录见[来源与许可](SOURCES-LICENSE.md)。

## 使用

网页提供正面、院内斜视、俯视、门廊、凸窗和中央老虎窗六个观察位置。源码入口为 `source/build_model.py`，使用 `--output villa.glb` 导出可编辑的完整模型，增加 `--lod` 导出简化模型。以 `--out <输出目录> --decoded <复核目录>` 生成三个下载件与两份独立解码。 [独立三维展示](../../../yimin-food-factory-reconstructed-villa.html)
