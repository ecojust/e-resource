# 美国花旗总会福州路主立面

福州路209号，1925年建成的美侨会所，后称高法大楼。上海市房屋管理局第二批名录2A031的原称栏为“美国花旗银行”，公布时名称为“高级法院”。上海市地方志办公室《上海名建筑志》、黄浦区政务账号“上海黄浦”和历史影像数据库 Virtual Shanghai 都将同一门牌记作美国总会。工作名录的“花旗总会”与这些独立记录吻合。[房管局第二批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海名建筑志存档](https://web.archive.org/web/20201103160708id_/http://www.shtong.gov.cn/newsite/node2/node71994/node81772/node81774/node81784/userobject1ai108962.html) · [上海黄浦现场资料](https://www.thepaper.cn/newsDetail_forward_21680720) · [Virtual Shanghai 建筑569](https://www.virtualshanghai.net/Data/Buildings?ID=569)

沿福州路的立面宽约23.1米。历史照片和2013、2016、2017、2019、2023年的图像共同支持七开间主立面、三开间四柱浅门廊、通长铁栏、三道重复的中段矩形窗和白石拱窗顶层。门廊两侧各有首跨短边可见。窗洞、后退玻璃、棕色贴面砖、窗楣雕饰、柱座及柱头分件制作。[历史照片1341](https://www.virtualshanghai.net/photos/images?ID=1341) · [2013年斜视](https://commons.wikimedia.org/wiki/File:Shanghai_American_Club.JPG) · [2019年入口](https://commons.wikimedia.org/wiki/File:Shanghai_Financial_Court_entrance.jpg)

《上海名建筑志》记七层和半地下室，工作名录和OSM均记8层。照片给出六道临街门窗层，模型按可见层次制作。站点25.6米的粗体高度、照片开间比例和源轮廓构成估算依据。背面、完整侧面、屋顶设施、内部和改建史另计。[地图来源](footprint-review.json) · [照片来源与署名](reference-review.json)
