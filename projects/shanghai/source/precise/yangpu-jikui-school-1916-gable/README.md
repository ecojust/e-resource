# 缉槼中学教学楼山墙1916纪年与百叶通风口

5G009在市表登记为聂中丞华童公学/缉槼中学教学楼，门牌荆州路42号。荆州路42号教学楼的2014年照片可见两个带纪年的山墙。这里取左边较近的一端，制作坡檐、嵌于屋脊下方的小百叶通风口、四位纪年及三扇窗的楣部。

1916位于尖顶与三扇窗之间，宽度超过上方的通风口。百叶两侧砖框在头、脚横向突出，顶端起一低尖。 中窗的券眉交错出砖，两侧为宽而平直的红色窗楣。深色坡檐下沿可见分块。

1916按图中的铭文刻画。窗体下部、围墙及另一端山墙不在取样内；字形和砌体深度依据正面像素近似。
