# 新华村12号题号山墙

上海市第三批优秀历史建筑名单将愚园路1320号新华村四栋建筑分为3M002至3M005。12号楼对应3M003。高参88在2014年公布的园中照片清楚拍到灰色山墙正面的数字“12”，逐栋题注的另一张照片把12号牌放在左侧砖墙上。两照中的三层绿窗、红砖交牙、窄廊和山花相互对应。[市房管局名单](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [摄影和逐栋题注](https://blog.sina.com.cn/s/blog_5d1bdf480101iqnm.html)

首稿包含三角山花、三樘绿色多格窗、中央12号、左右砖牙与粗砂面、山花两道收边、檐槽、落水管、烟囱、右侧短段凹廊和下部过梁。窗洞贯穿墙厚，窗扇与玻璃分别建模。屋面只取山墙背后的短段。正面先以檐墙宽7.4米及两层间高6.59米作为条件尺度，两张实照和后续独立测量均可用于修订。[像点、暂定标尺及两个数字的轮廓](source/registered-gable.json) · [原照指纹和保护编号](reference-review.json)
