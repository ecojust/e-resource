# 新华村12号题号山墙

上海市第三批优秀历史建筑名单将愚园路1320号新华村四栋建筑分为3M002至3M005。12号楼对应3M003。高参88在2014年公布的园中照片清楚拍到灰色山墙正面的数字“12”，逐栋题注的另一张照片把12号牌放在左侧砖墙上。两照中的三层绿窗、红砖交牙、窄廊和山花相互对应。[市房管局名单](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [摄影和逐栋题注](https://blog.sina.com.cn/s/blog_5d1bdf480101iqnm.html)

首稿包含三角山花、三樘绿色多格窗、中央12号、左右砖牙与粗砂面、山花两道收边、檐槽、落水管、烟囱、右侧短段凹廊和下部过梁。窗洞贯穿墙厚，窗扇与玻璃分别建模。屋面只取山墙背后的短段。正面先以檐墙宽7.4米及两层间高6.59米作为条件尺度，两张实照和后续独立测量均可用于修订。[像点、暂定标尺及两个数字的轮廓](source/registered-gable.json) · [原照指纹和保护编号](reference-review.json)

2026年9月《长宁金融园观览杂记》第12幅从花园一侧拍到有数字12的同一山墙。斜照还拍到转角后的两层三跨敞廊、外挑平台下的三道砖券、屋面老虎窗和远端山花。两侧窗洞、前墙数字、落水管与檐口用于和较早两照比对。侧面的纵深以这个斜角推算，后部尚待另侧照片复核。[2026年独立摄影](https://www.meipian.cn/5p7rb1d6) · [三台摄影机位](measurements/three-photographic-stations.json)

近档489个闭合构件、25,676面，远档351个、9,032面。修订时用两幅较早照片共同校正山墙左后侧的烟囱，并补建其下斜屋面、砖砌烟道、檐槽及凹入墙身，在花园斜照中另外辨出远端山花前的红瓦坡。三张照片另选61个面内点，固定机位查首个可见表面后，两档50点直接命中，58点在原照4像素内命中。远端红瓦位比原照偏约7像素。花木只取2026年上层栏板可见的垂挂枝叶。[独立抽查像点](measurements/independent-surface-interiors.json) · [烟囱与远端屋顶](source/roof-end.json)

独立具名地图点把12号落在城市粗模1888中，11号和邻栋分别占其他轮廓。2019与2025年正射图可见的屋缘受树木遮挡，门牌山墙和三跨园廊按局部独立模型展示。完整屋脊深度、背面和未入镜的另一端留待更多资料。[12号地图点与两期屋缘](measurements/numbered-12-and-two-roofs.json)
