# 贝宅花园侧主楼

上海市房屋管理局第二批名录第2B016号的四栏为“2B016、花园住宅、中信公司、北京西路1301号”。项目称贝宅，另有贝轩大公馆、Pei Mansion Hotel等称呼。SmartShanghai记载这所贝氏住宅建于1934年。中文条目引用的《静安历史文化图录》将住宅与贝星楼相联系，本次未取得该书原页或不动产契据。[市房管局第二批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [SmartShanghai酒店记录](https://www.smartshanghai.com/venue/5862/Pei_Mansion_Hotel) · [所据记录与书目](sources-and-identity.json)

南阳路170号是酒店的花园一侧出入点。2013年街道照片可读到170，2015年可见酒店字牌，2020年可核旁门位置。北京西路一侧在2013、2015和2021年的街面照片中可辨深色拱门与圆窗。两条路的地址点落在同一幢主楼，南阳路的院门则在主楼足迹之外约36米。东侧办公楼与主楼有各自的独立轮廓。[街面照片索引及朝向](sources-and-identity.json) · [两处地址与地块对照](registered-front.json)

2013年12月9日的三个园内视角显示三层石质立面、两侧转折面连续钢窗、两层内凹廊和上下对应的几何透空栏板。近照还可辨中部两扇玻璃门、石阶、檐口回纹浅饰和靠东一座窄竖井。本模型把钢框、栏板、折面窗及回纹留空分别建成可编辑网格；正门玻璃和金属门框反映拍摄时的酒店状态。庭院临时帐篷、花园亭与周围高楼未并入建筑。[园侧正面](../../../data/audit/pei-mansion-garden-front-v1/garden-front-2013.jpg) · [栏板局部](../../../data/audit/pei-mansion-garden-front-v1/gallery-rail-detail.jpg) · [影像作者与许可](../../../data/audit/pei-mansion-garden-front-v1/photo-credits.md)
