# 约克大楼四川南路题名入口与贯层楼梯窗

上海市房屋管理局第四批名录4A024登记约克大楼，现名金陵大楼，地址跨四川南路27至29号单号及金陵东路14号。两张独立署名外照把题名门锁定在四川南路29号正面。转角另一面的大窗、底层商铺与本入口分属不同开间。

门套的竖槽绕过横向过梁，四个金字抬高于题名石面。门牌位于南侧。铁门上方有固定条格，另有一道八格横窗。其上三道贯层钢窗各自分为双列玻璃，横格之间有突出的钢分档。2016年仰照片还看得见北侧一列中两处微开的窗扇。近档保留这两片开启构件和门框细纹。

三道钢窗上沿依街照估在23至25米，原城市模型整楼为19.20米。该次只调整西墙中央窄段，原楼其余墙体、西南斜角和邻栋均保留。两时期街照给出的上沿存在约1.75米误差。正面字形和门扇进深根据照片估配。
