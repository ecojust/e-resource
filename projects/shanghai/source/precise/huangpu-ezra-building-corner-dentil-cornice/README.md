# 新康大楼街角双层石窗与齿饰檐口

第五批上海市优秀历史建筑名录在新康大楼条下并列江西中路260号和九江路151号。Antigng于2015年7月20日从街面拍到大楼切角。这里取照片中连在一起的两层窗、齿饰檐口和檐上一联垂花。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Antigng原照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E6%96%B0%E5%BA%B7%E5%A4%A7%E6%A5%BC.jpg)

正面能看见两层窗和窗帽，成排短齿在浅色檐板下投影，檐上的垂花连接两枚圆饰。斜视显示石檐随街角转向，近远两档都留有这些轮廓。 中央立面宽暂取3.0米。侧翼转折角、窗内分格退深、檐齿与垂花伸出尺寸据照片比例估计。施工覆盖部分止于实照。

具名门牌点位于原建筑257，九江路151号点在这幢楼外3.56米，江西中路260号点最近的原建筑为2965。这三个位置可在街区找到这座楼，照片尚不足以把逐层窗位定高。作品另设观察页面。
