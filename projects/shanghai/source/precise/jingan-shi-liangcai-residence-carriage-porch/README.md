# 史量才旧居院内主楼车廊

上海市房屋管理局第四批优秀历史建筑表将铜仁路257号登记为4B004「花园住宅」，表中使用单位为上海市外事办公室。OpenStreetMap把同址标注为史量才旧居、上海市水务局，并注明足印合并多幢。两期影像中，南边屋顶带烟囱和老虎窗，北边另有一排直屋脊。模型范围取南部主楼朝向院内铺地的外挑车廊。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [OpenStreetMap原始记录](https://www.openstreetmap.org/way/437443890/history) · [铜仁路旧居资料](http://wap.tcmap.com.cn/landscape/105/tongrenlushiliangcaijiuju.html)

Livelikerw于2013年12月9日拍下弧形上楼、方墩花饰、曲首与一侧合拢的棕色百叶。Fayhoo于2014年7月12日从相反方向拍到另一侧券洞、敞开的百叶与玻璃窗格。正面和两侧各有一个通券，上层曲面前沿可辨三块浮雕花板。模型将可见的花叶与垂饰刻成几何，较远一档减少叶片、百叶和脚线分段。[Livelikerw原照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:257_Tongren_Rd._Shanghai.JPG) · [Fayhoo原照，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Tongrenlu_Shiliangcai_Guju.JPG)

正面名义宽4.84米，侧深3.87米，弧首另挑约0.69米。正券与两侧券顶估高3.60米和3.54米，屋檐约8.0米。尺寸依照片比例和两期影像估配，地面位置的影像判读误差约1.35米。模型记录上述照片的年代，主楼其余各面、两侧圆窗、北部附楼及院内其他建筑留作后续。室内仅在车廊同主楼相接处留出照片可见的暗色门扇。[逐项证据及原图校验](reference-review.json) · [原城足印](footprint-review.json)

可编辑模型、近景与远景网格均使用原创几何与材质。两位作者的照片仅供对照。模型按米、Z向上制作，曲首朝局部负Y，两侧通券沿局部X方向。[制作源](source/carriage_porch.py)
