# 亚细亚里黄渡路109号四窗老虎窗与瓦坡

取黄渡路109号2014年街照中并列四窗的横向老虎窗，含前脸、挑檐、浅坡红瓦与左侧相接的陡瓦面。

虹口区资料记载该里始建于1935年。市第四批名录题作“亚细亚里”，区政府页面作“亚西亚里”，两者均列黄渡路107弄及109号。主照片由Fayhoo于2014年5月1日拍摄，可同时辨认109号牌、四窗与檐顶。窗框按当时所见的两种分格处理，具体更换年代未见记载。2015年107弄照片用于辨别登记中的另一地址。
