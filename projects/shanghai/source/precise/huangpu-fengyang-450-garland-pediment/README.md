# 凤阳路450号小楼半圆山花与绶带花环

5A083在市表登记为白克路，门牌凤阳路450号。取凤阳路450号小楼正面左侧凸部阳台上方的半圆山花、双涡卷及绶带浮饰。2017年5月21日，Fayhoo从院门方向拍到两座同类侧部与较低的中央屋檐。

左侧山花上方为竖椭圆饰，左右叶卷相向，下面的长方壁面带两束结和两道截然不同下垂深度的花环。两侧各有凹槽竖框、外卷与斜落的墙肩。 此处只表现左侧山花及浮饰。窗扇、阳台栏杆、院门铁艺、右段相似构件与中段三窗另留在原照。

尺度和浮饰前伸依单张斜向仰拍估计。电线遮挡的小段按两端连续走向连接，花环两侧束结只保留照片上可辨的外轮廓。来源未标方位和具体修缮时间。
