# 龙江路2号住宅廊侧三联折线窗与瓶栏

5G001在市表登记为住宅，门牌龙江路2号。2015年署名照片中，两段宽玻璃窗之间的短墙开有三扇狭长折线顶窗。模型取这段短墙和正上方的一截瓶式栏杆。

三扇窄窗的淡色窗套各有两道斜边相接；腰部灰色砌层水平收头于各窗侧。窗内有细横梃、深色中央竖梃，底部露出红砖。 窗顶水平挑线之上是连续石栏的短侧面；这段栏杆在两端转折，前景宽窗和右后侧的菱格铁栏属于邻面。

依据单张斜照校比例。窗洞进深与栏杆背面均为估算，名录将此处列为院内1号楼，照片没有提供完整建筑尺寸。
