# 复兴西路34号会乐精舍

市房管局第二批2D043列原名「会乐精舍」、现名「会乐公寓」。徐汇区房管局2025年文章使用「卫乐公寓」和英文 Willow Court，记为1934至1935年建成的高层花园公寓，并引1935年日报照片、建筑结构公司宣传册和设计图。文章署建筑设计为义品放款银行营造部、结构设计为康益洋行，2023年《建筑可阅读》的署名为赉安洋行。2025年的建筑档案考证记录为主楼13层，花园一侧入口抬高半层，背面首层在原图上称地下一层。[市房管局第二批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [徐汇区房管局建筑档案和各期照片](https://www.xuhui.gov.cn/zfjg_qzfbm_fgj_bmdt/20250514/556864.html) · [2023年建筑可阅读资料](https://sh.people.com.cn/n2/2023/0324/c350122-40350777.html)

老总平面将半圆台阶、花园、穿至后院的车行道和后配屋分别画出。现状照片能辨认南花园一侧的五开间、半圆叠置阳台、入口两侧八字凸窗和半圆门阶。图纸一端画有架空的车道，另一端是落地山墙前的深凹。高处向两翼退进，屋顶设露台。模型沿花园面展开，中央两侧的每排大窗由窄侧灯与宽窗组成。阳台栏板、两侧梃带采用现状照片可见的暗红色，窗间墙取浅黄色。[逐图来源和年代](reference-review.json) · [2013年12月现场照片](https://commons.wikimedia.org/wiki/File:Willow_Court_Shanghai.JPG)

本项目底图中的主楼为14-13718-6695单元的4000号，标注「卫乐精舍」，面积约352平方米。2025年区档案记主楼占地约380平方米。对照1935年总图和2018、2021、2024年版航片，庭院在主楼以南，最近的复兴西路中心线在楼心以南约58米。带「旧址」名称的街图点实际落在东侧另楼3753，东邻与主楼地面外缘相隔约6.45米。鸟瞰照片所见高楼屋顶受视角影响产生位移。底图只给出四个主楼轮廓角点，作者以该地块南边24.45米面宽定比例。主楼本体以约14.4米进深落位；中央门阶、阳台和两侧凸窗向花园突出。东端车道在地面连续通向后院，西端近花园一段凹入，后段保留实体墙。东邻、南侧花园及两座后配楼保留原状。[底图原始边界、街线与三期影像](site-registration.json)

从花园向北看，中轴浅弧形阳台下是抬高的入口。模型逐层制作十一组暗红色弧形栏板、退入墙面的玻璃门和两侧内阳台。半圆门阶以七级叠起，估算的屋冠最高点约40.05米，窄翼在上一层露台处收住。窗距、栏板厚度和层高根据结构公司的外观照片估算。2025年入口近照记录的直列玻璃门和简化后的凸窗托底用于现状模型。[可编辑参数和构件](source/willow_geometry.py) · [三档模型打包](source/build_model.py)

现状入口近照还显示两座凸窗下方的双格低窗、半圆形红色门罩和浅色底面。模型将它们和带浅色前沿的七级踏步分别建网。左侧金属坡道及扶手属后期院落设施，未作复原。[区档案中的入口近照](https://www.xuhui.gov.cn/zfjg_qzfbm_fgj_bmdt/20250514/556864.html)
