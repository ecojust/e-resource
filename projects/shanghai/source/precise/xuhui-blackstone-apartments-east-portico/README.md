# 黑石公寓复兴中路弧形柱廊东段

复兴中路1331号的临街开放柱廊从中央向两边弯回。此模型取照片左方的东段，从靠东的一对柱到第一对前柱。站在柱廊前可以看见平滑石柱、雕叶柱头、檐下成排的齿饰和十格透空交叉栏板。首对前柱上方有两根相邻的方形栏柱，东端栏柱有石帽。2015年斜视照片较正面照片更容易数清每格栏板。

2013年和2017年两组同期道路照片分别解算两对柱的中心距为5.75米和5.68米，模型取5.71米。柱径、弯线和栏后深度为照片估计。柱脚受绿篱遮挡，保留简略收脚。原登记中1331号与1327号为两个独立地块，两栋原始足印最近相距21.63米。
