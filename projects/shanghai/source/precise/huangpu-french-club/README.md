# 法国总会 · 花园饭店历史会所

上海市第二批优秀历史建筑 `2C005` 登记为「法国总会｜花园饭店｜茂名南路58号」。在店方公开的市政府保护铭牌上，设计单位为赉安洋行，姚记营造厂承建，1924至1926年建造；1989年改建为花园饭店裙房。同批 `2C008` 是南昌路47号的「法国总会（老）｜科学会堂（一号楼）」。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [运营方历史资料](https://www.gardenhotelshanghai.com/hotel/) · [建筑保护铭牌实照](https://www.gardenhotelshanghai.com/wp-content/uploads/sites/252/2022/09/Heritage-AR.jpg)

花园侧的南立面由中央五扇大拱窗、两翼各五开间的柱廊和两个端部组成。1927年《Shanghai of To-day》第37图可看见原屋顶花架和两个圆亭。现状照片保留柱式、中央弧窗和裙房，但门前新增了玻璃雨篷，旧圆亭已消失。成品选用现况：有门前雨篷，中央及两端保留能在近照辨认的栏杆和压顶。[1927年正面照](https://commons.wikimedia.org/wiki/File:Cercle_Sportif_Francais,_Route_Cardinal_Mercier_1927_(Shanghai_Of_Today_Plate_37).jpg) · [运营方现状照](https://www.gardenhotelshanghai.com/photo-gallery/) · [逐项来源记录](reference-review.json)

运营方二楼平面把突出花园的中部记为 Jasmine Room，东北的 Grand Ball Room 有向外鼓出的端部。真实底图中，4860是低层裙房，3550则是贴在北边、独立标记34层的塔楼。模型依据二楼平面和东翼屋顶影像填补背部外形；内部房间、隐藏机械、雕饰细节和尺寸为估计。照片、平面及航片只用于参照。[二楼平面出处](https://www.gardenhotelshanghai.com/meeting-events/banquet-rooms-on-2f/) · [原地块与邻楼](footprint-review.json)
