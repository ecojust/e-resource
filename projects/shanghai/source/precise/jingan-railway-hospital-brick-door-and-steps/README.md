# 上海铁道医院虬江路红砖长楼玻璃门与三级踏步

5H002在市表登记为上海铁道医院，门牌虬江路1057号。Fayhoo于2016年2月10日在虬江路1057号拍摄了红砖长楼临庭院的一面。模型取画面右端的双扇玻璃门、浅色门楣、三级踏步与台旁小通气口。

门楣两端比深色门框稍长，门洞有凹入的侧边；横过门扇上方的固定亮子有一道中央竖框，门上有一对细长的金属拉手。 三层红色踏步向门口逐级收短，顶台可见砖缝。左右墙脚各有暗色横向小孔，门边是顺砖排列的红褐色墙面。

取照片右端开口。端部方位未经现场罗盘复测。台阶的踏深、墙厚和金属截面按可见比例推定。双扇玻璃上红色圆形标记可辨，标内纹字未辨。
