# 励家花园高安路街门与双面砖券过道

高安路63号在上海市第四批优秀历史建筑名录中登记为励氏花园住宅。现场保护牌记载该宅于1930年建成，由赉安洋行设计。院落西侧的门屋跨在车道上，街面与院内各有一座红砖圆券，两头都能望见对面的洞口。[市级名录](measurements/register.json) · [现场摄影与保护牌](measurements/field-photos.json)

两面砖券均沿层层退进的同心弧砌筑。中段的长砖竖向排列，头顶是带起伏的红瓦，靠近两肩转为短水平收头。院面借2017年2月2日照片逐道核对了灰缝、石脚和瓦下的暗红色收边。钢窗上方的半圆气窗、山墙下沿的双排挑砖、走道两侧的砖踢脚和打开的双扇铁门均独立建模。[券门实照片段](https://blog.sina.com.cn/s/blog_a598306e0102xtqj.html) · [券砖影像测量](measurements/arch-masonry-traces.json)

三处街景分别读取门洞左右边缘，交会所得净宽约3.08米，近站独立读数约3.10米。远处的廊内深度据透视估计。登记院落中的主住宅、庭园和两侧相连建筑分别留在后续调查范围。[街景交会](measurements/street-portal-triangulation.json) · [模型尺寸](measurements/building-dimensions.json) · [原地图范围](measurements/city-location.json)
