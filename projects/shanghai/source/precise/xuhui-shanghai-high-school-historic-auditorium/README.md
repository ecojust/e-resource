# 上海中学历史大礼堂

上海市第五批优秀历史建筑名录将上中路400号的建筑登记为“上海中学大礼堂”，编号5D087。校友回访照片把它定位在龙门楼对面。吴家巷新校于1934年迁入，题为《江苏省立上海中学 大礼堂》的旧照也著录为1934年。礼堂工程的确切竣工日期仍待工程档案核实。

模型采用2020年10月17日正门照片中的三对玻璃木门、六扇上亮、额墙垂饰和宽石阶。1934年的斜照记录了六根正面高墩、中央四扇竖窗和侧墙八个开间。到了2020年，能从前院辨认的中央上层已有三角纹饰。这一处按2020年的式样制作。东面采用1934年旧照可辨的窗孔，下部八跨有十六个窗孔，上部六跨可辨十二个。两期照片提供的信息共同构成这个外观模型。

屋顶参考四期独立航片。从南往北可见前厅高额、中央红色纵向坡顶、后部较高屋面，以及其东侧一条浅色带。按上沿影像估算，主立面跨度约31.5米，误差约1.4米。建筑轮廓数据另给出约36.4米乘55.6米的外围范围。坡度、背立面、台阶实际总高和门廊进深均为估值。1934年旧照最右另有一座高体量，现有建筑轮廓及第二个视角尚无法划清它与礼堂的关系。
