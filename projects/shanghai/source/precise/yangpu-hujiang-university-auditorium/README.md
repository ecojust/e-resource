# 沪江大学大学礼堂

上海市第二批优秀历史建筑2G002列“沪江大学”，地点为军工路516号礼堂／实验楼。上海理工大学档案馆将大学礼堂与北侧思魏堂分别称为University Auditorium和White Chapel，明确记有1994年2月15日保护公布日期。两厅为L形连体建筑，1937年5月落成。1949年校董会决定大学礼堂也使用“思魏堂”一名。1956年龙卷风破坏了楼体，1957年修缮完成。[校档案馆的大学礼堂与思魏堂原档](https://buildings.usst.edu.cn/2018/1002/c882a30387/page.htm) · [上海理工大学历史建筑介绍](https://iso.usst.edu.cn/2008/0529/c1109a9571/page.htm)

本项采用东西向大学主礼堂及可核实的北侧交接位置。经修缮后的校档照片可见红瓦坡顶、简化的哥特式花窗、竖向长窗和砖石墙面。历史效果图中有更高的钟塔，现有档案照与航片支持现有坡屋顶。西南端和北侧思魏堂的其余立面仍须逐面核查。校园另有中学礼堂、实验楼、科学馆等记录；第四批4G005列有中学礼堂和科学馆，校档案馆明确记科学馆于2005年10月31日公布保护。第二批中“实验楼”的正式归属留待原保护图核对。[原始图片和分期](reference-review.json) · [科学馆单栋档案](https://buildings.usst.edu.cn/2018/1002/c882a30388/page.htm)

实名大礼堂为w180126200第2版，中心约东经121.551804、北纬31.294926。冻结宏区14-13723-6691中的2357号源覆盖此L形地块面积约99.57%。东侧科学馆在另一实名地块w155557303，匹配同宏区1052号源。2024与2026年发布的航片分别显示主厅较长的红瓦坡顶、北翼较暗的坡顶与两翼交接。院内道路、科学馆及北侧小堂保留各自边界。[两座单栋与冻结源](source-fit.json) · [同期航片及瓦片签名](roof-imagery-receipts.json)

地块南侧长边实算约37.20米，与正东夹角约37.36°，至主厅西北侧墙面约17.08米。沿西北侧回折点划分主厅和联接部分，可分别用于核对今后模型的基座与原生邻体。航空影像中的屋面有视差，交接线是平面估计。[主厅、接缝及北翼分别量算](component-review.json)

校档现状原图为500×315像素。东北山墙的浅色尖券围合两排五联窗，下排为矩形，上排从中央向两侧逐级降低，门洞深嵌于底层。左侧长墙紧接两扇圆窗，远处转为尖券窗。对照早期近照可见相同的窗数、通层窗带、门套和山尖通风口。南北两翼的高度均由整体源体约20.4米和照片比例估算，公开照片未给出实测标高。原照片的像素取点、东北端的落点以及北侧小堂的留存面积列在[可编辑模型参数](source/parameters.json)。
