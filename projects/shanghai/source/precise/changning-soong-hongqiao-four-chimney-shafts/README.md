# 虹桥路宋氏花园住宅四联切角烟囱与叠帽

虹桥路1430号。近屋脊的宽烟囱，上端并列四支切角筒，三层深浅帽线，下接一圈外挑滴水线和粗抹灰筒身。

按照片将四支烟筒总宽估为1.32米，筒身向上收分、帽线凹凸依据两个视角。取可见的上段，屋顶以下、筒顶内部、烟道实际掏深和另一侧较窄烟囱留待调查，顶面只按外轮廓收边。

烟囱和两张实景近照片只用作形体和署名参考。页面所用九幅图片均由本项目独立三维网格渲染。
