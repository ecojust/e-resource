# 东湖宾馆七号楼花园立面

淮海中路1110号的现场保护牌记载住宅于1925年竣工。市房管局第二批名单以2D001登记为东湖宾馆七号楼。高参88发布的院内照片可读牌文，也可辨花园立面的弧拱窗、垂花、双柱、后加玻璃廊和中间石阶。另一位摄影者于2015年10月3日从已经开放的绿地拍到相同的窗廊。2021年报道收录的高位照片显示红瓦坡顶、三组老虎窗和玻璃棚分格。[保护牌、照片作者、文献与原图地址](reference-review.json)

三段花园立面分件建模。两翼的弧拱窗保留圆弧上亮、钢框、铁栏、锁石及垂花；中段可看到带涡卷的成对柱头和下层圆柱。相片中玻璃廊已经封闭，中门外尚有两坡透明雨篷、五步台阶和一对石质花器。玻璃采用近似色。窗墙精确进深、石材厚度、廊棚建成年及后方屋顶仍待测绘，东侧独立门廊、后部房间和园林另列。花园在2015年开放，早期敞廊只作年代记录。[几何源码](source/garden_elevation.py)

资料所述原业主存在异文。三角形花园和七号楼可由门牌、年代、柱窗及屋顶核对，东湖路70号原馆区和东湖路7号的新楼使用各自门牌。花园地图标点距七号楼边缘约89米，具名OSM地块与原建模底图的552号面重合约98.35%。三期航片用于对照花园侧玻璃棚与红瓦屋面。[原址和轮廓](building-identity-review.json) · [各期航片地址与校验值](aerial-register.json)
