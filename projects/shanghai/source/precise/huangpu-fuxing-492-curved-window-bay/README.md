# 复兴中路492号住宅浅弧窗湾与瓶形栏杆

5A079在市表登记为花园住宅，门牌复兴中路492号。取市第五批名录复兴中路492号住宅院面的一层浅弧窗湾。Antigng于2017年8月2日拍摄的正面照片可辨两根浅色圆柱，中间较宽的窗和两侧窄窗下方分别留出短段瓶形栏杆。

中央较宽窗和两侧窄窗随浅弧转向。两根柱贯通窗台以下的栏杆与上檐，柱脚有短厚底座，纤细瓶形杆逐根成形。 弧形下口是水平带，上方窗楣为多条叠线与小方齿，玻璃与外墙在不同进深。院树、门口招牌和照片中的车辆不进入该建筑构件。

窗湾截取自院中较高的两层开窗中的下层。照片没有给出平面尺寸，栏板投影、窗深和柱径按可见比例估计。左侧树叶遮挡的线脚在模型中止于可见边界。
