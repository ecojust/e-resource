# 白宫俱乐部廊顶瓶栏与浮雕柱头

2024年12月14日的实地走读在虹桥路1390号拍下“小白楼”匾和圆柱门廊。正面照片入镜两根浅色圆柱，柱头承托齿饰檐带，檐上横排十二支瓶形栏杆。图集中的较早斜照显示栏杆沿侧边折回。 [虹桥路实地走读](https://www.meipian.cn/599hkkn0) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

正面近档的十二支瓶栏之间有透空，左右圆柱上的柱头可见方形浮雕与两侧卷叶。转到斜面可看见廊后券比柱身更深，两侧栏杆回转。券下扇窗与下层菱格玻璃分别可辨，远档保留扇骨和格条。 图片中正面辨出十二支瓶柱。两侧回栏的深度、浮雕轮廓、背面和绝对尺寸按正斜照片近似。

市表与同组实照共同确认虹桥路1390号小白楼的门廊。1390号地址定位仅量至旧城楼壳，照片没有测量控制点足以把两根柱脚和十二支瓶栏配准于同一面旧墙。保留原城楼壳，门廊通过独立页展出。
