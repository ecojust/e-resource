# 华邨五原路76弄起伏铁门与弄牌

5D070在市表登记为华邸，门牌五原路76弄（1-16号），五原路72-74号（双号）。2017年8月19日Antigng拍摄的五原路76弄住宅入口，门柱绿牌写有“76弄1–16号 五原路”。内侧铁门的两道曲线顶栏间有环与菱芯，门右侧窄条用连续卷铁装饰。

弄牌右上方的数字和街名在原照放大后可读。铁门顶有轻缓起伏的两道平铁，夹着三个小环；右侧有竖向卷草。 弄牌所在墙柱平滑，铁门后墙面颗粒较粗。原照远处的弄内建筑没有被当作此门件的一部分。

5D070原名华邸，现名华邨。本件只截取照片所见的弄牌、相邻墙段及铁门上部；照片不能给门扇的建造年份，底部裁切处、漆层厚度、铁条尺寸亦无实测。
