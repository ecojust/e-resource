# 永年人寿保险公司大楼

广东路93号位于四川中路与广东路交叉口西南角。市房屋管理局第二批名录将它列为2A033「永年人寿保险公司」。《上海名建筑志》记载旧址曾称广东路13号，保险公司1898年设立，1907年拆旧重建，1910年新大楼建成。1908年英文印刷图题作“The New Shanghai Building of the China Mutual Life Insurance Co.”。此后大楼曾作轮船公司营业场所，亦称培高大楼。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [《上海名建筑志》存档](https://web.archive.org/web/20200927104145/http://www.shtong.gov.cn/Newsite/node2/node71994/node81772/node81774/node81784/userobject1ai108937.html)

现存外观以2011年9月3日的正侧两张街照为依据。入口向东北，方形门廊前立磨光红花岗石柱。两街的底层券窗之上是贯通两层的爱奥尼克柱、三角及弧状窗楣。按照片节奏，广东路使用七组开间，四川中路侧使用五组。门窗深度、开间尺寸与标高为估计。早期设计图上的屋顶纹章和人物未在这两张街照上确认。玻璃使用无图纹材质，独立门扇与扇形气窗只表达从街上可见的深度。[2011年街角](https://commons.wikimedia.org/wiki/File:Yongnian_Mansion.jpg) · [原图、侧照和元数据](reference-review.json)

地方志记载大楼三层、局部四层。2018、2021、2024年发布的Esri历史影像都显示街角后方有局部凸起，模型中的后部轮廓、局部第四层位置和屋顶标高据此估计。原生建筑源为14-13720-6694中的1289，西边与1397相接。独立照片均未嵌入模型，几何源与可编辑网格采用MIT许可。[航片、定位与六栋共用原始近景](footprint-review.json)
