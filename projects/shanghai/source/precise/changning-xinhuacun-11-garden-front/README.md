# 新华村11号楼四跨院廊

上海市第三批优秀历史建筑名录将愚园路1320号院内11、12、14、15号楼分列为3M002至3M005。本工程研究第一栋，即3M002、长宁区政府11号楼。区规划资源局将四栋花园住宅系于1925年。高参88于2014年6月发布的成对照片保留了四个楼号题注，11号楼有五根砖柱、两层四跨院廊、四座平排棚顶老虎窗和三座烟囱。这些特征也出现在Antigng于2014年4月拍摄的院面照片中。

本模型取敞廊状态，包含洗石双阶与中央平台的券孔、砖柱、透空栏板、上层檐底、后退的门窗面、屋檐和向院的一坡。区规划资源局图中有封入廊间的窗及中部徽记，属于另一幕立面状态；该图无拍摄日，无法由网页登载日期给改造断代。房屋背面、完整室内、两侧附屋及花园内其他单体仍待实测。

## 摄影与尺度

三张照片共享五条柱轴。令柱轴间距为5米，联合拟合摄影机、栏口、檐口、平台和老虎窗标高。2019年2月24日与2025年4月7日两期正射可辨四座老虎窗，最外两窗中心跨度14.44米与14.45米。两次读出的正面檐长分别约20.57米和21.84米。照片透视下的檐后进深、树冠遮住的侧缘及绝对标高仍为估计。具名OSM节点4812467687在旧城市模型1617轮廓内，距第二近轮廓约17.25米。原城市模型保持现状。

## 复建与阅读

源码包根目录的README列出建模、编码、重开Blender与交换格式的实际命令。两种程序表面分别表现旧红面砖与洗石，各附一张色图及一张切线空间法线。玻璃的透明材质alpha系数为0.67。照片名录及署名见本目录SOURCES-LICENSE.md，各原像读数、相机矩阵、两期航片版本及独立点位均在measurements目录。check_garden_views.py读实际GLB的第一层材质，并列出原位命中和五原像素内最近偏移。register_roof.py在取得注明来源的OSM原始XML、两个航片裁区和原城市地物表后可复核院号与檐宽。
