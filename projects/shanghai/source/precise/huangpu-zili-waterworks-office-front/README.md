# 自力大楼江西中路464号券门及上层窗墙

上海市房屋管理局把江西中路464–466号自力大楼登记为4A003，把同街484号自来大楼登记为4A002。前者为英商自来水公司办公楼，OSM门牌为464–466。市级登记与街照都支持本件采用的地址。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [具名地块](https://www.openstreetmap.org/way/495116055)

Fayhoo上传的照片里，464号绿色小牌嵌在门顶红砖券里。门的左边是一扇窄券窗，右边是用灰砖填实的券洞。两层窗墙之间留有红砖挑齿和灰白层带，转角另一侧另标460弄。照片于2015年1月上传，拍摄日未标。建年1888见二手记载。1922年另一栋办公楼的照片所述地址为484号。[Fayhoo街照](https://commons.wikimedia.org/wiki/File:Shanghai_Waterworks_Building.jpg) · [二手建筑记载](https://zh.wikipedia.org/wiki/自力大楼) · [1922年北楼图](https://avezink.livejournal.com/358500.html)

按长街墙28.12米的底图尺度校正透视，本件取前墙约11.32米长、三层约11.25米高。影像只足以估计墙厚、砖券进深和被雨篷遮挡的窗头。门牌三位数字、门扇折栅、左右两券、两排窗、红砖腰线及挑齿均各自建模。其余店面、室内和南侧墙体留作余项。可编辑模型使用原创砖纹。[取证和几何依据](reference-review.json) · [底模与街墙位置](footprint-review.json)
