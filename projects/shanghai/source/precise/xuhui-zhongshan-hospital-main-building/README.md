# 中山医院3号楼中央主楼

上海市房屋管理局在第二批优秀历史建筑名录以2D034登记中山医院，地址为徐汇区医学院路136号。复旦大学校史把最初医院本部确认为如今的西院区3号楼。基泰工程司设计，1935年6月开工、1936年12月落成，医院于1937年4月1日举行开幕典礼。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [复旦大学《中山医院3号楼》](https://www.fudan.edu.cn/2019/0424/c426a96006/page.htm)

模型选取照片能明确辨认的中央主楼。1936年正面照片记录四层病房窗、两端石色竖墙和屋檐下的通廊。2019年院区照片可见黄色琉璃瓦歇山顶、南坡五座老虎窗、突出的屋脊与白色石栏。最中间的老虎窗较宽。两组影像反映不同年份。两侧翼楼、旁边具有黄瓦屋顶的院楼和现代医院塔楼继续使用城市底图。[建设成果展两张原片](https://news.zhuyitai.com/sheji/detail/8ee6b79b62c4452ba16de7b012e7e997)

楼号点落在城市底图实名建筑3号楼中部。三个年份的航片都能分辨这段黄瓦顶，两端的平屋面和北侧围合的空间。屋内布局、精确信息不足的背面细部及不可见设施未作复原。建筑尺寸、柱距、纹饰和屋檐的曲线均为估计。[定位与各年份航片收据](footprint-review.json) · [名录和照片校核](reference-review.json)
