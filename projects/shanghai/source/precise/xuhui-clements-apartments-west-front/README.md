# 克莱门公寓弄口西侧前楼

上海市房屋管理局第二批优秀历史建筑表以2D044登记复兴中路1363弄整组。徐汇史料记载五幢公寓建于1929年，外墙水泥拉毛与清水砖相间，屋面有红色机制瓦。沿街底图和独立街景将其中的西前楼钉在具名院落西北角。弄内四栋、共用弄门、邻地玉门公寓及道路各有独立位置。历史文献中相近的名称、指向全弄的门牌或商业地点不足以判定住户楼号。[名录、区志、图像与来源](reference-review.json) · [地块与邻楼](footprint-identification.json)

Livelikerw的2013年12月25日临街照片和2015年12月、2017年9月街景均能分辨两个外突的翼端、其间的凹院、红砖窗间条、石座和顶层拱形钢窗。本次复原这段北立面和瓦顶，保留内凹处的窄门和行人通道。红瓦在树荫内的折线、屋面未见部分、局部遮挡窗列及收尾截面属于比例估计。院内另外四楼、居民室内与逐户编号仍待资料。[可编辑模型](source/build_facade.py) · [尺寸及方向](source/parameters.json) · [独立模型页](../../../clements-apartments-west-front.html)
