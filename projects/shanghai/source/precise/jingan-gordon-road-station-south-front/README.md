# 戈登路巡捕房南院面中央山墙与柱廊

上海市第四批优秀历史建筑4B013登记于江宁路511号。英国布里斯托大学藏 WG01-191 展示早期沿院三层红砖主楼，Pe01-061 展示弧形门楣。建筑师 Neri&Hu 将2012年完成的改造登记在同一地址，项目所附正照清楚保留中央门套、双层柱廊和屋脊山墙。[上海市房管局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [早期建筑照](https://hpcbristol.net/visual/wg01-191) · [早期门口照](https://hpcbristol.net/visual/pe01-061) · [修缮建筑师作品档案](https://www.neriandhu.com/en/works/the-recontextualiztion-of-history-design-republic-design-commune)

模型取三角山墙、券形木窗与浅弧形石门套，两侧各有两跨砖券、廊栏和靠上的石柱头。源文件中的砖、灰缝、栏杆、门窗与屋盖可分别编辑。近景制作砖拱缝及较密木栏，远景减少砖缝、栏片与细分段数。

Bristol馆藏说明记建筑于1908年建成。地方建筑阅读资料记1909年投资、1910年建成。2017年Fayhoo照片从主楼北侧上方拍得红瓦屋顶，可用于确认屋面形态。中央南院面的门窗依据修缮照片。街面玻璃、其余屋顶及东西两端留待另查。[阅读静安](https://m.readja.com/nd.jsp?id=127&mid=625) · [Fayhoo，2017，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Gorden_Road_Station.jpg)
