# 姜氏双子别墅东馆花园面西端柱廊

淮海中路796号有两幢花园住宅。市房管局第四批4C023登记作「花园住宅」。站在南花园向北看，两栋之间留有一条地面通道，上方两层有窗的连接廊跨过通道。照片右侧为东馆；本件从通道边的方墩做到东馆第一根圆柱，保留西馆和连廊。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [L’ÉCOLE《历峰双墅─建筑瑰宝》](https://www.lecolevancleefarpels.com/hk/zh-hans/online-conversation/the-twin-villas-an-architectural-jewel)

原城编号52和OpenStreetMap轮廓w494405859把两馆画在同一多边形内。独立航片能分辨两个屋顶。南面庭院照中，东馆内角的方墩从二楼跨至三楼，与浅色圆柱、瓶式石栏和出檐组成第一个开间。早期建筑修缮记录和恢复开放后的照片均保留了这套廊柱关系。[修缮后早期园景，Cool Cities／Villas Kee Club](https://cool-cities.com/796-huai-hai-lu-796-10149/) · [2025年发布的园景](https://www.sohu.com/a/870637762_121118713)

东馆花园面下缘从凹口一侧到外端约12.09米，第一方墩至圆柱轴约3.45米。垂直尺度由近正面照片的像比估算，墩顶约13.2米，误差约0.5至1.1米。柱后的实际廊深只能估读，重建采用约2.2米。原城给整块52的概化高度为9.6米。[相机与尺寸](measurements/garden-facade.json) · [两馆的轮廓与来源](measurements/two-villas-and-roofs.json)
