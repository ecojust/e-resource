# 佳庐庭墙尖顶石匾与卷叶花瓶浮雕

正面为庭墙临街石匾的尖顶卷叶雕饰。中央果盘或花瓶向上张开，左右叶茎成对回卷，尖顶两端折回短平檐，下部压有四道水平石线。

按2017年实照上的四角校正透视。取两侧短平檐之间约3.0米作为名义宽度。浮雕起伏约1至4厘米，实际刻深和背面均未测量。

浮雕轮廓、投影和色阶据Antigng于2017年8月9日拍摄的《北京西路1592弄11号》校正透视后制作。浅色雕饰的起伏是单张照片估算，照片及相应浮雕改编依CC BY-SA 4.0授权。 [原照](https://commons.wikimedia.org/wiki/File:%E5%8C%97%E4%BA%AC%E8%A5%BF%E8%B7%AF1592%E5%BC%8411%E5%8F%B7.jpg) [许可](https://creativecommons.org/licenses/by-sa/4.0/)
