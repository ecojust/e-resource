# 武夷路127号历史住宅南立面

上海市房屋管理局第二批优秀历史建筑表将武夷路127号登记为2M005「住宅」。原表列用名「比利时驻沪总领事馆」，项目工作名录转录为「意大利驻沪总领事馆」。长宁区房管局公布的建筑沿革分别记载了两个使用时期。区房管局记住宅建于1925年，《西区纪事》和工作名录记1932年，暂缺原始施工档案核准年份。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [长宁区房管资料](https://www.shcn.gov.cn/col5820/20240715/1263000.html) · [出处与指纹](reference-review.json)

南立面有一段凸出的三跨玻璃廊，廊顶的露台用宝瓶栏杆围合。栏杆后的主体外墙颜色浅淡，檐口下排列小牛腿。折坡瓦顶上有三组老虎窗，中央有三角山花，两侧用单坡顶。2018年发布的建筑近照可数出玻璃廊的开间，区房管局2024年公开的远照提供全幅轮廓。第三份图文用于核对窗框与栏杆。这里的年份指图文发表时间。[2018年建筑近照](https://news.qq.com/rain/a/2018102401068400) · [2020年图文及年代异文](https://www.sohu.com/a/401133473_722122)

模型重现照片所见花园立面，层高、窗距、栏杆节距和瓦坡进深按比例估算。屋面在可见屋脊处收束。主城通过街区级资料标记打开独立模型，原地块及其他建筑保留。三维几何和材质均为原创。[建模程序](source/garden_elevation.py) · [独立模型](../../../wuyi-road-127-history.html)
