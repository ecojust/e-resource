# 顾德坊沿街两窗的红白百叶与褐色木叶

5D058在市表登记为顾德坊，门牌襄阳北路66弄（1-14号）、68弄（1-11 号）、70弄（1-11号）、72弄（1-10 号）、74弄（1-10号）。Antigng于2017年8月19日拍摄的襄阳北路68至72弄住宅街面上，相邻两扇底层窗打开百叶板，左窗红色叶片间隔以白色横档、外缘为浅色，右窗用褐色细密横叶。两窗均带浅石窗台。

左窗叶框两侧和较粗的水平横条为浅色，红色短叶条列在其间，右侧两板则为褐色密叶。 灰色下层墙带水平分缝，窗下有两层浅色石台，内窗木梃的平面退到百叶之后。

顾德坊名录还包括66弄及74弄。原照可对到68至72弄名下的这一段街面，不能逐窗分配到具体住户。百叶数量按可见密度估算，背面深度、木叶倾斜角也未作现场测量。采样日期所见涂色没有建造年代记录。
