# 康定花园中楼南向柱廊

上海市第四批优秀历史建筑表以“花园住宅／康定花园”登记康定路2号。中楼临庭院一面由双圆柱和两端壁柱分成三开间。模型取中央柱廊、三组通透石栏、上部回纹实栏、瓦坡与一处老虎窗。两侧凸间、连桥、东西楼及庭院保留既有体量。[参考照片与名录](reference-review.json) · [地块和配准](footprint-review.json)

上海静安整理的材料记1923年开工、1925年竣工。园宅的早期关系人有张发文、曹氏兄弟与赵聘侯、赵国亭等不同记载，另有苏家翰设计并曾作事务所与住宅的说法。康定路380号／陕西北路805号属于另一院址。[原文及出处](reference-review.json)

两根通高柱的凹槽、透空栏杆和老虎窗玻璃分别建模。120×120像素的陶瓦图案与UV按米制坐标生成。原始与近景27,932三角面，远景14,408面。估算尺寸和相机朝向可在登记文件中复查。[可编辑生成源](source/build_model.py) · [瓦纹](source/roof_tiles.py) · [街面坐标](street-registration.json)
