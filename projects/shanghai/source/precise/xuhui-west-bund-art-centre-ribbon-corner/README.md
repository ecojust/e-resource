# 西岸艺术中心转角的两层钢格带窗与屋面采光窗

5D114在市表登记为西岸艺术中心，门牌龙腾大道2555号。Fayhoo在2015年3月29日拍摄的龙腾大道2555号西岸艺术中心照片中，浅灰体量一侧的两排钢窗由实墙分成开间，绕过实体转角，另一侧接成两道长窗。屋顶轮廓上方另立窄条绿色采光窗。

有间断的一面，近转角两个窗间每个各有三道宽格；宽格内可数三片窄玻璃，竖向上下两层宽格各分作两格。另一面长窗的中挺、腰档较粗。 转角保持实墙；屋面上方的狭长绿窗有细密竖梃，端头是浅灰色板与微倾的封边。

本件选照片中与白色外墙相连的局部。玻璃进深与屋顶灰色端头的倾角由单张照片估计，后方高厅、底部票房与红棚以及建筑改造各年代不作推定。
