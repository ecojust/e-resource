# 皇家旅馆旧址中段山墙的双圆窗与放射砖券

武进路393弄14号院内中段山墙的两圈圆窗砖券、伸出券面的四向压砖、三道壁柱与斜向压顶。

以2026年院内斜照测取砖环和壁柱。圆窗内径暂取0.79米，墙厚、砖长和砖数按比例估计。孔内深色部位的窗扇构造在照片中难辨。
