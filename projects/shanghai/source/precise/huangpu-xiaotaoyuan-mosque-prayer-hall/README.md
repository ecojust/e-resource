# 小桃园清真寺主礼拜殿

上海市第二批优秀历史建筑名录把2A057（原2E002）列在小桃园街52号，范围为主楼。2025年12月12日摄下的市政府文保牌同样注明52号，载明2014年4月4日公布。寺方介绍牌记1917年捐地设寺、1925年原地翻建，历两年余；上方1994年市级铭牌的英文说明记竣工于1930年。两个记载分别保留。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [两块市政府铭牌、寺内介绍及原照片摘要](reference-review.json)

院内东向门廊有两根独立圆柱，两端立墩，上下各三樘拱门或拱窗。上层“顯揚正教”横匾、底层扇形上亮及阶前门廊可由2015年和2025年的同部位照片对读。2014年街区远照可见绿色角穹顶与中央金色望月亭。主殿外观按这些公开照片核定；街上高门楼、净身堂和院内东侧附房另列，附近小桃园街24号另有清真女寺。[原照和两处独立门牌](reference-review.json)

实名地块w494394246第5版覆盖整个52号建筑组，在固定宏区14-13720-6694中对应1550号源，覆盖率约99.44%。2024和2026年发布的影像都显示四座角穹顶围绕中央亭，作为主殿单栋的定位依据。所取屋顶边缘沿轴约26.5×19.3米；有高度的屋面在斜射影像中会偏离基座，此量数作为外观比例估计。[实名地块和冻结底图](source-fit.json) · [屋顶量取及误差说明](roof-measurements.json) · [两期航片收据](aerial-receipts.json)

三扇门扇、弧形上亮与三扇楼上窗分别开洞，门廊由两根独立圆柱和两侧壁柱支承，四级踏步接门内平台。中央亭有通透的八边柱廊、浅金色顶、细长金杆和月牙。四座绿穹顶随远景切换仍可分别辨认。落地长宽估算为24.9×18.8米，中央月牙最高约23.34米。西侧凸出轮廓沿既有地块拟合，两长墙的开窗间距及屋顶高度按照片比例估算。[可编辑参数](source/parameters.json) · [中央匾字体来源和授权](source/fonts/provenance.json) · [主殿和原生院落边界](footprint-review.json)
