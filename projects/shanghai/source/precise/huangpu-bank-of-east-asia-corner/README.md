# 东亚大楼四柱门廊及转角立面

四川中路299号位于九江路口西南角。市房管局第三批名录登记为3A018东亚大楼。1926年建成时为七层，展馆介绍记载约在1930年代添建第八层。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [东亚大楼与沪港银行历史展览馆](https://www.sohu.com/a/335134332_283238)

2013年12月19日拍摄的街照可数出五道弧面主窗带、两层向后收进的角窗和小方冠。2019年刊出的照片把入口拍得更清楚，四根直柱表面有斜向石纹，山形门额下方可见英文行名、门牌和门扇。宽弧带上的四个铜色大字取修缮后样式。模型沿四川中路和九江路各带一个开间。[2013年街照](https://commons.wikimedia.org/wiki/File:Former_East_Asia_Bank_Shanghai.JPG) · [2019年入口近照及图源](https://www.sohu.com/a/335134332_283238) · [1926年鸿达设计图](https://commons.wikimedia.org/wiki/File:Bank_of_East_Asia_1926_drawing.jpg)

转角配准取底图1782号及具名OSM轮廓。模型只制作有公开照片的转角，建筑长翼、室内与后部屋面待补。高33.28米为小冠顶的模型估值，柱径、窗深及冠部背面均为估计。细灰石纹为原创程序材质，Noto字体子集随版保存SIL许可。[来源和估计项](reference-review.json) · [定位轮廓](footprint-review.json) · [圆角三点与尺度](source/frontage-registration.json)
