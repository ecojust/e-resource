# 南京饭店山西南路入口与钝角阳台

模型对应上海市第四批优秀历史建筑 4A016。以山西南路西墙的西南端为零点，沿墙向北取 35.16 至 56.39 米，覆盖现酒店正门和上方六开间。该段在西北斜角以南。中央入口的位置、雨篷样式和门前邮筒以 2018 年重新开业照片和 2019 年 5 月街景为准。2015 年照片中仍可见改造前连续的红色雨篷。

四、五层各有六座钝角阳台。每块挑板的前缘在中部折出，两个侧肩较浅。石栏身承托镂空的金属栏杆，阳台后方保留成对的窗。两侧木框玻璃门、中间凹入口、三片悬挑雨篷、铜色酒店牌和深绿色邮筒可以在近景分别查看。邮筒的制造年代、顶层背面以及室内空间仍待资料核实。

尺寸单位为米。原街墙在局部坐标的 Y=0，X 由西南沿墙向北，Y 正向朝街，Z 向上。四个独立相机位置给出的入口中心约在 45.8 米处。阳台前沿到窗墙的距离中位数约 0.82 米，两侧约 0.60 米。六层窗带采用后退 0.70 米的估计，第七层隐在街面之后。平面定位、被遮挡处及小构件的误差见各项量测记录。
