# 香港路117号键石窗楣与三角窗山花

5A043在市表登记为SHELL汽车公司、美灵登有限公司、永实业有限公司，门牌香港路117号。市表5A043登记香港路117号为SHELL汽车公司、美灵登有限公司、永实业有限公司旧址，现名凯恩宾馆。模型取Antigng在2015年7月20日拍到的两种并列窗楣及上部窗间墙。

左窗的平直分层挑檐中央下凸短键石，上一层窗下有一枚横菱纹；右窗由尖顶三角楣罩住，中央直条向下贯通。 上层窗间两侧可见很窄的竖向卷叶饰条，立柱有横向切分。上左窗带多道直向防护杆，上右窗内有两扇竖框。

仅据可见门面塑造。防护铁栅与现有窗框表现照片年份；浮饰深度、墙体截面与尺寸采用图片比例，未与旧城足印对齐。
