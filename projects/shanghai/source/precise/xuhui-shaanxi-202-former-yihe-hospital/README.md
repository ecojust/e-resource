# 怡和医院旧址庭院立面与拱顶门廊

上海市第五批优秀历史建筑登记的名称为“上海教育评估院”，地址为徐汇区陕西南路202号，编号5D079。院内主楼的六排红褐色百叶窗、两座挑阳台和中部伸出的拱形雨篷可从庭院辨认。门前四级石阶通往带两扇透花门的入口，方台上的两座石狮各有不同的姿态。右狮爪下可辨绣球、箍带与结饰。

模型单位为米。庭院主墙的长边约22.94米，局部X轴方位约73.2°，Y向楼内，Z向上。资料包括2015年Fayhoo的庭院照片、高参88于2016年及2018年拍摄的两个庭院视角和一张门厅近照。相机焦距、窗角、栏杆、雨篷和门洞读数见 measurements/。西侧翼与曲面栏杆按可见范围收束。屋脊的进深、树后遮挡处及门内照明只作估计。

归档保留立面模型、低精度模型、米制几何源和相机复核脚本。主楼东侧的前景车库、西侧不同楼栋的曲柱门厅和陕西南路188弄的后排楼另有各自的体量。照片作者及使用范围见 SOURCES-LICENSE.md。
