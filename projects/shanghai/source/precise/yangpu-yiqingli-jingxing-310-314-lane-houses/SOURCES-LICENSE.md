# 来源与许可

上海市房屋管理局公布的第五批优秀历史建筑名单将5G014记为“颐庆里住宅”，用途为住宅，地址为“景星路310、314弄（1-9号）”。登记地址涵盖组团。模型中的门洞、窗列和屋面范围结合逐栋摄影与航片判读。[上海市优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [本项录文与校核](measurements/registered-houses-and-photographs.json)

Fayhoo在2015年4月6日拍摄了310弄及314弄的独立题名照片，依CC BY-SA 3.0许可发布。原作署名与相机信息列在两份文件页中。项目中由原照片裁切、透视校正或与模型并置的对照图沿用相同许可。[310弄照片](https://commons.wikimedia.org/wiki/File:Jingxinglu_310_Long_Zhuzhai.JPG) · [314弄照片](https://commons.wikimedia.org/wiki/File:Jingxinglu_314_Long_Zhuzhai.JPG) · [照片许可](https://creativecommons.org/licenses/by-sa/3.0/)

屋面范围以2010、2019、2021和2025年四期航片及历史街景交叉判读。公开测量文件列出图源、拍摄年代、坐标、误差与独立测点，屋面图为原创线图。[航片日期与出处](measurements/placement-identity.json) · [街景站位与交会](measurements/streetside-triangulation.json)

作者使用程序构建网格及五种砖、抹面、瓦材纹理。原始GLB、网页GLB和Blender工程只嵌入这五幅原创材质图。模型几何、作者代码与程序纹理依项目MIT许可发布。[项目许可](../../../../../LICENSE)
