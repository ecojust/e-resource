# 金陵东路6–8号沿街三跨与门厅

上海市第四批优秀历史建筑名录将这处四层建筑登记为「雷米洋行／利名洋行」，编号4A023。2015年的街景可见金陵东路南立面的完整七跨。2021年9月的现场报道拍到中央入口、楼上成对窗户和门内木作。本模型取中央三跨，表现后一组照片中的街面。[独立模型页](../../../jinling-eight-trefoil-front.html) · [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2015年街景，Livelikerw，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:8_East_Jinling_Rd._Shanghai.JPG) · [2021年现场照片](https://m.thepaper.cn/newsDetail_forward_14628461)

## 临街立面

二层的透光窗开在矩形木框内。窗上方的尖券是实心浅色石饰，外圈有凸边，内圈下沉，中央三枚圆瓣在瓣根相接。六扇窗分别量取窗轴、宽度和尖顶位置。三层窗加阶梯形挑檐，四层窗较低。中央门洞的外铁栅与内木门相隔约0.7米，两侧绿色金属门叶向边上展开。内门的木框、三块弧顶玻璃和铁艺可以从街面辨认。西侧铺面的「烟酒商行」四字取自2021年现场照片。[照片测量](source/photographic-measurements.json) · [模型尺寸](source/dimensions.json)

南墙在城市场景中的长度约27.76米。由西向东计，本段从9.05米至20.12米，入口中轴在14.72米。六处尖券的顶点约高7.70至7.85米，屋面檐口约高13.20米。高度和窗轴由照片反推，估计误差约0.3至0.6米。窗台、石雕和门厅进深按近照比例制作。模型范围止于临街门厅和檐口，原建筑的侧翼、后部及楼梯仍待测绘。[旧城轮廓与地段](https://www.openstreetmap.org/way/495105528/history/3) · [来源与范围](reference-review.json)

## 历史门牌

1915年上海商名录第942页把 Tata, Sons & Co. 登记在领事馆路6、8、10号。1932年上海名录第252页把 B. D. Tata & Co. 登记在同路8号。这两页能确认当时在此营业的商号。建筑常见建造年份为1912年，原始产权人与建造委托人仍待查证。[1915年名录原页](https://archive.org/details/directorychroniclechina1915/page/n944/mode/1up) · [1932年名录原页](https://archive.org/details/1932-shanghai-directory-july-edition-of-the-china-hong-list_202412/page/n251/mode/1up)

## 网格与制作源

完整网格为48,362个三角形，远景为21,484个。两档都保留拱圈、三瓣石纹、入口铁栅、弧顶玻璃和上窗的窗梃。近景另有柱头叶脉、门扇卷草和八枚铁圆环。浅灰饰面纹理为原创，可从制作源重新生成。四个招牌字由思源字体的子集生成，字体许可随源文件提供。[几何生成器](source/build_model.py) · [材质生成器](source/stone_finish.py) · [字体许可](source/sign-lettering-OFL.txt) · [逐点核验](../../../data/audit/jinling-eight-trefoil-front-v1/verify-export.py)
