# 北大街208–212号江南第一茶楼：照片引导的临街前楼模型（v3）

模型对应青浦朱家角北大街208、210、212号的临街前楼，独立于222号民宅。原始城市要素是 `building:02c5c111-b4e8-4339-a8fd-b93b88bf65ea`，来源为 Overture 收录的 East Asian Buildings／Zenodo 轮廓；OSM只用于地址和道路定位。`geometry-input.json` 原样保留四点轮廓、城市宏 `14-13701-6700`、local ID 25 和同一近景块须保留的另外27个要素。

主要立面依据 Fayhoo 的 Commons 原图 `Zhujiajiaojulebuchalou.jpg`。原图明确展示三处砖拱、灰砖和红砖券／横带、开放的二层廊道、车木立柱及栏杆、上下各三盏黄灯笼、左侧绿色竖牌。EXIF 日期为2016-02-07，Commons描述日期为2013-09-07，两者有冲突。本模型采用该历史照片可见形态，不能声称2026现状逐厘米复原。原JPEG字节未修改，照片没有作为整面立面或窗玻璃纹理。

地层墙体是连续厚墙减去真实拱洞，表面砖片后有完整灰缝承墙；薄砖缝不会贯穿墙厚。中拱为真实通道及内开门片，两侧拱下为退进木窗。二层前缘是开放栏廊而非玻璃平面。车木栏杆、四根主柱、砖券、灯笼、可读近似字形、椽子及短节搭接瓦片均为实体几何。玻璃位于框面后20mm，分片避开窗框。

`calibration.json` 明确可见证据与估计。7.373m正面宽来自原轮廓短边，不是现场丈量；整高约8.187m、后部屋顶坡度、侧后墙、二层内侧三组门窗和内部遮挡面属于建模估计。足迹可能代表屋顶边缘而非墙脚，不能据此断言208／210／212号的地籍产权范围。雕饰、旧化色彩、字型和砖瓦尺寸均有简化。没有用单栋100m栅格平均高度冒充实测值。

## 重建

普通Python3.12及 `numpy`, `shapely>=2.1`, `fonttools` 足够生成raw，无需网络、生产目录或Blender：

```sh
python build_model.py --output output
python validate_model.py --glb output/qingpu-beidajie-208-212-raw.glb
```

`common/` 与 `fonts/` 必须和脚本一起保留。`geometry-input.json` 已内嵌冻结原始要素，重建无需全市原始数据。可选 `common/freeze_provider_geometry.py` 仅在拥有原版完整城市数据时重新审计映射，它不会修改项目；其中的地址交叉证据不声称官方测绘或历史建筑认定。

本次原生文件由统一渲染流程生成；重建时推荐前视方位146.3101°／仰角10°，斜视161.3101°／仰角15°；实体地面z=0，阈值台阶z=0.16，预览地面可放在-0.025m。不要整体抬升建筑去适应预览地面。

```sh
blender -b --python common/blender_finish.py -- \
  --glb output/qingpu-beidajie-208-212-raw.glb --output native \
  --render --view-azimuth 146.3101063318605 --view-elevation 10
```

`packaging-input.json` 显式声明raw/web/LOD/native四个目标路径和许可证，供项目通用打包器读取。它不安装或登记建筑，也不把待验状态自动升级为accepted。当前v3原生斜视图已与原照片实际对照通过，压缩后raw/web/LOD也已由实际Three解码检查；网页材质、远近切换与替换生命周期验收仍待集成流程完成。详见[交付与验收范围](DELIVERY.md)。`audit/`保留构建阶段原始报告，其中待验字段仅表示当时阶段，不替代后续独立证据。

## v2结构更正

v1在侧墙顶6.45m与8m屋脊间漏了山墙闭合。v2只在原侧边增加两片实心山墙至屋面下表面，属于明确标注的不可见部位保守构造；没有添加未知侧窗。v1/v2仅为私有工作区阶段历史，未重复装入本源码包；最终发布仅绑定v3同次生成的raw/native和对应审计。

## v3局部更正

竖牌整体移到檐前（牌中心外向0.90m、估计值），保留字序及高度中心；一字原字体bbox为938×148单位，恢复0.43×0.06785m自然比例，避免原每字正方形归一化造成约6.34倍竖向拉伸。新增两根隐蔽短支撑是构造估计。主屋顶35mm搭接按两坡方向加入18.5mm真实台阶，并将内外皮保持15mm竖向厚度以避免曲面肩部穿插，末节后坡在脊下结束；屋面基底、坡度、山墙和其他装饰不变。v2原文件保留在原工作区历史目录；本源码包不包含旧模型，v3使用新native和新审计，不沿用旧视觉通过。
