# 杜重远寓所南花园西端帕拉第奥式窗

淮海中路 1897 号花园住宅在上海市第四批优秀历史建筑中编号为 4D007。南花园底层中央是敞廊，两翼各有一组中间拱起、两侧平过梁的窗。本件取从花园看过去左手的西端窗组。2018 年张龙拍摄的高视点照片可以看到窗台和两侧窄窗，2021 年刊出的花园正面照片可以辨认圆柱、红木色窗框和突出的券心石。[市房屋管理局登记表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [新民晚报现场报道](https://news.sina.com.cn/o/2018-04-30/doc-ifzvpatr4954367.shtml) · [东方网建筑专题](https://m.thepaper.cn/newsDetail_forward_14158238)

中央半圆券的估算净跨约 2.22 米，两根柱子的中心距约 2.47 米，窗台至起拱处约 1.81 米。估算先将屋坡横宽同高视点照片中的檐口对比，再将券跨转到花园正面照片。给局部受树冠遮挡的檐角和券脚换取相邻像素，券跨约落在 1.88 至 2.71 米之间。下窗木框、侧窗、拱券和柱顶分别成形。卷涡券心石的侧面、扇窗细格和玻璃退进深度按可见轮廓估计。[逐项比量](measurements/garden-window-photo-scale.json) · [照片身份与制作边界](reference-review.json)

西端窗下部采用照片中的双扇木框。东端窗在另一侧树影下，外层可见菱形格栅。整宅的其他窗、中央拱廊、露台、屋顶及室内仍需另作。[可编辑几何生成器](source/build_model.py) · [七个观察机位](source/cameras.json)
