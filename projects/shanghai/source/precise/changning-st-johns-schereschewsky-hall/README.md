# 圣约翰大学怀施堂（韬奋楼）
 
华东政法大学长宁校区41号楼原名怀施堂，1894年奠基，1895年落成。1951年3月，校方为纪念1921届校友邹韬奋改用今名。市房管局在2M006项合列同一校园数栋建筑。校方俯照可分清南翼有钟楼的41号和西侧呈U形的40号思颜堂。学校现址为万航渡路1575号。[校方建筑档案](https://www.ecupl.edu.cn/2022/1101/c13514a193944/page.htm) · [完整出处](reference-review.json) · [地块编号与航片](measurements/quadrangle-registration.json)
 
从街面进入，钟楼中央的券门贯通南院。临街楼上的两侧各十孔，宽窄相间。内院对面每侧有三个上窗和三个底券。钟楼两面各有三组拱窗、三组方窗和方形钟面，12、3、6、9及八道整点时标均为几何构件。2026年街面特写可辨方窗中的蓝色卷曲花纹、漆木分格和两方匾额。校方旧照中的重檐、圆钟与现存单檐方钟分列。《解放日报》刊行的修缮照及11月启用报道记录了近期状态。[2004年内院照片](https://archive.metromod.net/viewer.p/69/2952/object/5145-11304822) · [2026年修缮现场图文](https://www.jfdaily.com/sgh/detail?id=4067621) · [11月重新开放报道](http://sh.people.com.cn/n2/2026/1106/c350122-41744057.html) · [两面钟楼实照配准](measurements/tower-stations.json)
 
南院北侧的白色中舱有三道楼上开口和三枚圆饰，中央圆饰内为红色五角星。校方斜航照给出的中舱底角距街面约45.6至46.9米，本版取46.4米。院两侧采用十一跨，平均节距3.08米。校方北望照片中可直接辨认八段，其余跨数用2004年对向照片、两端墩脚和校方航照共同约束。两台地面相机连同街面相机均保留原图像素坐标。青砖、红砖、灰色蝴蝶瓦、漆木分别配有自行生成的彩色和法线贴图。[双端机位留验](measurements/school-court-station.json) · [校方航片反算院深](measurements/school-aerial-station.json) · [门洞遮挡复验](measurements/camera-occlusion-review.json) · [饰面取色](measurements/finish-readings.json)
 
1995年11月15日，邹韬奋半身铜像在南院揭幕。模型中的四级台阶、红石座、西装驳领、圆眼镜、交握的手和卷件分别与2004年背面、2024年正面及2026年斜前照片核对。台正面可读“鄒韜奮”和“1895—1944”。按2004年院内相机把台阶四角反投到地面，像顶约高3.57米。精细面部和背碑正文仍待近照，台前文字采用字形近似。[纪念物影像与模型量测](measurements/sculpture-evidence.json) · [近远档闭合及投影](measurements/sculpture-check.json) · [题字字体许可](measurements/sculpture-lettering-LICENSE.txt)
 
北部两座小院东西并排。两期航片和区志照片中，南北向短翼的北端屋檐距滨河横翼内檐约2.7至3.8米，模型给这条横向通道留了空隙。滨河外墙和小院的门窗数缺少定位照片，仅复原可辨的屋形和建筑体量。北面屋檐取局部Y约78.5米，与现有城市地块北沿有差异，原地块保留。独立模型近景987个构件、145,120面，远景954个构件、98,072面，共十台可切换相机。[三套屋檐实测](measurements/north-courts-roof-limits.json) · [滨河照片归属核对](measurements/river-and-northern-courts.json) · [查看模型与下载](../../../st-johns-schereschewsky-hall.html) · [资料与许可](SOURCES-LICENSE.md)
