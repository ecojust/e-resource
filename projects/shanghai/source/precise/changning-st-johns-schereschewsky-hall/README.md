# 圣约翰大学怀施堂（韬奋楼）
 
华东政法大学长宁校区41号楼原名怀施堂，1894年奠基，1895年落成，1951年改名韬奋楼。学院地址为万航渡路1575号，房管局在2M006项下合列数栋圣约翰大学历史建筑。校方照片中其钟楼位于南翼中央，西侧另有U字平面的40号思颜堂。[校方建筑档案](https://www.ecupl.edu.cn/2022/1101/c13514a193944/page.htm) · [地块与两期航片取点](measurements/quadrangle-registration.json) · [出处与原件签名](reference-review.json)
 
南翼从临街向内院穿过钟楼券门。临街上层东西各十孔，内院对面则是每侧三个上窗、三个底券。模型凿开窗洞与拱廊，下层廊道有单独的内壁、门扇和楼板。钟楼两面各有三扇拱窗、三扇高方窗，方形钟面的12、3、6、9和其余八道时标均为独立几何。钟楼上方的瓦顶四角起翘。内院旧照及2026年街照拍摄时间不同，两面模型保留各自实照的指针位置。[2004年内院摄影](https://archive.metromod.net/viewer.p/69/2952/object/5145-11304822) · [2026年钟楼修缮后报道](http://sh.people.com.cn/n2/2026/1106/c350122-41744057.html) · [两台摄影机的控制点](measurements/tower-stations.json)
 
街侧地块边长40.53米，两期航片中的内庭净宽约20.50至21.00米。以20.75米作相机拟合的尺度，塔宽约4.85米，侧翼檐底约8.34米；内部街院两面的距离暂取12.5米。这些估算来自照片、地图与屋顶影像。历史重檐与圆钟、围合庭院的其余三翼及内部楼梯和钟体分别留待进一步复原。[校方原图及年代资料](reference-review.json) · [许可](SOURCES-LICENSE.md)
