# 建国西路629号旧住宅园立面照片量取

两张外观照共同记录了中央三层窗、砖芯、相邻窄带和上部退台。2017年8月2日照片保留了相机元数据，拍摄者为Antigng，采用CC BY-SA 4.0。另一张刊于2019年3月11日，摄影者和拍摄日期未载明。这里公布两图的像素位置、照片方向、计算方法和外立面结果。图像原件请到各自来源查看。[2017年照片及授权](https://commons.wikimedia.org/wiki/File:%E5%BB%BA%E5%9B%BD%E8%A5%BF%E8%B7%AF629%E5%BC%84.jpg) · [2019年刊发照片](https://www.sohu.com/a/300473463_120103574)

## 坐标与尺度

从刊发照片看，横轴 *u* 向画面右方，进深 *d* 垂直中央墙面向建筑一侧，*z* 向上。二层砖芯下沿中点给出 *u* 原点，砖芯所在平面给出 *d* 原点。*z* 原点采用照片中可读的下部勒脚交线。源图上两处各连续23皮的砖缝间距为235和233像素。单皮连灰缝取63毫米时，跨中层相邻两条水平檐带的高度差 *H* 为3.26米。单皮合理变化60至66毫米将整体改变比例。米制数值仅供模型定标。另存以 *H* 为单位的立面坐标，方便以后用房屋测绘尺度替换。[控制点与原照片校验值](front-registration-controls.json) · [相机、曲线与相对尺度](front-registration.json)

## 圆端和左右退台

刊发照片中三条水平饰带各有直线段，可以用同层直线段固定高度，再把其余29个像点反投影到对应的水平面。按三层合拟，曲面在 *u* 约2.97米与中央墙面相切，名义半径1.30米。可见段可按 *d* = *R* − √(*R*² − (*u* − 2.97)²) 绘制。最右可见点在三个高度各后退0.51、0.57和0.67米。在给定尺度和相机下，29点对圆弧的平面均方根差约0.04米。分别拿走一条饰带再拟合，半径从1.08到1.49米。连相机焦距、像点及砖模数一起改变，60次试算的半径第5至95百分位达0.99至3.08米。模型最可靠的是三个高度的可见终点与弧线走向，止点以后的屋身形状没有照片约束。[逐点平面轨迹与扰动结果](front-registration.json)

两张照片都能辨出高退台白檐、檐下居中小窗，以及左边大钢窗的右框。以中部墙面为起点，高白檐名义进深约1.0至1.2米，顶缘高约12米。居中小窗面名义进深约1.35米。左边大钢窗的右框上下两端分别给出约2.57、2.48米进深，窗头高约11.7米，窗台高约10.2米。2017年图上大窗左边超出了画框，宽度只能借2019年刊发图描出。三个部位的退距对标定分别有约0.33至1.60、0.53至1.80、1.16至3.33米的扰动范围。原片中有遮挡的窗框、檐顶栏杆和瓦脊未用于这些点的交会。[七个上部同名点与逐点残差](upper-wing-registration.json)

右侧后翼的两层平窗和底层外廊拱口在刊发照片中位于圆端背后。在2017年照片上，将这些檐端、窗或拱顶按0至5米不同退距投影，所得位置落入前景墙体或铁件，无法作同点交会。配置保留了刊发照片的像点和对应投影族，供复画外轮廓。实际进深仍未定。前景照片的相机参数适用于图像配准，弱约束的相机高度不应解释为实测地坪或拍摄位置。[右后翼可见性及单视投影](upper-wing-registration.json)

## 复算

2017年照片先按EXIF方向旋正为2988×5312，刊发照片采用原640×480像素。17个中央立面同名点先约束相机与立面。回投至刊发图的均方根误差为1.60像素，分别整组留出上中下砖芯、题字或窄带后，留出组误差约1.37至4.97像素。下层砖芯一组误差最大。上部七点另行交会，2017年高分辨率原图中未闭合量约16至30像素。原相机姿态、基准像点与每次扰动的假设均列于数据文件。[主面计算程序](register-front.py) · [上部交会程序](check-upper-wings.py)

在本目录安装NumPy和SciPy后，按以下命令运行。第一条同时核对两张原照片的SHA-256。提供其他输出路径时，原结果可保留用于比对。

```sh
python register-front.py --photos 2017-original.jpg 2019-published.jpg --output front-recomputed.json
python check-upper-wings.py --output upper-recomputed.json
```
