# 孙科住宅附楼三券通道与七跨木廊

番禺路60号园内的孙科住宅包括主楼、附楼和门卫室。2021年修缮专题的廊面实照与园口指示牌照片拍到同一方形穿堂、错台瓦顶、落水管及窄窗。2024年张唐景观刊布的总平面给出狭长翼22.2至23.0米长、7.2至7.4米宽的条件读数。模型取临院能辨识的一段，方门可穿通，三道扁券和七跨红木廊均为空间开口。北侧车廊和南园主立面归既有主楼模型。[上海市房管局修缮工程记录](https://fgj.sh.gov.cn/tpxw/20220913/7f0783f24e514531a2bc717a1a636b3d.html) · [长宁区修缮报道](https://m.thepaper.cn/baijiahao_14106378) · [总平面与摄影来源](reference-review.json) · [既有主楼](../changning-sun-ke-villa/README.md)

修缮专题的正面照片可辨七跨木廊、三道扁券、两座斜帽券墩与错高的檐沟。园口指示牌旁的第二张照片补足方门的进深、顶梁、双入口接水斗和右壁三对圆饰。模型中的鱼鳞状拉毛和筒瓦搭接均由程序生成颜色与法线纹理。两张照片只提供颜色范围及构造特征，道路指示牌、树影与店招均未写入纹理。[临院立面机位](measurements/gallery-station.json) · [园口机位及留出点](measurements/passage-station.json) · [纹理读数](measurements/finish-readings.json)

定稿近景有225个闭合构件、7,538个三角形，远景有179个闭合构件、4,002个三角形。两档都从源码逐字复建，逐面检查均无重复三角形。独立检查的49个材面及通视点中，正面28处全部命中，园口21处中20处命中。另有6处圆饰按第二张照片定位并在两档复查。园口一处预判为玻璃的点落在细钢窗梃上。正面保留的4个柱点相差1.2至2.3像素；园口另留5点，中位偏差约4.25像素，遮挡的远端窗角误差约11像素。[两站模型渲染](../../../data/audit/sun-ke-villa-annex-gallery-v1/registration/registered-gallery.jpg) · [近景与远景](../../../sun-ke-villa-annex-gallery.html)

2024年总图的尺度读取误差约1.3米。2019、2025年航片的屋面投影分别占入现有西侧建筑约42和35平方米，对既有主楼屋面的判断也不同。本成果在独立页面展示。原城市地图仍可查看已建的孙科别墅主楼。[总图的原像素与两期航片比较](measurements/2024-siteplan-and-orthophotos.json) · [主楼模型与资料](../changning-sun-ke-villa/README.md)

市房管局和区修缮纪录记主屋1931年建成；园景团队使用1930年，早期名录转录另载1948年。2003年研究所曾整修，2019年11月再开工，2020年11月开门。门卫室独立平面、附楼背面及改建前窗门尚待可定位的图纸。[修缮年代与总图](reference-review.json)
