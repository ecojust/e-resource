# 聂家花园高山墙三联窗与拱顶楔石

5G005在市表登记为聂家花园，门牌辽阳路51弄。辽阳路51弄的2014年现场照片里，较高的红砖山墙顶端开三扇共用平窗台的阁窗。中窗以半圆收顶，两侧较矮的窄窗为平头，上方两道坡檐收在同一脊点。

淡灰楔形饰石位于中窗拱头的正上方；两侧短而窄，其平头在中窗起拱处附近。 整道灰石窗台横贯三个洞口。砖墙两坡的窄深色檐边汇于脊顶；低翼及围栏另在画面两侧。

模型仅取可辨认的高山墙阁窗。尺寸按正面照片比例估算，角度、窗腔深度与所见砖缝的细小差异不作实测值。
