# 高安公寓转角弧窗与通高门廊

市房管局第二批名录2D042两栏均列“高安公寓”，门牌为高安路14号。高安路和康平路在公寓东侧相交。2014年《看看新闻》记旧名阿麦仑公寓（Amyron Apartments）、1941年建成；英文访谈图文记约1941年及设计师Alexandre Léonard。名录对应徐汇区的这处转角住宅。[市房管局名录](https://fgj.sh.gov.cn/yxlsjzcs/20200331/30c648cb811f401192bb61dd1dd487c9.html) · [图文及各自年代](reference-review.json)

天平街道文化中心“阿麦仑公寓”原档的两张照片分别拍于2008年9月3日与12月3日。2013年12月31日Livelikerw拍摄的路口原照显示同一浅褐饰面和上层弧形带窗，中央六层，两翼向较低的阳台部分跌落，地面入口后退并跨越两层。模型给木门、高侧窗、门廊内壁、弧窗钢框和圆端阳台分别建了几何。住家改装、空调与室内布置未建。曲率、窗格数量和进深参考外观估计。[天平街道文化中心原档](https://web.archive.org/web/20140517120622id_/http://tianping.xh.sh.cn/html/xh_tpwhzx/Flash_yffb/chou/chou-6.swf) · [2013年署名照片](https://commons.wikimedia.org/wiki/File:Amyron_Apartments.JPG)

高安路与康平路共用OSM节点1414884249。路口两处2020年街景中分别读取弧窗中心，改变读取位置后的四组交会均落在原城市要素3602。后部及两翼的实体外线与原始底图之间存在误差，地图只替换可对应的临街范围。西面1410和西南侧2081分别保留。[街角定位、取景与签收](frontage-location.json) · [城市原有模型与邻楼](footprint-review.json) · [查看单体](../../../amyron-apartments.html)
