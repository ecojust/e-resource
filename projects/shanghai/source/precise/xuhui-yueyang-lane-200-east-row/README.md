# 岳阳路200弄住宅临街锯齿立面

市房管局第二批优秀历史建筑名录的2D029行载「住宅」「里弄住宅」「岳阳路200弄」。2013年3月的有署名照片呈现浅色折角窗、突出的水平窗头、金属晒衣架、窗机、铁栏与黄色尖顶院柱。岳阳路上的2013年10月和2020年2月全景再次出现这些细部、墙前棕榈及同一排园墙，能把所建部分定位到住宅群东侧面街的一排。户号来自不同用途的地点条目，二手地图所称「4号楼」和其190号地址亦有出入。本项目不把整段临街外墙指定给某一户。[官方名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [原图与摄影信息](original-photo-retrieval.json) · [两期街景原始请求](street-observations.json) · [地址、折角特征和对应关系](registration-and-photo.json)

2016年7月图层保有无遮挡的屋顶折线，2018至2020年的若干发布层使用同一幅底图。2024年邻楼的倾斜投影遮住部分东缘。参考早期资料按同一像素比例取中央五处折角、内侧屋缘和两条横截位置，截面深度约13.2至14.5米。较晚的航片及地物库可辅助区分岳阳路沿街这一排、内侧住宅、门口小屋和建业里平行红瓦屋脊。未观察到住户后墙时只做素面截段，门牌分户、后部开窗及沿弄其余各排留待后续测绘。[屋面图源](roof-sources.json) · [折点、地方坐标与估算尺寸](source/parameters.json) · [两处取景间同一可见窗角](registration-and-photo.json)

原始场景14-13719-6695的4352地物只覆盖该排部分屋身，旧模型高27.4米，依据仅一个十米栅格样本。模型按照片比例恢复三个可见居住层及外墙逐层变化。屋面、晒衣杆、窗台、空调架与园墙均为独立几何。主楼与铁栏的两块地面碰撞也分别计算，街道、前院与内侧住宅间的空地继续通行。屋顶和窗列参考摄影测量及照片估算，未作现场精测。[既有地块与近邻净距](registered-front.json) · [源网格和同组户号](footprint-review.json) · [本户模型源码](source/build_front.py)
