# 瑞康公寓四川北路西立面三联钢窗与砖柱

上海市第四批优秀历史建筑名录以四川北路18号登记瑞康公寓。四川北路桥北侧的街景将公寓、邮政总局和南面的桥头置于同一视野。底图的邮政总局邻屋清单另列瑞康公寓原房屋1821。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [原楼轮廓](original-footprint.json)

2015年12月和2020年2月的街景显示，西墙红砖墩之间交替布置宽窗和窄窗。所选三窗均有后退的金属窗框、明显加厚的上部横梃、浅色窗下板和外挑砖楣。照片矩形投影用于估算窗宽和高度，较宽的中窗约1.20米，两侧各约0.76米。现场图片受反光、遮挡和道路坡度影响，钢框厚度、砖缝与窗下板颜色均作近似处理。[照片站点与标定](reference-review.json)
