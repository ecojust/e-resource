# 克美产科医院旧址西墙挑檐窗

市房管局第四批名录把克美产科医院列为重庆南路139号卢湾区政府2号楼，编号4C008。第五批首善堂也登记在139号。此模型沿具名建筑轮廓和重庆南路街照，取2号楼西墙靠南的一跨。三个年份的屋顶影像可核对朝街的折角。[第四批市表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [第五批市表](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [建筑轮廓](https://www.openstreetmap.org/way/372180528)

2020年2月和2021年1月的街照可见窗前直口挑檐、暗色窗扇、砖檐的叠涩和栏墙压顶。两处2021年相机交会得到挑檐前缘宽约1.53米，玻璃所在墙面在檐端后约半米。树枝、栏墙和相机定位误差限制了窗底及细部厚度的判读。相同点在两张图中估算出的高度差约0.6至0.9米。模型以两值均数定高，地方饰面采用估计色。[拍摄位置、原图来源与逐点量测](reference-review.json)

2015年Antigng所摄同名照片展示浅色巨柱和灰色基座，未能与所选西墙对应。该照片保留在来源辨析记录里。作品只制作两年街照中能辨认的红砖窗跨。[2015年照片](https://commons.wikimedia.org/wiki/File:%E5%85%8B%E7%BE%8E%E4%BA%A7%E7%A7%91%E5%8C%BB%E9%99%A2.jpg)
