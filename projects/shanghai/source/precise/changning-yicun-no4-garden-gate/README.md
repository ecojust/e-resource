# 泰安路76弄4号，贺绿汀旧居院门与正山墙

东华大学在2008年上海文化遗产日的报道里写道，贺绿汀的女婿在泰安路76弄4号旧居接待了公众。上海市房屋管理局第三批优秀历史建筑将整组亦村列为3M006。这里记录从弄道上能辨认出的4号院门和门后住宅正山墙。[东华大学实访](https://www.dhu.edu.cn/2008/0616/c7783a115089/pagem.htm) · [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html)

两张照片中，右侧门柱上的4号牌、铁门双扇中缝、浅色山墙上的品字形通气孔及大窗右侧空调的位置一一对应。2021年刊载的照片能看清门扇的绿色漆层、铁锈和窗格。2023年刊载的彩色轮播第四帧同时拍全了两根门柱。两篇报道均未署这两张照片的摄影者及拍摄日期。[上观号《寻访上海最美弄堂》](https://sghexport.shobserver.com/html/toutiao/2021/04/26/417857.html) · [人民网转载上海发布](https://sh.people.com.cn/n2/2023/0106/c350122-40256938.html)

复原范围沿可见门墙及后方住宅正面截取。院深和绝对尺度按照片比例估计。窗左树后、院内地面、屋后和室内缺少相应照片。模型中的建筑间距供两台相机的视线拟合使用。
