# 来源与许可

门柱和山墙的材料、颜色及轮廓以两篇报道的4号院门照片为据。几何、门牌上的数字及材料纹理均由源码生成。摄影原图保留于原出版单位；本站提供自制模型和渲染，可按仓库的MIT许可证复用。

- 2008年6月东华大学外语学院实际参加建筑开放活动，校方在记录中写明旧居在泰安路76弄4号。[活动原文](https://www.dhu.edu.cn/2008/0616/c7783a115089/pagem.htm)
- 2021年上观号文章的亦村段后第一张照片可辨右柱4号牌及门后窗框。2023年人民网转载上海发布的亦村轮播中，第四帧同时可见两柱、双扇门和同一山墙。两篇均未列出这两张照片各自的摄影者及拍摄日期。[上观号](https://sghexport.shobserver.com/html/toutiao/2021/04/26/417857.html) · [人民网](https://sh.people.com.cn/n2/2023/0106/c350122-40256938.html)
- 组群名称、第三批保护编号与集体住址来自市房管局名录。区规划资源局亦有专页。[市房管局](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [区规划资源局](https://www.shcn.gov.cn/col7698/20231023/1246567.html)
