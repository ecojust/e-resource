# 上海银行旧楼北京东路205号几何铁格门与上亮窗

上海市房屋管理局第五批名录5A073记载上海银行，登记地址跨江西中路372至390号与北京东路205至217号。这里记录北京东路205号的一樘门。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

褐色横枋上是两行上亮窗。绿色门扇由一条横向实板分隔，两列方折纹带上下呼应，金属扁条之间留有空隙。 门顶绿牌可读205，照片右侧另一门牌为211。地点照片未载摄影年月与个人摄影者，门洞与铁条进深按可见边缘估算。[北京东路205号实照](https://www.amap.com/ssr/place/B0JUT7H03N)

江西中路368至372号的具名照片记录邻街另一面。两街沿线门点和墙面转折收在地点调查中。[江西中路地点照片](https://www.amap.com/ssr/place/B0GRYZSG6Q)
