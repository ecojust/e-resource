# 思南路73号周公馆庭院立面

1946至1947年，中共代表团以周恩来寓所名义在此设立驻沪办事处。地方志所记马斯南路107号对应今日思南路73号。房屋坐北朝南，西侧临街。市房管局2C011登记的是思南路51至95号多幢花园住宅；本模型只取其中73号。国务院第八批文物保护单位登记号为8-0569-5-053。[地方志、市政府修缮报道与国务院名录](reference-review.json)

2010年12月从草坪拍摄的正面照片能看见底层浅拱、后退的内门、上下两层木窗与栏杆、左翼百叶及沿墙石阶。上层窗带的两个上角带弧，下面一排窗洞用平过梁。窗分格、栏杆间距、百叶片数和檐下进深均按照片估算。2013年7月同面照片用于对照植被遮挡处；2015年的思南路照片可见西侧山墙及旧门牌。[照片原件及作者](reference-review.json)

2020年的高处斜照能辨横向主屋面、南面凸廊的短斜脊、较低的后跨屋顶及烟囱。三版历史航片核对屋顶与邻楼的相对位置。底图4896轮廓与含周恩来旧居名称的独立地图多边形重合度为0.976，南边界估宽13.74米。坡度、烟囱高度与不可辨的背坡交线依影像估形。模型保留底图后段一、二层墙面，侧面与背面的门窗、院落和室内留待逐面调查。[航片及日期](aerial-register.json) · [底图轮廓和邻楼](footprint-review.json)
