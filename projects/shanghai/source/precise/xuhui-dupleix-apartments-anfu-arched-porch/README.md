# 巨泼来斯公寓安福路233号石券门廊与瓶栏露台

1918年建成的公寓列入上海市第四批优秀历史建筑，编号4D018。市房屋管理局名录与徐汇区修缮实录均将地址列为安福路233号。Fayhoo于2015年12月26日拍摄的照片与2026年修缮实录呈现同一座门廊，近照可读左侧绿色233门牌。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [徐汇区修缮实录](https://www.xuhui.gov.cn/zfjg_qzfbm_fgj_bmdt/20260130/568956.html) · [Fayhoo署名实照，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Dupleix_Apartments.JPG)

模型表现临街石券、两侧沟槽方柱、卷形拱心石、放射形扇窗及露台两段瓶栏。两处2017年9月4日街景机位相距11.26米，实测两柱饰之间约3.01米，柱饰至后方砖墙窗约1.17米。2026年正照可数两格各七根瓶柱，门洞净高约为净跨的1.33倍。水刷石纹理由程序生成。侧栏遮挡处和门扇暗部的细分格采用近似尺寸。[街景交会数据](source/porch-2017-survey.json) · [修缮正照逐像素量测](source/porch-83-proportions.json)

原城的四边形足印将整栋归为1784，原建筑北沿宽15.22米。门廊按实测投影接在这段北墙，原墙线与街景砖墙有约0.96米的平面偏差。安福路322号另有独立建筑，距233号近239米。原图内出现的229弄位于房屋侧面。[门牌与图源对读](source/independent-367.json) · [落位与原户](footprint-review.json)
