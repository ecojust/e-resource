# 武夷路234号住宅竖梳粉墙与阶梯砖窗套

5M013在市表登记为住宅，门牌武夷路234号。2018年2月13日的临街照片中，一扇狭长单窗位于前后两层红瓦坡檐之间。浅色框外两列深红横砖分段向浅色墙面伸出，形成阶梯形窗套。

将窗框的四角作透视校正，可数到约十八皮横砖。窗套外缘按长、次长、较短、最短的阶梯节奏反复，窗下有窄而出挑的浅色窗台。 窗楣上方是浅色短竖纹，左右大面积的竖梳状抹面在窗台下方继续。上、下坡瓦均带深灰色檐沿，末端在照片中被电线和相邻檐口遮挡。

照片只显示这扇窗的外表，窗框、压顶和墙厚均按照片比例估算。拍摄时的玻璃及窗框年代未考。
