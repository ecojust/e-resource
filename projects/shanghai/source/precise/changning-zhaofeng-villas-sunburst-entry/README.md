# 兆丰别墅长宁路弄口题名墙

长宁路712弄兆丰别墅属上海市第三批优秀历史建筑，编号M-Ⅲ-01。现存保护牌记载1929、1934、1935年分期建造，区史记载1929年始建。里弄中有多排住宅，面向长宁路的弄口可见两面灰色墙身、铁门及“712弄1至168号”的绿色地址牌。[长宁区建筑介绍](https://www.shcn.gov.cn/col6991/20210506/871962.html) · [市房管局展示的原牌照片](https://fgj.sh.gov.cn/gzdt/20240819/80a5d62b1c7b4e88a67213df115445f5.html)

这个阶段制作入口东侧墙面。屋冠层层起落，中央有半圆日盘和放射状浮雕，名额“兆豐別墅”四字立于两道前挑腰线之间。左端的半圆灯罩有上下灯座与纵横金属条，下方铭牌周围有细竖条。2021年5月近照与10月街口全景可相互核对，另一侧近照还拍到后来或较早的另一块矩形说明牌，具体拍摄时间未载。[10月街口照片出处](http://sh.people.com.cn/n2/2021/1002/c134768-34942337.html) · [原图档案和取景说明](reference-review.json)

初稿先按壁面横线放样，尺度在街景三角测量前采用暂定值。铸字轮廓逐字提取，立体挤出后重新检查封闭性。屋冠、墙面和灯具可逐组检查。左侧绿牌墙、铁门与内部住宅的边界还需分别核定。[具体像点与假定尺度](source/registered-name.json)
