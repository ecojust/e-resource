# 淮海中路1800号花岗石门柱与三角压顶

5D074在市表登记为住宅，门牌淮海中路1800号。Antigng于2017年8月19日实拍的淮海中路1800号住宅入口，金褐色凹角牌写有1800和淮海中路，系在灰色毛面石柱前。石封顶呈小三角，两坡之下可见一块前突的多边石与后退的暗面。

石柱有深横缝，各块外表粗糙隆起而边缘相对平直。两条斜压顶从上部合成三角，中间凹进一层。 牌面左、右可见安装圆头，四角各有向内削出的弧口，上排粗数字1800、下排淮海中路。照片远处宅前山花与门柱为两处独立构件。

第五批市表5D074登记住宅、现作办公。实照近大远小，本模型只取右侧石柱上段。各层石材与板厚依可见比例估计，墙内构造、石柱全高和院内建筑均未测绘。
