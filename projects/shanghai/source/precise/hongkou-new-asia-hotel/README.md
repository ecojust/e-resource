# 新亚酒楼 · 上海新亚大酒店

旅馆在虹口区四川北路与天潼路口西北角。市级第二批优秀历史建筑名录在天潼路422号一栏列原名“新亚酒楼”、现名“新亚大酒店”。天潼路长翼与四川北路短翼在入口处弯转，多道棕砖壁柱从浅色底层延伸至塔楼。2001年《虹口区志》记载二至七层用作客房，八层曾是露天花园，后加顶为餐厅。[名录、区志与附近街角照片](reference-review.json)

建模采用2025年5月和11月的现场照片作为修缮后立面参照。2009至2016年的照片可对照主入口原铭牌、窗带、垂直肋及屋顶“新亞”字架；商业入口的现状黄铜横招和浅色底层见于2025年照片。屋面高度、背面共墙、开窗进深和塔楼尺度按照片比例及公开航片估计。[拍摄位置、年代与许可](reference-review.json) · [原生生成器](source/hotel_geometry.py) · [招牌字体许可](source/fonts/OFL.txt)

具名酒店的OSM轮廓与冻结单体3209重叠约97.9%。模型沿当前L形临街轮廓止于后侧共墙；后方123号建筑和天潼路对面的上海邮政总局各自保有边界。《上海名建筑志》所述原主楼与副楼的历史分工采用史料口径，当前楼体不推定副楼的产权沿革或内部平面。[地图来源与三期航片](footprint-review.json) · [独立模型查看器](../../../new-asia-hotel.html)
