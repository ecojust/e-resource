# 东方饭店旧址

上海市第二批优秀历史建筑2A050登载「东方饭店」「上海市工人文化宫」「西藏中路120号」。饭店于1929年落成。1950年工人文化宫开馆，三角形地块西端的主入口至今通往文化宫。上海房管系统的建筑介绍将西端七层主楼与后部五层副楼分开，并点出跨越三、四、五层的爱奥尼石柱和方壁柱。[政府名录及建筑出处](reference-review.json) · [上海房管政务实照和说明](https://www.thepaper.cn/newsDetail_forward_8723539) · [1950年开馆沿革](https://www.thepaper.cn/newsDetail_forward_5162345)

西端狭面正对西藏中路，两侧斜面接向北海路、广东路。2013年斜照呈现三组巨柱、侧面带扶栏的凸阳台和底层转角券窗。2018年正面照片清楚标出屋顶「1929」与入口横榜。2020年房管部门照片和2026年劳动报记者现场图显示，修缮后的正面使用矩形门洞，现场展陈包覆会改变门面颜色。模型表达建筑的门、窗、横榜和柱式，屋顶标高与局部深度按照片和城市源面推定。[2013年照片](https://commons.wikimedia.org/wiki/File:Shanghai_Grand_Hotel.JPG) · [2018年照片](https://commons.wikimedia.org/wiki/File:上海工人文化宫.jpg) · [后续实景的原始文章与图片](reference-review.json)

本次只制作船首尖端及其19米纵深内的临街近段。源地块2313还包含向东的长翼、后院和副楼。独立登记的茉莉花剧场、都市总部大楼以及同一街区的其他楼栋均保留现有模型。[城市源地块、周边建筑与航图](footprint-review.json)
