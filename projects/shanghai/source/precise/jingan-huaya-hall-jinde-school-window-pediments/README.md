# 花雅堂的三联百叶窗和两层折角

上海市第五批优秀历史建筑名录把进德女子中学、花雅堂合列为5B045，地址包括延安中路718号和茂名北路65号。《阅读静安》记载花雅堂曾为卢永祥公馆。模型取庭院一段有三联窗的外墙，以及照片右侧相接的两层凸部。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [《阅读静安》](https://m.readja.com/nd.jsp?mid=625&id=209) · [校园门号与旧地块](measurements/footprint-review.json)

2016年11月2日下午，两张相隔11秒的照片分别对准三联窗和转角。三角窗楣下各有一对壁柱。中窗右侧卷草在照片中呈素面，左右两窗均能辨认双翼卷草。三组各有四扇百叶，共十二扇；每扇的上下段分别有11和30道叶片。转到凸部，下层两窗仍有三角山花，上层两窗改用圆弧窗冠，窄面可见开启的玻璃窗扇，宽面可见红色外折百叶。[2016年照片](https://blog.sina.cn/dpool/blog/s/blog_a598306e0102xev6.html) · [三联窗细部](measurements/window-evidence.md) · [百叶原照间距](measurements/louvre-spacing.json)

三窗轴距按2.40米估算，绝对尺度有待现场复核。按斜照的可辨水平直边定位墙面，折出方向相对三联窗直墙约−47.7°，再沿接近平行原墙的方向向前延伸。外端因透视压缩而有约一米的平面不确定性。窗台和挑檐以照片中的交点衔接；左端上层的未见区域按截面收口。[摄影机及观测点](measurements/2016-two-window-cameras.json) · [三面交角和标高](measurements/three-visible-wall-planes.json) · [重新提取直边](measurements/register_faceted_wall.py)

三档各有207个墙面和开口截面通过实测。相邻两面的49个独立原照片点，有39个直接命中预期材质。公开视图使用原创三维网格、石料和漆木纹理；校园现有地块另行保留。[建筑源文件](source/build_model.py) · [资料与许可](SOURCES-LICENSE.md)
