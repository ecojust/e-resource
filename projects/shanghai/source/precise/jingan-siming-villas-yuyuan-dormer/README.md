# 四明别墅临愚园路红瓦坡与四扇阁楼窗

临愚园路一排住宅的屋面局部。四扇赤褐色窄窗并列，浅色窗侧墙压到红色瓦坡上，窄横木窗台与坡檐在前后两个平面。

窗洞名义宽2.64米。两处2020年街景对同一窗台右下角的高程估算相差约0.5米。窗扇高度、侧墙厚度和瓦件曲率依可见轮廓估计；被电缆遮挡的格条以同扇可辨部分续接。

沿街屋面的方位和窗格参照百度地图2015年12月28日与2020年2月21日街景实录。Antigng摄《四明别墅》（2015年8月1日，CC BY-SA 4.0）作为弄内组群的补充参照。模型与瓦形用新绘几何表现。 [弄内照片及许可](https://commons.wikimedia.org/wiki/File:%E5%9B%9B%E6%98%8E%E5%88%AB%E5%A2%85.jpg)
