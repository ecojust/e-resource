# 武康路99号正广和大班住宅

武康路99号是正广和洋行大班的花园住宅，始建于1928年，后来成为刘靖基住宅。上海市房屋管理局第二批优秀历史建筑名录的2D036条将原名、现用途及门牌分别列作「正广和大班住宅」「住宅」「武康路99号」。福州路44号为正广和公司的办公楼，分别登记。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海地方志的住宅沿革](https://web.archive.org/web/20200707200106id_/http://shtong.gov.cn/newsite/node2/node71994/node81772/node81775/node81786/userobject1ai109013.html)

## 临街面与南园

Livelikerw在2013年12月31日的街面照片里拍到了院门、可读的「99／武康路」门牌及院内主屋。房屋的西侧山墙朝武康路，木栏阳台向街面伸出，阳台上有两扇主要长窗，上方山墙还开有一扇小窗。2009年街门照片和2013、2015、2020年的沿路视点显示了相同的主屋与门柱关系。[2013年西侧照片](../../../data/audit/caldbeck-manager-residence-v1/west-front-and-gate-2013.jpg) · [门牌局部](../../../data/audit/caldbeck-manager-residence-v1/number-99-crop-2013.jpg) · [原图署名与许可](../../../data/audit/caldbeck-manager-residence-v1/photo-credits.md) · [2009年街面照片](https://web.archive.org/web/20190623024723im_/http://image1.chinanews.com.cn/09p/PhotoN/090620/090620064ta_3.jpg)

从南园看，西翼半露木山墙向前突出，窗间与楼层之间有红褐色木构装饰。两翼间为砖柱敞廊，楼上的露台使用透花砖砌栏杆。南坡分别设有一座四坡和一座双坡老虎窗，砖烟囱的出烟口错位排列。杨浦区图书馆保留的花园实照至迟在2014年存档，具体拍摄日期未知。徐汇区图书馆的建筑说明另附表现模型，作为形体参考。[花园实照](https://web.archive.org/web/20140715183549im_/http://www.yplib.org.cn/upload/htmleditor/image/090811011955.jpg) · [徐汇区图书馆建筑记录](https://web.archive.org/web/20140714181241id_/http://www.xhlib.net/news/ArticleDetail.aspx?id=561&Rid=39) · [图书馆所附表现模型](https://web.archive.org/web/20140715132607im_/http://www.xhlib.net/system_dntb/upload/%E6%AD%A6%E5%BA%B7%E8%B7%AF99%E5%8F%B7-8.jpg)

## 足印、做法与保留项

主屋有独立L形足迹，占地约265平方米。现行OSM来源为w582914387，冻结城底对应宏块14-13718-6695的2729号。两期数据的足印交并比约97.9%。2016、2022、2024及2026年发表的屋顶影像核对长向屋脊、西南山墙和南坡两处老虎窗。实测的地图朝向以南园主立面朝154.06°为准。红瓦屋脊约11.93米、最高排烟口约13.66米，层高、烟囱和窗框比例由照片估计。近景与远景均保留可透视的砖栏孔洞、底层敞廊与独立柱脚。北、东外墙依单栋轮廓及檐线简化。院墙、99号门柱、其余庭院建筑、内部隔间以及背面分户门窗仍待补充。[史料与影像访问凭据](sources-and-identity.json) · [四期屋顶影像索引](roof-sources.json) · [单栋地块与邻楼](footprint-review.json) · [可编辑生成源码](source/build_residence.py) · [独立查看三维模型](../../../caldbeck-manager-residence.html)
