# 中垦大楼北京东路239号东北转角门楼

北京东路与江西中路交叉口西南角是中国垦业银行旧址。第四批优秀历史建筑名录的4A008同时列北京东路239号、255号。239号大门面向东北，255号在北京东路一翼另有入口。原城建筑1970和开源地图的380340021号建筑均登记为上海市电力公司，与东北对面的浙江兴业银行分属不同地块。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [现场两门与保护铭牌照片](https://www.meipian.cn/2xob2nih) · [地块记录](https://www.openstreetmap.org/way/380340021)

上海市人民政府2005年公布的铭牌记载本楼由赵新泰营造厂承建，钢筋混凝土结构，1932年建。黄浦文博的银行史文章记载1932年初购地、1933年10月竣工并迁入总行，文内还刊有民国二十二年十月六日的新屋落成纪念合影。[保护铭牌原照](https://ss-mpvolc.meipian.me/users/13306645/16321fa0-9328-11ea-9669-6dbf0c09c3c4__jpg.heic) · [黄浦文博文章转载](https://www.sohu.com/a/977111417_121123854)

模型采用2020年调查照片中两扇黑铁外门闭合的状态。黑铁门叶有圆章、菱纹和花饰，门上方另有铁格上亮。石门楣留有六处旧招牌底板和两侧的菱形浮雕。向上九排三联窗之间有浅色竖条，塔冠逐级收窄，顶端留两个短竖孔。照片中残留的字迹难以逐字辨读。两条长街翼、255号入口、内门厅和楼顶其余部分另待核实。[入口近照](https://ss-mpvolc.meipian.me/users/13306645/dc025750-9327-11ea-9669-6dbf0c09c3c4__jpg.heic) · [Fayhoo 的全楼照片，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Zhongkendalou.jpg)

五个有摄影方位记录的街景机位交会得到约4.23米的门洞宽度。门轴与原城斜边相差约4.70米，因此模型接在1970号源楼宽7.10米的东北斜边。不同路段远景读出的塔冠高度约44至47米，模型取约44.7米。旧城网格原高32米，矢量建筑另记37米。窗高、进深和塔冠退阶依据街照估计。[角点与原始地块](footprint-review.json) · [摄影方位和高度样本](street-photometry.json) · [来源与原图摘要](reference-review.json)
