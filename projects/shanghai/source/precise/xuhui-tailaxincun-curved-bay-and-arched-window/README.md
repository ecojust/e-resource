# 台拉新村支弄弧墙上的圆首钢窗与白色檐带

5D022在市表登记为台拉新村，门牌建国西路365 弄（1-11号） 、建国西路 363号、太原路254-258号（双号）。建国西路365弄支弄照片中的黄色弧墙，凹入的圆首钢窗、下层白色腰线和檐下圆端小齿。2017年署名街照可辨瓦端、三道横窗梃和上部扇形细钢条。

圆首钢窗位于突出的弧墙中，暗色玻璃后退。窗下可见白色凸线；上方白檐分层，最低一行有圆端白齿。 瓦端沿弯曲的檐边排列。右上是与侧墙交接的外凸石饰，左缘被枝叶遮盖，顶部和内部无法完整追踪。

市表记录一组住宅。照片标至支弄，未见这一跨的门牌。墙体曲率、窗深和瓦片进深按照片估算。侧边、底部和后部为局部截面。
