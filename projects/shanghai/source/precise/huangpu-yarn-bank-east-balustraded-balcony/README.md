# 上海纱业银行大楼东端弧形石阳台与瓶栏

上海市黄浦区延安东路134–150号。东端券窗上方外凸的石阳台。两道水平压边围住弧形楼板，瓶栏立在方座上，扶手绕到两端方墩，挑台底下有卷纹石托。

节选宽约3.5米，挑出约0.9米。弧面、瓶栏和石托按2013与2021年街摄比例构造。树枝掩住的端部、石雕背面和构件实尺仍待复测。
