# 模范邨22号冒广生旧居的临巷入口

1941年的人名录把冒鹤亭的住址写作“福煦路模範村二二號”。2021年10月21日发表的走访记录指明22号是单开间、进深较大的中间户，并刊有一张门口近照。绿色22号牌在铁格门廊的左边，旁边是有三组上亮的红木窗。市房管局第二批建筑名录2B007记“模范村，延安中路877号”，工作名录记“延安中路877弄”，并将整组列为1931年三层砖木建筑。[1941年名录原图](https://imagepphcloud.thepaper.cn/pph/image/159/427/947.jpg) · [走访文章与22号近照](https://www.thepaper.cn/newsDetail_forward_14975239) · [市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html)

模型截取一层门口与左侧伴窗。从巷内可以看见浅色门槛、两侧内收的白墙、里面的红木门框及侧墙上的信箱口。门上铁条围出竖向椭圆，两根斜条交叉。绿色门牌上的“22”由独立几何构成。窗的三扇木框、上亮、细窗栅、石窗台和下方灰色墙裙按近照安排。门廊后的起居空间、照片右侧相邻的椭圆玻璃门和楼上各层留待另项核实。尺寸均以照片比例估计，摄制日期无单独记录。[带绿色22号牌的原照](https://imagepphcloud.thepaper.cn/pph/image/159/427/951.jpg) · [三维源程序](source/entrance.py) · [交互模型](../../../mofan-village-no22.html)

延安中路2015年12月、2017年9月和2021年2月的街景，可同时辨认模范邨北门及其东侧一排的北墙。站在街上面向南，四户间中部有一对窄门，22号实照所见门在左。各期街景中篱笆与树叶遮住部分底层，号数以走访近照为据。两个分别记为“冒广生旧居”和“3号楼、877弄22号”的地址点落入同一排房；另一条“22号楼、延安中路847号”的结果另有所指。2022年发布的航片可辨这排红瓦屋面，2024和2026年发布的斜摄影像有邻塔屋顶投影遮挡。门槛在排房中的经纬位置依据这些影像与成对门的位置估计。[逐期影像、地址与实照记录](reference-review.json) · [城市源地块与同组邻房](footprint-review.json)

2014年1月23日Livelikerw摄于模范村的开放许可照片显示连续弧阳台与端墙，画面无可读22号牌，作为里弄环境参照。走访记录记载东邻四方新城建于1997年。两个时期的资料均未给22号门窗和铁栅单独断代。本项目的几何和代码采用MIT许可。外部照片保留原作者署名和许可，仅以链接供查考。[2014年照片及许可](https://commons.wikimedia.org/wiki/File:Mofan_Cun.JPG) · [可编辑及网页模型](../../../assets/models/candidates/jingan-mofan-village-no22-entrance/manifest.json)
