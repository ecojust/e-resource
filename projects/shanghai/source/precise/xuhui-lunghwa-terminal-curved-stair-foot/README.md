# 龙华机场旧候机厅弧形楼梯下段

上海市房屋管理局第四批名录4D048登记“龙华机场候机楼”，地址龙华西路1号。上海徐汇的历史报道记载候机楼原接待民航旅客，1966年定期客运转往虹桥。采访中所见的飞机瓷画能与此后刊出的大厅照片互证。[上海市房管局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海徐汇，2019年](https://m.thepaper.cn/baijiahao_4675590)

从大厅朝楼梯看，浅色石踏步在下端张开。两旁石挡墙收成弧线，黄铜圆扶手接入方形端柱的顶板。踏面与立面分缝，石鼻略向外突出，端柱顶部分为薄板和凸出的帽石。模型保留下六级以及这两道扶手的下段。[东方网，上海老底子转载，2021年](https://m.thepaper.cn/newsDetail_forward_13607172) · [楼梯正面照片](https://imagepphcloud.thepaper.cn/pph/image/142/901/703.jpg)

以一级高0.154米和踏面深0.305米为建模参考值，沿正面照片取端柱宽高、石鼻厚度和扶手的外撇比例。相机透视会缩短后方踏步的可见深度。石材纹理、各构件网格和预览图均为项目原创。独立页展示照片刊发时室内可见的踏步，照片所见的装修年代另待历史资料。
