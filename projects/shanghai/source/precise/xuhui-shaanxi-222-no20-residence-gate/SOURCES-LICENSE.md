# 来源与许可

地址以《上海市第五批优秀历史建筑名单》中5D063为据。2016年2月2日，高参88发表的图文《陕西南路222弄优秀历史建筑》说明保护范围特指20号。第06、07幅拍摄同一扇门。本文用其中的建筑事实、测点和统计量制作原创网格与材质，两幅原摄影留在作者网站，公开模型和渲染图未嵌入原片。[政府名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [高参88的原文与摄影](https://blog.sina.com.cn/s/blog_5d1bdf480102whoy.html)

Antigng于2018年2月7日拍摄的弄堂照片可核实公共入口和主弄朝向，画面没有清楚呈现20号门头。登记的现状建筑轮廓由OpenStreetMap贡献者提供，适用ODbL 1.0。历史地籍配准和现代影像的候选落位分别保存；单个现代底图体块不足以界定旧宅全院。[照片与门号核对](measurements/numbered-photo-source-matrix.json) · [影像来源](measurements/address-20-imagery-sources.json) · [OpenStreetMap许可](https://www.openstreetmap.org/copyright)
