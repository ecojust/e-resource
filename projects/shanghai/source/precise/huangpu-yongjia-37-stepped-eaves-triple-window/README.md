# 永嘉路37号住宅错层檐口与三联长窗

5A067在市表登记为住宅，门牌永嘉路37号。市表5A067列永嘉路37号住宅。据Antigng在2015年9月9日拍摄的门牌题名照片，取花园内高起的浅色窗间及其接入低翼屋面的转角。

三条竖长窗排在同一高起立面，两侧较窄；左转角逐层排大块浅色隅石，屋檐早于窗顶接到一处落差。 高低两组檐口相遇；高窗外的浅色线脚以一段低弧跨过三窗。中、右两窗上段有向外突出的亮面扇，低翼交接处可见落水管。

照片从院墙外斜望，右侧窗的开闭和局部栏杆须以当时影像为准。模型截取到高翼窗台和低翼接缝；拍摄处树盖、院墙和后期蓝色卷帘不作为墙体线脚。
