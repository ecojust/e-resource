# 上海特别市市政府旧址3号楼砖山墙与四扇百叶

市房屋管理局将平江路48号3号、7号楼同列为第四批优秀历史建筑4D046。Fayhoo的全景照片在楼身正面右侧拍到了蓝底白字的3号牌，中央阁楼的四扇百叶和红砖山墙可据此归到3号楼。照片于2015年1月18日上传，拍摄日期未载。[市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [Fayhoo原照](https://commons.wikimedia.org/wiki/File:Shanghai_Tebieshi_Zhengfu_Jiuzhi.jpg) · [照片许可](https://creativecommons.org/licenses/by-sa/3.0)

照片中，浅色窗楣及边框围住四扇红色百叶。窗下砖面有长条形凹格，上缘随横向砖带转折。红褐色的两段斜封檐板在屋脊相交，到檐脚附近变宽。屋脊下垂的一条浅色窄构件按照片中的位置建模，用途未详。[读图记录](reference-review.json)

模型截取山墙及其两侧一小段砖墙，以独立展品呈现。四扇百叶分别建框，倾斜叶片之间留空。山墙宽、檐高和前后深度依照片比例估算。此项只取3号楼的局部，7号楼另列于同一名录。[展示范围](placement-review.json) · [建模源码](source/municipal_gable.py)
