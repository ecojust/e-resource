# 美商卫利韩公司楼顶层双列窄窗与宽钢窗

5A035在市表登记为美商卫利韩公司，门牌福州路37号。第五批市表登记福州路37号为美商卫利韩公司。取Fayhoo在2015年9月3日高处拍下的长立面右部顶层和下一层两开间。

平屋面的深檐带之下，每组窄钢窗由一段实墙分成左右两洞。下一层宽窗保留多列玻璃和连续窗台。 两开间之间的窄立柱旁有深色管线。照片左开间的部分钢扇打开，可见扇边及玻璃反光。

现场照片从邻近高处斜看，平面方向、各扇开启角、窗台进深和绝对尺度另待实测。屋顶棚架、空调和近侧相邻红瓦屋未收入局部。
