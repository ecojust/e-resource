# 延庆路18弄10号弧托雨篷与圆形端饰

5D050在市表登记为住宅，门牌延庆路18弄10号。2018年2月7日Antigng的署名照片拍到延庆路18弄10号住宅的入口，灰色平雨篷从门上挑出，两边各有一道曲托。曲线沿下缘从门侧上翻，近端的侧面可辨圆饰。

雨篷前沿厚直，侧托下缘弧度由陡变缓；近侧可见沿弧肩线与圆形端饰。 棕红色门在两托之后，贴近住宅的灰色水平勒线经过入口左右。

原照从门外斜下方拍摄，门心、雨篷上表面和一侧曲托被树木遮挡。侧托轮廓、板厚、门洞进深均按可见关系估计。院内格局与绝对尺寸未有测绘。
