# 东湖路17号花园住宅门牌与临街围墙

上海市第四批优秀历史建筑名录将东湖路17号登记为“花园住宅”，表中使用单位为“青年报社”。同页的东湖路70号杜氏公馆另有编号4D001。2014年的《看懂上海：东湖路的四个故事》记述，《青年报》于1964年迁入17号。[上海市房屋管理局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2014年报道](https://www.kaiwind.com/n1790/c263635/content.html)

模型依据钱泽民2026年10月14日发表的第37幅照片。绿色板面的上行是“17”，下行是“东湖路”。赭红色面层有连续的横缝。门牌上方的灰色石带分为下肩、宽带、窄凸带和顶面，在画面右侧折回。转角上有竖向接缝。石材的细颗粒用独立几何近似。板面四角用于校正正面比例，制作时假定号牌宽0.32米、高0.22米。围墙厚度、转折角和绝对标高均未实测。照片下缘以展品截面表现。[钱泽民实拍，第37幅](https://www.meipian.cn/5q6lq3ec)

2021年3月的行记将一座赭色建筑与红瓦白墙的小楼并列收入17号的同一图注。2026年5月的另一篇行记也拍到白墙楼的双山墙和小阳台。院墙其他部位有带孔栏板。现有材料不能将其中一栋确定为《青年报》历史主楼，也不能确定门牌墙段的建造年代。[天高云淡，2021年3月15日，第11幅](https://www.meipian.cn/3h20k7by) · [冬美，2026年5月15日，第26至29幅](https://www.meipian.cn/5mdl1pql)
