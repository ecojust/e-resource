# 岳阳路265号东庐三层小挑台与弧端金属栏板

5D082在市表登记为菁英会，门牌岳阳路265号。高参88发表的岳阳路265号花园住宅两幅实照中，三层钢窗前单独挑出一座窄阳台，端部圆转。浅色整片金属栏板与楼板之间有一条空隙，上部为细横杆。按这座小挑台制作。

栏板自正面绕过两端，外挑的楼板以较暗前缘与浅色金属分开。两根能看清的正面立杆延伸到宽栏板以下。 深色细窗框嵌在棕黄色小面砖墙内，长边水平；照片在窗旁显出对齐的竖缝，模型纹理由程序重绘。

两幅照片给出正面及侧前轮廓。挑台进深、栏板背面、近墙的扶手端和固定件尺寸据比例估计。小挑台位于大露台旁的上层，图中的大露台未纳入模型。
