# 桃源坊端部阳台的折弧线脚、卷草铁栏与四杆晾衣架

愚园路1292弄桃源坊建于1938年。长宁区档案记载弄内有18幢三层新式里弄住宅，单幢约90平方米，总建筑面积约1620平方米。2018年2月10日，Antigng从巷内拍到临街一排阳台。本模型选取照片右端、由浅色隔板和外墙围合的一跨。原照没有给出户号。[模型展页](../../../taoyuanfang-curved-balcony.html) · [2018年照片](https://commons.wikimedia.org/wiki/File:桃源坊中一幢里弄建筑.jpg) · [长宁区建筑资料](https://www.shcn.gov.cn/col7698/20211207/1152638.html)

楼板端部两道浅色线脚从直段过渡到缓弧。黑色铁栏以竖杆和细折线相间，中间的格片饰三枝斜叶，两侧共四个回卷。两副交叉扁钢支架托起四根银色晾衣杆，销头、收拢端的安装片与支架下沿各自成形。隔板有阶梯形压顶，阳台下方留有弯臂灯。模型在相连窗墙处收束。[阳台和原照](study-views/balcony-end-in-2018.jpg) · [中央卷饰](study-views/scrolled-centre-panel.jpg) · [交叉支架和四杆](study-views/folding-steel-carrier.jpg) · [两道线脚](study-views/balcony-edge-in-oblique-light.jpg)

图像配准用楼面、端墙、金属杆与竖向构件的投影方向。以照片中央栏杆一根立杆高0.94米作比例假设。四杆两端的8个位置用于拟合间隔和高度。楼板下部浅色线脚另取62个独立位置检验，近景和远景网格投到5312×2988原照上的纵向均方根偏差分别约1.27和1.30像素。外墙进深、架座接墙处及电缆遮住的端部保留估算。[相机](measurements/balcony-camera.json) · [晾衣杆八个端点](measurements/drying-rack.json) · [楼板线脚测点](measurements/slab-edge.json) · [独立复核](measurements/independent-moulding-edge.json)

地图可识别桃源坊地块。2018年原照附有精确到整秒的相机经纬度，未记镜头朝向；51、53、65号等门牌也无法确定这跨端部阳台的位置。展页按住宅组归档，主图保留原建筑。[位置核对](../../../data/audit/taoyuanfang-curved-balcony-v1/preflight/final-placement-review.json)
