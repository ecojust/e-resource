# 美丽园14号园侧立面

延安西路379弄美丽园列入上海市第五批优秀历史建筑。高参88在院内记录了14号，照片可见两处两层外挑窗、三层侧墙和花园转角。弄外另一张照片从院门方向拍到同一栋的砖色、层数、挑窗和屋缘。2016年看看新闻的报道也提到14号各面的跳空阳台。[走访记录](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480102uyin.html) · [看看新闻](https://m.kankanews.com/detail/8029PVl75w6)

主凸窗宽面的钢窗各分六列，折转短面各有两列，露台后墙可见由实墙墩分开的高窗。园侧主墙三层的深窗膛和斜面石窗台相互对应。转角处有28道上下交错的隅石，檐下方斗通过弯管接向地面。远端小凸窗也有两层窄窗和一座浅露台。[园侧照片](https://s1.sinaimg.cn/mw690/001HIrzOzy7eMoPOZck90&690) · [可见墙段量取](measurements/garden-extensions.json)

模型取园内照片能看见的两面外墙，两条屋坡在檐后截短。墙厚、窗深、坡度、树木遮住的窗边和花园内的绝对尺寸为估计。地址检索将12、14、16号投到同一坐标，园内原照片的文字与院门顺序用于辨认14号。独立模型保留城市底图的周围住宅。[地图与门牌验证](measurements/footprint-review.json) · [原照与许可](SOURCES-LICENSE.md) · [构件源文件](source/build_model.py)
