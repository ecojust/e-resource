# 衡山路10号美童公学主教学楼

徐汇区文化局的历史记录把衡山路主教学楼定年为1922年，记载了两层舒展的红砖立面、成排老虎窗和中部屋顶突塔。1912年是学校开学的年份。二批名录2D020登记学校主楼，宿舍与水塔另在第四批。华山路639、643号登记在静安区2B019。[市房管局第二批名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [徐汇区文化局2006年档案](https://web.archive.org/web/20131104135900/http://xhculture.xuhui.gov.cn/xhwh_website/HTML/xhwh_zxzs_wmrg_lfz/Info/Detail_27853.htm)

独立教学楼东翼由成排教室窗、中间石门楣、正中五扇屋窗和浅色钟亭识别。2011、2013与2017年街面实照、校史文章所载老照片，以及2022、2024年两期航片用于确定立面形态、方位和屋顶范围。地块角点来自原始地图，门脚到檐口、钟亭高度及屋顶背面均按资料估计。[外观来源与逐张散列](reference-review.json) · [校史图像](https://m.thepaper.cn/newsDetail_forward_22259828)

原始轮廓把东翼与向西北延伸的一段合成L形。此模型取经照片确认的东翼，临街长约75.50米、进深约19.51米。西北延伸段继续保留原场景，教室内部未建模。[地块分界](../../../data/audit/american-school-hengshan-v1/footprint-partition.json)
