# 上海钱业公会大楼

市房管局第四批 4A015 登记宁波路 276 号。地方报道记载秦润卿于 1916 年筹款购下隆庆里房产，1917 年改建竣工；南市钱业公所与沪北钱业公会在 1922 年迁入。部分百科页面写宁波路 265 号，房管名录、道路门牌、街景和具名地块均指向 276 号。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [文汇报修缮报道](https://wenhui.whb.cn/zhuzhan/yis/20170824/61216.html) · [新民晚报建筑与人物资料](https://wap.xinmin.cn/content/31960106.html)

模型表现宁波路三开间正面。中央券门由两侧石柱承托，上部三组长窗分别接悬挑铁栏阳台。每座阳台可从斜侧辨认牛腿；窗上穗饰、檐下小托座和中段略有升起的檐线可在照片中互证。下层店面和窗框在修缮前后有变化，模型按后期照片取形。原四层以上的后加部分、其他街墙和室内留待另行记录。[2015 年 2 月 6 日街照，Livelikerw，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:276_Ningbo_Rd._Shanghai.JPG) · [2022 年刊发的正面和建筑铭牌](https://finance.sina.com.cn/jjxw/2022-03-02/doc-imcwiwss3696244.shtml) · [照片与门牌比对](reference-review.json)

原城 14-13720-6694 的 182 号楼对应具名门牌地块 w414733198@3。宁波路一面旧轮廓边长约 15.97 米，OSM 边长约 15.84 米。双档实测旧表面落在模型原点后方 0.605 至 0.865 米，外墙背面延至 0.96 米与旧墙相接。原房及同组另外 17 栋建筑全部保留。[落位和底图来源](footprint-review.json) · [独立页](../../../shanghai-money-guild-front.html)
