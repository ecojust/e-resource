# 新闸路1378弄17号弧形钢窗与露台铁栏

临院的一段弧形钢窗。可见八列宽窄不一的窗面，一根深色横档划分上下两排。窗前是浅色凸窗台，露台左端留有弯铁撑与砖挑头；右侧树后没有可辨栏杆。

模型弧窗高约1.50米、名义半径2.36米，由单张斜照片估计；端部与树后墙面没有测绘依据。玻璃的灰绿明暗为原创材料。
