# 外观证据与使用权

建筑构造、剖切的模型、材质定义和重复砖面图由本项目制作，适用仓库 MIT 许可。两机位测量记录保留照片网址、像素坐标和估尺假设。参考照片未打包到 GLB、Blender 文件或纹理中。[来源清单](reference-review.json)

院史文字与院方图片归相关发布者。2018年现场照片的署名为「言衣草－上海历史建筑前世今生」。1930年代旧照在维基共享资源标为公共领域。[院方建筑史](https://www.thepaper.cn/newsDetail_forward_7738435) · [现场组图](https://blog.sina.com.cn/s/blog_a598306e0102yxe9.html) · [历史照片信息](https://commons.wikimedia.org/wiki/File:Sainte_Marie_Hospital_-_maternity_pavilion.jpg)
