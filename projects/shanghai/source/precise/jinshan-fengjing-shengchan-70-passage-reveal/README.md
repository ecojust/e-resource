# 枫泾生产街70号入巷门洞与嵌砖墙脚

5Y001在市表登记为住宅，门牌枫泾镇生产街70号、油车弄2号。Fayhoo于2015年9月20日拍摄枫泾生产街70号住宅。门洞左侧绿底牌面可读“70 生产街”，与市级名录中的生产街70号相合。取凹入墙面的矩形入巷口、折入过道的砖脚和剥落抹灰，以及上方门牌。

绿牌悬在洞口左上侧，与右侧竖边几乎齐高；其上缘有裸露掉灰，形成暗横带。左、右墙脚露出长短错缝的灰色砖块。 门洞里左侧还能看到剥落白灰与一段低处的深色砖面。街门上方另有后装红色水槽及外走线；本件止于门洞上部。

市表兼列生产街70号和油车弄2号，现照的绿色牌只读得生产街70号。模型记录此门洞；窗景中洞内的暗部在退进的侧墙之后以单面阴影收束。门后的实测终点、油车弄另一侧出入口及相邻院落关系没有资料。宽高、洞口进深、裸砖块尺寸均依照片估计。
