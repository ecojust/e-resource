# 大北大楼电报局延安东路正立面

市房管局第三批3A005登记的大北大楼电报局位于延安东路34号。大北电报公司于1918年3月14日购入爱多亚路地块，委托新瑞和洋行设计七层钢框架办公楼。1921年底基本完工，1922年大北、大东与美商太平洋商务电报公司迁入。市政府资料记载，中国电信上海公司后来将一至四层改为上海电信博物馆，2010年6月开放。[官方登记](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [上海市经信委建筑史与今昔正面照](https://sheitc.sh.gov.cn/djjcdt/20240827/e6af8d5267b245469a35cdc8e055425f.html)

爱多亚路4号是今日延安东路34号的历史街址。第二批2A004则是中山东一路7号原大北电报局，登记使用单位为盘谷银行上海分行，项目已收录为外滩7号。1947年图录可辨前者与上海总会的相对位置。两处街坊轮廓净距约162米。现有亚细亚大楼的精建轮廓位于34号以东，最近相隔约11.3米。[官方第二批2A004](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [历史门牌与街坊图](https://m.thepaper.cn/baijiahao_16148691) · [地图、库存及现有外滩道路几何](prior-inventory-and-streets.json)

从延安东路向北看，三座门口各有平伸的玻璃门篷。中央六组窗之间竖向分隔，窗裙有圆花浮饰，窗上可见石檐与托座。两翼每层各有一对窗，正面宽檐下排列托块，两端女儿墙略高。馆名黑底金字置于中央。Livelikerw于2014年1月14日拍摄的原片清楚记录了馆牌和上部窗列；三门及门篷采用市经信委刊载的现状全景比对。历史正面照还显示较靠后的顶层，当前身处街面可见的范围随仰角而变。[2014年原片及作者许可](https://commons.wikimedia.org/wiki/File:Shanghai_Telecom_Museum.JPG) · [逐项资料和尺寸限制](reference-review.json)
