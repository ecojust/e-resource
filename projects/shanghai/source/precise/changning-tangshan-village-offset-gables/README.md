# 汤山村弄内住宅错落双山墙

长宁区规资局将武夷路466弄的汤山村记为1930年后建造的三层花园住宅。区档照片里，两面粉刷山墙前后错开。前面的高山墙下有两扇窄窗，较低的坡檐退入它的左侧。 [长宁区规划和自然资源局](https://www.shcn.gov.cn/col7698/20211207/1151478.html) · [上海市第四批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

正面图可分辨高山墙向两端折回的深色檐板、下半设栏的高窗和左侧低山墙的斜檐。斜面图显示两道檐板的前后次序，浅色雨水管从高檐转向窗旁。近远两档均保留了窗洞和两道檐下的亮边。 小山墙略向后，檐口较低。前后距离和绝对尺寸为估计。照片未在这些山墙标出分户门牌。

区版照片可辨一对前后错落的山墙，没有分户门号，也没有能区分2至9号屋体的侧向照片。
