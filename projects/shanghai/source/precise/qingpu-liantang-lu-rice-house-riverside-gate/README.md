# 练塘陆家米行旧址沿河院墙与石框门洞

5X006在市表登记为陆家米行旧址，门牌练塘镇前进街77号。陈永年在《春节走进陈云故里练塘古镇》中点出前进街77号陆家米行的高围墙和石库门。紧随题注的沿河照片可读出白灰墙、偏右的矩形大门、门边较矮的横孔和左端较高的方孔。青浦区发改委2026年6月的修缮批复写明同一门牌，并列出各立面、院落格局、木质结构、门窗及走廊栏杆等修缮项目。本件仅取照片中白墙中段。

门洞跨过墙脚直抵步道。左方方孔位于接近门框的上角高度，门右的小孔矮一些，三处在沿河正照里同见。 下段墙皮比上段更亮，临地墙脚露出不连续的深灰边。树干在门右及墙中央形成遮挡，现照无法精确给出门后院落的平面。

署名图像为600×394，近树和垂枝挡住门头及中段上缘。仅取读得清的矩形灰框、凹口和墙顶暗压线，暗部深度依比例估计。河埠、相邻楼房、院内各间与墙上未能逐件辨清的构件保持在本次观察范围之外。
