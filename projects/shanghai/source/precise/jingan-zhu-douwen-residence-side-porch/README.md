# 朱斗文公馆侧门柱廊与弧窗

市房管局将康定路759弄住宅列为第四批优秀历史建筑4B015，登记使用单位为静安区政协。区图书馆记载花园住宅建于1926年。主楼南面面向花园，两层圆弧巨柱敞廊是辨认东南墙角的标志。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [静安区图书馆《朱斗文公馆》](https://www.shjinganlib.net/JaImpressionHistoryContent.aspx?id=126)

从南墙角向北看东侧面，先是弧形木格窗与小阳台，随后是圆花饰、窄窗，最后是侧门前的方柱围廊。两根方柱顶端有卷托，露台边缘连接瓶状石栏。门洞为半圆券，窄窗上方有断开的三角形窗楣。两种拍摄距离可互相核对这些构件。[高参88，2014年近照](https://blog.sina.cn/dpool/blog/s/blog_5d1bdf480101hvos.html) · [《静安文博勾沉》资料与住宅斜照，上海老底子2020年刊](https://m.thepaper.cn/newsDetail_forward_6634480)

2024和2026两期屋顶影像、门牌与院门位置，以及OSM轮廓均对应原城14-13718-6694图组817。住宅的OSM第1版轮廓与原城足印的交并比为98.18%。东侧门廊外沿长约6.7米，深约1.6至2.4米。门高、凸窗曲率、檐口高程和浅浮雕细节依庭院照片比例估算。南立面、主屋其余各翼、屋顶、院门及室内留待另行测认。[OSM建筑轮廓](https://www.openstreetmap.org/way/490282146/history/1) · [实测配准](frontage-location.json)
