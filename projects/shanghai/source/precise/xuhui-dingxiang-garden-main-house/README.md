# 丁香花园一号楼拱廊与露木山墙

上海市房管局第二批名录以2D013登记华山路849号主楼。2013年12月31日的照片可以读出拱廊右侧金属牌上的“1”。2007年已公开的另一张照片拍到同一组出挑木窗、窗下木托、成对窄窗、烟囱和回转的拱廊。上海空间规划设计研究院又从落叶前的庭院拍到这处入口。模型按这三幅照片制作。[照片、地方志与名录](reference-review.json)

近景模型含贯通的半圆拱与上方小拱洞、柱肩牛腿、三步石阶、后退的门扇、四扇出挑窗及上亮、深色露木、两座带压顶的烟囱，以及两侧可辨的转折窗墙。右侧凸窗下的两重线脚、屋坡上的错缝及圆弧窗墙的带线均可独立编辑。被树冠遮住的开间、拱高、构架厚度、玻璃分格和屋坡为比例估计。南面敞廊的2015年照片用于辨认楼栋，南廊、屋后其余棚房、室内、二号楼与三号楼仍列在后续任务中。[可重建的几何源码](source/porch_gable.py)

2015年具名的三号楼有水刷石外墙、宽老虎窗和单独的“3”号牌。其夏朵餐厅街侧入口与华山路855号相合。一号楼的露木山墙、浅色烟囱和两层木廊另有照片。园外另一排住宅也有一号门牌。楼号、地区标注和地块逐项核实，航片用于约束既有地块轮廓。[两栋的照片与餐厅门牌](numbered-buildings-review.json) · [街景、三期航片与底图](building-identity-review.json)

2013年照片的原始手机记录了拍摄磁方位，以拱廊檐口和山墙木带两组消失线独立推算，带牌入口的正面朝约330°真方位，与底图1353西北侧约10.76米长、朝328.6°的折边相近。地方志对拱洞和牛腿的描述归在东立面，照片给出的朝向保留为另一条独立证据。三张街景将附近小山墙的同一屋檐交点定位到1353以内；它与庭院拱廊的逐点关系尚无实测总图。模型顺着该折边估放，沿墙方向仍有尺度不确定性。[照片方位与误差](facade-orientation.json) · [当前底图配准](footprint-review.json)
