# 来源与许可

本模型使用原创的几何、纹理和渲染。源程序和这些资产按仓库 MIT 许可交付。2015 年现场照片由「中国の風景」发表，用于识别门牌、比较窗门和屋面比例。照片权利归原作者，本项目只发布链接、测量数据及模型图。[拍摄者的图集](https://4travel.jp/travelogue/10996441) · [逐张记录](measurements/photographic-sources.json)
