# 谦信大楼江西中路中央六券窗廊

上海市房屋管理局第三批优秀历史建筑名录3A019登记谦信大楼，地址为江西中路138号。工作名录记1907年建、砖木结构、第五层后加。2015年照片的作者将该楼标作祥泰银行旧址。斜对街的恒业里位于115号，是独立条目。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [历史名称与地址](site-location.json)

Livelikerw于2015年2月17日从街上拍下楼上中央窗廊。上下两排各三座大券，红砖券环在拱腹内延伸，拱脚有浅色柱头。棕红色窗扇后退，下排三处石栏可透见窗扇。清晰的右栏有11根正面带圆饰的石柱，左、中两栏部分受遮挡，重复数量据右栏推估。左下和右上的拱窗还可辨放射状窗棂。模型止于中央窗墙及其下短檐。两端小券、楼顶加建、首层与室内留待另查。[摄影原件与署名](https://commons.wikimedia.org/wiki/File:Former_The_China_Import_%26_Export_Lumber_Co._Building_Shanghai.JPG) · [图像与年代复核](reference-review.json)

窗廊的拱砖、退进的窗框、拱脚叠涩、栏杆和短檐分件制作。模型宽约9.68米、高约7.99米，依据照片相对比例估计。1937和1946年的两张江西路街景不足以辨认此处六券细节，加层具体年份待查。城市地图按名录地址显示街区位置，独立页显示2015年的影像展件。[1937年街景](https://pastvu.com/p/827331) · [1946年街景](https://pastvu.com/p/2427691) · [查看模型](../../../qianxin-six-arches-history.html)
