# 礼和洋行九江路街面

市房管局保护建筑第二批登记表2A036记作“礼记洋行”，地址江西中路255号，登记使用单位为鲤鱼门酒店。黄浦区公布的修缮报告使用“礼和洋行”一名。现状地图的同一建筑同时收录“礼和大楼”“礼记洋行”与英文名Carlowitz & Co.。[市房管局登记表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) [原件、日期与其他来源](reference-review.json)

1908年印本上方的上海洋行正面可见三座双券窗山花，山花之间有两对较低的小老虎窗，下方为连续宽券窗。Livelikerw于2013年12月19日拍摄的彩照显示清水红砖、浅色石栏和当时较封闭的底层，并能读出九江路路牌。市文化旅游局于2022年刊发的外景和廊内照片记录了修缮后分隔开的砖柱、圆角窗、底层券廊与退入的店面。模型采用修缮后廊道，楼上窄窗、栏杆数量及材质据三期照片核对。[1908年出版的洋行照片，上幅](https://commons.wikimedia.org/wiki/File:Tcitp_d621_carlowitz_%26_co.jpg) [2013年实照，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Carlowitz_%26_Co..JPG) [市文化旅游局图文，人民网2022年刊发](https://sh.people.com.cn/n2/2022/1118/c350122-40200023.html)

2013年高清原图清楚显示，东端顶层的成对浅石附柱与较宽的砖方墩相间，柱头有浅色花叶石块，下面一层的两段石栏微向外弯。靠街角的末端砖墩托起宽柱头，浅石饰带随圆角转向江西中路。花叶纹样只按照片可辨的凹凸关系概括。[东端细节与原图像素坐标](reference-review.json)

市文化旅游局记建于1898年，区政府公开的修缮材料将建筑工程记为1901至1904年。两种年代留待施工档案进一步辨明。市表与修缮报告均以四层砖木为基本体量，山花间屋顶窗单列。责任范围沿九江路约44.56米，包括临街四层立面、屋顶前坡和转入江西中路的近端圆角。背翼、完整江西中路立面和各时期店铺内装没有进入本次调查。窗宽、廊深和垂直尺寸按照片比例估计。[街道、源建筑与地块边界](frontage-registration.json)

```sh
python -B projects/shanghai/source/precise/huangpu-carlowitz-jiujiang-front/source/build_model.py --out /tmp/carlowitz-assets --audit /tmp/carlowitz-check
```
