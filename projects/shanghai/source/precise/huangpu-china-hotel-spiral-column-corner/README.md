# 中国大饭店西南切角螺旋柱窗墙

宁波路588号、贵州路160至170号共属中国大饭店。上海市房屋管理局第四批优秀历史建筑表列为4A029，登记使用名为上海铁道宾馆。建筑位于两路交会处的东北角，模型呈现朝向路口的西南切角。邻号宁波路586号的新光大戏院另有4A028保护编号。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [逐份来源、署名和原图校验](reference-review.json)

1930年建成的中国大饭店由哈沙德洋行设计、杨瑞记营造厂承建。上海城建档案在2021年7月31日介绍了馆藏楼宇施工图，并刊出这个街角的一幅现场影像。该幅图片未标拍摄日期。模型取景以可确认拍摄日期的两张街照相互对照。[上海城建档案《贵州路》](https://www.thepaper.cn/newsDetail_forward_13821380) · [贵州路160号建筑史材料](https://blog.sina.com.cn/s/blog_5d1bdf480102v31d.html)

2015年2月6日，Livelikerw拍下铁道宾馆竖牌、底层店铺、螺旋石柱和券窗。2025年酒店改为书香心泊酒店。N509FZ于2026年8月25日从街口拍摄的照片显示修缮后的红色矩形门套、两根螺旋石柱、居中三层窗轴、石涡卷腰带、上端券窗和两翼相邻的一组窗。模型采用后一张照片的外观。预检对照图中的照片经过裁切、排版，两张原照及相应照片裁图按 CC BY-SA 4.0 使用。[2015年实照与署名](https://commons.wikimedia.org/wiki/File:Shanghai_Railways_Hotel.JPG) · [2026年实照与署名](https://commons.wikimedia.org/wiki/File:Habo_Hotel_Shanghai_%2820260825073725%29.jpg) · [许可](https://creativecommons.org/licenses/by-sa/4.0/)

原城建筑2411与具名轮廓373833572第6版重合98.94%。切角宽4.94米，从两端分别沿贵州路与宁波路做3.72米窗墙。立面总高按照片比例估至约17.27米；原楼后部较高。门窗进深、柱径和涡卷尺度均属图像估算。两翼其余长度、退高屋面和室内留待更多测绘资料。[地块核对](footprint-review.json) · [切角与两翼方向](street-registration.json) · [建模源文件](source/hotel.py) · [独立模型](../../../china-hotel-spiral-corner.html)
