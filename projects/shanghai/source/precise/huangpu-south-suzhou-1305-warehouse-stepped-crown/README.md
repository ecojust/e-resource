# 南苏州路1305号仓库山字形圆饰及水泥压花壁柱

南苏州路1305号正门旁的保护铭牌将这幢砖木仓库定年为1933年，并记载河岸立面中央的“山”字形构图。原照可直接辨认圆饰上方的“1933”、四根竖向壁柱、三个短垂饰和两侧成对的箭形压花。模型以箭形压花下沿的一道砖皮为下界。[现场照片与来源](reference-review.json)

四个2019年5月18日的街景位置给出两外柱间约9.23米、两内柱间约3.50米。每次删去一站重算，外柱间距在9.12–9.61米之间，内柱在3.42–3.83米之间。另一张由Dragon发表于2020年的照片从东侧斜望檐冠，六个构件在原图的重投影残差为1.5–3.8像素。拍摄方向使水泥冠和砖面之间产生视差，较窄石边的位置仍有不确定性。[四站交会](street-four-stations.json) · [2020照片配准](publication-rectification.json)

5A081的登记范围横跨1295至1305号。仓库照片中可分别读到灰色柱身的1305号、红褐色侧门的1307号和保护牌上的1305–1307号。东侧1295号另入第四批4A031。模型只取西幢河岸面檐冠，地图保留两栋原有轮廓。[门牌与原址](site-review.json)

近、远景都保留七组高低相间的柱帽、两件对称压花、凸起的圆框与内凹实心圆面。数字、砖面纹理和水泥压花均为原创重绘。墙后深度和装饰厚度按阴影估计。生成脚本和纹理依MIT许可发布，所引照片保留在原出处。[建模程序](source/build_model.py)
