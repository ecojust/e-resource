# 美伦大楼西楼转角柱头双面椭圆盾饰

上海市黄浦区南京东路161号。西楼转角斜面与侧面相接的一根石柱，柱首两面各有一枚椭圆盾饰，盾面有珠花，周缘的卷叶向上翻回，顶部和底部又收成短叶。柱身的凹缝与上方线脚继续绕角。

两面节选各宽约0.57米，柱头连下方两层石皮约高0.88米。双盾、边叶及整体比例按实名历史照片与街摄估建，浅浮雕背面、石种与实际高程待测。
