# 延安西路238号市文联老楼南园面

上海市房屋管理局第二批优秀历史建筑名录2B009列原名“意大利总会”、现用名“市文联”。华建集团历史建筑保护设计院将1947年行号图、1979年航拍和1995年鸟瞰对读，确认西侧238号是独立的三层花园住宅。上海文联资料称房产证记1925年，文献另有1924和1929年说法。原业主和设计人待考。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海文联建筑考证](https://www.icppcc.cn/newsDetail_1138604?utm_source=chatgpt.com)

南立面原先面向住宅花园。1995年前后的道路拓宽缩小了花园，2018至2020年的保护修缮恢复了开敞廊道。模型据1995年照片和2020年12月工程竣工后的影像表现南面。左右切角凸窗和小阳台之间有两层开敞廊，实柱、石栏、后墙木窗依各自深度建模。第三层六轴窗上有弧形窗眉，两侧三瓣曲线山花各开一扇小窗。东向主入口、北楼、西附房及室内另留。层高、栏杆和檐口尺寸为估计。[修缮团队资料与历史照片](https://www.archiposition.com/items/20210824101636?utm_source=chatgpt.com) · [原始读图与哈希](reference-review.json)

东邻大西路10号的意大利商务总会大礼堂由邬达克设计，1941年9月建成。1979年航拍尚见，1995年照片中已拆。**另待制作**的项目为东侧旧礼堂的历史外观，现有竣工照和1947年行号图。238号的OSM门牌、两期屋顶影像和市图1559共同定位本次花园立面。[落点与邻栋](garden-front-location.json) · [市图原件](footprint-review.json)
