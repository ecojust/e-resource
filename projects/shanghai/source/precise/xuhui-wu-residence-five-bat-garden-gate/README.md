# 吴氏花园住宅庭院五蝠石券仪门

沿庭院步道仰看，五只石蝠排在内券。券面可以看到云纹，上方的回纹檐带与绿色琉璃瓦脊分层相接。

市表4D017将201号登记为吴氏花园住宅。区级报道分别拍摄院门、牌楼内券与瓦顶。石蝠采用原创网格按其正面轮廓塑形，树叶掩住的侧缘、门洞深度与脊端按照片估计。 [municipal register](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海徐汇](https://www.thepaper.cn/newsDetail_forward_2340772) · [上海徐汇](https://www.163.com/dy/article/DQD96N4C05149R72.html)
