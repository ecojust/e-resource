# 新乐坊143-1号临街窗墙与弄口门柱

上海市第五批优秀历史建筑 5D107 登记为新乐坊住宅，地址是新乐路143弄1–4号。2018年2月7日的街道照片同时拍到门旁的黑色「新乐路143-1」牌和黄门柱上的绿色「143弄／新乐路」牌。模型以这两处实物确定临街前楼，恢复当时可见的钢窗、门面、砖饰、弄内返墙和屋檐。照片中的招牌随拍摄年代保留。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Antigng于2018年拍摄的原图](https://commons.wikimedia.org/wiki/Special:Redirect/page/66206083)

七樘临街钢窗按各窗分格、窗梃和玻璃所在深度建模。黑牌与绿牌的字形分别取自两块牌的原始像素。两处「CUBTINA」分别挂在门顶布篷和墙面灯箱上。首层东段沿街另有玻璃橱窗、绿门、六格表箱和分体外机。两支斜向金属件各有明亮端面、套箍和独立穿墙洞，洞口一处露砖，一处留有赭黄色填料。

前墙实测宽约11.1米。弄内可核7.1米，保留下层栅门、开扇窗、遮阳片、落水管和水斗。结合五个冬季街景站位，临街墙顶在距地约10.52米处接檐，局部露台墙顶约10.18米。2019年及2025年俯拍均可辨临街屋顶前部的折线。后部屋脊、院内各户与室内须另行核实。原城市地物493覆盖约28.3米的街排，模型只覆盖其中由照片确定的临街东楼。弄口另一侧地物4001、院内3674和其他临街段均另有归属。[街面尺寸](measurements/street-front-measured-limits.json) · [屋面形状与边界](measurements/roof-fold-survey.json)
