# 舟山路394号住宅二层弧形窗罩与六菱格阳台

5F037在市表登记为住宅，门牌舟山路394号。虹口区舟山路394号住宅的正面二层，四列矩形窗上方留有浅色抹灰弧面，外侧是向前挑出的弧形窗罩。前沿石栏开出六个连续的菱形孔，上下保留矩形透孔。金红卫的正照和斜照均标有门牌；高参88另记院内正面拱窗、底层二柱和鹅卵石贴面。

左右窄窗分居中央两窗的两侧，窗头均为平直横框。窗头以上的半圆区域在照片中可辨剥落的抹灰面；深色外檐与内圈压线投下两级阴影。 正照左侧围墙遮住部分栏板。斜照露出从头柱至尾柱的六个菱孔，栏帽为深色，栏身浅灰，横带之间另留小矩孔。

模型只取院内正面的二层窗组、窗罩和阳台前栏。窗台、檐口的前挑和栏板截面按照片比例估计；道路一侧的砖山墙阳台另有形制，未并入本件。
