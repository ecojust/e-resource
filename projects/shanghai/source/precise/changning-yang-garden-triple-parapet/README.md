# 杨氏花园南立面三弧山花与双扇窗

花园南立面顶层的三个半圆山花、上下叠线、三樘双扇窗及窗下浅饰板。

市第四批名录与长宁区规资局采用愚园路838弄7号。朝愚园路的南门另编858号，入口照片与2014年南园照片指向同一栋。

据影像比例估算此段宽6.74米，从底部水平线至中间弧顶约3.8米；窗框的内部木、钢基材及背部厚度无图纸量测。
