# 岳阳路110号住宅花园立面

市房屋管理局第二批名录把岳阳路110号列为2D027「花园住宅」。衡复风貌区2020年建筑专栏把它定位在岳阳路与永嘉路路口西北侧，刊有1948年行号图和同栋花园一面的照片。永嘉路501号与岳阳路145号位于其他地块。1948年图把该处标作民宅，原始产权人仍待契据证实。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [衡复建筑专栏](https://www.sohu.com/a/441238885_802458)

文旅资料记载本宅建于20世纪30年代，为两层砖木花园住宅。占地991平方米、建筑面积377平方米为文献所载。花园一面的照片能辨出退入的底层门窗、前出的二层长窗、方柱挑檐和成排椽头、左侧方形栏杆、四级台阶及数段深檐红瓦坡。右段枝叶遮挡处、其他立面和室内仍保留调查余项。2023年建筑可阅读资料也记载四坡瓦面及乳黄色拉毛，配用早先的屋顶影像。[2023年建筑可阅读资料](https://www.thepaper.cn/newsDetail_forward_23387445)

模型根据公开历史外观资料估算各部分比例，两个年代的航片只用于核对历史楼身的屋面轮廓与方向。花园地面细部和院内设施不在复原范围。原照片的文件散列、日期及对应构件见 [来源核对](reference-review.json)，原模型边界、配准依据见 [位置核对](footprint-review.json)。
