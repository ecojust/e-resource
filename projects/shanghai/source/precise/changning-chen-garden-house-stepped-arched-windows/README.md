# 陈氏花园住宅阶梯三拱窗与绞绳柱

上海市房管局第四批名录4M039把虹桥路1440号的陈氏花园住宅、先前医院使用名与申康宾馆列于同一条。2018年上观新闻报道“1901记·忆虹桥展”，刊载题为“陈氏花园住宅”的虹桥街道资料照片。画面中三扇半圆拱窗逐级升高，两根细柱分别连在相邻的两个高度上。报道还具体提及窗柱表面的绞绳纹。原照片拍摄日期未载。
