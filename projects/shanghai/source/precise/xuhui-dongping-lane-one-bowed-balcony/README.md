# 东平路住宅弧形铁阳台与彩玻圆首门

5D026在市表登记为住宅，门牌东平路1号。市第五批5D026住宅，早期公布地址为东平路1弄。Fayhoo于2015年1月拍到住宅墙面凸出的弧形铁阳台，圆拱有多重细线脚和居中楔石，扇形亮窗及双扇门都留有彩色花叶玻璃。

圆拱的细线脚从两边延至拱顶，正中方楔石有凸起细舌。亮窗和双扇细木门的玻璃保留绿色与琥珀色色块。 黑色栏杆沿浅弧形石板边缘围合，顶铁较粗，两侧下方有卷纹，照片下半被花盆和鲜花遮住。

后来名录的地址写作东平路1号。照片说明按1弄，镜头只支持这一处住宅立面。彩玻花叶取可见色块和排列，未逐片复绘。阳台的实际出挑、栏杆净高和门后室内均未实量。
