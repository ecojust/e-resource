# 中山公园大理石亭

上海市房屋管理局第三批优秀历史建筑 3M026，长宁路780号中山公园内。长宁区档案介绍记载，石亭于1935年迁建入园。四根前柱的中间跨约等于两侧各一跨之和。后屏有三个贯通的拱孔，两端为雕像龛。旧照片可从梁间看到天空，现状照片上方覆盖藤蔓。

## 重建首版

在安装 NumPy、SciPy、Shapely 2.1 和 Pillow 的项目环境中运行以下命令。

```sh
python measurements/fit_pavilion.py measurements/pavilion-cameras.json
python measurements/make_pavilion_cameras.py
python measurements/check_mesh.py /tmp/marble-pavilion-check
```

初稿记录前廊、后屏、柱、透空椽架、石阶、侧栏、花钵和雕像龛的位置。参数与摄影尺寸见 [三站原始测读](measurements/pavilion-observations.json)。步道前缘总宽采用两期航片可辨台阶范围给出的条件值18.7±2.1米。区政府发布的两个视点没有原始拍摄日期。2014年照片由 Fayhoo 拍摄并以 CC BY-SA 3.0 发布。公开模型及纹面由程序独立生成。
