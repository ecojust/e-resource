# 福新面粉一厂沿河厂房红砖壁柱与矩形窗

上海市静安区光复路423–433号、长安路101号。沿河三层厂房上部的一跨窗墙，红砖壁柱与浅褐砖墙交接，矩形窗上方设砖过梁，窗底石台向外挑出。

取沿河三层厂房上层单跨，区分后排六层钢筋混凝土建筑。宽约3.0米、高约3.1米和各构件进深均据实景照片估算。
