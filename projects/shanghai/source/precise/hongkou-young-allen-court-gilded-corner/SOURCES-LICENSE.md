# 来源与许可

- 本项目原创的网格、参数、灰砖贴图与相机定义依仓库许可发布。原创灰砖由制作脚本绘制。网页GLB内嵌贴图，原生工程按每个面的顶点重建砖纹坐标。[仓库许可](../../../../../LICENSE) · [灰砖脚本](source/grey_brick.py)
- 普通街角照片《Young Allen Court》作者为Fayhoo，于2015年1月25日上传，作品采用CC BY-SA 3.0。图中未提供独立拍摄日期。对照图将该照片缩放后与模型并排，增加文字；整张对照图同样采用CC BY-SA 3.0。[原作与作者](https://commons.wikimedia.org/wiki/File:Young_Allen_Court.jpg) · [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- 公共地图轮廓来自OpenStreetMap贡献者，使用ODbL 1.0。建筑沿街部分的窗序、金顶轮廓和山花来自另行观察。地图第1版外廓与实景拍摄的凸角位置存在偏差，本模型作独立展示。[建筑轮廓与版本](https://www.openstreetmap.org/way/494547086/history) · [ODbL与署名](https://www.openstreetmap.org/copyright)
- 2015至2021年的街景用于跨站辨认，Esri World Imagery Wayback用于观察屋脊和横向压带。资料清单记录站号、时间、瓦片地址与摘要，随模型发布自主测得的位置和绘制的几何。市级名录用于核对地址与登记年代。[照片查验清单](measurements/ordinary-street-photography.json) · [World Imagery Wayback](https://livingatlas.arcgis.com/wayback/) · [上海市房管局](https://fgj.sh.gov.cn/yxlsjzcs/20200414/b9946bf8508e4b9689671fcd4146bb86.html)
