# 丰乐里北贰支弄红砖券与浅色券心石

5F017在市表登记为丰乐里，门牌四川北路1999弄（1-110号），四川北路2001-2021号（单号）。四川北路1999弄丰乐里的一条支弄口，在祥子g的2016年图文中标明“丰乐里北贰”。本件取低弧红砖券及两侧起拱段，正中有浅色凸缘、内面下凹的券心石。

大券内弧顶比起拱点仅高约半个窗半径。红砖在上方放射排列，在右侧起拱处转为水平砖皮，最外圈砖沿有一道窄凸边。 券心外框接近竖矩形，顶沿比券砖高，里面有深浅两面。灰砖墙两侧各有横向红砖带，券下能透视支弄街巷。

比例按该文题注的单张正面照片估计，无测绘的绝对高度与墙厚。未辨清的门额文字不在截取范围内。照片记录2016年或以前的外观。
