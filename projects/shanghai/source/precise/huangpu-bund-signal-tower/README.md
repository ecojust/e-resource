# 外滩信号台

上海市房屋管理局登记2A011，名称为外滩信号台，公布时使用名称为外滩史陈列室。门旁的市政府铭牌写有中山东二路1号甲、1907年建造及1993年整体向东南移位20余米。1880年代洋泾浜入江处的早期信号杆与现存钢筋混凝土塔分期记载。模型位于迁移后的江边步道。[市登记表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [铭牌、日期及历年照片](reference-review.json)

十张照片中，2015年两张分别能看到塔基的竖向窗与门旁的铭牌，2019年的近照保留了号址、门扇和雨篷，2022年照片展示了转角站房与塔顶号杆。航片能区分西北端塔基和东南端两层长方形站房。交付范围包括厚墙开口、红砖腰带、两处环形栏杆、桅杆和信号横桁。门窗尺寸、室外构件截面、杆索和楼高按照片比例估算。[外观与迁移依据](reference-review.json) · [2013年修缮报道](https://www.chinanews.com.cn/cul/2013/08-08/5140259.shtml)

现址底图589直接继承OSM建筑440730276第4版，其标签同时载有市名录工作编号、现名和旧名。原来约6.4米高的普通房屋网格未表现信号塔。外滩15栋精建模型和27处步道另有范围，离此处最近的精建包围范围至少还有85米。[冻结地物与邻接](footprint-review.json) · [已有精建和街具逐项核对](../../../data/audit/bund-signal-tower-v1/prior-model-coverage.json) · [单体模型页](../../../bund-signal-tower.html)
