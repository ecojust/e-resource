# 富民新邨弄口四块字牌与通道过梁

取富民路148—172弄临街入口上方四块浅色方牌。自右向左的“富民新邨”立体深红字、各牌的下缘、过梁底和两侧墙的起端可单独查看。

依据2017年街面正照取四个字面、石牌与过梁之间的比例。过梁名义全长4.99米，字的凸出高度约2至3厘米，实际未量。

Antigng，2017-08-19，《富民新邨》，Wikimedia Commons，CC BY-SA 4.0。 依据原照描出四字的可见面后制成立体浮字。左端“邨”的一小段被管线遮住；保留现有读数。字的色彩、背面和凸出尺寸是估算。 [照片原页](https://commons.wikimedia.org/wiki/File:%E5%AF%8C%E6%B0%91%E6%96%B0%E9%82%A8.jpg)
