# 襄阳南路364号券门

2020年2月22日的街照在券门右侧拍到绿色364号牌。2015年4月12日的照片从另一方向拍到同一券口，电杆偏在更右侧，两门脚、后退的木门与门槛都可辨认。两侧底窗、楼上的长方窗及南侧圆券窗提供了跨年的对照点。[2015年街景源](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300001504120633239165R) · [2020年街景源](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122002221452176135O)

| 券口 | 净宽1.80米，起拱高1.71米，内券顶2.41米，外缘顶2.53米 | 2015年近正面可见完整窄券边。2020年照片的电杆遮住了右门脚。 |
| 木门和台阶 | 门背入墙1.10米，门槛较人行道高约0.18米 | 门背左边上下两处跨站交会，进深分别为1.09与1.12米。 |

| 两处低窗 | 左窗较深，右窗带竖铁条及一道横档 | 两年可辨正面开口。框、罩和低墙表面按2020年照片表现。 |
| 首层腰线 | 下缘约3.08米，上缘约3.22米 | 2015年较宽照片可在券门轴的左右两侧沿墙追踪，门口正上方有横线遮挡。 |

坐标原点位于券门前缘的地面，横轴向照片右侧，深度向室内。估算以2015年站点记录的2.32米镜头高和约0.13米的路面至人行道高差为尺。后者没有现场实测，门宽、券顶高度的取值精度约为0.20米，进深约为0.25米。15个墙面同名点对第二站的重投影中位偏差为6.49像素，两张局部图的分辨率均为1320×1150。[投影与原始量点](numbered-entrance-two-stations.json) · [重算脚本](register_numbered_entrance.py)

模型中的门扇保留了照片可见的深木色与接缝。窗下两个小通风花格可辨圆角外框和内部卷线，花心线条作简化处理。[三维首交检查](check_numbered_entrance.py)
