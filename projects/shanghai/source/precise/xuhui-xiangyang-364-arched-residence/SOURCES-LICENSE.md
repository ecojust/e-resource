# 来源与授权

- 上海市房屋管理局第五批优秀历史建筑名录登记5D023为住宅，地址为襄阳南路364号。行政记录用于协调地图条目和门牌。[市房管局原表](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)
- 百度地图沿街全景用于核对外轮廓、窗型、门牌、屋顶小屋和北侧遮挡边界。测量文件给出摄影站、方向、原图摘要、取点画幅与误差。发布件含自绘几何、测量数字与模型渲染。[南侧摄影站](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122002221452161555O) · [正面摄影站](https://mapsv0.bdimg.com/?qt=sdata&sid=09000300122002221452176135O) · [北侧控制](measurements/street-three-station-control.json)
- 四期航片分别摄于2010、2019、2021和2025年。地图宏图形保留其原始面，街面可量区域从照片另行测量。[影像期次和来源](measurements/four-imagery-epochs.json) · [底图及地址](measurements/placement-identity.json)
- Antigng于2018年8月2日所摄的院内照片以CC BY-SA 4.0发布，照片题为“襄阳南路362号住宅”。该照片和对应院廊的比较资料列在362号独立目录。[原摄影页](https://commons.wikimedia.org/wiki/File:襄阳南路362号住宅.jpg) · [362号院廊](../xuhui-xiangyang-south-362-courtyard-arcade/)
- 本项目制作的程序化建筑网格、粗抹灰和水洗石纹理按仓库MIT许可发布。两种纹理可由固定随机种子重新生成。[纹理生成脚本](source/finishes.py)
