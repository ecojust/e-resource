# 襄阳南路364号住宅

上海市第五批优秀历史建筑名录将5D023登记为襄阳南路364号住宅。2020年沿街照片中，绿色364号门牌位于入口券洞右肩。正立面南端以圆角收头，二、三层各有一樘随墙面弯曲的钢窗，北端则在直角转向西，两扇上下对齐的矩形窗在北侧可见。街侧模型的内界位于主墙后3.18米，这一截面对应街上能辨清的范围。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [门牌和地址](measurements/placement-identity.json) · [街侧截段和三站控制](measurements/public-front-envelope.json)

入口有三层门阶，门扇位于券洞内约1.10米。入口上方宽窗左右，各有一樘带放射扇肋的圆头钢窗。再上一层的中央双窗下，灰色窗裙嵌有三枚八角花格，下缘有四处弧形凹口。屋顶抬高的小屋有两扇窗。两处街道摄影站交会所得正面宽约4.87米，压顶高约12.58米。南端圆角半径采用1.82米，近地投影和曲线端点仍有测量误差。[正立面两站测量](measurements/street-facade-dimensions.json) · [南端弧窗与取点](measurements/curved-casements.json) · [入口详测](measurements/numbered-entrance-two-stations.json) · [屋顶小屋](measurements/roof-room-two-stations.json)

队列原地址写作“襄阳南路364弄”。另有Antigng署名、题为“襄阳南路362号住宅”的2018年院内照片，记录三个券窗和圆端。该院侧单独建模，其与364号沿街建筑的产权和相接位置仍待图纸核定。[登记地址与相关影像](measurements/placement-identity.json) · [362号院侧独立模型](../xuhui-xiangyang-south-362-courtyard-arcade/)
