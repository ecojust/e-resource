# 沙美大楼北京东路主立面与四川中路转角

沙美大楼在北京东路190号。上海市第四批优秀历史建筑以信托大楼／上海信托公司为原名称，以沙美大楼为现名，编号4A006。修缮团队记载大楼于1921年完工。本模型采用修缮后的街面外观。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [修缮团队报告](https://m.thepaper.cn/baijiahao_21990753)

北京东路南面包括八跨银行窗墙和居中的主入口、楼梯间。双柱上有卷涡断山花和英文楼名，楼梯间的大窗、圆窗及屋顶山花均按独立开口制作。露台以后的楼身向内退，突出阳台有独立板、托座和铁花围栏。东南街角的圆廊与人行道接平，可从双柱间走到内门前。临四川中路细化了紧邻转角的一跨。[2022年项目与朱润资实拍](https://www.archdaily.com/zh/998286/huan-xing-fei-xu-sha-mei-da-lou-gai-zao-shi-suo-she-ji)

直街墙按OSM节点与相切圆弧拟合至34.22米，2026年刊出的南向正面照片用首层和退进楼身分别配准。主门轴距西界约17.38米，直墙女儿墙和楼梯间山花最高点约23.5米与30.0米。各点的照片像素、单照尺度假设和误差列在[南立面标定表](source/south-front-metrics.json)。[北京东路正面实照](https://n.sinaimg.cn/sinakd20260817s/303/w1080h823/20260817/9895-13bf7d6564b758617bbeb060d94a57f0.jpg)

鼓座内部敞天。修缮团队的内照与两组街拍可辨街面三只拱窗，六分节奏延续到背面是模型估计。室内、屋顶花园、北西后壁、四川中路其余窗墙和历史高穹顶留在后续调查范围。[2024年路口街拍](https://www.trip.com/moments/detail/shanghai-2-120137561/) · [鼓座修缮后内景](https://imagepphcloud.thepaper.cn/pph/image/239/200/767.jpg)
