# 宜德堂（杨氏花园住宅）

上海市房屋管理局第四批优秀历史建筑名录将静安区昌化路136号登记为4B011「宜德堂」，现名「杨氏花园住宅」。2003年《上海青年报》记者张琪与实习生高越在杨家陪同下访宅，将宅名记作「懿德堂」，并记载蒋静宜聘请通和洋行设计，1938年落成，一至四层封闭，五层设天台。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2003年入户报道](https://news.sina.com.cn/c/2003-07-30/0940470579s.shtml)

2021年2月22日，百度地图从昌化路的相邻站点拍到院墙上方的两层窗带。中心窗轴相距约4.3米，窗墙比街侧足印边线退进约5.2米。浅色细砖按错缝铺砌，顶部有一行竖砖；较宽的灰色水泥带贯穿两开间。建模取照片汇合最清楚的四扇矩窗，为每扇分别构造玻璃面、两列三排细框、外挑窗台和内壁。2017年9月的照片用于复核院墙和宅体的位置；树叶遮住大部分窗面。[站点、照片来源及量测](reference-review.json)

具名足印与原城楼体2107的交并比为98.46%。街面渲染只在二三层窗带的高度局部退进，地面通行沿用原建筑。首层、内堂、天台及屋脊留待有对应影像时细化。模型不使用原始照片作为贴图。[足印与原始网格](footprint-review.json)
