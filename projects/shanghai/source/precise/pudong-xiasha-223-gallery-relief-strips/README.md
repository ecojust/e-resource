# 下沙街223号楼廊竖饰板的长框与菱花

5W031在市表登记为住宅，门牌航头镇下沙街219-223号（单号）。Dragon于2020年9月20日拍摄下沙街219至223号住宅；一张近照同时拍到了清晰的223号绿牌和二层楼廊。栏面深色横条之间排列着窄长的红褐色饰板，顶部有短卷纹，上段带收尖的细框，下段有两个菱形小饰。

作者同组的五张实照依次记录楼廊全貌、两处斜视及法定保护牌。竖饰板反复出现于扶手下，最上端与下方长饰框之间有短横分隔。 斜穿廊面的电线和靠近下轨的电缆圈可辨；测量取未被遮挡的竖框与菱形，不将线缆计为原建筑细饰。

现场照片所在章节和保护标牌均标219至223号单号，本件取同图可读223号的门前一段。雕饰表面的材料、线脚最细处和板间暗部不能由照片独断；饰板背面和绝对尺度按比例估计。
