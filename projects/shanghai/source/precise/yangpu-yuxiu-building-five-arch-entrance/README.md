# 毓秀楼正门五券石廊

上海市第四批优秀历史建筑名录4G009登记毓秀楼，地址为武东路100号。大楼建于1953年，通常为三层，中央局部为四层。正门底层有五券，背面三门另设台阶。南北两侧的清水红砖楼各自独立。[上海住房城乡建设管理，2020年6月](https://www.thepaper.cn/newsDetail_forward_7698556)

2020年的总图和2023年近照都能辨认连续五道圆券。券下石墩有凸起腰线和宽柱脚。中间三跨可见后退的深色玻璃门，两端各有菱形格窗。题名的三个字高于券顶。模型按约2.52米的开间中心距估算，进深、石色及门内分格有近似。三字用 Noto Serif CJK 排印，原题笔形可与摄影对看。[上海杨浦，2023年12月](https://www.thepaper.cn/newsDetail_forward_25522297)

武东路校区主楼落在原城2090，四层的OpenStreetMap轮廓与其重合98.83%。同栋有多个门址，现有地点资料只到门级。两期正面照片没有给出五券端点的平面坐标，故本页独立展示门廊。[OpenStreetMap 主楼](https://www.openstreetmap.org/way/496441479)

在上海项目根运行 `python source/precise/yangpu-yuxiu-building-five-arch-entrance/source/build_model.py --out out --audit review`。两期照片仅引出处。字形依照 Noto Serif CJK（SIL OFL 1.1），详见 source/OFL.txt。模型及实图的其余部分均为原创。
