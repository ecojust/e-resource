# 愚园路419弄3号外墙烟囱与瓦檐

5B004在市表登记为住宅，门牌愚园路419弄（3-32号）、愚园路411号、愚园路427号。Antigng于2018年2月13日从街道拍摄愚园路419弄3号。取外墙上的高矩形烟囱，以及被烟囱中断的两段棕色瓦檐。

正面浅色拉毛延续在檐下，右侧面较暗。顶部小幅出挑的灰压顶在向阳处呈细白线。 烟囱左右棕色斜瓦檐被竖直正脸截断，檐下是深棕的水平封檐。

名录涵盖419弄3至32号以及愚园路411、427号。这里依摄影者题名辨认3号。从街面仅见烟囱正脸、右侧及两道小压顶，未见顶部烟道开口。进深、逐瓦尺寸与室内烟路均没有实测，截段尺度按照片比例估计。
