# 模型与来源许可

本项目自行编写几何、墨绿色铁门的格栅、1327门牌数字和程序化水泥墙面。源码、纹理和导出模型沿用仓库 [MIT 许可证](../../../../../LICENSE)。

建筑身份来自上海市房屋管理局。建筑尺度取自公开刊载的李维原始北立面图，门与楼梯外观取自公开建筑报道中的照片。源图著作权归各自权利人，模型使用从图上读出的尺寸和轮廓。[市级登记表](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [刊载北立面原图的报道](https://www.thepaper.cn/newsDetail_forward_24151077) · [东方网建筑报道](https://m.thepaper.cn/newsDetail_forward_13957394)

底图对照使用 OpenStreetMap 贡献者的建筑要素1153085062，第2版，按 ODbL 使用。仓库城市图层内1005号要素与它的面积交并比约为0.964。两者都记录整栋公寓的简化轮廓，模型所取范围仅占北面中央一段。[建筑要素](https://www.openstreetmap.org/way/1153085062) · [OpenStreetMap 版权声明](https://www.openstreetmap.org/copyright) · [本件核对记录](reference-review.json)
