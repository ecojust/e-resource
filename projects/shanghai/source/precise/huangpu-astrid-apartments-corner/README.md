# 南昌大楼南端街角

市房管局第二批名录将茂名南路143号登记为「ASTRID公寓／南昌大楼」。1994年现场保护牌同时列143号、151号，记载建筑师列文、1933年竣工。门牌点与有名称、地址的屋面轮廓支持同一幢。2019年发表的街面组照分别拍到门扇、冠饰与门框。2023年黄浦区的街区图文提供街角高位、正向及冠部近景。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [2019年组照](https://www.sohu.com/a/318837468_99931207) · [2023年街区图文](https://www.thepaper.cn/newsDetail_forward_25322592) · [逐照记录](reference-review.json)

本次制作两路交会处的几何门额、内收铁门和扇形气窗，向上延伸至七层双列窗、奶黄与浅绿面砖和顶部浮雕。两侧各建临街首段凸窗，后方长翼、屋面与内院沿用城市底图。两套照片均可见冠饰下的挑托、弧线和顶端斜向折带。阳台、门格及浮雕的截面按照片估计，门内空间尚缺实测。[原生构造源码](source/street_corner.py) · [几何与通行检查](../../../data/audit/astrid-apartments-v1/README.md)
