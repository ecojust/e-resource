# 张园威海路590弄77号绿肋圆顶与石饰鼓座

5B036在市表登记为住宅，门牌威海路590弄77号。按Windmemories于2026年2月9日署名拍摄的威海路590弄77号现貌，取弧形凸出部最上端绿色圆顶、短顶管、横向搭接线、竖肋和石饰鼓座的可见前半部。

表层有密集的竖向细纹，数道深绿色拱肋从檐缘收向顶部短管。横向搭接线穿过两肋间的浅绿色表面。 檐缘下有一排小石齿，鼓座由弧面上的浅凹矩形板构成。主楼屋面遮到鼓座下沿。

视图未露出圆顶后沿、烟囱后的肋和石座背面。直径、进深、竖肋与内凹面板在背面的完整数量缺测，仅呈现正面研究片段。
