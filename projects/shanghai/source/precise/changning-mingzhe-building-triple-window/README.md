# 明哲楼南面三联长窗与盾形窗饰

市名录4M015列为愚园路864号长宁区教育学院1号楼。2014年刊出的照片可见南面四柱门廊及其一侧的窗列。近照中，双扇长窗居中，两旁各有一扇窄窗，额部中央的盾形花饰向两侧伸出枝叶。建模尺度取自画面比例，雕饰背面和实际窗深缺少实测。
