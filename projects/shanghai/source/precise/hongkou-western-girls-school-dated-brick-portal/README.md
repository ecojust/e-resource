# 工部局西童女子学校双年份砖券门

市房屋管理局第四批名录4F006记载，塘沽路390号原为工部局西童女子学校，名录所列现用单位为上海市安装工程有限公司。对街塘沽路387–401号小浦西公寓另列为4F005。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

Fayhoo在2014年9月14日从院内拍摄正门。砖拱上方左右两块浅底红字年牌依次为1893、1894。往上还有两块浅色素面横匾，再上为当中以砖垛隔开的两块低浮雕。入口后方另有一段更高的屋面。[摄影原件](https://commons.wikimedia.org/wiki/File:Gonglijihanbilixitongnvxue.JPG) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0)

模型取券门本身。沿原片两侧砖垛和上下横线校正透视，深红与青灰券砖分圈砌入，券下留通口。年牌数字、外伸檐带、卷枝主轮廓与台阶侧栏单独建模。门面展示宽度约3.41米，系比例估算。照片暗处、饰板风化处及背面深度只能近似表达。[照片测量记录](reference-review.json) · [置地说明](placement-review.json) · [源码](source/dated_portal.py)
