# 华山路831号孙氏花园住宅筒瓦拱门

第四批优秀历史建筑名录列华山路831号为花园住宅，编号4D022。上海图书馆将武康路1号与这座住宅并列著录。模型取华山路的西院门。2015年两个街道机位能读出券右方的绿色831号牌，2020年复拍仍可见宽券和门前双树。华山路849号丁香花园有独立院落。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海图书馆](https://data.library.sh.cn/entity/architecture/d2mlofut4jyxzshk)

2021年正面照片可辨灰色筒瓦门帽、宽券两侧的竖向六边形透孔、孔内交叉铁条和赭黄色墙面的竹叶纹。门额下小齿沿短檐连续排列。2014年黄石的写生独立记录了相同的拱门与双树。门牌下方另有金属牌，现有资料的字迹难辨，模型保留其轮廓。[2021年东方网图4](https://m.thepaper.cn/baijiahao_14024059) · [黄石写生](https://news.ifeng.com/c/7fkd33jXYRT)

两处2015年12月18日的实景机位相距16.89米。分别沿门内沿与路面量取后，临街净宽约4.11米，券顶距地约3.13米，两侧可见的券腹深度约1.41至1.54米。轴线绝对位置估计有1至2.5米误差。照片边缘的墙段以截面收束，瓦件分隔与竹叶纹的疏密采用图像比例估算。图中树木、院内楼房和武康路入口各自保留。[实测记录](source/street-measurements.json)

几何、竹叶纹材质和数字831的笔画由项目制作。第三方照片的署名、日期、来源和图像摘要见[资料记录](source/street-registration.json)。
