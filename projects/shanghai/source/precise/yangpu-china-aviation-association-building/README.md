# 中国航空协会旧址：来源与外观范围

模型 ID：`yangpu-china-aviation-association-building`；名录 `sh-historic-b4-177` / `4G011`。对象为上海市杨浦区长海路174号长海医院内的飞机楼，是旧中国航空协会建筑，与同院旧上海市博物馆影像楼分开。

本轮按修缮后可见外观制作：西侧宽圆角翼和中央圆塔、三重石栏退台与顶部小圆体、低筒拱机舱连接段、东侧窄翼和中央后门阳台。西门保留双翼飞机徽、龙框和黑金门的几何主题，东西入口台阶形状分别依据照片。树木、河道、现代病房楼及同院博物馆不并入。

实际阅读了[上海杨浦官方账号2019文章](https://www.163.com/dy/article/F0V9CJ2105348TJL.html)、[历史建筑保护网归档](https://web.archive.org/web/20140502190753id_/http://www.aibaohu.com/2008/12/20081201143005-67608.html)、[政协联线2020文章](https://www.icppcc.cn/newsDetail_1040008)及百科建筑段落。采用1935兴建、1936落成、1991资助修缮和1993修复的年级别口径；政协文1933奠基、美篇段落1934奠基的冲突不默改，也不采用其精确时序。没有取得官方修缮工程图或原设计图，不称1935原貌复原。

参考人员实际查看18张照片，其中17张为航空楼及其标牌，1张为同院博物馆对照图并排除。Root另独立实际查看其中6张：2013高斜全体、2010西门近照、搜狐图02顶视/04正面高斜/07塔冠近照和美篇图33东后门。其他照片不混称为Root全阅。Commons照片分别拍于2010和2013；搜狐与美篇页面发表于2022，实际拍摄日期未核。[照片记录](photo-review.json)逐图注明URL、哈希、可见范围和审查者。

前翼三道窗带在照片中明确可见，下两道较近；馆外导览的一二层为工字主体，第三层仅为圆塔圆环。此证据与保护网“主体两层、前楼较高”相容，因此三窗带不等于三个等高翼层。塔冠为三重厚石栏与逐级平台，中央小圆体有短竖窗及平圆盖，不能简化为无层次的帽顶。东后门照片明确浅凸圆角中央块、二层云纹阳台、两层窄窗、门楣四个八角饰及矩形短阶。

1522平方米为文字中的建筑面积，10亩为征地面积，均不是足迹尺度。宽深、高度、栏杆节距及微小雕饰继续注明地图或照片估计，不称现场测量。虽然东后门中央立面已补证，完整东后翼外围、树挡南侧低窗与隐藏墙角仍缺清楚影像；已建机身两侧及后翼普通侧窗按可见类别和两层关系作估计布局，间距与完整窗位未经逐面照片核验；不制作未核室内。文字中的八螭首仅可保守表达，照片没有逐个细节测量。

[来源索引](source-register.json)、[文字审查](documentary-review.json)和[照片审查](photo-review.json)为同一组公开来源记录，审计可直接引用，无需复制原始网页和照片。第三方材料只在私缓存中保存，公开文件仅包含独立摘要、链接与哈希，不发布原图、全文或原图贴图。地图定位、覆盖集合与尺度以独立足迹审查为准；最终资产、重建和许可另由作者文件记录。

## 最终资产、许可与重建

[全局主图直达](https://raw.githack.com/ecojust/e-resource/master/projects/shanghai/index.html#landmark=yangpu-china-aviation-association-building&mode=overview)

原始档与网页档各106,192个三角面，远景档60,384个；四资产共10,057,090字节，含可编辑Blender。外包高度约16.7米，所有尺寸仍为估计。[四资产清单](../../../assets/models/candidates/yangpu-china-aviation-association-building/manifest.json)逐件绑定大小与SHA256；[作者说明](AUTHOR_NOTES.md)列出造型范围、估计和重建命令。

本轮新建工字形前后翼、圆塔、三重开孔退台栏、低圆窗亭、双弧梯、低筒拱与东西门简化细部。顶照复核后塔位按照片规整，西侧前凸约2.4米；不把粗地图西凸弧当作测绘塔心。机身两侧和后翼普通侧窗位置为估计布局，非逐面照片验收。室内、医院邻楼和院区地面不并入。

灰色平屋面与环台低于周边石材泛水台约4厘米（估计），墙厚仍包住屋面边；[屋面接缝检查](../../../data/audit/aviation-building-v1/author-roof-cap-overlaps.json)逐一扫描全部同高度向上灰面/石材面，并检查实体连接。

几何及代码采用[MIT许可](LICENSE)，地图参考为ODbL-1.0；[辅助代码来源](source/HELPER_PROVENANCE.json)记录明确复用范围，航空建筑本体未复用其他楼网格。[可移植源码](source/)已在独立复制目录重建raw及未压缩LOD并逐字节核对；压缩两档按材质有向FLOAT32三角摘要核对相等，记录位于[重建检查](../../../data/audit/aviation-building-v1/author-portable-rebuild.json)和[压缩几何检查](../../../data/audit/aviation-building-v1/author-packaged-geometry-checks.json)。

作者实际查看front、roof、rear、oblique、entrance、crown、eastportal、connector八张原生图。八图由同一最终raw几何在保存前渲染，随后`.blend`实际保存、重开并验证建筑几何摘要相同；不是声称八图都在重开后重新渲染。参见[作者原生图检查](../../../data/audit/aviation-building-v1/author-native-visual-review.json)。全局网页、来源裁剪和碰撞检查另行记录。
