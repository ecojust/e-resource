# 裕华新村3号临弄院门与可见楼面

上海市第一批优秀历史建筑 **1B004** 登记「裕华新村」，地址为富民路182弄1–32、178、180、184、186号。地方文史记载，上海裕华银公司在1938–1941年间投资建造，由兴业建筑师事务所徐敬直、杨润均和李惠伯共同设计。东段16幢采用四坡顶耦合式住宅，西段20幢采用两坡顶耦合式住宅。这里制作东段182弄3号照片中可见的临弄院门与楼面。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/fe7b4d6f35774b708a2c5122849065bd.html) · [《裕华新村史话》](https://www.thepaper.cn/newsDetail_forward_7314165)

Livelikerw 于2014年2月14日摄得的竖幅照片中，院门左边的绿色门牌上可读出3。高翼有成对的狭窗和深色砖板，砖砌竖片越过檐口。退台一侧的宽窗左边后退，窗前有横栏，后方可见半圆上窗。院门位于楼墙前方，带矮砖围墙、石色门柱及细枝攀援的棚架。模型保留了这些前后层次。尺寸、门墙间距与受遮细节依实照估计。另一住宅单元、后墙、完整屋顶和室内留待独立研究。[2014年实照](https://commons.wikimedia.org/wiki/File:Yuhua_New_Residential_Quarter_2.JPG) · [照片时相、建筑资料与文件摘要](reference-review.json)

「裕华新村-3号」地址点位于14-13719-6695宏区881号粗模内，距质心约0.27米。2号在内弄北侧，4号在东南，门牌点分别落在独立单体2844及4645。19级航影可辨较宽的红瓦屋面，881的原生轮廓只描出屋内一小段。立面轴向取面向内弄的长边，具体门槛位置、方向和到主墙距离仍为估计。GPS或实测尺寸可用于将来校正。[门牌与地块复核](footprint-review.json) · [可编辑生成代码](source/elevation.py)

从上海项目目录运行，需 Python、Blender、gltfpack、ImageMagick 和 Open Image Denoise。

    python -B source/precise/jingan-yuhua-new-residential-quarter-03/source/build_model.py --out /tmp/yuhua/assets --audit /tmp/yuhua/audit --decoded /tmp/yuhua/decoded --gltfpack gltfpack --blender blender --oidn oidnDenoise
