# 熊佛西楼东南转角双层木围廊

上海戏剧学院华山路校区内的熊佛西楼见于第四批优秀历史建筑名录4B023，门牌为华山路630号。校方记录原楼建于1930年代，曾为外侨俱乐部。市表同门牌另列仲彝楼、健吾楼。跨街的美国学校办公楼在华山路639、643号。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海戏剧学院转载《新民晚报》](https://wmzx.sta.edu.cn/e5/a2/c3731a124322/page.htm)

本次截取南长廊最东端两开间和折向北的第一开间。两层方木柱沿外缘排列，斜撑接到梁枋，中间的木百叶遮住楼板边缘。窗洞开在靠后的青红砖墙上。铁栏和通风孔随基座转向东侧，两档几何均能从孔口看见后方深色凹面。近景另保留细铁花、上层木角花、分板与砖缝。[Legolas1024，2014年8月2日](https://commons.wikimedia.org/wiki/File:%E7%86%8A%E4%BD%9B%E8%A5%BF%E6%A5%BC%EF%BC%88%E4%B8%8A%E6%B5%B7%E6%88%8F%E5%89%A7%E5%AD%A6%E9%99%A2%EF%BC%89.jpg) · [Antigng，2014年5月21日](https://commons.wikimedia.org/wiki/File:%E4%B8%8A%E6%88%8F.jpg)

长短檐线用足印长24.47米、宽16.47米和东南斜照标定。模型的下层廊面约高0.86米，上层廊面约高5.08米，外檐约高8.38米。车体遮住的柱脚、内墙退深与构件厚度按照片约估。2018、2022及2024年屋顶正射提供转角朝向与院内相邻房屋位置。原城业主为14-13718-6695的2769号，OSM版本为w490279570@3。[测量点与三期正射记录](reference-review.json) · [OSM地块](https://www.openstreetmap.org/way/490279570)

原楼的其余开间、主屋顶、庭院附房与室内留待其他实测。两幅2014年照片的作者保留各自CC BY-SA 4.0署名，模型用独立网格和程序化材质建成。米制源以东南角为原点，X沿南墙向东、Y向北、Z向上。[几何源](source/veranda.py)
