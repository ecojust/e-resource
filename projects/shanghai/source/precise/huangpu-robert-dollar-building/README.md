# 大来大楼

大来轮船公司（Robert Dollar & Co.）原办公楼在广东路南侧。上海市房屋管理局第二批优秀历史建筑名录2A032登记广东路51、59号及锦江集团财务公司证券经营部、建设银行三支行两个使用名称。OSM独立建筑w378107108同时登记英文Former Robert Dollar Building和旧名大来大楼，源标记为八层。[官方名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [OSM地块](https://www.openstreetmap.org/way/378107108)

## 沿街立面

照片中能由西向东追踪九道底层拱门。拱门之间的花岗石水平缝在拱肩向上折转。进门扇、拱形门楣及部分扇形铁花低于连续卷饰檐带。上部成对钢窗按层重复，中央突出的长阳台下有多个石托座和金属栏杆。模型截取沿街约九米进深，源地块登记业主2245的后部保留原景。东邻在街景中有连排高柱和大檐，照片放大辨别后单列为邻栋。

2015年2月17日的原照由Livelikerw拍摄，许可CC BY-SA 4.0。照片裁切西端上檐，街车和电线遮挡部分门区，未获门号各自扇位和确切标高。楼层及阳台尺度、钢窗分格与背后屋面属推定。[原始街景](https://commons.wikimedia.org/wiki/File:Former_Robert_Dollar_Building_Shanghai.JPG) · [参考图与检索记录](reference-review.json)
