# 仁记路119号大楼红砖切角窗间

市第五批名录记“仁记路119号大楼”，现用作住宅，地址为四川中路420号、滇池路119号。Fayhoo在2014年11月29日拍摄同一街角，把照片题为“上海工业银行大楼”，并注明相同的两个门牌。模型采用市名录建筑名，取照片中三层红砖切角及两侧一截立面。

三处弧形窗篷是2014年照片中可辨的部分，安装年份尚无记录。砖券、石线、砖面和篷体分别建模，未使用街照贴图。
