# 武康路2号花园住宅南向弧形阳台与双柱

从花园望向莫觞清旧居，南面中央的阳台向前挑出，两根浅色塔司干柱托住弧形底板。栏板的绿色椭圆环之间留有空隙。站在栏杆斜侧，可以同时看见柱与内退的木框门。

上海市第四批优秀历史建筑名录4D025著录花园住宅，名称栏记上海科技文献出版社，门牌为武康路2号。地方文史记载洋房建于1922年，莫觞清于1926年购入。相邻的武康路4号由女儿莫怀珠与女婿蔡声白居住。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [张伟《武康路2号传奇》上篇](https://www.sohu.com/a/303528397_155927)

栏片、分隔柱、柱顶方板和门廊从徐汇区融媒体中心报道所刊南面资料图取形。资料图的拍摄年份未详。2024年正射可量出弧台宽约6.1米，端点的树影和斜视使估计误差约0.6米。柱的间距约3.7米，阳台向花园挑出的深度估为2.6米。模型覆盖南向中央一跨。原城轮廓1046与该宅足印吻合，现有数据尚不足以确定弧台外沿对应的地面位置。[徐汇区融媒体中心报道](https://www.163.com/dy/article/LB7EQPV005568W0A.html) · [照片与尺度](reference-review.json) · [地块对照](placement-review.json)
