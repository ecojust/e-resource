# 南洋大楼

南洋大楼位于南京西路与陕西北路交会处东南角。上海市第五批优秀历史建筑名录列入陕西北路204–216号双号及南京西路1175–1185号单号，编号5B041。2015年保护铭牌记载这座四层公寓1927年竣工。1941年七月《Shanghai Desk Hong List》的公寓名录与道路名录分别把 Continental Court Apartments 登在 Seymour Road 204号。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [保护铭牌](https://www.meipian.cn/4ja3bpdg) · [公寓名录](https://archive.org/details/1941-shanghai-desk-hong-list-july-edition/page/n101/mode/1up) · [道路名录](https://archive.org/details/1941-shanghai-desk-hong-list-july-edition/page/n547/mode/1up)

十二根水刷石尖墩分出十一个开间，底部石带随街角转折，三层红砖立面有75组窗。两幅早期街照可辨成对的窗和窗间石墩；四张较近的街角照片用于测量各墩的位置。204号门洞的四个小尖龛分列在浅凹石额两旁。门牌在两个时期的位置不同。模型采用绿色204号与保护铭牌同在右墩上的外观。[街角照片](https://blog.sina.com.cn/s/blog_5d1bdf480102zetd.html) · [门洞和铭牌](https://www.meipian.cn/4ja3bpdg) · [早期窗列对照](measurements/paired-window-period-comparison.json)

204号上方的浅色凸窗有三樘并列窗和两条石梃。斜照中的四个返回面按相同高度或单一出挑方向估算，窗面突出普通红砖面约0.49至0.66米。院侧拱口有原照，通道中段、受遮挡的店面间隔和屋面内侧按可见边界连接。地图保留原建筑135及相邻住宅，本件单独展示街面。[凸窗深度](measurements/204-splayed-bay-oblique.json) · [两条原照拱边](measurements/204-front-and-soffit-edges.json) · [底层店面](measurements/street-shops-roof-and-passages.json) · [建筑轮廓](measurements/footprint-review.json)

近景99,488个三角面，远景69,368个。每档分别实查门洞、店面和屋顶154处、尖墩374处、上层墙身397处及窗扇495处。204号门的43个独立照片像点有39个直接击中预期表材。独立留出的22个女儿墙照片像点有16个首击相符，其余6个先遇尖角砖面或灰边。[建筑源文件](source/build_model.py) · [资料与许可](SOURCES-LICENSE.md)
