# 清溪茶馆内院三联木格压花玻璃窗

高桥镇清溪茶馆内院里，三扇相邻的棕色木窗各留两组完整的长方格。中央长玻璃通高，两侧小格各有一根短横梃。三道横带内各有两块矮玻璃，左窗呈暖黄色，向右逐渐显出灰蓝色。

截取照片可完整辨认的上五排。单扇玻璃净宽估为0.445米。木框深度、玻璃表面压纹和未见的背面按可见反光近似刻画，真实尺寸待实测。

内院窗格见Fayhoo摄《Qingxi Chaguan》，2015年5月9日。蟋有的蟀2013年9月16日摄茶馆院门，题注同指东街20至22号。两照与此窗格模型按CC BY-SA 3.0署名。
