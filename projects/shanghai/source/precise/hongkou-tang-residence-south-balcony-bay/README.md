# 原汤公馆南门廊中跨弧形阳台与双柱

四川北路2023弄35号南门廊的两根中央通高石柱、科林斯式柱头、弧形阳台石边及铁花栏杆，并表现其后可见的红褐色木窗。

四川北路2023弄35号住宅建于20世纪20年代。虹口区资料记载南面四根石柱贯穿两层，外挑阳台覆盖底层入口。本件取中间一跨，花园侧斜照可以看到光面柱身、卷叶柱头、石质阳台边、黑色铁栏和后方棕红木窗。两侧其余柱与壁龛不在截取范围。柱距、栏高、窗深按照片比例推估。
