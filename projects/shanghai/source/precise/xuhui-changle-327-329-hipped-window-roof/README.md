# 长乐路327至329号住宅双窗上方的斜脊瓦顶

5D098在市表登记为住宅，门牌长乐路327-329号（单号）。Antigng在2017年8月19日拍摄的长乐路327至329号住宅照片中，沿街浅色墙上的两扇钢窗共用一片灰褐色瓦顶。两道浅褐斜脊从顶端向深色檐口张开，檐下露出一排短椽头。

屋面有连续深浅交替的瓦垄与叠瓦横缝；两道斜脊上的弧形盖瓦端头互相搭接。前檐平直而厚，底部短椽分开显露。 檐下两樘深色钢窗各有一面向外打开的格扇，另一扇接近墙面；窗底各有独立浅灰色短窗台。

原照与市表均同时列出327、329号。图内这片瓦顶无法细分到其中一个门牌。两条可见斜脊、檐口、窗扇的比例由照片估测；后半屋面与树木遮住的外墙未纳入取景。
