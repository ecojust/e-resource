# 康定东路85号李宅门廊砖雕拱券

修缮前保留的门廊一跨。弧顶的砖券内侧为辐射状砖缝，中段卷叶连续转过拱顶，外圈收一道细凸线。两边各保留一座带叶饰的红砖柱头及其下面可见的砌砖。

参照修缮记录中的600×400像素局部照片拟合券面两条轮廓。模型所取内券宽约3.10米、柱间名义尺度、砖雕深度与卷叶单元间距均为估算。砖墙在画框处截断，灯、黑色木梁与后室另计。

澎湃新闻《上海老建筑修缮记｜苏州河边的张爱玲出生地，如何重现原貌》，2021年4月发表。摄影图注“拆除后遗留的门廊局部（修缮前）（受访者供图）”。照片12用于辨识砖雕门廊。图2为沿街社区活动中心大门，所处位置不同。 [修缮报道](https://www.thepaper.cn/newsDetail_forward_12015167)
