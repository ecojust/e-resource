# 尚贤坊淮海中路主弄门楼

从淮海中路往里看，尚贤坊三个字竖列在两扇小窗之间，楼下的主弄穿过第一排住宅。模型选取两侧方尖碑之间的中央开间，依据上海黄浦发布的正视照片表现修缮后的清水红砖、曲线山墙、涡纹、石门框、木窗和内退铁栅。立面两边的独立商铺、东西街角、弄内其余三排住宅及地块北侧新楼由各自的资料确定。[2022年上海黄浦介绍及照片](https://m.thepaper.cn/baijiahao_20383137) · [完整来源与照片回执](reference-review.json)

2005年与2014年的近照记录灰白粉刷立面，可辨竖匾文字和窗栏细节。2018年市文物局、市规土局说明临淮海中路第一、二排以原址修缮为主，第三、四排因地铁工程拆卸编号，待原址复建。2021年1月街景已经显示沿街门楼的红砖，2022年区级照片正面确认。2024年街角实景还可见后方高楼施工，2026年9月同段沿街已有商铺营业。2025年公示图用于核对地块与主弄关系。[2018年原报道存档](https://web.archive.org/web/20180119235028id_/http://www.jfdaily.com/news/detail?id=77460) · [规划公示](https://ghzyj.sh.gov.cn/nw2268/20250714/39880461c5704d52b36e82cec20f5a0a.html)

名录1C003原表写淮海中路50号，OSM保护地块使用350弄，上海黄浦介绍和南门地图点写358弄，道路条目写350–358弄。落位采用临街地块长边与航片可辨的主弄轴线交点，平面位置估计误差约3米。门楼中央石框宽约7米，高约13.2米。前后纵深、侧面共墙、门窗深度及材质颜色根据照片比例、航片和门楼通道推定。竖匾字用开源字体重绘。模型的三维几何可按仓内MIT许可使用，三字字体子集另附 SIL OFL 1.1。[落位依据](footprint-review.json) · [源文件](source/gatehouse.py) · [字体许可](source/fonts/OFL.txt) · [独立模型查看器](../../../shangxianfang-gate.html)
