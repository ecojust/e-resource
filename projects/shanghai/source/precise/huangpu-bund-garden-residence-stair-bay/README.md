# 汉口路花园住宅临街错层楼梯窗

汉口路南向街墙上，两排细长钢窗沿楼梯向西升高。每排四窗，窗头分别错开约0.25至0.33米。近景模型刻画玻璃、凹入的钢框、窗套和红砖灰缝。远景保留八扇窗洞、钢格和石质边块。

市房管局第四批名录4A020记作“花园住宅，上海外滩花园酒店，汉口路200号”。2013年逐址街访和具名OSM标210号。两种门牌的出处均保存在来源文件中。三一堂、钟楼和九江路的旧英童学校各有独立足印。

2020年2月南侧街照可辨窗间的石色壁带与红砖交界。另两个角度的树冠遮住下排，杆后格条按同排可见窗估配。2014年署名Legolas1024的整体斜照用于辨认住宅其他墙面和坡屋顶。
