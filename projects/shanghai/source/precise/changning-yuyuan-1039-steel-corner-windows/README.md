# 愚园路1039号住宅转角钢格窗与下槛铁花

5M021在市表登记为住宅，门牌愚园路1039号。2018年2月的街照可见转角两面均有黑色方格窗。靠左的一面在窗下有一排直杆，转角右侧短面的窗套为浅灰色，其下栏心留有四段曲线围成的菱花。

黑色上悬段以一根较粗的横框与下部钢格分开。两面的窗框在黄墙转角两侧各自收边，右面框有一圈浅灰抹面。 窗腰下，正面直杆延到底，沿侧的一格把四段弧片围在中间直杆上。上下均有连续出挑的深色或浅灰线脚。

所建范围为连续楼窗中最靠前的一角。立面开间、窗腔和窗下铁栏的深度按透视比例近似；原照片没有施工年代和测绘尺寸。
