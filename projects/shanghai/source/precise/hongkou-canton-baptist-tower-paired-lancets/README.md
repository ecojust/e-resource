# 广东浸信会堂旧址塔楼双联尖券长窗

5F029在市表登记为广东浸信会，崇德小学，门牌川公路109号、新乡路66号。Fayhoo于2015年拍摄的广东浸信会堂旧址，临院塔楼正面有一对狭长尖券窗。蓝色中梃将上下两排窗格及米黄色下栏板分开，外侧一圈蓝色大尖券围合两孔。

两道小尖券各自起尖，合在一个蓝色大尖券下；中间浅色间墙有一个小菱形蓝饰，较近一侧窗台有蓝色凸出的边。 每孔上、下各有暗色水平细格，中间深色区域光差大，未补造其中构件。窗下侧有两块浅黄色的实板。

这件模型取2015年照片所见的塔面长窗。涂色按照片当时状态估计，来历及初建色彩未知；不据学校院落照片确定塔的经纬度或开口实测高度。
