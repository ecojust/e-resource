# 郭氏花园住宅折坡山墙木阳台

市表4M027列延安西路949弄25–47号，并在地址中排除37号。高参88于2014年刊出的两张仰视照片，可对上同一面阳台的窄槽、红色栏板和外露木托梁。上海长宁在2022年的记述中也写到南面跌坡式屋顶、深挑檐和露木构架。照片未将这个阳台标到某一门号。
