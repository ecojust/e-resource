# 狄思威公寓四川北路砖砌女儿墙冠与窗檐

市房屋管理局第四批名录记载，狄思威公寓现名溧阳大楼，地址为四川北路1914–1932号。[市名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)

2014年，Livelikerw从街口斜向拍到深红砖冠。凸脊有向两侧折回的砖边，浅色女儿墙经过冠脚，下面的窗各有薄板挑檐。2024年Windmemories的正面夜景显示，同一组冠体正面有五个升起的脊头。原图1800像素宽，冠体占约94像素，两窗中心相距约130像素。[2014年日景](https://commons.wikimedia.org/wiki/File:Liyang_Apartments_Shanghai.JPG) · [2024年夜景](https://commons.wikimedia.org/wiki/File:20240107_Liyang_Building,_North_Sichuan_Road.jpg) · [照片取点与署名](reference-review.json)

模型取这组街面上缘。五道脊按同一砖面转折，近景另有折回的水平砖缝。两个薄檐各自下折，钢窗凹入墙内。模型按照片比例取约6.72米宽；出挑和构件厚度为估值，两期照片没有给出修缮竣工日期。[置地说明](placement-review.json) · [建模程序](source/parapet.py)
