# 基督教内地会旧址北楼弧形挑台与交叉圆环铁栏

5B044在市表登记为基督教内地会/上海市第六人民医院，门牌新闸路1515-1533号（单号）、北京西路1400弄24号。依据Fayhoo于2016年2月12日所摄并标为北京西路1400弄24号五层北楼的照片，选连续三开间阳台中央一间最上两层。两层弧形出挑的阳台、铁栏和背后的两对窗均可见。

这组阳台共三个横向开间。所取中央一间上层的一对窗为弧顶，下层一对为平顶；每一层的两窗共用一座弧形阳台。 最外两根立杆间，中央细铁圈被两条对角线穿过。圆圈两旁各夹一块窄卷花板，再向外为密直栅，横向扶手沿弧连到侧端。

市表同时登记园内多楼，所选北楼未换算为现有院内楼号。栏下地坪、横檐向外出挑深度和侧接长度按单张斜照估计。中央左右的细部铁花仅可辨大致卷曲形态。
