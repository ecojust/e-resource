# 高桥季景北路608至612号街屋的四联折线格窗

5W047在市表登记为李元庆民宅、民宅，门牌高桥镇石家街27弄3号、季景北路608-612号（双号）。Fayhoo于2016年2月13日摄下季景北路608至612号街屋。临街赭色立面有几组楼上窗，610号绿牌在左侧方格窗下方；本件选择它右边的四联窗，窗内的斜格成对交替向中间收拢。

中间一组窗由四个细长扇组成，各有竖向中梃和三道短横梃；相邻层的两支斜线方向相反，其中间交点与竖梃重叠。 窗外墙面为偏赭色的水平分缝，左邻另一组方格窗下能读到绿色610号牌。跨窗斜穿的街线未作窗格。

5W047同列石家街27弄3号。照片只题季景北路608至612号，不能将这组窗归到石家街院内，亦不足以独断折格窗的单门号。材质和窗框厚度依正面照片近似。
