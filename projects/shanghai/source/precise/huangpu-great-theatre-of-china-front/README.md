# 中国大戏院牛庄路双塔入口

上海市房屋管理局第四批优秀历史建筑4A027的名称为“三星大舞台/中国大戏院”，公布时使用单位为中国剧场，登记范围为牛庄路700至714号。剧院对外使用704号门牌，正门由两座红褐色砖塔夹着，窄街对面能看到雨篷、中文院名和门上的英文院名。北京东路780号的黄浦剧场属于4A026，位于另一地块。[上海市房屋管理局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2018年修缮后报道与入口照片](https://www.chinawriter.com.cn/n1/2018/0630/c403994-30097155.html)

上海发布记载剧院于1929年兴建。开业日期有两种记载，2017年的报道记作1930年2月5日，2022年的“建筑可阅读”记作1931年1月30日。剧院在1934年易名更新舞台，1944年易名中国大戏院。2018年修缮后的街照片显示，上部有两座恢复的尖塔，中段下排三扇长窗、上排三扇短窗，塔窗外有浅色窗框和弧形窗眉。郑娜拍摄的2018年照片用于辨认门额与退进门厅，斜向街照用于判断尖塔形状。报道发表日与照片拍摄日分别记录。[2017年报道](https://www.thepaper.cn/newsDetail_forward_1644563) · [2022年“建筑可阅读”与修缮前后照片](https://www.thepaper.cn/newsDetail_forward_20975670) · [逐图来源、尺寸与摘要](reference-review.json)

模型覆盖牛庄路约25.55米街墙中央的10.8米。两座砖塔、各层窗洞、双语题额、挑篷和门扇各自建模。高度以公开资料所述23.2米为参照，塔宽、窗距和进深依据不同角度照片估计。砖纹自行绘制，文字依据实照转录后用开源字体重新排版。两侧长翼、后台和观众厅留待另行测绘。[原址和尺度依据](street-registration.json) · [几何作者文件](source/entrance.py) · [逐项网格复核](source/check_surfaces.py)
