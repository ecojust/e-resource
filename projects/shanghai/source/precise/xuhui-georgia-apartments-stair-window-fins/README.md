# 会斯乐公寓衡山路楼梯间竖窗与水泥线板

范文照设计的公寓沿衡山路展开。临街楼梯间的窗从地面以上连续上升，两侧住宅窗与其分开。这里取楼梯间靠西南的两列、上下两个楼层。水泥竖向线板通长，后方各扇钢窗可见两列八排透光格。历史平面、1960年代街景与设计叙述刊于上海当代艺术博物馆的范文照回顾。[范文照的住宅设计](https://www.sohu.com/a/556746714_121124747)

四处开口按2013年12月临街原片作平面校正。把《老上海经典公寓》的标准层平面与63.51米临街边线按比例对齐，可辨六道线板；所画三道线板的外轴相距2.21米，照片对齐后的净窗宽约0.78米。两期临街照片的联合估算给出下层净高2.27米、上层净高2.02米。钢框和水泥竖线的出挑深度按斜照估计。[Livelikerw 街景原片](https://commons.wikimedia.org/wiki/File:Georgia_Apartments.JPG) · [量测与出处](reference-review.json)

2015年12月和2020年2月的两次街景都拍到六根肋线、钢窗和正下方人行道。用标准层图的2.21米肋距校正两次相机角度，联合反算的下层窗台、窗头约高13.72、15.99米，上层约高16.75、18.77米。两期各自反算上层窗头相差1.37米。三根竖肋按图中轴线，四扇窗的分格按2013年近照，距地高度按估测保留。[两期逐点实测及误差](cross-date-window-elevations.json) · [标准层肋线](printed-plan-axes.json)
