# 市眼科医院3号楼西南弧窗与山墙

陕西北路805号原为花园住宅。市房屋管理局第四批登记编号为4B014，现用名为市眼科医院。医院康定路院区也使用康定路380号门牌。模型选取停车院西南端立有金色楼号3的窗间。站在院中面向主立面，它位于左手。参见[市房屋管理局登记](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html)和[医院官网](https://www.shsyf.com/)。

高参88于2014年3月发表的照片和Legolas1024同年7月的原照，从不同方向记录了楼号、两层凸弧窗和三层小阳台。两端壁柱有分层石带、圆盘饰及檐下齿块。上层的弧形门楣、卷草、台阶形曲线山墙和球饰均可从院地辨认。模型保留花瓶栏杆间的通孔、窗框的凹入深度和凸窗两侧的斜窗面。中央玻璃雨棚、另一端凸窗、后部红瓦屋面、附楼与两楼间楼梯平台另列调查。参见[二月照片与三月调查](https://blog.sina.com.cn/s/blog_5d1bdf480101hexu.html)和[七月原照](https://commons.wikimedia.org/wiki/File:Residence,_North_Shaanxi_Road,_Shanghai.jpg)。

## 尺寸与定位

旧城建筑712与标有4B014的OSM轮廓相交面积占并集98.56%。建筑两端的凸窗均面向东南停车院。窗间宽约6.48米，球顶高约17.84米，窗面弧弦宽4.46米、矢高1.47米，顶层曲栏矢高约1.23米。两个方向的照片给出的水平带和屋顶高度有差异，这些数值为图像比例估计。挂牌下方细字只记录行组。参见[定位依据](footprint-review.json)、[七月照片拟合](measurements/courtyard-facade-fit.json)、[独立机位](measurements/independent-cameras.json)与[弧窗采点](measurements/july-arc-depth.json)。

## 制作与署名

本模型的墙体、窗套、木格、屋面、栏杆与浮饰为独立制作的网格。玻璃纹理取自Legolas1024于2014年7月27日拍摄的《Residence, North Shaanxi Road, Shanghai》，依CC BY-SA 4.0许可裁切、缩放并拼合为五格色样。色样和嵌入模型的同一图像沿用该许可。两次拍摄的完整原图可在下面的来源页查看。详见[原照](https://commons.wikimedia.org/wiki/File:Residence,_North_Shaanxi_Road,_Shanghai.jpg)、[许可](https://creativecommons.org/licenses/by-sa/4.0/)及[取样程序](source/glazing.py)。

[编辑源文件](source/build_model.py)可重新导出近景、远景和Blender原生模型。[来源与尺寸记录](reference-review.json)保留登记行、资料页、图像日期、原始字节校验值和采用范围。
