# 华山路原美国学校办公楼

上海市房屋管理局第二批名录2B019载原名“美国学校”，列华山路643号、639号，以及中福会儿童艺术剧院、马可波罗俱乐部。2018年照片拍到639号门牌。2024年市政府报道以643号指院内受保护的1920年代办公楼，建筑面积约3165平方米。名录没有说明俱乐部所占用的具体房间。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [上海市政府2024年9月报道](https://www.shanghai.gov.cn/nw4411/20240905/834272bbeba446eeae049d777613d343.html)

639号门口拍摄的2018年照片与中国福利会旧照记录了朝华山路的门斗和阁窗。2024年区政府所刊现场照片记录了朝草坪的双层柱廊、弧形转角露台、细铁栏和红瓦阁楼。黑白旧照和现场照片可核实两面的具体构件，更新方案效果图只辅助辨认平面位置。[2018年门口实照](https://commons.wikimedia.org/wiki/File:%E4%B8%AD%E7%A6%8F%E4%BC%9A%E5%84%BF%E7%AB%A5%E8%89%BA%E6%9C%AF%E5%89%A7%E9%99%A2.jpg) · [静安区政府报道及院藏影像](https://www.jingan.gov.cn/rmtzx/003008/003008003/20240906/ffa0e119-8903-4f29-a769-20398d771580.html)

2018、2022、2024三期航片均可辨认草坪北侧的红瓦办公楼和西边长条形的马兰花剧场。原地图把两栋分为独立建筑3170和3433。院内其他排演空间、花园活动设施及舞台另有各自用途。衡山路10号1922年美童公学主楼对应徐汇区2D020。[逐图来源与方向](reference-review.json)
