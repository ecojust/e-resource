# 清心女中庚午校舍（北大楼）中央山花柱列正面

市房管局第三批名录3A021写清心女中、陆家浜路550号。工作名录另写650号及1920年。上海市美国问题研究所将北大楼具体辨认为李锦沛设计的庚午校舍，记1930年落成；2017年转载图页另记1933年竣工。早期女子学堂的创办、登记条目和这座楼的建造各有各的年代。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [上海市美国问题研究所，2023年](https://m.thepaper.cn/newsDetail_forward_24623168)

民国题署的斜面照片和2014年11月23日的北大楼正面照片均可辨中央五开间、四根通高柱、阁层窗、三角山花及中心圆窗。设计稿的山花画有飘带，模型采用照片所见圆窗和四枚突出石键。2017年是旧照转载年，原拍摄日期及原刊待考。独立历史展件沿两端壁柱及柱脚带收口，现行校园的使用安排、教学楼内部和所属其他楼栋各自另列。[民国照片和设计图的转载](https://tieba.baidu.com/p/5025644082) · [2014年照片，我爱波音哈，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:The_North_Building_of_Shanghai_No.8_Senior_High_School.jpg) · [来源、日期异文与原图摘要](reference-review.json)

1918年旧照展示早期清心女子中学校门。1947年行号图显示清心女子中学与清心中学隔陆家浜相望。另一个已登记项目清心堂位于大昌街30号，1923年落成，保护编号2A058。[清心堂的独立核对](../huangpu-pure-heart-church/README.md)
