# 扆虹园弧形端廊上下双券与铸铁栏杆

武进路扆虹园临园端廊，上下两层沿弯墙各开两道砖券。模型取两对通透的券孔、三道墩柱、上廊细铁栏和随弧线出挑的腰线与檐口。

据2026年2月8日的公开实照测记当时修缮外观。单券净宽暂取1.63米，两层皆有透空；柱距、归圆半径、栏杆数量、檐与楼板进深属于比例估计。
