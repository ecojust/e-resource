# 北京公寓街面椭圆花饰壁柱与双层窗楣

上海市房管局将北京公寓登记在北京东路163号。Antigng于2015年7月20日从街面对这幢红砖楼拍照，窗列一直伸向街角。这里取一跨上下两层窗和旁边的花饰壁柱。[上海市第五批优秀历史建筑名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Antigng原照，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E5%8C%97%E4%BA%AC%E5%85%AC%E5%AF%93.jpg)

上窗的砖券在长石形券心两侧展开，下窗三角檐的横线被垂石盖住。黑色铁栏在玻璃前方，椭圆花环和下垂串饰浮在浅色壁柱表面，两档的实射均可区分铁花前缘和后方直杆。 上窗净宽暂取1.55米。出檐、窗后深度、铁花曲线和砖块尺寸按斜照片比例估计。

163号门牌点在原城市编号760的建筑内。窗列重复，照片只给出一处街面视角。单体保留其装饰关系，城市保留整幢房屋。
