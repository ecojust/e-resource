# 建国西路598号花园住宅临街转角钢窗与赭砖窗垛

第四批优秀历史建筑名录以“花园住宅”列出建国西路598号。徐汇区政协的建筑记录说明两幢同式三层住宅各有自己的院落。2021年文章中的街门照片上可读绿色“598”号牌。[市房管局第四批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [徐汇区政协建筑记录](https://m.thepaper.cn/newsDetail_forward_14319144) · [街门照片](https://imagepphcloud.thepaper.cn/pph/image/151/643/365.jpg)

Antigng于2018年2月7日从街面拍下带门牌的院门和后方的建筑转角。模型依这张照片保留两层转角钢窗。临街窗分三跨，通长横亮下方有成对的绿色细窗扇。赭色贴面砖沿转角砌出一条窄窗垛，水泥窗台和中层挑檐均顺着短边折返。[现场照片与作者署名](https://commons.wikimedia.org/wiki/File:%E5%BB%BA%E5%9B%BD%E8%A5%BF%E8%B7%AF598%E5%8F%B7%E4%BD%8F%E5%AE%85.jpg) · [照片许可](https://creativecommons.org/licenses/by-sa/4.0/)

模型中每层临街窗的净宽取2.85米、窗高取1.72米。实际墙厚、窗格被枝叶遮挡的局部及赭砖缝深按照片估计。粗粉墙面纹理由程序生成，窗垛的横向砖缝、钢窗梃和挑檐均有实际厚度。[读图坐标与出处](reference-review.json) · [可编辑网格源码](source/corner.py)

2015年12月的三处街景都能对上598号临街南栋的三跨窗、窗右的红砖窄垛和折向侧面的窗扇。将同一窗垛的左右边分别交会，量得砖面宽约0.70米、相邻钢窗宽约2.83米。把各摄站的窗框读点移动2至4像素，估算窗宽在2.60至3.07米之间。原城市轮廓的南边比窗垛向街突出约2.38米，东边突出约3.33米。该模型独立展示，城市保留原楼体。[三个摄站与窗墙对照](street-registration.json) · [展示范围](placement-review.json) · [底图楼体](https://www.openstreetmap.org/way/1274527956)
