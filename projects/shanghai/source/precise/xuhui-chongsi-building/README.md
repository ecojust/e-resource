# 徐汇公学崇思楼

上海市房屋管理局第二批2D031将徐汇公学旧址列在虹桥路68号，项目的早期发现名录另记虹桥路50号。现行地图在原校园内给崇思楼单独标注了名称与轮廓，建筑中心约为东经121.431736、北纬31.194842。西面的另一个校园参考坐标与实体相距约927米。实名原生楼体316覆盖现行崇思楼地块的99.89%。[政府登记、两种门牌及原照](reference-review.json) · [原生楼体和校园边界](footprint-review.json)

学校创办于1850年。上海建工五建项目部记录了1917年1月8日奠基、1918年6月20日落成。负责修缮的上海交通大学建筑文化遗产保护国际研究中心记录为1918年，砖木结构，三层及阁楼，2009年至2010年完成这轮修复设计。施工方区分了1980年代初的改造与1990年代初因漏雨而拆掉原屋顶。保护设计单位记载了历史屋顶的损失，以及对孟莎式双折屋面、石板瓦和老虎窗的复原。2010年11月6日独立照片已经拍到恢复后的两段屋面，2012年交大的工程报道明确标注其图片为修复后的南立面。[施工项目部原始技术报告](https://www.shjx.org.cn/userfiles/images/WangZhanMuLu/f882327955ae4088911658f83a6b8fcd.pdf) · [保护设计单位](https://ahc.sjtu.edu.cn/Show.aspx?info_lb=31&info_id=57&flag=2) · [交大修复后实照](https://news.sjtu.edu.cn/jdyw/20180405/8120.html)

南面以入口居中，两侧布置贯穿上层的红砖柱、白色柱头、底层条纹墩、分段弧顶窗和百叶。中央屋顶窗用开口曲线山花，端部屋顶窗用弧形上楣。北立面依据保护设计单位的实照另作，两侧退入的墙段各有一座错层梯塔。2024和2026年两组航片中，邻近高层的屋顶因视差覆盖了崇思楼的一部分，定位与朝向取自实名建筑轮廓、修缮说明和地面照片。[南北窗墙](source/school.py) · [屋面、老虎窗和山花](source/mansard.py) · [柱头、石饰和门窗](source/window_bays.py)

地图原生轮廓约68.10×24.07米。模型对准该地块的中心和朝向，并采用施工方给出的东西轴线66.140米、南北轴线25.144米。结合2010年斜照中的两端墙角、中轴入口和檐线，主檐约14.52米，主脊约21.66米。屋顶各段进深和两端墙的遮挡处为照片估计。当前四级窗列包括阁楼老虎窗。邻楼、树木、室内结构和校园通道不纳入外观交付。[标高拟合记录](elevation-estimate.json) · [可复算的相机拟合](source/estimate_elevation.py)
