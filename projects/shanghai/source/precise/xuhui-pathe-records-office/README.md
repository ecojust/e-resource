# 东方百代唱片公司办公楼（百代小楼）

衡山路811号的这幢红砖楼建于1921年，现为义勇军进行曲灌制地纪念馆。市房管局第四批名录4D031登记的原名是“东方百代唱片公司办公楼”。区志资料记载主楼占地约192平方米，建筑面积约480平方米。历史照片中的厂房另有其址。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [区级建筑介绍](https://m.thepaper.cn/newsDetail_forward_14760545)

北面门旁两层大窗给出了砖墙的尺幅。2013年的照片保留了16毫米焦距。在四处墙面分别量得底层大窗高度约为22至23皮砖。按每皮连灰缝约65毫米，净高约1.47米，楼上、楼下窗台相差约3.27米。2021年的正面图还可辨出楼梯高窗后的斜段、入口弧形雨篷及低翼的瓦檐。[北墙两层大窗](measurements/north-planar-metrology.json) · [两个年代的机位](measurements/north-front-second-camera.json)

从南面的花园登上弧形石阶，廊前有两组双柱。西段上层四个开口伸向通长阳台，东端凸翼上下两层各有一道拱形大窗。树荫中的红瓦坡顶与紧贴西北面的低翼共同形成今日的外轮廓。[拍摄记录](reference-review.json) · [尺寸依据及估计范围](measurements/building-dimensions.json) · [来源与许可](SOURCES-LICENSE.md)
