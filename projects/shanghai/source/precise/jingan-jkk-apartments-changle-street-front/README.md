# J.K.K.公寓长乐路临街立面

上海市第五批优秀历史建筑将长乐路962弄1–4号登记为5B001。1937年英文街道名录在蒲石路956–958号旁印有“J.K.K. Apts.”，同页另列962号。1941及1942年的名录将公寓列在956–962号。老门牌与今天1–4号的逐户对应关系仍待史料确认。[历史名录扫描页及读数](measurements/historic-jkk-apartments-address.json)

从长乐路可以辨认四列三层阳台。每层楼板沿外缘转圆，两列相邻阳台之间有一道竖向分界。窗后浅墙设水平压线，东西两处楼梯间都向内收。西侧楼梯间有三个较高窗洞和一道独立横窗。模型表现2020年2月可见的墙色和开窗姿态，参照2015年的另外两季街景补读被树枝遮住的窗头及板缘。[阳台断面](measurements/jkk-balcony-sections.json) · [中央窗扇](measurements/central-steel-reconstruction.json) · [窗头交会](measurements/room-window-head-intersections.json)

望不见窗脚的阳台门采用估计下缘。屋面展示街侧挑檐和短截面，深度为估计。原底图中1、2号位于2963，3号落在另一轮廓145，4号接近955。独立街面模型保留这三处原轮廓与门牌资料。[位置核对](measurements/footprint-review.json) · [拍摄参考与许可](SOURCES-LICENSE.md) · [制作程序](source/build_model.py)
