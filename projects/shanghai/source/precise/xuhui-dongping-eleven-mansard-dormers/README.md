# 东平路11号宋氏住宅南坡三扇老虎窗

上海市第四批优秀历史建筑4D016登记东平路11号宋氏住宅。1921年落成的花园主宅最初为罗森菲尔德家族居所。修缮前后的花园照片均可辨南坡三扇方形老虎窗。修缮后的正面照显示每扇保留一对木框窗，细木棂分出小块玻璃，上方是有四道斜向叠线的浅色山花。斜视照补充了窗侧壁、屋面坡度和红瓦搭接。

模型依三条屋顶窗轴取约3.8米的间距。航片上两个轴间距分别约3.82米和3.76米。窗套的宽、高按近正面图比定，画面下方被南阳台挡住的窗槛采用估计。原城主宅编号336，主宅以北有独立辅楼467；2015年的街侧门面照片显示的是辅楼。目录同时保留东平路5号的音乐学院建筑。
