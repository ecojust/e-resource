# 卫乐园泰安路街门

卫乐园在上海市第二批优秀历史建筑中编号2M007，表列泰安路120号。2017年刊载的现场介绍指明总门位于泰安路120弄，31幢花园住宅由大陆银行在1924年投资建造。2019年新民晚报记者沈琦华另行拍摄了1号黄佐临故居的铁门与铭牌，可辨别住户门与总弄口。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [东方网，2017年9月10日](https://web.archive.org/web/20171122001949id_/http://sh.eastday.com/m/20170910/u1a13258959.html) · [新民晚报实地报道](https://baijiahao.baidu.com/s?id=1632932827078736788)

Livelikerw于2014年12月24日从泰安路对面拍摄正立面，原图宽4912像素。门洞两边的陶饰从门墩上的葡萄垂饰延伸到拱肩的卷草与顶部的中央花饰。两端墙头高于覆盖筒瓦的中段；右侧院墙压顶先下凹再抬升。模型将这些构件制成有厚度的网格，门扇朝院内开启。模型范围横向约16.9米。园内1号、10号及其余住宅保留为单独调查对象。[2014年正面照片及许可](https://commons.wikimedia.org/wiki/File:Willow_Garden_Shanghai.JPG) · [逐张摄影与来源](reference-review.json)

2021年1月两处街景的拍摄点相距约10.39米。分别量取同一门洞左右拱脚的全景水平角并求交，得到净宽约4.30米及距泰安路中心线约8.85米的门心。原生近邻住宅与弄口间有空地，门和墙段按现场单独安放。尺寸与绝对坐标均有误差；街景地图的“南门”点落在园内。[两站交会及邻屋](footprint-review.json) · [模型尺寸](source/parameters.json)
