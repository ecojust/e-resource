# 华亭路42号三座瓦顶门柱与铁栏

5D046在市表登记为住宅，门牌华亭路30、32、42、44、58号,延庆路132号。2018年2月7日Antigng拍摄的华亭路42号住宅街门有三座浅灰框、淡黄心的尖顶门柱，左柱挂绿色42号牌。两段黑铁栏一繁一简，本展取三柱与相接的铁栏。

三柱的黄心板上都有同色三角尖顶，两坡铺褐瓦，最上方为浅色圆脊。左柱绿色42号牌就在黄心板上部。 左栏可辨迂回卷草，另两柱之间的栏杆由竖铁和浅弧组成，底部有低矮的水泥墙。

5D046同时登记多处门牌，本展对应原照可读的42号。柱侧、瓦片搭接长度及铁栏后向尺寸为估计。左段卷草的部分轮廓被树叶遮挡，未补作完整铁门的内部扣件。
