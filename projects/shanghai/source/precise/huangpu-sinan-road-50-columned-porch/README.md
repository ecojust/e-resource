# 思南路50号花园住宅瓦檐门廊

思南路50号位于市房管局第四批优秀历史建筑登记的思南路50–70号花园住宅内。店铺公开门牌和2020年街景中门廊旁的金属「50」号牌共同确定地址。2017年斜照可辨一根圆柱、与墙相接的另一端和门上斜脊。2015年Antigng摄于附近街口的照片用来认街坊，门廊各件的形状依据2017、2020、2021年现场影像。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [2015年街坊照片](https://commons.wikimedia.org/wiki/File:卢湾区48街坊.jpg) · [门牌和拍摄站资料](reference-review.json)

模型包括瓦面小四坡顶、外伸过梁、圆柱、侧墙、铺石台阶、门扇和地址牌。2021年两处街景站的位置和俯仰角给出柱脚约0.74米、柱顶约3.13米、檐口约3.96米、屋脊约4.79米。中间踏级和门扇下格在照片中有遮挡，按可辨边沿估计。模型以原地面为零点，对齐此处底图东墙时含约1.47米的横向校正。[两站交会量测](photographic-survey.json) · [尺寸及误差](source/dimensions.json) · [原城底图身份](footprint-review.json)
