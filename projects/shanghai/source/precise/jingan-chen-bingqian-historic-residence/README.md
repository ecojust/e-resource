# 陈炳谦宅（原托益住宅）双塔与券廊历史正立面

上海市房管局第二批优秀历史建筑名录静安区第2B012*项登记“住宅／第二工业大学／陕西北路80号”，同区星号脚注注明约1994年灭失。第五批在同一地址另列第5B032项，原名“瑞士国总领事馆”，登记现名“上海第二工业大学教研楼①／上海市慈善教育培训中心”。模型入口采用陕西北路80号的街区定位。现存的校舍及周边建筑保留在现状图层。[第二批原表](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [第五批原表](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

高参88于2014年2月28日刊载《陕西北路80号托益住宅》，记旧门牌为威海卫路771号，称宅约建于1900年、原属托益，后来由祥茂洋行买办陈炳谦购得。原始营造档案和交易日期待考。文章刊有一张花园正面旧照，拍摄年份未详。另一幅标为1948年的航片显示外侧的双塔住宅与内侧的一栋楼。旧照刊载年、航片所标年份和住宅建造时间分别记录。[住宅图文及两幅图注](https://blog.sina.com.cn/s/blog_5d1bdf480101hdo2.html)

花园正面两端为折坡角塔，中间上下两层各有八跨券廊。下层拱券较圆，上层较扁，券后檐廊产生阴影。模型还表现层间横带、通透女儿墙、屋脊和烟囱轮廓。花木遮住庭院下部，只截取花木上方可辨的中央低矮轮廓。入口、台阶、背部平面与房间待有原图再考。局部窗棂、栏杆间距与砖色依图文近似，三维宽约38.55米、高约20.15米，均为按照片比例估算的展示尺度。未贴入第三方照片像素。[主立面旧照](https://s11.sinaimg.cn/mw690/001HIrzOzy7fASwVP747a&690) · [1948年航片刊载图](https://s2.sinaimg.cn/mw690/001HIrzOzy7noKTCaiJb1&690)
