# 宛平路7号上层三联格窗与齿饰檐口

5D078在市表登记为中共上海市纪委，门牌宛平路7号。Livelikerw于2019年2月23日拍摄的宛平路7号街面，最上层赭色墙面开深色格窗，细浅边框和外挑窗台围住三个并排窗扇。檐下的一列浅色方齿以阴影相隔。

每扇下部可辨两列三行玻璃，上部亮窗为两列两行；宽中横档和三联窗间的连续竖梃比格条粗。浅色平窗台在两端伸出。 两侧较突出的浅色壁柱有清楚的横缝，柱上小层叠托住通长檐线；窗上方方形檐齿各自投出阴影。画面中的树枝与架空线未归入建筑。

取原照片右段最上层、一对分缝壁柱之间的单窗。窗扇每组三列中的一列含两小格；框色、抹面色与可见接缝依当日记录。构件高宽与进深为照片比例估计，檐齿只表现所选一段。
