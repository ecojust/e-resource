# 小浦西公寓塘沽路圆角檐带与齿饰

上海市房管局第四批名录将塘沽路387–401号列为小浦西公寓。街角另一座有竖向阳台的红砖楼是浦西公寓，登记在相邻的4F004。2019年两楼同框的高位照片可对照屋顶与街墙的边界。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [两座公寓](https://commons.wikimedia.org/wiki/File:%E6%B5%A6%E8%A5%BF%E5%85%AC%E5%AF%93%C2%B7%E4%B8%8A%E6%B5%B7%E8%99%B9%E5%8F%A3%C2%B7%E8%88%AA%E6%8B%8D.jpg)

Fayhoo上传的街道照片能看到腰檐底面的两排细部。上层大方托在圆弧上均匀排开，中央卷状托座向下跨过腰线，下方还有密排的小齿。Legolas1024在2019年从另一侧高位拍摄，可由檐口顶面确认同一转角的弧度。模型保留弧段约6.2米，尺寸依两张照片比例估计。[街道角度](https://commons.wikimedia.org/wiki/File:Xiaopuxigongyu.jpg) · [2019年俯照](https://commons.wikimedia.org/wiki/File:%E5%B0%8F%E6%B5%A6%E8%A5%BF%E5%85%AC%E5%AF%93%C2%B7%E4%B8%8A%E6%B5%B7%E8%99%B9%E5%8F%A3%C2%B7%E4%BF%AF%E8%A7%86.jpg) · [地块对照](original-footprint.json)
