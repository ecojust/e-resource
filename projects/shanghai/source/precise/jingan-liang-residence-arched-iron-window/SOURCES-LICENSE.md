# 来源与许可

Aaron Zhu 于2012年7月4日拍摄《上海闸北区山西北路457弄61号之窗门》。原始像素为3240 × 4320。照片在 Wikimedia Commons 登记为 CC BY-SA 3.0。本项目校正照片透视、量取窗与砖券轮廓，并追踪上下两层铁花。原图保留作者水印。照片的裁切、并排比较图与派生模型均按 CC BY-SA 3.0 分发。[作者与原始文件](https://commons.wikimedia.org/wiki/File:%E4%B8%8A%E6%B5%B7%E9%97%B8%E5%8C%97%E5%8C%BA%E5%B1%B1%E8%A5%BF%E5%8C%97%E8%B7%AF457%E5%BC%8461%E5%8F%B7%E4%B9%8B%E7%AA%97%E9%97%A8_-_panoramio.jpg) · [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

Aaron Zhu 于2015年9月10日拍摄的梁宅山墙仅作为门牌、房屋和相邻建筑的核对资料。该原图同样按 CC BY-SA 3.0 共享。[山墙原图](https://commons.wikimedia.org/wiki/File:%E4%B8%8A%E6%B5%B7%E9%97%B8%E5%8C%97%E5%8C%BA%E5%B1%B1%E8%A5%BF%E5%8C%97%E8%B7%AF457%E8%B7%AF61%E5%8F%B7%E6%A2%81%E6%B0%8F%E5%A4%A7%E5%AE%85%E5%B1%B1%E5%A2%99_-_panoramio.jpg) · [共同作者和许可信息](measurements/gable-photo-source.json)
