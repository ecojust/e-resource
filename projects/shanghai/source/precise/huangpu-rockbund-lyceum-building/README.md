# 兰心大楼圆明园路入口塔楼与东立面

上海市房屋管理局第三批优秀历史建筑名录把黄浦区圆明园路185号列为3A014，表内另记渣打银行上海分行。2014年1月27日的街照在同一入口拍到门号185、中文楼名及两侧“LYCEUM”。茂名南路57号兰心大戏院另有独立的地址、模型和地图入口。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/bc5957926d80432b8bea0157eb16bb94.html) · [2014年街照，Livelikerw，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Lyceum_Building_Rockbund_Shanghai.JPG)

## 圆明园路东立面

模型的门洞含深色门扇、菱形气窗、双语字牌、浅石线脚和外挑门檐托块。塔身下部券窗带三角楣、石台和双托，顶部大券窗位于另一层。浅石塔角、北侧返面的券窗和最高水平檐交代了塔身的厚度。北翼在临街商铺上方分出窄窗和四组三联窗，另有临街栏栅、浅框矮窗与后退的两层。砖纹以米制贴图绘制，字牌用可编辑轮廓建成。[修缮东立面图](https://davidchipperfield.com/media/Projects/769-Rockbund-Project/769-dca-rockbund-project-dca-02.jpg) · [项目街景，Fangfang Tian](https://davidchipperfield.com/media/Projects/769-Rockbund-Project/769-dca-rockbund-project-fangfang-tian-03.jpg)

地块2358与门牌185的OSM第6版建筑轮廓重叠约97.83%。东边实长约30.75米，正面两端按近景与远景原始几何向内收边。照片与东立面尺图支持塔檐约35米，窗深、檐深与露台纵深为比例估值。屋顶背坡、后院、塔内楼梯和分期增层须另查档案。模型西端的中性截面用于接合底图。修缮项目期为2006至2023年，项目街景的摄影日尚无独立记录。[OSM原建筑](https://www.openstreetmap.org/way/446934736) · [修缮设计项目页](https://davidchipperfield.com/projects/rockbund-project) · [来源记录](reference-review.json)
