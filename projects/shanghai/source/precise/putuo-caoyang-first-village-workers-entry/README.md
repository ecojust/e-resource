# 曹杨一村工人住宅折角门廊与窄窗

1952年8月《人民画报》第8期刊载的工人住宅照片中，两层外墙在入户处转折。铺瓦的小雨篷出挑于深色门洞之上，旁边是一樘底边高于常规首层窗台的窄窗。向院中伸出的侧墙有两层分格窗，首层一片窗扇向外打开。

模型依据这幅黑白照片的可见部分，把灰泥、窗扇、门洞和叠瓦分别制作。色彩、背侧进深和尺寸为估算。2016年Fayhoo的高处全景可见成组的坡屋顶，2021年Antigng的照片记录了修缮期脚手架。原照未记此次所画住宅的栋号。
