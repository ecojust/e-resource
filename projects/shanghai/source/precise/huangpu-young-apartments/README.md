# 永业大楼与杨氏公寓

上海市房屋管理局的第二批优秀历史建筑名录在黄浦区 2C003 栏记载永业大楼，门牌为淮海中路 481–501 号单号、雁荡路 2–34 号双号。街口的弧形立面曾是聚兴诚银行所在地，上部为杨氏公寓。银行博物馆记载 1932 年委托马海洋行设计。旧照上已经建成的圆形日光室、低坡瓦顶和顶上小鼓座，与同篇收录的高塔设计草图外形不同。[市级名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [银行史图版与来源](bank-museum-plates.json) · [逐项核对](reference-review.json)

本次制作街角底层石面、商铺腰带、二层窄窗、三层弧形阳台和栏杆、筒形日光室与重檐小屋顶。2006 年的街口实照可辨底部连续弧栏和高两层退入石框内的分段栏杆，2014 年上传的署名照片证实三开间石框和砖色侧翼。没有复刻店铺标志、空调或临时遮阳设施。两条街翼只保留连接楼角的相邻窗组。母楼剩余两翼、更远的屋顶、院落和室内仍待建模。[2006 年实照](https://commons.wikimedia.org/wiki/File:Immeuble_de_1930_de_l%27ancienne_concession_fran%C3%A7aise_(Shanghai,_Chine)_(40031551192).jpg) · [Fayhoo 署名照片](https://commons.wikimedia.org/wiki/File:Young_Apartments.jpg) · [街景影像记录](street-receipts.json)

母楼使用 Overture 的 2824 号地块。两期航片及三处地块折点支持弧形外角的位置，19.2 米是底图的按层数估计值。阳台、日光室和重檐的高度按正面照片、街景仰角和档案照片比例估算。原照片出处与许可在资料记录中保留，第三方图像未嵌入模型。原创几何、材质及制作代码按仓库 MIT 许可发布，OSM 派生平面遵循 ODbL。[航片记录](roofs.json) · [底图来源和位置](footprint-review.json) · [建模参数](source/parameters.json)
