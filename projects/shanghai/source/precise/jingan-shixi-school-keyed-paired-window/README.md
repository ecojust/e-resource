# 市西中学2号楼双扇窗与咬接石窗套

5B016在市表登记为汉璧礼蒙童养学堂、汉璧礼西童公学，门牌愚园路404号。按Fayhoo 2015年12月26日所摄愚园路404号市西中学2号楼，仅重建院内正面一组深色双扇窗、窄石中梃和左右各三块伸入灰石面层的窗套。

浅色中梃两侧各有一扇深色窗框，窗上部横档贯通，左右各一条细竖格。 窗台略出墙，侧框各有三个短矩形石键。外墙面带密集粗粒，洞内四面向暗色窗框收窄。

照片可确定石套与外墙的轮廓、投影和上下分格；窗洞绝对尺寸、窗扇材质和石套背后的墙体厚度未测。
