# 资料与许可

上海市第五批优秀历史建筑名录5A064登记“郑家衖”，地址永嘉路39弄。2015、2017及2020年的不同拍摄站可以看见街口双柱、西柱绿底门牌以及门后的横屋。街景影像仅供研究，公开工程提供测量值和可复算的相机。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [弄口摄影站](measurements/zhengjia-entrance-cameras.json)

Antigng于2015年9月9日14时46分拍下弄内横屋，原始图片说明为“第五批优秀历史建筑”。Fayhoo于同年11月25日在图片说明中加入泰兴路383弄。街面实景中十二个窗和铁格角点、独立的“家政”招牌以及两台空调位置共同将原照定位到永嘉路39弄。工程保留图注变更与逐点误差。[原照片与版本记录](https://commons.wikimedia.org/wiki/File:%E9%83%91%E5%AE%B6%E5%BC%84.jpg) · [影像定位证据](measurements/courtyard-house-photo-identification.json)
