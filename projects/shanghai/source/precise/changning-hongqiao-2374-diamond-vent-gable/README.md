# 虹桥路2374号花园住宅菱孔山墙与筒瓦

长宁区规划资源局2012年8月16日公布的登记资料，将这幢两层西班牙式住宅认在上海动物园对面、新泾港西侧，并将建造年代列为1930年代。题照右侧较低的小屋清楚露出菱孔、搭接瓦和外开扇。画面右边切去了另一坡的大半，模型止于这一段。市名录另列邻近的虹桥路2419号住宅。
