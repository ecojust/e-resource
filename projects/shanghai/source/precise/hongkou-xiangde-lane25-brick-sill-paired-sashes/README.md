# 祥德路25弄住宅临院双扇格窗与竖砖窗台

5F005在市表登记为住宅，门牌祥德路25弄1号、2、3号。Fayhoo的2015年4月12日原照摄于祥德路25弄1号、2号住宅。临院红砖墙的两扇红框格窗在树冠下露出，窗内呈蓝绿色，窗下有一整排向墙外突出的竖砖。取下半部可见的框扇、窗台及墙边。

中央合缝比两侧窗扇内的细竖梃宽，横格穿过每扇窗内的细竖梃。下沿贴着竖砖砌成的窗台，台砖侧面有深浅变化。 临院面为暖红顺砖，浅色横灰缝连续，几皮砖的竖缝交错；窗框退入墙面。

现行市表还列3号。照片未给这扇窗的逐户门号，故按1、2号原照的范围题名。蓝绿色的表面是否属于玻璃或窗内织物未明，源图中树叶覆盖的窗上缘不作复原。
