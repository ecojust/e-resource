# 公益坊一号楼 · 四川北路1297–1311号

这幢三层商住楼沿四川北路西侧而建，修缮后编为今潮8弄一号楼。面对街墙，左边是有阶梯状竖肋的南段，右边是清水红砖的北段。北段二层、三层各有三跨外廊，每跨两组红褐色木门扇。朝街的铸铁栏片中，六辐圆轮与方折卷纹组成中段，两侧直条上方穿插小圆环。[房可圆《保护修缮篇》，上海章明建筑设计事务所供图](https://m.thepaper.cn/baijiahao_31065777)

## 两段街面的年代

南段现存设计图由施北光工程师事务所绘制，落款1931年7月9日。图纸在北边标有已有房屋，原设计南端第一间店较宽。1940年街景中，北段已经有连续阳台。调查报告把两幢商住楼合述为1936年建造，分段考证时另引了1931年图纸。[房可圆《历史调查篇》](https://m.thepaper.cn/baijiahao_31033143)

2015年12月街景和修缮前调查照都可见南段窗列已经改变。上两层现状从南到北各为三窗、两窗、两窗、两窗。1931年图纸上的通高装饰窗列单列在测量依据中。两篇报告为同一张修前照片标注了2018年12月和2021年3月，原图逐字相同，本研究只计一次观察。2021年的工程修缮了北段木门、铁栏、石饰与清水砖，南段保留既有形制。2024年天华总平面将这幢、居中的新建二号楼及南边975–987号三号楼分别绘出。[天华项目总平面和项目说明](https://www.thape.com/news/833)

## 尺度与使用

天华总平面50米标尺给出南段23.7米、北段16.5米。三站街景交会分别为25.04米和15.00米。1931年图纸上的常规轴距为17英尺4英寸，据四间门面全长估出南段约24.4米。模型结合三项依据，取全长40.05米，南段24.4米、北段15.65米；分段交界的误差约1.5米。两道外廊的出挑深度估为1.38米，误差约0.30米。南段坡瓦屋顶和北段平顶的分界以2018年航照及总平面交核。北端山墙有六块凹入暖灰石框的清水砖面。天华2024年鸟瞰还可辨出青绿透光设备屏、顶面格架与数个低矮箱体。修缮报告建议保留原屋面楼梯间，后期鸟瞰难以确定各箱体用途。背面与内部缺少同等精度的材料，模型将非街面收为平整截面。[原尺寸、图像边界与精度](measurements/frontage-measurements.json)

街面共30处实开上层门窗，底层7处店面。北段的双层阳台、铸铁花、深嵌木门、南段的三联与双联窗、实际瓦坡和北段平顶均可分别编辑。建模入口为 `source/build_model.py --output <文件.glb>`，远档增加 `--lod`。网页提供六处观察位置及下载。[独立展示](../../../gongyi-fang-1297-1311-sichuan-road.html) · [模型核验与实测图](../../../data/audit/gongyi-fang-1297-1311-sichuan-road-v1/geometry/README.md)
