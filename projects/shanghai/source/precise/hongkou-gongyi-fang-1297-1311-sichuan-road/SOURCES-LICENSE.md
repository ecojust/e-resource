# 来源与许可

- 上海章明建筑设计事务所提供的历史调查，房可圆2025年发布。图3为1948年行号图，图13为1931年南段原设计图，图14为1940年街景，图15为修缮前南北两段街面。[报告和原图](https://m.thepaper.cn/baijiahao_31033143)
- 上海房屋修建行业协会历保专委会供稿，资料来自上海章明建筑设计事务所。图3、图4为1297–1311号修前屋面，图7为临街立面，图14与17可辨修缮后的阳台、门扇、石饰和铸铁图案。街照在两个报告中的拍摄月份标注不同，详见研究表。[保护修缮实录](https://m.thepaper.cn/baijiahao_31065777)
- 天华设计，2024年5月14日。带比例尺的总平面区分现一、二、三号楼。图像权利依项目页标注，署名包括崇邦集团、DP建筑师事务所、上海章明建筑设计事务所、是然建筑摄影及天华。[设计方原文](https://www.thape.com/news/833)
- 2015年12月14日的四个公开街景记录按原站号及取图摘要列出，分别观察南端三联窗、居中竖肋、南北街面接合及北端边界。两篇2025年文章内相同的修前镜头共用一个图片摘要。[来源索引、像幅及指纹](measurements/sources-and-periods.json)
