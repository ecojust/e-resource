# 长乐路325号院内弧窗与红瓦券廊的资料和许可

上海市房屋管理局第五批优秀历史建筑名录将长乐路325号、陕西南路164号合列为5D111。2024年上海市住建委、市历保中心发布的建筑介绍和俯拍用于辨认院落及旁侧主体的关系。[名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [建筑介绍及俯拍](https://www.jingan.gov.cn/rmtzx/003008/003008006/20240709/1174d789-6e15-4a17-a47a-570f15625a48.html)
