# 长乐路325号院内弧窗与红瓦券廊

第五批优秀历史建筑5D111同时登记长乐路325号、陕西南路164号。2015年12月街景能读出基金会院门左柱上的绿色325号牌，2013年与2015年的街景能透过铁门看到院内弧形窗墙。Fayhoo在2015年4月4日拍摄的院内原照记录了同一窗墙和更深处的红瓦券廊、石阶与玻璃入口。临街书店和先前建模的长乐坊337号院门各有独立的位置。[市房管局原名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [上海市住建委、市历保中心的建筑介绍与俯拍](https://www.jingan.gov.cn/rmtzx/003008/003008006/20240709/1174d789-6e15-4a17-a47a-570f15625a48.html) · [2015年院内原照与作者署名](https://commons.wikimedia.org/wiki/Special:Redirect/page/39388838)

前侧窗墙分别制作了弧形粗砂外墙、挑带、钢窗和上部小窗。后侧入口保留前券、凹入玻璃门、两竖拉手和门底金属夹。陶瓦按坡面分垄、分片建模，前缘有16枚完整圆形陶面，最右一垄在前景遮挡处截止。石阶的十道鼻口分别在原照七个横向位置量取。左右下柱是浅碟形石饰，上柱是圆石球。近段栏杆、曲脚、压顶和两侧高度分别参照照片定位。

院内相机和四个街景机位给出了尺度和可见面的约束。弧墙半径估计约0.93米，挑出约0.43米。楼梯估计每级高0.168米、深0.365米，十级平台高约1.68米。券前落脚深度暂取0.45米，门玻璃后退约1.20米。这些数值保留了相机与遮挡带来的不确定范围。后方整排主屋、临街书店、院内其他住宅与室内陈设仍待核。[五站资料与门牌依据](measurements/wing-photographic-sources.json) · [石阶与前券的原始像素](measurements/porch-photo-controls.json) · [局部坐标及尺度拟合](measurements/porch-frame.json)
