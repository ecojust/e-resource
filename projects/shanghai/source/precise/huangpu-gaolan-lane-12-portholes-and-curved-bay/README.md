# 皋兰路12弄街面住宅双层圆窗与弧形带窗

上海市第五批优秀历史建筑名录将住宅登记在皋兰路12号，与思南路36号一项同印为5A012。这座住宅在原表第15行。Antigng于2018年7月30日摄得街面弧窗，画面下方的绿牌写皋兰路12弄1–4号，市级铭牌还列10号和14号。作品取同一画面里上下两层的圆窗与弧窗。[上海市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [Antigng《皋兰路12弄》，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:%E7%9A%8B%E5%85%B0%E8%B7%AF12%E5%BC%84.jpg)

正面观察，两层圆窗外圈均在红砖墙前方。上层深色钢框分出多道横格，下层浅色窗框分出短亮窗。斜看时，两层弧窗都比左侧圆窗墙突出，中间的水刷石腰带沿圆角转折。近远景的窗框和窗后玻璃可分别命中。 圆窗净径暂取1.02米。曲面半径与转角、窗后深度、外墙厚度及遮蔽部分按照片比例估计。下层明色窗框及上层深色钢窗按2018年拍摄状态表达。

地址定位中，12弄落在城市原屋3590，14号落在相邻原屋4245。街面照片可以辨认铭牌与窗列，还缺把这段墙的端点独立量到某一户的尺寸。独立页面展示这一跨外墙，原城保留整个建筑群。
