# 嘉定耶稣圣心堂尖塔透空三角与天主堂竖题

5S002在市表登记为耶稣圣心堂、宫保桥天主堂，门牌嘉定镇中下塘街99号。市第五批名录将耶稣圣心堂、宫保桥天主堂列于嘉定镇中下塘街99号。Fayhoo的2016年1月24日现场照片题为“圣心堂 嘉定中下塘街小囡桥西南堍”，从水岸正对教堂。只取其尖塔上部：浅色三角外轮廓、透光的下三角洞口、上方竖列“天主堂”及顶部细十字架。

洞口由外层与较内侧的两道斜缘围成；上端暗部可见两条交叉横材，晴空从下方贯通。 塔尖以圆形接点连接竖杆，竿上单横臂，外端均有小结；塔正中竖题三个深色字。“天主堂”用开放许可字体重绘。

照片记录2016年建筑现状，不能单从图中断定所见塔面的建造或重修年代。前后两道斜缘和洞内构件按透光与遮挡关系构造，塔深、文字笔画和十字架截面为估计。
