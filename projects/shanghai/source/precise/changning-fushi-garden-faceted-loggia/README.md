# 福世花园园侧折线浅拱敞廊与铁栏

安化路200弄。花园一侧二层敞廊的五段折线券底、外挑窗台、分叉花铁栏和后退的两樘玻璃门窗。

廊口按照片比例估计，净宽约3.58米，栏顶高约1米，后排门窗与栏杆相距约1.2米。被树枝和衣物遮挡的栏花间距与末端以照片中的重复间距推估。两张同栋照片可核，具体门牌缺独立可读证据。

未把照片中的阳台分配给具体门牌，按同栋现场第4/8图重构莳花园侧的二层敞廊。照片只署名引用，公开图为本模型独立渲染。
