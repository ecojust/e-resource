# 静安别墅25号院门与弄面院墙

南京西路1025弄列入上海市第二批优秀历史建筑，编号2B005。2013年12月12日的弄内实照清楚拍到25号绿色门牌、黑色双扇铁门与菱格铁饰、气窗、红砖门垛和层叠灰色压顶。本模型重建这些外侧构件及相连的一段院墙。门头约3.04米高，墙段连门垛约4.40米长，数字依据可见砖层及门宽估算。[2013年实照及授权](https://commons.wikimedia.org/wiki/File:Jing%27an_Villa_2.JPG) · [照片版本与实际范围](reference-review.json)

25号位于同排西南端，向东北依次为27、29、31及33号。门牌点与院门近照可核对这一顺序，卫星影像可辨南侧前院带与后方的连续屋面。住宅后部及邻户仍按当地原场景保留。[连排屋与前院核查](courtyard-roof-survey.json) · [底图来源与定位](footprint-review.json)

门面、铁栏、牌号、砖缝与压顶均为原创几何，未使用照片纹理。[生成程序](source/build_model.py) · [院门参数](source/gate_geometry.py)
