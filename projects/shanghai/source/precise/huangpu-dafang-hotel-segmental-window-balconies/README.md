# 大方饭店福建南路弧形窗楣与悬挑栏板

5A047在市表登记为大方饭店，门牌福建南路33号。第五批5A047登记福建南路33号大方饭店。2013年与2015年的同址图可读锦江之星的中英文招牌，2017年和2021年见康铂；取两期均可对照的上层临街双开间窗楣及栏板。

浅色栏板显著伸出墙面，两侧实墙折回，正面有窄横线与较短的折角收头。 每个窗口上方有分层浅弧压顶，弧线下可辨深色窗洞、直顶的窗扇及竖梃，栏板遮住下部窗框。

立面层高、构件厚度和墙体截深依照片比例估算。未定建造年代、墙材配方或改造年份，招牌和临时绿棚另有实照可查。
