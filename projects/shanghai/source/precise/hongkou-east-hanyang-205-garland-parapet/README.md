# 东汉阳路205号花园住宅右翼女儿墙花环垂饰

5F001在市表登记为花园住宅，门牌东汉阳路205号。Fayhoo的2016年2月6日庭院正照显示，花园住宅的左右两翼各有一块屋顶饰面。本件取画面右翼一块，复原向中央下垂的叶花、左端短叶坠、两头的卷带和直凹线边框。

两头系带下方有叶花串，曲线由两端向中间下垂；花串中可见大小不一的圆形凸点和斜向叶片。左头有更长的垂叶，右头的饰带向外翻卷。 饰面顶部与底部各有水平凸线，花串左右的窄直框内有长方形与成对短竖线。

未实测屋顶饰板的绝对尺度。枝叶的朝向按照片可辨的起伏排列，果花数量、背面厚度和被线缆短暂遮住的边缘为近似。
