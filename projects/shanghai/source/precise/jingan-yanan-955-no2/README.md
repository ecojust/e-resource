# 延安中路955弄2号住宅

上海市房屋管理局第二批名录将2B008列为“住宅”，地址为延安中路955弄（1–11号）。项目的历史线索另录延安中路931～979号。2号在延安中路南侧、955弄西侧，模型以面向道路的老虎窗和低凸廊为重点。[市名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [门牌、弄道与原楼定位](footprint-review.json)

2号名称点位于原生地块2661内，距离下一个地块20.49米。点位的地址栏同时含其他门牌信息，街景中的门牌被树木与围界遮住。2021年2月23日的三个独立道路机位可交会出同座长屋脊、两扇带尖顶的老虎窗与前方低檐。另核对2017年9月及2020年2月的街景。两扇老虎窗的影像射线平面残差为0.03–0.16米，车载定位与视向仍有系统误差；屋面交接和高度按比例估算。[街景日期、相机和来源](reference-review.json) · [交会数据与误差](roof-feature-triangulation.json)

原地块覆盖主体朝南的一条瓦坡。2018、2021和2024年发布的航片版本共同显示南坡、两处北坡开口和伸向前庭的低屋面。版本日期为影像服务的发布日期。树梢遮住部分外墙，模型将南侧窗列和墙体轮廓作概括处理。北侧其他红顶片、院门和弄内其余住宅保留在各自位置。[航片版本及逐瓦片来源](aerial-editions.json)

2024年街道更新报道明确提及同弄7号与9号的共同北后院，并称这批住宅留有红顶、黄墙和圆拱门廊。该工程用于区分相邻院落，2号的窗廊根据其自身街景绘制。[上海静安，2024年10月28日](https://www.thepaper.cn/newsDetail_forward_29183523)

独立网格包含屋面转角瓦脊、局部瓦垄、实际凿空的山墙老虎窗、内退窗玻璃与窗框、北侧低屋面和排水管。原始和网页文件保留瓦垄，远景保留屋形和各个窗洞。模型以米为单位，在Blender中以Z轴为高；局部X轴沿长屋脊指向东北偏东，Y轴指向北侧凸廊。模型未使用街景或航片纹理。[查看或下载](../../../yanan-955-no2.html) · [建模源码](source/house_geometry.py) · [导出脚本](source/build_model.py)
