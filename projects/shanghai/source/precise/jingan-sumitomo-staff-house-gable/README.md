# 司米托莫银行职员宿舍（培进中学6号楼）

上海市第四批优秀历史建筑名录将胶州路510号列为4B016「司米托莫银行」。上海静安2024年的报道说明，院内这座假三层花园住宅曾作住友银行职工宿舍，后来由培进中学使用。它与北邻522号龚氏花园住宅分属两个院落。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海静安，记者、摄影陈洁](https://www.thepaper.cn/newsDetail_forward_27269259)

本次制作院门内赭红色的胶州路侧山墙。三扇二层窗的中窗呈矩形，两侧窗的外肩分别向外下降。上部保留浅色木饰、阁窗、白色封檐板和前缘一小段红瓦。完整近景能看清浅色窗花和瓦搭接处，远景保留四个真实开口、深色窗框和两片挑檐。

2015年1月Livelikerw的斜照同时拍到另一朝向的浅色墙面和弧形阳台。2020年2月的两处街景以及陈洁2024年摄入「510」门牌的照片共同确定本件所取的红色山墙。两站交会将中窗上缘定在约7.3米、山墙脊尖定在约11.7米。树干遮挡了其中一站的脊尖，标高为近似值。其余坡屋顶、浅色弧形阳台、旧南门廊与地面仍由原场景表示。[2015年斜照，Livelikerw，CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:510_Jiaozhou_Rd._Shanghai.JPG) · [2017年校舍记述，乐宁工社](https://www.sohu.com/a/208584759_99933301)
