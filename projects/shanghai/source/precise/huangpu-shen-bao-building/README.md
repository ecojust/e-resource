# 申报馆

汉口路309号在汉口路与山东中路西南角。第二批上海市优秀历史建筑名录以2A034登记申报馆，使用单位一栏为三环房产公司。原有两层砖木报馆在1916至1918年间改建为钢筋混凝土楼。地块申报馆的名称、门号和五层记录也见于OSM。街角原照能区分四层较高的开口和檐下矮窗，矮窗所对应的实际楼层、房间分布及各次改建详图尚待核实。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [报馆沿革](https://zh.wikipedia.org/wiki/申报馆) · [地块](https://www.openstreetmap.org/way/414733200)

## 两条街面

2015年街照中，削角门额仍可逐字辨出「申報館」。二楼两侧石栏在门角旁收住，角窗上方有一条平檐。三、四层两街都有通高的竖槽壁柱和带卷饰的柱头，窗间墙有浅浮雕菱形轮廓。整排屋檐从街墙外挑，底部可分辨粗托座和一层较小的细齿。2016年独立照片同时拍到写有「汉口路 西」的路牌及斜面入口，能确认照片的两街方位。照片用于量形与人工描图。[2015年全景](https://commons.wikimedia.org/wiki/File:Former_Shun_Pao_Building_Shanghai.JPG) · [2016年正对汉口路一侧的近照](https://commons.wikimedia.org/wiki/File:%E5%A4%96%E7%81%98,_%E8%90%AC%E5%9C%8B%E5%BB%BA%E7%AF%89%E5%8D%9A%E8%A6%BD%E7%BE%A4,_%E6%9D%B1%E6%96%B9%E8%8F%AF%E7%88%BE%E8%A1%97,_%E4%B8%8A%E6%B5%B7,_%E4%B8%AD%E8%8F%AF%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9C%8B,_%E4%B8%AD%E5%9C%8B,_The_Bund,_Waitan,_Shanghai,_People%27s_Republic_of_China,_PRC,_China_(29832073123).jpg)

模型登记地块2422。源数据的汉口路街墙长34.68米、山东中路街墙长30.52米，两者之间的削角宽5.70米。本次取削角和每边最靠近路口的13.6米，均划成四个开间。栏板和柱头的具体剖面、窗棂格数、实际总高和屋顶深度都按照照片估计。保留两臂远端和原楼后部，周围的高楼也各依原地块。两张外景无法确定附件印刷厂的门牌、开工年代、厂房连廊和内部平面，待有资料再续。[足印](footprint-review.json) · [独立参考和原档散列](reference-review.json)
