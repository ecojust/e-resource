# 大桥公寓门厅方形几何拼花地面

市房屋管理局第四批名录的4F002将四川北路85号列为大桥公寓。Legolas1024拍下的2012年门头可见“大桥大楼”题字，2013年7月14日的街角正面照片标注了同一地址。隔邻的四川北路71号德邻公寓和18号瑞康公寓在名录中各有编号。[官方名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [门头](https://commons.wikimedia.org/wiki/File:%E5%A4%A7%E6%A1%A5%E5%A4%A7%E6%A5%BC%E9%97%A8%E5%A4%B4.jpg) · [街角正面](https://commons.wikimedia.org/wiki/File:%E5%A4%A7%E6%A1%A5%E5%A4%A7%E6%A5%BC.jpg)

2013年12月8日16时46分，Legolas1024从门厅向街道拍摄地面。赭红方块居中，黑色粗带分四向折出，细红线勾出外围方框。四角各有三条平行黑线；左后的一小段被金属扶手遮住。根据可见框边校正透视后，各色区域按同一水平面分件建模。[原始门厅照片](https://commons.wikimedia.org/wiki/File:%E5%A4%A7%E6%A1%A5%E5%A4%A7%E6%A5%BC%E9%97%A8%E5%8E%85%E5%9C%B0%E7%A0%96.jpg) · [摄影许可](https://creativecommons.org/licenses/by-sa/3.0) · [测读记录](reference-review.json)

独立展品包含方形拼花与外侧一圈素地。模型中的拼花边长暂取1.80米，剖边厚度和颗粒大小亦用作展示估值。两档均保留四角共十二条黑线。[可编辑源码](source/lobby_inlay.py) · [展示范围](placement-review.json)
