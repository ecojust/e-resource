# 资料与许可

上海市房屋管理部门第五批优秀历史建筑名录列合肥路592弄，编号5A056。门牌、地块边线与相邻房号的原始来源、坐标和日期均见[位置记录](measurements/footprint-review.json)。2015年2月9日多个街景观察位置用于量取同一墙面，2017和2019年的街景用来核对弄口和材料变化。可以按[街景相机登记](measurements/hefei-street-cameras.json)的相机编号复核公布的数值。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html)

这些观察图像属于其原平台。模型和材料包使用自行生成的网格、数值测量、颜色与灰泥纹理，项目将这些原创部分按MIT许可提供。门牌使用Noto Sans CJK SC Regular生成的四字子集。工程中附有[字体来源与修改说明](source/fonts/provenance.json)和[字体许可原文](source/fonts/OFL.txt)。
