# 广东路131弄券门与卷形拱心石

5A015在市表登记为复昌仓库、卓成洋行栈房，门牌广东路131弄。依据Livelikerw在2019年7月11日拍摄的广东路街景，取右拱脚有绿色131弄铭牌的通道入口。造型包括水平分缝、扇形券石、转折的石雕卷托及券底阴影。

131弄小牌正置于券口右肩，左边123号的蓝色门牌另属沿街商铺。 券脚以下是呈平行分缝的大块面，起券后接放射状楔块，块间有明显凹槽。 中心石前脸弯曲，侧面上下两端大小不同的卷眼可以辨别。照片中电杆及缆线遮住左半，券石规模依据可见右半估计。

左起毗邻商铺的蓝色门牌为广东路123号。券口右侧带131弄绿牌，能确定通道所在；两侧大部分内墙被电缆、车辆及行人遮挡。券宽、进深、背面和卷托外伸按图估算，缺少绝对坐标。
