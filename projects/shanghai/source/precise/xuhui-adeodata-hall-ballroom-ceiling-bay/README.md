# 天赐大宅舞厅圆形顶饰与弧肋

淮海中路1209号天赐大宅曾称Adeodata Hall。传世舞厅内景中，两枚亮色圆饰沿厅的长向排列，深浅相间的肋带从两侧起拱处伸展至平顶。模型截取前方圆饰所在的一跨，保留阶状环边、横肋、侧面弧顶及起拱檐线。独立展台支持从下方观看。

原黑白内景没有尺寸注记。圆饰直径设为2.60个展示单位，灰色材质用于区分照片中的明暗。远处另一圆饰、吊灯、家具和其余房间留待后续考据。作者手工绘制网格与中性材质，历史图版仅作参考。
