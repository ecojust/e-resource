# 圣三一基督教堂（主堂与花园门廊）

上海圣三一堂俗称红礼拜堂，主堂位于黄浦区九江路219号院内，东侧庭园通江西中路。现存的红砖教堂于1866年奠基、1869年开放，由 George Gilbert Scott 设计、William Kidner 调整。它之前的礼拜堂建于1840年代。北侧1928年的教会学校后来用作同仁医院、百乐饭店和黄浦区政府，第四批优秀历史建筑为这幢同址建筑另设条目。[Scott 家族史料整理](https://gilbertscott.org/holy-trinity-cathedral-shanghai/) · [同址建筑名录](../../../data/model-todo/discovered-buildings.json)

市房屋管理局2023年公布的第一批优秀历史建筑名录将本建筑列为 **1A025**，原名“圣三一基督教堂”，表内现名“黄浦区政府礼堂”，地址九江路201号。现宗教机构公布的联系地址为九江路219号。门牌沿用的年代有别，院内主堂和钟塔按照片与地图轮廓分别定位。[市房管局首批名录](https://fgj.sh.gov.cn/yxlsjz/20200331/fe7b4d6f35774b708a2c5122849065bd.html) · [主管机构现行地址](https://www.ccctspm.org/)

## 主堂与钟塔

1877年刊出的插图已能看见东山墙、六叶花窗、三拱入口门廊、两侧低矮的敞廊及近西端的横翼。后建钟塔的位置与主堂分离，1908年印刷照片上有低廊联系。塔尖在1966年被毁，2006年照片仍是平顶，2015年与2026年照片可见恢复后的尖顶。塔的建设日期有两种说法，Scott 家族网站记1893年完成，《Victorian Web》引 Darwent 记1901年奠塔基。主管机构记2007年启动修复，2014年举行修缮后首次感恩礼拜，列现塔尖高48米。Darwent 所述历史塔尖为105英尺，约32米。模型保留主堂的纵向外廊，向北伸至塔基的横向短廊随独立钟塔另查。[基督教全国两会的建筑记录与航拍照](https://www.ccctspm.org/churchinfo/396) · [1877年图、Darwent 尺寸和年代](https://victorianweb.org/art/architecture/scott/39.html) · [1908年全景](https://commons.wikimedia.org/wiki/File:Tcitp_d381_the_shanghai_anglican_cathedral.jpg) · [照片日期与实看记录](reference-review.json)

花园端有三孔门廊，中孔为半圆券，两侧为尖券。灰石圆柱承托交替砌色的砖券，廊顶有一排小拱栏墙。其后山墙设两层窄尖券和圆形六叶花窗，顶部为十字架。两边敞廊有通行空间，较高的中殿两侧连排高窗，灰色坡屋面在后方与横翼相交。模型根据2008年工地近照、2016年日照和2026年10月3日夜景复核同一组外部特征。门窗格、窗色、石柱剖面与灰缝只是外观近似。[修缮期东立面](https://commons.wikimedia.org/wiki/File:Holy_trinity_under_re-decorating.JPG) · [2026年照片分类](https://commons.wikimedia.org/wiki/Category:Holy_Trinity_Cathedral_(Shanghai))

## 尺寸和边界

Darwent 记主堂长152英尺、宽58英尺6英寸、高54英尺，约46.33、17.83和16.46米；中文条目写长约47米、宽18米、堂高19米。含柱廊和横翼的地图外边界宽于主殿宽度。三期19级卫星图可见主脊、后部横翼及东向门廊，屋面投影随期次偏移。主管机构发布的上方照片显示，西端有带短筒形屋面的半圆圣所，两侧各接一间较低的矩形附屋。模型按这些轮廓收口，屋脊、石线标高和被树遮住的西墙细节为估计。内部、管风琴、彩窗图像、独立塔楼、校园和围栏另待调查。[来源与空间收据](reference-review.json)

地图宏块 `14-13720-6694` 的 `587` 对应 OSM way `292718778`。建模原点取主堂东端地图边线中点，东经121.48200452、北纬31.23849256，X 正向沿立面朝北偏西343.41°，Y 深入教堂朝西偏南253.41°。glTF 使用 Y 朝上、Z 朝东侧花园。相邻 `1810` 为旧校楼。[OSM 主堂](https://www.openstreetmap.org/way/292718778) · [OSM 旧校楼](https://www.openstreetmap.org/way/292718777)

## 重建

在仓库根目录执行，环境需有 Python 3、NumPy、Shapely 2.1以上、Node.js、gltfpack 0.25、Blender 4.3、ImageMagick 7 和 Open Image Denoise 2.5。可用 `--gltfpack`、`--blender`、`--oidn` 指定工具位置。

```sh
python -B projects/shanghai/source/precise/huangpu-holy-trinity-cathedral/source/build_model.py \
  --out /tmp/trinity-assets --audit /tmp/trinity-audit
```

原创几何和代码采用 MIT，外观根据公开资料目视重建。照片仅用于研究，具体作者、年代、许可及原文件哈希见来源表。地图来源为 © OpenStreetMap contributors（ODbL 1.0）、Overture 派生数据，以及 Esri World Imagery Wayback 与其影像提供者。[MIT许可](../../../../../LICENSE) · [来源、署名与许可](reference-review.json)
