本件为江湾体育中心内独立封闭的综合体育馆历史主楼外观。已建室外主场看台环、南侧游泳馆及周边建筑分别处理；交付体育馆不等于优秀历史建筑名录 `sh-historic-b1-021` 全条完成。国和路346号与淞沪路245号来自整体育中心资料，单馆门牌尚未独立确认。

实际阅读六份文字资料的相关内容：董大酉1934年《上海市体育场设计概况》、江湾体育中心百科条目、杨浦官方2021介绍、上海体育局2009介绍、新闻晨报转载上海体育的2024文章及中天票务馆介绍。百科采用此前实际取回的修订94750796页面，固定修订链接另供查阅，没有把所有被引外文献自动算作已读。

原扫描重点阅读PDF14—15页的体育馆文字，并实际查看18、23、24页的体育馆透视、平面、正侧背立面三幅设计图。没有声称阅读全部85页。设计图是历史方案，不能代替现状照片或测绘。

## 六张照片与能确认的外观

实际查看两张旧运营站正门照片、一张2013年泳馆照片中的后方体育馆、2024文章中的两张高位全景，以及一张馆内顶光参考照，共六张目标相关照片。前三类共五张外观/背景照片；室内照片仅辅助理解弧顶和顶光，不用于本轮室内建模。另有三幅1934设计图，不计入照片数。

现代正门照确认西端为连续浅石墙，三大拱门上方是三条高竖格窗，窗下各有小挑栏台；后方露出红砖弧形山墙和灰色曲顶。这里没有已建主场西门的四高墩塔或双鼎。近门图可见拱框滚边、凹入门扇和小栏台孔饰；照片无法证明入口贯通整馆，不据此开放室内通行。活动横幅、临时旗及历史艺术透视中未获现代照片支持的夸张雕灯不作为永久构件直接复制。

2013年原图的主体和标题仍是游泳馆，体育馆位于后方；灰色金属肋弧顶、沿屋脊的窄长顶光带、南侧红砖墙局部上窗和西端低附体较清楚。结合后方教堂、主场及泳馆的相对位置，可以确认独立馆楼；树木遮挡处不能逐窗数。2024两张全景仅640像素宽，支持整体朝向与屋顶位置，不用于精细尺寸或花饰复刻。

2011年是运营站存档日期，版权行2008年不是摄影日期；2024年是文章发布日期，不是两幅高位照片的拍摄日。2013年Commons照片描述与EXIF同记2013-08-06。室内照片EXIF原摄时间为2005-12-12，处理时间却为2003-12-14，保留这一矛盾，不当作确定拍摄年份。

## 数值与边界

1934设计记整馆宽约46米、长约82米，中央运动厅约23×40米；两端桁架支点跨度42.7米（140呎），屋顶最高约20米、两边外墙约12米。百科另称钢桁架跨度46米，两种口径分别保留，不能将“整体宽”与“支点跨度”混为一项。

原文“開八角小窗各十六孔”是每侧十六个八角高窗，八角指窗形，不是八个窗。原文所述前后高窗、各侧窗列和设计剖面用于约束形制，现代树遮外照与室内照片仍不能证明每个现存开口完全未变。模型的米高、窗洞、板缝、后端与隐蔽构造均须在作者参数中标明估计。

现地图主源外包约72.88×44.85米，与设计82×46米尤其长度存在差异。地图轮廓也不是现场测量；不把长度差机械延成西门前长台阶，更不压过已有道路或占用相邻泳馆。定位、实际源替换及碰撞由本栋合同另行验证。

官方3500人与百科/票务介绍约2100人属于不同时点或容量口径，不据此反推建筑高度。1934年8月开工、1935年8月底竣工、1935年10月投入使用及百科表格1934启用的说法分别记录；不能只凭整体育中心修缮介绍给每个现存屋盖定年。

## 后续范围与使用

独立泳馆继续单列。1934泳池设计写“露天式”，2013年照片却已明确覆顶，后续须区分历史池馆外墙与现状屋盖，不能把早期露天方案冒充现状。主场既有局部边界、门台细部调查也不因体育馆完成而删除。
