# 归仁里康定东路过街楼

上海市第五批优秀历史建筑名录登记归仁里，地址为康定东路3弄。这里展示朝西北的主弄口及两侧紧邻的开间。2016年夏季正面照片能读到康定东路的绿色门牌，另几次冬季街景能看清镜心石饰、窗扇和穿堂前段。独立入口点落在原有城市轮廓1797内，弄内住宅保留现有轮廓。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [2016年高参88原照](https://s2.sinaimg.cn/large/001HIrzOzy72WuRSyZjc1) · [弄口和地块](measurements/footprint-review.json)

中央门洞净宽约2.68米，梁底约3.40米高。东墙八道红砖带围着上下两樘窗。西侧二楼窗廊相对弄口正面前伸约0.89米，实照能见开启的窗扇和十块横亮。门上“归仁里”另有刻字实形，门号的字样来自现场牌面。绝对尺度和被遮挡处的深度均按摄影估算。[门洞和立面量测](measurements/gate-layout.json) · [街景相机](measurements/gate-camera-registration.json) · [窗扇投影观测](measurements/window-photo-observations.json)

每个交付网格都复核了104条墙身截面、94处山花与题字、112处窗面和162处铁门或透空间隔。在另62处实拍照片取样中，57处直接命中所记材料，余下5处位于砖带和阴影边缘。[墙身与照片复核](measurements/released-gate-wall-verification.json) · [建模源程序](source/build_model.py) · [资料与许可](SOURCES-LICENSE.md)
