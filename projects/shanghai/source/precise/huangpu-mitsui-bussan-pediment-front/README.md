# 三井洋行四川中路东立面南端山花与入口

上海市房屋管理局第二批名录2A055登记「三井洋行、手表七厂办公楼、四川中路185号」。项目转录和具名地图足印写175号。2013年12月19日街照能读到四川中路路牌南175、北215，南端石门罩右侧的绿色小牌则写181。此处位于四川中路西侧、福州路北侧。九江路50号的三井银行另有独立建筑与已建模型。[市房管局2A055](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [181号实物门牌](../../../data/audit/mitsui-bussan-pediment-front-v1/green-plaque-181.jpg) · [具名足印](https://www.openstreetmap.org/way/380339927) · [九江路三井银行](../huangpu-former-mitsui-bank/README.md)

Virtual Shanghai建筑档案543记建于1903年，旧门牌为福州路100号。1908年出版的《Twentieth Century Impressions of Hongkong, Shanghai, and Other Treaty Ports of China》图版中可辨同一转角、上两层窗组和山花。另一张街面照片收于Virtual Shanghai，著录的估计摄影时期为1915至1935年。工作名录另记1937年和公和洋行；百科条目称平野勇造，现有材料缺少工程图签。此件按照片所见建筑制作。[建筑档案543](https://www.virtualshanghai.net/Data/Buildings?ID=543) · [1908年图版](https://picryl.com/media/tcitp-d629-mitsui-bussan-kaisha-premises-in-szechuen-road-baed3f) · [历史街照1558](https://www.virtualshanghai.net/Photos/Images?ID=1558)

Livelikerw的2013年原照可辨东面南端白石隅、底层双洞、二层双拱、三层三连拱及其上方的三角山花。石门罩在窗组北边，门扇后退。模型取这段红砖立面与相邻的一组竖向窗列。公共路口、北段东立面、福州路方向街墙和后部屋面沿用原有城市形体。立面尺度、石饰的浅浮雕、砖纹与被电线遮挡处按照片估计。[2013年街照与署名](https://commons.wikimedia.org/wiki/File:Mitsui_Bussan_Kaisha_Building.JPG) · [原件指纹及年代异文](reference-review.json) · [原创几何](source/pediment_front.py)
