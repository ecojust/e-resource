# 北京西路1394弄2号花园住宅

上海市房屋管理局第四批优秀历史建筑名录将4B006登记为「花园住宅」，原门牌为北京西路1394弄2号，表列单位为上海电气进出口公司。上海市文旅推广网以街门1394号介绍在园宅内开放的毕加索艺术馆。2013年拍摄的院门旁可以看到这四位门牌数字。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海静安毕加索艺术馆](https://www.meet-in-shanghai.net/cn/galleries/picasso-art-museum-jingan-shanghai-210760/)

Livelikerw于2013年12月12日从街对面拍到主楼南面、二层瓶栏露台和露台后的三组窗。市文旅推广网2025年刊用的独立近照可辨中央台阶、三道券拱、四根有竖槽的柱子、圆首门和扇形窗格，以及当时墙上的中英文馆名。模型使用自行描绘的轮廓和材质，远景档仍保留三孔、石阶和栏杆的贯通空隙。[2013年原照，Livelikerw，CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Lane_1394_West_Beijing_Road_Shanghai.JPG) · [馆前实照，上海市文旅推广网，未署摄影者](https://www.meet-in-shanghai.net/cn/uploads/2025/06/12/1933036426696314881.jpg)

两处OSM屋体同录4B006，又都把街路写作南京西路。场馆坐标位于临花园的较小屋体，市底图标识为1962；与其足印重合98.06%。东北方向的办公楼原城260距场馆坐标66.13米。模型局限于1962中央南面，侧翼、屋顶、院门和园内其余各栋沿用原城。[地点与两期航片依据](reference-review.json) · [两档原城屋体比对](footprint-review.json)
