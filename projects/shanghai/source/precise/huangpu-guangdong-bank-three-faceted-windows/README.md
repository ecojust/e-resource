# 广东银行转角塔三面切肩钢窗

5A023在市表登记为广东银行，门牌宁波路52号。按Fayhoo于2014年11月29日拍摄并题为广东银行、宁波路52号的现场照片，取转角塔顶层三扇切肩钢窗、窗顶浅色楔块及三级抬起的冠顶。

街角有连续三个略有转向的墙面，各设一扇深色长窗。窗头收成窄肩，顶部接一块上宽下窄的浅色墙饰。 中间一面最高，冠顶逐级抬起。三处窗下浅色带与下一排较宽的矩形窗竖向对齐。 钢窗的竖向细梃和数道横分格均可见。照片中的明暗受阴影影响，玻璃按中性冷色处理。

三面的折角、窗进深与顶层后侧缺少现场量测。画面中的空调、缆线及后加招牌不在此段建筑构件范围内。
