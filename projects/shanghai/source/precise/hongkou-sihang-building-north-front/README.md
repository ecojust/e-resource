# 四川北路四行大楼临街北段

1932年，大陆、中南、金城、盐业四家银行共同投资的大楼在四川北路建成。上海市房屋管理局第二批优秀历史建筑名录2F008列「四行大楼」「九州商厦」「四川北路1274号」。2013年关于修缮计划的报道给出1274–1290号，记载当时底层为商铺、楼上为住宅。以「四行大楼」检索的地图服务标作934号，该数据仅用于初步查找。[市房管局名录](https://fgj.sh.gov.cn/yxlsjz/20210922/8f72fa07617c4828a25ef948cd1c5da7.html) · [2013年修缮报道](https://news.sina.cn/sa/2013-11-19/detail-ikmxzfmk2648473.d.html)

Legolas1024于2012年4月29日由街面斜拍，影像可见长列窗间墙、逐窗挑檐和底层店铺。2021年1月6日四川北路街景提供六个带位姿的站位。从南往北，连续的褐砖横带转为带独立浅色竖墩的开间，顶层有弧形挑板和栏杆。靠北店面的三角小山花、三扇放射形气窗按2021年画面建模。照片反映相应年代，未推定店面装饰始自1932年。窗扇分格、材质色泽、檐口和层高均为估计。[2012年照片及许可](https://commons.wikimedia.org/wiki/File:四行大楼.jpg) · [影像采集与年代](reference-review.json)

三站交会定位北端与盛邦国际大厦交界处，在冻结城市源1243长边的北端约0.15米外。此长条为28.78×8.22米，横向西边伸至实景所见街面以外约6米。模型取北段有据的26.44米街墙及3.06米浅返面，保留人行道，沿南端截断。原图中的南部商面继续向两个其他来源单元延伸。市表没有给出每座保护建筑的地籍分界线。三期航空图日期为服务版本日期。[定位、交会与航片](frontage-location.json) · [近远城市源绑定](footprint-review.json)

模型以米为单位，局部X轴沿街向南，Y轴从街道向东。北端窄窗列与六列较宽窗分开；弧形阳台有实体板、栏杆和两者之间的空隙。原生工程保留可编辑构件，原始、网页与远景文件使用原创几何及纯色材质。[生成源码](source/build_model.py) · [构件建模](source/north_front.py) · [独立模型页](../../../sihang-building.html)
