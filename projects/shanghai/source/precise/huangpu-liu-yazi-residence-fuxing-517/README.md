# 柳亚子旧居（思南书局）主楼与东侧砖券入口

这栋住宅位于黄浦区复兴中路517号，建于1926年，柳亚子于1932年迁入。庭院在南，复兴中路在北。2018年修缮后用作思南书局，保留了临街山墙、灰色卵石墙面、红色坡瓦及朝东的砖券入口。第四批优秀历史建筑名录4C014还登记了531号、533–537号、539号和541号。此次制作仅涉及517号主楼。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200331/e3b99cf457ae48cab87ad5c02aa0fee3.html) · [上海市国资委](https://www.gzw.sh.gov.cn/shgzw_zxzx_gqdt/20240508/29566079c18847c18fce67a97319cab9.html) · [修缮单位项目页](https://www.wutopialab.com/worksinfo.aspx?id=8)

从东侧先登外部弧形石阶，到门槛后再穿过红色砖券廊，踏上通往二层的直梯。砖券边沿可以看到不同半径的砖环、凸出的起拱线及两边下垂的砖饰。南庭院一侧，下层是向花园开敞的柱廊，上面两层各有一对大玻璃窗，顶层石栏的菱形花格架在瓦坡之间。南北各有两座山墙，北墙窗洞的数量和位置逐层变化。[东门现状](https://www.thepaper.cn/newsDetail_forward_24699147) · [庭院立面、俯视照片与修缮图](https://www.archdaily.com/895564/sinan-books-wutopia-lab)

修缮图包括首层、二层、三层、阁层和两张剖面。将图上的外墙四角与城市轮廓配准后，矩形主体约宽17.71米、深10.90米。南庭院地坪至大屋脊约14.66米，至最高烟管约16.65米。两处年代不同的东向街景得到券口顶高5.78–5.96米、门槛高1.37–1.45米，两者的高程基准都是各自拍到的室外铺地。各处压顶、窗格、门洞内肋、烟管、檐口和侧墙细节为图像估算。可见通道、层板和门窗均有实体，室内家具与展陈未制作。[平面配准和剖面读数](measurements/first-floor-section-anchor.json) · [图纸与地面量测核对](measurements/plan-and-street-report.json) · [屋面测读](measurements/roof-study.json)

模型以米为单位，坐标原点在矩形主楼中心、南庭院地坪标高。正X沿南立面指向东偏北，真北方位角约78.37°。城市底图对应 OpenStreetMap w496382177（第2版）。原有近远模型将其拉伸到37.608米。楼外邻房、围界和同名保护组的其余门牌独立保留。
