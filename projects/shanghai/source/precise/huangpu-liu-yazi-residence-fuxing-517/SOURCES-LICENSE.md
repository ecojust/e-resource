# 来源和许可

建筑模型、建模程序、原创卵石纹理和据此生成的检查图按本仓库的 MIT 许可使用。卵石图案由固定随机种子和程序绘制，最终模型没有嵌入第三方照片、建筑师图纸或现成的三维模型。[仓库许可](../../../../../LICENSE) · [纹理生成器](source/generate_pebbles.py)

建筑设计与修缮图署名 Wutopia Lab。建筑摄影署名 CreatAR Images。新闻照片、公开地图街景和文字由对应来源署名，登记文件保留查阅时的原始链接和字节摘要。楼层和屋顶尺寸是从公开图像配准估计所得。各外部资料依其原有使用条件提供。[参考登记](reference-review.json) · [修缮单位](https://www.wutopialab.com/worksinfo.aspx?id=8) · [图纸与摄影](https://www.archdaily.com/895564/sinan-books-wutopia-lab)

建筑外轮廓与底图身份引用 OpenStreetMap contributors 数据，适用 ODbL 1.0。入口字样的字体来自 Noto Sans CJK SC Regular，字形子集另行重命名为 Sinan Entry Labels，并附 SIL Open Font License 1.1。题字、标志和照片中可见构件的形制均为据图近似。[OpenStreetMap 许可](https://www.openstreetmap.org/copyright) · [字体原作者与指纹](source/lettering/provenance.json) · [字体授权原文](source/lettering/OFL.txt)
