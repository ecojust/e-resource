# 松韵别墅总弄转角扇砖窗楣与木窗上扇

上海市黄浦区复兴路498弄1-8、10、11号。松韵别墅总弄转角楼的二层，木窗上方以红褐色立砖排成扇形，外圈另砌窄券。窗楣以上保留一段齿砖檐口，以下可见一对方形上窗与下扇上部。

依据2017年8月Antigng拍摄的《松韵别墅总弄》全幅原照，以窗框四个交点校正透视。暂按窗框宽1.26米、上扇高0.73米换算。穿过下窗的电缆后方和转角另一扇窗均超出本件取样范围。
