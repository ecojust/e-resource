# 荣康别墅常熟路南弄门及两侧街屋

上海市房屋管理局第五批优秀历史建筑名录将荣康别墅列在常熟路102至120号，编号5B061。1941年和1942年的街道名录在善鐘路112号写有“Gloria Estate”，并将108、120号作为各自的弄口另列。2017年实照中沿街店旁有绿色118号牌，同段店铺的一份旧商户详情写作常熟路118-1号。门头与历史弄号的具体对应仍有不确定性。常熟路100弄10号的上海歌舞剧院在市表中另有4B021登记。[上海市房屋管理局](https://fgj.sh.gov.cn/yxlsjz/20200414/b9946bf8508e4b9689671fcd4146bb86.html) · [1941年名录，第546页](https://archive.org/details/1941-shanghai-desk-hong-list-july-edition/page/n545/mode/1up) · [1942年名录，第115页](https://archive.org/details/shanghai-up-to-date-directory-1942/page/n424/mode/1up)

从常熟路西侧面对南弄门，可以看见低矮的双峰门额、灰色门墩、横向饰带、楼上浅色抹灰和窗间的竖向红砖饰面。2017年8月的照片记录了两侧店面与门柱上的字样。树叶遮住部分上窗，模型的上层转角和窗列另参考2015年至2021年多期街景。后部屋顶高度、窗玻璃退深和街面可见段的后部收口含估测。[Antigng摄《荣康别墅》](https://commons.wikimedia.org/wiki/File:%E8%8D%A3%E5%BA%B7%E5%88%AB%E5%A2%85.jpg) · [街面量测与估算范围](measurements/street-layout.json) · [窗洞定位](measurements/street-window-openings.json)

整街复核在每档模型上检查了257条实体截线和25个来源照像素，包含118号的数字与“8”的两个孔。[街面证据与三档结果](measurements/released-streetfront-verification.json)

原始模型保留灰泥、门额、窗扇、店招与门栅的可编辑构件。近景和远景模型各有同机位七张图，供比较门额凹处、窗格和店面。[模型生成程序](source/build_model.py) · [七个机位](source/cameras.json) · [资料与许可](SOURCES-LICENSE.md)
