# 英商自来水公司大楼（自来大楼）西南转角花饰

江西中路484号的西南斜角正对香港路口。2019年10月20日Legolas1024拍摄的俯瞰原片可见红瓦坡面、深色檐边、单樘矩形窗、花叶环饰与下方凸线素板。高参88的正面、侧向和浮雕特写补足了束带、花结与两条收卷的石饰。yiyi01831sh公布的另一组街照可交叉核对转角位置与层次。饰件的深度、标高与配色依照照片估计。

第四批优秀历史建筑名录将江西中路484号自来大楼列为4A002。隔香港路的江西中路464–466号自力大楼为4A003。两栋各有独立的足印和原生3D房屋，原生网格同在16户一组。模型保持484号的底层、两翼长立面及后加屋顶，并保留南楼与人行道。旧水塔和早期办公室只在沿革资料中作为辨认依据。

独立页模型原点位于西南斜面正中，长轴沿街角切面，斜面宽5.9686米。编辑网格、浏览近景及远景由同一组建筑组件导出，远景减少瓦垄、花瓣、卷叶和窗棂的细分。原照未作为模型纹理打包。
