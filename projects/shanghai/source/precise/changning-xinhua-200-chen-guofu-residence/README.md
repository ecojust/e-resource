# 新华路200号陈果夫住宅南面重檐外廊

长宁区第三批优秀历史建筑3M011。市历史建筑保护事务中心供稿记载这栋住宅1934年始建，甘少明设计，安泰营造厂承建，1948年改建。市文旅局的2023年报道着重记述了光佛寺旧址及1948年建造的阶段。这里曾用于《汉语大词典》编纂，2023年保护性修缮后成为上海电影艺术中心。

模型比较2010年1月15日庭院正面和2023年文旅局公布的庭院、内厅与卧狮照片。南面可看到两层外廊、入口的两组并柱、上层窄窗夹着中央内凹窗、朝花园突出的短瓦檐，以及正脊与檐角。两期正射上可分别辨认屋盖和轴线草地，19米进深是外轮廓约束。原城地块1241的27.8米是市模估高。首稿先做南院部分，背面窗洞、内厅格局和两狮个别差异尚待更多视角。

终版把庭院外廊的两头卧狮分别建成可编辑实体。2023年石狮近照用于确定卧姿、前爪与石座，成对布置依据2010年庭院全景。两狮背侧有视线遮挡。模型还纳入瓦鼻、悬檐底面、可透视的廊间开口、两组入口柱与园侧台阶。近档798个闭体、93,168个三角面，远档534个闭体、25,800个三角面。

2010年和2023年两幅院面照片分别标定相机。拟合均方根误差为7.73与7.28像素，留出像点的相应误差为14.51与11.11像素。四种表面有程序生成的颜色与法线贴图，观测点、取色资料和相机矩阵收在 measurements 目录。

从真北向顺时针计，南檐沿照片向右约110.62°。约25.04米宽、19.19米深为屋盖地理配准尺度，两期航片给出的地理位置约有1至2米误差。城图1241号原宅与周边地物保留，院面两档通过独立页面展示。
