# 新华路200号陈果夫住宅南面重檐外廊

长宁区第三批优秀历史建筑3M011。市历史建筑保护事务中心供稿记载这栋住宅1934年始建，甘少明设计，安泰营造厂承建，1948年改建。市文旅局的2023年报道着重记述了光佛寺旧址及1948年建造的阶段。这里曾用于《汉语大词典》编纂，2023年保护性修缮后成为上海电影艺术中心。

模型比较2010年1月15日庭院正面和2023年文旅局公布的庭院、内厅与卧狮照片。南面可看到两层外廊、入口的两组并柱、上层窄窗夹着中央内凹窗、朝花园突出的短瓦檐，以及正脊与檐角。两期正射上可分别辨认屋盖和轴线草地，19米进深是外轮廓约束。原城地块1241的27.8米是市模估高。首稿先做南院部分，背面窗洞、内厅格局和两狮个别差异尚待更多视角。
