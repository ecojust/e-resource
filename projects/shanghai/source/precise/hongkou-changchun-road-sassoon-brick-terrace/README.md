# 长春路沙逊楼群北立面八开间

沿着长春路望向南侧这一排住宅，屋顶依次出现一对并排山花、三座较低的屋窗、另一对并排山花。模型止于这八个开间。三层中央四扇窗用较浅的弧券，两侧双开间的窗券较圆。二层窗的弧形上亮与外面挑出的砖砌尖券分别建模。[打开三维模型](../../../changchun-road-sassoon-brick-terrace.html)

## 房屋和门牌

上海市房屋管理局将此组登记为第五批优秀历史建筑5F014，原名新沙逊洋行、东南日报，公布时用作住宅。市级名录列长春路307–365号与四川北路1938–1950号（双号）。项目早期发现表中的长春路307–381号是调查线索。长春路319号是有独立文献和门牌照片可辨认的其中一户。[保护记录、门牌照片与出处](measurements/historic-address-and-photographs.json)

2015年街景原片能读清左起第二轴楼门上的绿色319门牌。虹口区资料记载，1931年8月17日至22日，鲁迅在该址三楼举办木刻讲习会。今天的街前院门另设两块牌，和这块楼门号码牌分处两道墙面。[街道和既有建筑轮廓](measurements/street-front-and-address.json)

## 图像与尺寸

2023年区方刊载的正面照片决定八开间的范围、窗扇和木板围墙的外观。高参88的索尼相机于2015年4月25日拍下斜视原片。原照片上的屋脊、红砖券、门牌和水平灰缝使两个视角能互相核对。25个可辨认的同名特征在平面配准后，正面照片上的中位误差为1.21像素。采用物理相机再现的误差另记。2020年的实景中，沿街围墙仍是铁栏。[两站配准](measurements/two-view-north-front.json) · [相机、误差和单位](measurements/north-frontage-cameras.json)

展件采用局部坐标，面对墙体，X向右，Y向建筑内部，Z向上。七处灰缝的重复间距用于图像定尺，每皮砖连缝暂按6.3厘米，中央开间的代表间距约3.37个模型单位。出挑窗扇、坡瓦、三座低屋窗与四个山花分别设置进深。院墙距主立面的6.64个模型单位也属照片估值。这些尺寸仍待实测。后院、其余开间和室内未计入这一交付范围。[七座屋窗的平面与正面](measurements/roof-openings.json)

## 重建

从本目录运行，生成保留构件名称的近、远两档。三种砖纹由固定随机种子生成。原始照片仅用于测量，模型及网页对照图均由原创几何和材质生成。

```sh
python source/build_model.py --output terrace-full.glb
python source/build_model.py --output terrace-lod.glb --lod
python source/build_model.py --out assets-out --audit audit-out --blender blender
```

网页提供整体、砖券、楼门、屋窗和俯视等七个视角。原始近景和网页压缩近景均为135,612个三角面，远景为68,298个。审核记录保存各档的实际网格、逐三角纹理坐标、材料命中和照片比对结果。[审核目录](../../../data/audit/changchun-road-sassoon-brick-terrace-v1/) · [资料和许可](SOURCES-LICENSE.md)
