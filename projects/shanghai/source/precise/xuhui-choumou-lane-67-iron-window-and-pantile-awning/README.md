# 绸缪村67号北入口铁花窗与筒瓦雨厦

5D030在市表登记为住宅，门牌淮海中路1857弄67号。淮海中路1857弄67号北入口上方，矩形窗洞中嵌尖拱形铁窗。上部两条弯梃朝中央汇拢，拱肩留卷草铁花，下部双扇外有一排侧砖窗台。窗下向外伸出带重叠筒瓦的雨厦。

右侧矩形窗洞内可辨中央纵梃、两道横轨及上部成对弯梃。尖拱外、两侧拱肩内仍有小卷草，左侧楼梯长窗属于另一窗洞。 浅黄拉毛墙面上，窗台由一列侧砖砌成。雨厦后高前低，筒瓦逐道跨过下层板瓦，前缘露出瓦口。

模型表现发表照片里的北入口上部。高参88记原有的铁艺支托筒瓦雨厦已经改建，模型只复现图上的瓦面和前沿。玻璃色彩按照片明暗概括，雨厦背部、固定做法与实际尺寸缺少测绘。
