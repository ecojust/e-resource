### 崇明区

待补充逐栋精细建筑。该区已有全市底图，不表示已完成逐栋复原。

本轮新增徐汇区**巴金旧居主楼**。依据建筑文献及照片复原武康路113号主楼外观。

包含南侧折线山墙、拱形阁楼窗、绿色分格门窗、北侧拱廊入口、三层台阶与屋面瓦片细节。墙面使用原创卵石抹灰材质，提供可编辑Blender文件及可复现建模源码。

[网页模型](projects/shanghai/assets/models/precise/14-13718-6695/xuhui-bajin-residence/xuhui-bajin-residence-web.glb)（2,868,520字节）· [Blender模型](projects/shanghai/assets/native/precise/14-13718-6695/xuhui-bajin-residence/xuhui-bajin-residence.blend)（3,215,562字节）· [来源与验收](projects/shanghai/CURRENT_STATE.md)。

四件模型单文件最大5,069,420字节，均严格小于100,000,000字节。尺寸以2.20米门扇高度先验推估，约12.33米模型高度、隐藏北屋面及侧墙均非测绘结果；花园、附楼、围墙和室内未纳入本轮模型。全市建筑尚未全部逐栋精细复原。下载ZIP仍为v13旧启动包；更新请使用上方网页。
