# 传国玉玺 · 文章首图参考复原

![玉玺模型预览](preview.png)

以[搜狐文章《洛阳博物馆辟谣后，传国玉玺下落再成悬案，它最可能在哪呢？》](https://www.sohu.com/a/1091255651_122157668)的**第一张玉玺图片**为造型参考制作。文章中其他玉玺配图的形制不同，本模型采用首图的蹲兽钮、素面高方印和上角补金。

这是依据单张图片完成的三维视觉复原，不是经考古认证的传国玉玺原貌。原图没有显示的背部、底面及细节需要建模补全；模型尺寸为设计设定，并非对原图中物品的实测尺寸。

## 造型与尺寸

- 素面高方印，印体尺寸 **96 × 96 × 51.75 毫米**，整体高度约 **103 毫米**。
- 单首蹲伏兽钮，宽胸、圆肩、粗壮四肢，前爪落在印体顶面上；短卷角、张口獠牙和下垂长须构成面部特征。
- 身体采用浅刻卷云纹，保留首图紧凑、厚重的兽形轮廓。
- 玉质以浅象牙白与淡灰青为主，带柔和的云状色差。
- 不规则倒三角补金从印体的上部角位向下收尖，包覆相邻两个立面。
- 底面补设“**受命於天，既壽永昌**”八字凹刻，印面反字、钤印正读。首图未展示底面，因此该印文布局与字体均属于解释性补充；采用 **Noto Serif CJK TC Bold** 繁体字形，不作秦代篆书的精确复原。

模型由多个部件组成，保留相交几何，尚未整理成可直接三维打印的单一封闭实体。打印前应按目标尺寸进行网格合并、薄壁检查及切片处理。

## 重新生成

使用 Blender 4.3 或兼容版本，进入本模型目录后运行：

```sh
blender --background --python source/build_seal.py
```

可通过环境变量选择生成方式：

| 变量 | 取值与作用 |
|---|---|
| `SEAL_RENDER` | `final`：最终渲染，默认模式；`draft`：快速预览；`none`：生成模型而不渲染预览 |
| `SEAL_OUTPUT_DIR` | 指定生成文件的输出目录 |

例如：

```sh
SEAL_OUTPUT_DIR=./generated SEAL_RENDER=draft blender --background --python source/build_seal.py
```
